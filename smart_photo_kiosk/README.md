# 📸 Smart Tourist Photo Kiosk (ระบบค้นหาและพิมพ์ภาพถ่ายท่องเที่ยวอัตโนมัติ)

แอปพลิเคชัน Desktop ต้นแบบ (Prototype PoC) พัฒนาด้วยภาษา **Python + PySide6 (Qt)** รองรับการทำงานบน Windows สำหรับสถานที่ท่องเที่ยว ร้านถ่ายรูปธีมพาร์ค หรือจุดชมวิว

## 🎯 ฟีเจอร์หลัก (Key Features)

1. **Auto Folder Watcher:**
   - มอนิเตอร์โฟลเดอร์ภาพถ่าย (`demo_photos/` หรือโฟลเดอร์ที่ผู้ใช้เลือก)
   - เมื่อพนักงาน/ช่างภาพส่งไฟล์ภาพ JPEG เข้าโฟลเดอร์ ระบบจะสแกนและสกัดใบหน้าเก็บลงฐานข้อมูล SQLite ในเครื่องทันที
2. **Real-time Face Detection & Recognition (การตรวจจับและจับคู่ใบหน้า):**
   - ใช้โมเดล **YuNet** (Face Detection) ตรวจจับใบหน้าในภาพและจากกล้องหน้า Kiosk
   - ใช้โมเดล **SFace** (Face Recognition) สกัดเวกเตอร์ใบหน้า 128 มิติ (Face Embedding)
   - ค้นหาภาพที่ตรงกันด้วย **Vectorized Cosine Similarity** ใช้เวลาค้นหา **< 0.05 วินาที**
   - รองรับทั้งภาพเดี่ยวและภาพหมู่ (Group Photo) หากคนในภาพเดินผ่านกล้อง ภาพหมู่ก็จะแสดงขึ้นมาด้วย
3. **Smart Display & Instant Printing (หน้าจอแสดงผลและการสั่งพิมพ์):**
   - แสดงแกลเลอรีรูปถ่ายของลูกค้ารายนั้นขึ้นจอ Display ทันทีเมื่อเดินผ่านกล้อง
   - ลูกค้า/พนักงานสามารถคลิกเพื่อดูภาพขนาดใหญ่ ตรวจสอบความคมชัด
   - รองรับการเลือกพิมพ์เฉพาะใบ หรือกดสั่งพิมพ์ภาพที่เลือกพร้อมกันทีเดียว (Batch Print)
4. **โหมดจำลองทดสอบ (Simulation Mode):**
   - มีปุ่ม `🧪 ทดสอบด้วยภาพ` เพื่อทดลองเลือกภาพถ่ายมาทดสอบการค้นหาได้ทันที แม้ไม่มีกล้องหรือไม่ได้ยืนหน้ากล้อง

## 🚀 วิธีเปิดใช้งานโปรแกรม (How to Run)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ Batch (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์ **`run_kiosk.bat`**

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
cd smart_photo_kiosk
python main.py
```

## 🧪 วิธีทดสอบการทำงานของต้นแบบ

1. **ทดสอบด้วยภาพตัวอย่าง (ทันทีโดยไม่ต้องเปิดกล้อง):**
   - เปิดโปรแกรมขึ้นมา
   - กดปุ่ม **`🧪 ทดสอบด้วยภาพ`** ที่แถบด้านบน
   - เลือกไฟล์ `demo_photos/tourist_A_photo1.jpg`
   - ระบบจะตรวจจับใบหน้า และดึงภาพทั้งหมดที่มีลูกค้ารายนี้ (รวมถึงภาพเดี่ยวและภาพถ่ายคู่ใน `tourist_group_photo.jpg`) ขึ้นมาแสดงทันที!
2. **ทดสอบด้วยภาพของตัวคุณเอง (Live Webcam):**
   - ถ่ายภาพตัวคุณเอง 1-2 ภาพ แล้วนำไฟล์ภาพไปวางไว้ในโฟลเดอร์ `demo_photos/`
   - โปรแกรมจะสแกนรูปของคุณเข้าสู่ฐานข้อมูลอัตโนมัติ
   - เมื่อคุณขยับมายืนหน้ากล้อง Webcam ระบบจะตรวจจับใบหน้าสด แล้วดึงภาพถ่ายที่คุณเพิ่งนำไปวางขึ้นจอ Display ในเสี้ยววินาที!
3. **การสั่งพิมพ์:**
   - ติ๊กถูกเลือกภาพที่ต้องการ -> กด **`🖨️ สั่งพิมพ์ภาพที่เลือก`** หรือคลิกดูรูปขยายใหญ่แล้วกดพิมพ์
