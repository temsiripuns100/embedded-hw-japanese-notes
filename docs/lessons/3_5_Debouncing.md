# 3.5 チャタリング除去（Debouncing） (การกำจัดสัญญาณรบกวนจากการกดปุ่ม)

## 📖 ทฤษฎี (Theory - Engineering Perspective)
**チャタリング (Chattering / Bouncing)** คือปรากฏการณ์ทางกลศาสตร์ของหน้าสัมผัสสวิตช์หรือปุ่มกด (Mechanical Switch) เมื่อเรากดหรือปล่อยปุ่ม หน้าสัมผัสโลหะจะสั่นกระแทกกันหลายครั้งในระดับมิลลิวินาที (ms) ทำให้เกิดสัญญาณลอจิกสลับไปมา (1-0-1-0-1) อย่างรวดเร็วก่อนจะนิ่ง หากต่อเข้าวงจรดิจิทัลตรงๆ วงจรอาจเข้าใจว่าเรากดปุ่มรัวๆ เป็นสิบครั้ง!
**Debouncing** คือกระบวนการกรองสัญญาณสั่นนี้ออกไป สามารถทำได้ 2 ทาง:
1. **Hardware:** ใช้ RC Filter + Schmitt Trigger Inverter 
2. **Software/RTL:** ใช้ตัวนับ (Counter) ใน FPGA หรือหน่วงเวลาใน Code ไมโครคอนโทรลเลอร์

## 💡 ทริคหน้างาน (OJT Tricks)
- **ประหยัด BOM Cost ด้วย RTL:** ในงานผลิตจำนวนมาก (Mass Production) การลดตัวต้านทาน 1 ตัวและคอยล์ 1 ตัว (RC) สำหรับทุกๆ ปุ่ม สามารถประหยัดเงินได้มหาศาล! ทริคคือให้ใช้ FPGA/MCU จัดการเรื่อง Debouncing แทน โดยออกแบบ Counter ให้นับหน่วงเวลาประมาณ 20-50ms หากสถานะปุ่มยังคงที่ค่อยยอมรับค่านั้น
- **ต้องผ่าน Synchronizer ก่อนเสมอ:** สัญญาณจากปุ่มกดถือเป็น Asynchronous Signal เมื่อต่อเข้า FPGA ต้องนำไปผ่าน 2-Stage Synchronizer ก่อนเสมอ แล้วค่อยนำเข้าวงจร Debounce Counter เพื่อป้องกันวงจรนับรวนจากอาการ Metastable

## 🗣️ คำศัพท์และประโยคภาษาญี่ปุ่น
- **チャタリング (Chataringu):** Chattering / Bouncing (อาการสั่นของหน้าสัมผัส)
- **除去 (Jokyo):** Removal / Elimination (การกำจัด)
- **誤入力 (Gonyūryoku):** False input (การป้อนข้อมูลผิดพลาด)
- **メカニカルスイッチ (Mekanikaru Suitchi):** Mechanical Switch
- **カウンタ (Kaunta):** Counter (วงจรนับ)

**ประโยคที่ใช้บ่อย:**
> 「スイッチの入力にチャタリングが発生しているため、RTL側で20msのデバウンス回路を追加しました。」
> *(Suitchi no nyūryoku ni chataringu ga hassei shite iru tame, RTL-gawa de nijū-miribyō no debaunsu kairo o tsuika shimashita.)*
> "เนื่องจากเกิดอาการ Chattering ที่สัญญาณเข้าของสวิตช์ จึงได้เพิ่มวงจร Debounce หน่วงเวลา 20ms ทางฝั่ง RTL ให้แล้วครับ/ค่ะ"

## 📝 ควิซทดสอบ (Quiz)
**คำถาม:** หากคุณออกแบบวงจร Debounce ใน FPGA โดยใช้ Counter หน่วงเวลา 50ms แล้วพบว่าปุ่มกดตอบสนองช้าเกินไป (กดแล้วหน่วง) แต่พอลดเวลาเหลือ 1ms วงจรกลับนับจำนวนการกดเบิ้ล (Double click) เอง คุณคิดว่าช่วงเวลา Debounce ที่เหมาะสมที่สุดควรอยู่ในช่วงกี่มิลลิวินาทีสำหรับสวิตช์มาตรฐาน?
