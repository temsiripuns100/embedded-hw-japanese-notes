# 1.5 リセットICとシーケンス制御 (การทำงานของ Reset IC และการควบคุมลำดับการจ่ายไฟ)

## 📖 ทฤษฎี (Theory - Engineering Perspective)
**Reset IC** หรือ Voltage Detector/Supervisor ทำหน้าที่ตรวจสอบแรงดันไฟเลี้ยง หากแรงดันต่ำกว่าเกณฑ์ (Threshold) มันจะส่งสัญญาณ Reset ไปยัง CPU/FPGA เพื่อป้องกันไม่ให้ทำงานผิดพลาดในช่วงที่ไฟยังมาไม่ครบ
**Power Sequence (ลำดับการจ่ายไฟ)** ไอซีที่มีความซับซ้อนอย่าง FPGA หรือ SoC มักต้องการไฟเลี้ยงหลายระดับ (เช่น Core, I/O, PLL) และต้องการลำดับการจ่ายไฟที่ชัดเจน (เช่น Core -> PLL -> I/O) การเปิดไฟผิดลำดับอาจทำให้เกิดปรากฏการณ์ Latch-up (กระแสช็อตภายในชิปทำให้อุปกรณ์ไหม้) หรือทำงานผิดปกติ

## 💡 ทริคหน้างาน (OJT Tricks)
- **ขา Reset มักเป็น Active Low และ Open Drain:** ดังนั้นจำเป็นต้องมี Pull-up Resistor ทริคคือต้องมั่นใจว่า ไฟที่นำมา Pull-up ขา Reset นั้น ต้องเสถียรก่อนที่สัญญาณ Reset จะถูกปล่อย (Release) ไม่เช่นนั้นอาจเกิดสภาวะลอย (Floating) ชั่วขณะ
- **Power-Down Sequence ก็สำคัญ:** อย่าสนใจแค่ตอนเปิด (Power-up) ตอนปิด (Power-down) ก็สำคัญ! บางชิปต้องการให้ไฟลดลงตามลำดับย้อนกลับเพื่อหลีกเลี่ยงกระแสย้อนกลับ (Reverse Current)

## 🗣️ คำศัพท์และประโยคภาษาญี่ปุ่น
- **リセットIC (Risetto IC):** Reset IC / Voltage Supervisor
- **電源シーケンス (Dengen Shīkensu):** Power Sequence
- **立ち上げ (Tachiage):** Power-up (การเปิดไฟ)
- **立ち下げ (Tachisage):** Power-down (การปิดไฟ)
- **ラッチアップ (Ratchiappu):** Latch-up

**ประโยคที่ใช้บ่อย:**
> 「SoCの仕様書に従い、コア電源からI/O電源の順に立ち上がるようシーケンス制御を実装しました。」
> *(SoC no shiyōsho ni shitagai, koa dengen kara I/O dengen no jun ni tachiagaru yō shīkensu seigyo o jissō shimashita.)*
> "ได้ดำเนินการออกแบบควบคุมลำดับการจ่ายไฟ ให้เริ่มจากไฟ Core แล้วตามด้วยไฟ I/O ตามคู่มือของ SoC แล้วครับ/ค่ะ"
