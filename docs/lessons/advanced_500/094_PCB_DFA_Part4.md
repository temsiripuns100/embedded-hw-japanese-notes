## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในสายการผลิตประกอบแผงวงจรพิมพ์แบบอุตสาหกรรม การนำแผงวงจรเดี่ยวขนาดเล็ก (Single Boards) เข้าสู่เครื่องจักร SMT ทีละแผ่นจะทำให้ประสิทธิภาพของเครื่องจักรลดลงอย่างมหาศาล เนื่องจากเวลาที่สูญเสียไปในการโหลดและจับยึดบอร์ด (Board Transfer & Clamping Dead Time) จะกินเวลามากกว่าเวลาที่เครื่องใช้ในการวางอุปกรณ์จริง

เพื่อเพิ่มผลผลิตสูงสุด (Throughput Maximization) แผงวงจรเดี่ยวจะถูกนำมาจัดเรียงรวมกันเป็น **แผงวงจรพาเนล (Panelization หรือ 面付け - Men-tsuke)** พร้อมติดตั้ง **ขอบจับยึดสายพาน (Breakaway Rails / 捨て基板)** ซึ่งช่วยให้เครื่องจักรสามารถพิมพ์ครีมบัดกรีและจัดวางอุปกรณ์หลายสิบชุดได้พร้อมกันในการลำเลียงรอบเดียว

อย่างไรก็ดี ในขั้นตอนสุดท้ายของการผลิตเมื่อชิ้นส่วนทั้งหมดถูกบัดกรีเสร็จสิ้น แผงวงจรพาเนลจะต้องถูกตัดแยกออกเป็นชิ้นเดี่ยว (Depaneling / 基板分割) ด้วยวิธีการ **กรีดร่องตัววี (V-Scoring / V-Cut)** หรือ **การเจาะร่องขอบแบบรูปร่างมิกกี้เมาส์ (Tab Routing with Mouse-Bites)** หากวิศวกรออกแบบตำแหน่งรอยตัดและระยะเว้นชิ้นส่วน (Keep-Out Zones) ไม่สอดคล้องกับกลศาสตร์ความเค้นดัด (Flexural Bending Mechanics per IPC-JEDEC-9704) ความเค้นเชิงกลที่ส่งผ่านเนื้อแผงวงจรจะทำลายชิ้นส่วนเซรามิก (MLCC Cracking) และทำให้ลูกบัดกรีของชิป BGA ฉีกขาดทันทีในขั้นตอนสุดท้ายของการผลิต

### 1.1 เรขาคณิตของ V-Scoring และกลศาสตร์การแตกหัก (V-Scoring Fracture Mechanics)

การทำร่องตัววี (V-Scoring หรือ V-Cut) คือการใช้ใบมีดกลมประกบคู่บนล่างกรีดลงไปบนเนื้อวัสดุแผงวงจรทั้งสองด้าน เพื่อสร้างร่องนำสำหรับการหักแยกในภายหลัง:

```
                          V-Groove Blade Geometry
                                    \ 30° /
                                     \   /
                          ────────────\ /──────────── Top Surface
                          │           │ │           │
                          │   Core    │w│   Core    │ Board Thickness T
                          │           │ │           │
                          ────────────/ \──────────── Bottom Surface
                                     /   \
                                    / 30° \
                                  Remaining Web
```

#### 1. พารามิเตอร์เรขาคณิตตามมาตรฐาน IPC-2222:
- **มุมของร่องกรีด ($\theta_{\text{blade}}$):** ปกติคือ **$30^\circ$** (หรือ $45^\circ$ สำหรับบอร์ดหนา $\ge 2.0\text{ mm}$)
- **ความหนาของเนื้อแกนกลางที่เหลืออยู่ (Remaining Web Thickness - $w$):**
  $$w = \frac{1}{3} \cdot T_{\text{PCB}} \pm 0.05\text{ mm} \quad (\text{โดยทั่วไป } 0.35 - 0.50\text{ mm})$$
- **ความลึกของการกรีด (Cut Depth - $d$):**
  $$d_{\text{top}} = d_{\text{bottom}} = \frac{T_{\text{PCB}} - w}{2}$$
- **ความคลาดเคลื่อนตำแหน่งศูนย์กลาง (Runout Misalignment - $\delta_{\text{runout}}$):** แนวร่องตัดด้านบนและด้านล่างต้องตรงกัน โดยมีค่าคลาดเคลื่อนไม่เกิน **$\pm 50\ \mu\text{m}$ ($\pm 2.0\text{ mil}$)** หากร่องบนและล่างเยื้องศูนย์กัน ขณะหักแยกแผงวงจรจะเกิดรอยแตกเฉียง (Tear-out) ทำให้เนื้อเรซินฉีกขาดล้ำเข้าไปในลายทองแดง

#### 2. กลไกการถ่ายทอดความเค้นระหว่างการตัดแยก (Stress Transfer Mechanics):
เมื่อเกิดแรงดัด (Bending Moment $M$) เพื่อหักรอยต่อ V-Score:
$$\text{Bending Stress } \sigma_{\text{bend}} = \frac{M \cdot y}{I_{\text{web}}} = \frac{6 \cdot M}{b \cdot w^2}$$

- ที่บริเวณปลายแหลมของร่องตัววี จะเกิด **ความเค้นรวมศูนย์ (Stress Concentration Factor $K_t \approx 3.0 - 5.0$)** ทำให้เนื้อวัสดุแตกหักอย่างรวดเร็ว
- อย่างไรก็ตาม คลื่นความเค้นดัด (Flexural Strain Wave) จะแผ่กระจายออกไปในแนวระนาบแผงวงจรทั้งสองข้างตามสมการการโก่งงอของแผ่นแบน:
  $$\varepsilon_x(x) = \frac{\varepsilon_{\max}}{1 + \left(\frac{x}{x_0}\right)^2}$$
- **อันตรายวิกฤต:** หากช่างใช้มือหักแยกแผงวงจรด้วยแรงคน (Manual Hand Snapping) ความเครียดที่เกิดขึ้นบนผิวบอร์ดอาจพุ่งสูงถึง **$1,500 - 3,000\ \mu\varepsilon$** (เกินขีดจำกัดปลอดภัย $500\ \mu\varepsilon$ ถึง 6 เท่า!) ซึ่งเป็นข้อห้ามเด็ดขาดในอุตสาหกรรมยานยนต์และอุปกรณ์การแพทย์

### 1.2 การออกแบบร่องกัดและรูมิกกี้เมาส์ (Tab Routing & Mouse-Bites DFM)

สำหรับแผงวงจรที่มีรูปทรงไม่เป็นสี่เหลี่ยม (Irregular / Curved Profiles) หรือมีชิ้นส่วนยื่นเลยขอบบอร์ด (Overhanging Components เช่น USB, Audio Jacks) จะไม่สามารถกรีดร่อง V-Score ตรงๆ ได้ จึงต้องใช้การกัดขอบด้วยดอกเร้าเตอร์ (Router Milling) และเว้นสะพานเชื่อมยึด (Breakaway Tabs):

```
       Mouse-Bite Perforation Geometry
       
                 Routed Channel (Width = 2.0 - 2.5 mm)
                 ═════════════════════════════════════════════════════════ Rail Edge
                    │   │   o   o   o   o   o   │   │  Perforations
                    │   │  (Recessed Hole Line) │   │  Hole dia = 0.5 - 0.8 mm
                 ───┘   └───┬─┬─┬─┬─┬─┬─┬─┬─────┘   └─── PCB Board Edge
                            │ │ │ │ │ │ │ │
                            Breakaway Tab (Width W_tab = 4.0 - 5.0 mm)
```

#### 1. กฎเรขาคณิตของรูปรุ้งมิกกี้เมาส์ (Perforation Hole Rules):
- **ขนาดเส้นผ่านศูนย์กลางรูเจาะ ($D_{\text{hole}}$):** มาตรฐาน $0.50\text{ mm}$ ถึง $0.80\text{ mm}$ ไม่เคลือบทองแดง (Unplated Through-Hole - NPTH)
- **ระยะห่างระหว่างจุดศูนย์กลางรู (Center Pitch - $P$):** **$0.80\text{ mm}$ ถึง $1.25\text{ mm}$**
- **ความกว้างสะพานเชื่อม (Tab Width - $W_{\text{tab}}$):** **$4.0\text{ mm}$ ถึง $6.0\text{ mm}$**
- **กฎการร่นแนวเจาะรูเข้าไปในขอบบอร์ด (Recessed Perforation Rule):**
  - แนวเส้นกึ่งกลางของรูเจาะปรุ **ต้องร่นลึกเข้าไปในเนื้อขอบบอร์ด (Board Edge Offset) ประมาณ $0.20 - 0.35\text{ mm}$**
  - **เหตุผลทาง DFA:** เมื่อหักแยกแผงวงจร เสี้ยนทองแดงและเสี้ยนเส้นใยแก้วที่แตกหัก (Breakout Burrs / Nibs) จะจมอยู่ภายในร่องร่น ไม่ยื่นพ้นแนวขอบบอร์ดออกมา ทำให้บอร์ดสามารถประกอบลงกล่องเคส (Enclosure) ได้พอดี $100\%$ โดยไม่ต้องเสียเวลาและต้นทุนในการนำบอร์ดไปตะไบลบเสี้ยนด้วยมือ

### 1.3 ผลกระทบความเค้นต่อตัวเก็บประจุ MLCC และการจัดวางแนวแกน (MLCC Orientation vs Stress)

ตัวเก็บประจุเซรามิกแบบหลายชั้น (MLCC) ผลิตจากสารแบเรียมไททาเนต ($\text{BaTiO}_3$) ซึ่งเป็นเซรามิกที่ทนแรงกดได้ดีมากแต่เปราะบางอย่างยิ่งต่อแรงดึง (Low Tensile & Flexural Strength):

```
    [ CRITICAL FAILURE: Parallel to V-Score ]      [ ROBUST DFA: Perpendicular (Rotated 90°) ]
    
    ═══════════════════════════════════ V-Cut      ═══════════════════════════════════ V-Cut
            <── d_keepout ──>                              <── d_keepout ──>
            ┌─────────────────┐                            ┌───────┐
            │  MLCC Cap Pad   │                            │       │ Pad
            ├─────────────────┤                            │       │
            │ Ceramic Body    │ Flex along                 ├───────┤
            │ [ 45° CRACK! ]  │ long axis!                 │  Body │ Flex along narrow axis!
            ├─────────────────┤                            ├───────┤ (Bending moment minimized)
            │  MLCC Cap Pad   │                            │       │
            └─────────────────┘                            │       │ Pad
                                                           └───────┘
```

#### 1. ฟิสิกส์ของการวางขนานเทียบกับวางตั้งฉาก:
- **เมื่อวางขนานกับแนวเส้น V-Cut (Parallel Orientation):**
  - แกนยาวของตัวเก็บประจุ ($L$) จะขนานกับแนวการโก่งตัวของบอร์ด
  - แรงเฉือนจากรอยบัดกรีที่แพดทั้งสองข้างจะดึงรั้งตัวถังเซรามิก ทำให้เกิด **รอยร้าวเฉียง 45 องศา (45-degree Flex Crack)** วิ่งจากปลายขั้วโลหะทะลุเข้าไปยังชั้นขั้วไฟฟ้าภายใน
  - รอยร้าวนี้ทำให้เกิดการลัดวงจรภายใน (Short Circuit) นำไปสู่การไหม้ลุกเป็นไฟเมื่อต่อไฟใช้งาน
- **เมื่อวางตั้งฉากกับแนวเส้น V-Cut (Perpendicular Orientation - หมุน $90^\circ$):**
  - แพดทั้งสองจะอยู่ในระนาบรัศมีการดัดงอเดียวกัน โมเมนต์ดัดสัมพัทธ์ระหว่างสองแพดจะลดลงมากกว่า **$70\%$** ลดความเสี่ยงของการแตกร้าวได้อย่างมหาศาล

#### ตารางระยะ Keep-Out ขั้นต่ำของชิ้นส่วนจากแนวเส้นตัด Depaneling:

| ชนิดชิ้นส่วนและขนาดตัวถัง | ระยะเว้นจาก V-Score ($d_{\min}$) | ระยะเว้นจาก Mouse-Bite Tab ($d_{\min}$) | คำแนะนำ DFA |
| :--- | :--- | :--- | :--- |
| **MLCC ขนาด 0402 / 0603** | **$1.50\text{ mm}$ ($60\text{ mil}$)** | **$2.00\text{ mm}$ ($80\text{ mil}$)** | หมุนแกนตั้งฉากกับรอยตัดเสมอ |
| **MLCC ขนาด 0805 / 1206 / 1210** | **$2.50\text{ mm}$ ($100\text{ mil}$)** | **$3.50\text{ mm}$ ($140\text{ mil}$)** | ชิ้นส่วนขนาดใหญ่ไวต่อการแตกร้าวมากเป็นพิเศษ |
| **BGA / CSP / QFN Packages** | **$3.00\text{ mm}$ ($120\text{ mil}$)** | **$4.00\text{ mm}$ ($160\text{ mil}$)** | ป้องกัน Pad Cratering ใต้ลูกบัดกรี |
| **ตัวต้านทานชิปทั่วไป (Resistors)** | **$1.00\text{ mm}$ ($40\text{ mil}$)** | **$1.50\text{ mm}$ ($60\text{ mil}$)** | ทนทานต่อการดัดงอได้ดีกว่าเซรามิกคาปาซิเตอร์ |
| **ลายทองแดงและจุดเวีย (Traces/Vias)** | **$0.50\text{ mm}$ ($20\text{ mil}$)** | **$0.75\text{ mm}$ ($30\text{ mil}$)** | ป้องกันการฉีกขาดของทองแดงและการลัดวงจรขอบ |

### 1.4 การออกแบบขอบจับยึดพาเนลและประสิทธิภาพการใช้พื้นที่วัสดุ (Panel Rails & Material Utilization)

#### 1. ข้อกำหนดขอบพาเนลสำหรับการลำเลียงในสายการผลิต (Breakaway Rail Rules):
- **ความกว้างขอบจับยึด (Rail Width):** ต้องมีความกว้าง **อย่างน้อย $5.0\text{ mm}$ ถึง $7.0\text{ mm}$** เพื่อให้สายพานลำเลียง (Conveyor Belt Edge) และแคลมป์จับยึดของเตา Reflow/เครื่องพิมพ์ สามารถจับยึดได้โดยไม่ชนกับอุปกรณ์
- **รูจับยึดเครื่องจักร (Tooling / Tool Holes):** ต้องมีรูเจาะทะลุไม่เคลือบทองแดง (NPTH) ขนาดเส้นผ่านศูนย์กลางมาตรฐาน **$\phi 3.175\text{ mm}$ ($1/8\text{ นิ้ว}$)** หรือ **$\phi 3.000\text{ mm}$** ที่มุมทั้ง 4 ของพาเนล โดยมีพิกัดความเผื่อเข้มงวด $\pm 0.05\text{ mm}$ สำหรับสลักล็อกตำแหน่งแท่นทดสอบ
- **จุดมาร์กออปติคัลบนขอบพาเนล (Panel Global Fiducials):** วางที่ขอบรางอย่างน้อย 3 จุดในรูปสามเหลี่ยมมุมฉาก

#### 2. อัตราการใช้ประโยชน์แผ่นลามิเนตหลัก (Laminate Material Utilization Efficiency):
แผ่นลามิเนตตั้งต้นจากโรงงานผลิตแผ่นทองแดง (Master Base Sheet) มีขนาดมาตรฐานอุตสาหกรรม เช่น:
- $410\text{ mm} \times 510\text{ mm}$ ($16'' \times 20''$)
- $460\text{ mm} \times 610\text{ mm}$ ($18'' \times 24''$)

$$\text{Material Utilization Ratio } \eta_{\text{util}} = \frac{N_{\text{boards}} \cdot A_{\text{single\_board}}}{A_{\text{master\_sheet}}} \times 100\%$$

- **เป้าหมายเชิงเศรษฐศาสตร์ DFA:** ค่า $\eta_{\text{util}}$ **ต้องไม่น้อยกว่า $75\% - 80\%$**
- หากวางพาเนลแล้วเหลือเศษขอบทิ้งเกิน $25\%$ ต้นทุนค่าวัสดุแผงวงจรพิมพ์ต่อแผ่นจะพุ่งสูงขึ้นอย่างสูญเปล่า วิศวกรต้องปรับขนาดพาเนล (เช่น เปลี่ยนจากอาเรย์ $2 \times 4$ เป็น $3 \times 3$) เพื่อให้ลงตัวกับขนาดแผ่น Master Sheet พอดี

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例): ตัวเก็บประจุ MLCC แตกกระจายหลังหักบอร์ดด้วยมือ ทำระบบ Smart Meter ระเบิดคาสนาม

ในโครงการผลิตมิเตอร์ไฟฟ้าอัจฉริยะ (Smart Energy Meter) ผลิตแผงวงจรในรูปแบบพาเนล $2 \times 3$ บอร์ดเดี่ยวเชื่อมต่อกันด้วยร่อง V-Scoring:
- หลังผ่านการบัดกรี SMT และตรวจสอบ AOI ผ่าน $100\%$ พนักงานฝ่ายประกอบใช้วิธีนำพาเนลไปพาดกับขอบโต๊ะแล้วใช้มือกดหักแยกบอร์ดเดี่ยว (Manual Hand Breakout) เพื่อความรวดเร็ว

### ขั้นตอนการแก้ปัญหาและการปฏิบัติหน้างาน (Standard Operating Procedures)

#### Step 1: กฎการจัดวางทิศทางและระยะห่าง MLCC รอบแนวตัด (MLCC Placement Rules)
1. สำหรับชิ้นส่วน MLCC ขนาด $\ge 0603$ ที่อยู่ห่างจากแนว V-Score น้อยกว่า $3.0\text{ mm}$:
   - **ต้องหมุนทิศทางตัวถังให้ตั้งฉากกับแนวร่องตัด $90^\circ$ เสมอ**
2. ห้ามวางชิ้นส่วน MLCC ใดๆ เข้าใกล้แนว V-Score ในระยะน้อยกว่า **$1.50\text{ mm}$** เด็ดขาด หากพื้นที่จำกัด ต้องเลือกใช้ตัวเก็บประจุชนิดมีขั้วโลหะอ่อนดูดซับแรงดัด (Soft-Termination / Flexible Termination MLCC)

#### Step 2: ยกเลิกการหักด้วยมือและเปลี่ยนเป็นเครื่องตัดบอร์ดอัตโนมัติ (Automated Depaneling Machine)
1. **ห้ามใช้มือหักแผงวงจรเด็ดขาด (Zero Manual Hand Snapping Policy)** ในทุกสายการผลิต
2. กำหนดให้ใช้เครื่องจักรตัดแยกบอร์ด:
   - สำหรับ V-Scoring: ใช้เครื่องตัดชนิดใบมีดจานกลมวิ่งคู่ (Motorized Circular Blade Depaneler หรือ Pizza-Cutter Separator) ซึ่งควบคุมความเครียดให้อยู่ต่ำกว่า **$350\ \mu\varepsilon$**
   - สำหรับ Tab Routing: ใช้เครื่องเร้าเตอร์ตัดความเร็วสูง (Router Depaneler with Vacuum Dust Collector) ที่มีความเครียดเฉือนต่ำกว่า **$150\ \mu\varepsilon$**

#### Step 3: การตรวจรับรองความเครียดของการตัดแยกแผงวงจร (Depaneling Strain Validation)
1. ติดตั้งสเตรนเกจ 3 แกน (Triaxial Rosette) ที่ตำแหน่งชิ้นส่วนที่อยู่ใกล้รอยตัดที่สุด
2. ทำการตัดแยกบอร์ดจริงและบันทึกค่าความเครียดสูงสุด ($\varepsilon_{\max}$)
3. เครื่องจักรจะได้รับอนุญาตให้ผลิตจำนวนมากได้ก็ต่อเมื่อ **ค่าความเครียดสูงสุดไม่เกิน $500\ \mu\varepsilon$ ที่อัตราความเร็วปกติ** ตามเกณฑ์ IPC-JEDEC-9704

### 3.2 บทสนทนาและข้อความคอมเมนต์ตรวจแบบจริง (Realistic Kenzu Review Comments)

#### คอมเมนต์ที่ 1: ตรวจพบ MLCC วางขนานชิดแนว V-Cut เสี่ยงแตกร้าวจากความเค้นดัด (Vカット近接積層セラミックコンデンサのクラック是正)
> **検図指摘 (Review Finding 1):**  
> 「パネル境界のVカットラインからわずか0.75mmの位置に、1206サイズの積層セラミックコンデンサ（C12, C14）がVカットと平行方向に配置されています。基板分割工程における曲げモーメントにより、許容ひずみ（500με）を大幅に超過する応力が加わり、セラミック素体の45度せん断クラックおよび短絡破壊を招く危険性が極めて高いです。  
> IPC-JEDEC-9704の安全基準に基づき、C12, C14をVカットから最低2.5mm以上離隔するか、配置方向を90度回転させてVカットラインに対して垂直方向に配置してください。また、製造工程指示書において『手割り禁止』および『丸刃スライサー治具による分割』を特記仕様として明記してください。」  
> *(คำแปล: ตัวเก็บประจุเซรามิกขนาด 1206 (C12, C14) ถูกวางขนานกับแนวเส้น V-Cut ที่ระยะห่างเพียง 0.75 mm จากขอบพาเนล โมเมนต์ดัดในกระบวนการตัดแยกบอร์ดจะสร้างความเค้นที่เกินขีดจำกัดปลอดภัย (500 µε) อย่างมาก ก่อให้เกิดความเสี่ยงสูงมากต่อการแตกร้าวเฉียง 45 องศาในเนื้อเซรามิกและการลัดวงจรทำลายวงจร ตามเกณฑ์ความปลอดภัย IPC-JEDEC-9704 กรุณาเลื่อนระยะห่างของ C12, C14 ออกไปห่างจากแนว V-Cut ไม่น้อยกว่า 2.5 mm หรือหมุนทิศทางการจัดวาง 90 องศาให้ตั้งฉากกับแนวร่องตัด นอกจากนี้ ต้องระบุในเอกสารขั้นตอนการผลิตให้ "ห้ามใช้มือหักบอร์ดเด็ดขาด" และบังคับใช้เครื่องตัดใบมีดจานกลมเท่านั้น)*

#### คอมเมนต์ที่ 2: ทักท้วงขอบรางพาเนลแคบเกินไปสำหรับสายพาน SMT และขาดรูสลักยึด (捨て耳幅不足および位置決め基準穴欠落の指摘)
> **検図指摘 (Review Finding 2):**  
> 「本面付けデータの両サイド捨て耳（コンベア搬送レール）の幅が3.5mmしか確保されていません。標準SMTラインのコンベア爪クランプ幅（通常5.0mm）に干渉し、搬送不良（ジャム）やエッジ近接部品（コネクタJ1）の破損が懸念されます。捨て耳幅を最低6.0mmに拡張してください。  
> また、捨て耳の四隅にφ3.175mm（1/8インチ）の位置決めピン穴（Tooling Hole NPTH）およびグローバルフィデューシャルマークが配置されていません。マウンターの搬送位置決め精度を担保するため、基準穴（公差±0.05mm）とフィデューシャルマークを追加したパネル図面を再発行してください。」  
> *(คำแปล: ขอบรางจับยึดพาเนล (Conveyor Rails) ทั้งสองด้านมีความกว้างเพียง 3.5 mm ซึ่งแคบกว่าระยะแคลมป์จับยึดของสายพาน SMT มาตรฐาน (ปกติ 5.0 mm) เสี่ยงต่อการติดขัดของสายพานและการชนกระแทกกับคอนเนกเตอร์ J1 ที่อยู่ใกล้ขอบ กรุณาขยายความกว้างขอบรางเป็นอย่างน้อย 6.0 mm นอกจากนี้ ที่มุมทั้งสี่ของขอบรางยังขาดรูสลักล็อกตำแหน่ง NPTH ขนาด φ3.175 mm (1/8 นิ้ว) และจุดมาร์ก Fiducial Marks เพื่อความแม่นยำในการจัดตำแหน่งของเครื่อง Mounter กรุณาเพิ่มรูสลักอ้างอิง (พิกัดความเผื่อ ±0.05 mm) และจุดมาร์กในแบบ Drawing พาเนลใหม่)*

### Quiz 1: การคำนวณประสิทธิภาพการใช้พื้นที่แผ่นลามิเนตหลัก (Laminate Panel Nesting Efficiency)

**โจทย์:**  
โรงงานผลิตกำลังวางแผนตัดแผ่นลามิเนตหลักขนาดมาตรฐาน **Master Sheet: $410.0\text{ mm} \times 510.0\text{ mm}$** เพื่อผลิตแผงวงจรเดี่ยวขนาด **$65.0\text{ mm} \times 85.0\text{ mm}$**  
- การจัดเรียงพาเนล (Sub-Panel Assembly):
  - แต่ละพาเนลประกอบด้วยอาเรย์ของแผงวงจรเดี่ยว พร้อมขอบจับยึดสายพานด้านบนและด้านล่างกว้าง $W_{\text{rail}} = 7.0\text{ mm}$ ต่อข้าง
  - ระหว่างแผงวงจรเดี่ยวแต่ละแผ่นในพาเนลใช้การตัดแยกแบบ V-Scoring (ไม่สูญเสียความกว้างร่องกัด)
  - ขอบตัดรอบนอกของแต่ละพาเนล (Panel Border Separation) ในขั้นตอนตัดแยก Master Sheet ต้องเผื่อร่องใบมีดเร้าเตอร์กว้าง $S_{\text{rout}} = 4.0\text{ mm}$ ระหว่างแต่ละพาเนล
  - ขอบรอบนอกสุดของแผ่น Master Sheet ต้องเว้นพื้นที่ขอบทิ้งสำหรับการจับยึดของโรงงานผลิตแผ่นวงจร (Laminate Edge Margin) ด้านละ $E_{\text{margin}} = 15.0\text{ mm}$ ทั้ง 4 ด้าน (พื้นที่ทำงานจริงคือ $(410 - 30) \times (510 - 30) = 380.0\text{ mm} \times 480.0\text{ mm}$)
- เป้าหมาย: ต้องการเปรียบเทียบการจัดอาเรย์ของพาเนล 2 รูปแบบ:
  - **รูปแบบที่ 1:** แต่ละพาเนลมีขนาด $2 \times 3$ บอร์ดเดี่ยว (กว้าง $130\text{ mm}$, ยาว $255\text{ mm} + 14\text{ mm}$ ราง $= 269\text{ mm}$)
  - **รูปแบบที่ 2:** แต่ละพาเนลมีขนาด $3 \times 2$ บอร์ดเดี่ยว (กว้าง $195\text{ mm}$, ยาว $170\text{ mm} + 14\text{ mm}$ ราง $= 184\text{ mm}$)

**คำถาม:**
1. จงคำนวณจำนวนพาเนลสูงสุดและจำนวนบอร์ดเดี่ยวรวมทั้งหมด ($N_{\text{total}}$) ที่สามารถบรรจุลงในแผ่น Master Sheet ได้สำหรับทั้งสองรูปแบบ
2. จงคำนวณอัตราส่วนการใช้ประโยชน์วัสดุของแผ่นลามิเนตหลัก (Master Sheet Utilization Ratio $\eta_{\text{util}}$) สำหรับรูปแบบที่ดีที่สุด และตรวจสอบว่าผ่านเกณฑ์เป้าหมาย $\eta_{\text{util}} \ge 75.0\%$ หรือไม่?
3. หากยอดการผลิตทั้งหมดคือ $100,000$ แผ่นบอร์ดเดี่ยว การเลือกรูปแบบที่มีประสิทธิภาพสูงกว่าจะสามารถประหยัดแผ่น Master Sheet ได้กี่แผ่น?

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 1:

**1. คำนวณจำนวนพาเนลที่บรรจุได้:**
พื้นที่ทำงานจริงบนแผ่น Master Sheet: $W_{\text{usable}} = 380.0\text{ mm}$, $L_{\text{usable}} = 480.0\text{ mm}$
พื้นที่รวม Master Sheet ทั้งหมด: $A_{\text{master}} = 410.0 \times 510.0 = 209,100\text{ mm}^2$
พื้นที่ของบอร์ดเดี่ยว 1 แผ่น: $A_{\text{single}} = 65.0 \times 85.0 = 5,525\text{ mm}^2$

- **การประเมินรูปแบบที่ 1 (พาเนล $2 \times 3$ บอร์ด = 6 บอร์ดต่อพาเนล):**
  - ขนาดพาเนลรวมราง: กว้าง $130.0\text{ mm}$, ยาว $269.0\text{ mm}$
  - บวกช่องว่างใบมีดตัด $4.0\text{ mm}$: ต้องใช้พื้นที่ช่วง $134.0\text{ mm} \times 273.0\text{ mm}$
  - ตรวจสอบในแนวแกน $W$ ($380\text{ mm}$): $\lfloor 380 / 134 \rfloor = 2$ พาเนล (เหลือเศษ $380 - 268 = 112\text{ mm}$)
  - ตรวจสอบในแนวแกน $L$ ($480\text{ mm}$): $\lfloor 480 / 273 \rfloor = 1$ พาเนล (เหลือเศษ $480 - 273 = 207\text{ mm}$)
  - บรรจุได้เพียง $2 \times 1 = 2$ พาเนล ($12$ บอร์ดเดี่ยว) $\to$ เหลือพื้นที่ว่างทิ้งมหาศาล

- **การประเมินรูปแบบที่ 2 (พาเนล $3 \times 2$ บอร์ด = 6 บอร์ดต่อพาเนล):**
  - ขนาดพาเนลรวมราง: กว้าง $195.0\text{ mm}$, ยาว $184.0\text{ mm}$
  - บวกช่องว่างใบมีดตัด $4.0\text{ mm}$: ต้องใช้พื้นที่ช่วง $199.0\text{ mm} \times 188.0\text{ mm}$
  - ทดลองวางแนวตรง:
    - ด้านกว้าง ($380\text{ mm}$): $\lfloor 380 / 188 \rfloor = 2$ พาเนล (ใช้ไป $376\text{ mm}$)
    - ด้านยาว ($480\text{ mm}$): $\lfloor 480 / 199 \rfloor = 2$ พาเนล (ใช้ไป $398\text{ mm}$)
    - บรรจุได้ $2 \times 2 = 4$ พาเนล
    - จำนวนบอร์ดเดี่ยวรวม: $N_{\text{total}} = 4 \text{ พาเนล} \times 6 = 24\text{ บอร์ดเดี่ยว}$

**2. คำนวณ Material Utilization Ratio ($\eta_{\text{util}}$):**
สำหรับรูปแบบที่ 2 (บรรจุได้ 24 บอร์ด):
พื้นที่บอร์ดจริงที่เป็นประโยชน์:
$$A_{\text{boards\_total}} = 24 \times 5,525\text{ mm}^2 = 132,600\text{ mm}^2$$

อัตราส่วนการใช้วัสดุเทียบกับ Master Sheet ทั้งหมด:
$$\eta_{\text{util}} = \frac{A_{\text{boards\_total}}}{A_{\text{master}}} \times 100\% = \frac{132,600\text{ mm}^2}{209,100\text{ mm}^2} \times 100\% \approx 63.41\%$$

หากปรับขนาดรางลงเหลือข้างละ $5.0\text{ mm}$ (พาเนลยาว $180\text{ mm}$ ช่วงตัด $184\text{ mm}$):
- ตรวจสอบการหมุน 90 องศาเพื่อจัดวางแบบผสม (Nesting Optimization): สามารถวางได้ถึง **$28$ บอร์ดเดี่ยว**:
  $$A_{\text{boards}} = 28 \times 5,525 = 154,700\text{ mm}^2 \implies \eta_{\text{util}} = \frac{154,700}{209,100} \approx 74.0\%$$
- ซึ่งเข้าใกล้เกณฑ์เป้าหมาย $75.0\%$ อย่างมาก

---

**3. การประหยัดแผ่น Master Sheet สำหรับยอดผลิต $100,000$ แผ่น:**
- กรณีจัดเรียงได้ $24$ บอร์ดต่อแผ่น Master Sheet:
  $$\text{จำนวนแผ่นที่ต้องใช้} = \frac{100,000}{24} \approx 4,167\ \text{แผ่น}$$
- กรณีจัดเรียงแบบ Optimized ได้ $28$ บอร์ดต่อแผ่น Master Sheet:
  $$\text{จำนวนแผ่นที่ต้องใช้} = \frac{100,000}{28} \approx 3,572\ \text{แผ่น}$$
- **ผลต่างที่ประหยัดได้:**
  $$\Delta \text{Sheets} = 4,167 - 3,572 = 595\ \text{แผ่น Master Sheet!}$$
  หากแผ่นลามิเนตคุณภาพสูง 4-Layer มีราคาแผ่นละ $\$30$ การออกแบบการวางพาเนลที่ดีจะ **ประหยัดต้นทุนค่าวัสดุได้ทันทีถึง $\$17,850$ (มากกว่า 600,000 บาท)!**

### Quiz 2: การคำนวณความเครียดดัดในรอยต่อ V-Score และความเสี่ยงต่อการแตกร้าวของ MLCC

**โจทย์:**  
แผงวงจรพิมพ์ FR-4 ความหนา $T_{\text{PCB}} = 1.60\text{ mm}$ (โมดูลัสยัง $E = 20.0\text{ GPa} = 20,000\text{ N/mm}^2$) มีร่อง V-Score โดยมีความหนาเนื้อบอร์ดที่เหลืออยู่ $w = 0.50\text{ mm}$  
- ในขั้นตอนการหักแยกแผงวงจร ช่างใช้มือออกแรงดัดจนแผงวงจรโก่งตัวเป็นมุมเอียง $\theta = 15.0^\circ$ ($0.2618\ \text{rad}$) ก่อนที่รอยต่อตัววีจะหักขาดออกจากกัน
- รัศมีความโค้งของการดัดงอเฉพาะที่ (Local Radius of Curvature) บริเวณขอบบอร์ดมีค่า $R_{\text{bend}} = 380\text{ mm}$
- มีตัวเก็บประจุเซรามิก MLCC ขนาด 1206 ติดตั้งอยู่ขนานกับแนวร่องตัด โดยอยู่ห่างจากแนวศูนย์กลางของ V-Cut เป็นระยะทาง $x_1 = 1.20\text{ mm}$
- การกระจายความเครียดดึงบนผิวบนของแผงวงจรตามระยะทาง $x$ จากรอยตัด เป็นไปตามสมการ:
  $$\varepsilon(x) = \frac{T_{\text{PCB}}}{2 \cdot R_{\text{bend}}} \cdot e^{-x / x_0} \quad [\text{ในหน่วย } \mu\varepsilon]$$
  โดยค่าคงที่การสลายตัวของความเครียดคือ $x_0 = 1.80\text{ mm}$
- มาตรฐาน IPC-JEDEC-9704 กำหนดว่า ความเครียดดึงสูงสุดบนผิวบอร์ด ณ ตำแหน่งชิ้นส่วน MLCC ต้อง **ไม่เกิน $\varepsilon_{\max} \le 500\ \mu\varepsilon$** เพื่อป้องกันการแตกร้าวของเซรามิก

**คำถาม:**
1. จงคำนวณค่าความเครียดดึงสูงสุดที่ขอบร่องตัด ($x = 0$) บนผิวบนของแผงวงจร
2. จงคำนวณค่าความเครียดดึง ณ ตำแหน่งที่ตัวเก็บประจุ 1206 ติดตั้งอยู่ ($x_1 = 1.20\text{ mm}$)
3. ตรวจสอบว่าความเครียดที่เกิดขึ้นเกินขีดจำกัดปลอดภัย $500\ \mu\varepsilon$ หรือไม่? และหากต้องการลดความเครียดให้เหลือต่ำกว่า $400\ \mu\varepsilon$ วิศวกรต้องขยายระยะห่าง Keep-Out ($x_{\text{safe}}$) ออกไปเป็นกี่มิลลิเมตร?

---

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 2:

**1. คำนวณความเครียดดึงสูงสุดที่ขอบร่องตัด ($x = 0$):**
ความหนาบอร์ด $T_{\text{PCB}} = 1.60\text{ mm}$, รัศมีความโค้ง $R_{\text{bend}} = 380\text{ mm}$:
$$\varepsilon(0) = \frac{T_{\text{PCB}}}{2 \cdot R_{\text{bend}}} = \frac{1.60\text{ mm}}{2 \times 380\text{ mm}} = \frac{1.60}{760} \approx 0.0021053$$
แปลงเป็นหน่วยไมโครสเตรน ($\mu\varepsilon$ โดยคูณ $10^6$):
$$\varepsilon(0) \approx 2,105.3\ \mu\varepsilon$$

---

**2. คำนวณความเครียด ณ ตำแหน่ง MLCC ($x_1 = 1.20\text{ mm}$):**
ที่ $x_1 = 1.20\text{ mm}$ และ $x_0 = 1.80\text{ mm}$:
$$\frac{x_1}{x_0} = \frac{1.20}{1.80} \approx 0.6667$$
$$e^{-0.6667} \approx 0.5134$$
ความเครียดที่ตำแหน่งตัวเก็บประจุ:
$$\varepsilon(1.20) = 2,105.3\ \mu\varepsilon \times 0.5134 \approx 1,080.9\ \mu\varepsilon$$

---

**3. การตรวจสอบความปลอดภัยและคำนวณระยะ Keep-Out ใหม่:**
- **การตัดสิน:** $\varepsilon(1.20) = 1,080.9\ \mu\varepsilon \gg 500\ \mu\varepsilon$ **ไม่ผ่านเกณฑ์อย่างรุนแรง!** ความเครียดสูงกว่าขีดจำกัดปลอดภัยเกิน 2 เท่า ตัวเก็บประจุเซรามิก 1206 จะเกิดรอยร้าว Flex Crack และลัดวงจรเสียหายอย่างแน่นอน
- **คำนวณระยะ Keep-Out ปลอดภัย ($x_{\text{safe}}$ เพื่อให้ $\varepsilon \le 400\ \mu\varepsilon$):**
  $$400 = 2,105.3 \cdot e^{-x_{\text{safe}} / 1.80}$$
  $$e^{-x_{\text{safe}} / 1.80} = \frac{400}{2,105.3} \approx 0.18999$$
  Take natural logarithm:
  $$-\frac{x_{\text{safe}}}{1.80} = \ln(0.18999) \approx -1.6608$$
  $$x_{\text{safe}} = 1.80 \times 1.6608 \approx 2.989\text{ mm} \approx 3.00\text{ mm}$$

**บทสรุปทางวิศวกรรม:** วิศวกรต้องกำหนดระยะ Keep-Out ในไฟล์ CAD ให้ตัวเก็บประจุอยู่ห่างจากแนว V-Cut ไม่น้อยกว่า **$3.00\text{ mm}$** เพื่อรับประกันความปลอดภัยต่อความเครียดดัดงอ

### Quiz 3: การคำนวณความแข็งแรงและแรงตัดหักของสะพานเชื่อมมิกกี้เมาส์ (Mouse-Bite Breakaway Force)

**โจทย์:**  
แผงวงจรพาเนลยึดบอร์ดเดี่ยวด้วยสะพานเชื่อมแบบ Tab Routing ขนาดความกว้างสะพาน $W_{\text{tab}} = 5.00\text{ mm}$  
- แผงวงจรหนา $T_{\text{PCB}} = 1.60\text{ mm}$ ทำจากวัสดุ FR-4 ซึ่งมีค่าความแข็งแรงรับแรงเฉือนสูงสุด (Ultimate Shear Strength) $\tau_{\text{uts}} = 75.0\ \text{MPa} = 75.0\text{ N/mm}^2$
- ภายในสะพานเชื่อม มีการเจาะรูปรุปรังผึ้ง (Mouse-Bite Perforations) จำนวน $N = 4$ รู ขนาดเส้นผ่านศูนย์กลาง $D_{\text{hole}} = 0.65\text{ mm}$ ต่อรู เรียงเป็นแถวตรง
- ระยะความกว้างสุทธิของเนื้อทองแดงและเรซินที่เหลืออยู่เพื่อรับแรง (Net Solid Width):
  $$W_{\text{net}} = W_{\text{tab}} - N \cdot D_{\text{hole}} = 5.00 - (4 \times 0.65) = 5.00 - 2.60 = 2.40\text{ mm}$$

**คำถาม:**
1. จงคำนวณพื้นที่หน้าตัดสุทธิที่เหลืออยู่ของเนื้อวัสดุ ($A_{\text{net}}$ ในหน่วย $\text{mm}^2$)
2. จงคำนวณแรงเฉือนบริสุทธิ์ (Pure Shear Breakout Force - $F_{\text{shear}}$ ทั้งในหน่วย $\text{N}$ และ $\text{kgf}$) ที่ต้องใช้ในการตัดสะพานเชื่อมนี้ให้ขาดออกจากกัน
3. หากในระหว่างการบัดกรี Reflow อุปกรณ์ทั้งหมดบนบอร์ดเดี่ยวมีน้ำหนักรวม $50\text{ กรัม}$ ($0.49\text{ N}$) และบอร์ดเดี่ยวนี้ถูกยึดไว้ด้วยสะพานเชื่อม Mouse-Bite เพียง 2 จุด จงคำนวณหาค่าอัตราส่วนความปลอดภัย (Factor of Safety - FOS) ในแนวดิ่งขณะลำเลียงผ่านเตาอบเพื่อยืนยันว่าบอร์ดจะไม่หลุดหักร่วงลงไปในเตา

---

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 3:

**1. คำนวณพื้นที่หน้าตัดสุทธิ ($A_{\text{net}}$):**
$$A_{\text{net}} = W_{\text{net}} \cdot T_{\text{PCB}} = 2.40\text{ mm} \times 1.60\text{ mm} = 3.84\text{ mm}^2$$

---

**2. คำนวณแรงเฉือนตัดหัก ($F_{\text{shear}}$):**
$$\tau_{\text{uts}} = 75.0\text{ N/mm}^2$$
$$F_{\text{shear}} = \tau_{\text{uts}} \cdot A_{\text{net}} = 75.0\text{ N/mm}^2 \times 3.84\text{ mm}^2 = 288.0\text{ N}$$
แปลงเป็นกิโลกรัม-แรง ($1\text{ kgf} \approx 9.80665\text{ N}$):
$$F_{\text{shear}} = \frac{288.0\text{ N}}{9.80665} \approx 29.37\text{ kgf}$$

---

**3. คำนวณ Factor of Safety ขณะผ่านเตาอบ Reflow:**
บอร์ดเดี่ยวมีสะพานเชื่อม 2 จุด แรงรับน้ำหนักรวมในแนวดิ่งก่อนขาด:
$$F_{\text{capacity}} = 2 \times F_{\text{shear}} = 2 \times 288.0\text{ N} = 576.0\text{ N}$$
น้ำหนักรวมของบอร์ดและอุปกรณ์:
$$W_{\text{load}} = 0.49\text{ N}$$
อัตราส่วนความปลอดภัย:
$$\text{FOS} = \frac{F_{\text{capacity}}}{W_{\text{load}}} = \frac{576.0\text{ N}}{0.49\text{ N}} \approx 1,175$$

**บทสรุปทางวิศวกรรม:**
- ค่า $\text{FOS} > 1,000$ ยืนยันว่าสะพานเชื่อมมีความแข็งแกร่งเชิงกลเหลือเฟือในการป้องกันไม่ให้แผงวงจรร่วงหลุดขณะผ่านเตาอบ Reflow แม้จะมีการสั่นสะเทือนของสายพาน
- ในขณะเดียวกัน แรงตัดหัก $288\text{ N}$ (~$29\text{ kgf}$) ต่อสะพาน อยู่ในพิกัดที่ใบมีดตัดของเครื่องตัดเร้าเตอร์หรือคีมตัดนิวแมติกสามารถตัดขาดได้อย่างนุ่มนวลและรวดเร็วโดยไม่ส่งผ่านความเค้นสะสมที่เป็นอันตรายกลับเข้าไปในตัวบอร์ด
