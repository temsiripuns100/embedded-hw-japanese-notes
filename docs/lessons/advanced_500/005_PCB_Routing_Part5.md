## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

สัญญาณรบกวนข้ามสาย (Crosstalk) เป็นหนึ่งในปัจจัยหลักที่ทำให้ Timing Margin ของบัสความเร็วสูง (เช่น DDR4/5, LPDDR, PCIe) แคบลงจนเกิดข้อผิดพลาดในการรับส่งข้อมูล ในระดับ Senior Engineer เราวิเคราะห์ Crosstalk ผ่านพารามิเตอร์ของสนามไฟฟ้า (Capacitive Coupling: $C_m$) และสนามแม่เหล็ก (Inductive Coupling: $L_m$) ที่เหนี่ยวนำข้ามระหว่างเส้นทางตัวส่ง (Aggressor Line) ไปยังเส้นทางตัวรับเคราะห์ (Victim Line)

---

### 1.1 กลไกของ Mutual Capacitance ($C_m$) และ Mutual Inductance ($L_m$)
เมื่อสัญญาณบน Aggressor มีการเปลี่ยนแปลงแรงดันอย่างรวดเร็ว ($\frac{dV}{dt}$) และมีการเปลี่ยนแปลงของกระแส ($\frac{dI}{dt}$):
1. **Capacitive Coupling ($C_m$):** ฉีดกระแสเหนี่ยวนำ $I_{cap} = C_m \frac{dV}{dt}$ เข้าสู่ Victim Line โดยกระแสนี้จะแยกไหลไปทั้งสองทิศทาง (ไปทางต้นทางและปลายทาง)
2. **Inductive Coupling ($L_m$):** เหนี่ยวนำแรงดัน $V_{ind} = L_m \frac{dI}{dt}$ บน Victim Line ตามกฎของฟาราเดย์ ซึ่งสร้างกระแสไหลวนสวนทางกับกระแสต้นทาง

```
     Aggressor ────[  I_aggressor  ]────────────────────────────>
                         │                │
                        (Cm)             (Lm)
                         ▼                ▼
     Victim    ◄───[  I_NEXT  ]───────[  I_FEXT  ]──────────────>
                 Near-End (ต้นทาง)       Far-End (ปลายทาง)
```

---

### 1.2 Near-End Crosstalk (NEXT) และ Far-End Crosstalk (FEXT)

#### 1. Near-End Crosstalk (NEXT):
สัญญาณรบกวนที่สะท้อนย้อนกลับมายังขั้วต้นทาง (Near-End) ของ Victim Line:
- กระแสเหนี่ยวนำจาก $C_m$ และ $L_m$ มีทิศทาง **เสริมกัน (Add up in phase)**:
  $$V_{NEXT} = K_b \times V_{in}$$
  โดยที่ค่า Backward Crosstalk Coefficient ($K_b$) คำนวณได้จาก:
  $$K_b \approx \frac{1}{4} \left( \frac{C_m}{C_0} + \frac{L_m}{L_0} \right)$$
- **ความยาวอิ่มตัว (Saturation Length, $L_{sat}$):**  
  หากความยาวที่สายทั้งสองเดินขนานกัน ($L$) เกินกว่าค่า $L_{sat}$:
  $$L_{sat} = \frac{t_r}{2 \times t_{pd}}$$
  แอมพลิจูดของ NEXT จะ **ไม่เพิ่มขึ้นอีกต่อไป** แต่จะคงที่อยู่ที่ค่าระดับสูงสุด (Plateau) และขยายตัวในแนวกว้างตามเวลาแทน ($t_{width} = t_r + 2 \times t_{pd} \times L$)

#### 2. Far-End Crosstalk (FEXT):
สัญญาณรบกวนที่เดินทางไปพร้อมกับคลื่นสัญญาณหลักสู่ขั้วปลายทาง (Far-End):
- กระแสเหนี่ยวนำจาก $C_m$ และ $L_m$ มีทิศทาง **หักล้างกัน (Oppose each other)**:
  $$V_{FEXT}(t) = K_f \times L \times \frac{dV_{in}}{dt}$$
  โดยที่ Forward Crosstalk Coefficient ($K_f$) คำนวณได้จาก:
  $$K_f = \frac{1}{2v} \left( \frac{C_m}{C_0} - \frac{L_m}{L_0} \right)$$
- **ความลับของ Stripline ในระนาบเนื้อเดียว (Homogeneous Dielectric):**  
  สำหรับลายวงจรชั้นใน (Stripline) ที่ฝังตัวในเนื้อ Dielectric ล้วน ความเร็วเฟสของสนามไฟฟ้าและสนามแม่เหล็กจะเท่ากันเป๊ะ ทำให้ $\frac{C_m}{C_0} = \frac{L_m}{L_0}$ ส่งผลให้ **$K_f = 0$ (ไม่มี FEXT เลย!)**  
  แต่สำหรับชั้นนอก (Microstrip) ที่มีขอบเขตระหว่างอากาศ ($\epsilon_r = 1.0$) กับ Substrate ($\epsilon_r \approx 4.0$) สนามทั้งสองมีความเร็วไม่เท่ากัน ทำให้เกิด FEXT พุ่งเป็น Spike รุนแรงที่ปลายทางเสมอ!

### 1.3 กฎ 3W Rule vs. อัตราส่วนความสูง ($s/h$)
กฎพื้นฐาน 3W Rule ระบุว่า:
> *"ระยะห่างกึ่งกลางระหว่าง Trace (Center-to-Center Spacing, $S$) ควรมีขนาดอย่างน้อย 3 เท่าของความกว้าง Trace ($W$)"* (หรือระยะห่างระหว่างขอบ $s \ge 2W$)

```
          ◄── W ──►   ◄───── s ─────►   ◄── W ──►
          ┌───────┐                     ┌───────┐
          │ Trace │                     │ Trace │
          └───────┘                     └───────┘
          ◄────────────── S ────────────►
                      (S ≥ 3W)
```

**ข้อคิดวิเคราะห์ระดับ Senior:**
- การใช้กฎ 3W จะช่วยลด Crosstalk ลงได้ประมาณ **$70\%$** (เมื่อเทียบกับกรณีเดินชิดกัน $s = W$)
- แต่ตัวแปรที่แท้จริงไม่ใช่แค่ $W$ แต่คือ **อัตราส่วน $s/h$ (ระยะห่างต่อความสูงของ Dielectric เหนือ Reference Plane)**
  - ถ้า $h$ มีขนาดบางมาก (เช่น $h = 3 \text{ mil}$) สนามแม่เหล็กจะถูกดึงดูดลง Ground Plane แน่นหนามาก ทำให้ระยะห่าง $s = 2h$ ก็เพียงพอที่จะกำจัด Crosstalk ลงได้ถึง 90%
  - แต่ถ้า $h$ หนา (เช่น $h = 8 \text{ mil}$) แม้จะใช้ระยะ $3W$ สนามก็อาจจะยังกระจายข้ามไปกวนเส้นข้างๆ ได้อยู่ดี ดังนั้นกฎที่ปลอดภัยกว่าคือ:
    $$s \ge 3h \quad (\text{หรือ } 4W \text{ สำหรับสัญญาณ Sensitive})$$

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** บอร์ดควบคุมระบบขับเคลื่อนมอเตอร์ที่ใช้หน่วยความจำ DDR4-3200 เกิดข้อผิดพลาด Memory Test (MemTest86) ล้มเหลวแบบสุ่มเมื่อมีการอ่านเขียนข้อมูลแบบเต็มแบนด์วิธ (High-Traffic Burst)
**สาเหตุที่ตรวจพบ (検図での指摘):**
สัญญาณ Data Strobe (`DDR_DQS0_P/N`) ถูกเดินขนานแนบชิดกับเส้น Data Bit (`DDR_DQ0` ถึง `DQ3`) เป็นระยะทางยาวกว่า $65 \text{ mm}$ บน Layer บนสุด (Microstrip) โดยมีระยะห่างระหว่างขอบเพียง $1.2W$ ($s \approx 5 \text{ mil}$) ทำให้เกิด FEXT ขนาดสูงถึง **$280 \text{ mV}$** เหนี่ยวนำเข้าสู่เส้น DQS สัญญาณ Strobe จึงเกิด False Edge Trigging บอร์ดอ่านข้อมูลผิดทันที!

---

### ขั้นตอนการป้องกัน Crosstalk ในงานจริง (検図チェックリスト):
1. **การแยกระยะห่างตามระดับความไว (Critical Signal Isolation):**
   - เส้นสัญญาณ Clock, Strobe (`DQS`), Reset, และ Analog ต้องใช้กฎ **$4W - 5W$** เสมอเมื่อเทียบกับ Data Bus ทั่วไป
2. **ข้อเท็จจริงเกี่ยวกับ Guard Trace (GND Shield Trace):**
   - การวางเส้นทองแดงต่อกราวด์ (Guard Trace) คั่นระหว่างลายวงจรความเร็วสูง **จะมีประโยชน์ก็ต่อเมื่อมีการเจาะ Ground Via เย็บตลอดแนว (Via Stitching)** ด้วยระยะห่าง:
     $$Pitch_{via} \le \frac{\lambda}{10} \approx \frac{c}{10 \times f_{max} \times \sqrt{\epsilon_r}}$$
     *(เช่น สำหรับสัญญาณ 5 GHz ควรเจาะ Via ทุกๆ ไม่เกิน 3–4 mm)*
   - **ข้อควรระวังอันตราย:** หากวาง Guard Trace ยาวๆ ลอยไว้โดยไม่มี Via เจาะลง Ground ถี่พอ Guard Trace เส้นนั้นจะทำหน้าที่เป็นสายอากาศ (Patch Resonator) ดูดพลังงานจาก Aggressor แล้วยิงเข้าใส่ Victim หนักกว่าเดิม!
3. **การเดินสายแบบตั้งฉากระหว่างเลเยอร์ (Orthogonal Routing):**
   - เมื่อมี Signal Layer สองชั้นอยู่ติดกัน (ไม่มี Ground Plane คั่นกลาง) ชั้นหนึ่งต้องเดินแนวแกน X (Horizontal) และอีกชั้นต้องเดินแนวแกน Y (Vertical) ห้ามเดินขนานกันในแนวระนาบดิ่งเดียวกันเด็ดขาด

> *(แนว Guard Trace ของสัญญาณ Clock มีจุดที่เจาะ GND Via ห่างกันเกิน 20mm เพื่อป้องกันไม่ให้ Guard Trace กลายเป็นตัวเรโซแนนซ์แผ่คลื่นรบกวน กรุณาเจาะ GND Stitching Via ทุกๆ ระยะไม่เกิน 5mm)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การวิเคราะห์ความยาวอิ่มตัว Saturation Length)
ลายวงจรความเร็วสูงสองเส้นเดินขนานกันบนชั้นนอก (Microstrip, $t_{pd} = 150 \text{ ps/inch}$) สัญญาณ Aggressor มีขอบขาขึ้น $t_r = 600 \text{ ps}$ หากวิศวกร Layout ลดความยาวที่เส้นทั้งสองเดินขนานกันจาก $6.0 \text{ นิ้ว}$ ลงมาเหลือ $3.0 \text{ นิ้ว}$ ถามว่าจะส่งผลต่อแอมพลิจูดสูงสุดของ Near-End Crosstalk (NEXT) อย่างไร?

- **ก)** แอมพลิจูดของ NEXT จะลดลงครึ่งหนึ่ง ($50\%$) ทันที
- **ข)** แอมพลิจูดของ NEXT ไม่ลดลงเลย (ยังคงเท่าเดิม) แต่ความกว้างของพัลส์สัญญาณกวนในแกนเวลาจะแคบลง
- **ค)** แอมพลิจูดของ NEXT จะลดลงจนเป็นศูนย์
- **ง)** แอมพลิจูดของ NEXT จะเพิ่มขึ้นเป็นสองเท่าเพราะความหนาแน่นพลังงานเพิ่มขึ้น

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> คำนวณความยาวอิ่มตัว (Saturation Length) ของ NEXT:  
> $$L_{sat} = \frac{t_r}{2 \times t_{pd}} = \frac{600 \text{ ps}}{2 \times 150 \text{ ps/inch}} = 2.0 \text{ นิ้ว}$$  
> เนื่องจากทั้งความยาวเดิม ($6.0 \text{ นิ้ว}$) และความยาวใหม่ ($3.0 \text{ นิ้ว}$) มีค่ามากกว่า $L_{sat} (2.0 \text{ นิ้ว})$ ทั้งคู่  
> เมื่อความยาวขนานเกินค่าอิ่มตัว แอมพลิจูดสูงสุดของ NEXT จะพุ่งขึ้นแตะเพดานสูงสุด ($K_b \times V_{in}$) และ **ไม่เพิ่มหรือลดตามความยาวอีกต่อไป** สิ่งที่เปลี่ยนไปคือความกว้างของช่วงเวลาพัลส์รบกวน ($t_{width}$) จะสั้นลงจาก $6 \text{ นิ้ว}$ มาเป็น $3 \text{ นิ้ว}$ เท่านั้น หากต้องการลดแอมพลิจูดของ NEXT จะต้องถ่างระยะห่างระหว่างเส้น ($S$) ให้กว้างขึ้น ไม่ใช่แค่ลดความยาว

---

### ข้อที่ 2 (ความลับทางฟิสิกส์ของ Stripline vs. Microstrip)
เหตุใดในระบบส่งสัญญาณความเร็วสูงระดับสูงมาก (เช่น 28G/56G SerDes) วิศวกรจึงนิยมย้ายลายวงจรเข้าไปเดินในชั้นในแบบ Stripline (ประกบด้วย Ground บนและล่าง) มากกว่าการเดินบนชั้นผิวนอกแบบ Microstrip เพื่อจัดการปัญหา Crosstalk?

- **ก)** เพราะ Stripline มีต้นทุนการผลิตทองแดงที่ถูกกว่า Microstrip
- **ข)** เพราะ Stripline ฝังตัวในไดอิเล็กตริกชนิดเดียวกันรอบทิศทาง ทำให้ความเร็วเฟสของสนามไฟฟ้าและสนามแม่เหล็กเท่ากัน ส่งผลให้ Far-End Crosstalk (FEXT) หักล้างกันเองจนเกือบเป็นศูนย์ในทางทฤษฎี
- **ค)** เพราะ Stripline ไม่เกิดความร้อนเลยแม้แต่น้อย
- **ง)** เพราะ Stripline สามารถใช้ความกว้างของ Trace ขนาดเท่าใดก็ได้โดยไม่ต้องคำนวณ Impedance

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในโครงสร้าง Stripline สนามแม่เหล็กไฟฟ้าทั้งหมดจะกระจายตัวอยู่ภายในเนื้อ Dielectric ชนิดเดียวกัน (Homogeneous Medium) ส่งผลให้อัตราส่วนของ Mutual Capacitance และ Mutual Inductance สมดุลกันพอดี: $\frac{C_m}{C_0} = \frac{L_m}{L_0}$  
> เมื่อแทนค่าลงในสมการ FEXT: $K_f = \frac{1}{2v} \left( \frac{C_m}{C_0} - \frac{L_m}{L_0} \right) = 0$ สัญญาณรบกวนที่เดินทางไปข้างหน้า (FEXT) จึงหักล้างกันจนหมดสิ้น ในขณะที่ Microstrip มีชั้นอากาศอยู่ด้านบนทำให้สนามไฟฟ้าวิ่งเร็วกว่าสนามในเนื้อบอร์ด จึงเกิด FEXT พุ่งสูงเสมอ

### ข้อที่ 3 (ข้อควรระวังในการใช้ Guard Trace)
ในกรณีใดต่อไปนี้ที่การใส่ Guard Trace (GND Shield Trace) คั่นระหว่างคู่สัญญาณความเร็วสูง จะส่งผลเสีย (Negative Impact) ต่อระบบมากกว่าการไม่ใส่?

- **ก)** เมื่อ Guard Trace ถูกต่อลง Ground ผ่าน Via ทุกๆ 1 mm
- **ข)** เมื่อ Guard Trace เดินขนานไปยาวๆ โดยไม่มีการเจาะ Ground Via เชื่อมลงระนาบ Ground เลยตลอดแนว ทำให้เกิดภาวะ Floating Guard ที่ทำหน้าที่เป็นสายอากาศเหนี่ยวนำสัญญาณรบกวนข้ามเส้น
- **ค)** เมื่อ Guard Trace มีความกว้างมากกว่า 10 mil
- **ง)** เมื่อบอร์ดทำงานที่อุณหภูมิต่ำกว่า 0 องศาเซลเซียส

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> Guard Trace ที่ปล่อยลอยไว้โดยไม่มี Ground Stitching Via (หรือเจาะ Via ห่างเกินไป) จะเกิดการเหนี่ยวนำทางความจุและขดลวดแฝง ทำให้มันกลายเป็น **สายส่งปลายเปิดหรือเรโซเนเตอร์ (Resonant Antenna)** ที่ดักจับพลังงานจาก Aggressor แล้วส่งต่อเข้าสู่ Victim อย่างรุนแรง นอกจากนี้ยังไปลดระยะห่างทางกายภาพที่มีประสิทธิภาพระหว่าง Aggressor และ Victim ลงอีกด้วย  
> วิศวกร Senior จึงมักแนะนำว่า: *"หากไม่มีพื้นที่พอที่จะเจาะ Ground Stitching Via อย่างหนาแน่น ให้ถ่างระยะห่างระหว่างเส้นสัญญาณด้วยพื้นที่ว่างเปล่า (Empty Space) ตามกฎ 3W/4W จะให้ผลดีกว่าการใส่ Guard Trace เปล่าๆ เสมอ"*
