## 1. ทฤษฎีวิศ곽รรมเชิงลึก (高度なエンジニアリング理論)

ในระบบส่งสัญญาณดิจิทัลความเร็วสูงระดับ Multi-Gigabit (เช่น PCIe Gen 4/5/6, 112G PAM4, DDR5) รูเจาะเปลี่ยนเลเยอร์ (Via) ไม่ใช่สายส่งแบบอุดมคติ แต่เป็น **จุดสะดุดของโครงสร้างทางเรขาคณิต (Geometrical Discontinuity)** ที่เปลี่ยนแนวการไหลของคลื่นแม่เหล็กไฟฟ้าจากระนาบ 2 มิติในแนวนอน (Planar Horizontal Traces) ไปสู่กระบอกตัวนำ 3 มิติในแนวดิ่ง (Vertical Cylindrical Barrel)

การเปลี่ยนผ่านนี้ก่อให้เกิดพารามิเตอร์แฝงทั้ง **ความจุไฟฟ้าแฝง ($C_v$)** และ **ความเหนี่ยวนำแฝง ($L_v$)** 
และที่สำคัญที่สุด หากวิศวกรละเลยการจัดเตรียม **Ground Return Via (グラウンドリターンビア)** สำหรับกระแสไหลกลับ สัญญาณจะกระตุ้นคลื่นนิ่งในโพรงแผ่นวงจร (Parallel-Plate Cavity Resonance) ส่งผลให้เกิด Jitter ขนาดมหึมาและทำลายความสมบูรณ์ของสัญญาณในพริบตา

---

### 1.1 วงจรสมมูลพารามิเตอร์แฝงของ Via (Lumped Equivalent Model: $C_v$ และ $L_v$)

โครงสร้างของ Via มาตรฐานประกอบด้วย: กระบอกทองแดง (Barrel), แผ่นวงแหวนเชื่อมต่อ (Pad), และรอยฉลุกราวด์ (Anti-Pad):

```
                       L_via / 2               L_via / 2
        Trace In ───────( ( ( )───────┬─────────( ( ( )─────── Trace Out
                                      │
                                    ──┴── C_via (Parasitic Capacitance)
                                    ──┬──
                                      │
        ──────────────────────────────┴─────────────────────── Ground Reference
```

1. **ความจุไฟฟ้าแฝงของ Via ($C_v$):**  
   เกิดจากสนามไฟฟ้าระหว่างแผ่น Pad และกระบอก Barrel เทียบกับขอบทองแดงของระนาบ Ground โดยรอบ (ฉลุผ่าน Anti-Pad):

$$C_v \approx \frac{1.41 \cdot \epsilon_r \cdot T \cdot D_{pad}}{D_{anti} - D_{pad}} \quad [\text{pF}]$$

โดยที่:
- $\epsilon_r$ คือค่า Dielectric Constant ของเนื้อบอร์ด
- $T$ คือความหนาของแผ่นบอร์ด (นิ้ว)
- $D_{pad}$ คือเส้นผ่านศูนย์กลางของ Via Pad (นิ้ว)
- $D_{anti}$ คือเส้นผ่านศูนย์กลางของรอยฉลุ Anti-Pad บนระนาบกราวด์ (นิ้ว)

*ผลกระทบทางไฟฟ้า:* ในบอร์ดทั่วไป $C_v$ มีค่าประมาณ **$0.3 - 0.8 \text{ pF}$** ซึ่งค่าความจุนี้จะดึงให้อิมพีแดนซ์ชั่วขณะ ($Z_0 = \sqrt{L/C}$) ดิ่งลงต่ำกว่าเป้าหมาย $50 \ \Omega$ (Capacitive Dip เหลือประมาณ $32 - 42 \ \Omega$) ปรากฏเป็นหลุมลึกในการวัด TDR

2. **ความเหนี่ยวนำแฝงของ Via ($L_v$):**  
   เกิดจากการไหลของกระแสในแนวดิ่งผ่านความยาวกระบอก $h$:

$$L_v \approx 5.08 \cdot h \cdot \left[ \ln\left( \frac{4h}{d} \right) + 1 \right] \quad [\text{nH}]$$

โดยที่ $h$ คือความยาวกระบอกเวีย (นิ้ว) และ $d$ คือเส้นผ่านศูนย์กลางรูเจาะ (นิ้ว)  
หรือในหน่วยระบบ SI:

$$L_v \approx \frac{\mu_0 \cdot h}{2\pi} \left[ \ln\left( \frac{2h}{r} \right) - 0.75 \right] \quad [\text{H}]$$

*ผลกระทบทางไฟฟ้า:* ค่า $L_v$ มีค่าประมาณ **$0.5 - 1.5 \text{ nH}$** ความเหนี่ยวนำนี้ทำให้เกิดแรงดันเหนี่ยวนำขวางกั้น $\Delta V = L_v \frac{dI}{dt}$ ขอบสัญญาณขาขึ้นจะถูกหน่วงช้าลง (Rise Time Degradation) และเกิดการสะท้อนของคลื่นความถี่สูง

---

### 1.2 ปรากฏการณ์ Return Path Discontinuity และการกระตุ้น Cavity Modes

เมื่อสัญญาณความเร็วสูงมุดผ่าน Via จากเลเยอร์บน (Layer 1 อ้างอิง GND Layer 2) ลงสู่เลเยอร์ล่าง (Layer 4 อ้างอิง GND Layer 3):

```
       Layer 1: Signal Trace ───────┐
                                    ▼ Signal Via
       Layer 2: Ground Plane 1 ═══╗   ╔═════════════════════════════════════════
                                  ║   ║ ◄── Anti-pad Void (Return Current Blocked!)
                                  ║   ║
       Layer 3: Ground Plane 2 ═══╝   ╚═════════════════════════════════════════
                                    ▲
       Layer 4: Signal Trace ───────┘
```

1. **เส้นทางกระแสไหลกลับถูกตัดขาด (Severed Return Path):**
   - กระแสสัญญาณไหลลงไปตามกระบอก Signal Via แต่ **กระแสไหลกลับที่วิ่งอยู่ใต้สายบน Layer 2 ไม่สามารถกระโดดข้ามเนื้อฉนวนไปยัง Layer 3 ได้!**
2. **การตื่นตัวของคลื่นในโพรงขนาน (Parallel-Plate Waveguide Excitation):**
   - หากไม่มี Ground Return Via อยู่ใกล้ๆ กระแสไหลกลับจะถูกบังคับให้กระจายตัวออกไปในแนวรัศมีทุกทิศทางระหว่างแผ่น Layer 2 และ Layer 3
   - พลังงานคลื่นแม่เหล็กไฟฟ้าจะกระตุ้นโหมดคลื่นในโพรง (Cavity Resonant Modes) วิ่งสะท้อนไปมาระหว่างขอบบอร์ด ก่อให้เกิด:
     - การเหนี่ยวนำสัญญาณรบกวนข้ามสาย (Crosstalk) สู่ทุก Via ที่อยู่ในบริเวณนั้น
     - การแผ่คลื่นแม่เหล็กไฟฟ้ารั่วไหลออกจากขอบบอร์ด (Edge Radiation EMI)

---

### 1.3 ทฤษฎีการจัดวาง Ground Return Via เพื่อควบคุมลูปเหนี่ยวนำ

เพื่อสร้างทางไหลกลับที่สั้นที่สุดและกดค่า Loop Inductance ให้ต่ำที่สุด วิศวกรต้องวาง **Ground Return Via (GNDステッチングビア)** ประชิดกับ Signal Via:

```
        Structure A: 1 Return Via               Structure B: Coaxial Cage (4 Return Vias)
               GND Return Via                              GND        GND
                   ( o )                                  ( o )      ( o )
                     │ d                                     \        /
                     ▼                                        \  d   /
                   ( O ) Signal Via                            ( O ) Signal Via
                                                              /        \
                                                             /    d     \
                                                          ( o )      ( o )
                                                           GND        GND
```

| การจัดวาง Return Via | ค่า Loop Inductance สัมพัทธ์ | ประสิทธิภาพการกด Cavity Noise | การประยุกต์ใช้งาน |
|---|---|---|---|
| **ไม่มี Return Via เลย** | $100\%$ ($> 1.8 \text{ nH}$) | แย่มาก ($< 10 \text{ dB}$ Isolation) | วงจรความถี่ต่ำ $< 50 \text{ MHz}$ |
| **1 Return Via ประชิด ($d \le 0.5 \text{ mm}$)** | $\approx 45\%$ ($\sim 0.8 \text{ nH}$) | ปานกลาง ($-20 \text{ dB}$ Isolation) | DDR4 Data lines, สัญญาณต่ำกว่า 5 Gbps |
| **2 Return Vias (ประกบซ้าย-ขวา)** | $\approx 28\%$ ($\sim 0.5 \text{ nH}$) | ดีมาก ($-30 \text{ dB}$ Isolation) | PCIe Gen 3/4, 10GbE SerDes |
| **4 Return Vias (โครงสร้างกรง Coaxial)**| **$\approx 15\%$ ($< 0.25 \text{ nH}$)**| **ยอดเยี่ยมที่สุด ($> -45 \text{ dB}$)** | **PCIe Gen 5/6, 112G PAM4, 28GHz RF** |

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** บอร์ดเราเตอร์เครือข่ายความเร็วสูง 10GbE SFP+ (อัตราส่งข้อมูล $10.3125 \text{ Gbps}$) เกิดอาการ Packet Loss สูงผิดปกติและล้มเหลวในการทดสอบ Eye Mask Margin โดยตรวจพบว่าที่จุดเปลี่ยนผ่านของ Via มีค่า Total Jitter (TJ) สูงถึง **$0.55 \text{ UI}$** (มาตรฐานบังคับ $TJ \le 0.28 \text{ UI}$)
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **Signal Via เปลี่ยนเลเยอร์โดยไม่มี Return Via ในระยะ $4.5 \text{ mm}$:** สัญญาณ SerDes มุดเปลี่ยนเลเยอร์จาก Layer 1 ไปยัง Layer 8 บนบอร์ดหนา 12 ชั้น โดยรอบรูเจาะในรัศมี $4.5 \text{ mm}$ ไม่มี Ground Via เจาะทะลุเลยแม้แต่รูเดียว
2. **เกิด Cavity Resonance ที่ความถี่ 5.15 GHz:**  
   - กระแสไหลกลับกระจายตัวอัดประจุระหว่างระนาบกราวด์ชั้น L2 และ L7 เกิดการสั่นพ้องที่ความถี่ Nyquist ของสัญญาณ ($10.3125 / 2 \approx 5.15 \text{ GHz}$) พอดิบพอดี
   - พลังงานคลื่นสะท้อนฉีดกลับเข้าสู่กระบอก Signal Via ทำให้ Eye Diagram ปิดสนิทและเกิดการแผ่คลื่นรบกวนข้ามไปกวนช่องสัญญาณข้างเคียง

---

### ขั้นตอนการจัดวาง Return Via สไตล์ Senior (検図チェックリスト):
1. **การควบคุมระยะห่างของ Return Via ($d_{return}$):**
   - **กฎเหล็ก:** Ground Return Via ต้องอยู่ห่างจาก Signal Via เป็นระยะทาง:
     $$d_{return} \le 0.50 \text{ mm} \ (20 \text{ mil}) \quad (\text{แนะนำ: } 0.35 - 0.40 \text{ mm})$$
   - ยิ่งอยู่ใกล้กันมากเท่าใด ลูปของสนามแม่เหล็ก ($A_{loop}$) จะยิ่งเล็กลงเท่านั้น ส่งผลให้ค่า Mutual Inductance ชดเชยค่า Self Inductance ได้สูงสุด
2. **การประกบคู่สำหรับ Differential Pair Vias:**
   - สำหรับคู่สาย Differential (เช่น PCIe หรือ 56G PAM4):
   - ต้องวาง Ground Return Via ขนาบข้างทั้งสองด้านของคู่สัญญาณในลักษณะ **G-S-S-G (หรือวางบน-ล่างเป็นรูปกากบาท)**:
     - ช่วยรักษาความสมมาตรของสนามแม่เหล็กไฟฟ้า และป้องกันไม่ให้เกิด Common-Mode Conversion ($S_{cd21}$)
3. **การปรับแต่งขนาด Anti-Pad เพื่อชดเชย Capacitive Dip:**
   - เพื่อดึงอิมพีแดนซ์ของกระบอก Via ไม่ให้ดิ่งลงเหว ($35 \ \Omega$):
   - ขยายขนาดเส้นผ่านศูนย์กลางรอยฉลุ Anti-Pad ($D_{anti}$) บนระนาบกราวด์ชั้นในให้ใหญ่ขึ้นจากเดิม $18 \text{ mil}$ เป็น **$26 - 30 \text{ mil}$** (หรือรวม Anti-Pad เข้าด้วยกันเป็นรูปวงรี Racetrack)
   - การขจัดเนื้อทองแดงที่ประชิดรอบรูเจาะจะช่วยลดค่า $C_v$ ลงได้ถึง $40\%$ ช่วยดึงอิมพีแดนซ์ของ Via กลับขึ้นมาใกล้เคียง **$50 \ \Omega$ หรือ $85/100 \ \Omega$** อย่างราบรื่น

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Parasitic Capacitance ของ Via)
วิศวกรออกแบบ Through-Hole Via บนบอร์ด 8 เลเยอร์ ความหนารวม $T = 1.60 \text{ mm} \ (0.063 \text{ inches})$ ใช้วัสดุที่มีค่า $\epsilon_r = 4.2$ โดยมีเส้นผ่านศูนย์กลางของ Via Pad เท่ากับ $D_{pad} = 0.50 \text{ mm} \ (0.020 \text{ inches})$ และมีขนาดเส้นผ่านศูนย์กลางของรอยฉลุ Anti-Pad เท่ากับ $D_{anti} = 0.75 \text{ mm} \ (0.030 \text{ inches})$ จากสูตรประมาณการ $C_v \approx \frac{1.41 \cdot \epsilon_r \cdot T \cdot D_{pad}}{D_{anti} - D_{pad}}$ ถามว่าค่าความจุไฟฟ้าแฝง ($C_v$) ของ Via นี้มีค่าเท่ากับข้อใดโดยประมาณ?

- **ก)** $C_v \approx 0.15 \text{ pF}$
- **ข)** $C_v \approx 0.75 \text{ pF}$
- **ค)** $C_v \approx 2.50 \text{ pF}$
- **ง)** $C_v \approx 0.03 \text{ pF}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> แทนค่าพารามิเตอร์ในหน่วยนิ้วลงในสมการ:  
> - $\epsilon_r = 4.2$  
> - $T = 0.063 \text{ in}$  
> - $D_{pad} = 0.020 \text{ in}$  
> - $D_{anti} - D_{pad} = 0.030 - 0.020 = 0.010 \text{ in}$  
> คำนวณค่า $C_v$:  
> $$C_v \approx \frac{1.41 \times 4.2 \times 0.063 \times 0.020}{0.010} = \frac{1.41 \times 4.2 \times 0.00126}{0.010} \approx \frac{0.00746}{0.010} \approx \mathbf{0.746 \text{ pF} \ (\approx 0.75 \text{ pF})}$$  
> ค่าความจุแฝงระดับ $0.75 \text{ pF}$ ถือเป็นค่าความจุแฝงที่สูงมาก ซึ่งจะทำหน้าที่เสมือนตัวเก็บประจุแบบก้อนโหลดลงกราวด์ ดึงให้อิมพีแดนซ์ชั่วขณะของ Via ดิ่งลงเหลือเพียง $32 - 36 \ \Omega$ ก่อให้เกิดคลื่นสะท้อนและทำให้ขอบสัญญาณเบลอ

### ข้อที่ 2 (ทำไมการวาง Ground Return Via 4 ตัวแบบ Coaxial Cage จึงลด Loop Inductance ได้มากกว่า 80%?)
เหตุใดในทฤษฎีสนามแม่เหล็กไฟฟ้า การวาง Ground Return Via จำนวน 4 รูล้อมรอบ Signal Via เป็นรูปกรงสี่เหลี่ยม (Coaxial Cage Configuration) จึงสามารถลดค่า Loop Inductance และขจัด Cavity Modes ได้อย่างมีประสิทธิภาพสูงสุด?

- **ก)** เพราะความต้านทานกระแสตรงของทองแดงลดลง 4 เท่า
- **ข)** เพราะโครงสร้างกรง 4 รูทำหน้าที่จำลองสนามแม่เหล็กไฟฟ้าเสมือนเป็นสายโคแอกเชียล (Coaxial Cable) สนามแม่เหล็กหมุนวนรอบตัวนำสัญญาณจะถูกเหนี่ยวนำหักล้างด้วยกระแสไหลกลับที่แบ่งไหล 4 ทิศทางอย่างสมมาตร ($I/4$ ในแต่ละรู) บีบกักขังสนามแม่เหล็กไฟฟ้าไว้ภายในกรง ไม่ให้รั่วไหลออกไปกระตุ้น Cavity ภายนอก
- **ค)** เพราะรูเจาะ 4 รูช่วยให้อากาศถ่ายเทระบายความร้อนได้ดีขึ้น
- **ง)** เพราะช่วยลดค่าคงที่ไดอิเล็กทริก $\epsilon_r$ ของบอร์ดลงเหลือ 1.0

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> เมื่อกระแสสัญญาณไหลลงในกระบอก Signal Via มันจะสร้างสนามแม่เหล็กหมุนวนตามกฎมือขวาของแอมแปร์  
> หากมี Ground Return Via ล้อมรอบ 4 ด้านอย่างสมมาตร:  
> 1. กระแสไหลกลับจะแบ่งตัวไหลย้อนขึ้นไปใน Return Via ทั้ง 4 รูอย่างเท่าเทียมกัน (รูละ $25\%$)  
> 2. สนามแม่เหล็กที่สร้างขึ้นจากกระแสไหลกลับทั้ง 4 ทิศทางจะเหนี่ยวนำหักล้างกับสนามแม่เหล็กของสายสัญญาณแทบสมบูรณ์แบบ (Mutual Inductance Cancellation)  
> 3. โครงสร้างนี้ประพฤติตัวเสมือนเป็น **สายส่งแบบ Coaxial ในแนวดิ่ง** กักขังเส้นแรงสนามแม่เหล็กไฟฟ้าไว้ภายในรัศมี $d$ ทำให้ค่า Loop Inductance ลดลงฮวบฮาบ ($< 0.25 \text{ nH}$) และตัดพลังงานที่จะรั่วไหลออกไปกระตุ้น Cavity Modes ได้มากกว่า $99\%$

### ข้อที่ 3 (การขยาย Anti-Pad ส่งผลต่อการตอบสนองของ TDR อย่างไร?)
ในการปรับจูนอิมพีแดนซ์ของรูเจาะ Through-Hole Via หากวิศวกรทำการขยายขนาดเส้นผ่านศูนย์กลางของรอยฉลุ Anti-Pad ($D_{anti}$) บนระนาบ Ground ชั้นในให้กว้างขึ้น ผลลัพธ์ข้อใดจะเกิดขึ้นกับรูปคลื่น TDR ของ Via?

- **ก)** รอยหลุม Capacitive Dip จะลึกขึ้นกว่าเดิม
- **ข)** รอยหลุม Capacitive Dip จะตื้นขึ้นและอิมพีแดนซ์ของ Via จะขยับสูงขึ้นเข้าใกล้ $50 \ \Omega$ เพราะระยะห่างระหว่างขอบทองแดงกับกระบอกเวียเพิ่มขึ้น ช่วยลดความจุไฟฟ้าแฝง ($C_v$) ลงอย่างมีนัยสำคัญ
- **ค)** รูปคลื่น TDR จะไม่เปลี่ยนแปลงเลยเพราะ Anti-pad อยู่ในชั้นใน
- **ง)** สัญญาณจะสะท้อนกลับเป็นศูนย์โวลต์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> จากสมการความจุแฝงของ Via: $C_v \propto \frac{1}{D_{anti} - D_{pad}}$  
> ตัวหารคือระยะห่างระหว่างขอบของ Via Pad ไปยังขอบทองแดงของระนาบ Ground  
> เมื่อทำการขยายเส้นผ่านศูนย์กลาง Anti-Pad ($D_{anti} \uparrow$):  
> ระยะช่องว่างจะกว้างขึ้น ส่งผลให้ค่าความจุไฟฟ้าแฝง $C_v$ ลดลงอย่างรวดเร็ว  
> จากนิยามของ Characteristic Impedance ชั่วขณะของ Via: $Z_{via} = \sqrt{\frac{L_v}{C_v}}$  
> เมื่อค่า $C_v$ ลดลง ค่า $Z_{via}$ จะขยับตัวสูงขึ้น ชดเชยจุดสะดุดทำให้รอยหลุม Capacitive Dip บนเครื่องวัด TDR หดเล็กลง รูปคลื่นสะท้อนจะเรียบเนียนขึ้น และการสูญเสีย Return Loss จะดีขึ้นอย่างเห็นได้ชัด
