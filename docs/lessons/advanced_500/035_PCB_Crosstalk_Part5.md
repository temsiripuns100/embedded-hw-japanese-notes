# Lesson 035: PCB Crosstalk Part 5 - 3W/5W Rule, Guard Traces, Resonant Stubs & Via Stitching
*(クロストーク対策 - 3W/5Wルール・ガード配線の落とし穴・1/4波長共振スタブとビアステッチング)*

---

## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการต่อสู้กับสัญญาณรบกวน Crosstalk กฎการจัดวางยอดนิยมอันดับหนึ่งที่วิศวกรทุกคนคุ้นเคยคือ **"กฎ 3W (3W Rule)"** และการเดินสายกราวด์คั่นกลางที่เรียกว่า **"Guard Trace (ガード配線)"** 

อย่างไรก็ดี ในมุมมองของ Senior Signal Integrity Architect กฎเกณฑ์เหล่านี้เต็มไปด้วย **กับดักทางฟิสิกส์ (Physics Traps)** ที่มักสร้างหายนะให้กับนักออกแบบที่ไม่เข้าใจทฤษฎีสนามแม่เหล็กไฟฟ้าอย่างถ่องแท้:
1. กฎ 3W ถูกสร้างขึ้นบนสมมติฐานของความสูงไดอิเล็กทริก ($H$) ค่าหนึ่งเท่านั้น หากความสูง $H$ มีค่ามาก กฎ 3W จะล้มเหลวโดยสิ้นเชิง
2. การวาง Guard Trace โดยปราศจากการตอกกราวด์เวีย (Stitching Vias) ที่หนาแน่นพอ จะเปลี่ยนสายกราวด์ให้กลายเป็น **เสาอากาศสั่นพ้อง (Resonant Quarter-Wave Antenna)** ที่ดูดซับสัญญาณรบกวนและยิงซ้ำลงสู่สาย Victim ทำให้ Crosstalk เลวร้ายลงกว่าการไม่ใส่ Guard Trace เสียอีก!

### 1.1 การวิเคราะห์กฎ 3W vs 5W และความสัมพันธ์กับความสูงของชั้นไดอิเล็กทริก ($H$)

นิยามดั้งเดิมของกฎ 3W กำหนดระยะห่างจากกึ่งกลางสายถึงกึ่งกลางสาย (Center-to-Center Pitch) เท่ากับ $3 \times W$ ซึ่งเทียบเท่ากับระยะห่างขอบถึงขอบ (Edge-to-Edge Spacing) เท่ากับ $S = 2W$:

```
        3W Rule (Center-to-Center)                 5W Rule (Ultra-Sensitive)
     │◄──────────── 3W ───────────►│            │◄──────────── 5W ───────────►│
     ┌─────┐      S = 2W     ┌─────┐            ┌─────┐      S = 4W     ┌─────┐
     │  W  │                 │  W  │            │  W  │                 │  W  │
     └─────┘                 └─────┘            └─────┘                 └─────┘
   ────────────────────────────────── Ground  ────────────────────────────────── Ground
                   Height H                                    Height H
```

- **พฤติกรรมสนามไฟฟ้าที่ 3W ($S = 2W$):** เส้นแรงสนามไฟฟ้าระหว่างสายส่งทั้งสองจะลดลงเหลือประมาณ $30\%$ ของจุดชิดติดกัน (ลดทอนลงราว $-10 \text{ dB}$ ถึง $-12 \text{ dB}$)
- **พฤติกรรมสนามไฟฟ้าที่ 5W ($S = 4W$):** เส้นแรงสนามไฟฟ้าเกือบ $90\%$ จะเบี่ยงตัวลงสู่ระนาบกราวด์ด้านล่าง สัญญาณรบกวน Crosstalk ลดลงต่ำกว่า $-20 \text{ dB}$ ($< 10\%$)

**ข้อจำกัดวิกฤตของกฎ 3W (The Critical Flaw of 3W Rule):**  
สนามแม่เหล็กไฟฟ้าไม่ได้ตัดสินการกระจายตัวจากความกว้างของสาย ($W$) เพียงอย่างเดียว แต่ตัดสินจากอัตราส่วนระยะห่างต่อความสูงของระนาบกราวด์ ($S/H$):
- หากบอร์ดมีชั้น Prepreg บาง ($H = 3 \text{ mil}$, $W = 6 \text{ mil}$): อัตราส่วน $S/H = (2 \times 6)/3 = 4.0$ กฎ 3W จะทำงานได้ดีเยี่ยม
- **หากบอร์ดมีชั้น Prepreg หนา ($H = 12 \text{ mil}$, $W = 6 \text{ mil}$):** อัตราส่วน $S/H = 12/12 = 1.0$ สนามไฟฟ้าส่วนใหญ่จะยังคงกระโดดข้ามระหว่างสาย กฎ 3W จะล้มเหลวทันที!

*กฎของวิศวกรอาวุโส:*  
**"ให้ใช้กฎ $S \ge 3H$ แทนกฎ $3W$ เสมอ"** เพราะระยะห่างเทียบกับความสูงของกราวด์ ($S \ge 3H$) รับประกันได้ตามทฤษฎีบททางฟิสิกส์ว่าเส้นแรงสนามไฟฟ้าจะเลือกพุ่งลงกราวด์มากกว่ากระโดดข้ามสายเสมอ ไม่ว่าความกว้างสายจะเป็นเท่าใด

### 1.2 อันตรายของ Floating Guard Trace และทฤษฎี Quarter-Wave Resonant Stub

เมื่อวิศวกรแทรกสาย Guard Trace ระหว่าง Aggressor และ Victim โดยไม่มีการเจาะ Via ลงระนาบ Ground อย่างเพียงพอ:

```
      Aggressor Trace          Ungrounded Guard Trace           Victim Trace
    ────────────────────      ════════════════════════      ────────────────────
             │                           │                           │
             ├─── Cm1 ───►               ├─── Cm2 ───►               │
             │           ┌───────────────┴───────────────┐           │
             │           │  Resonates at λ/4 Frequency!  │           │
             │           │  (Acting as RF Antenna Stub)  │           │
             │           └───────────────────────────────┘           │
   ──────────────────────────────────────────────────────────────────────── Ground Plane
```

1. **การเกิดเรโซแนนซ์แบบ Quarter-Wave ($f_{res}$):**  
   หาก Guard Trace ต่อลงกราวด์เพียงจุดเดียวที่ปลายข้างหนึ่ง และปล่อยลอยที่ปลายอีกข้างหนึ่ง หรือไม่มี Via เลย สายเส้นนี้จะกลายเป็น **Open-Circuited Transmission Line Stub**:

$$f_{res} = \frac{c}{4 \times \text{Len}_{guard} \times \sqrt{\epsilon_r}} \quad [\text{Quarter-Wave Resonance}]$$

2. **การขยายสัญญาณรบกวน (Crosstalk Amplification):**  
   ที่ความถี่เรโซแนนซ์ $f_{res}$ อิมพีแดนซ์ที่ปลายเปิดจะพุ่งสูงขึ้นอย่างมหาศาล Guard Trace จะกลายเป็นเสาอากาศรับคลื่นพลังงานสูงจาก Aggressor และแผ่คลื่นสะท้อนซ้ำลงสู่สาย Victim โดยตรง ส่งผลให้แรงดัน Crosstalk บนสาย Victim **พุ่งสูงขึ้นกว่าการไม่มี Guard Trace ถึง $6 - 10 \text{ dB}$!**

### 1.3 สูตรคำนวณระยะพิตช์ของ Stitching Via บน Guard Trace

เพื่อให้ Guard Trace ทำหน้าที่เป็นกำแพงป้องกันสนามแม่เหล็กไฟฟ้า (Faraday Shield Wall) ได้อย่างแท้จริง สายกราวด์จะต้องถูกตรึงศักย์ไฟฟ้าให้เท่ากับศูนย์โวลต์ตลอดความยาว โดยเจาะ Stitching Via เรียงเป็นระยะ:

$$\lambda_g = \frac{c}{f_{max} \times \sqrt{\epsilon_r}} \quad [\text{Guide Wavelength at Harmonic Frequency}]$$

$$p_{via} \le \frac{\lambda_g}{10} \quad \text{ถึง} \quad \frac{\lambda_g}{8}$$

ตัวอย่าง: สัญญาณนาฬิกา $1 \text{ GHz}$ ที่มีฮาร์มอนิกถึง $f_{max} = 5 \text{ GHz}$ บนบอร์ด FR-4 ($\epsilon_r = 4.0$):
$$\lambda_g = \frac{3 \times 10^8 \text{ m/s}}{5 \times 10^9 \text{ Hz} \times \sqrt{4.0}} = \frac{3 \times 10^8}{1 \times 10^{10}} = 0.030 \text{ m} = \mathbf{30.0 \text{ mm}}$$

$$p_{via} \le \frac{30.0 \text{ mm}}{10} = \mathbf{3.0 \text{ mm} \ (118 \text{ mil})}$$

หากระยะห่างระหว่างจุดเจาะเวียเกินกว่า $3.0 \text{ mm}$ คลื่นฮาร์มอนิก 5 GHz จะสามารถแทรกซึมและกระตุ้นการสั่นพ้องในเนื้อ Guard Trace ได้

### 1.4 Guard Trace vs การเพิ่มระยะห่างว่างเปล่า (Separation Space Efficiency)

บทวิเคราะห์เปรียบเทียบเชิงพื้นที่โดย ดร. Howard Johnson:

```
    Option A: Guard Trace with Vias            Option B: Pure Separation Space
   Trace 1    Guard Trace    Trace 2          Trace 1                   Trace 2
   ┌─────┐  S1 ┌───┐  S2   ┌─────┐            ┌─────┐                 ┌─────┐
   │     │◄───►│(o)│◄─────►│     │            │     │                 │     │
   └─────┘     └───┘       └─────┘            └─────┘                 └─────┘
   │◄────── Total Width W_total ──────►│      │◄─────── Total Width W_total ───────►│
```

| ปัจจัยการเปรียบเทียบ | Option A: มี Guard Trace + Via | Option B: เว้นระยะห่างว่างเปล่าเท่ากัน |
|---|---|---|
| **การลดทอน Crosstalk** | ลดทอนได้ประมาณ $-25 \text{ dB}$ ถึง $-30 \text{ dB}$ | **ลดทอนได้เท่ากันหรือดีกว่า ($-30 \text{ dB}$ ถึง $-35 \text{ dB}$)** |
| **ความเสี่ยง Resonant Stub** | มีความเสี่ยงสูงมากหาก Via หลุดหรือพิตช์ห่าง | **ไม่มีความเสี่ยงใดๆ ทั้งสิ้น (Zero Risk)** |
| **ผลกระทบต่ออิมพีแดนซ์ ($Z_0$)**| Guard Trace ดึงความจุแฝง ดึง $Z_0$ ตกฮวบ | อิมพีแดนซ์ของสายคงที่สม่ำเสมอ |
| **ความหนาแน่นของการเจาะรู** | เพิ่มจำนวนรูเจาะ Via มหาศาล ทำลายความแข็งแรงบอร์ด | **ไม่เปลืองรูเจาะแม้แต่รูเดียว** |

*ข้อสรุปของ Senior Engineer:*  
ในเกือบทุกสถานการณ์ **"การเว้นช่องว่างว่างเปล่า (Pure Spacing) มีประสิทธิภาพสูงกว่า ปลอดภัยกว่า และคุ้มค่ากว่าการใส่ Guard Trace"** ควรสงวน Guard Trace ไว้เฉพาะกรณีที่จำเป็นต้องแยกโดเมนสัญญาณต่างชนิดกันอย่างยิ่งยวดยวด (เช่น สัญญาณ RF อ่อนไหว ขนานข้างตัวจ่ายไฟ Switching Power Supply)

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** วงจรสร้างความถี่ PLL (Phase-Locked Loop 2.4 GHz) ในโมดูลสื่อสารไร้สาย เกิดอาการ Phase Noise พุ่งสูงขึ้นผิดปกติและหลุดล็อก (PLL Unlock Failure) เป็นช่วงๆ โดยพบว่าสัญญาณรบกวนหลักมาจากฮาร์มอนิกของสัญญาณนาฬิการะบบ 125 MHz 
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **วาง Guard Trace ปลายเปิดโดยมี Via ห่างกันเกินไป:** ทีมออกแบบต้องการป้องกันสัญญาณนาฬิกา 125 MHz ไม่ให้ไปกวนสายควบคุม VCO จึงแทรก Guard Trace กว้าง $0.3 \text{ mm}$ ขนานยาว $42 \text{ mm}$ แต่ **เจาะ Ground Via ไว้เพียง 2 จุดที่หัวและท้ายของสายเท่านั้น** (ระยะห่าง Via $= 42 \text{ mm}$)
2. **เกิด Quarter-Wave Resonance ที่ 1.25 GHz:**  
   สาย Guard Trace ที่ยาว 42 mm สั่นพ้องที่ความถี่ฮาร์มอนิกที่ 10 ของสัญญาณนาฬิกา ($10 \times 125 \text{ MHz} = 1.25 \text{ GHz}$) พอดิบพอดี ส่งผลให้ Guard Trace ทำหน้าที่เป็นเสาอากาศเหนี่ยวนำขยายขนาดสัญญาณรบกวน 1.25 GHz เข้าสู่ขา VCO ป้อนตรงเข้าสู่ลูป PLL จนระบบพังทลาย

---

### ขั้นตอนการตรวจสอบและแก้ไข Guard Trace สไตล์ Senior (検図チェックリスト):
1. **การประเมินความจำเป็นของ Guard Trace (Do We Really Need It?):**
   - คำนวณพื้นที่ว่าง: หากมีพื้นที่กว้างพอ ให้ลบ Guard Trace ออก แล้วขยายระยะห่างระหว่างสายทั้งสองเส้นให้กว้างที่สุด ($S \ge 4W$ หรือ $S \ge 3H$)
   - หากต้องใช้ Guard Trace จริง (เช่น การแยกสาย Analog ออกจาก Digital ในพื้นที่แคบ) ต้องปฏิบัติตามกฎด้านล่างอย่างเคร่งครัด
2. **การกำหนดระยะพิตช์ของ Stitching Via อย่างเข้มงวด:**
   - ห้ามต่อกราวด์เฉพาะหัวท้ายเด็ดขาด!
   - วาง Stitching Via เจาะทะลุลง Solid Ground Plane ตลอดแนวสายด้วยระยะก้าวคงที่:
     $$p_{via} \le \frac{c}{10 \cdot f_{max} \cdot \sqrt{\epsilon_r}} \quad (\text{คำนวณที่ฮาร์มอนิกสูงสุดที่น่ากังวล})$$
   - สำหรับระบบดิจิทัลทั่วไปที่มี Rise Time $t_r \le 1.0 \text{ ns}$ ให้กำหนดระยะพิตช์เวีย **ไม่เกิน $2.0 \text{ mm} - 2.5 \text{ mm} \ (80 - 100 \text{ mil})$**
3. **การต่อปลายสาย Guard Trace เข้าสู่ Ground Plane ทั้งสองด้าน:**
   - ที่จุดเริ่มต้นและจุดสิ้นสุดของแนวขนาน ต้องมี Via เชื่อมลงกราวด์ทันที ห้ามปล่อยให้มีติ่งทองแดงยื่นเลยออกไปเป็น Stub ปลายเปิดแม้แต่ 0.5 mm

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「125MHzシステムクロックと高周波VCO制御線間のガード配線（L=40mm）において、両端2箇所のビア接続のみで中間部にステッチングビアが配置されていません。基板比誘電率εr=4.0での1/4波長共振周波数が約937MHz（第7次高調波近傍）に合致し、オープンスタブ共振によってガード配線自身が寄生アンテナ化してVCOラインへノイズを再放射しています。共振を完全に抑制するため、ガード配線上にピッチ2.0mm以下でリファレンスGNDへのステッチングビアを連続配置してください。」  
> *(สาย Guard Trace ยาว 40mm ระหว่าง Clock 125MHz กับ VCO มีการต่อเวียเพียงแค่สองปลายหัวท้าย ทำให้ความถี่สั่นพ้อง 1/4 ความยาวคลื่นตกที่ 937MHz ใกล้ฮาร์มอนิกที่ 7 กลายเป็นเสาอากาศปล่อยคลื่นรบกวนใส่ VCO เสียเอง เพื่อตัดการสั่นพ้อง กรุณาเจาะ Stitching Via ลงกราวด์ตลอดแนวด้วยระยะพิตช์ไม่เกิน 2.0mm)*

> **指摘事項 2:**  
> 「データバス間に幅0.15mmのガード配線を無理に挿入した結果、信号線-ガード間スペースがS=0.1mmまで狭まり、信号線インピーダンスが43Ωまで容量性低下（不連続点）を引き起こしています。当該帯域においてビアのないガード配線はシールド効果が薄いため、ガード配線を撤去し、空いたスペースを純粋な離隔距離（S≧0.4mm、3Hルール以上）として配線間隔を均等に再配分してください。」  
> *(การฝืนแทรก Guard Trace กว้าง 0.15mm ทำให้ช่องว่างหดเหลือ 0.1mm ดึงให้อิมพีแดนซ์ดิ่งลงเหลือ 43 โอห์ม ในย่านความถี่นี้สายที่ไม่มีเวียแทบไม่ช่วยบังคลื่น ขอสั่งให้ลบ Guard Trace ออก แล้วนำพื้นที่ที่ได้คืนมาไปขยายระยะห่างระหว่างสายทั้งสองเส้นให้กว้างขึ้นเป็น S>=0.4mm ตามกฎ 3H)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณความถี่สั่นพ้อง 1/4 ความยาวคลื่นของ Guard Trace ที่ไม่ได้เจาะเวีย)
วิศวกรลากสาย Guard Trace บนบอร์ด FR-4 ($\epsilon_r = 4.0$) เป็นแนวยาว $\text{Len} = 37.5 \text{ mm}$ โดยต่อปลายข้างหนึ่งลงสู่ Ground Plane แต่ปล่อยปลายอีกข้างหนึ่งเปิดลอยไว้ (Floating Open-End) ถามว่าสาย Guard Trace นี้จะเกิด Quarter-Wave Resonance ($f_{res}$) ที่ความถี่ใด และเสี่ยงต่อการแผ่คลื่นรบกวนมากที่สุด?

- **ก)** $f_{res} = 1.0 \text{ GHz}$
- **ข)** $f_{res} = 2.0 \text{ GHz}$
- **ค)** $f_{res} = 500 \text{ MHz}$
- **ง)** $f_{res} = 4.0 \text{ GHz}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ก)**  
> 1. ความเร็วคลื่นในบอร์ด FR-4:  
> $$v_p = \frac{c}{\sqrt{\epsilon_r}} = \frac{3.0 \times 10^8 \text{ m/s}}{\sqrt{4.0}} = \frac{3.0 \times 10^8}{2} = 1.5 \times 10^8 \text{ m/s} = 150 \text{ mm/ns}$$  
> 2. จากสมการ Quarter-Wave Stub Resonance:  
> $$f_{res} = \frac{v_p}{4 \times \text{Len}} = \frac{150 \times 10^6 \text{ mm/s}}{4 \times 37.5 \text{ mm}} = \frac{150 \times 10^6}{150} = \mathbf{1.0 \times 10^9 \text{ Hz}} = \mathbf{1.0 \text{ GHz}}$$  
> ที่ความถี่ 1.0 GHz ความยาว 37.5 mm จะมีขนาดเท่ากับ $1/4$ ของความยาวคลื่นพอดีเป๊ะ!  
> สาย Guard Trace จะกลายเป็นวงจรเรโซแนนซ์แบบขนานที่มีอิมพีแดนซ์สูงมากที่ปลายเปิด เกิดแรงดันคลื่นนิ่ง (Standing Wave) ขนาดใหญ่ และทำหน้าที่เป็นเสาอากาศแผ่สัญญาณรบกวนลงสู่วงจรรอบข้างอย่างรุนแรง

### ข้อที่ 2 (ทำไมกฎ S >= 3H จึงเหนือกว่ากฎ 3W ในการป้องกัน Crosstalk?)
เหตุใดในทฤษฎีการออกแบบบอร์ดไฮสปีดยุคใหม่ จึงแนะนำให้วิศวกรใช้กฎระยะห่างเชิงกายภาพ $S \ge 3H$ (ระยะห่างของสายเทียบกับความสูงของระนาบกราวด์) แทนที่จะใช้กฎ $3W$ (ระยะห่างเทียบกับความกว้างของสาย)?

- **ก)** เพราะความกว้างของสาย $W$ ไม่สามารถวัดได้ด้วยสายตา
- **ข)** เพราะเส้นแรงสนามแม่เหล็กไฟฟ้าจะกระจายตัวข้ามไปยังสายข้างเคียงหรือดิ่งลงกราวด์ ขึ้นอยู่กับอัตราส่วนระยะทางไปยังระนาบกราวด์ ($H$) เทียบกับระยะห่างระหว่างสาย ($S$) หาก $H$ หนามาก การเว้นระยะ $S = 2W$ อาจยังคงอยู่ใกล้กันมากกว่าระยะทางลงกราวด์ ทำให้สนามไฟฟ้ากระโดดข้ามสายได้อยู่ดี
- **ค)** เพราะกฎ 3H ช่วยลดต้นทุนค่าทำแผ่นฟอยล์ทองแดง
- **ง)** เพราะเครื่องจักรในโรงงานรองรับเฉพาะการตั้งค่า $H$ เท่านั้น

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> สนามไฟฟ้าและสนามแม่เหล็กจะเลือกเส้นทางที่มีค่าความต้านทานและระยะทางสั้นที่สุด  
> หากบอร์ดมีความหนาของไดอิเล็กทริก $H$ มาก (เช่น $H = 10 \text{ mil}$) แต่สายส่งมีความกว้างเพียง $W = 4 \text{ mil}$:  
> การใช้กฎ $3W$ จะให้ระยะห่างขอบสายเพียง $S = 2W = 8 \text{ mil}$  
> สังเกตว่าระยะห่างระหว่างสาย ($S = 8 \text{ mil}$) **สั้นกว่าระยะทางไปยังกราวด์ ($H = 10 \text{ mil}$)** เสียอีก! เส้นแรงสนามไฟฟ้าจึงเลือกที่จะกระโดดข้ามไปหาสายข้างเคียงมากกว่าวิ่งลงกราวด์ ก่อให้เกิด Crosstalk ขนาดใหญ่  
> แต่หากใช้กฎ $S \ge 3H$ ระยะห่างจะต้องกว้างอย่างน้อย $30 \text{ mil}$ ซึ่งรับประกันได้ว่าระยะทางไปยังกราวด์ใกล้กว่าระยะข้ามสายถึง 3 เท่า เส้นแรงสนามไฟฟ้าเกิน $98\%$ จะถูกดูดลงกราวด์อย่างแน่นอน

### ข้อที่ 3 (การตัดสินใจทางสถาปัตยกรรม: Guard Trace vs Pure Spacing)
เมื่อวิศวกรมีพื้นที่ว่างบนบอร์ดจำกัดขนาดหนึ่ง เช่น กว้างรวม $1.0 \text{ mm}$ ระหว่างสาย Aggressor และสาย Victim ตัวเลือกใดระหว่าง (A) การใส่ Guard Trace กว้าง 0.2 mm พร้อมเจาะ Via กับ (B) การปล่อยให้เป็นพื้นที่ว่างเปล่า 1.0 mm โดยไม่มีทองแดงใดๆ คั่นกลาง ให้ผลลัพธ์ในการลด Crosstalk และความสมบูรณ์ของสัญญาณที่ดีกว่าในทางปฏิบัติส่วนใหญ่?

- **ก)** ตัวเลือก A ดีกว่าเสมอเพราะมีทองแดงเป็นกำแพงกั้น
- **ข)** ตัวเลือก B ดีกว่า เพราะการเว้นระยะห่างว่างเปล่ากว้างเต็มที่ ช่วยลดค่าความจุและอินดักแตนซ์ร่วมลงตามธรรมชาติ ไม่เสี่ยงต่อปัญหาเรโซแนนซ์ของเวีย ไม่ทำลายความสม่ำเสมอของ $Z_0$ และไม่กินเนื้อที่กราวด์บนเลเยอร์อื่นจากรูเจาะเวีย
- **ค)** ตัวเลือก A ดีกว่าเพราะช่วยให้บอร์ดระบายความร้อนได้เร็วขึ้น
- **ง)** ทั้งสองตัวเลือกให้ผลลัพธ์เหมือนกันทุกประการ

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> จากการทดลองและการวิเคราะห์เชิงตัวเลขของ ดร. Howard Johnson และ Eric Bogatin:  
> เมื่อพิจารณาพื้นที่จำกัดเท่ากัน การแทรก Guard Trace ลงไปจะกินพื้นที่ว่างของช่องว่าง ($S$) ทำให้ระยะห่างระหว่างสายกับ Guard Trace แคบลงมาก ส่งผลให้:  
> 1. อิมพีแดนซ์ของสายส่งหลักตกลงจากความจุแฝงที่เหนี่ยวนำกับ Guard Trace  
> 2. ต้องเจาะ Via เรียงกันเป็นพรืด ซึ่งรูเจาะ Via จะไปตัดฉลุระนาบ Ground Plane ด้านล่าง (Swiss-Cheese Effect) เพิ่มความเหนี่ยวนำในระนาบกราวด์  
> 3. หาก Via ห่างเกินไป Guard Trace จะกลายเป็นตัวกระจายสัญญาณรบกวนเสียเอง  
> ในทางตรงกันข้าม การปล่อยให้เป็นพื้นที่ว่างเปล่าบริสุทธิ์ (Pure Spacing) กว้างเต็ม $1.0 \text{ mm}$ สนามแม่เหล็กไฟฟ้าจะลดทอนลงตามกฎระยะทางผกผันอย่างเป็นธรรมชาติ ไม่มีจุดสะดุดของอิมพีแดนซ์ และไม่มีความเสี่ยงจากการสั่นพ้องใดๆ ทั้งสิ้น ตัวเลือก B จึงเป็นคำตอบระดับ Best Practice ของ Senior Engineer เสมอ
