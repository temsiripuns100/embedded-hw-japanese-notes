## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการออกแบบแผงวงจรความหนาแน่นสูง (High-Density Interconnect - HDI) ที่ใช้งานชิปประมวลผลขนาดใหญ่ เช่น FPGA, SoC, และ High-Performance Computing (HPC) ASICs ซึ่งมีพินบอลบัดกรีระดับ 1,000 ถึง 3,000+ พิน และมีระยะพิตช์ (Pitch) แคบลงตั้งแต่ $1.0\text{ mm}$ ลงไปจนถึง $0.4\text{ mm}$ ความท้าทายสูงสุดของวิศวกรออกแบบ PCB ไม่ใช่เพียงแค่การเชื่อมต่อสัญญาณให้ครบทุกเส้น แต่คือ **"การออกแบบโครงสร้างสถาปัตยกรรมการคลี่สัญญาณออกจากใต้ตัวถัง (BGA Escape Routing / Fanout Architecture)"** ควบคู่ไปกับการควบคุมความต้านทานจำเพาะ (Impedance), สัญญาณรบกวนข้ามช่อง (Crosstalk), ความสมบูรณ์ของระนาบกราวด์อ้างอิง (Reference Plane Integrity), และความสามารถในการผลิตเชิงอุตสาหกรรม (DFM - Design for Manufacturability)

### 1.1 คณิตศาสตร์การคำนวณพื้นที่ช่องสัญญาณรอด (Routing Channel Width) และจำนวนคู่สาย

ในการวางผัง Fanout ใต้ BGA พารามิเตอร์พื้นฐานที่กำหนดว่าสัญญาณสามารถวิ่งลอดระหว่างแพดหรือเวียได้กี่เส้น คือความกว้างของช่องเปิดทางเรขาคณิต (Geometric Routing Channel):

#### 1. ช่องสัญญาณลอดระหว่าง BGA Pad คู่ติดกัน (Outer Layer Routing Channel):
$$W_{\text{channel, pad}} = P - D_{\text{pad}} - 2 \cdot C_{\text{mask/trace}}$$

โดยที่:
- $P$ = BGA Pitch (ระยะห่างระหว่างจุดกึ่งกลางของบอลบัดกรี, $\text{mm}$)
- $D_{\text{pad}}$ = เส้นผ่านศูนย์กลางของ BGA Land Pad ($\text{mm}$)
- $C_{\text{mask/trace}}$ = ระยะห่างขั้นต่ำตาม DFM ระหว่างขอบ Pad ถึงเส้น Trace หรือขอบ Solder Mask ถึง Trace ($\text{mm}$)

#### 2. ช่องสัญญาณลอดระหว่าง Fanout Via Pad คู่ติดกันในชั้นสัญญาณด้านใน (Inner Layer Via Channel):
เมื่อใช้โครงสร้าง Dog-bone ซึ่งต้องเจาะ Through-hole Via ทะลุลงไปชั้นใน พื้นที่ช่องทางวิ่งสัญญาณในชั้น Inner Layer จะถูกจำกัดด้วย Via Capture Pad และ Anti-pad:
$$W_{\text{channel, via}} = P - D_{\text{via\_pad}} - 2 \cdot S_{\text{trace\_via}}$$

โดยที่:
- $D_{\text{via\_pad}}$ = เส้นผ่านศูนย์กลางของ Via Capture Pad (รวม Annular Ring)
- $S_{\text{trace\_via}}$ = ระยะห่างทางไฟฟ้าระหว่างขอบทองแดงของเส้น Trace กับขอบ Via Pad

#### 3. จำนวนเส้นสัญญาณที่สามารถวิ่งลอดได้ต่อ 1 แถวพิน (Trace Routing Capacity per Channel):
$$N_{\text{trace}} = \left\lfloor \frac{W_{\text{channel}} - W_{\text{trace}}}{W_{\text{trace}} + S_{\text{trace\_trace}}} \right\rfloor + 1 \quad \text{(กรณี } W_{\text{channel}} \ge W_{\text{trace}}\text{)}$$
หรือเขียนในรูปทั่วไป:
$$W_{\text{channel}} \ge N_{\text{trace}} \cdot W_{\text{trace}} + (N_{\text{trace}} + 1) \cdot S_{\text{clearance}}$$

หากต้องการลากสายสัญญาณ 2 เส้น (Dual-track routing / Differential pair) ลอดผ่านระหว่างรูเวียของ BGA Pitch $0.8\text{ mm}$ วิศวกรต้องตรวจสอบว่า:
$$P - D_{\text{via\_pad}} \ge 2 \cdot W_{\text{trace}} + S_{\text{diff\_space}} + 2 \cdot S_{\text{trace\_via}}$$

### 1.2 Dog-Bone Fanout เทียบกับ VIPPO (Via-in-Pad Plated Over)

| คุณลักษณะทางวิศวกรรม | Dog-Bone Fanout Architecture | VIPPO / POFV Architecture (IPC-4761 Type VII) |
| :--- | :--- | :--- |
| **โครงสร้างทางกายภาพ** | ลากเส้นทองแดงสั้น ๆ ออกจาก BGA Pad ไปยัง Via ด้านข้าง คล้ายรูปกระดูกสุนัข | เจาะรู Via ตรงจุดศูนย์กลางของ BGA Pad อุดด้วยเรซิน แล้วชุบทองแดงปิดทับเรียบ (Planarized) |
| **ระยะ BGA Pitch ที่เหมาะสม** | $\ge 0.8\text{ mm}$ (หากใช้กับ $0.65\text{ mm}$ ต้องลดขนาด Drill/Pad จนแตะขีดจำกัด Fab) | เหมาะสำหรับ $\le 0.65\text{ mm}$, $0.5\text{ mm}$, $0.4\text{ mm}$ และสัญญาณระดับ Multi-GHz |
| **การควบคุม Impedance** | ต้องบีบขนาดเส้น Trace สั้นลง (Neck-down) ทำให้เกิด Discontinuity Dip $3\text{ - }7\ \Omega$ | ไม่มี Neck-down เส้นวิ่งตรงจาก Pad สู่ Inner Layer รักษา $Z_0 = 50\ \Omega$ สม่ำเสมอ |
| **ปรสิตทางไฟฟ้า (Parasitic Inductance)** | เหนี่ยวนำสูง มี Inductance จาก Neck Trace + Via Stub รวม $\approx 0.8\text{ - }1.5\text{ nH}$ | ปรสิตต่ำสุด Inductance ลดลงเหลือเพียงความยาวของตัว Via ($\approx 0.2\text{ - }0.4\text{ nH}$) |
| **พื้นที่ระนาบอ้างอิง (Plane Perforation)** | เสียพื้นที่ทองแดงระนาบกราวด์มาก เนื่องจากรู Via ต้องเยื้องออกจากพินบอล | รูเวียอยู่ตรงกับตำแหน่งบอล ทำให้ระนาบกราวด์ชั้นล่างมีพื้นที่ต่อเนื่องกว้างกว่า |
| **ต้นทุนการผลิตแผ่นวงจร (PCB Cost)** | ต้นทุนมาตรฐาน (Standard Process) ไม่ต้องมีขั้นตอนอุดรูและเจียรผิวหน้า | ต้นทุนเพิ่มขึ้น $15\% - 25\%$ เนื่องจากมีกระบวนการ Resin Plugging + Planarization + Cap Plating |
| **ความเสี่ยงในการบัดกรี (SMT Risk)** | ปลอดภัยจากปัญหา Solder Wicking เพราะมี Solder Mask Dam กั้นระหว่าง Pad กับ Via | หากชุบปิดทองแดงไม่สมบูรณ์ (Dimple $> 15\ \mu\text{m}$) จะเกิด Solder Void หรือ Solder Wicking |

### 1.3 สถาปัตยกรรม High-Density Interconnect (HDI) Micro-via: Staggered เทียบกับ Stacked

เมื่อพิตช์ของ BGA ลดลงสู่ $0.5\text{ mm}$ หรือ $0.4\text{ mm}$ รูเจาะกลไก (Mechanical Drill) ไม่สามารถทำขนาดเล็กกว่า $0.15\text{ mm}$ ได้อย่างคุ้มค่าเชิงพาณิชย์ วิศวกรต้องก้าวเข้าสู่เทคโนโลยี **HDI ตามมาตรฐาน IPC-2226** โดยใช้ Laser Micro-via (เส้นผ่านศูนย์กลางเลเซอร์ $75\text{ - }100\ \mu\text{m}$):

#### 1. อัตราส่วนความลึกต่อขนาดรูเจาะเลเซอร์ (Laser Aspect Ratio Limit):
$$AR_{\text{laser}} = \frac{T_{\text{dielectric}}}{D_{\text{laser\_drill}}} \le 0.8 : 1 \quad (\text{ขีดจำกัดสูงสุดเชิงพาณิชย์ไม่ควรเกิน } 1.0 : 1)$$
หากไดอิเล็กทริกระหว่างชั้นหนา $60\ \mu\text{m}$ ขนาดรูเลเซอร์ที่เหมาะสมคือ $75\ \mu\text{m}$ ซึ่งได้ $AR = 60/75 = 0.8$ หากเจาะรูลึกเกินไป น้ำยาเคมีชุบทองแดงจะไม่สามารถซึมเข้าไปเคลือบก้นหลุมได้อย่างสมบูรณ์ เกิดโพรงอากาศ (Void at Bottom of Via)

#### 2. Staggered Micro-via (เยื้องศูนย์):
- Micro-via ในแต่ละชั้นสะสม (Build-up layer) จะวางเยื้องตำแหน่งกัน (Offset distance $\ge D_{\text{pad}} + 50\ \mu\text{m}$)
- **ความเค้นเชิงกล (Thermo-mechanical Stress):** การเยื้องศูนย์ช่วยกระจายแรงเค้นจากการขยายตัวในแนวแกน Z ของบอร์ด ($CTE_z$ Mismatch) ทำให้มีความทนทานต่อการเปลี่ยนแปลงอุณหภูมิ (Thermal Cycling Reliability) สูงกว่ามาก
- **ข้อจำกัด:** สิ้นเปลืองพื้นที่ Routing ในชั้นสัญญาณด้านใน เนื่องจากต้องเผื่อแลนด์แพดสำหรับจุดเยื้อง

#### 3. Stacked Micro-via (ซ้อนศูนย์ตรงกัน):
- Micro-via วางซ้อนทับกันในแนวดิ่งโดยตรงจาก L1 สู่ L2 สู่ L3
- ทุกชั้นของ Micro-via ต้องผ่านกระบวนการชุบทองแดงปิดตันรูเต็มหลุม (Solid Copper Filled Micro-via) ตามมาตรฐาน IPC-4761
- **ความเค้นรวมศูนย์ (Stress Concentration):** เมื่อแผ่นบอร์ดได้รับความร้อน แกน Z ของเรซิน FR-4 จะขยายตัวด้วย $CTE_z \approx 45 - 60\ \text{ppm}/^\circ\text{C}$ ขณะที่แท่งทองแดงขยายตัวเพียง $17\ \text{ppm}/^\circ\text{C}$ ความแตกต่างนี้สร้างแรงดึงมหาศาล (Tensile Stress) ในแนวดิ่ง
- เสี่ยงต่อการเกิด **การแยกตัวที่รอยต่อระหว่างหลุมเวีย (Target Pad Separation / Interface Cracking)** ระหว่างก้นของ Micro-via ชั้นบน กับหัวของ Micro-via ชั้นล่าง

### 1.4 การคำนวณจำนวนชั้นสัญญาณที่ต้องใช้สำหรับการคลี่สาย (Layer Count Determination)

ในการประเมินโครงสร้าง Stackup วิศวกรอาวุโสต้องคำนวณจำนวนชั้นสัญญาณ (Signal Layers) ที่ต้องการล่วงหน้าเพื่อหลีกเลี่ยงการติดล็อก (Dead-end Routing):

#### โมเดลการคำนวณความสามารถในการคลี่สายตามแนวระนาบ (Boundary Escape per Layer):
สำหรับ BGA ทรงสี่เหลี่ยมจัตุรัสที่มีจำนวนพินทั้งหมด $N_{\text{total}} = M \times M$ พิน:
1. **พิน 2 วงนอกสุด (Rows 1 & 2):** สามารถลากสัญญาณออกจากชั้นผิวด้านนอก (Component Layer) ได้โดยตรง 100% โดยไม่ต้องใช้รูเวียเจาะลงชั้นใน
2. **พินแถวถัด ๆ ไป (Inner Rows $\ge 3$):** ต้องใช้รูเวียเจาะทะลุลงไปยังชั้นสัญญาณภายใน
3. กำหนดให้จำนวนพินสัญญาณที่ต้องคลี่ออกคือ $N_{\text{sig}}$ และจำนวนเส้นสัญญาณที่สามารถวิ่งลอดออกจากช่องทางของแต่ละชั้นใน 1 ด้านคือ $E_{\text{side}}$:

$$N_{\text{escape\_capacity\_per\_layer}} = 4 \times \left( \frac{M}{2} - 1 \right) \times N_{\text{traces\_per\_channel}}$$

จำนวนชั้นสัญญาณขั้นต่ำที่ต้องการ ($L_{\text{signal}}$) ประเมินได้จาก:
$$L_{\text{signal}} \ge \left\lceil \frac{N_{\text{sig\_inner}}}{N_{\text{escape\_capacity\_per\_layer}}} \right\rceil$$

โดยที่ $N_{\text{sig\_inner}}$ คือจำนวนพินสัญญาณทั้งหมดลบด้วยสัญญาณที่หลุดออกในชั้นนอกสุดแล้ว

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例 - Shippai Jirei)

**เหตุการณ์:** การนำบอร์ดประมวลผลเครือข่ายความเร็วสูง (Enterprise Core Router Switch) ที่ใช้ชิป Multi-core Network Processor (NPU) ขนาดตัวถัง BGA 1,156 พิน ($35 \times 35\text{ mm}$, Pitch $0.8\text{ mm}$) เข้าสู่กระบวนการผลิตล็อตนำร่อง (Pilot Run) จำนวน 200 แผ่น พบอัตราของเสียสูงถึง $34\%$ จาก 2 ปัญหาหลัก:
1. การตรวจสอบรังสีเอ็กซ์ (3D AXI) พบโพรงอากาศขนาดใหญ่ (Excessive Solder Voids $> 35\%$) ที่บอลบัดกรีแถวสัญญาณความเร็วสูง และมีบางพินเกิดอาการขาบัดกรีไม่สัมผัส (Open Joint)
2. สัญญาณบัสหน่วยความจำ DDR4-3200 เกิดปัญหาข้อผิดพลาดบิตสุ่ม (Intermittent Bit Errors) และมีสัญญาณรบกวน Jitter เกินเกณฑ์มาตรฐานเมื่อชิปทำงานที่ภาระงานสูงสุด

```

|                                                                                         |
|     BGA Solder Ball                             Dog-Bone Via Array                      |
|         ┌───────┐                                 (Oversized Anti-pads Overlap!)        |
|        /  VOID!  \                                ┌───┐       ┌───┐       ┌───┐         |

|       ─┴───   ───┴─  Solder Mask Clearance        └───┘       └───┘       └───┘         |
```

#### การวิเคราะห์หาสาเหตุรากเหง้า (Root Cause Analysis - RCA):
1. **สาเหตุของ Solder Void / Open Joint:** ทีมออกแบบต้องการประหยัดต้นทุนบอร์ด จึงสั่งให้โรงงาน PCB ผลิตรูเวียใต้แพดแบบ **Tented Via (IPC-4761 Type II)** แทนที่จะสั่ง VIPPO (Type VII) แต่ในไฟล์ Gerber มีการเปิดหน้ากาก Solder Mask คลาดเคลื่อน ทำให้ฟิล์มแห้งทับรูเจาะไม่สมบูรณ์ เมื่อแผ่นบอร์ดเข้าสู่เตาอบ Reflow ตะกั่วบัดกรีจากเม็ด BGA หลอมละลายและถูกแรงตึงผิวดูดกลืนไหลลงไปในรูเจาะของเวีย (Solder Wicking Mechanism) ส่งผลให้เนื้อตะกั่วบนผิวหน้าแพดไม่เพียงพอที่จะประสานกับบอลบัดกรี
2. **สาเหตุของ DDR4 Bit Errors & High Jitter:** ในการทำ Dog-bone Fanout วิศวกรใช้ขนาด Anti-pad บนระนาบกราวด์ชั้น L2 กว้างถึง $0.70\text{ mm}$ เพื่อลดการเกิด Parasitic Capacitance ของเวีย แต่เนื่องจาก BGA Pitch แคบเพียง $0.8\text{ mm}$ ช่องว่างระหว่าง Anti-pad สองช่องติดกันจึงเหลือเพียง:
   $$\text{Webbing} = 0.80\text{ mm} - 0.70\text{ mm} = 0.10\text{ mm}$$
   เมื่อโรงงานเกิดความคลาดเคลื่อนในการกัดกรดทองแดง (Etch Tolerance $\pm 25\ \mu\text{m}$) และความคลาดเคลื่อนในการประกบชั้นเลเยอร์ (Layer Registration Offset $\pm 35\ \mu\text{m}$) แถบทองแดงกั้นกลางขาดออกจากกัน ทำให้ Anti-pad รวมตัวกันกลายเป็น **ร่องเหวลอย (Continuous Copper Slot)** ใต้แนวพิน BGA เส้นสัญญาณความเร็วสูงที่วิ่งลอดผ่านร่องนี้สูญเสียระนาบอ้างอิง กระแสไหลย้อนกลับ (Return Current) ถูกบีบให้ต้องอ้อมร่องทองแดงเป็นระยะทางกว่า $4.5\text{ mm}$ สร้าง Parasitic Loop Inductance สูงถึง $3.2\text{ nH}$ เหนี่ยวนำสัญญาณรบกวนข้ามช่องและเกิด Ground Bounce อย่างรุนแรง

#### มาตรการแก้ไขเชิงวิศวกรรม (Engineering Countermeasures):
1. **ปรับสถาปัตยกรรมสู่ VIPPO (IPC-4761 Type VII):** เปลี่ยนรูเวียใต้ BGA ทั้งหมดให้เป็น Via-in-Pad ที่ผ่านกระบวนการอุดด้วยอีพอกซีเรซิน (Epoxy Resin Plugging) เจียรผิวให้เรียบเสมอกัน และชุบทองแดงเคลือบผิวหน้า (Over-plated Copper Cap) ควบคุมค่าความเว้าลึกของหน้าสัมผัส (Dimple Depth) ให้น้อยกว่า $10\ \mu\text{m}$ ตามมาตรฐาน IPC-4761
2. **ออกแบบ Anti-pad Geometry ใหม่ (Oval/Oblong Anti-pads):** เปลี่ยนรูปทรงของ Anti-pad ในระนาบกราวด์จากวงกลมขนาดใหญ่มาเป็นทรงแคปซูลไข่ (Oblong Anti-pad) และควบคุมแถบทองแดงกั้นกลาง (Copper Webbing) ให้มีความกว้างไม่ต่ำกว่า $0.15\text{ mm}$ เสมอ เพื่อการันตีว่าระนาบกราวด์จะไม่ขาดจากกัน แม้เกิดค่าความคลาดเคลื่อนสูงสุดในการผลิต

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณขีดจำกัดทางเรขาคณิตของการลากเส้นลอดช่อง BGA (Routing Channel Geometry Calculation)

**โจทย์:**  
วิศวกรต้องการออกแบบแผงวงจรสำหรับชิปประมวลผลที่มี BGA Pitch $P = 0.80\text{ mm}$ โดยมีขนาด BGA Land Pad $D_{\text{pad}} = 0.40\text{ mm}$ (โครงสร้างแบบ NSMD)  
ในการเดินสายสัญญาณชั้นนอกสุด (Layer 1) วิศวกรต้องการทราบว่า:
1. หากโรงงานผลิตมีความสามารถด้าน DFM ขั้นต่ำดังนี้:
   - ระยะห่างต่ำสุดระหว่างขอบทองแดง Pad กับเส้น Trace ($S_{\text{pad-trace}}$) = $0.10\text{ mm}$
   - ระยะห่างต่ำสุดระหว่างขอบ Trace กับ Trace ($S_{\text{trace-trace}}$) = $0.10\text{ mm}$
   - ความกว้างเส้น Trace ขั้นต่ำ ($W_{\text{min}}$) = $0.10\text{ mm}$  
   จะสามารถลากเส้นสัญญาณคู่ (Dual traces) ลอดผ่านระหว่าง BGA Pad สองตัวที่ติดกันได้หรือไม่?
2. หากจำเป็นต้องลากเส้นสัญญาณแบบ Differential Pair ความต้านทาน $100\ \Omega$ ลอดผ่านช่องนี้ โดยกำหนดให้ $W_{\text{trace}} = 0.075\text{ mm}$ และ $S_{\text{pair}} = 0.090\text{ mm}$ โรงงานจะต้องมีความสามารถในการผลิตระยะห่าง Pad-to-Trace ($S_{\text{pad-trace}}$) อย่างน้อยที่สุดเท่าใด?

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณหาความกว้างช่องสัญญาณรอดทั้งหมด (Total Channel Width):**
ระยะห่างขอบถึงขอบระหว่าง Pad ที่อยู่ติดกัน:
$$W_{\text{clear}} = P - D_{\text{pad}} = 0.80\text{ mm} - 0.40\text{ mm} = 0.40\text{ mm}\ (400\ \mu\text{m})$$

หากต้องการลากเส้นสัญญาณ 2 เส้น ($N = 2$) โดยใช้สเปกของโรงงาน ($W = 0.10\text{ mm}, S = 0.10\text{ mm}$):
พื้นที่ความกว้างขั้นต่ำทางกายภาพที่ต้องการคือ:
$$W_{\text{required}} = 2 \cdot W_{\text{trace}} + S_{\text{trace-trace}} + 2 \cdot S_{\text{pad-trace}}$$
$$W_{\text{required}} = (2 \times 0.10\text{ mm}) + 0.10\text{ mm} + (2 \times 0.10\text{ mm}) = 0.20 + 0.10 + 0.20 = 0.50\text{ mm}\ (500\ \mu\text{m})$$

เปรียบเทียบค่า:
$$W_{\text{clear}} (0.40\text{ mm}) < W_{\text{required}} (0.50\text{ mm})$$
**คำตอบส่วนที่ 1:** ไม่สามารถลากเส้นสัญญาณคู่ลอดผ่านได้ (พื้นที่ขาดไปถึง $0.10\text{ mm}$ หรือ $100\ \mu\text{m}$) สามารถลากได้เพียง **เส้นเดี่ยวเส้นเดียว (Single trace escape)** เท่านั้น ซึ่งต้องการพื้นที่:
$$W_{\text{single}} = 0.10 + (2 \times 0.10) = 0.30\text{ mm} \le 0.40\text{ mm} \quad (\text{ผ่านเกณฑ์})$$

---

**2. คำนวณหาระยะห่าง Pad-to-Trace ขั้นต่ำสำหรับคู่สาย Differential Pair:**
กำหนดให้:
- $W_{\text{trace}} = 0.075\text{ mm}$ (2 เส้น)
- $S_{\text{pair}} = 0.090\text{ mm}$ (1 ช่องว่างระหว่างคู่สาย)
- ความกว้างช่องเปิด $W_{\text{clear}} = 0.400\text{ mm}$

ตั้งสมการสมดุลทางเรขาคณิต:
$$W_{\text{clear}} = 2 \cdot W_{\text{trace}} + S_{\text{pair}} + 2 \cdot S_{\text{pad-trace}}$$
$$0.400 = (2 \times 0.075) + 0.090 + 2 \cdot S_{\text{pad-trace}}$$
$$0.400 = 0.150 + 0.090 + 2 \cdot S_{\text{pad-trace}}$$
$$0.400 = 0.240 + 2 \cdot S_{\text{pad-trace}}$$
$$2 \cdot S_{\text{pad-trace}} = 0.400 - 0.240 = 0.160\text{ mm}$$
$$S_{\text{pad-trace}} = \frac{0.160}{2} = 0.080\text{ mm}\ (80\ \mu\text{m} \approx 3.15\ \text{mil})$$

**คำตอบส่วนที่ 2:** โรงงานผลิต PCB จะต้องมีขีดความสามารถในการผลิตระดับสูง (Advanced HDI Process) ที่สามารถควบคุมระยะห่างระหว่าง Pad กับ Trace ($S_{\text{pad-trace}}$) ได้ที่ **$0.080\text{ mm}$ ($80\ \mu\text{m}$)** หรือต่ำกว่า จึงจะสามารถเดินสาย Differential Pair คู่นี้ลอดออกจาก BGA ได้อย่างปลอดภัย

</details>

### ข้อที่ 2: การประเมินจำนวนชั้นสัญญาณขั้นต่ำของชิปประมวลผลขนาดใหญ่ (BGA Layer Count Estimation)

**โจทย์:**  
ชิป SoC ประมวลผลภาพปัญญาประดิษฐ์ (Edge AI Processor) มีแพ็กเกจ BGA ทรงสี่เหลี่ยมจัตุรัสแบบสมมาตร $32 \times 32$ แถวพิน (รวม $1,024$ พิน) ระยะพิตช์ $P = 1.0\text{ mm}$  
การจัดสรรพินของตัวถังมีรายละเอียดดังนี้:
- พินจ่ายไฟหลักและกราวด์ (Power & Ground Balls): รวม $424$ พิน ซึ่งทั้งหมดกระจุกตัวอยู่บริเวณใจกลางของตัวถัง (Center Core Cavity)
- พินสัญญาณ I/O ความเร็วสูงและควบคุม (Signal Balls): รวม $600$ พิน จัดเรียงตัวอยู่รอบนอกเป็นวงแหวน (Outer Ring Perimeter) ตั้งแต่แถวที่ 1 ถึงแถวที่ 6 นับจากขอบนอกสุด
- เทคโนโลยีการผลิตกำหนดให้ใช้แผ่นวงจรมาตรฐานแบบ **Dog-bone Fanout** โดยแต่ละช่องระหว่างรูเวียชั้นใน (Inner Layer Via Channel) สามารถลากเส้นสัญญาณลอดผ่านได้เพียง **1 เส้นต่อ 1 ช่องสัญญาณเท่านั้น** ($N_{\text{trace}} = 1$)
- สัญญาณในแถวที่ 1 และแถวที่ 2 สามารถคลี่ออกที่ผิวชั้นนอก (Layer 1 / Top Layer) ได้ทั้งหมด 100%

จงคำนวณหา:
1. จำนวนพินสัญญาณที่สามารถคลี่สายออกทางผิวชั้นบน (Top Layer)
2. จำนวนพินสัญญาณคงเหลือที่ต้องเจาะเวียลงไปคลี่สายในชั้นสัญญาณภายใน (Inner Routing Layers)
3. ขีดความสามารถในการคลี่สายสูงสุดต่อ 1 ชั้นสัญญาณภายใน ($N_{\text{escape\_capacity\_per\_layer}}$)
4. จำนวนชั้นสัญญาณภายในขั้นต่ำ (Minimum Inner Signal Layers) ที่ต้องมีใน Layer Stackup

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณจำนวนพินสัญญาณในแถวที่ 1 และ 2 ที่คลี่ออกทางชั้น Top Layer:**
- ตัวถัง BGA มีขนาด $32 \times 32$ พิน
- จำนวนพินในวงรอบนอกสุด (แถวที่ 1):
  $$N_{\text{row1}} = 4 \times (32 - 1) = 124\ \text{พิน}$$
- จำนวนพินในวงรอบถัดมา (แถวที่ 2):
  ขนาดกรอบคือ $(32 - 2) \times (32 - 2) = 30 \times 30$
  $$N_{\text{row2}} = 4 \times (30 - 1) = 116\ \text{พิน}$$
- รวมพินที่คลี่ออกทาง Top Layer ได้โดยตรง:
  $$N_{\text{top\_escape}} = 124 + 116 = 240\ \text{พิน}$$

---

**2. คำนวณพินสัญญาณคงเหลือที่ต้องเจาะลงชั้นใน ($N_{\text{sig\_inner}}$):**
$$N_{\text{sig\_inner}} = N_{\text{total\_sig}} - N_{\text{top\_escape}} = 600 - 240 = 360\ \text{พิน}$$

---

**3. คำนวณขีดความสามารถในการคลี่สายของชั้นสัญญาณภายในต่อ 1 เลเยอร์:**
สัญญาณที่ลงสู่ชั้นในจะต้องวิ่งลอดผ่านช่องระหว่าง Through-hole Via ของแถวที่ 2 เพื่อทะลุออกสู่ภายนอก
- ในแต่ละด้านของสี่เหลี่ยมจัตุรัส มีจำนวนเวียในแถวขอบในคือ $30$ ตัว
- จำนวนช่องว่างระหว่างเวียต่อ 1 ด้าน:
  $$\text{Channels per side} = 30 - 1 = 29\ \text{ช่อง}$$
- มีทั้งหมด 4 ด้าน แต่ละช่องลากได้ 1 เส้น ($N_{\text{trace}} = 1$):
  $$N_{\text{escape\_capacity\_per\_layer}} = 4 \times 29 \times 1 = 116\ \text{เส้นต่อชั้น}$$

---

**4. คำนวณจำนวนชั้นสัญญาณภายในขั้นต่ำ:**
$$L_{\text{inner\_signal}} = \left\lceil \frac{N_{\text{sig\_inner}}}{N_{\text{escape\_capacity\_per\_layer}}} \right\rceil = \left\lceil \frac{360}{116} \right\rceil = \lceil 3.103 \rceil = 4\ \text{ชั้น}$$

**สรุปการวิเคราะห์สถาปัตยกรรม Stackup:**  
- ต้องการชั้นสัญญาณด้านในอย่างน้อย **4 ชั้นสัญญาณ (Inner Signal Layers)**
- เมื่อรวมกับชั้นบน (Top Layer) จะมีชั้นสัญญาณทั้งหมด $1 + 4 = 5$ ชั้นสัญญาณ
- ตามกฎสมดุลของ Stackup (Symmetry & Stripline Reference) ชั้นสัญญาณภายใน 4 ชั้นจะต้องประกบด้วยระนาบ Ground/Power เสมอ โครงสร้างที่เหมาะสมที่สุดคือ **Stackup 10 ถึง 12 ชั้น (เช่น SIG-GND-SIG-SIG-GND-PWR-GND-SIG-SIG-GND)** เพื่อให้เส้นสัญญาณความเร็วสูงทุกเส้นมีระนาบอ้างอิงประกบติดสม่ำเสมอ

</details>

### ข้อที่ 3: การวิเคราะห์ความเค้นและโหมดความล้มเหลวของ Stacked Micro-via เทียบกับ Staggered Micro-via

**โจทย์:**  
ในการผลิตแผงวงจรระบบเรดาร์ยานยนต์ (Automotive ADAS Sensor) วิศวกรต้องเลือกระหว่างสถาปัตยกรรม Micro-via 3 ชั้น (1-2, 2-3, 3-4) แบบ **Stacked Micro-via (ซ้อนทับกันตรงศูนย์)** กับ **Staggered Micro-via (เยื้องศูนย์)**  
แผงวงจรต้องผ่านการทดสอบความน่าเชื่อถือตามมาตรฐานยานยนต์ AEC-Q100 / IPC-9701 Thermal Shock Test:
- ช่วงอุณหภูมิ: $-40^\circ\text{C}$ ถึง $+125^\circ\text{C}$ ($\Delta T = 165^\circ\text{C}$)
- ค่าสัมประสิทธิ์การขยายตัวจากความร้อนของเรซินไดอิเล็กทริกแกน Z: $\alpha_{z,\text{resin}} = 55\ \text{ppm}/^\circ\text{C}$
- ค่าสัมประสิทธิ์การขยายตัวจากความร้อนของเนื้อทองแดงที่ชุบในเวีย: $\alpha_{\text{copper}} = 17\ \text{ppm}/^\circ\text{C}$
- ความหนาของชั้นไดอิเล็กทริกแต่ละชั้น: $t_{\text{layer}} = 65\ \mu\text{m}$ (ความสูงรวม 3 ชั้น $H = 195\ \mu\text{m}$)
- โมดูลัสความยืดหยุ่นของทองแดงชุบ: $E_{\text{copper}} = 110\ \text{GPa}$

จงวิเคราะห์เชิงวิศวกรรม:
1. คำนวณหาผลต่างการขยายตัวในแนวแกน Z ($\Delta L_{\text{mismatch}}$) ระหว่างแท่งทองแดง Stacked Micro-via กับเนื้อเรซินโดยรอบ เมื่ออุณหภูมิสูงขึ้น $165^\circ\text{C}$
2. อธิบายกลไกการเกิดความล้มเหลวระดับจุลภาค (Micro-scale Failure Mechanism) ที่มักเกิดขึ้นในโครงสร้าง Stacked Micro-via พร้อมระบุตำแหน่งที่เป็นจุดรวมความเค้นสูงสุด (Stress Hotspot)
3. เหตุใดมาตรฐานยานยนต์และอากาศยาน (High-Reliability Class 3) จึงมีข้อกำหนดแนะนำให้ใช้ **Staggered Micro-via** แทน Stacked Micro-via แม้จะต้องสูญเสียพื้นที่การเดินสายมากกว่า?

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณและการวิเคราะห์:**

**1. คำนวณหาผลต่างการยืดตัวในแนวแกน Z ($\Delta L_{\text{mismatch}}$):**
ความสูงรวมของแท่ง Micro-via 3 ชั้น:
$$H_0 = 3 \times 65\ \mu\text{m} = 195\ \mu\text{m}$$

การขยายตัวทางความร้อนอิสระของเนื้อเรซินไดอิเล็กทริก:
$$\Delta H_{\text{resin}} = H_0 \cdot \alpha_{z,\text{resin}} \cdot \Delta T$$
$$\Delta H_{\text{resin}} = 195\ \mu\text{m} \times (55 \times 10^{-6}\ /^\circ\text{C}) \times 165^\circ\text{C} = 1.7696\ \mu\text{m}$$

การขยายตัวทางความร้อนอิสระของแท่งทองแดงชุบ:
$$\Delta H_{\text{copper}} = H_0 \cdot \alpha_{\text{copper}} \cdot \Delta T$$
$$\Delta H_{\text{copper}} = 195\ \mu\text{m} \times (17 \times 10^{-6}\ /^\circ\text{C}) \times 165^\circ\text{C} = 0.5469\ \mu\text{m}$$

ผลต่างการขยายตัว (Mismatched Thermal Expansion):
$$\Delta L_{\text{mismatch}} = \Delta H_{\text{resin}} - \Delta H_{\text{copper}} = 1.7696\ \mu\text{m} - 0.5469\ \mu\text{m} = 1.2227\ \mu\text{m}$$

ผลลัพธ์นี้แสดงให้เห็นว่าเนื้อเรซินไดอิเล็กทริกพยายามจะยืดตัวสูงกว่าแท่งทองแดงถึง $1.22\ \mu\text{m}$ ซึ่งทำให้แท่งทองแดงตกอยู่ภายใต้ **แรงดึงมหาศาล (Severe Tensile Stress)** โดยเรซินจะดึงหัวและท้ายของโครงสร้างเวียออกจากกัน

---

**2. กลไกการเกิดความล้มเหลวระดับจุลภาคใน Stacked Micro-via:**
- **ตำแหน่ง Stress Hotspot:** จุดรวมความเค้นสูงสุดไม่ได้อยู่ที่ลำตัวของเวีย แต่อยู่ที่ **รอยต่อระนาบสัมผัส (Interface Joint)** ระหว่างก้นของ Micro-via ชั้นบน (Target Pad Interface) กับผิวด้านบนของ Micro-via ชั้นล่าง
- **โหมดความล้มเหลว (Interface Separation / Latent Open):**
  1. เนื่องจากกระบวนการผลิตเป็นแบบสะสมชั้นทีละชั้น (Sequential Build-Up) ผิวหน้าของเวียชั้นล่างจะต้องผ่านการขัดและล้างด้วยสารเคมีก่อนจะยิงเลเซอร์เจาะชั้นถัดไป หากมีเศษสิ่งสกปรกตกค้าง ฟิล์มออกไซด์บาง ๆ หรือการยึดเกาะของพันธะโลหะทองแดงไม่สมบูรณ์ พันธะระดับโมเลกุลที่รอยต่อจะอ่อนแอกว่าเนื้อทองแดงแท้ (Electrodeposited Copper Grain Boundary)
  2. เมื่อได้รับแรงดึงซ้ำ ๆ จากวงจรอุณหภูมิ (Thermal Fatigue) รอยต่อนี้จะเกิดรอยแตกร้าวระดับไมโคร (Micro-crack)
  3. **ลักษณะอาการแฝง (Latent Defect):** ที่อุณหภูมิห้อง รอยแตกอาจยังแตะกันอยู่และวัดค่าความต้านทานผ่านการทดสอบ ICT ได้ปกติ แต่เมื่ออุปกรณ์ทำงานจนร้อนขึ้น บอร์ดขยายตัว รอยแตกจะอ้าออกจากกัน ทำให้ระบบหยุดทำงานกะทันหัน (Intermittent Field Failure) ซึ่งตรวจพบได้ยากมาก

---

**3. เหตุผลที่มาตรฐาน Class 3 แนะนำให้ใช้ Staggered Micro-via:**
- **การปลดปล่อยและกระจายความเค้น (Stress Relief Buffer):** ในโครงสร้าง Staggered (เยื้องศูนย์) ก้นของ Micro-via ชั้นบนจะวางอยู่บนแผ่นทองแดงแลนด์แพดซึ่งมีเนื้อเรซินด้านข้างรองรับ การยืดตัวในแนวแกน Z จะถูกดูดซับด้วยความยืดหยุ่นของแผ่นทองแดงและเรซินที่คั่นระหว่างชั้น (Shear & Bending Compliance) แทนที่จะกลายเป็นแรงดึงตรง ๆ ในแนวดิ่ง
- **ป้องกันการแตกหักแบบต่อเนื่อง (No Catastrophic Cascade):** หากเกิดความเค้นสูง รอยต่อของ Staggered จะไม่เกิดแรงดึงแบบตั้งฉากตรงรอยต่อเหมือน Stacked ทำให้อายุการใช้งานต้านทานความล้าจากความร้อน (Thermal Fatigue Life cycles) ของ Staggered Micro-via สูงกว่า Stacked Micro-via อย่างมีนัยสำคัญ (ทนทานได้มากกว่า $3\text{ - }5$ เท่า ในการทดสอบ Thermal Shock)

</details>
