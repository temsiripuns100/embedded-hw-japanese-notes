## 1. ทฤษฎีวิศวรรรมเชิงลึก (高度なエンジニアリング理論)

เมื่อความเร็วในการส่งผ่านข้อมูลของระบบดิจิทัลก้าวเข้าสู่ยุค **PCIe Gen5/Gen6 (32 - 64 GT/s)** และ **112G/224G PAM4 SerDes** ความยาวคลื่นของสัญญาณในตัวกลาง ($\lambda$) จะหดสั้นลงเหลือเพียงระดับไม่กี่มิลลิเมตร บริเวณที่ถือเป็น **"คอขวดวิกฤตสูงสุดของความสมบูรณ์ของสัญญาณ (Signal Integrity - SI)"** ไม่ใช่เส้นทางเดินสายระนาบ Stripline ยาว ๆ บนบอร์ด แต่เป็น **"บริเวณพินบอล BGA และกลุ่มรูเวียสำหรับคลี่สาย (BGA Pin-Field & Breakout Via Field)"**

ในบริเวณนี้ โครงสร้างทางกายภาพจะเปลี่ยนจากเส้นส่งคลื่นที่มีการชีลด์สม่ำเสมอ (Uniformly Shielded Transmission Lines) กลายเป็นโครงสร้างตัวนำแนวตั้งสามมิติ (3D Vertical Conductors) ที่ล้อมรอบด้วยไดอิเล็กทริกไม่สม่ำเสมอ ก่อให้เกิดสัญญาณรบกวนข้ามช่อง (Crosstalk), การสูญเสียระนาบกระแสไหลกลับ (Return Path Discontinuity), และการสะท้อนกลับของคลื่นอย่างรุนแรง

### 1.1 แบบจำลองทางคณิตศาสตร์ของการคู่ควบในสนามพิน BGA (Pin-Field Crosstalk Modeling)

เนื่องจากพินบอล BGA และกระบอกรูเวีย (Via Barrels) วางตัวขนานกันในแนวดิ่ง จึงเกิดการคู่ควบทั้งทางสนามไฟฟ้าผ่านตัวเก็บประจุร่วม ($C_m$) และทางสนามแม่เหล็กผ่านตัวเหนี่ยวนำร่วม ($L_m$):

#### 1. ค่าสัมประสิทธิ์สัญญาณรบกวนปลายใกล้ (Near-End Crosstalk Coefficient - $K_{\text{NEXT}}$):
$$K_{\text{NEXT}} = \frac{V_{\text{NEXT}}}{V_{\text{step}}} = \frac{1}{4} \left( \frac{C_m}{C_{\text{tot}}} + \frac{L_m}{L_{\text{tot}}} \right)$$

#### 2. ค่าสัมประสิทธิ์สัญญาณรบกวนปลายไกล (Far-End Crosstalk Coefficient - $K_{\text{FEXT}}$):
$$K_{\text{FEXT}} = \frac{V_{\text{FEXT}}}{V_{\text{step}}} = \frac{1}{2} \cdot \frac{t_{\text{prop}}}{t_{\text{rise}}} \left( \frac{C_m}{C_{\text{tot}}} - \frac{L_m}{L_{\text{tot}}} \right)$$

โดยที่:
- $C_m$ = ความจุไฟฟ้าเสมือนร่วมระหว่างคู่พิน (Mutual Capacitance)
- $L_m$ = ความเหนี่ยวนำร่วมระหว่างคู่พิน (Mutual Inductance)
- $C_{\text{tot}}, L_{\text{tot}}$ = ความจุและความเหนี่ยวนำรวมต่อหน่วยความยาว
- $t_{\text{prop}}$ = เวลาหน่วงการแพร่กระจายของคลื่นผ่านบริเวณพินบอล
- $t_{\text{rise}}$ = เวลาขาขึ้นของสัญญาณกระตุ้น (Signal Rise Time)

#### ปรากฏการณ์ความไม่สมดุลในตัวกลางผสม (Inhomogeneous Dielectric FEXT):
ในระนาบ Stripline ปกติ ความเร็วคลื่นสนามไฟฟ้าและสนามแม่เหล็กจะเท่ากัน ($\frac{C_m}{C_{\text{tot}}} = \frac{L_m}{L_{\text{tot}}}$) ส่งผลให้ $K_{\text{FEXT}} \approx 0$  
**แต่ในบริเวณ BGA Pin-Field:** ตัวกลางประกอบด้วยอากาศรอบเม็ดบอล, หน้ากาก Solder Mask ($\epsilon_r \approx 3.8 - 4.2$), และเรซินแก้ว FR-4 ($\epsilon_r \approx 4.0 - 4.5$) สภาพแวดล้อมที่เป็น Inhomogeneous Dielectric ทำให้ความเร็วการแพร่กระจายไม่เท่ากัน ก่อให้เกิด **FEXT ระดับสูงมาก** ซึ่งจะพุ่งเข้าทำลายตาข่ายดวงตาสัญญาณ (Eye Diagram) ของตัวรับฝั่งตรงข้ามโดยตรง

### 1.2 สถาปัตยกรรมการจัดสรรพินคู่สายอนุพันธ์ (Differential Pinout Topologies)

| :--- | :--- | :--- | :--- | :--- |

### 1.3 ความไม่ต่อเนื่องของระนาบกระแสไหลกลับ (Return Path Discontinuity & Anti-pad Cavities)

เมื่อกลุ่มของรูเวียสัญญาณเจาะทะลุผ่านระนาบกราวด์อ้างอิงชั้นใน (Inner Reference Plane) จะต้องเปิดช่องเว้นระยะฉนวนรอบรูเจาะที่เรียกว่า **Anti-pad**:

#### 1. การเกิดร่องตัดขาดระนาบกราวด์ (Swiss-Cheese Effect & Anti-pad Overlapping):
หากระยะห่างระหว่างจุดศูนย์กลางรูเวีย ($P_{\text{via}}$) น้อยกว่าขนาดเส้นผ่านศูนย์กลางของ Anti-pad สองตัวรวมกัน ($D_{\text{anti}}$):
$$P_{\text{via}} \le D_{\text{anti}}$$
ช่อง Anti-pad จะกลืนกินซ้อนทับกัน กลายเป็น **ร่องเหวตัดขาดเนื้อทองแดง (Copper Void Slot)** ขนาดใหญ่

#### 2. ความเหนี่ยวนำวงรอบปรสิตส่วนเกิน (Excess Return Path Loop Inductance):
เมื่อระนาบกราวด์ใต้เส้นสัญญาณขาดออกจากกัน กระแสไหลย้อนกลับความถี่สูง (High-Frequency Return Current) ซึ่งไหลแนบชิดอยู่ใต้เส้นสัญญาณจะไม่สามารถกระโดดข้ามร่องได้ และถูกบังคับให้ไหลอ้อมรอบร่อง Anti-pad:
$$\Delta L_{\text{return}} \approx \frac{\mu_0}{\pi} \cdot \ln \left( \frac{2 \cdot S_{\text{detour}}}{W_{\text{trace}}} \right) \cdot d_{\text{slot}}$$

โดยที่ $S_{\text{detour}}$ คือระยะทางที่กระแสต้องไหลอ้อมออกไปด้านข้าง ความเหนี่ยวนำส่วนเกินนี้จะก่อให้เกิด:
1. **การลดลงของ Impedance ฉับพลัน:** บริเวณร่องจะเกิด Inductive Discontinuity Spike ($\Delta Z_0 \approx +15\text{ ถึง }+30\ \Omega$)
2. **สัญญาณรบกวนกระเพื่อมกราวด์ (Ground Bounce & Cavity Resonance):**
   $$V_{\text{bounce}} = \Delta L_{\text{return}} \cdot \frac{di}{dt}$$

#### 3. กฎการวางเวียกราวด์ประกบกระแสไหลกลับ (Ground Return Stitching Vias):
สำหรับคู่สายสัญญาณอนุพันธ์ทุกคู่ที่เปลี่ยนชั้นสัญญาณผ่านรูเวีย จะต้องมี **Stitching Ground Via** วางขนาบข้างคู่สายนั้นเสมอ โดยระยะห่าง $d_{\text{stitch}}$ ต้องสอดคล้องกับความถี่สูงสุดของสัญญาณ:
$$d_{\text{stitch}} \le \frac{\lambda_{\text{min}}}{10} = \frac{c}{10 \cdot f_{\text{knee}} \cdot \sqrt{\epsilon_r}}$$

โดยที่ $f_{\text{knee}} \approx \frac{0.35}{t_{\text{rise}}}$ คือความถี่หัวเข่าของสเปกตรัมสัญญาณ

### 1.4 การวิเคราะห์พารามิเตอร์การกระจายคลื่น (S-Parameter Analysis) ในรอยต่อ BGA

ความสมบูรณ์ของการส่งสัญญาณผ่านบริเวณ BGA Breakout ประเมินผ่านพารามิเตอร์ S-Parameters 4 พอร์ต (Differential Mixed-Mode S-Parameters):

```
Differential S-Parameters (dB)
  0 ──┬───────────────────────────────────────────────── Sdd21 (Insertion Loss)
      │ \
-10 ──┼──\──────────────────────────────────────────────
      │   \
-20 ──┼────\──────────────────────────────────────────── Sdd11 (Return Loss Limit: <= -15 dB)
      │     \      ▲ Via Stub Resonance Dip!
-30 ──┼──────\────/ \───────────────────────────────────
      │       └───   \
-40 ──┼───────────────────────────────────────────────── Sdd41 (FEXT Limit: <= -40 dB)
      └───┴───────┴───────┴───────┴───────┴───────┴────
          5      10      15      20      25      30   Frequency (GHz)
```

1. **$S_{\text{dd21}}$ (Differential Insertion Loss):** ต้องมีความลาดเอียงราบเรียบ ปราศจากรอยเว้าลึก (Resonant Dips) ที่ความถี่ใช้งาน
2. **$S_{\text{dd11}}$ (Differential Return Loss):** ต้องต่ำกว่า $-15\ \text{dB}$ ในช่วงแถบความถี่ใช้งาน เพื่อป้องกันการสะท้อนกลับของพลังงาน
3. **ปรากฏการณ์ติ่งเวียสะท้อนคลื่น (Via Stub Resonance):** กระบอกเวียส่วนเกินที่ไม่ได้ใช้งานด้านล่าง (Unused Via Stub ความยาว $h_{\text{stub}}$) จะทำหน้าที่เป็น Open-circuit Resonator ก่อให้เกิด Quarter-wave Resonance Notch:
   $$f_{\text{notch}} = \frac{c}{4 \cdot h_{\text{stub}} \cdot \sqrt{\epsilon_r}}$$
   หากความยาว Stub เท่ากับ $0.8\text{ mm}$ และ $\epsilon_r = 4.0$:
   $$f_{\text{notch}} = \frac{3 \times 10^8}{4 \times (0.8 \times 10^{-3}) \times 2} = \frac{3 \times 10^8}{6.4 \times 10^{-3}} \approx 46.8\ \text{GHz}$$
   ซึ่งจะทำลายฮาร์มอนิกของสัญญาณ PAM4 ในทันที จำเป็นต้องกำจัดออกด้วยกระบวนการ **Back-drilling (Controlled Depth Counter-boring)** ให้เหลือติ่งสั้นกว่า $0.15\text{ mm}$

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例 - Shippai Jirei)

**เหตุการณ์:** การพัฒนาบอร์ดสวิตช์เครือข่ายความเร็วสูงระดับดาต้าเซ็นเตอร์ (3.2 Tbps Ethernet Switch) ที่ใช้งาน ASIC ชิปตัวถัง FC-BGA ขนาด $55 \times 55\text{ mm}$ (2,500 พิน, Pitch $1.0\text{ mm}$) ซึ่งมีช่องส่งสัญญาณความเร็วสูง 100GbE (4 เลน $\times$ 25.78125 Gbps NRZ) จำนวน 32 พอร์ต:
1. ในขั้นตอนการทดสอบอัตราความผิดพลาดของบิต (Bit Error Rate Testing - BERT) พบว่าช่องสัญญาณกลุ่มพอร์ต 17 ถึง 24 มีค่า BER แย่ถึง $10^{-6}$ (ในขณะที่เกณฑ์มาตรฐานกำหนดให้ต้องดีกว่า $10^{-15}$ โดยไม่ใช้ FEC)
2. เมื่อตรวจสอบด้วย Oscilloscope ตรวจดูรูปตาสัญญาณ (Eye Diagram) พบว่าช่องเปิดตา (Eye Opening) ถูกสัญญาณรบกวนบีบจนเกือบปิดสนิท (Eye Height ลดลงเหลือเพียง $22\ \text{mV}$ จากปกติที่ต้องได้ $\ge 120\ \text{mV}$)

#### การวิเคราะห์หาสาเหตุรากเหง้า (Root Cause Analysis - RCA):
1. **การละเลยการชีลด์พินสัญญาณ (Pinout Crosstalk Vulnerability):**
   - ในการทำ Floorplan พินของชิป ASIC ทางทีมออกแบบได้จัดวางคู่สายส่งสัญญาณ ($TX1+/TX1-$) และคู่สายรับสัญญาณ ($RX1+/RX1-$) อยู่ในพินบอลที่อยู่ติดกันโดยไม่มีพินกราวด์คั่นกลาง (Pin Pattern แบบ SS-SS)
   - สัญญาณด้านส่ง (TX) มีแอมพลิจูดสูงถึง $800\ \text{mV}_{\text{p-p}}$ ในขณะที่สัญญาณด้านรับ (RX) ที่เดินทางมาจากสายเคเบิลยาวมีแอมพลิจูดอ่อนแรงเหลือเพียง $70\ \text{mV}_{\text{p-p}}$
   - การคู่ควบทางสนามแม่เหล็ก ($L_m$) และสนามไฟฟ้า ($C_m$) ระหว่างกระบอกเวีย TX และ RX ในระยะห่างเพียง $1.0\text{ mm}$ ทำให้เกิด Near-End และ Far-End Crosstalk พุ่งสูงถึง $-18\ \text{dB}$ ซึ่งสัญญาณรบกวนนี้กลืนสัญญาณอ่อนของ RX จนหมดสิ้น
2. **การซ้อนทับของ Anti-pad จนระนาบกราวด์ขาดทะลุ (Overlapping Anti-pad Perforation):**
   - รูเวียของคู่สายทั้ง 4 เลนเจาะทะลุระนาบกราวด์ชั้น L2 โดยวิศวกรกำหนดขนาด Anti-pad ทรงกลมเส้นผ่านศูนย์กลาง $1.15\text{ mm}$ ซึ่งใหญ่กว่าระยะพิตช์ $1.0\text{ mm}$
   - ส่งผลให้ Anti-pad ซ้อนทับกันต่อเนื่อง เกิดเป็น **ร่องเหวไร้ทองแดง (Continuous Slot)** กว้าง $1.15\text{ mm}$ และยาวถึง $8.5\text{ mm}$ ตัดผ่านใต้แนวพิน BGA ทั้งหมด
   - กระแสไหลกลับของสัญญาณ 25 Gbps ถูกตัดขาดและต้องอ้อมร่องนี้ ก่อให้เกิด Parasitic Loop Inductance เพิ่มขึ้นถึง $2.4\text{ nH}$ เหนี่ยวนำสัญญาณรบกวน Ground Bounce และทำลายโครงสร้างอิมพีแดนซ์จน $S_{\text{dd11}}$ เลวร้ายลงแตะ $-7\ \text{dB}$

#### มาตรการแก้ไขเชิงวิศวกรรม (Engineering Countermeasures):
1. **จัดสรรผังพินใหม่ตามโครงสร้าง G-S-S-G อย่างเคร่งครัด:**
   - ออกแบบการจัดพิน BGA ใหม่โดยกำหนดให้มีพินกราวด์ชีลด์ล้อมรอบคู่สายอนุพันธ์ทุกคู่ และคั่นกลางระหว่างคู่ TX และ RX เสมอ ควบคุมให้ระดับ FEXT ลดลงต่ำกว่า $-42\ \text{dB}$
2. **ออกแบบ Anti-pad ทรงวงรี (Oval Anti-pad) และเจาะ Stitching Vias:**
   - เปลี่ยนรูปทรง Anti-pad ให้เป็นทรงแคปซูลวงรีรวมสำหรับคู่สายอนุพันธ์ (Common Differential Oval Anti-pad) แต่รักษาระยะความกว้างเนื้อทองแดง (Copper Webbing) ระหว่างคู่สายติดกันไว้ไม่น้อยกว่า $0.15\text{ mm}$
   - ติดตั้ง Ground Stitching Vias ประกบติดกับคู่สายสัญญาณอนุพันธ์ทุกคู่ที่ระยะห่าง $0.8\text{ mm}$ เพื่อสร้างเส้นทางกระแสไหลกลับแนวดิ่งที่สมบูรณ์ทันที
3. **ทำ Back-drilling กำจัด Via Stub:** เจาะล้างติ่งเวียที่ไม่ได้ใช้งานจากด้านล่างของบอร์ด โดยจำกัดความยาวติ่งตกค้าง (Residual Stub Length) ไม่ให้เกิน $0.125\text{ mm}$ ($5\text{ mil}$)

### 3.2 ประโยคตรวจแบบที่ใช้จริงในโรงงานญี่ปุ่น (指摘事項 - Shiteki Jikō)

#### ตัวอย่างข้อคิดเห็นที่ 1: การตรวจพบการขาดพินกราวด์ชีลด์ระหว่างคู่สาย TX และ RX

#### ตัวอย่างข้อคิดเห็นที่ 2: การตรวจพบร่องขาดของระนาบกราวด์จากการซ้อนทับของ Anti-pad

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณ Crosstalk ใน BGA Pin-Field และผลของการเสริมพิน GND Shielding

**โจทย์:**  
ในการส่งสัญญาณดิจิทัลความเร็วสูง 28 Gbps NRZ ผ่านพินบอล BGA ระยะพิตช์ $1.0\text{ mm}$ สัญญาณตัวกระตุ้น (Aggressor) มีขนาดแรงดัน $V_{\text{step}} = 800\text{ mV}$ และมีเวลาขาขึ้น (Rise Time) $t_{\text{rise}} = 25\text{ ps}$ เวลาหน่วงในการเดินทางผ่านพินบอลคือ $t_{\text{prop}} = 15\text{ ps}$  
วิศวกรทำการจำลองสถานการณ์สนามแม่เหล็กไฟฟ้า 3D เพื่อเปรียบเทียบระหว่าง 2 รูปแบบการวางพิน:

- **กรณีที่ A (ไม่มีการชีลด์ - Unshielded SS Adjacent Pins):**
  - ความจุไฟฟ้ารวมของพิน: $C_{\text{tot}} = 300\ \text{fF}$
  - ความเหนี่ยวนำรวมของพิน: $L_{\text{tot}} = 0.65\ \text{nH}$
  - ความจุไฟฟ้าร่วมระหว่างพิน: $C_{m} = 45\ \text{fF}$
  - ความเหนี่ยวนำร่วมระหว่างพิน: $L_{m} = 0.14\ \text{nH}$

- **กรณีที่ B (เสริมพินชีลด์ - Shielded G-S-S-G Pattern):**
  มีพินกราวด์คั่นกลางระหว่างคู่สาย ทำให้สนามแม่เหล็กไฟฟ้าถูกดูดซับ:
  - ความจุไฟฟ้าร่วมลดลงเหลือ: $C_{m}' = 6\ \text{fF}$
  - ความเหนี่ยวนำร่วมลดลงเหลือ: $L_{m}' = 0.015\ \text{nH}$
  - (สมมุติให้ $C_{\text{tot}}$ และ $L_{\text{tot}}$ คงเดิม)

จงคำนวณหา:
1. ค่าสัมประสิทธิ์สัญญาณรบกวน $K_{\text{NEXT}}$ และ $K_{\text{FEXT}}$ ของกรณีที่ A พร้อมทั้งหาขนาดแรงดันสัญญาณรบกวนสูงสุด ($V_{\text{NEXT}}$ และ $V_{\text{FEXT}}$)
2. ค่าสัมประสิทธิ์สัญญาณรบกวน $K_{\text{NEXT}}'$ และ $K_{\text{FEXT}}'$ ของกรณีที่ B พร้อมทั้งหาขนาดแรงดันสัญญาณรบกวนสูงสุด
3. คำนวณอัตราการลดทอนสัญญาณรบกวน (Crosstalk Reduction Ratio ในหน่วย $\text{dB}$) ที่ได้รับจากการปรับเปลี่ยนมาใช้โครงสร้าง G-S-S-G

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณกรณีที่ A (Unshielded Adjacent Pins):**
อัตราส่วนความจุและความเหนี่ยวนำร่วม:
$$\frac{C_m}{C_{\text{tot}}} = \frac{45\ \text{fF}}{300\ \text{fF}} = 0.150$$
$$\frac{L_m}{L_{\text{tot}}} = \frac{0.14\ \text{nH}}{0.65\ \text{nH}} \approx 0.2154$$

- คำนวณ $K_{\text{NEXT}}$:
  $$K_{\text{NEXT}} = \frac{1}{4} \left( \frac{C_m}{C_{\text{tot}}} + \frac{L_m}{L_{\text{tot}}} \right) = \frac{1}{4} (0.150 + 0.2154) = \frac{0.3654}{4} \approx 0.09135\ (9.14\%)$$
  แรงดันรบกวนปลายใกล้:
  $$V_{\text{NEXT}} = K_{\text{NEXT}} \cdot V_{\text{step}} = 0.09135 \times 800\ \text{mV} \approx 73.08\ \text{mV}$$

- คำนวณ $K_{\text{FEXT}}$:
  $$K_{\text{FEXT}} = \frac{1}{2} \cdot \frac{t_{\text{prop}}}{t_{\text{rise}}} \left( \frac{C_m}{C_{\text{tot}}} - \frac{L_m}{L_{\text{tot}}} \right)$$
  $$K_{\text{FEXT}} = \frac{1}{2} \cdot \left( \frac{15\ \text{ps}}{25\ \text{ps}} \right) (0.150 - 0.2154) = 0.5 \times 0.60 \times (-0.0654) = -0.01962\ (-1.96\%)$$
  แรงดันรบกวนปลายไกล:
  $$|V_{\text{FEXT}}| = |K_{\text{FEXT}}| \cdot V_{\text{step}} = 0.01962 \times 800\ \text{mV} \approx 15.70\ \text{mV}$$

---

**2. คำนวณกรณีที่ B (Shielded G-S-S-G Pattern):**
อัตราส่วนใหม่:
$$\frac{C_m'}{C_{\text{tot}}} = \frac{6\ \text{fF}}{300\ \text{fF}} = 0.020$$
$$\frac{L_m'}{L_{\text{tot}}} = \frac{0.015\ \text{nH}}{0.65\ \text{nH}} \approx 0.02308$$

- คำนวณ $K_{\text{NEXT}}'$:
  $$K_{\text{NEXT}}' = \frac{1}{4} (0.020 + 0.02308) = \frac{0.04308}{4} \approx 0.01077\ (1.08\%)$$
  แรงดันรบกวนปลายใกล้ใหม่:
  $$V_{\text{NEXT}}' = 0.01077 \times 800\ \text{mV} \approx 8.62\ \text{mV}$$

- คำนวณ $K_{\text{FEXT}}'$:
  $$K_{\text{FEXT}}' = \frac{1}{2} \times 0.60 \times (0.020 - 0.02308) = 0.30 \times (-0.00308) \approx -0.000924\ (-0.0924\%)$$
  แรงดันรบกวนปลายไกลใหม่:
  $$|V_{\text{FEXT}}'| = 0.000924 \times 800\ \text{mV} \approx 0.74\ \text{mV}$$

---

**3. คำนวณอัตราการลดทอนสัญญาณรบกวน (Reduction in dB):**
- สำหรับ NEXT:
  $$\Delta \text{Crosstalk}_{\text{NEXT}} = 20 \log_{10} \left( \frac{V_{\text{NEXT}}'}{V_{\text{NEXT}}} \right) = 20 \log_{10} \left( \frac{8.62}{73.08} \right) = 20 \log_{10} (0.1180) \approx -18.56\ \text{dB}$$
- สำหรับ FEXT:
  $$\Delta \text{Crosstalk}_{\text{FEXT}} = 20 \log_{10} \left( \frac{V_{\text{FEXT}}'}{V_{\text{FEXT}}} \right) = 20 \log_{10} \left( \frac{0.74}{15.70} \right) = 20 \log_{10} (0.0471) \approx -26.53\ \text{dB}$$

**บทวิเคราะห์:** การใส่พินกราวด์ชีลด์แบบ G-S-S-G ช่วยกดสัญญาณรบกวน NEXT ลงได้ถึง **$18.56\ \text{dB}$** (แรงดันลดลงจาก $73\ \text{mV}$ เหลือ $8.6\ \text{mV}$) และกด FEXT ลงได้ถึง **$26.53\ \text{dB}$** (ลดลงเหลือไม่ถึง $1\ \text{mV}$) ซึ่งสามารถกอบกู้รูปตาสัญญาณให้เปิดกว้างผ่านมาตรฐานได้อย่างสมบูรณ์

</details>

### ข้อที่ 2: การวิเคราะห์ Inductive Ground Bounce จากร่องตัดขาด Anti-pad และการปิดตัวของ PAM4 Eye Margin

**โจทย์:**  
อินเทอร์เฟซหน่วยความจำ LPDDR5 หรือบัสความเร็วสูงมีสายสัญญาณแบบ Single-ended จำนวน 8 เส้น ($N = 8$) วิ่งขนานกันออกจาก BGA ตัวถังเดียวกัน  
สายสัญญาณแต่ละเส้นมีกระแสขับ $I = 12\ \text{mA}$ และมีเวลาสลับสัญญาณฉับพลัน (Switching Slew Time) $\Delta t = 80\ \text{ps}$  
ใต้กลุ่มพินสัญญาณนี้ รูเจาะ Anti-pad ในระนาบกราวด์เกิดการซ้อนทับกันจนตัดขาดเป็นร่องเหวยาว ทำให้กระแสไหลกลับของสัญญาณทั้ง 8 เส้นไม่สามารถไหลย้อนกลับใต้เส้นได้ และต้องอ้อมร่องทองแดงไปเป็นระยะทางเฉลี่ย $d = 3.5\text{ mm}$  
การจำลองทางฟิสิกส์ระบุว่าโครงสร้างร่องนี้สร้างค่าความเหนี่ยวนำของเส้นทางไหลกลับ (Shared Return Path Inductance) รวม $L_{\text{return}} = 1.60\ \text{nH}$

1. หากสัญญาณทั้ง 8 เส้นเกิดการสลับสถานะพร้อมกันในทิศทางเดียวกันทั้งหมด (Simultaneous Switching Noise - SSN / Worst-case SSO) จงคำนวณค่าแรงดันเหนี่ยวนำกระเพื่อมบนระนาบกราวด์ (Ground Bounce Voltage: $V_{\text{bounce}}$)
2. หากระบบทำงานด้วยสัญญาณระดับ PAM4 ที่มีระดับแรงดันเต็มสเกล $V_{\text{swing}} = 600\ \text{mV}$ ซึ่งแบ่งออกเป็น 4 ระดับ (Eye Height ทฤษฎีของแต่ละช่องตาเท่ากับ $\frac{600\ \text{mV}}{3} = 200\ \text{mV}$) จงวิเคราะห์ว่า Ground Bounce ที่เกิดขึ้นจะกินพื้นที่ตาข่ายสัญญาณ (Eye Margin Degradation) ไปคิดเป็นกี่เปอร์เซ็นต์ของความสูงตาสัญญาณ?
3. ระบุแนวทางการแก้ไขเชิงเรขาคณิตบนแผ่นวงจร PCB เพื่อลดค่า $L_{\text{return}}$ ให้เหลือต่ำกว่า $0.20\ \text{nH}$

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณ Ground Bounce Voltage ($V_{\text{bounce}}$):**
อัตราการเปลี่ยนแปลงกระแสรวมของสัญญาณทั้ง 8 เส้นที่สลับสถานะพร้อมกัน:
$$\frac{dI_{\text{total}}}{dt} = N \cdot \frac{\Delta I}{\Delta t} = 8 \times \left( \frac{12 \times 10^{-3}\ \text{A}}{80 \times 10^{-12}\ \text{s}} \right)$$
$$\frac{dI_{\text{total}}}{dt} = 8 \times (1.5 \times 10^8\ \text{A/s}) = 1.2 \times 10^9\ \text{A/s}$$

แรงดันกระเพื่อมเหนี่ยวนำบนระนาบกราวด์:
$$V_{\text{bounce}} = L_{\text{return}} \cdot \frac{dI_{\text{total}}}{dt} = (1.60 \times 10^{-9}\ \text{H}) \times (1.2 \times 10^9\ \text{A/s}) = 1.92\ \text{V}$$

---

**2. การวิเคราะห์ผลกระทบต่อ PAM4 Eye Margin:**
- สัญญาณ PAM4 มีช่วงตาสัญญาณ 3 ช่อง โดยแต่ละตามีความสูงเพียง:
  $$V_{\text{eye, ideal}} = 200\ \text{mV} = 0.200\ \text{V}$$
- เปรียบเทียบกับ Ground Bounce ที่เกิดขึ้น:
  $$V_{\text{bounce}} = 1.92\ \text{V} = 1,920\ \text{mV}$$
- สัดส่วนความเสียหาย:
  $$\% \text{Eye Closure} = \frac{1,920\ \text{mV}}{200\ \text{mV}} \times 100\% = 960\%$$
**บทวิเคราะห์ระดับ Senior:** แรงดัน Ground Bounce สูงถึง $1.92\ \text{V}$ ซึ่งสูงกว่าระดับแรงดันใช้งานของสัญญาณทั้งสเกล ($600\ \text{mV}$) ถึง $3.2$ เท่า! รูปตาสัญญาณ PAM4 ทั้ง 3 ช่องจะพังทลายลงอย่างสมบูรณ์ (Total Eye Collapse) ตัวรับสัญญาณจะไม่สามารถแยกแยะระดับแรงดันได้ เกิดข้อผิดพลาดบิตอย่างมหาศาล (Continuous Bit Errors / Link Down)

---

**3. มาตรการแก้ไขเชิงเรขาคณิตบน PCB เพื่อลด $L_{\text{return}} < 0.20\ \text{nH}$:**
1. **ออกแบบ Webbing กั้นระหว่าง Anti-pad:** ปรับลดขนาด Anti-pad จากวงกลมเดี่ยวขนาดใหญ่มาเป็นทรงแคปซูลเฉพาะจุด และรักษาระยะเนื้อทองแดงกั้นกลาง (Webbing) ไว้ไม่ต่ำกว่า $0.125\text{ mm}$ ($5\text{ mil}$) เพื่อเชื่อมต่อเนื้อทองแดงของระนาบกราวด์ไม่ให้ขาดเป็นร่อง
2. **เจาะ Ground Stitching Vias ขนาบข้าง:** เจาะรูเวียกราวด์ประกบข้างทุก ๆ 2 พินสัญญาณ เพื่อให้กระแสไหลย้อนกลับมีเส้นทางลัดในแนวดิ่งระยะสั้นที่สุด ($< 0.5\text{ mm}$)
3. **การแทรกพินกราวด์ (Ground Ball Interleaving):** ปรับผังพิน BGA โดยแทรกพิน GND 1 พินต่อสัญญาณทุก ๆ 2-3 พิน เพื่อแชร์กระแสไหลกลับและลดค่า Mutual Loop Inductance รวมลงมาสู่ช่วง $0.08 - 0.15\ \text{nH}$

</details>

### ข้อที่ 3: การคำนวณ Quarter-Wave Resonance ของติ่งเวีย (Via Stub) และการกำหนดสเปก Back-Drilling

**โจทย์:**  
บอร์ดประมวลผลเซิร์ฟเวอร์ความหนา $T_{\text{board}} = 2.40\text{ mm}$ มีเลเยอร์สแตกอัปทั้งหมด 18 ชั้น  
สัญญาณเครือข่าย 56 Gbps PAM4 (Nyquist Frequency $f_{\text{Nyquist}} = 28\text{ GHz}$) ถูกเดินสายจาก BGA Top Layer (Layer 1) มุดผ่านรู Through-hole Via ลงไปวิ่งในชั้นใน Layer 3 (ความลึกจากผิวบน $z_{\text{L3}} = 0.30\text{ mm}$)  
แผ่นบอร์ดผลิตจากวัสดุ Low-loss High-Speed Laminate ที่มีค่าคงที่ไดอิเล็กทริกยังผล $\epsilon_r = 3.61$  
หากไม่มีการทำ Back-drilling กระบอกรูเวียจาก Layer 3 ลงไปจนถึงก้นบอร์ด Layer 18 จะกลายเป็นติ่งเวียปลายเปิด (Unused Via Stub)

1. จงคำนวณหาความยาวของติ่งเวีย ($h_{\text{stub}}$)
2. คำนวณหาความถี่เรโซแนนซ์ดูดกลืนพลังงานคลื่นไตรมาส (Quarter-Wave Resonant Frequency: $f_{\text{notch}}$) ของติ่งเวียนี้ และวิเคราะห์ว่าความถี่นี้จะส่งผลกระทบต่อสัญญาณ 56 Gbps PAM4 หรือไม่
3. เพื่อป้องกันไม่ให้ Via Stub ทำลายสัญญาณ วิศวกรกำหนดให้ความถี่ Resonance ตกออกไปอยู่นอกแถบความถี่ใช้งาน โดยต้องมีค่าอย่างน้อย $f_{\text{notch}} \ge 85\text{ GHz}$ จงคำนวณหา **ความยาวติ่งเวียตกค้างสูงสุดที่ยอมรับได้ (Maximum Allowable Residual Stub Length: $h_{\text{stub, max}}$)**
4. โรงงาน PCB มีค่าความคลาดเคลื่อนของการควบคุมความลึกในการเจาะ Back-drill (Depth Tolerance) $\pm 0.075\text{ mm}$ วิศวกรจะต้องระบุเป้าหมายความลึกในการเจาะ (Nominal Drill Depth Target) บนแบบสั่งผลิตอย่างไร เพื่อให้มั่นใจว่าจะไม่เจาะโดนเส้นสัญญาณ Layer 3 ในขณะที่ไม่เหลือติ่งเกินสเปก?

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณและการวิเคราะห์:**

**1. คำนวณความยาวติ่งเวีย ($h_{\text{stub}}$):**
$$h_{\text{stub}} = T_{\text{board}} - z_{\text{L3}} = 2.40\text{ mm} - 0.30\text{ mm} = 2.10\text{ mm}\ (2.10 \times 10^{-3}\ \text{m})$$

---

**2. คำนวณความถี่ Quarter-Wave Resonance ($f_{\text{notch}}$):**
ความเร็วคลื่นแม่เหล็กไฟฟ้าในไดอิเล็กทริก:
$$v = \frac{c}{\sqrt{\epsilon_r}} = \frac{3 \times 10^8\ \text{m/s}}{\sqrt{3.61}} = \frac{3 \times 10^8}{1.9} \approx 1.5789 \times 10^8\ \text{m/s}$$

ความถี่เรโซแนนซ์คลื่นไตรมาส:
$$f_{\text{notch}} = \frac{v}{4 \cdot h_{\text{stub}}} = \frac{1.5789 \times 10^8\ \text{m/s}}{4 \times (2.10 \times 10^{-3}\ \text{m})} = \frac{1.5789 \times 10^8}{8.40 \times 10^{-3}} \approx 18.796 \times 10^9\ \text{Hz} \approx 18.80\ \text{GHz}$$

**การวิเคราะห์ผลกระทบ:**  
- สัญญาณ 56 Gbps PAM4 มีความถี่ Nyquist อยู่ที่ $28\text{ GHz}$
- ค่าความถี่เรโซแนนซ์ $f_{\text{notch}} = 18.80\text{ GHz}$ ตกอยู่ **ใจกลางแบนด์วิดท์ใช้งานหลักของสัญญาณ (In-band Resonance Notch)**
- ที่ความถี่นี้ คลื่นสัญญาณจะสะท้อนกลับแบบกลับเฟส $180^\circ$ ที่ปลายเปิดและกลับมาหักล้างสัญญาณต้นทางจนเกิดหลุมลึกในกราฟ $S_{\text{dd21}}$ (Insertion Loss Notch ลึกกว่า $-30\ \text{dB}$) ทำให้พลังงานของสัญญาณสูญหายอย่างสิ้นเชิง ลิงก์จะไม่สามารถเชื่อมต่อได้เลย

---

**3. คำนวณความยาวติ่งตกค้างสูงสุดที่ยอมรับได้ ($h_{\text{stub, max}}$) สำหรับ $f_{\text{notch}} \ge 85\text{ GHz}$:**
$$h_{\text{stub, max}} = \frac{v}{4 \cdot f_{\text{notch, min}}} = \frac{1.5789 \times 10^8\ \text{m/s}}{4 \times (85 \times 10^9\ \text{Hz})} = \frac{1.5789 \times 10^8}{3.40 \times 10^{11}} \approx 4.644 \times 10^{-4}\ \text{m} \approx 0.464\text{ mm}\ (18.3\ \text{mil})$$

และหากต้องการผลักดันให้พ้นฮาร์มอนิกที่ 3 ของสัญญาณ Nyquist ($\approx 3 \times 28 = 84\text{ GHz}$) ต้องควบคุมติ่งให้สั้นกว่า **$0.46\text{ mm}$**

---

**4. การกำหนดเป้าหมายความลึกในการเจาะ Back-drill (Nominal Depth Specification):**
กำหนดให้:
- ชั้นสัญญาณ L3 อยู่ที่ความลึก $0.300\text{ mm}$ จากผิวด้านบน หรือคิดเป็นระยะห่างจากผิวด้านล่าง (Back-drill Reference Surface):
  $$Z_{\text{trace, from\_bottom}} = 2.400 - 0.300 = 2.100\text{ mm}$$
- ความคลาดเคลื่อนของสว่าน Back-drill: $\Delta z = \pm 0.075\text{ mm}$
- **ข้อกำหนดความปลอดภัยทางวิศวกรรม:**
  1. *ห้ามเจาะทะลุถึงเนื้อ Trace L3 เด็ดขาด:* ต้องรักษาระยะความปลอดภัยขั้นต่ำ (Keep-out Clearance) $C_{\text{safe}} \ge 0.050\text{ mm}$
  2. *ติ่งตกค้างสูงสุดต้องไม่เกิน:* $h_{\text{stub, max}} \le 0.250\text{ mm}$ (สเปกความปลอดภัยสูง)

**การตั้งค่าเป้าหมายความลึกการเจาะ (Back-drill Target Depth จากผิวด้านล่าง):**
- ระยะความลึกเจาะสูงสุดที่ปลอดภัย (Deepest Limit):
  $$\text{Depth}_{\text{max}} = Z_{\text{trace, from\_bottom}} - C_{\text{safe}} = 2.100 - 0.050 = 2.050\text{ mm}$$
- ค่าความลึกเจาะเป้าหมายปกติ (Nominal Target):
  $$\text{Depth}_{\text{nominal}} = \text{Depth}_{\text{max}} - \Delta z = 2.050 - 0.075 = 1.975\text{ mm}$$
- ตรวจสอบติ่งตกค้างกรณีเจาะตื้นที่สุด (Shallowest Limit):
  $$\text{Depth}_{\text{min}} = \text{Depth}_{\text{nominal}} - \Delta z = 1.975 - 0.075 = 1.900\text{ mm}$$
  ความยาวติ่งตกค้างสูงสุดที่จะเกิดขึ้น:
  $$h_{\text{residual, worst}} = Z_{\text{trace, from\_bottom}} - \text{Depth}_{\text{min}} = 2.100 - 1.900 = 0.200\text{ mm}\ (200\ \mu\text{m})$$
  ซึ่ง $0.200\text{ mm} < 0.464\text{ mm}$ ผ่านเกณฑ์อย่างปลอดภัยสมบูรณ์

**ข้อความที่ต้องระบุบนแบบ Kenzu:**
"Back-drill from Layer 18 towards Layer 3: Target depth = $1.975\text{ mm} \pm 0.075\text{ mm}$ from bottom surface. Maximum allowable residual stub $\le 0.20\text{ mm}$. Must not violate $0.05\text{ mm}$ dielectric barrier to Layer 3 trace."

</details>
