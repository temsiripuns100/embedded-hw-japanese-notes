## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการเปลี่ยนผ่านจากการผลิตบอร์ดต้นแบบ (Prototype) ไปสู่การผลิตจำนวนมากในระดับอุตสาหกรรม (Mass Production) ความสมบูรณ์ของการออกแบบ Stackup ไม่ได้วัดกันที่การทำงานได้ในห้องทดลองเท่านั้น แต่วัดกันที่ **อัตราผลได้ของการผลิต (Yield Rate / 歩留まり - Budomari)** และ **ต้นทุนรวมต่อหน่วย (Total Unit Cost)**
วิศวกรระดับ Senior ต้องเข้าใจ **การคำนวณประสิทธิภาพการใช้พื้นที่แผงผลิต (Panel Utilization Efficiency)**, **กลศาสตร์ความเค้นจากการตัดแยกบอร์ด (Depaneling Stress & IPC-9704 Strain Limits)**, **อัตราส่วนการเปิดหน้าต่างแผ่นพิมพ์ตะกั่ว (Stencil Area Ratio)**, และ **การออกแบบขอบจับและปีกทิ้ง (Breakaway Rails / 捨て耳)**

---

### 1.1 ประสิทธิภาพการใช้พื้นที่แผงผลิต (Panel Utilization Efficiency, $\eta_{panel}$)
โรงงานผลิต PCB ไม่ได้ผลิตบอร์ดทีละชิ้น แต่ผลิตบนแผงมาตรฐานอุตสาหกรรม (Standard Production Panel) ขนาดที่นิยมที่สุดคือ:
- **$18 \times 24 \text{ นิ้ว} \ (457 \times 610 \text{ mm})$**
- **$12 \times 18 \text{ นิ้ว} \ (305 \times 457 \text{ mm})$**
- **$21 \times 24 \text{ นิ้ว} \ (533 \times 610 \text{ mm})$**

```
 ◄────────────────────── 24 นิ้ว (610 mm) ──────────────────────►
 ┌──┬────────────────────────────────────────────────────────┬──┐ ▲
 │  │ ขอบทิ้ง (Panel Margin: 15-20 mm)                       │  │ │
 ├──┼────────────────────────────────────────────────────────┼──┤ │
 │  │  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐     │  │ │
 │  │  │ PCB  │  │ PCB  │  │ PCB  │  │ PCB  │  │ PCB  │     │  │ 18 นิ้ว
 │  │  └──────┘  └──────┘  └──────┘  └──────┘  └──────┘     │  │ (457 mm)
 │  │  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐     │  │ │
 │  │  │ PCB  │  │ PCB  │  │ PCB  │  │ PCB  │  │ PCB  │     │  │ │
 │  │  └──────┘  └──────┘  └──────┘  └──────┘  └──────┘     │  │ │
 ├──┼────────────────────────────────────────────────────────┼──┤ │
 │  │ Tooling Holes, Fiducials, Plating Coupons              │  │ │
 └──┴────────────────────────────────────────────────────────┴──┘ ▼
```

- บริเวณขอบโดยรอบของ Panel ต้องเว้นพื้นที่ขอบว่าง (Margin) ไว้อย่างน้อย **$15 - 20 \text{ mm}$** สำหรับจับยึดในรางชุบ, เจาะรู Tooling Holes, วาง Fiducial Markers และคูปองทดสอบ
- ประสิทธิภาพการใช้พื้นที่แผงผลิตคำนวณได้จาก:

$$\eta_{panel} = \frac{N_{boards} \times \text{Area}_{board}}{\text{Area}_{panel}} \times 100\%$$

**เกณฑ์ความคุ้มค่าเชิงวิศวกรรม:**
- หาก $\eta_{panel} \ge 75\% - 85\%$: ถือว่าเป็นการจัดวางแบบ (Panelization Array) ที่มีประสิทธิภาพสูงสุด ต้นทุนต่อบอร์ดต่ำสุด
- หาก $\eta_{panel} < 65\%$: ถือว่าเป็นการสูญเสียพื้นที่และสร้างเศษขยะทองแดง (Scrap) สูงมาก ส่งผลให้ราคาบอร์ดต่อแผ่นแพงขึ้นโดยไม่จำเป็นถึง **$25\% - 40\%$!** วิศวกร Senior ต้องปรับขนาดขอบบอร์ด หรือจัดเรียงเป็นแบบหันหน้าชนกัน (Rotate / Interlock Nesting) เพื่อดึงค่า $\eta_{panel}$ ให้กลับขึ้นมาสูงกว่า $75\%$

### 1.2 กลศาสตร์การตัดแยกบอร์ดและความเค้นดัดงอ (Depaneling Flexural Strain per IPC-9704)
ในกระบวนการประกอบแผงวงจร (PCBA) หลังจากผ่านเตาอบ Reflow และบัดกรีอุปกรณ์เสร็จสิ้น แผงบอร์ดรวม (Array/Panel) จะต้องถูกตัดแยกออกเป็นชิ้นเดี่ยว (Depaneling) ด้วยวิธีใดวิธีหนึ่ง:
1. **การกรีดร่อง V (V-Scoring / V-Cut):** กรีดใบมีดทำมุม $30^\circ - 45^\circ$ ทั้งบนและล่าง เหลือเนื้อแกนกลาง (Web Thickness) ไว้ประมาณ $\frac{1}{3}$ ของความหนาบอร์ด
2. **การเซาะร่องและเจาะรอยปรุ (Tab Routing / Mouse Bites):** กัดร่องทะลุรอบตัวบอร์ดและยึดไว้ด้วยติ่งหู (Tabs) ที่เจาะรูพรุนขนาด $\phi 0.5 - 0.8 \text{ mm}$

**อันตรายต่อตัวเก็บประจุเซรามิก MLCC (Capacitor Cracking):**
ในระหว่างการหักหรือตัดแยกแผ่นบอร์ด แผ่นวงจรพิมพ์จะเกิดการแอ่นตัวงอชั่วขณะ ก่อให้เกิดความเครียดดัดงอ (Flexural Strain, $\epsilon$) ถ่ายทอดผ่าน Pad บัดกรีเข้าสู่ตัวถังของตัวเก็บประจุเซรามิก (MLCC)
- เซรามิกแบเรียมไททาเนต ($BaTiO_3$) มีความเปราะสูงมากและทนแรงดึงไม่ได้
- **ขีดจำกัดความเครียดตามมาตรฐาน IPC-9704:**
  $$\epsilon_{max} \le 500 \ \mu\epsilon \quad (0.05\% \text{ strain})$$
  *(หากความเครียดเกิน $700 - 1000 \ \mu\epsilon$ ตัวเก็บประจุจะเกิดรอยร้าวภายใน (Sub-surface Flex Crack) ก่อให้เกิดการลัดวงจรและไฟลุกไหม้ในภายหลัง!)*

```
     แรงกดจากการตัด ──► ▼
    ─────────────────┐   ┌─────────────────────────────── PCB
                     │   │ ◄── ร่อง V-Cut
    ─────────────────┘   └───────────────────────────────
          ▲
          │ d_keepout (ระยะห่างจากแนวตัดถึง MLCC ต้อง ≥ 3.0 - 5.0 mm!)
       ┌─────┐
       │MLCC │ ◄── หากวางชิดแนวตัด รอยดัดงอจะฉีกเนื้อเซรามิกแตกร้าว!
       └─────┘
```

### 1.3 อัตราส่วนพื้นที่หน้าต่างแผ่นพิมพ์ตะกั่ว (Stencil Area Ratio & Aspect Ratio)
ในการลงอุปกรณ์ความหนาแน่นสูง (Fine-Pitch QFN, BGA Pitch 0.4mm, 0201/01005 Passives) ข้อบกพร่องในการบัดกรีกว่า **$60\% - 70\%$** เกิดขึ้นที่ขั้นตอนการพิมพ์ Solder Paste ผ่านแผ่นโลหะมาร์ค (Stencil):

$$\text{Area Ratio (AR)} = \frac{\text{Aperture Area}}{\text{Aperture Wall Area}} = \frac{W \times L}{2 \times (W + L) \times T_{stencil}} \ge \mathbf{0.66}$$

$$\text{Aspect Ratio} = \frac{W}{T_{stencil}} \ge \mathbf{1.50}$$

- $W, L$: ความกว้างและความยาวของช่องเปิดบนแผ่น Stencil
- $T_{stencil}$: ความหนาของแผ่นฟอยล์ Stencil (เช่น $4 \text{ mil} = 100 \ \mu\text{m}$ หรือ $5 \text{ mil} = 125 \ \mu\text{m}$)

*ข้อสรุปทางฟิสิกส์การปล่อยตะกั่ว (Paste Release):*  
หากค่า $\text{AR} < 0.66$ แรงยึดติดของเนื้อตะกั่วกับผนังด้านข้างของช่อง Stencil (Wall Adhesion Force) จะชนะแรงดึงดูดของแผ่น Pad บนบอร์ด ทำให้เนื้อตะกั่วติดค้างอยู่ในรู Stencil ไม่ยอมหลุดลงมาบนบอร์ด ก่อให้เกิดข้อบกพร่อง **ตะกั่วไม่พอ (Insufficient Solder / Open Circuit)**

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** ผลิตภัณฑ์กล้องติดหน้ารถยนต์อัจฉริยะ (ADAS Camera) ล็อตผลิตจำนวน 5,000 แผง พบว่าหลังจากผ่านการตัดแยกบอร์ดด้วยเครื่องตัดแบบใบมีดกลิ้ง (Pizza-Wheel Depaneler) มีบอร์ดส่งซ่อมสูงถึง **$4.2\%$** จากอาการไฟลัดวงจรบนรางไฟ $+3.3\text{V}$ เมื่อส่งตัวเก็บประจุ MLCC 0805 ไปส่องกล้องตัดขวางพบ **รอยร้าวเฉียง 45 องศา (Flex Crack) ผ่ากลางเนื้อเซรามิก**
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. ตัวเก็บประจุ MLCC ตัวที่มีปัญหาถูกวาง **ขนานกับแนวร่อง V-Cut ในระยะห่างเพียง $0.8 \text{ mm}$!**
2. ติดตั้งเซนเซอร์ Strain Gauge วัดค่าความเครียดในจังหวะที่ใบมีดตัดร่อง V-Cut พบค่าความเครียดพุ่งสูงถึง **$1,420 \ \mu\epsilon$** (เกินขีดจำกัดปลอดภัย $500 \ \mu\epsilon$ ของ IPC-9704 ไปเกือบ 3 เท่าตัว)

---

### ขั้นตอนการออกแบบ DFM/DFA สไตล์ Senior Engineer (検図チェックリスト):
1. **กฎระยะเว้นปลอดภัยจากแนวตัดแยกบอร์ด (Depaneling Keepout Rules):**
   - **แนวร่อง V-Scoring:** ตัวเก็บประจุเซรามิก MLCC และชิป BGA ต้องอยู่ห่างจากแนวกึ่งกลางร่องตัดอย่างน้อย **$3.0 \text{ mm}$ (หากวางขนานกับแนวตัด)** หรือ **$1.5 \text{ mm}$ (หากหมุนตัวถัง 90 องศาให้ตั้งฉากกับแนวตัด)**
   - **แนวติ่งเจาะรูพรุน Mouse Bites:** อุปกรณ์ที่มีความไวต่อแรงเค้นต้องอยู่ห่างจากขอบติ่งอย่างน้อย **$5.0 \text{ mm}$**
   - หากเลี่ยงไม่ได้ ให้กำหนดให้ใช้อุปกรณ์ชนิด **Soft-Termination / Flexible-Termination (FlexiCap)** ซึ่งมีขั้วต่อชั้นเรซินนำไฟฟ้ายืดหยุ่นรองรับแรงบิด
2. **การออกแบบติ่งหัก Mouse Bites แบบร่นเข้าด้านใน (Recessed Tabs):**
   - รูปร่างของติ่ง Tab ต้องสั่งกัดร่องให้ถอยร่นเข้าไปในเนื้อบอร์ดเล็กน้อย ($0.5 \text{ mm}$ Recessed) เพื่อให้รอยฉีกขาดของเนื้อไฟเบอร์กลาส (Breakaway Burr) ซ่อนตัวอยู่ด้านใน ไม่ยื่นโผล่ออกมานอกขนาดขอบบอร์ด ซึ่งจะไปขัดขวางการประกอบลงกล่องเคสอะลูมิเนียม
3. **การออกแบบขอบจับสายพาน SMT (Conveyor Breakaway Rails):**
   - ขอบด้านยาวทั้งสองข้างของแผง Array ต้องมีขอบจับยึด (Rails) กว้างอย่างน้อย **$5.0 - 7.0 \text{ mm}$** โดยปราศจากชิ้นส่วนอุปกรณ์ใดๆ เพื่อให้สายพานเครื่องจักร SMT จับยึดได้อย่างมั่นคงโดยไม่ชนตัวถังอุปกรณ์

> *(จากการคำนวณประสิทธิภาพการใช้แผงผลิตมาตรฐาน พบว่ามี utilization เพียง 58% ซึ่งสูญเสียเนื้อที่มาก เพื่อลดต้นทุนการผลิตจำนวนมาก กรุณาปรับการจัดเรียงบอร์ดในแผงใหม่ (เช่น การหมุนสลับทิศทาง) และปรับขนาดขอบทิ้งให้ได้ utilization ไม่น้อยกว่า 75%)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Stencil Area Ratio สำหรับอุปกรณ์ Fine-Pitch)
วิศวกรใช้แผ่น Stencil สแตนเลสสตีลหนา $T = 4.0 \text{ mil} \ (101.6 \ \mu\text{m})$ สำหรับการพิมพ์ตะกั่วบัดกรีลงบน Pad ของชิป QFN ระยะ Pitch $0.4 \text{ mm}$ หากช่องเปิดของ Stencil มีความกว้าง $W = 8.0 \text{ mil} \ (203.2 \ \mu\text{m})$ และมีความยาว $L = 16.0 \text{ mil} \ (406.4 \ \mu\text{m})$ ถามว่าค่า Stencil Area Ratio (AR) มีค่าเท่าใด และผ่านเกณฑ์มาตรฐานการปล่อยตะกั่ว (Paste Release Rule $\ge 0.66$) หรือไม่?

- **ก)** $\text{AR} = 0.50$, ไม่ผ่านเกณฑ์ ตะกั่วจะติดค้างในช่อง Stencil
- **ข)** $\text{AR} \approx 0.67$, ผ่านเกณฑ์มาตรฐานขั้นต่ำ ($\ge 0.66$) พอดีเป๊ะ ตะกั่วสามารถหลุดลอกลงสู่แผ่นบอร์ดได้อย่างราบรื่น
- **ค)** $\text{AR} = 1.33$, ผ่านเกณฑ์อย่างเหลือเฟือ
- **ง)** $\text{AR} = 0.25$, ตะกั่วจะล้นทะลักออกมาลัดวงจร

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> จากสมการ Stencil Area Ratio (AR):  
> $$\text{AR} = \frac{\text{พื้นที่ช่องเปิด (Aperture Area)}}{\text{พื้นที่ผนังด้านข้าง (Wall Area)}} = \frac{W \times L}{2 \times (W + L) \times T}$$  
> คำนวณพื้นที่:  
> - พื้นที่ช่องเปิด: $W \times L = 8.0 \times 16.0 = 128.0 \ \text{mil}^2$  
> - พื้นที่ผนังด้านข้าง: $2 \times (8.0 + 16.0) \times 4.0 = 2 \times 24.0 \times 4.0 = 192.0 \ \text{mil}^2$  
> คำนวณอัตราส่วน:  
> $$\text{AR} = \frac{128.0}{192.0} \approx \mathbf{0.667}$$  
> เนื่องจากค่าที่คำนวณได้ $\text{AR} = 0.667 > 0.66$ จึงผ่านเกณฑ์มาตรฐานสากลของสมาคม IPC แสดงว่าแรงดึงดูดของผิว Pad บนบอร์ดสามารถเอาชนะแรงตึงผิวที่ผนังช่อง Stencil ได้ ตะกั่วจึงหลุดลงบนบอร์ดได้อย่างสม่ำเสมอ

### ข้อที่ 2 (กลไกการแตกร้าวของตัวเก็บประจุเซรามิก MLCC จาก Depaneling Stress)
เหตุใดการวางตัวเก็บประจุเซรามิก (MLCC) โดยให้ขั้วบัดกรีวาง **ตั้งฉาก (Perpendicular)** กับแนวร่องตัด V-Cut จึงมีความเสี่ยงต่อการแตกร้าวต่ำกว่าการวางในแนว **ขนาน (Parallel)** กับร่องตัด เมื่อแผ่นบอร์ดถูกหักแยกชิ้น?

- **ก)** เพราะการวางตั้งฉากช่วยระบายความร้อนได้เร็วกว่า
- **ข)** เมื่อบอร์ดแอ่นตัวตามแนวร่องตัด แรงดัดงอจะสร้างความเครียดเฉือนดึงรั้งระหว่างขั้วทั้งสองของตัวเก็บประจุ การวางขนานจะทำให้ขั้วหนึ่งถูกยกขึ้นขณะที่อีกขั้วถูกกดลงเกิดแรงบิดเฉือนตัวถังเซรามิกสูงสุด แต่การวางตั้งฉากจะทำให้ขั้วทั้งสองได้รับแรงโก่งตัวเท่าๆ กันในระนาบเดียว แรงเฉือนระหว่างขั้วจึงลดลงอย่างมาก
- **ค)** เพราะขั้วบัดกรีของตัวเก็บประจุทำหน้าที่เป็นแม่เหล็กดูดซับแรงกด
- **ง)** เพื่อให้เครื่องจักร Pick-and-Place วางอุปกรณ์ได้เร็วขึ้น

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในจังหวะที่ใบมีดกดตัดร่อง V-Cut แผ่นบอร์ดจะโค้งงอโดยมีแนวร่องตัดเป็นแกนการหมุน (Bending Axis)  
> หากวาง MLCC ขนานกับแนวตัด (ตามยาว) รอยต่อบัดกรีของขั้วหนึ่งจะอยู่ใกล้จุดหมุนมากกว่าอีกขั้วหนึ่ง เกิดความต่างของระยะแอ่นตัวมหาศาล ทำให้เกิดแรงบิดเฉือนดึงฉีก (Torsional Shear) ผ่ากลางเนื้อเซรามิก  
> แต่หากหมุนตัวถัง 90 องศาให้ตั้งฉากกับแนวตัด ขั้วทั้งสองจะวางตัวขนานไปกับแนวโค้ง ทำให้แรงเครียดที่กระทำต่อปลายทั้งสองมีความสมมาตรและลดความเค้นสะสมลงได้มากกว่า $50\%$

### ข้อที่ 3 (ผลกระทบของการออกแบบ Panel Utilization ต่ำต่อต้นทุนการผลิต)
หากวิศวกรออกแบบแผงรวมบอร์ด (Array) โดยมีค่า Panel Utilization ต่ำเพียง $55\%$ เทียบกับกรณีที่ปรับขนาดบอร์ดให้สามารถทำ Panel Utilization ได้สูงถึง $80\%$ บนแผงขนาด $18 \times 24 \text{ นิ้ว}$ ข้อใดอธิบายผลกระทบทางการเงินในการผลิต 100,000 ชิ้นได้ถูกต้องที่สุด?

- **ก)** ไม่มีผลกระทบใดๆ เพราะโรงงานคิดราคาตามจำนวนชิ้นงาน
- **ข)** ต้นทุนค่าแผ่นบอร์ดเปล่า (Raw Material Cost) จะแพงขึ้นกว่าเดิมประมาณ $30\% - 45\%$ เพราะพื้นที่ทองแดงและแผ่นลามิเนตเกือบครึ่งหนึ่งกลายเป็นเศษขยะทิ้งเปล่าที่ลูกค้าต้องจ่ายเงินซื้อ
- **ค)** โรงงานจะแถมบอร์ดให้ฟรีเพื่อชดเชยพื้นที่ที่เสียไป
- **ง)** บอร์ดจะมีคุณภาพความทนทานสูงขึ้นเป็นสองเท่า

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> โรงงานผลิตแผ่นวงจรพิมพ์คิดต้นทุนการผลิตหลักจาก **จำนวนแผงแม่ (Number of Production Panels)** ที่ต้องวิ่งผ่านกระบวนการชุบ เจาะ กัดกรด และอบอัด  
> หาก Panel Utilization อยู่ที่เพียง $55\%$ หมายความว่าในทุกๆ แผงที่โรงงานผลิต จะมีเนื้อบอร์ดที่มีประโยชน์เพียงครึ่งเดียว ส่วนอีก $45\%$ คือขยะที่ถูกตัดทิ้ง  
> สำหรับยอดการผลิต $100,000$ ชิ้น ความแตกต่างระหว่าง $55\%$ กับ $80\%$ Utilization คิดเป็นต้นทุนส่วนต่างค่าวัตถุดิบมหาศาลหลักแสนหรือหลักล้านบาท! วิศวกรระดับ Senior จึงต้องให้ความสำคัญกับการคำนวณ Panel Fit ตั้งแต่วันแรกที่กำหนดขนาด Outline ของบอร์ด
