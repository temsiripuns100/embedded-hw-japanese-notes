## 1. ทฤษฎีวิศวรรรมเชิงลึก (高度なエンジニアリング理論)

ในการออกแบบฮาร์ดแวร์ระดับ Senior Engineer การทำ Decoupling ไม่ได้มีเป้าหมายเพียงแค่รักษาความเสถียรของแรงดันไฟฟ้า (Signal & Power Integrity) เท่านั้น แต่มีบทบาทชี้ขาดต่อ **ความเข้ากันได้ทางแม่เหล็กไฟฟ้า (Electromagnetic Compatibility: EMC)** และการผ่านการทดสอบมาตรฐานการปล่อยคลื่นรบกวนสากล (เช่น CISPR 25 Class 5 สำหรับยานยนต์, CISPR 32 / FCC Part 15 Class B สำหรับอุปกรณ์ไอที)

โครงข่ายจ่ายไฟ (PDN) ที่มีอิมพีแดนซ์สูงหรือมีลูปการจ่ายกระแสที่กว้าง จะทำตัวเป็น **สายอากาศกระจายคลื่นแม่เหล็กไฟฟ้า (Efficient RF Antennas)** ที่ทรงพลัง โดยเปลี่ยนกระแสสลับในโหมดดิฟเฟอเรนเชียล (Differential-Mode Current) ให้กลายเป็นกระแสคอมมอนโหมด (Common-Mode Current) ที่ฉีดสัญญาณรบกวนเข้าสู่สายเคเบิลภายนอกและแผ่รังสีออกสู่อากาศ

```
+-------------------------------------------------------------------------+
|                  From PDN Noise to Radiated Emissions                   |
|                                                                         |
|  1. Gate Switching (di/dt) ──► Dynamic Voltage Droop (ΔV = L * di/dt)   |
|  2. Power Rail Ripple      ──► Drives Power Supply Induced Jitter (PSIJ)|
|  3. Return Path Gap Cross  ──► Huge Loop Area (A_loop)                  |
|  4. RF Voltage on GND/PWR  ──► Drives Attached Cables as Monopole!      |
|  5. Open Plane Edges       ──► Cavity Edge Radiation (Slot Antenna)     |
+-------------------------------------------------------------------------+
```

### 1.1 การแปลงสัญญาณรบกวนจากดิฟเฟอเรนเชียลเป็นคอมมอนโหมด (DM-to-CM Conversion)

กระแสสลับที่ไหลวนในลูปของตัวเก็บประจุ Decoupling บนแผ่น PCB เป็นกระแส Differential-Mode ($I_{DM}$) ตามสมการการแผ่รังสีสนามแม่เหล็กของลูปขนาดเล็ก ($A_{loop} \ll \lambda^2$):

$$E_{DM} \approx \frac{\mu_0 \cdot \pi \cdot f^2 \cdot I_{DM} \cdot A_{loop}}{r} \quad [\text{V/m}]$$

จะเห็นได้ว่า สนามไฟฟ้าแผ่รังสีของลูปแปรผันตาม **กำลังสองของความถี่ ($f^2$)** และ **พื้นที่ลูป ($A_{loop}$)**

อย่างไรก็ตาม กลไกการแผ่รังสีที่ร้ายแรงที่สุดและทำให้บอร์ดตกการทดสอบ EMC มากกว่า $90\%$ คือ **การแผ่รังสีคอมมอนโหมด (Common-Mode Radiation)** ซึ่งเกิดจากแรงดันตกคร่อมความเหนี่ยวนำของระนาบกราวด์ ($V_{CM} = L_{GND} \cdot \frac{di}{dt}$):

$$E_{CM} \approx \frac{\mu_0 \cdot f \cdot I_{CM} \cdot L_{cable}}{2 r} \quad [\text{V/m}]$$

ข้อเท็จจริงทางฟิสิกส์ที่น่าตกใจคือ: **กระแสคอมมอนโหมดเพียง $5 - 10\ \mu\text{A}$ บนสายเคเบิลภายนอกยาว 1 เมตร สามารถสร้างสนามไฟฟ้าที่ทำให้บอร์ดตกการทดสอบ FCC Class B ได้ทันที!** ในขณะที่กระแสดิฟเฟอเรนเชียลบนบอร์ดต้องมีขนาดหลายร้อยมิลลิแอมป์จึงจะสร้างการแผ่รังสีในระดับเดียวกัน

```
Differential-Mode Loop:               Common-Mode Cable Radiation:
    Trace (I_DM)                         PCB Ground Plane
 ───►─────────────────────┐               ═════════════════════════
                          │                 ▲ V_CM = L_gnd * di/dt
 ◄────────────────────────┘                 │
    Return Plane (-I_DM)                  ──┴── Cable Shield (I_CM ~ 10 µA!)
 (Magnetic fields cancel)                 (Monopole Antenna radiates easily!)
```

### 1.2 รอยต่อระนาบอ้างอิงขาดตอนและตัวเก็บประจุเย็บระนาบ (Return Path Discontinuities & Stitching Capacitors)

เมื่อลายสัญญาณความเร็วสูง (High-Speed Trace) วิ่งข้ามชั้นระนาบอ้างอิง (Reference Plane Transition) เช่น:
- สัญญาณวิ่งบน Layer 1 อ้างอิงระนาบ Ground ที่ Layer 2
- สัญญาณมุดรูเจาะ Via ลงไป Layer 6 ซึ่งอ้างอิงระนาบ Power ที่ Layer 5

กระแสไหลกลับความถี่สูง (High-Frequency Return Current) ซึ่งไหลแนบชิดอยู่ใต้ลายสัญญาณจะต้องกระโดดข้ามจากระนาบ Ground (L2) ไปยังระนาบ Power (L5) หากไม่มีทางเชื่อมต่อความต้านทานต่ำ กระแสไหลกลับจะถูกบังคับให้กระจายตัวออกเป็นวงกว้างเพื่อหาทางผ่านตัวเก็บประจุ Decoupling ที่อยู่ใกล้ที่สุด

ความไม่ต่อเนื่องของทางเดินกระแสไหลกลับ (Return Path Discontinuity: RPD) นี้จะ:
1. ทำลายอิมพีแดนซ์ของสายส่ง ($Z_0$ Discontinuity ก่อให้เกิด Reflection & Eye Closure)
2. ขยายพื้นที่ลูปกระแส ($A_{loop}$) ให้ใหญ่ขึ้นนับร้อยเท่า ก่อให้เกิดการแผ่รังสี EMI พุ่งสูงขึ้นทันที **$+20\text{ dB} - 35\text{ dB}$**

**โซลูชันระดับ Senior:**
ต้องติดตั้ง **Stitching Capacitor (ตัวเก็บประจุเย็บระนาบ)** ขนาด 0402 หรือ 0201 ค่า $1.0\text{ nF} - 10\text{ nF}$ (หรือใช้ขนาด $0.1\ \mu\text{F}$ Low-ESL) ประกบติดกับคู่รูเจาะสัญญาณ (ห่างไม่เกิน $0.5\text{ mm} - 0.8\text{ mm}$) เพื่อทำหน้าที่เป็นสะพานเชื่อมความต้านทานต่ำ (AC Return Bridge) ให้กระแสไหลกลับข้ามระหว่างระนาบได้อย่างราบรื่น

```
+-------------------------------------------------------------+
|  Return Path Discontinuity Mitigation:                      |
|                                                             |
|           Signal Trace Transition Via                       |
|                 │                                           |
|                 ▼                                           |
|   Layer 1 ──────( O )───────► Signal Trace                  |
|   ══════════════════════════ Layer 2 Ground Plane           |
|                 │ ◄─── d < 0.8mm                            |
|             [Stitching Cap]                                 |
|             (1nF - 10nF)                                    |
|                 │                                           |
|   ══════════════════════════ Layer 5 Power Plane            |
|                 │                                           |
|   Layer 6 ──────( O )───────► Signal Trace                  |
|                                                             |
|   AC Return current jumps smoothly through Stitching Cap!   |
+-------------------------------------------------------------+
```

### 1.3 ทฤษฎีการร่นขอบระนาบไฟ (The 20-H Rule vs Perimeter Ground Via Fence)

กฎ **20-H Rule** ถูกเสนอโดย W. Michael King โดยระบุว่า ให้ร่นขอบของระนาบ Power Plane เข้ามาจากขอบของระนาบ Ground Plane โดยรอบ เป็นระยะทาง $20$ เท่าของความหนาชั้นฉนวนระหว่างระนาบ ($d$ หรือ $h$):

$$\text{Setback Distance } (S) \ge 20 \cdot h$$

- ที่ระยะร่น $10 \cdot h$: สนามไฟฟ้าเล็ดลอด (Fringing Flux) จะลดลงประมาณ **$70\%$**
- ที่ระยะร่น $20 \cdot h$: สนามไฟฟ้าเล็ดลอดจะลดลงประมาณ **$98\%$**

```
Cross-Section of 20-H Rule:
           |<------- 20 * h Setback ------->|
           [================================] Power Plane (Inner)
           . . . . . . . . . . . . . . . . .  Dielectric (Height h)
============================================== Ground Plane (Extended)
                    \       /
             Fringing Flux loops curve down to Ground,
             preventing radiation into free space!
```

**ข้อควรระวังระดับ Senior Architect:**
งานวิจัยสมัยใหม่ (Dr. Eric Bogatin / Mark Montrose) ชี้ให้เห็นว่า แม้กฎ 20-H จะช่วยลด Fringing Field แต่การตัดขอบทองแดงจะทำให้ความถี่ Cavity Resonance ของระนาบเลื่อนตัว (Frequency Shift) และหากสัญญาณรบกวนมีความถี่สูงเกิน $1\text{ GHz}$ กฎ 20-H เพียงอย่างเดียวจะไม่เพียงพอ 

โซลูชันที่สมบูรณ์แบบที่สุดคือการ **ผสมผสาน 20-H Rule เข้ากับ Perimeter Ground Stitching Via Fence** (ร่นขอบระนาบไฟเข้ามา $1.0\text{ mm} - 1.5\text{ mm}$ และเจาะรูเจาะกราวด์รอบขอบที่พิทช์ $\le \lambda/20$) ซึ่งจะกำจัดการแผ่รังสีที่ขอบบอร์ดได้อย่างเด็ดขาด $100\%$

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน: 失敗事例 (Shippai Jirei)

**เหตุการณ์:** กล่องควบคุมกล้องมองรอบทิศทางในรถยนต์ (Automotive Surround View ECU) ใช้บอร์ด 8-Layer ประมวลผลภาพจากกล้องความละเอียดสูง 4 ช่องผ่านอินเทอร์เฟซ FPD-Link III / MIPI CSI-2 สัญญาณส่งข้อมูลความเร็ว $1.5\text{ Gbps}$ ต่อช่อง 

**อาการล้มเหลว:**
1. ในขั้นตอนการทดสอบมาตรฐานยานยนต์ **CISPR 25 Class 5 (Reverberation & ALSE Chamber Test)** บอร์ดตกการทดสอบ Radiated Emissions อย่างรุนแรงในย่านความถี่ **$375\text{ MHz}$ และ $750\text{ MHz}$** โดยมีสัญญาณรบกวนเกินขีดจำกัดมาตรฐานถึง **$+24\text{ dB}\mu\text{V/m}$**
2. บอร์ดตกการทดสอบ Conducted Emissions (Voltage Method บนชุดสายไฟแบตเตอรี่) ที่ความถี่ฮาร์โมนิกของสัญญาณนาฬิกา $125\text{ MHz}$
3. เมื่อตรวจสอบด้วยกล้องสแกนสนามแม่เหล็กไฟฟ้า (EM Scanner) พบจุดกระจายสัญญาณรบกวนรุนแรง 2 จุด:
   - จุดที่ 1: แนวกึ่งกลางบอร์ดที่มีลายสัญญาณ Differential Pair ของ MIPI CSI-2 วิ่งข้ามร่องตัดแยกของระนาบไฟ $1.8\text{ V}$ และ $3.3\text{ V}$ (Split Power Plane Crossing)
   - จุดที่ 2: ขอบบอร์ดฝั่งเชื่อมต่อกับขั้วต่อสายไฟเข้าสู่ตัวรถ (Wiring Harness Connector)

```
[Defect Mechanism: Split Plane Crossing & Harness Driving]
  MIPI Differential Pair (1.5 Gbps)
  ═════════════════════════════════════════►
  ┌──────────────────┐    Split Gap    ┌──────────────────┐
  │ L3: 1.8V Plane   │   (No Stitch!)  │ L3: 3.3V Plane   │
  └──────────────────┘                 └──────────────────┘
            │                                   │
            ▼                                   ▼
    Return current forced into huge 45mm loop around the split!
    Forms powerful magnetic dipole antenna radiating at 375 MHz!
```

**Root Cause Analysis (RCA):**
1. **การวิ่งข้ามร่องตัดโดยไม่มี Stitching Capacitor (Split Plane Violation):** 
   คู่สัญญาณ MIPI CSI-2 จำนวน 8 คู่ถูกเดินอยู่บน Layer 4 ซึ่งมีระนาบอ้างอิงด้านบนคือ Layer 3 แต่ Layer 3 ถูกซอยแบ่งเป็น 2 ระนาบ ($1.8\text{ V}$ และ $3.3\text{ V}$) โดยมีร่องผ่ากว้าง $1.0\text{ mm}$ สัญญาณวิ่งตัดข้ามร่องนี้โดยตรง กระแสไหลกลับไม่สามารถกระโดดข้ามร่องตัดได้ จึงถูกบีบให้เลี้ยวอ้อมไปตามขอบร่องตัดระยะทางกว่า $45\text{ mm}$ ก่อให้เกิดพื้นที่ลูปขนาดยักษ์ ($A_{loop} \approx 45\text{ mm} \times 12\text{ mm} = 540\text{ mm}^2$) ซึ่งทำหน้าที่เป็นสายอากาศกระจายคลื่นความถี่ $375\text{ MHz}$ (ฮาร์โมนิกของ $1.5\text{ Gbps}$) ทะลุเกณฑ์ CISPR 25 อย่างง่ายดาย
2. **การขับชุดสายไฟเป็นสายอากาศโมโนโพล (Cable Driving):** 
   ที่ขอบบอร์ดใกล้คอนเนกเตอร์ ขอบของระนาบไฟ $1.8\text{ V}$ วางเสมอกับขอบบอร์ด ($0\text{ mm}$ Setback) และไม่มีตัวเก็บประจุกรองสัญญาณรบกวนความถี่สูงที่ขาไฟของคอนเนกเตอร์ แรงดันกระเพื่อม RF จากโปรเซสเซอร์จึงรั่วไหลเข้าสู่สายไฟเลี้ยงของรถยนต์ ขับให้สายไฟรถยนต์ยาว 2 เมตรแผ่รังสีเป็นสายอากาศโมโนโพล

### Step-by-Step Engineering Checklist: กฎเหล็กการออกแบบ Decoupling เพื่อพิชิตมาตรฐาน EMC

#### ขั้นตอนที่ 1: กฎการจัดการรอยต่อระนาบและ Stitching Capacitors
- **กฎเหล็กข้อที่ 1 (Golden Rule):** พยายามออกแบบให้สัญญาณความเร็วสูงทุกเส้นอ้างอิงกับ **Solid Ground Plane ทึบแผ่นเดียวกันตลอดทั้งเส้นทาง**
- **หากหลีกเลี่ยงการวิ่งข้ามร่องตัดไม่ได้ (Cross-Split Crossing):**
  - ติดตั้งตัวเก็บประจุ **Stitching Capacitor ขนาด 0402 ค่า $1.0\text{ nF} - 10\text{ nF}$ (พิกัดแรงดัน $\ge 2 \times V_{working}$)** คร่อมข้ามร่องตัดแยกทันที
  - วางตัวเก็บประจุให้ห่างจากคู่สัญญาณไม่เกิน **$0.5\text{ mm} - 1.0\text{ mm}$** ทั้งสองฝั่งของรอยตัด
  - สำหรับคู่สัญญาณแบบ Differential Pair ให้วาง Stitching Capacitor ขนาบข้างคู่สัญญาณทั้งสองด้านอย่างสมมาตร

```
+-------------------------------------------------------------+
|  Correct Stitching Across Split Planes:                     |
|                                                             |
|           [ PWR 1 Plane ]        [ PWR 2 Plane ]            |
|                  │                      │                   |
|                  ▼                      ▼                   |
|           ┌─────────────┐        ┌─────────────┐            |
|           │ Pad (PWR 1) │─[MLCC]─│ Pad (PWR 2) │            |
|           └─────────────┘ 1-10nF └─────────────┘            |
|           ═════════════════════════════════════             |
|           ───► Signal Trace crossing gap ───►               |
|           ═════════════════════════════════════             |
|           ┌─────────────┐        ┌─────────────┐            |
|           │ Pad (PWR 1) │─[MLCC]─│ Pad (PWR 2) │            |
|           └─────────────┘ 1-10nF └─────────────┘            |
+-------------------------------------------------------------+
```

#### ขั้นตอนที่ 2: การควบคุมการแผ่รังสีที่ขอบบอร์ดด้วย 20-H และ Via Fence
- **การร่นขอบระนาบไฟ (20-H Setback Rule):**
  - ในไฟล์เค้าโครง PCB ให้กำหนดระยะร่นขอบของ Copper Pour ทุกระนาบที่เป็นรางไฟ (Power Planes) ให้หดสั้นเข้ามาจากเส้นขอบบอร์ดอย่างน้อย **$1.0\text{ mm} - 1.5\text{ mm}$**
  - ปล่อยให้ระนาบ Ground Plane ทุกชั้นขยายตัวออกไปจนชิดระยะ Margin ขอบตัดบอร์ดปกติ ($0.3\text{ mm}$)
- **การสร้าง Via Shielding Fence:**
  - วางแนวกราวด์รูเจาะ (GND Stitching Vias) เรียงเป็นแถวเดี่ยวหรือแถวคู่รอบขอบบอร์ดทั้งหมด
  - กำหนดระยะห่างระหว่างรูเจาะกึ่งกลางถึงกึ่งกลาง:
    $$s_{via} \le 1.5 - 2.0\text{ mm} \ (60 - 80\text{ mils})$$

#### ขั้นตอนที่ 3: การกรองสัญญาณรบกวนที่พินคอนเนกเตอร์ (Connector Pin Decoupling)
- **High-Frequency Connector Bypassing:** 
  ที่พินไฟเลี้ยงทุกพินบนคอนเนกเตอร์ที่ต่อออกสู่ภายนอกตัวถัง (I/O Connectors, Battery Power Input):
  - ต้องวางตัวเก็บประจุ MLCC ความเหนี่ยวนำต่ำ (เช่น 0402 ค่า $0.1\ \mu\text{F}$ หรือ Feedthrough Cap) จ่อติดกับขาคอนเนกเตอร์ในระยะ **$< 2.0\text{ mm}$**
  - เจาะรู Via กราวด์ลงสู่ระนาบกราวด์แชสซี (Chassis Ground) หรือ Digital Ground ทันที เพื่อดักจับกระแสสลับความถี่สูง (RF Ripple) ให้ไหลวนกลับลงบอร์ด ไม่ให้เล็ดลอดออกไปขับสายไฟภายนอก

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### คำถามที่ 1: การคำนวณการแผ่รังสีสนามไฟฟ้า (Radiated Emissions) จากการวิ่งข้ามร่องระนาบไฟ

ลายสัญญาณความเร็วสูงแบบ Single-ended ส่งสัญญาณสลับที่ความถี่ฮาร์โมนิกวิกฤต $f = 400\text{ MHz} = 4.0 \times 10^8\text{ Hz}$ โดยมีกระแสสัญญาณความถี่สูง $I_{rf} = 20\text{ mA} = 0.020\text{ A}$

วิศวกรเปรียบเทียบผลลัพธ์ของสนามไฟฟ้าแผ่รังสีที่ระยะวัดมาตรฐาน $r = 3.0\text{ เมตร}$ ใน 2 กรณี:
- **กรณีที่ 1 (วิ่งข้ามร่องตัดโดยไม่มี Stitching Cap):** กระแสไหลกลับต้องเลี้ยวอ้อมร่องตัด ก่อให้เกิดพื้นที่ลูปกระแสขนาดใหญ่ $A_{loop, 1} = 200\text{ mm}^2 = 2.0 \times 10^{-4}\text{ m}^2$
- **กรณีที่ 2 (ติดตั้ง Stitching Cap ติดชิดลายสัญญาณ):** ติดตั้งตัวเก็บประจุ 0402 Stitching Capacitor ระยะห่าง $0.5\text{ mm}$ ทำให้กระแสไหลกลับข้ามร่องตัดได้ทันที เหลือพื้นที่ลูปเพียง $A_{loop, 2} = 2.0\text{ mm}^2 = 2.0 \times 10^{-6}\text{ m}^2$

กำหนดสูตรประมาณการสนามไฟฟ้าการแผ่รังสีในระนาบไกล (Far-Field Radiation from Small Loop):

$$E_{max} \approx \frac{1.316 \times 10^{-14} \cdot f^2 \cdot I_{rf} \cdot A_{loop}}{r} \quad [\text{V/m}]$$

จงคำนวณ:
1. ค่าความเข้มสนามไฟฟ้าสูงสุด ($E_{max}$) ของกรณีที่ 1 และกรณีที่ 2 ในหน่วย $\mu\text{V/m}$ และ $\text{dB}\mu\text{V/m}$
2. เปรียบเทียบกับขีดจำกัดมาตรฐาน **FCC Part 15 Class B (ที่ระยะ 3 เมตร ขีดจำกัดคือ $46.0\text{ dB}\mu\text{V/m}$ ที่ความถี่ $400\text{ MHz}$)** ว่ากรณีใดผ่านและกรณีใดตก
3. สรุปอัตราส่วนการลดทอนสัญญาณรบกวน (Attenuation in dB) ที่ได้รับจากการใส่ Stitching Capacitor?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความเข้มสนามไฟฟ้า ($E_{max}$):**
- พจน์ $f^2$:
  $$f^2 = (4.0 \times 10^8\text{ Hz})^2 = 1.6 \times 10^{17}\text{ Hz}^2$$
- สัมประสิทธิ์ร่วม:
  $$C = \frac{1.316 \times 10^{-14} \cdot f^2 \cdot I_{rf}}{r} = \frac{(1.316 \times 10^{-14}) \times (1.6 \times 10^{17}) \times 0.020\text{ A}}{3.0\text{ m}} = \frac{42.112}{3.0} \approx 14.037\text{ V/m}\cdot\text{m}^{-2}$$

- **กรณีที่ 1 ($A_{loop, 1} = 2.0 \times 10^{-4}\text{ m}^2$):**
  $$E_{max, 1} = 14.037 \times (2.0 \times 10^{-4}\text{ m}^2) \approx 0.002807\text{ V/m} = 2,807\ \mu\text{V/m}$$
  แปลงเป็นหน่วย $\text{dB}\mu\text{V/m}$:
  $$E_{dB, 1} = 20 \log_{10}(2,807) \approx 20 \times 3.4482 \approx 68.96\text{ dB}\mu\text{V/m}$$

- **กรณีที่ 2 ($A_{loop, 2} = 2.0 \times 10^{-6}\text{ m}^2$):**
  $$E_{max, 2} = 14.037 \times (2.0 \times 10^{-6}\text{ m}^2) \approx 0.00002807\text{ V/m} = 28.07\ \mu\text{V/m}$$
  แปลงเป็นหน่วย $\text{dB}\mu\text{V/m}$:
  $$E_{dB, 2} = 20 \log_{10}(28.07) \approx 20 \times 1.4482 \approx 28.96\text{ dB}\mu\text{V/m}$$

**2. เปรียบเทียบกับเกณฑ์มาตรฐาน FCC Class B ($46.0\text{ dB}\mu\text{V/m}$):**
- **กรณีที่ 1:** มีสนามไฟฟ้า $68.96\text{ dB}\mu\text{V/m}$ ซึ่ง **เกินมาตรฐานอย่างรุนแรงถึง $+22.96\text{ dB}$ (ตกการทดสอบแบบสิ้นเชิง!)**
- **กรณีที่ 2:** มีสนามไฟฟ้า $28.96\text{ dB}\mu\text{V/m}$ ซึ่ง **ต่ำกว่ามาตรฐานถึง $17.04\text{ dB}$ (ผ่านการทดสอบอย่างงดงามและมี Margin ปลอดภัยสูง)**

**3. อัตราส่วนการลดทอนสัญญาณรบกวน:**
$$\text{Attenuation} = 68.96\text{ dB}\mu\text{V/m} - 28.96\text{ dB}\mu\text{V/m} = \mathbf{40.0\text{ dB}}$$
*(สัญญาณรบกวนลดลงถึง 100 เท่าในสเกลเชิงเส้น หรือ $40\text{ dB}$!)*

**บทสรุปของ Senior Engineer:**
การใส่ตัวเก็บประจุ Stitching Capacitor เพียงตัวเดียวที่มีมูลค่าไม่ถึง $0.01\text{ USD}$ สามารถลดสัญญาณรบกวน EMI ลงได้ถึง $40\text{ dB}$ และเปลี่ยนบอร์ดจากสภาวะตกมาตรฐานระดับหายนะให้กลายเป็นบอร์ดที่ผ่านการรับรองระดับสากลได้ทันที

### คำถามที่ 2: การวิเคราะห์กระแสคอมมอนโหมดที่ขับสายเคเบิลภายนอก (Cable Shield Driving)

ในระบบบอร์ดคอนโทรลเลอร์ยานยนต์ ความเหนี่ยวนำของระนาบกราวด์ระหว่างจุดกำเนิดสัญญาณรบกวนของสวิตชิ่งเรกูเลเตอร์ไปยังขั้วต่อคอนเนกเตอร์ภายนอกคือ $L_{GND} = 0.40\text{ nH}$ 

เมื่อชิปสลับโหลด กระแสกระชากในระนาบกราวด์มีความชัน $\frac{di}{dt} = 5.0\text{ A/ns} = 5.0 \times 10^9\text{ A/s}$ ส่งผลให้เกิดแรงดันกระเพื่อมคอมมอนโหมด ($V_{CM} = L_{GND} \cdot \frac{di}{dt}$) ปรากฏขึ้นที่จุดต่อกราวด์ของคอนเนกเตอร์ 

ชุดสายไฟภายนอกที่เสียบเข้ากับคอนเนกเตอร์มีความต้านทานอิมพีแดนซ์คอมมอนโหมดที่ความถี่ $150\text{ MHz}$ เท่ากับ $Z_{cable} = 180\ \Omega$

จงคำนวณ:
1. แรงดันตกคร่อมคอมมอนโหมด ($V_{CM}$) ที่เกิดขึ้นบนระนาบกราวด์
2. ขนาดของกระแสคอมมอนโหมด ($I_{CM} = \frac{V_{CM}}{Z_{cable}}$) ที่ถูกฉีดไหลเข้าสู่ชุดสายไฟภายนอก
3. สนามไฟฟ้าแผ่รังสีที่ระยะ $1.0\text{ เมตร}$ ตามมาตรฐานยานยนต์ CISPR 25 ($E_{CM} \approx \frac{\mu_0 \cdot f \cdot I_{CM}}{2 r}$) และตรวจสอบว่าจะเกินขีดจำกัดมาตรฐาน **CISPR 25 Class 5 (ที่ $150\text{ MHz}$ ขีดจำกัดคือ $28.0\text{ dB}\mu\text{V/m}$)** หรือไม่?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณแรงดันคอมมอนโหมด ($V_{CM}$):**
$$V_{CM} = L_{GND} \cdot \frac{di}{dt} = (0.40 \times 10^{-9}\text{ H}) \cdot (5.0 \times 10^9\text{ A/s}) = 2.0\text{ V}$$
*(เกิดแรงดัน Ground Bounce ถึง $2.0\text{ V}$ บนระนาบกราวด์!)*

**2. คำนวณกระแสคอมมอนโหมดบนสายไฟ ($I_{CM}$):**
$$I_{CM} = \frac{V_{CM}}{Z_{cable}} = \frac{2.0\text{ V}}{180\ \Omega} \approx 0.01111\text{ A} = 11.11\text{ mA} = 11,111\ \mu\text{A}$$

**3. คำนวณสนามไฟฟ้าแผ่รังสีที่ระยะ $r = 1.0\text{ เมตร}$ ($f = 150\text{ MHz} = 1.5 \times 10^8\text{ Hz}$):**
$$E_{CM} \approx \frac{\mu_0 \cdot f \cdot I_{CM}}{2 r} = \frac{(4\pi \times 10^{-7}\text{ H/m}) \times (1.5 \times 10^8\text{ Hz}) \times 0.01111\text{ A}}{2 \times 1.0\text{ m}}$$
$$E_{CM} \approx \frac{1.8849 \times 10^{-1} \times 0.01111}{2.0} \approx \frac{0.002094}{2.0} \approx 0.001047\text{ V/m} = 1,047\ \mu\text{V/m}$$

แปลงเป็นหน่วย $\text{dB}\mu\text{V/m}$:
$$E_{dB} = 20 \log_{10}(1,047) \approx 20 \times 3.020 \approx 60.40\text{ dB}\mu\text{V/m}$$

**4. เปรียบเทียบกับเกณฑ์ CISPR 25 Class 5 ($28.0\text{ dB}\mu\text{V/m}$):**
$$E_{margin} = 60.40 - 28.00 = +32.40\text{ dB}$$

**บทวิเคราะห์ของ Senior Engineer:**
- ระดับสัญญาณรบกวนสูงเกินมาตรฐานยานยนต์อย่างมหาศาลถึง **$+32.4\text{ dB}$ (เกินกว่าเกณฑ์กว่า 40 เท่า!)**
- นี่คือหลักฐานว่าทำไมการละเลยค่าความเหนี่ยวนำของกราวด์ ($L_{GND}$) เพียง $0.4\text{ nH}$ สามารถเปลี่ยนชุดสายไฟรถยนต์ให้กลายเป็นเครื่องส่งสัญญาณรบกวนที่ทรงพลังได้
- การแก้ไขคือการติดตั้งตัวเก็บประจุบายพาสความถี่สูงคร่อมที่พินคอนเนกเตอร์ลงสู่โครง Chassis Ground โดยตรง เพื่อบายพาสกระแส $I_{CM}$ ทิ้งตั้งแต่ต้นทาง

### คำถามที่ 3: การเปรียบเทียบประสิทธิผลการลดสนามไฟฟ้าเล็ดลอดระหว่าง 20-H Rule กับ Perimeter Stitching Via Fence

ระนาบ Power/Ground ในแผ่น PCB ความหนาฉนวน $h = 0.10\text{ mm} = 100\ \mu\text{m}$ มีแรงดันกระเพื่อมความถี่สูง $V_{rf} = 0.5\text{ V}$ ที่ความถี่ $f = 1.0\text{ GHz}$

วิศวกรเปรียบเทียบ 3 แนวทางการจัดการขอบบอร์ด:
- **แนวทาง A (Baseline):** ไม่มีการร่นขอบและไม่มี Via Fence ขอบระนาบไฟเสมอกับขอบกราวด์พอดี ($0\text{ mm}$ Setback)
- **แนวทาง B (20-H Setback Rule Only):** ร่นขอบระนาบไฟเข้ามา $S = 20 \cdot h = 20 \times 0.10\text{ mm} = 2.0\text{ mm}$ โดยไม่มี Via Fence
- **แนวทาง C (20-H Setback + Perimeter Via Fence):** ร่นขอบระนาบไฟเข้ามา $2.0\text{ mm}$ ร่วมกับเจาะรูเจาะ GND Stitching Vias ตลอดแนวขอบบอร์ดที่ระยะพิทช์ $s = 1.5\text{ mm}$

กำหนดประสิทธิภาพการลดทอนสนามไฟฟ้าเล็ดลอด (Shielding / Attenuation Effectiveness):
- แนวทาง B ให้การลดทอนของสนามไฟฟ้าเล็ดลอดสถิตที่ขอบ $\approx 14\text{ dB}$
- แนวทาง C ให้ประสิทธิภาพการปิดกั้นทางแม่เหล็กไฟฟ้า (Shielding Effectiveness: $SE$) ตามสมการรูเปิดของกรงฟาราเดย์:
  $$SE \approx 20 \log_{10}\left( \frac{\lambda}{2 s} \right) \quad [\text{dB}]$$
  โดยที่ $\lambda$ คือความยาวคลื่นในเนื้อไดอิเล็กทริก FR-4 ($\varepsilon_r = 4.0 \implies v = 1.5 \times 10^8\text{ m/s}$) ที่ความถี่ $1.0\text{ GHz}$

จงคำนวณ:
1. ความยาวคลื่นในเนื้อไดอิเล็กทริก ($\lambda_{diel}$) ที่ความถี่ $1.0\text{ GHz}$
2. ค่า Shielding Effectiveness ($SE$) ของแนวกั้น Via Fence ในแนวทาง C
3. เปรียบเทียบประสิทธิภาพรวมในการสกัดกั้น EMI ระหว่างแนวทาง B และแนวทาง C และสรุปเหตุผลว่าทำไมแนวทาง C จึงเป็นมาตรฐานบังคับสำหรับบอร์ดระดับ Mission-Critical?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความยาวคลื่น ($\lambda_{diel}$):**
$$\lambda_{diel} = \frac{v}{f} = \frac{1.5 \times 10^8\text{ m/s}}{1.0 \times 10^9\text{ Hz}} = 0.15\text{ m} = 150\text{ mm}$$

**2. คำนวณค่า Shielding Effectiveness ($SE$) ของ Via Fence (พิทช์ $s = 1.5\text{ mm}$):**
$$SE \approx 20 \log_{10}\left( \frac{\lambda_{diel}}{2 s} \right) = 20 \log_{10}\left( \frac{150\text{ mm}}{2 \times 1.5\text{ mm}} \right) = 20 \log_{10}\left( \frac{150}{3.0} \right) = 20 \log_{10}(50)$$
$$SE \approx 20 \times 1.6990 \approx 33.98\text{ dB}$$

เมื่อรวมกับการลดทอนของ 20-H Setback อีกประมาณ $14\text{ dB}$:
$$SE_{total, C} \approx 33.98\text{ dB} + 14\text{ dB} \approx 48.0\text{ dB}$$

**3. บทวิเคราะห์เชิงเปรียบเทียบ:**
- **แนวทาง B (20-H อย่างเดียว):** ลดทอนได้เพียง **$14\text{ dB}$** ซึ่งเพียงพอสำหรับบอร์ดความเร็วต่ำทั่วไป แต่สำหรับผลิตภัณฑ์ยานยนต์หรือเซิร์ฟเวอร์ที่มีพลังงานสวิตชิ่งสูง การลดทอนเพียง $14\text{ dB}$ ยังคงมีความเสี่ยงสูงที่จะตกเกณฑ์ CISPR 25
- **แนวทาง C (20-H + Via Fence):** ให้การลดทอนรวมสูงถึง **$48\text{ dB}$ (สัญญาณรบกวนลดลงกว่า 250 เท่า!)**
- แนวกั้นกราวด์รูเจาะทำหน้าที่เสมือนกำแพงโลหะปิดล้อมรอบบอร์ด สะท้อนคลื่นแม่เหล็กไฟฟ้า $1.0\text{ GHz}$ กลับเข้าสู่ภายในบอร์ด และถูกดูดซับทิ้งในเนื้อไดอิเล็กทริกผ่านค่า Loss Tangent ($\tan\delta$) ป้องกันไม่ให้คลื่นหลุดรอดออกไปรบกวนระบบภายนอกได้อย่างสมบูรณ์แบบ
