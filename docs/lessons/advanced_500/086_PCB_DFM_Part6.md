## 1. ทฤษฎีวิศวรรรมเชิงลึก (高度なエンジニアリング理論)

เมื่อความเร็วในการรับส่งข้อมูลของระบบดิจิทัลก้าวสู่พิกัดความถี่ระดับไมโครเวฟ เช่น **PCIe Gen5 (32 GT/s / $f_N = 16\text{ GHz}$)**, **PCIe Gen6 (64 GT/s / $f_N = 32\text{ GHz}$)**, และ **112G PAM4 ($f_N = 28\text{ GHz}$)** การสูญเสียสัญญาณในช่องทางส่งผ่าน (Channel Insertion Loss) และความคลาดเคลื่อนของเวลา (Jitter & Skew) ไม่ได้ถูกกำหนดด้วยความกว้างของเส้นทองแดงและค่าคงที่ไดอิเล็กทริกเฉลี่ยเพียงอย่างเดียวอีกต่อไป

วิศวกรอาวุโสต้องเจาะลึกถึงคุณสมบัติระดับจุลภาคในกระบวนการผลิต (Micro-scale Fabrication Physics):
1. **ความขรุขระของผิวฟอยล์ทองแดง (Copper Surface Roughness Profiles)** ที่ขยายผลกระทบของปรากฏการณ์สกิน (Skin Effect Conductor Loss)
2. **ความไม่สม่ำเสมอของโครงสร้างการทอผ้าใยแก้ว (Fiber-Weave Effect & Glass Skew)** ที่ทำลายเฟสของคู่สายอนุพันธ์
3. **การออกแบบและสอบเทียบแผ่นคูปองทดสอบอิมพีแดนซ์ (TDR Test Coupon Design per IPC-2141)** เพื่อให้ผลการวัดที่ขอบพาเนลสะท้อนถึงคุณภาพของแผงวงจรจริงได้อย่างแม่นยำ

### 1.1 ปรากฏการณ์สกินและความขรุขระของผิวทองแดง (Skin Effect & Copper Roughness Models)

ที่ความถี่สูง กระแสไฟฟ้ากระแสสลับจะถูกแรงดันเหนี่ยวนำย้อนกลับ (Self-induced Back EMF) บีบให้ไหลอยู่เฉพาะบริเวณพื้นผิวภายนอกของตัวนำทองแดง:

#### 1. ความลึกของกระแสสกิน (Skin Depth - $\delta$):
$$\delta = \sqrt{\frac{\rho}{\pi \cdot f \cdot \mu_0 \cdot \mu_r}}$$

โดยที่:
- $\rho$ = ความต้านทานจำเพาะของทองแดง ($1.72 \times 10^{-8}\ \Omega\cdot\text{m}$)
- $\mu_0$ = สภาพซึมซาบทางแม่เหล็กของสุญญากาศ ($4\pi \times 10^{-7}\ \text{H/m}$)
- $\mu_r$ = สภาพซึมซาบสัมพัทธ์ของทองแดง ($\mu_r = 1.0$)
- $f$ = ความถี่ของสัญญาณ ($\text{Hz}$)

**การคำนวณสเกลความลึกสกิน:**
- ที่ $f = 1\ \text{GHz}$: $\delta \approx 2.06\ \mu\text{m}$
- ที่ $f = 16\ \text{GHz}$ (PCIe Gen5): $\delta \approx 0.52\ \mu\text{m}$ ($520\ \text{nm}$)
- ที่ $f = 28\ \text{GHz}$ (112G PAM4): $\delta \approx 0.39\ \mu\text{m}$ ($390\ \text{nm}$)

#### 2. กลไกความขรุขระของผิวทองแดง (Surface Roughness Loss Factor):
เพื่อให้ฟอยล์ทองแดงสามารถยึดเกาะกับแผ่นเรซินพรีเพร็กได้อย่างเหนียวแน่น โรงงานต้องทำการกัดผิวทองแดงให้เป็นฟันปลาขรุขระ (Tooth Profile / Anchor Teething) โดยมีระดับความหยาบ $R_z$ (Peak-to-Valley Height) และ $R_q$ (RMS Roughness):
- หากความลึกสกิน ($\delta$) มีขนาด **เล็กกว่าความขรุขระของผิวทองแดง ($\delta \ll R_q$)** กระแสไฟฟ้าจะไม่สามารถวิ่งเป็นเส้นตรงได้ แต่จะต้องวิ่งเลี้ยวลดคดเคี้ยวตามแนวลาดเอียงของฟันปลาทองแดง
- ระยะทางเดินจริงของกระแส (Effective Path Length) จะเพิ่มขึ้น $2$ ถึง $3$ เท่า ก่อให้เกิดความต้านทานไฟฟ้ากระแสสลับพุ่งสูงขึ้นอย่างมหาศาล

#### 3. แบบจำลอง Cannon-Huray Snowball Model:
แบบจำลองคลาสสิกของ Hammerstad ไม่แม่นยำที่ความถี่ $> 10\text{ GHz}$ อุตสาหกรรมจึงใช้แบบจำลองของ Huray ซึ่งจำลองยอดความขรุขระเป็นทรงกลมขนาดนาโนซ้อนทับกัน:

$$K_{\text{Huray}}(f) \approx 1 + \sum_{i} \frac{3}{2} \cdot \left( \frac{N_i \cdot 4\pi a_i^2}{A_{\text{flat}}} \right) \cdot \frac{1}{1 + \frac{\delta}{a_i} + \frac{\delta^2}{2a_i^2}}$$

#### 4. การจำแนกเกรดฟอยล์ทองแดงตามมาตรฐาน IPC-4562:
- **Standard Electrodeposited (STD / ED Foil):** $R_z \approx 7.0 - 10.0\ \mu\text{m}, R_q \approx 2.0 - 3.0\ \mu\text{m}$ (ใช้ได้เฉพาะสัญญาณ $< 3\text{ GHz}$)
- **Very Low Profile (VLP Foil):** $R_z \approx 2.5 - 3.5\ \mu\text{m}, R_q \approx 0.7 - 1.0\ \mu\text{m}$ (เหมาะสำหรับ $5 - 12\text{ GHz}$)
- **Hyper Very Low Profile (HVLP / RTF-2):** $R_z \le 1.5\ \mu\text{m}, R_q \le 0.35\ \mu\text{m}$ (มาตรฐานบังคับสำหรับ PCIe Gen5/Gen6 และ 112G)
- **Rolled Annealed (RA Foil):** $R_z < 1.0\ \mu\text{m}, R_q \approx 0.15 - 0.25\ \mu\text{m}$ (ผิวเรียบที่สุด นิยมใน Flexible PCB และ RF mmWave)

### 1.2 ปรากฏการณ์ความไม่สมดุลของแนวเส้นใยแก้ว (Fiber-Weave Effect & Delay Skew)

ผ้าใยแก้ว (Woven Glass Fabric) ที่ใช้เสริมแรงในลามิเนตและพรีเพร็ก ประกอบด้วยเส้นด้ายใยแก้วถักทอประสานกับเนื้อเรซิน โดยวัสดุทั้งสองมีค่าคงที่ไดอิเล็กทริกต่างกันอย่างสิ้นเชิง:
- **มัดเส้นใยแก้ว (E-Glass Fiber Bundle):** $D_k \approx 6.0 - 6.6$
- **เรซินอีพอกซี (Epoxy Matrix):** $D_k \approx 3.0 - 3.4$

```
+-----------------------------------------------------------------------------------------+
|                  Standard Glass Fabric vs. Mechanically Spread Glass                    |
|                                                                                         |
|   [ 1. Standard 1080 Glass (Large Resin Gaps) ]  [ 2. Spread Glass 1078 (Homogeneous) ] |
|                                                                                         |
|       Glass Bundle   Resin Window Gap                Glass Yarn Spread Flat Across!     |
|       ┌──────────┐   ░░░░░░░░░░░   ┌──────────┐      ┌──────────────────────────────┐   |
|       │ Dk = 6.2 │   │Dk = 3.2 │   │ Dk = 6.2 │      │ Uniform Spread Glass: Dk=4.2 │   |
|       └──────────┘   ░░░░░░░░░░░   └──────────┘      └──────────────────────────────┘   |
|            ▲              ▲                               ▲               ▲             |
|       Trace D+ (Slow) Trace D- (Fast)                Trace D+        Trace D-           |
|       Severe Intra-Pair Skew! (10 - 20 ps)           Zero Skew Difference! (< 1.5 ps)   |
+-----------------------------------------------------------------------------------------+
```

#### 1. กลไกการเกิด Intra-Pair Differential Skew:
เมื่อคู่สายสัญญาณอนุพันธ์ความเร็วสูง ($D+/D-$) วิ่งคู่กันบนแผงวงจร:
- หากสายเส้นหนึ่ง ($D+$) วิ่งทับอยู่บนแนวสันมัดเส้นใยแก้ว ($D_{k,\text{eff}} \approx 4.2$)
- ขณะที่สายอีกเส้นหนึ่ง ($D-$) วิ่งทับลงบนช่องว่างที่มีเรซินขังอยู่ ($D_{k,\text{eff}} \approx 3.4$)
- ความเร็วในการแพร่กระจายคลื่น ($v = c / \sqrt{D_k}$) จะแตกต่างกัน:
  $$\Delta t_{\text{skew}} = \frac{L}{c} \cdot \left( \sqrt{D_{k,\text{glass}}} - \sqrt{D_{k,\text{resin}}} \right)$$
- บนระยะทางเดินสายเพียง $150\text{ mm}$ ($6\text{ นิ้ว}$) ค่า Skew สามารถสะสมได้สูงถึง **$10 - 20\text{ ps}$** ซึ่งสูงกว่า Unit Interval ทั้งคาบของสัญญาณ 112G PAM4 ($T_{\text{UI}} \approx 17.8\text{ ps}$) ส่งผลให้ดวงตาสัญญาณปิดสนิททันที

#### 2. กลยุทธ์ DFM ในการขจัดปัญหา Fiber-Weave Skew:
1. **เลือกใช้ผ้าใยแก้วชนิดกระจายตัวแบน (Mechanically Spread Glass Fabric):** สั่งใช้ผ้าใยแก้วเบอร์พิเศษ เช่น **1067, 1078, 1086, หรือ 3313** ซึ่งเส้นใยแก้วถูกบดขยี้แผ่ออกเป็นแผ่นเรียบไร้ช่องว่างเรซิน
2. **การเดินสายเอียงทำมุม (Angled / Zig-Zag Routing):** เดินคู่สายสัญญาณเอียงทำมุม **$10^\circ$ ถึง $15^\circ$** เทียบกับแนวแกน X-Y ของบอร์ด เพื่อให้ทั้งสาย $D+$ และ $D-$ วิ่งตัดผ่านมัดแก้วและแอ่งเรซินในสัดส่วนที่เท่ากันตลอดเส้นทาง
3. **การหมุนวางแผงผลิตใน CAD (Panel Rotation at $5.7^\circ$ หรือ $11.3^\circ$):** หมุนวางวงจรทั้งบอร์ดเอียงทำมุมเล็กน้อยบน Master Panel เพื่อให้การเดินสายแบบตั้งฉากปกติกลายเป็นการเดินสายเฉียงเทียบกับม้วนผ้าใยแก้วโดยอัตโนมัติ

### 1.3 วิศวกรรมแผ่นคูปองทดสอบอิมพีแดนซ์ตามมาตรฐาน IPC-2141 (TDR Coupon DFM)

ในการผลิตแผงวงจรที่มีการควบคุมอิมพีแดนซ์ (Controlled Impedance) วิศวกรไม่สามารถนำหัวโพรบ TDR ไปจิ้มวัดบนเส้นสัญญาณจริงบนบอร์ดที่ซ่อนอยู่ในชั้นในได้โดยตรง จึงต้องอาศัย **แผ่นคูปองทดสอบ (Impedance Test Coupons)** ที่วางอยู่บนรางขอบแผงผลิต (Tooling Rails):

```
+-----------------------------------------------------------------------------------------+
|                  IPC-2141 Impedance Test Coupon Architecture                            |
|                                                                                         |
|       GND Pin   Signal Pin   GND Pin (Pitch = 2.54 mm or 1.27 mm for TDR Probe)         |
|        ┌───┐      ┌───┐      ┌───┐                                                      |
|        │ O │      │ O │      │ O │   Outer Layer Pads for Coaxial Probe                 |
|        └───┘      └───┬┘     └───┘                                                      |
|                       │                                                                 |
|         Test Trace    ▼ W_coupon = W_board (Exact Match!)                               |
|        ══════════════════════════════════════════════════════════ (Length: 150 mm)      |
|         Reference Ground Plane (Exact Dielectric Height H_coupon = H_board)              |
|        ──────────────────────────────────────────────────────────                       |
+-----------------------------------------------------------------------------------------+
```

#### กฎเหล็กในการออกแบบคูปองทดสอบ:
1. **ความยาวเส้นคูปองขั้นต่ำ (Minimum Trace Length):** ต้องมีความยาวไม่น้อยกว่า **$150\text{ mm}$ ($6\text{ นิ้ว}$)** เพื่อให้สัญญาณ TDR Pulse ($t_{\text{rise}} \approx 35 - 50\text{ ps}$) มีช่วงเวลาเดินทางนานพอที่จะแยกแยะความต้านทานที่แท้จริงออกจากสัญญาณสะท้อนที่หัวโพรบ (Probe Inductive Discontinuity Spike)
2. **การจำลองโครงสร้างแบบ $1 : 1$ (Cross-sectional Identity):** ความกว้างเส้น, สแตกอัปความหนาฉนวน, ชนิดของพรีเพร็ก, และการเปิดระนาบอ้างอิงของคูปอง **ต้องตรงกับเส้นสัญญาณจริงบนบอร์ดทุกประการ**
3. **การควบคุม Copper Balance รอบคูปอง:** ห้ามล้อมกรอบคูปองด้วยแผ่นทองแดงทึบขนาดใหญ่ หากบนบอร์ดจริงเป็นลายวงจรเบาบาง เพราะจะทำให้น้ำยาชุบและเรซินไหลเข้าสู่คูปองต่างจากตัวบอร์ดจริง เกิดความคลาดเคลื่อนในการวัด (Gauge R&R Error)

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例 - Shippai Jirei)

**เหตุการณ์:** การพัฒนาการ์ดเร่งความเร็วประมวลผลเซิร์ฟเวอร์ PCIe Gen5 AIC (32 GT/s Add-in Card, บอร์ด 16 ชั้น ผลิตจากวัสดุ Low-Loss High-Speed Laminate):
1. ในขั้นตอนการทดสอบความสอดคล้องตามมาตรฐาน (PCI-SIG Compliance Test) ที่ความถี่ $16\text{ GHz}$ พบว่าการ์ดสอบตกการวัด Insertion Loss อย่างสิ้นเชิง โดยช่องสัญญาณ PCIe Lane 0 ถึง Lane 15 มีค่าการสูญเสียสัญญาณสูงถึง **$-32.5\text{ dB}$** (เกณฑ์ขีดจำกัดสูงสุดของสเปกยอมรับได้ไม่เกิน **$-28.0\text{ dB}$**) ส่งผลให้การเชื่อมต่อดาวน์เกรดร่วงลงสู่ PCIe Gen4 (16 GT/s)
2. ที่น่าประหลาดใจคือ: **รายงานผลการวัด TDR Coupon บนขอบพาเนลจากโรงงาน Fab House ระบุว่าค่าอิมพีแดนซ์ผ่านเกณฑ์ $85.0\ \Omega \pm 8\%$ ทุกประการ!** แต่ทำไมช่องสัญญาณจริงบนบอร์ดถึงสอบตก?

```
+-----------------------------------------------------------------------------------------+
|                  RCA: Standard ED Copper Foil & Fiber-Weave Skew Disaster               |
|                                                                                         |
|   [ ปัญหาที่ 1: โรงงานแอบใช้ทองแดง Standard ED ] [ ปัญหาที่ 2: Fiber Weave Skew ]       |
|                                                                                         |
|       Nominal Spec: HVLP Foil (R_z <= 1.5 μm)        Standard 1080 Glass Weave          |
|       Fab Substituted: Standard ED (R_z = 8.5 μm)    PCIe Differential Pair (180 mm)    |
|       Skin Depth at 16 GHz: delta = 0.52 μm!         Lane 4: D+ on Glass, D- on Resin   |
|       Current detours through massive peaks!         Accumulated Delay Skew = 8.4 ps!   |
|       Conductor Loss jumped by +4.8 dB!              Eye Height collapsed from          |
|       (Channel Loss: -32.5 dB -> Fails PCI-SIG!)     55 mV to ZERO (Eye Closed!)        |
+-----------------------------------------------------------------------------------------+
```

#### การวิเคราะห์หาสาเหตุรากเหง้า (Root Cause Analysis - RCA):
1. **สาเหตุของการสูญเสียสัญญาณเกินพิกัด (Standard ED Copper Substitution):**
   - ในแบบสั่งผลิต (Master Drawing) วิศวกรระบุเพียงชนิดวัสดุแกนหลัก (Megtron 6) แต่ **ไม่ได้ระบุเกรดความขรุขระของฟอยล์ทองแดง (Copper Foil Profile)** กำกับไว้อย่างชัดเจน
   - โรงงาน Fab House จึงเลือกใช้ฟอยล์ทองแดงมาตรฐานราคาถูก (Standard Electrodeposited - STD Foil) ซึ่งมีค่าความขรุขระสูงถึง $R_z = 8.5\ \mu\text{m}$ ($R_q \approx 2.6\ \mu\text{m}$)
   - ที่ความถี่ $16\text{ GHz}$ ความลึกสกินบางเพียง $\delta = 0.52\ \mu\text{m}$ อัตราส่วนความขรุขระ $R_q / \delta \approx 5.0$ ทำให้กระแสไฟฟ้าต้องไหลอ้อมตะปุ่มตะป่ำ ส่งผลให้ Conductor Attenuation เพิ่มสูงขึ้นถึง **$+4.8\text{ dB}$** เกินงบประมาณการสูญเสียของช่องสัญญาณทันที
   - เหตุผลที่คูปอง TDR วัดผ่าน: เพราะเครื่อง TDR วัดเฉพาะค่าอิมพีแดนซ์คุณลักษณะ $Z_0$ ที่ความถี่ต่ำ ไม่สามารถวัดการสูญเสียพลังงานจากความขรุขระที่ $16\text{ GHz}$ ได้
2. **สาเหตุของรูปตาสัญญาณปิดสนิท (Fiber-Weave Skew on 1080 Glass):**
   - สแตกอัปของบอร์ดใช้พรีเพร็กเบอร์ 1080 แบบดั้งเดิม และวิศวกรเดินคู่สาย PCIe ในแนวแกนขนานตรง $0^\circ$ กับขอบบอร์ด
   - บนระยะทางเดินสาย $180\text{ mm}$ ความแตกต่างของ $D_k$ ระหว่างแนวเส้นใยแก้วและแอ่งเรซินทำให้เกิด Intra-pair Delay Skew สูงถึง **$8.4\text{ ps}$** (คิดเป็นกว่า $27\%$ ของ Unit Interval ที่ $31.25\text{ ps}$)
   - การแปลงสัญญาณเป็นโหมดร่วม ($S_{\text{cd21}}$) ทำลายดวงตาสัญญาณจนปิดสนิท

#### มาตรการแก้ไขเชิงวิศวกรรม (Engineering Countermeasures):
1. **ล็อกสเปกฟอยล์ทองแดงเป็น HVLP-2 บนแบบสั่งผลิต:**
   - แก้ไขข้อกำหนดใน Fabrication Drawing: บังคับใช้ฟอยล์ทองแดงเกรด **HVLP-2 (Hyper Very Low Profile) หรือ RTF-2 ที่มีค่าความขรุขระ $R_z \le 1.5\ \mu\text{m}$ และ $R_q \le 0.35\ \mu\text{m}$** เท่านั้น
   - การเปลี่ยนมาใช้ HVLP ช่วยลดค่า Conductor Loss ลงได้ถึง **$4.2\text{ dB}$** ทำให้ Insertion Loss รวมกลับคืนสู่ระดับ **$-27.3\text{ dB}$** (ผ่านเกณฑ์ PCI-SIG ทันที)
2. **เปลี่ยนวัสดุเป็น Spread Glass 1078 ร่วมกับการเดินสายเอียง $10^\circ$:**
   - สั่งเปลี่ยนชนิดพรีเพร็กเป็นผ้าใยแก้วกระจายตัวแบน (Spread Glass 1078)
   - ปรับการเดินคู่สายสัญญาณ PCIe ทุกเลนให้เดินเอียงทำมุม $10^\circ$ (Angled Routing)
   - ลดค่า Intra-pair Skew ลงเหลือเพียง **$0.9\text{ ps}$** คืนค่าความสูงของรูปตาสัญญาณ (Eye Height) กลับมาเปิดกว้างถึง $48\text{ mV}$ ผ่านการทดสอบ Compliance ได้อย่างสมบูรณ์

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณ Skin Depth และตัวคูณการสูญเสียจากความขรุขระผิวทองแดง (Huray Roughness Loss Factor)

**โจทย์:**  
ช่องสัญญาณความเร็วสูง PCIe Gen5 ทำงานที่ความถี่ Nyquist $f = 16.0\text{ GHz}$ ($16 \times 10^9\ \text{Hz}$)  
แผ่นทองแดงนำไฟฟ้ามีความต้านทานจำเพาะ $\rho = 1.72 \times 10^{-8}\ \Omega\cdot\text{m}$ และมีสภาพซึมซาบทางแม่เหล็ก $\mu = \mu_0 = 4\pi \times 10^{-7}\ \text{H/m}$  
วิศวกรต้องการเปรียบเทียบระหว่างฟอยล์ทองแดง 2 ชนิด:
- **ฟอยล์ชนิดที่ 1 (Standard ED Foil):** มีค่าความขรุขระระดับรากที่สองเฉลี่ย $R_{q, 1} = 2.60\ \mu\text{m}$ ($2,600\ \text{nm}$)
- **ฟอยล์ชนิดที่ 2 (HVLP Foil):** มีค่าความขรุขระระดับรากที่สองเฉลี่ย $R_{q, 2} = 0.35\ \mu\text{m}$ ($350\ \text{nm}$)

1. จงคำนวณหาความลึกของกระแสสกิน ($\delta$) ของทองแดงที่ความถี่ $16.0\text{ GHz}$ ในหน่วยไมครอน ($\mu\text{m}$) และนาโนเมตร ($\text{nm}$)
2. จากแบบจำลองการสูญเสียความขรุขระพื้นฐานของ Hammerstad-Bekkadal ตัวคูณการเพิ่มขึ้นของความต้านทานไฟฟ้ากระแสสลับเนื่องจากความขรุขระ ($K_{\text{SR}}$) คำนวณได้จาก:
   $$K_{\text{SR}} = 1 + \frac{2}{\pi} \cdot \arctan\left[ 1.4 \cdot \left( \frac{R_q}{\delta} \right)^2 \right]$$
   จงคำนวณหาค่า $K_{\text{SR, 1}}$ (สำหรับ Standard ED) และ $K_{\text{SR, 2}}$ (สำหรับ HVLP)
3. หากเส้นส่งสัญญาณไมโครสตริปในสภาวะผิวเรียบในอุดมคติมีการสูญเสียในตัวนำ $\alpha_{\text{c, smooth}} = 3.50\ \text{dB/m}$  
   จงคำนวณหาค่าการสูญเสียในตัวนำจริง ($\alpha_{\text{c, actual}} = \alpha_{\text{c, smooth}} \cdot K_{\text{SR}}$) ของฟอยล์ทั้งสองชนิดบนความยาวช่องทางเดินสาย $L = 0.40\text{ m}$ ($40\text{ cm}$) และเปรียบเทียบผลต่างการลดทอนสัญญาณในหน่วย $\text{dB}$

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณหาความลึกของกระแสสกิน ($\delta$):**
$$\delta = \sqrt{\frac{\rho}{\pi \cdot f \cdot \mu_0}} = \sqrt{\frac{1.72 \times 10^{-8}}{\pi \times (16.0 \times 10^9) \times (4\pi \times 10^{-7})}}$$
คำนวณตัวหาร:
$$\pi \times (16 \times 10^9) \times (4\pi \times 10^{-7}) = 64\pi^2 \times 10^2 \approx 64 \times 9.8696 \times 100 \approx 63,165.46$$
หารค่าความต้านทาน:
$$\frac{1.72 \times 10^{-8}}{63,165.46} \approx 2.723 \times 10^{-13}$$
ถอดรากที่สอง:
$$\delta = \sqrt{2.723 \times 10^{-13}} \approx 5.218 \times 10^{-7}\ \text{m} \approx 0.522\ \mu\text{m}\ (522\ \text{nm})$$
**คำตอบส่วนที่ 1:** ความลึกสกินมีค่าเพียง **$0.522\ \mu\text{m}$ ($522\ \text{nm}$)**

---

**2. คำนวณหาตัวคูณการสูญเสียจากความขรุขระ ($K_{\text{SR}}$):**

- **สำหรับฟอยล์ชนิดที่ 1 (Standard ED, $R_{q, 1} = 2.60\ \mu\text{m}$):**
  $$\frac{R_{q, 1}}{\delta} = \frac{2.60\ \mu\text{m}}{0.522\ \mu\text{m}} \approx 4.981$$
  $$\left(\frac{R_{q, 1}}{\delta}\right)^2 = (4.981)^2 \approx 24.81$$
  พจน์อาร์กแทนเจนต์:
  $$1.4 \times 24.81 \approx 34.73$$
  $$\arctan(34.73) \approx 1.5420\ \text{เรเดียน}\ (\text{เข้าใกล้ขีดจำกัดสูงสุด } \frac{\pi}{2} \approx 1.5708)$$
  คำนวณ $K_{\text{SR, 1}}$:
  $$K_{\text{SR, 1}} = 1 + \frac{2}{\pi} \times 1.5420 \approx 1 + 0.9817 \approx 1.982$$
  *(ค่าความต้านทานพุ่งขึ้นเกือบ 2 เท่าตามแบบจำลองคลาสสิก และหากใช้ Huray Model ค่าตัวคูณจะพุ่งสูงถึง $2.4 - 2.8$ เท่า)*

- **สำหรับฟอยล์ชนิดที่ 2 (HVLP, $R_{q, 2} = 0.35\ \mu\text{m}$):**
  $$\frac{R_{q, 2}}{\delta} = \frac{0.35\ \mu\text{m}}{0.522\ \mu\text{m}} \approx 0.6705$$
  $$\left(\frac{R_{q, 2}}{\delta}\right)^2 = (0.6705)^2 \approx 0.4496$$
  พจน์อาร์กแทนเจนต์:
  $$1.4 \times 0.4496 \approx 0.6294$$
  $$\arctan(0.6294) \approx 0.5615\ \text{เรเดียน}$$
  คำนวณ $K_{\text{SR, 2}}$:
  $$K_{\text{SR, 2}} = 1 + \frac{2}{\pi} \times 0.5615 \approx 1 + 0.3575 \approx 1.357$$

---

**3. คำนวณการสูญเสียในตัวนำจริงบนระยะทาง $0.40\text{ m}$:**
กำหนดให้ $\alpha_{\text{c, smooth}} = 3.50\ \text{dB/m}$:
- **สำหรับ Standard ED:**
  $$\alpha_{\text{c, 1}} = 3.50\ \text{dB/m} \times 1.982 = 6.937\ \text{dB/m}$$
  การสูญเสียบนความยาว $0.40\text{ m}$:
  $$\text{Loss}_1 = 6.937\ \text{dB/m} \times 0.40\text{ m} \approx 2.775\ \text{dB}$$

- **สำหรับ HVLP:**
  $$\alpha_{\text{c, 2}} = 3.50\ \text{dB/m} \times 1.357 = 4.750\ \text{dB/m}$$
  การสูญเสียบนความยาว $0.40\text{ m}$:
  $$\text{Loss}_2 = 4.750\ \text{dB/m} \times 0.40\text{ m} \approx 1.900\ \text{dB}$$

- **ผลต่างการลดทอนสัญญาณ:**
  $$\Delta \text{Loss} = \text{Loss}_1 - \text{Loss}_2 = 2.775\ \text{dB} - 1.900\ \text{dB} = 0.875\ \text{dB}$$
  *(และในบอร์ด Stripline จริงที่มีพื้นผิวทองแดงทั้งด้านบนและล่างประกบสองด้าน ผลต่างความสูญเสียจะทวีคูณเป็น **$> 1.75\text{ ถึง }2.5\ \text{dB}$**)*

**บทวิเคราะห์ทางวิศวกรรม:**  
ในงบประมาณการสูญเสียสัญญาณของ PCIe Gen5 ที่ตึงตัวมาก (Loss Budget Margin มักเหลือไม่ถึง $1.5\ \text{dB}$) ผลต่างเกือบ $2\ \text{dB}$ จากความขรุขระของทองแดงนี้ คือจุดชี้ขาดระหว่าง **"ผ่านการรับรอง (PASS)"** กับ **"สอบตกร่วงลงสู่ Gen4 (FAIL)"**

</details>

### ข้อที่ 2: การคำนวณ Intra-Pair Fiber-Weave Delay Skew และการประเมินความสอดคล้องตามมาตรฐาน PCIe Gen5

**โจทย์:**  
บนแผงวงจรเซิร์ฟเวอร์ คู่สายอนุพันธ์ PCIe Gen5 (อัตราส่ง $32\text{ GT/s}$, คาบเวลา Unit Interval $T_{\text{UI}} = 31.25\text{ ps}$) มีความยาวทางกายภาพ $L = 200.0\text{ mm}$ ($0.200\text{ m}$)  
แผงวงจรผลิตด้วยพรีเพร็กผ้าใยแก้วแบบดั้งเดิมเบอร์ 1080 โดยสายสัญญาณถูกเดินในแนวขนานตรงกับแกนม้วนผ้า ($0^\circ$ Parallel to Yarn):
- สายสัญญาณ $D+$ วิ่งทับอยู่บนแนวสันมัดเส้นใยแก้วโดยตรง มีค่าคงที่ไดอิเล็กทริกยังผล: $D_{k, +} = 4.35$
- สายสัญญาณ $D-$ วิ่งทับอยู่บนช่องว่างแอ่งเรซิน มีค่าคงที่ไดอิเล็กทริกยังผล: $D_{k, -} = 3.55$
- ความเร็วแสงในสุญญากาศ: $c = 3.0 \times 10^8\ \text{m/s}$
- ตามข้อกำหนดมาตรฐาน **PCI-SIG PCIe Gen5 Base Specification**: ค่าความคลาดเคลื่อนเวลาหน่วงสะสมภายในคู่สายอนุพันธ์ (Intra-Pair Delay Skew: $\Delta t_{\text{skew}}$) ณ ตัวรับสัญญาณปลายทาง ต้องถูกควบคุมให้ **ไม่เกิน $0.15\ \text{UI}$** ($\Delta t_{\text{limit}} = 0.15 \times 31.25\text{ ps} \approx 4.69\text{ ps}$)

1. จงคำนวณหาความเร็วการแพร่กระจายคลื่น ($v_+$ และ $v_-$) ของสายสัญญาณทั้งสองเส้น
2. คำนวณหาเวลาเดินทางรวม ($t_{\text{prop, +}}$ และ $t_{\text{prop, -}}$) บนระยะทาง $200.0\text{ mm}$
3. คำนวณหา **ค่า Intra-Pair Delay Skew สะสม ($\Delta t_{\text{skew}}$)** ในหน่วยพิโกวินาที ($\text{ps}$)
4. ตัดสินว่าช่องสัญญาณนี้ผ่านเกณฑ์มาตรฐาน PCI-SIG หรือไม่ และคำนวณหาความยาวสูงสุด ($L_{\text{max}}$) ที่ยอมให้เดินสายขนานแบบนี้ได้ก่อนที่ Skew จะแตะขีดจำกัด $4.69\text{ ps}$

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณความเร็วการแพร่กระจายคลื่น:**
- สำหรับสาย $D+$ ($D_{k, +} = 4.35$):
  $$v_+ = \frac{c}{\sqrt{D_{k, +}}} = \frac{3.0 \times 10^8\ \text{m/s}}{\sqrt{4.35}} = \frac{3.0 \times 10^8}{2.0857} \approx 1.4384 \times 10^8\ \text{m/s}$$
- สำหรับสาย $D-$ ($D_{k, -} = 3.55$):
  $$v_- = \frac{c}{\sqrt{D_{k, -}}} = \frac{3.0 \times 10^8\ \text{m/s}}{\sqrt{3.55}} = \frac{3.0 \times 10^8}{1.8841} \approx 1.5923 \times 10^8\ \text{m/s}$$

---

**2. คำนวณเวลาเดินทางรวมบนระยะทาง $L = 0.200\text{ m}$:**
- เวลาเดินทางของ $D+$:
  $$t_{\text{prop, +}} = \frac{L}{v_+} = \frac{0.200\ \text{m}}{1.4384 \times 10^8\ \text{m/s}} \approx 1.3904 \times 10^{-9}\ \text{s} = 1,390.4\ \text{ps}$$
- เวลาเดินทางของ $D-$:
  $$t_{\text{prop, -}} = \frac{L}{v_-} = \frac{0.200\ \text{m}}{1.5923 \times 10^8\ \text{m/s}} \approx 1.2560 \times 10^{-9}\ \text{s} = 1,256.0\ \text{ps}$$

---

**3. คำนวณหา Intra-Pair Delay Skew สะสม ($\Delta t_{\text{skew}}$):**
$$\Delta t_{\text{skew}} = t_{\text{prop, +}} - t_{\text{prop, -}} = 1,390.4\ \text{ps} - 1,256.0\ \text{ps} = 134.4\ \text{ps}$$
*(หรือคิดตามแบบจำลอง Partial Bundle Overlap ในความเป็นจริงที่ความแปรปรวนเฉลี่ยอยู่ที่ประมาณ $5\% - 10\%$ ของค่าสุดโต่งนี้ จะได้ $\Delta t_{\text{skew, practical}} \approx 8 - 14\ \text{ps}$)*  
หากคิดตามกรณี Worst-case ทางกายภาพนี้:
$$\Delta t_{\text{skew}} = 134.4\ \text{ps}$$

---

**4. การตัดสินผลตามเกณฑ์ PCI-SIG:**
- ขีดจำกัดสูงสุดที่ยอมรับได้: $\Delta t_{\text{limit}} = 4.69\text{ ps}$ ($0.15\ \text{UI}$)
- ค่าที่เกิดขึ้นจริง ($134.4\ \text{ps}$) สูงกว่าเกณฑ์ถึง **$28.6$ เท่า!** (และแม้คิดค่าเฉลี่ย $10\ \text{ps}$ ก็ยังเกินเกณฑ์กว่า 2 เท่า)
- **ผลการตัดสิน:** **สอบตกอย่างสิ้นเชิง (FAIL)**  
  สัญญาณ Differential จะแปลงสภาพเป็น Common-mode Noise เกือบหมด รูปตาสัญญาณจะพังทลาย ลิงก์จะไม่สามารถทำงานที่ความเร็ว PCIe Gen5 ได้เลย

- **คำนวณหาความยาวสูงสุดที่ปลอดภัย ($L_{\text{max}}$):**
  อัตราการสะสม Skew ต่อหนึ่งหน่วยความยาว:
  $$\text{Skew Rate} = \frac{\Delta t_{\text{skew}}}{L} = \frac{134.4\ \text{ps}}{200.0\ \text{mm}} = 0.672\ \text{ps/mm}$$
  ความยาวสูงสุดที่จะไม่เกิน $4.69\text{ ps}$:
  $$L_{\text{max}} = \frac{4.69\ \text{ps}}{0.672\ \text{ps/mm}} \approx 6.98\text{ mm}$$

**บทสรุปทางวิศวกรรม:**  
หากใช้ผ้าใยแก้ว 1080 แบบดั้งเดิมและเดินสายขนานตรง จะเดินสายได้ไกลไม่เกิน **$7\text{ mm}$** เท่านั้น!  
จึงเป็นข้อบังคับเด็ดขาดที่ต้อง **เปลี่ยนไปใช้ผ้าใยแก้วชนิดกระจายตัวแบน (Spread Glass 1078/1067) ร่วมกับการเดินสายเอียงทำมุม $10^\circ - 15^\circ$** ซึ่งจะกดอัตราการสะสม Skew ลงเหลือต่ำกว่า $0.015\ \text{ps/mm}$ ทำให้สามารถเดินสายได้ไกลกว่า $300\text{ mm}$ อย่างปลอดภัย

</details>

### ข้อที่ 3: การวิเคราะห์ความคลาดเคลื่อนระหว่าง TDR Test Coupon และแผงบอร์ดจริง (Coupon Correlation Error)

**โจทย์:**  
โรงงานผลิต PCB ส่งมอบล็อตแผงวงจรเซิร์ฟเวอร์ 12 ชั้นที่มีข้อกำหนดควบคุมอิมพีแดนซ์ Stripline $50.0\ \Omega \pm 10\%$ ($45.0\ \Omega - 55.0\ \Omega$)  
ผลการทดสอบด้วยเครื่อง TDR บนแผ่นคูปองทดสอบ (Coupon) ที่ขอบพาเนลระบุว่า:
- $Z_{\text{coupon}} = 49.5\ \Omega$ (ผ่านเกณฑ์อย่างสมบูรณ์แบบ)  
แต่เมื่อทีมฮาร์ดแวร์นำบอร์ดจริงมาผ่าตัดตรวจสอบหน้าตัดจุลภาค (Microsection) บนเส้นสัญญาณ Stripline บริเวณใจกลางของแผงบอร์ด พบพารามิเตอร์ทางเรขาคณิตจริงดังนี้:
- ความกว้างเส้นบนคูปอง: $W_{\text{coupon}} = 105.0\ \mu\text{m}$ (ขอบพาเนลมีทองแดงล้อมรอบหนาแน่น เรซินไม่ไหลหนี)
- ความกว้างเส้นบนบอร์ดจริง: $W_{\text{board}} = 98.0\ \mu\text{m}$ (เกิด Over-etching มากกว่าคูปอง $7.0\ \mu\text{m}$)
- ความหนาชั้นไดอิเล็กทริกบนคูปอง: $H_{\text{coupon}} = 120.0\ \mu\text{m}$
- ความหนาชั้นไดอิเล็กทริกบนบอร์ดจริง: $H_{\text{board}} = 105.0\ \mu\text{m}$ (เนื่องจากพื้นที่รอบข้างมีทองแดงเบาบาง เรซินจึงถูกบีบไหลหนีไปเติมช่องว่าง ทำให้ชั้นฉนวนบางลง $15.0\ \mu\text{m}$)
- ค่าความไวของอิมพีแดนซ์ Stripline ต่อตัวแปรทางเรขาคณิต:
  $$\frac{\partial Z_0}{\partial W} \approx -0.32\ \Omega/\mu\text{m}, \quad \frac{\partial Z_0}{\partial H} \approx +0.42\ \Omega/\mu\text{m}$$

1. จงคำนวณหาผลกระทบต่ออิมพีแดนซ์จากการเปลี่ยนแปลงความกว้างเส้น ($\Delta Z_W$) บนบอร์ดจริงเทียบกับคูปอง
2. คำนวณหาผลกระทบต่ออิมพีแดนซ์จากการเปลี่ยนแปลงความหนาไดอิเล็กทริก ($\Delta Z_H$) บนบอร์ดจริงเทียบกับคูปอง
3. คำนวณหา **ค่าอิมพีแดนซ์จริงของเส้นสัญญาณบนบอร์ด ($Z_{\text{board, actual}}$)**
4. อธิบายสาเหตุของความคลาดเคลื่อนนี้ และระบุข้อกำหนด DFM ที่ต้องเพิ่มใน Master Drawing เพื่อให้ผลการวัดคูปองสอดคล้องกับบอร์ดจริง $100\%$

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณผลกระทบจากความกว้างเส้น ($\Delta Z_W$):**
ความกว้างเส้นบนบอร์ดจริงเทียบกับคูปอง:
$$\Delta W = W_{\text{board}} - W_{\text{coupon}} = 98.0\ \mu\text{m} - 105.0\ \mu\text{m} = -7.0\ \mu\text{m}$$
การเปลี่ยนแปลงของอิมพีแดนซ์:
$$\Delta Z_W = \Delta W \times \left( \frac{\partial Z_0}{\partial W} \right) = (-7.0\ \mu\text{m}) \times (-0.32\ \Omega/\mu\text{m}) = +2.24\ \Omega$$
(เส้นแคบลง ทำให้อิมพีแดนซ์เพิ่มขึ้น $+2.24\ \Omega$)

---

**2. คำนวณผลกระทบจากความหนาไดอิเล็กทริก ($\Delta Z_H$):**
ความหนาฉนวนบนบอร์ดจริงเทียบกับคูปอง:
$$\Delta H = H_{\text{board}} - H_{\text{coupon}} = 105.0\ \mu\text{m} - 120.0\ \mu\text{m} = -15.0\ \mu\text{m}$$
การเปลี่ยนแปลงของอิมพีแดนซ์:
$$\Delta Z_H = \Delta H \times \left( \frac{\partial Z_0}{\partial H} \right) = (-15.0\ \mu\text{m}) \times (+0.42\ \Omega/\mu\text{m}) = -6.30\ \Omega$$
(ฉนวนบางลง ทำให้อิมพีแดนซ์ลดลง $-6.30\ \Omega$)

---

**3. คำนวณหาค่าอิมพีแดนซ์จริงบนบอร์ด ($Z_{\text{board, actual}}$):**
การเปลี่ยนแปลงอิมพีแดนซ์รวม:
$$\Delta Z_{\text{total}} = \Delta Z_W + \Delta Z_H = +2.24\ \Omega - 6.30\ \Omega = -4.06\ \Omega$$

อิมพีแดนซ์จริงบนบอร์ด:
$$Z_{\text{board, actual}} = Z_{\text{coupon}} + \Delta Z_{\text{total}} = 49.5\ \Omega - 4.06\ \Omega = 45.44\ \Omega$$

**การประเมินผล:**  
ค่าอิมพีแดนซ์จริงบนบอร์ดตกลงมาอยู่ที่ **$45.44\ \Omega$** แม้ว่าจะยังเฉียดฉิวอยู่ในกรอบล่างสุดของ $\pm 10\%$ ($45.0\ \Omega$) แต่มีมาร์จินความปลอดภัยเหลือเพียง $0.44\ \Omega$ (เกือบหลุดสเปก) ในขณะที่คูปองรายงานค่าสวยหรูที่ $49.5\ \Omega$

---

**4. การวิเคราะห์สาเหตุและมาตรการแก้ไข DFM:**
- **สาเหตุรากเหง้า (Root Cause):**
  1. **Copper Density Mismatch:** คูปองทดสอบถูกวางไว้ที่ขอบรางพาเนลซึ่งแวดล้อมด้วยแผ่นทองแดงทึบของรางจับ ทำให้เรซินไม่ไหลหนี ในขณะที่ตัวบอร์ดจริงมีลายวงจรเบาบาง เรซินจึงไหลหนีเข้าไปในช่องว่าง ทำให้ความหนาฉนวนยุบตัวลงมากกว่าคูปอง
  2. **Etching Fluid Velocity Mismatch:** สเปรย์น้ำยากัดกรดที่ขอบพาเนลและใจกลางพาเนลมีความดันต่างกัน ทำให้เกิด Over-etching ที่ใจกลางบอร์ดมากกว่า
- **ข้อกำหนด DFM ที่ต้องระบุใน Master Drawing (検図対策):**
  1. **Thieving Matching:** สั่งเติม Copper Thieving บนบอร์ดจริงให้มีเปอร์เซ็นต์ทองแดงเท่ากับบริเวณคูปอง ($R_{\text{Cu}} \approx 75\% - 80\%$)
  2. **Co-located Coupon Design:** สั่งให้โรงงานวางคูปองทดสอบจำลองไว้ที่ **ใจกลางของแผงพาเนล (Center-Panel Test Coupon)** อย่างน้อย 1 จุด ร่วมกับคูปองที่ขอบ เพื่อตรวจสอบความสม่ำเสมอของอิมพีแดนซ์ข้ามแผงผลิตจริง

</details>
