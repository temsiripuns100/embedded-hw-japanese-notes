## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในระบบฮาร์ดแวร์ประมวลผลยุคใหม่ (เช่น AI Accelerators, High-End FPGAs, Multi-core SoCs) แรงดันไฟเลี้ยงแกนประมวลผล (Core Voltage, $V_{core}$) ลดต่ำลงมาอยู่ที่ **$0.75\text{V} - 0.90\text{V}$** ในขณะที่กระแสไฟฟ้าสลับการทำงาน (Transient Dynamic Current) พุ่งสูงขึ้นถึง **$20\text{A} - 100\text{A}$** ภายในเวลาเพียงไม่กี่นาโนวินาที 
การออกแบบระบบโครงข่ายจ่ายพลังงาน (Power Delivery Network - PDN) ไม่ใช่เพียงแค่การลากเส้นทองแดงให้หนาเพื่อไม่ให้ทองแดงไหม้ แต่คือการควบคุม **AC Impedance ของ PDN ให้ต่ำกว่าเป้าหมาย (Target Impedance) ตลอดช่วงความถี่ตั้งแต่ DC ไปจนถึงหลายร้อย MHz**

---

### 1.1 การคำนวณ Target Impedance ($Z_{target}$)
เพื่อให้มั่นใจว่าแรงดันกระเพื่อม (Voltage Ripple / Sag) จะไม่แกว่งเกินขอบเขตที่ชิปประมวลผลยอมรับได้ (ปกติอยู่ที่ $\pm 3\%$ ถึง $\pm 5\%$) เมื่อเกิดการกระชากของกระแสแบบกะทันหัน ($\Delta I_{step}$):

$$Z_{target} = \frac{V_{rail} \times \%RippleMargin}{\Delta I_{step}} \quad [\Omega]$$

- $V_{rail}$: แรงดันไฟฟ้าของรางจ่ายไฟ (เช่น $0.85 \text{ V}$)
- $\%RippleMargin$: สัดส่วนการกระเพื่อมที่ยอมรับได้ (เช่น $\pm 3\% \rightarrow 0.85 \times 0.03 = 25.5 \text{ mV}$)
- $\Delta I_{step}$: ขนาดการกระชากของกระแสในสภาวะ Transient (ตามหลักการออกแบบ Senior นิยมคิดที่ $50\%$ ของกระแสสูงสุด $I_{max}$)

**ตัวอย่างการคำนวณจริง (FPGA Core Power Rail):**
กำหนดให้ $V_{core} = 0.85 \text{ V}$, ยอมรับ Ripple ได้ $3\%$ ($25.5 \text{ mV}$), และชิปดึงกระแสกระชาก $\Delta I = 30 \text{ A}$:
$$Z_{target} = \frac{0.0255 \text{ V}}{30 \text{ A}} = 0.00085 \ \Omega = \mathbf{0.85 \ m\Omega}$$

*ความหมายเชิงวิศวกรรม:* ไม่ว่าที่ความถี่ใดก็ตาม ตั้งแต่ DC ไปจนถึงความถี่หลายร้อย MHz ค่า Impedance ของระบบ PDN **ต้องต่ำกว่า $0.85 \text{ m}\Omega$ ตลอดเวลา** มิฉะนั้น Voltage Drop จะเกิน $25.5 \text{ mV}$ และทำให้ชิปเกิดข้อผิดพลาดในการคำนวณหรือรีเซ็ตตัวเองทันที!

### 1.2 โครงสร้างลำดับชั้นของ PDN (PDN Decoupling Hierarchy)
ไม่มีตัวเก็บประจุชนิดใดชนิดหนึ่งที่สามารถครอบคลุมช่วงความถี่ได้ทั้งหมด ระบบ PDN จึงต้องใช้โครงสร้างแบบลำดับขั้น (Tiered Decoupling):

```
 Impedance [Ω]
   ▲
   │        VRM (Low-Freq)
   │        ┌──────┐         Bulk Caps (Mid-Freq)
   │        │      │          ┌──────┐         MLCC Decaps (High-Freq)
   │        │      │          │      │          ┌──────┐        Plane Capacitance (Ultra-High)
   │        │      │          │      │          │      │         ┌──────┐
 ──┼────────┴──────┴──────────┴──────┴──────────┴──────┴─────────┴──────┴───────  Z_target
   │
   └────────────────────────────────────────────────────────────────────────► Frequency
      DC      100kHz          1MHz             50MHz            500MHz    1GHz
```

1. **DC ถึง ~100 kHz:** ควบคุมโดยวงจรแปลงแรงดัน **VRM (Voltage Regulator Module)** ผ่าน Feedback Loop
2. **100 kHz ถึง ~2 MHz:** ควบคุมโดย **Bulk Capacitors** (Tantalum Polymer, POSCAP, หรือ Aluminum Polymer ขนาด $100\mu\text{F} - 470\mu\text{F}$)
3. **2 MHz ถึง ~50 MHz:** ควบคุมโดย **High-Capacitance Ceramic MLCCs** (ขนาด $10\mu\text{F} - 47\mu\text{F}$ 0805/0603)
4. **50 MHz ถึง ~200 MHz:** ควบคุมโดย **Low-Inductance MLCCs** (ขนาด $0.1\mu\text{F} - 1\mu\text{F}$ 0402/0201 หรือ Reverse Geometry 0306/0508)
5. **200 MHz ถึง 1 GHz:** ควบคุมโดย **Inter-plane Capacitance (ความจุระหว่างระนาบ Power/Ground Plane)** ร่วมกับตัวเก็บประจุในแพ็กเกจชิป (On-Die / On-Package Capacitance)

---

### 1.3 ปรากฏการณ์ Anti-Resonance Peaking
หนึ่งในข้อผิดพลาดที่ร้ายแรงที่สุดของการวาง Decoupling Capacitor คือการขนานตัวเก็บประจุหลายๆ ค่าต่างกัน เช่น $10\mu\text{F} \parallel 0.1\mu\text{F} \parallel 0.001\mu\text{F}$:
- ตัวเก็บประจุแต่ละตัวมีค่าความเหนี่ยวนำอนุกรมแฝง (ESL - Equivalent Series Inductance) และความต้านทานแฝง (ESR)
- เหนือความถี่เรโซแนนซ์ตัวเอง (Self-Resonant Frequency - SRF) ตัวเก็บประจุตัวใหญ่ ($10\mu\text{F}$) จะกลายสภาพเป็น **Inductor**
- ในขณะที่ตัวเก็บประจุตัวเล็ก ($0.1\mu\text{F}$) ยังคงมีพฤติกรรมเป็น **Capacitor**
- การขนานกันระหว่าง Inductance ของตัวใหญ่ กับ Capacitance ของตัวเล็ก จะก่อให้เกิดวงจรขนาน $LC$ เรโซแนนซ์คู่ขนาน เรียกว่า **Anti-Resonance Peak** ซึ่งจะทำให้ Impedance รวมของ PDN **พุ่งกระฉูดขึ้นไปเป็นภูเขาสูงทะลุค่า $Z_{target}$** ที่ความถี่บางย่าน!

```
 Impedance [Ω]
   ▲
   │                 Anti-Resonance Peak! (เสี่ยงชิปพัง)
   │                       /\
   │                      /  \
 ──┼─────────────────────/────\──────────────────  Z_target (เกณฑ์กำหนด)
   │      \             /      \
   │       \  C1       /        \  C2
   │        \_________/          \_________
   └────────────────────────────────────────────► Frequency
```

*แนวทางแก้ไขของ Senior Engineer:* ใช้วิธี **Same-Value Decoupling Strategy** คือการใช้ตัวเก็บประจุค่าเดียวกันจำนวนมาก (เช่น ใช้ $1\mu\text{F}$ 0402 ทั้งหมด 20 ตัว) หรือควบคุมค่า ESR ของตัวเก็บประจุให้เหมาะสมเพื่อแดมป์ (Damp) ไม่ให้ยอด Anti-resonance พุ่งสูง

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** บอร์ด AI Vision Processor ทำงานทดสอบความเร็วต่ำผ่านปกติ แต่เมื่อโหลดโมเดล Deep Learning เต็มรูปแบบและรัน Inference ชิปจะเกิดอาการ Hang และสุ่มรีเซ็ตตัวเอง วัดแรงดันไฟเลี้ยง $0.85\text{V}$ ด้วย Oscilloscope พบว่าแรงดันไฟดิ่งลงฮวบเหลือเพียง $0.74\text{V}$ (แรงดันตกถึง $13\%$) เป็นระยะเวลา 35 ns
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. ตัวเก็บประจุ Decoupling $0.1\mu\text{F}$ วางอยู่ใต้ท้อง BGA แต่เดินเส้น Trace ลากยาวออกมา $1.5\text{ mm}$ ก่อนจะลง Via สู่ Power Plane
2. แต่ละ Pad ใช้ Via เจาะเพียงรูเดียว (Loop Inductance รวมของตัวเก็บประจุแต่ละตัวพุ่งสูงถึง **$1.8\text{ nH}$**)
3. ที่ความถี่ Transient $60\text{ MHz}$ ค่า Impedance จากความเหนี่ยวนำ ($X_L = 2\pi f L_{loop} \approx 0.68 \ \Omega$) ทำให้ Decoupling Capacitor ไม่สามารถจ่ายกระแสชดเชยได้ทัน

---

### ขั้นตอนการวาง Decoupling และ Power Plane สไตล์ Senior (検図チェックリスト):
1. **การลด Loop Inductance ของ Decap ให้ต่ำที่สุด:**
   - **อย่ายาว (No Traces):** เจาะ Via ติดกับ Pad ของ Capacitor โดยตรง (ห้ามเดิน Trace ลากยาว)
   - **ใช้ Via คู่ (Dual Vias per Pad):** เจาะ 2 Via ต่อ 1 ขั้ว Pad ขนานกัน เพื่อลดค่า Via Inductance ลงครึ่งหนึ่ง
   - **ใช้ตัวเก็บประจุแบบ Reverse Geometry (0306 หรือ 0508):** ซึ่งมีขั้ว Pad อยู่ทางด้านยาว ทำให้ระยะห่างระหว่างขั้วสั้นลง ช่วยลด ESL ภายในตัวเก็บประจุลงได้ถึง **$60\%$** (เหลือเพียง $\approx 0.15\text{ nH}$)
2. **การสร้าง Inter-plane Capacitance จาก Stackup:**
   - จัดเรียงชั้น Power Plane และ Ground Plane ให้อยู่ **ติดกันแนบชิดที่สุด** คั่นด้วย Prepreg ที่บางที่สุดเท่าที่ทำได้ (เช่น ความหนา Dielectric $2.0 - 3.0 \text{ mil}$):
     $$C_{plane} = \frac{\epsilon_0 \ \epsilon_r \ A}{d}$$
   - โครงสร้างนี้สร้างตัวเก็บประจุในอุดมคติที่ไม่มีขั้วต่อลีด (Leadless Capacitor) ซึ่งให้ค่า Spreading Inductance ต่ำระดับ sub-picohoney สามารถจ่ายกระแสความถี่สูงระดับ GHz ได้อย่างราบรื่น
3. **การตรวจสอบ DC IR-Drop และจุดคอขวด (Neckdown):**
   - คำนวณความหนาแน่นกระแส (Current Density) ต้องไม่เกิน **$30\text{ mA/mil}^2$** ($46.5\text{ A/mm}^2$) สำหรับทองแดง 1 oz เพื่อป้องกันไม่ให้อุณหภูมิของระนาบทองแดงเพิ่มขึ้นเกิน $10^\circ\text{C}$

> **指摘事項 2:**  
> 「L3層の1.2V電源プレーンにおいて、BGAの貫通ビア密集部でプレーン幅が0.3mmまで狭窄（ボトルネック）しており、DC IRドロップ解析で許容値（2%）を超える35mVの電圧降下が予測されます。電源パターンの幅を最低1.5mm以上確保できるよう、信号ビアの配置を見直してください。」  
> *(บนระนาบไฟ 1.2V ชั้น L3 มีจุดคอขวดที่ความกว้างระนาบถูกบีบเหลือเพียง 0.3mm จากแนวเจาะ Via หนาแน่นของ BGA ส่งผลให้เกิด IR Drop สูงถึง 35mV ซึ่งเกินเกณฑ์ 2% กรุณาปรับเปลี่ยนตำแหน่ง Via สัญญาณเพื่อเปิดพื้นที่ระนาบไฟให้กว้างอย่างน้อย 1.5mm ขึ้นไป)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Target Impedance และขนาด Ripple)
ชิปประมวลผล GPU ต้องการไฟเลี้ยง $V_{DD} = 0.90 \text{ V}$ โดยยอมรับแรงดันกระเพื่อมได้สูงสุด $\pm 4\%$ หากในสภาวะที่มีการเปิดใช้งานคอร์ประมวลผลพร้อมกัน กระแสโหลดกระชากจาก $5 \text{ A}$ ขึ้นเป็น $45 \text{ A}$ ภายในเวลา $2 \text{ ns}$ ($\Delta I = 40 \text{ A}$) ถามว่าค่า Target Impedance ของระบบ PDN สูงสุดที่ยอมรับได้คือเท่าใด?

- **ก)** $9.00 \text{ m}\Omega$
- **ข)** $0.90 \text{ m}\Omega$
- **ค)** $22.5 \text{ m}\Omega$
- **ง)** $0.09 \text{ m}\Omega$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> คำนวณช่วงแรงดันกระเพื่อมที่ยอมรับได้:  
> $$\Delta V = V_{DD} \times 0.04 = 0.90 \text{ V} \times 0.04 = 0.036 \text{ V} \ (36 \text{ mV})$$  
> คำนวณ Target Impedance:  
> $$Z_{target} = \frac{\Delta V}{\Delta I} = \frac{0.036 \text{ V}}{40 \text{ A}} = 0.0009 \ \Omega = \mathbf{0.90 \text{ m}\Omega}$$  
> ระบบ PDN ทั้งหมดจะต้องรักษาระดับ AC Impedance ไม่ให้เกิน $0.90 \text{ m}\Omega$ ตลอดช่วงแบนด์วิธการทำงาน หาก Impedance พุ่งสูงเกินค่านี้แม้เพียงเสี้ยวความถี่ แรงดันจะตกเกิน 36 mV และทำให้ GPU แครช

---

### ข้อที่ 2 (กลไกการเกิด Anti-Resonance)
เมื่อวิศวกรต่อขนานตัวเก็บประจุ $C_1 = 10 \ \mu\text{F}$ (ค่า $\text{ESL} = 1.0 \text{ nH}$) เข้ากับตัวเก็บประจุ $C_2 = 0.1 \ \mu\text{F}$ (ค่า $\text{ESL} = 0.4 \text{ nH}$) ที่ความถี่สูงกว่า Self-Resonant Frequency ของ $C_1$ ปรากฏการณ์ใดจะเกิดขึ้น และส่งผลอย่างไรต่อระบบ PDN?

- **ก)** ค่า Capacitance รวมจะเพิ่มขึ้นเป็นสองเท่าโดยไม่มีการเปลี่ยนแปลงของ Impedance
- **ข)** $C_1$ จะเริ่มมีพฤติกรรมเป็น Inductor เหนี่ยวนำขนานกับพฤติกรรม Capacitive ของ $C_2$ ก่อให้เกิด Anti-Resonance Peak ที่มีความต้านทานสูงมาก ณ ย่านความถี่รอยต่อ
- **ค)** ตัวเก็บประจุ $C_2$ จะระเบิดออกทันทีจากกระแสกระชาก
- **ง)** สัญญาณรบกวนจะถูกดูดซับลงกราวด์ได้สมบูรณ์แบบ 100%

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> เหนือความถี่ SRF ของตัวมันเอง พฤติกรรมของตัวเก็บประจุจะถูกครอบงำด้วย ESL (กลายเป็นขดลวดตัวนำ)  
> ในย่านความถี่ระหว่าง SRF ของ $C_1$ กับ SRF ของ $C_2$ ตัวเก็บประจุ $C_1$ จะทำหน้าที่เป็น Inductor ขณะที่ $C_2$ ยังเป็น Capacitor วงจรขนาน $L-C$ นี้จะสร้าง **Parallel Resonance (Anti-Resonance)** ซึ่งมีค่า Impedance พุ่งสูงขึ้นอย่างรุนแรง หากค่า ESR ของตัวเก็บประจุทั้งสองต่ำมาก (เช่น เซรามิกเกรดสูง) ยอดแหลมของภูเขาจะสูงทะลุ $Z_{target}$ กลายเป็นจุดอ่อนของ PDN

### ข้อที่ 3 (เทคนิคการลด Loop Inductance ของ Via สำหรับ Decap)
วิธีใดในการต่อขั้วของ Decoupling Capacitor SMD เข้ากับแผ่นวงจรพิมพ์ที่ให้ค่า Loop Inductance ($L_{loop}$) ต่ำที่สุดตามหลักการออกแบบ High-Speed Power Integrity?

- **ก)** เดินลายเส้น Trace กว้าง 10 mil ลากออกไป 2 mm แล้วจึงเจาะ Via ลงระนาบ Ground
- **ข)** เจาะ Via ระหว่างขั้ว Pad ทั้งสองของ Capacitor
- **ค)** เจาะ Via ชิดติดกับขอบด้านข้างของ Pad โดยตรง และใช้ Via คู่ (Dual Vias) ต่อ 1 Pad ร่วมกับการวางระนาบ Power และ Ground ไว้ใกล้ผิวด้านบนสุดของ Stackup
- **ง)** ต่อสายไฟเส้นเล็กๆ โยงจากขั้ว Capacitor ไปยังแหล่งจ่ายไฟภายนอก

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ค)**  
> Loop Inductance เกิดจากพื้นที่วงลูปที่กระแสไหลจาก Plane ขึ้นมาผ่าน Via เข้าขั้ว Pad ตัวเก็บประจุ ไหลผ่านชิป และมุดกลับลงสู่ Plane อีกระนาบหนึ่ง  
> การเจาะ Via ติด Pad โดยตรงจะขจัดความยาว Trace ออกไปจนหมด การใช้ **Via คู่ (Dual Vias)** จะทำให้ค่า Via Inductance ต่อขนานกันจนลดลงครึ่งหนึ่ง และการจัดให้ระนาบ Power/GND อยู่ชิดผิวบอร์ดที่สุดจะทำให้กระบอก Via มีความยาวสั้นที่สุด ซึ่งช่วยลด Loop Inductance ลงเหลือต่ำกว่า **$0.3 - 0.4 \text{ nH}$**
