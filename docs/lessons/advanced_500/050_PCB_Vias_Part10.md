# Lesson 050: PCB Vias Part 10 - Via Reliability, Thermal Cycling, CAF Resistance & IPC Class 3 Qualification
*(ビアの信頼性物理 - 熱疲労破壊・導電性陽極フィラメントCAF耐性とIPC-6012 Class 3認定試験)*

---

## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการประเมินความน่าเชื่อถือระยะยาว (Long-Term Reliability) ของแผ่นวงจรพิมพ์ระดับเกรดยานยนต์ (AEC-Q100/Q200), อุปกรณ์การแพทย์ช่วยชีวิต, และโครงสร้างพื้นฐาน 5G/เซิร์ฟเวอร์ โครงสร้างที่มีอัตราความล้มเหลวสะสมสูงสุดในภาคสนามคือ **รูเจาะเปลี่ยนเลเยอร์ (Via Interconnects)**

ความล้มเหลวของ Via ถูกขับเคลื่อนด้วย 2 กลไกทางฟิสิกส์หลัก:
1. **ความล้าจากการขยายตัวทางความร้อน (Thermomechanical Cyclic Fatigue):** ซึ่งเกิดจากความไม่เข้ากันของสัมประสิทธิ์การขยายตัวทางความร้อนในแนวแกนดิ่ง (**$Z$-axis CTE Mismatch**) ระหว่างกระบอกทองแดงกับเนื้อฉนวนเรซิน อธิบายได้ด้วยสมการความล้า **Coffin-Manson Relation**
2. **การลัดวงจรเคมีไฟฟ้าตามแนวเส้นใยแก้ว (Conductive Anodic Filament: CAF - 陽極フィラメント形成):** การเคลื่อนที่ของไอออนทองแดงภายใต้สนามไฟฟ้ากระแสตรงและความชื้นสัมพัทธ์สูง ก่อให้เกิดสะพานตัวนำลัดวงจรข้ามระหว่างรูเจาะ (Hole-to-Hole Micro-Shorts)

วิศวกรระดับ Senior ต้องเข้าใจพารามิเตอร์การทดสอบ **Interconnect Stress Testing (IST)**, การออกแบบ **Anti-CAF Design Rules**, และเกณฑ์การตรวจรับรองคุณภาพตาม **IPC-6012 Class 3**

### 1.1 ฟิสิกส์ความล้าจากความเค้นเทอร์โมเมคานิกส์และสมการ Coffin-Manson

ในกระบวนการเปลี่ยนแปลงอุณหภูมิ (Thermal Cycling เช่น $-40^\circ\text{C}$ ถึง $+125^\circ\text{C}$ หรือระหว่างการบัดกรี $260^\circ\text{C}$):

```
                                 Top Copper Land
                            ┌───────────────────────┐
                            │                       │
      Dielectric Expansion  │  ┌─────────────────┐  │
      ▲ ΔH_resin            │  │   PTH Barrel    │  │  ▲ ΔH_copper
      │ (CTE_z = 50-250)    │  │   (CTE = 17)    │  │  │ (Stretched by Resin!)
      │                     │  │                 │  │  │
      ▼                     │  │  Barrel Tensile │  │  ▼
                            │  │  Stress σ_z     │  │
                            │  └─────────────────┘  │
                            │                       │
                            └───────────────────────┘
                                Bottom Copper Land
```

1. **ความไม่เข้ากันของอัตราการขยายตัว (CTE Mismatch in Z-axis):**
   - ทองแดงในกระบอก Via มีค่า $CTE_{Cu} \approx 17 \text{ ppm/}^\circ\text{C}$ คงที่ตลอดช่วงอุณหภูมิ
   - เนื้อฉนวนอีพอกซีเรซิน (FR-4) มีค่า $CTE_{z1} \approx 45 - 60 \text{ ppm/}^\circ\text{C}$ ในช่วงต่ำกว่า $T_g$ และพุ่งทะยานขึ้นเป็น **$CTE_{z2} \approx 250 - 320 \text{ ppm/}^\circ\text{C}$** เมื่ออุณหภูมิสูงกว่าจุดหลอมแก้ว ($T > T_g$)
   - ความต่างของการยืดตัวนี้ทำให้เนื้อเรซินทำหน้าที่เสมือน "แม่แรงไฮดรอลิก" ดึงกระชากกระบอกทองแดงในแนวดิ่งตลอดเวลา

2. **การทำนายอายุการใช้งานด้วยสมการ Coffin-Manson (Fatigue Life Estimation):**  
   จำนวนรอบอุณหภูมิก่อนที่กระบอก Via จะเกิดการขาดสะบั้น (Cycles to Failure: $N_f$) คำนวณได้จากช่วงความเครียดพลาสติก ($\Delta \epsilon_p$):

$$N_f = \frac{1}{2} \left( \frac{\Delta \epsilon_p}{2 \epsilon_f'} \right)^{1/c}$$

โดยที่:
- $\Delta \epsilon_p$ คือช่วงการเปลี่ยนรูปพลาสติก ซึ่งแปรผันตรงกับ $\Delta T \times (CTE_{resin} - CTE_{Cu})$
- $\epsilon_f'$ คือสัมประสิทธิ์ความเหนียวของทองแดงชุบ (Fatigue Ductility Coefficient $\approx 0.15 - 0.30$)
- $c$ คือเลขชี้กำลังความล้าของทองแดง (Fatigue Ductility Exponent $\approx -0.5$ ถึง $-0.6$)

*ข้อสรุปเชิงวิศวกรรม:* หากเลือกใช้วัสดุที่มีค่า $T_g$ ต่ำและ $CTE_z$ สูง ค่า $\Delta \epsilon_p$ จะเพิ่มขึ้นเป็น 2 เท่า ส่งผลให้อายุการใช้งาน ($N_f$) ของกระบอก Via **ร่วงหล่นลงเหลือไม่ถึง 1 ใน 4 ของค่าเดิมทันที!**

### 1.2 กลไกการเกิดการลัดวงจรเคมีไฟฟ้า (Conductive Anodic Filament: CAF Formation)

ปรากฏการณ์ CAF คือการลัดวงจรแบบฉับพลันภายในเนื้อแผ่นวงจรพิมพ์ระหว่างรูเจาะ 2 รูที่อยู่ใกล้กันและมีความต่างศักย์ไฟตรง (DC Voltage Gradient):

```
       Anode (+) Via Barrel                        Cathode (-) Via Barrel
     ════════════════════════                    ════════════════════════
     ║                      ║                    ║                      ║
     ║  Cu -> Cu2+ + 2e-    ║   Glass Filament   ║  Cu2+ + 2e- -> Cu    ║
     ║  (Oxidation)         ║   Leakage Path     ║  (Reduction)         ║
     ║        │             ║   ─────────────►   ║        ▲             ║
     ║        ▼             ║                    ║        │             ║
     ║   [ Cu2+ Ions ] ═════╬════════════════════╬════════╝             ║
     ║                      ║  ◄── CAF Bridge! ──║                      ║
     ════════════════════════  (Subsurface Short)════════════════════════
     ◄────────────────── Wall-to-Wall Distance d ───────────────────────►
```

1. **ปฏิกิริยาเคมีไฟฟ้า 4 ขั้นตอน:**
   - **ขั้นที่ 1: การแยกตัวทางกล (Hydrolytic Degradation):** ความเค้นและความชื้นทำลายพันธะไซเลน (Silane Coupling Agent) ระหว่างผิวเส้นใยแก้วกับกาวเรซินอีพอกซี เกิดรอยแยกตามแนวยาว (Micro-capillary Tunnel)
   - **ขั้นที่ 2: ปฏิกิริยาออกซิเดชันที่ขั้วบวก (Anode Reaction):**  
     ทองแดงที่ขั้วบวกถูกกัดกร่อนกลายเป็นไอออน:
     $$\text{Cu} \longrightarrow \text{Cu}^{2+} + 2e^-$$
   - **ขั้นที่ 3: การเคลื่อนย้ายของไอออน (Ion Migration):**  
     ไอออน $\text{Cu}^{2+}$ และเกลือทองแดงไฮดรอกไซด์/คลอไรด์ ละลายในชั้นฟิล์มน้ำบางๆ และเคลื่อนตัวไปตามรอยแยกระหว่างเส้นใยแก้ว มุ่งหน้าสู่ขั้วลบ
   - **ขั้นที่ 4: การตกตะกอนเป็นสะพานตัวนำที่ขั้วลบ (Cathode Deposition):**  
     ไอออนรับอิเล็กตรอนตกตะกอนกลับเป็นสายฟิลาเมนต์ทองแดงบริสุทธิ์:
     $$\text{Cu}^{2+} + 2e^- \longrightarrow \text{Cu} \quad [\text{Conductive Bridge}]$$
   - เมื่อสายฟิลาเมนต์เชื่อมต่อระหว่างรูเจาะทั้งสองสำเร็จ ความต้านทานฉนวนจะดิ่งลงจาก $> 10^{10} \ \Omega$ เหลือต่ำกว่า **$10 \ \Omega$** ก่อให้เกิดไฟลัดวงจรและบอร์ดไหม้ในพริบตา

### 1.3 กฎการออกแบบป้องกัน CAF (Anti-CAF Design Rules)

| ปัจจัยการออกแบบ | กฎเกณฑ์ระดับมาตรฐานทั่วไป | กฎเกณฑ์ระดับ Anti-CAF สำหรับยานยนต์ / High-Voltage |
|---|---|---|
| **ระยะขอบผนังรูเจาะ (Wall-to-Wall Clearance)** | $d \ge 0.20 \text{ mm} \ (8 \text{ mil})$ | **$d \ge 0.30 - 0.35 \text{ mm} \ (12 - 14 \text{ mil})$** (หรือ $\ge 0.50 \text{ mm}$ สำหรับไฟ $>48\text{V}$) |
| **การจัดวางมุมแนวรูเจาะเทียบกับใยแก้ว** | วางเรียงตรงแนวตารางแกน $X-Y$ ($0^\circ/90^\circ$) | **วางเอียงแบบสลับฟันปลา (Staggered $45^\circ$)** เพื่อไม่ให้รูเจาะอยู่บนเส้นใยแก้วเส้นเดียวกัน |
| **เกรดของวัสดุลามิเนต (Laminate Grade)** | Standard FR-4 ทั่วไป | **Anti-CAF Certified Laminate** (เคลือบด้วย Silane Nanocoating ทนความชื้นสูง) |
| **การควบคุมความคมของดอกสว่าน** | เปลี่ยนสว่านทุก 1,500 - 2,000 รู | **เปลี่ยนสว่านทุก $\le 1,000$ รู** เพื่อป้องกันเส้นใยแก้วแตกช้ำ (Fracturing) |

---

### 1.4 การทดสอบความน่าเชื่อถือตามมาตรฐาน IPC-6012 Class 3

1. **Interconnect Stress Testing (IST - IPC-TM-650 2.6.26):**  
   ใช้กระแสไฟฟ้า DC ความหนาแน่นสูงวิ่งผ่านคูปองทดสอบ Daisy Chain พิเศษ เพื่อเหนี่ยวนำความร้อนให้กระบอก Via พุ่งแตะ **$260^\circ\text{C}$ ภายในเวลา 3 นาที** จากนั้นเป่าลมเย็นลงสู่ $25^\circ\text{C}$ ทำซ้ำต่อเนื่อง $500 - 1,000$ รอบ พร้อมวัดค่าความต้านทานระดับมิลลิโอห์ม:
   - **เกณฑ์การตัดสิน Class 3:** ความต้านทานต้องเปลี่ยนแปลง **$\Delta R \le 5.0\%$** ตลอด 500 รอบการทดสอบ
2. **การทดสอบความต้านทานฉนวนไฟฟ้าภายใต้ความชื้นเร่งด่วน (SIR / CAF Testing - IPC-TM-650 2.6.25):**  
   นำบอร์ดเข้าตู้อบสภาวะเร่งรัด **$85^\circ\text{C} / 85\% \text{ RH}$ พร้อมป้อนแรงดันไฟตรง $100 \text{ V}$ (หรือ $500 \text{ V}$)** ต่อเนื่องกันเป็นเวลา **1,000 ชั่วโมง**:
   - **เกณฑ์การตัดสิน:** ค่าความต้านทานฉนวนระหว่างรูเจาะ (Insulation Resistance) ต้องคงอยู่สูงกว่า **$10^8 \ \Omega$ ($100 \ \text{M}\Omega$)** ตลอดเวลา หากเกิด Breakdown จะถือว่าสอบตกทันที

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** บอร์ดกระจายกำลังไฟ 48V Power Distribution Unit (PDU) ในศูนย์ข้อมูล เกิดการลัดวงจรระเบิดอย่างรุนแรงจนไฟลุกไหม้ หลังจากติดตั้งใช้งานในห้องเซิร์ฟเวอร์เขตร้อนชื้นไปได้ 14 เดือน 
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **วางรูเจาะ 48V ชิดกับ GND Via เกินไป:** วิศวกรจัดวางรูเจาะ Through-Hole Via รางจ่ายไฟ 48V ขนานข้างกับ Ground Return Via โดยมีระยะห่างขอบผนังรูถึงขอบผนังรู (Hole Wall-to-Wall) เพียง **$0.18 \text{ mm} \ (7 \text{ mil})$**
2. **จัดวางตรงแนวตารางเส้นใยแก้ว $0^\circ$:** รูเจาะทั้งสองตัวร้อยผ่านเส้นใยแก้วมัดเดียวกันพอดีเป๊ะ
3. **ใช้วัสดุเกรดมาตรฐานที่ไม่ใช่ Anti-CAF:** เกิดการนำประจุเคมีไฟฟ้าตามรอยแยกของเส้นใยแก้ว เกิดเส้นใย CAF วิ่งเชื่อมระหว่าง 48V และ GND ความต่างศักย์ $48 \text{ V}$ ปลดปล่อยกระแสกระชากขนาดมหาศาลจนบอร์ดไหม้ละลาย

---

### ขั้นตอนการออกแบบ Anti-CAF และ Reliability สไตล์ Senior (検図チェックリスト):
1. **การตั้งค่ากฎ DRC Drill-to-Drill Clearance ในโปรแกรม CAD:**
   - สำหรับเน็ตที่มีความต่างศักย์ DC สูง (เช่น $12\text{V}, 24\text{V}, 48\text{V}$ เทียบกับ GND):
     - กำหนดระยะห่างขอบรูถึงขอบรูขั้นต่ำ:
       $$d_{wall-to-wall} \ge 0.35 \text{ mm} \ (14 \text{ mil}) \quad [\text{สำหรับ } \le 24\text{V}]$$
       $$d_{wall-to-wall} \ge 0.50 \text{ mm} \ (20 \text{ mil}) \quad [\text{สำหรับ } 48\text{V} - 100\text{V}]$$
2. **การจัดวาง Via แบบเอียงแนวทแยง 45 องศา (Staggered Layout Rule):**
   - ห้ามวางรูเจาะขนานกันตรงๆ ในแนวแกน $X$ หรือ $Y$ ที่ระยะชิด
   - ให้จัดวางรูเจาะเอียงทำมุม **$45^\circ$** เทียบกับขอบบอร์ด เพื่อบังคับให้รูเจาะทั้งสองตัวร้อยผ่านเส้นใยแก้วคนละมัด ตัดเส้นทางเดินของฟิลาเมนต์ CAF ทันที
3. **การระบุสเปกวัสดุ Anti-CAF ใน Fabrication Drawing:**
   - ระบุข้อกำหนดบังคับในเอกสารจัดซื้อและ Drawing:
     > *"Base material MUST be certified Anti-CAF grade per IPC-4101 slash sheet /126 or /130 (e.g. Isola 370HR, Shengyi S1000-2M, or Panasonic R-1755V). Must pass IPC-TM-650 2.6.25 CAF test: 85C/85%RH, 100V bias for 1000 hours with minimum insulation resistance > 10^8 ohms."*

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「48V電源プレーンの給電ビア群とGNDビア群の間において、ドリル内壁間クリアランスが0.18mm（約7mil）と極めて狭小であり、かつガラス繊維の織り方向と平行（0度方向）に配置されています。高温高湿環境下（85℃/85%RH）における長期通電により、ガラス/エポキシ界面の剥離毛細管を介した導電性陽極フィラメント（CAF現象）が急激に成長し、層間ショート破壊に至る致命的リスクがあります。ホール内壁間距離を最低0.40mm以上へ離隔し、かつ配置角度を45度千鳥配置へレイアウト修正してください。」  
> *(ระหว่างกลุ่ม Via ไฟ 48V กับ GND มีระยะห่างขอบรูเจาะเพียง 0.18mm และวางตรงแนวเส้นใยแก้ว 0 องศา เสี่ยงต่อการเกิด CAF ลัดวงจรในสภาวะร้อนชื้น ขอสั่งให้ขยายระยะห่างขอบรูเป็นอย่างน้อย 0.40mm ขึ้นไป และปรับการจัดวางเป็นแบบสลับฟันปลา 45 องศา)*

> **指摘事項 2:**  
> 「車載パワートレインECU（IPC Class 3仕様）の基板材料仕様において、耐CAF性規格の指定が欠落しています。車両寿命15年間の絶縁信頼性を保証するため、基板材料仕様書に「IPC-4101/126準拠の高Tg（Tg≧170℃）低熱膨張かつ高耐CAF認定材（85℃/85%RH、DC100V印加、1000時間後絶縁抵抗≧10^8Ω）」を必須条件として明記してください。」  
> *(ในสเปกบอร์ด ECU ยานยนต์ตาม IPC Class 3 ขาดการระบุมาตรฐานความทนทานต่อ CAF เพื่อรับประกันอายุการใช้งาน 15 ปี กรุณาระบุในสเปกบังคับให้ใช้วัสดุ High-Tg >= 170°C และผ่านการรับรอง Anti-CAF ตาม IPC-4101/126 ความต้านทานคงอยู่เกิน 10^8 โอห์มหลังทดสอบ 1000 ชั่วโมง)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การประเมินความเสี่ยงต่อการเกิด CAF และระยะห่างขั้นต่ำ)
ในวงจรขับมอเตอร์แรงดันไฟฟ้า $48 \text{ V}$ ที่ต้องทำงานในสภาวะแวดล้อมร้อนชื้นกลางแจ้ง (Outdoor Harsh Environment) ข้อกำหนดการออกแบบ Layout ข้อใดช่วยลดความเสี่ยงต่อการเกิดการลัดวงจรแบบ Conductive Anodic Filament (CAF) ระหว่างรูเจาะ Through-Hole ได้อย่างมีประสิทธิภาพสูงสุด?

- **ก)** ทาสี Solder Mask ทับรูเจาะให้หนาขึ้น 2 เท่า
- **ข)** กำหนดระยะห่างระหว่างขอบผนังรูเจาะ (Hole Wall-to-Wall Clearance) ไม่น้อยกว่า $0.40 - 0.50 \text{ mm}$, จัดวางรูเจาะเอียงทำมุม $45^\circ$ เทียบกับแนวตารางเส้นใยแก้ว และระบุใช้วัสดุเคลือบ Silane เกรด Anti-CAF Certified ตามมาตรฐาน IPC-4101/126
- **ค)** เพิ่มความหนาของแผ่นทองแดงเป็น 3 oz
- **ง)** ลดขนาดเส้นผ่านศูนย์กลางของรูเจาะลงเหลือ $0.10 \text{ mm}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> การป้องกัน CAF ต้องอาศัยการบูรณาการ 3 ปัจจัยร่วมกัน:  
> 1. **การลดความชันของสนามไฟฟ้า ($E = V/d$):** การขยายระยะห่างขอบผนังรู ($d$) ให้กว้างไม่น้อยกว่า $0.40 - 0.50 \text{ mm}$ สำหรับแรงดัน 48V จะช่วยลดความชันของสนามไฟฟ้ากระแสตรงลง ขัดขวางแรงผลักดันไอออนทองแดง  
> 2. **การทำลายแนวระนาบของท่อร้อยใยแก้ว (Fiber Orientation):** การวางรูเจาะเอียงทำมุม $45^\circ$ รับประกันว่ารูเจาะขั้วบวกและขั้วลบจะไม่อยู่บนมัดใยแก้วเดียวกัน บังคับให้กระแสเคมีต้องว่ายข้ามเนื้อเรซินที่หนาแน่น  
> 3. **วัสดุ Anti-CAF Substrate:** ใช้สารเคลือบไซเลนชนิดพิเศษที่สร้างพันธะโควาเลนต์ระหว่างแก้วกับเรซินอย่างเหนียวแน่น ป้องกันไม่ให้เกิดรอยแยกแบบ Micro-capillary เมื่อได้รับความชื้น

---

### ข้อที่ 2 (ทำไมบอร์ดที่ใช้วัสดุ Low-Tg จึงเกิด Barrel Cracking ได้ง่ายกว่า High-Tg?)
จากสมการความล้า Coffin-Manson เหตุใดบอร์ดที่ใช้วัสดุ FR-4 เกรดมาตรฐานที่มีจุดกลายเป็นแก้วต่ำ ($T_g \approx 130^\circ\text{C}$) จึงเกิดการแตกร้าวของกระบอก Via (Barrel Cracking) ในระหว่างกระบวนการบัดกรีไร้สารตะกั่ว ($260^\circ\text{C}$) ได้ง่ายกว่าบอร์ดที่ใช้วัสดุ High-$T_g$ ($T_g \ge 175^\circ\text{C}$) อย่างมหาศาล?

- **ก)** เพราะวัสดุ Low-Tg มีความหนาแน่นของเนื้อทองแดงน้อยกว่า
- **ข)** เพราะเมื่ออุณหภูมิพุ่งทะลุจุด $T_g$ อัตราการขยายตัวในแนวแกนดิ่ง ($CTE_z$) ของเรซินจะกระโดดสูงขึ้นถึง 5-6 เท่า (พุ่งแตะ $250 - 300 \text{ ppm/}^\circ\text{C}$) วัสดุที่มี $T_g$ ต่ำจะเข้าสู่สภาวะการขยายตัวรุนแรงนี้เป็นช่วงอุณหภูมิที่กว้างกว่ามาก ทำให้เกิดความเครียดพลาสติกสะสม ($\Delta \epsilon_p$) สูงลิ่ว ดึงกระบอกทองแดงจนฉีกขาด
- **ค)** เพราะสว่านเจาะจะทำงานได้ช้าลงบนวัสดุ Low-Tg
- **ง)** เพราะสารฟลักซ์จะกัดกร่อนวัสดุ Low-Tg จนละลาย

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในระหว่างกระบวนการบัดกรี Lead-Free Reflow อุณหภูมิจะขึ้นไปแตะจุดสูงสุดที่ประมาณ $260^\circ\text{C}$  
> - สำหรับวัสดุ **Low-$T_g$ ($130^\circ\text{C}$):** เรซินจะเข้าสู่สภาวะขยายตัวรวดเร็ว (Rubbery State: $CTE_z \approx 280 \text{ ppm/}^\circ\text{C}$) ตั้งแต่อุณหภูมิ $130^\circ\text{C}$ ไปจนถึง $260^\circ\text{C}$ (ช่วงอุณหภูมิวิกฤติต่างถึง $\Delta T = 130^\circ\text{C}$) ก่อให้เกิดการยืดตัวมหาศาล  
> - สำหรับวัสดุ **High-$T_g$ ($175^\circ\text{C}$):** เรซินจะคงอยู่ในสภาวะของแข็ง (Glassy State: $CTE_z \approx 40 \text{ ppm/}^\circ\text{C}$) จนถึง $175^\circ\text{C}$ และมีช่วงอุณหภูมิวิกฤติเหนือ $T_g$ เพียง $\Delta T = 85^\circ\text{C}$ เท่านั้น  
> ผลรวมของความเครียดพลาสติก ($\Delta \epsilon_p$) ในวัสดุ High-$T_g$ จึงต่ำกว่ามาก ช่วยยืดอายุความล้าของกระบอก Via ตามสมการ Coffin-Manson ได้มากกว่าเดิมหลายเท่าตัว

### ข้อที่ 3 (เกณฑ์การยอมรับในการทดสอบ Interconnect Stress Testing: IST ตาม IPC Class 3)
ในการทดสอบความเค้นของจุดเชื่อมต่อ Interconnect Stress Testing (IST) สำหรับการรับรองคุณภาพของ Via ในบอร์ดระดับ IPC-6012 Class 3 ค่าการเปลี่ยนแปลงของความต้านทานไฟฟ้ากระแสตรง ($\Delta R$) สูงสุดที่ยอมรับได้ตลอดการทดสอบ 500 รอบวัฏจักรความร้อนมีค่าเท่ากับข้อใด?

- **ก)** $\Delta R \le 5.0\%$
- **ข)** $\Delta R \le 25.0\%$
- **ค)** $\Delta R \le 50.0\%$
- **ง)** ตราบใดที่ยังไม่ขาดเป็น Open Circuit ถือว่าผ่านทั้งหมด

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ก)**  
> การทดสอบ IST ตามมาตรฐาน IPC-TM-650 2.6.26 ถือเป็นการทดสอบที่เข้มงวดที่สุดในวงการอุตสาหกรรม:  
> เครื่องมือจะป้อนกระแสไฟฟ้าเพื่อให้เกิดความร้อนแบบ Joule Heating ภายในกระบอก Via เอง พุ่งขึ้นแตะ $260^\circ\text{C}$ ในเวลาอันรวดเร็วเพื่อสร้างความเค้นเทอร์โมเมคานิกส์สูงสุด  
> หากกระบอกทองแดงเริ่มเกิดรอยแตกร้าวระดับจุลภาค (Micro-cracking) แม้เพียงเล็กน้อย ค่าความต้านทานระดับมิลลิโอห์มจะเริ่มกระเพื่อมสูงขึ้น  
> มาตรฐาน IPC Class 3 กำหนดเกณฑ์ผ่าน-ตกอย่างเด็ดขาดว่า: **ค่าความต้านทานต้องเปลี่ยนแปลงไม่เกิน $\Delta R \le 5.0\%$ ตลอด 500 รอบการทดสอบ** หากเกินกว่า $5\%$ จะถือว่าชิ้นงานสอบตกทันที เพื่อตัดความเสี่ยงที่จะเกิดความเสียหายในระหว่างการใช้งานจริง
