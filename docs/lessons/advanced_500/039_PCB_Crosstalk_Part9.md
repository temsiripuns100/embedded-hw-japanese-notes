## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

เมื่อความถี่ของสัญญาณดิจิทัลก้าวข้าม $10 \text{ GHz}$ ขึ้นสู่ย่านไมโครเวฟและมิลลิเมตรเวฟ สูตรคำนวณ 2D ทั่วไป (เช่น Polar SI9000 หรือ 2D BEM Solvers) จะไม่สามารถทำนายพฤติกรรมของสนามแม่เหล็กไฟฟ้าในจุดเปลี่ยนผ่านเชิงปริมาตร 3 มิติ (3D Transitions เช่น BGA Pinfields, Via Arrays, และ Connector Footprints) ได้อย่างแม่นยำอีกต่อไป 
วิศวกรระดับ Senior จึงต้องพึ่งพา **เครื่องจำลองสนามแม่เหล็กไฟฟ้า 3 มิติ (3D Full-Wave Electromagnetic Field Solvers)** เช่น Ansys HFSS, CST Studio Suite, และ Cadence Clarity 3D

อย่างไรก็ดี การรันการจำลอง 3D ไม่ใช่เพียงแค่การกดปุ่ม "Start Simulation" แต่ต้องอาศัยความเข้าใจอย่างลึกซึ้งใน **วิธีการเชิงตัวเลข (Numerical Methods)**, **การตั้งค่าพอร์ตกำเนิดคลื่น (Wave Port Sizing)**, **การลู่เข้าของตาข่ายคำนวณ (Mesh Convergence Criteria)**, และ **เทคนิคการขจัดส่วนต่อประสาน (De-embedding ตามมาตรฐาน IEEE 370)** เพื่อให้ไฟล์ S-Parameter (.sNp) มีความเป็นเหตุเป็นผล (Causality) และไม่ละเมิดกฎการอนุรักษ์พลังงาน (Passivity)

### 1.1 การเปรียบเทียบระเบียบวิธีเชิงตัวเลขใน 3D EM Solvers (FEM vs FDTD vs MoM)

ในวงการอุตสาหกรรม การเลือก Solver ให้เหมาะสมกับลักษณะงานโครงสร้างจะชี้ขาดความแม่นยำและเวลาในการคำนวณ:

| อัลกอริทึมเชิงตัวเลข | โปรแกรมชั้นนำ | โดเมนการคำนวณ | ลักษณะการแบ่ง Mesh | เหมาะสมกับโครงสร้างประเภทใด |
|---|---|---|---|---|
| **Finite Element Method (FEM)** | **Ansys HFSS**, Cadence Clarity | ความถี่ (Frequency Domain) | เตตราฮีดรอน 3 มิติ (Tetrahedral Meshing) | โครงสร้าง 3D ซับซ้อนสูง, Via Transition, Footprint, ขั้วต่อ RF |
| **Finite Integration / FDTD** | **CST Studio Suite** | เวลา (Time Domain) | กล่องสี่เหลี่ยมลูกบาศก์ (Hexahedral Grid) | โครงสร้างขนาดใหญ่, บอร์ดทั้งแผ่น, ตู้แคบิเน็ตโลหะ, การทดสอบ EMI/EMC |
| **Method of Moments (MoM / PEEC)** | **Ansys SIwave**, Keysight ADS | พื้นผิว (Boundary Element) | แผ่นสามเหลี่ยม 2.5D (Planar Meshing) | ลายวงจรแผ่นเรียบขนาดใหญ่, บัสขนาน DDR ทั้งบอร์ด (คำนวณเร็วมาก) |

1. **สมการ Helmholtz ในระเบียบวิธี FEM (Ansys HFSS):**  
   FEM แก้สมการคลื่นในรูปแบบสมการอนุพันธ์ย่อยในทุกจุดย่อยของตาข่ายเตตราฮีดรอน:

$$\nabla \times \left( \frac{1}{\mu_r} \nabla \times \vec{E} \right) - k_0^2 \epsilon_r \vec{E} = -j \omega \mu_0 \vec{J}_{source}$$

2. **เกณฑ์การลู่เข้าของ Adaptive Mesh (Adaptive Mesh Convergence):**  
   โปรแกรมจะเริ่มจำลองด้วยตาข่ายหยาบ จากนั้นทำการคำนวณค่า S-Parameter ซ้ำ แล้วเปรียบเทียบผลต่างของเมทริกซ์ S กับรอบก่อนหน้า ($\Delta S$):

$$\Delta S = \max_{i,j} |S_{ij}^{(N)} - S_{ij}^{(N-1)}|$$

- **เกณฑ์มาตรฐานอุตสาหกรรม:** กำหนด $\Delta S < 0.01$ (หรือ $0.02$) ต่อเนื่องกัน 2 รอบขึ้นไป เพื่อรับประกันว่าผลการคำนวณมีความแม่นยำสูงและไม่อ่อนไหวต่อความละเอียดของเมช

### 1.2 การตั้งค่า Wave Port vs Lumped Port และกฎขนาดของพอร์ต (Port Sizing Rules)

การกำหนดจุดป้อนสัญญาณ (Excitation Ports) ถือเป็นจุดผิดพลาดอันดับหนึ่งของผู้เริ่มต้นใช้งาน:

```
        Structure A: Incorrect Wave Port (Too Small)       Structure B: Correct Wave Port Sizing
       ┌────────────────────────┐ (Side PEC shorts fields!) ┌───────────────────────────────────────────┐
       │     ┌────────────┐     │                           │                                           │
       │     │ Trace (W)  │     │                           │              ┌────────────┐               │
       │     └─────┬──────┘     │                           │              │ Trace (W)  │               │
       │           │ H          │                           │              └─────┬──────┘               │
       └───────────┴────────────┘                           │                    │ H                    │
        Field lines touch boundary!                         └────────────────────┴──────────────────────┘
        (Artificial impedance shift)                        Width: 3W to 5W each side, Height: 4H to 5H
```

1. **Wave Port (導波管ポート):** จำลองเสมือนมีท่อนำคลื่นกึ่งอนันต์ (Semi-Infinite Transmission Line) ยื่นเชื่อมต่อเข้ามาที่หน้าตัดของบอร์ด
   - มีความแม่นยำสูงสุดเพราะโปรแกรมจะคำนวณโหมดของสนามแม่เหล็กไฟฟ้า (2D Quasi-TEM Mode Eigenmode Solution) ที่ตรงกับโครงสร้างจริง
   - **กฎการตั้งขนาดพอร์ต (Port Dimension Rules):**
     - ความกว้างพอร์ต: ต้องกว้างอย่างน้อย **$3 \times W$ ถึง $5 \times W$** ทั้งสองข้างของขอบสายส่ง
     - ความสูงพอร์ต: ต้องสูงอย่างน้อย **$4 \times H$ ถึง $5 \times H$** เหนือและใต้ระนาบอ้างอิง
     - **คำเตือน:** หากพอร์ตแคบเกินไป เส้นแรงสนามไฟฟ้าจะชนกับขอบขอบเขตตัวนำสมบูรณ์ (PEC Boundary) ของพอร์ต ทำให้อิมพีแดนซ์เพี้ยนและเกิดคลื่นสะท้อนเทียม!
2. **Lumped Port (集中定数ポート):** ป้อนสัญญาณระหว่างจุด 2 จุด (มักใช้ภายในบอร์ด เช่น เชื่อมต่อระหว่าง Signal Pad กับ Ground Via ที่อยู่ใกล้เคียง)
   - ข้อควรระวัง: เส้นลวดของพอร์ตจะมีความเหนี่ยวนำแฝง (Parasitic Inductance) กวนเข้ามาในผลลัพธ์ที่ความถี่สูงเกิน $10 \text{ GHz}$ จึงต้องใช้ร่วมกับเทคนิค De-embedding

### 1.3 การขจัดส่วนต่อประสานตามมาตรฐาน IEEE 370 (Fixture De-embedding: 2X-Thru & TRL)

ในการวัด S-Parameter ด้วยเครื่อง VNA จริงหรือการจำลองที่มีรอยต่อของสายนำสัญญาณ (Launch Traces / Test Fixtures):

```
       DUT (Device Under Test: Via Array / Connector)
    ┌──────────────┐     ┌───────────────────────────────────┐     ┌──────────────┐
    │ Left Fixture │ ──► │     Actual High-Speed Structure   │ ◄── │ Right Fixture│
    │  (Lead-in)   │     │        (De-embedded S-Matrix)     │     │  (Lead-out)  │
    └──────────────┘     └───────────────────────────────────┘     └──────────────┘
```

เพื่อขจัดผลกระทบของสายนำสัญญาณออกไป มาตรฐาน **IEEE 370 (Electrical Characterization of Printed Circuit Board and Related Interconnects)** กำหนดวิธีทดสอบและอัลกอริทึม:
1. **เทคนิค 2X-Thru De-embedding:**
   - ออกแบบลายวงจรคูปองทดสอบ "2X-Thru" ซึ่งมีความยาวเท่ากับความยาวของ Fixture ด้านซ้ายบวกกับด้านขวาต่อชนกันโดยตรง ($L_{total} = L_{left} + L_{right}$)
   - อัลกอริทึม IEEE 370 จะทำการแยกครึ่ง (Bisect) เมทริกซ์ S-Parameter ในโดเมนเวลาโดยใช้ Time-Domain Gating และขจัดสายนำสัญญาณออกจาก DUT ได้อย่างแม่นยำ
2. **การตรวจสอบความถูกต้องของไฟล์ S-Parameter (Quality Verification):**
   - **การอนุรักษ์พลังงาน (Passivity Check):** พลังงานคลื่นที่กระเจิงออกมาต้องไม่มากกว่าพลังงานคลื่นที่ป้อนเข้าไป ($|S_{11}|^2 + |S_{21}|^2 \le 1$)
   - **ความเป็นเหตุเป็นผล (Causality Check via Kramers-Kronig Relations):** สัญญาณเอาต์พุตจะต้องไม่ปรากฏขึ้นก่อนที่สัญญาณอินพุตจะเดินทางไปถึง (No Non-Causal Pre-cursor Ringing)

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** ผลการจำลองช่องสัญญาณ 28 GHz mmWave ในโปรแกรม Circuit Simulator (Keysight ADS / Cadence Virtuoso) เกิดอาการระบบไม่ลู่เข้า (Convergence Failed) และเมื่อรัน Transient Simulation เกิดคลื่นสั่นพ้องระเบิด (Unstable Non-Physical Ringing) ที่มีแรงดันพุ่งสูงเกิน $10 \text{ V}$ 
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **ไฟล์ S-Parameter ขาดความเป็นเหตุเป็นผล (Causality Violation):** วิศวกรนำโมเดล 3D เข้า HFSS และกำหนดขอบเขต Wave Port แคบเกินไป ทำให้เส้นแรงสนามไฟฟ้าชนขอบพอร์ต เกิดรอยสะท้อนเทียม (Artificial Anti-Resonance) ที่ความถี่ $26.5 \text{ GHz}$
2. **เมทริกซ์ละเมิด Passivity:** ค่า $|S_{21}|$ ที่จุดรอยตัดพุ่งสูงแตะ $+0.2 \text{ dB}$ ($> 1.0$) เสมือนวงจรกลายเป็นตัวขยายสัญญาณ (Active Gain) วงจรจำลองจึงมองเห็นเป็น Negative Resistance และระเบิดค่าแรงดันในทันที

---

### ขั้นตอนการตั้งค่า 3D Simulation และสกัด Crosstalk Matrix สไตล์ Senior (検図チェックリスト):
1. **การตรวจสอบขนาดของ Wave Port ก่อนรันการจำลอง:**
   - ตรวจสอบในหน้าจอแสดงผลสนามไฟฟ้าพอร์ต (Port Field Display):
     - ดูเส้นแรงสนามไฟฟ้า (E-field vectors): หากเส้นแรงพุ่งชนขอบข้างหรือขอบบนของพอร์ต แสดงว่า **พอร์ตเล็กเกินไป**
     - ขยายกรอบพอร์ตให้ครอบคลุมระนาบกราวด์ทั้งซ้าย-ขวาอย่างน้อย $4W$ และสูงกว่าผิวหน้าสายส่งอย่างน้อย $5H$ จนกระทั่งเส้นแรงสนามไฟฟ้าลู่เข้าหาศูนย์ที่ขอบพอร์ตอย่างสมบูรณ์
2. **การตั้งค่าความถี่สูงสุด (Solution Frequency) และ Frequency Sweep:**
   - กำหนดค่า Single Solution Frequency ไว้ที่ **ความถี่สูงสุดของช่วงการจำลอง ($f_{max}$)** เสมอ (เช่น หากต้องการผลลัพธ์ $0 - 40 \text{ GHz}$ ให้ตั้งจุดแก้สมการไว้ที่ $40 \text{ GHz}$)
   - สาเหตุ: ที่ความถี่สูงสุด ตาข่ายเมชเตตราฮีดรอนจะถูกซอยย่อยจนละเอียดที่สุดตามความยาวคลื่น ($\lambda_{min}$) เมื่อนำเมชนี้ไปกวาดความถี่ต่ำลงมา ผลการคำนวณจะแม่นยำตลอดทั้งย่าน
   - เลือก Sweep Type เป็น **Interpolating Sweep** พร้อมตั้งค่าพิกัดความผิดพลาด (Error Tolerance) ต่ำกว่า $0.5\%$
3. **การประเมินคุณภาพไฟล์ Touchstone (.sNp) ตามมาตรฐาน IEEE 370:**
   - ก่อนนำไฟล์ S-Parameter ไปใช้งาน ให้เปิดผ่านโปรแกรม IEEE 370 Quality Checker หรือ Keysight ADS S-Parameter Checker:
     - ตรวจสอบ Passivity: ค่า Eigenvalue ของเมทริกซ์ $([I] - [S]^\dagger [S])$ ต้องเป็นบวกเสมอ
     - ตรวจสอบ Causality: ผลการแปลง Hilbert Transform ของส่วนจริงและส่วนจินตภาพต้องสอดคล้องตามสมการ Kramers-Kronig

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「HFSSによるBGA部差動ビア遷移モデル（40GHz帯）において、Wave Portの開口寸法が横幅2W、高さ2Hと極めて狭小に設定されています。高周波電界ベクトルがポート境界（完全導体PEC壁）に激しく衝突しており、境界条件の歪みから28GHz近傍で非物理的なゲイン（S21 > 0dB：受動性侵害）および因果律破綻（Causality Error）が発生しています。ポートサイズを横幅5W以上、高さ5H以上へ再定義し、適応メッシュ収束判定をΔS≦0.01（2連続パス）で再計算してください。」  
> *(ในการจำลอง HFSS สำหรับเวีย BGA ที่ 40GHz มีการตั้งขนาด Wave Port แคบเกินไปเพียง 2Wx2H ทำให้เวกเตอร์สนามไฟฟ้าชนขอบผนัง PEC เกิด Gain ที่ผิดธรรมชาติ S21>0dB และละเมิด Causality กรุณาขยายขนาดพอร์ตเป็นอย่างน้อย 5Wx5H และตั้งเกณฑ์ลู่เข้าของเมชเป็น Delta S <= 0.01 ติดต่อกัน 2 รอบ)*

> **指摘事項 2:**  
> 「28Gbps SerDesチャネルの実測評価において、テストフィクスチャ（SMAコネクタおよび引き出し配線）のディエンベディングが実施されていないため、DUT真のクロストーク特性が隠蔽されています。IEEE 370規格に準拠した2X-Thruテストクーポンを用いてフィクスチャ特性を高精度に減算（ディエンベディング）し、純粋なBGAブレークアウト部のSパラメータを再抽出してください。」  
> *(ในการวัด SerDes 28Gbps ไม่ได้ทำ De-embedding สายนำสัญญาณและขั้วต่อ SMA ทำให้คุณลักษณะ Crosstalk ที่แท้จริงของอุปกรณ์ถูกบดบัง กรุณาใช้คูปอง 2X-Thru ตามมาตรฐาน IEEE 370 ทำการลบผลกระทบของ Fixture ออกอย่างแม่นยำ แล้วสกัดเมทริกซ์ S-Parameter เฉพาะของโซน BGA ออกมาใหม่)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (หลักการลู่เข้าของ Adaptive Meshing ใน Ansys HFSS)
ในโปรแกรมจำลองสนามแม่เหล็กไฟฟ้า 3 มิติ Ansys HFSS เมื่อตั้งค่าเกณฑ์การลู่เข้าของตาข่ายคำนวณ (Mesh Convergence Criterion) เป็น $\Delta S = 0.01$ มีความหมายทางคณิตศาสตร์และวิศวกรรมอย่างไร?

- **ก)** ตาข่ายเตตราฮีดรอนจะถูกเพิ่มขึ้น $1\%$ ในแต่ละรอบการคำนวณ
- **ข)** โปรแกรมจะคำนวณขนาดของเมทริกซ์ S-Parameter ในแต่ละรอบ และจะถือว่าการคำนวณลู่เข้าสำเร็จก็ต่อเมื่อ ผลต่างสูงสุดของค่าสัมบูรณ์ของอิลิเมนต์ทุกตัวในเมทริกซ์ S ระหว่างรอบปัจจุบัน ($N$) กับรอบก่อนหน้า ($N-1$) มีค่าน้อยกว่า $0.01$ ($\max |S_{ij}^{(N)} - S_{ij}^{(N-1)}| < 0.01$)
- **ค)** พลังงานความร้อนในโครงสร้างจะลดลง $1\%$
- **ง)** อิมพีแดนซ์ของสายส่งจะมีความผิดพลาดไม่เกิน $0.01 \ \Omega$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในระเบียบวิธี Adaptive Mesh Refinement ของ HFSS:  
> โปรแกรมจะเริ่มจำลองโครงสร้างด้วยตาข่ายหยาบเพื่อหาเมทริกซ์ S จากนั้นโปรแกรมจะทำการแบ่งย่อยตาข่ายเตตราฮีดรอน (Refining Tetrahedra) ในบริเวณที่มีความหนาแน่นของสนามแม่เหล็กไฟฟ้าหรือความผิดพลาดสูงขึ้นประมาณ $30\%$ แล้วทำการแก้สมการเพื่อหาเมทริกซ์ S ชุดใหม่  
> เกณฑ์การตัดสิน $\Delta S = 0.01$ หมายถึง:  
> ผลต่างของอิลิเมนต์ทุกตัวในเมทริกซ์ S-Parameter ระหว่างสองรอบการคำนวณล่าสุด จะต้องมีค่าน้อยกว่า $0.01$ (หรือมีผลต่างน้อยกว่า $1\%$ บนสมิธชาร์ต)  
> เมื่อเงื่อนไขนี้บรรลุผล แสดงว่าความละเอียดของตาข่ายเพียงพอแล้วที่จะให้คำตอบที่แท้จริงของสมการคลื่น Maxwell โดยการเพิ่มตาข่ายต่อไปจะไม่ทำให้ผลการคำนวณเปลี่ยนแปลงอย่างมีนัยสำคัญอีก

### ข้อที่ 2 (ทำไมไฟล์ S-Parameter ที่ละเมิดกฎ Causality จึงสร้างหายนะใน Transient Simulation?)
หากไฟล์ S-Parameter (.sNp) ที่ได้จากการจำลอง 3D ละเมิดกฎความเป็นเหตุเป็นผล (Causality Violation) เมื่อนำไปแปลงเข้าสู่วงจรจำลองในโดเมนเวลา (Transient SPICE Simulation) จะเกิดพฤติกรรมผิดปกติข้อใด?

- **ก)** แรงดันเอาต์พุตจะลดลงเป็นศูนย์ตลอดเวลา
- **ข)** เกิดปรากฏการณ์สัญญาณตอบสนองล่วงหน้า (Non-Causal Pre-cursor Ringing) ที่แรงดันกระเพื่อมขึ้นมาก่อนที่พัลส์สัญญาณอินพุตจะถูกส่งเข้ามาในระบบ นำไปสู่วงจรจำลองที่ไม่เสถียร (Divergence / Exploding Voltages)
- **ค)** ตัวเก็บประจุในวงจรจะหยุดการทำงาน
- **ง)** สัญญาณนาฬิกาจะเปลี่ยนความถี่เป็น 2 เท่า

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ตามกฎฟิสิกส์พื้นฐานของเอกภพ (Causality Law): ผลลัพธ์จะต้องไม่เกิดขึ้นก่อนต้นเหตุ (Output cannot precede Input)  
> ในการแปลงไฟล์ S-Parameter จากโดเมนความถี่กลับมาเป็นโดเมนเวลา (Inverse Fast Fourier Transform: IFFT หรือ Rational Vector Fitting):  
> หากเฟสและขนาดของ S-Parameter ในโดเมนความถี่ไม่เป็นไปตามความสัมพันธ์ของ Kramers-Kronig (ซึ่งมักเกิดจากการตัดขอบเขตพอร์ต Wave Port เล็กเกินไป หรือช่วงความถี่แคบเกินไป):  
> ฟังก์ชันตอบสนองอิมพัลส์ (Impulse Response) ในโดเมนเวลาจะมีพลังงานคลื่นปรากฏขึ้นที่เวลาติดลบ ($t < 0$) เรียกว่า **Pre-cursor Energy**  
> ในวงจร Transient Solver วงจรจะมองเห็นเสมือนมีแหล่งจ่ายพลังงานลึกลับป้อนเข้ามาล่วงหน้า ก่อให้เกิดลูปการป้อนกลับบวก (Positive Feedback Ringing) ที่ทำให้แรงดันขยายตัวอย่างไม่มีที่สิ้นสุดจนระบบจำลองระเบิด (Blow up)

### ข้อที่ 3 (ความเหนือกว่าของมาตรฐาน IEEE 370 2X-Thru เทียบกับเทคนิค 1X-Reflection แบบเก่า)
เหตุใดมาตรฐาน IEEE 370 จึงกำหนดให้ใช้เทคนิค **2X-Thru De-embedding** ในการขจัดส่วนต่อประสานของบอร์ดวงจรพิมพ์ แทนที่จะใช้เทคนิค 1X Open/Short Reflection แบบดั้งเดิม?

- **ก)** เพราะ 2X-Thru ใช้พื้นที่บนแผงบอร์ดน้อยกว่า
- **ข)** เพราะเทคนิค 1X Open/Short มีความไวอย่างยิ่งยวดต่อความจุแฝงที่ปลายเปิด (Fringing Capacitance at Open Tip) ซึ่งไม่สามารถคาดเดาได้ที่ความถี่สูงเกิน 10 GHz ขณะที่ 2X-Thru ใช้วิธีต่อเชื่อม Fixture ทั้งสองข้างเข้าหากันโดยตรง ทำให้ขจัดผลกระทบของสนามขอบและสะท้อนคุณสมบัติการส่งผ่านที่แท้จริงของ Fixture ได้อย่างแม่นยำ
- **ค)** เพราะ 2X-Thru ไม่จำเป็นต้องใช้เครื่องมือวัด VNA
- **ง)** เพราะเทคนิค 1X สามารถวัดได้เฉพาะสัญญาณกระแสตรงเท่านั้น

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในอดีต วิศวกรพยายามใช้คูปอง 1X Open (ปลายเปิด) หรือ 1X Short (ปลายลัดวงจร) เพื่อวัดและขจัด Fixture  
> ทว่าที่ความถี่สูงระดับ Multi-Gigabit (เช่น $20 - 50 \text{ GHz}$):  
> ปลายเปิดของ 1X Open ไม่ใช่การเปิดวงจรในอุดมคติ แต่มีสนามไฟฟ้าแผ่ออกสู่อากาศและไดอิเล็กทริก (Fringing Open-End Capacitance) ซึ่งมีค่าแปรผันตามความถี่และคลาดเคลื่อนได้ง่ายมาก  
> มาตรฐาน IEEE 370 จึงสร้างนวัตกรรม **2X-Thru Method**:  
> โดยการนำ Fixture ฝั่งซ้ายและขวาที่มีโครงสร้างสมมาตรมาต่อชนกันโดยตรงเป็นสายส่งเส้นเดียวที่ต่อเนื่อง (Thru Line)  
> เมื่อไม่มีปลายเปิด ค่า $S_{11}$ และ $S_{21}$ ที่วัดได้จะสะท้อนคุณสมบัติการนำส่งคลื่นที่แท้จริง จากนั้นใช้อัลกอริทึมแยกครึ่ง (Bisecting Algorithm) ถอดสมการแยก Fixture แต่ละฝั่งออกจากกันได้อย่างสมบูรณ์แบบโดยปราศจากความคลาดเคลื่อนจากขอบปลายเปิด
