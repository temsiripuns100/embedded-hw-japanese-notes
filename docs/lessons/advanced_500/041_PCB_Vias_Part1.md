*(プリント基板のビア構造 - 製造プロセス・アスペクト比・アニュラーリングとスローイングパワー)*

## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการออกแบบบอร์ด Multi-layer ความหนาแน่นสูง รูเจาะเปลี่ยนเลเยอร์ (Via) ไม่ได้เป็นเพียงแค่ "ท่อเชื่อมต่อทางไฟฟ้าธรรมดา" 
แต่เป็นโครงสร้างทางกลและเคมีที่ซับซ้อนที่สุดในกระบวนการผลิต PCB ความเข้าใจที่ถูกต้องเกี่ยวกับ **สถาปัตยกรรมของ Via แต่ละประเภท (PTH, Blind, Buried, Microvia)**, **ขีดจำกัดของอัตราส่วนความลึกต่อเส้นผ่านศูนย์กลาง (Aspect Ratio)**, และ **ความสามารถในการชุบเคลือบทองแดงในแนวดิ่ง (Plating Throwing Power)** ถือเป็นความรู้พื้นฐานที่ชี้วัดความน่าเชื่อถือ (Reliability) ของผลิตภัณฑ์ในระยะยาว

---

### 1.1 สถาปัตยกรรมทางกายภาพของ Via 5 ประเภทหลัก

```
        Layer 1 (Top)      ──┬───────┬──────┬───────┬──────────────┬──────────────
                             │  PTH  │Blind │       │Stacked μVia  │Staggered μVia
        Layer 2 (Inner 1)  ──┼───────┼──────┤Buried ├──────┬───────┴──────┬───────
                             │       │      │ Via   │      │              │       
        Layer 3 (Inner 2)  ──┼───────┼──────┴───────┤      │              └───────
                             │       │              │      │                      
        Layer 4 (Bottom)   ──┴───────┴──────────────┴──────┴──────────────────────
```

1. **Plated Through-Hole Via (PTH / 貫通ビア):** เจาะทะลุจากเลเยอร์บนสุดถึงล่างสุดด้วยสว่านกลไก (Mechanical Drill) เป็นโครงสร้างที่มีต้นทุนต่ำที่สุด แต่กินพื้นที่ทุกเลเยอร์และก่อให้เกิดปัญหา Via Stub หากใช้งานกับสัญญาณความถี่สูง
2. **Blind Via (ブラインドビア / 盲孔):** เจาะเชื่อมระหว่างเลเยอร์ภายนอก (Top หรือ Bottom) ไปยังเลเยอร์ภายในเพียงบางชั้น โดยมองไม่เห็นทะลุอีกด้านหนึ่ง
3. **Buried Via (ベリードビア / 埋め込み孔):** เจาะเชื่อมเฉพาะระหว่างเลเยอร์ภายในด้วยกัน โดยถูกอบอัด (Laminated) ฝังมิดอยู่ข้างในเนื้อบอร์ด ไม่ปรากฏบนผิวนอก
4. **Stacked Microvia (スタックマイクロビア):** รูเจาะเลเซอร์ขนาดจิ๋ว (Laser Microvia) วางซ้อนทับกันตรงๆ ในแนวดิ่ง โดยต้องเติมเนื้อทองแดงเต็มรู (Copper Filled) เพื่อให้เป็นฐานรองรับเลเยอร์ถัดไป
5. **Staggered Microvia (スタガードマイクロビア):** รูเจาะเลเซอร์จัดวางแบบเยื้องศูนย์ (สลับฟันปลา) โดยมีแผ่นทองแดงคั่นกลาง ซึ่งมีความเค้นทางกล (Thermomechanical Stress) ต่ำกว่าแบบ Stacked อย่างมีนัยสำคัญ

### 1.2 ทฤษฎี Aspect Ratio (アスペクト比) และข้อจำกัดด้าน Plating Throwing Power

หนึ่งในตัวแปรวิกฤตที่สุดที่กำหนดความสำเร็จในการผลิตบอร์ดคือ **Aspect Ratio ($AR$)**:

$$AR = \frac{\text{Board Thickness } (H_{board})}{\text{Drilled Hole Diameter } (D_{drill})}$$

หรือสำหรับ Microvia ในแต่ละชั้น:

$$AR_{\mu via} = \frac{\text{Dielectric Thickness } (H_{layer})}{\text{Laser Drill Diameter } (D_{laser})}$$

```
                Top Surface Pad (Thickness t_top)
             ┌──────────────────┐      ┌──────────────────┐
             │                  │      │                  │
             │     ┌────────────┘  D   └────────────┐     │
             │     │                                │     │  ▲
             │     │ ◄── t_mid (Mid-barrel copper) ─│     │  │
             │     │                                │     │  │ Board Thickness H
             │     │                                │     │  │ (e.g. 2.4 mm)
             │     │                                │     │  │
             │     └────────────┐      ┌────────────┘     │  ▼
             │                  │      │                  │
             └──────────────────┴──────┴──────────────────┴
                Bottom Surface Pad
```

1. **ปรากฏการณ์ Throwing Power ของอ่างชุบเคมีไฟฟ้า (Electroplating Throwing Power):**
   - ในกระบวนการชุบทองแดงด้วยไฟฟ้า (Electrolytic Copper Plating) สารละลายคอปเปอร์ซัลเฟตจะต้องไหลเวียนเข้าไปในรูกระบอก Via
   - ที่บริเวณปากรูผิวนอก เส้นแรงสนามไฟฟ้าและกระแสน้ำยาเคมีจะมีความหนาแน่นสูงที่สุด ทำให้ทองแดงพอกตัวได้หนา ($t_{top} \ge 30 - 35 \ \mu\text{m}$)
   - ที่บริเวณกึ่งกลางกระบอกรูเจาะ ($H/2$) การไหลเวียนของไอออนทองแดงจะถูกจำกัดจากความฝืด (Diffusion Limited) ทำให้เนื้อทองแดงที่ชุบติดมีความบางกว่าผิวหน้ามาก:

$$\text{Throwing Power (\%)} = \frac{t_{mid}}{t_{top}} \times 100\%$$

2. **ขีดจำกัด Aspect Ratio ในอุตสาหกรรมปัจจุบัน:**
   - **Mechanical Drill มาตรฐานทั่วไป:** $AR \le 8:1$ (โรงงานทั่วไปชุบได้ $t_{mid} \ge 20 \ \mu\text{m}$ อย่างสม่ำเสมอ)
   - **Advanced High-Aspect Ratio Plating:** $AR = 10:1$ ถึง $12:1$ (ต้องใช้เคมีภัณฑ์ขั้นสูงและการพ่นน้ำยาแบบแรงดัน Pulse Plating)
   - **ขีดจำกัดอันตราย ($AR > 12:1$):** ทองแดงกึ่งกลางรูกระบอกจะบางเฉียบต่ำกว่า $12 \ \mu\text{m}$ ส่งผลให้เกิดการขาดแตกร้าวจากความเค้นอุณหภูมิ (Barrel Cracking) ในขั้นตอนบัดกรี Reflow ทันที
   - **Laser Microvia (HDI):** กำหนดอย่างเคร่งครัดตาม IPC-2226 ว่า **$AR_{\mu via} \le 1:1$ (แนะนำ $0.75:1$)** หากเจาะลึกเกินกว่าเส้นผ่านศูนย์กลาง รูเลเซอร์จะกลายเป็นหลุมลึกที่น้ำยาชุบทองแดงไม่สามารถเติมเต็ม (Voiding) ได้

### 1.3 ทฤษฎี Annular Ring และการควบคุม Teardrop ตามมาตรฐาน IPC-6012

**Annular Ring (アニュラーリング / ランド幅)** คือความกว้างของเนื้อทองแดงของ Pad ที่ล้อมรอบรูกระบอกเจาะ:

$$AR_{nominal} = \frac{D_{pad} - D_{drill}}{2}$$

ในกระบวนการผลิตจริง เครื่องเจาะรู CNC และฟิล์มโฟโต้มาสก์จะมีความคลาดเคลื่อนเชิงตำแหน่ง (Layer-to-Layer Misregistration $\pm 35 - 50 \ \mu\text{m}$) ส่งผลให้รูเจาะเบี่ยงออกจากศูนย์กลางของ Pad:

```
        Ideal Centered Via                      Misregistered Via with Breakout (外れ)
         ┌───────────────┐                             ┌───────────────┐
         │     Pad       │                             │     Pad       │
         │   ┌───────┐   │                             │         ┌─────┴─┐  ◄── Breakout (Tangency)
         │   │ Hole  │   │                             │         │ Hole  │
         │   └───────┘   │                             │         └─────┬─┘
         │               │                             │   AR_min      │
         └───────────────┘                             └───────────────┘
```

**เกณฑ์การตรวจรับตามมาตรฐาน IPC-6012:**
- **Class 2 (Dedicated Service Electronic Products):** ยอมรับการเจาะรูหลุดขอบ Pad (Breakout) ได้สูงสุดไม่เกิน $90^\circ$ ของเส้นรอบวง โดยต้องมีเนื้อทองแดงเหลืออยู่ที่รอยเชื่อมต่อกับลายวงจรไม่น้อยกว่า $50 \ \mu\text{m}$
- **Class 3 (High Reliability / Aerospace / Medical):** **ห้ามเกิด Breakout เด็ดขาด (Zero Breakout Allowed)** โดยต้องมีเนื้อทองแดงขั้นต่ำรอบรูเจาะภายใน ($Internal \ AR_{min} \ge 25 \ \mu\text{m}$) และภายนอก ($External \ AR_{min} \ge 50 \ \mu\text{m}$)

**เทคนิคการเสริม Teardrop (หยดน้ำตา):**  
เพื่อป้องกันไม่ให้รูเจาะตัดขาดรอยต่อระหว่าง Pad กับลายวงจร (Conductor-to-Pad Junction Severing) วิศวกรต้องเปิดใช้ฟังก์ชัน **Teardrop (ティアドロップ)** ขยายเนื้อทองแดงตรงทางแยกเสมอ

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** เมนบอร์ดเซิร์ฟเวอร์ความหนา $2.8 \text{ mm}$ (16 เลเยอร์) ผ่านการทดสอบฟังก์ชันไฟฟ้าขั้นต้น (ICT) แต่เมื่อนำไปผ่านเตาอบบัดกรี Lead-Free Wave Soldering อุณหภูมิ $260^\circ\text{C}$ พบว่าเกิดอาการวงจรเปิด (Open Circuit) ที่รูเจาะสัญญาณความเร็วสูงคิดเป็นอัตราความล้มเหลวสูงถึง **$8.5\%$**
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **Aspect Ratio สูงเกินพิกัดโรงงาน ($AR = 14:1$):** วิศวกรออกแบบเลือกใช้สว่านเจาะขนาดรู $0.20 \text{ mm} \ (8 \text{ mil})$ บนบอร์ดหนา $2.8 \text{ mm}$ ทำให้มีสัดส่วน $AR = 2.8 / 0.20 = 14:1$
2. **Throwing Power ตกต่ำเหลือ $35\%$:** น้ำยาชุบเคมีไม่สามารถหมุนเวียนเข้าถึงกึ่งกลางบอร์ด ส่งผลให้ความหนาทองแดงบริเวณกึ่งกลางกระบอก (Mid-barrel Copper Thickness) หนาเพียง **$9.5 \ \mu\text{m}$** (สเปก IPC Class 3 บังคับ $\ge 20 \ \mu\text{m}$)
3. **การแตกหักจาก Z-axis Thermal Expansion:** เมื่อเข้าเตาอบ $260^\circ\text{C}$ เนื้อฉนวน FR-4 ขยายตัวตามแนวแกน Z สูงกว่าทองแดงถึง 4 เท่า ดึงรั้งจนกระบอกทองแดงที่บางเฉียบขาดสะบั้นออกจากกัน

---

### ขั้นตอนการคำนวณและกำหนดสเปก Via สไตล์ Senior (検図チェックリスト):
1. **การคุม Aspect Ratio ให้อยู่ในโซนปลอดภัยของการผลิต:**
   - คำนวณความหนาบอร์ดรวม ($H_{board}$):
     $$D_{drill,min} \ge \frac{H_{board}}{AR_{safe}} = \frac{H_{board}}{10} \quad (\text{สำหรับโรงงานมาตรฐาน: } \frac{H_{board}}{8})$$
   - หากบอร์ดหนา $2.4 \text{ mm}$ รูเจาะสว่านเล็กสุดที่ปลอดภัยคือ $D_{drill} \ge 0.25 \text{ mm} \ (10 \text{ mil})$ ไม่ควรดันทุรังใช้ $0.15 \text{ mm}$ โดยไม่จำเป็น
2. **การระบุสเปกความหนาทองแดงในกระบอก Via (Plating Specification):**
   - ระบุใน Fabrication Drawing อย่างชัดเจน:
     > *"Plated Through-Hole (PTH) barrel copper thickness MUST meet IPC-6012 Class 3 requirements: Average thickness >= 25 um (1.0 mil), minimum individual point thickness >= 20 um (0.8 mil)."*
3. **การออกแบบ Pad ให้สอดคล้องกับขนาดสว่านเจาะ (Drill-to-Pad Ratio):**
   - กำหนดขนาด Pad ให้มี Annular Ring กว้างพอเพื่อรองรับความคลาดเคลื่อน:
     $$D_{pad} = D_{drill} + 0.25 \text{ mm} \ (10 \text{ mil}) \quad [\text{สำหรับ Inner Layers}]$$
     $$D_{pad} = D_{drill} + 0.30 \text{ mm} \ (12 \text{ mil}) \quad [\text{สำหรับ Outer Layers}]$$
   - สั่งเปิดฟังก์ชัน Teardrop บนทุก Via อัตโนมัติในขั้นตอน CAM เสมอ

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「板厚2.8mmの高多層基板において、内層信号ビアのドリル径がφ0.20mm（アスペクト比14:1）で設計されています。製造工場の標準めっき能力（スローイングパワー）を考慮すると、バレル中央部の銅めっき厚が10μm以下まで薄肉化し、鉛フリーリフロー時（260℃）の基板Z軸熱膨張（CTEミスマッチ）に耐えきれずバレルクラック断線に至る重大リスクがあります。信号ビア径をφ0.28mm以上（アスペクト比10:1以下）へ拡大するか、高アスペクト比対応のパルスめっきラインを必須製造条件として指定してください。」  
> *(บนบอร์ดหนา 2.8mm มีการใช้ขนาดสว่าน 0.20mm ทำให้ Aspect Ratio สูงถึง 14:1 ด้วยกำลังชุบของโรงงาน เนื้อทองแดงกึ่งกลางจะบางต่ำกว่า 10um เสี่ยงต่อการเกิด Barrel Crack จากการขยายตัวแกน Z ในเตาอบ 260°C ขอสั่งให้ขยายขนาดรูเป็น 0.28mm ขึ้นไป (AR<=10:1) หรือบังคับใช้สายการผลิต Pulse Plating ขั้นสูง)*

> **指摘事項 2:**  
> 「車載ECU向け基板（IPC Class 3適用）において、内層ビアパッド寸法がドリル径＋0.15mm（片側アニュラーリング0.075mm）と極小に設定されています。積層ズレ公差（±0.05mm）およびドリル位置精度を勘案すると、内層アニュラーリング規格（最薄部25μm以上、外れ禁止）を割り込む危険性が極めて高いです。パッド径をドリル径＋0.25mmへ拡大し、全ビア根元にティアドロップ（補強パターン）を付加してください。」  
> *(บนบอร์ด ECU ยานยนต์ตาม IPC Class 3 ขนาด Pad ในชั้นในตั้งไว้ใหญ่กว่ารูเจาะเพียง 0.15mm ทำให้เสี่ยงต่อการหลุดสเปก Annular Ring (ห้ามหลุดขอบ และต้องเหลือเนื้อทองแดงอย่างน้อย 25um) จากความคลาดเคลื่อนในการเจาะ กรุณาขยายขนาด Pad เป็น Drill+0.25mm พร้อมใส่ Teardrop เสริมทุกจุด)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Aspect Ratio และความเสี่ยงของกระบอก Via)
โรงงานผลิต PCB มีขีดจำกัดความสามารถของอ่างชุบเคมีไฟฟ้ามาตรฐาน โดยรับประกันความหนาทองแดงในกระบอก Via ได้สม่ำเสมอตลอดความลึก ($t_{mid} \ge 20 \ \mu\text{m}$) ที่ค่า Aspect Ratio ไม่เกิน $AR \le 9:1$ หากวิศวกรต้องออกแบบบอร์ดอุตสาหกรรมความหนา $H_{board} = 2.25 \text{ mm}$ ถามว่าขนาดรูเจาะสว่านขั้นต่ำสุด ($D_{drill,min}$) ที่ยอมรับได้มีค่าเท่ากับข้อใด?

- **ก)** $D_{drill,min} = 0.15 \text{ mm} \ (6 \text{ mil})$
- **ข)** $D_{drill,min} = 0.25 \text{ mm} \ (10 \text{ mil})$
- **ค)** $D_{drill,min} = 0.35 \text{ mm} \ (14 \text{ mil})$
- **ง)** $D_{drill,min} = 0.10 \text{ mm} \ (4 \text{ mil})$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> จากนิยามของ Aspect Ratio:  
> $$AR = \frac{H_{board}}{D_{drill}} \le 9.0$$  
> คำนวณหาขนาดเส้นผ่านศูนย์กลางรูเจาะขั้นต่ำสุด ($D_{drill,min}$):  
> $$D_{drill,min} \ge \frac{H_{board}}{AR_{limit}} = \frac{2.25 \text{ mm}}{9.0} = \mathbf{0.25 \text{ mm} \ (10 \text{ mil})}$$  
> หากวิศวกรเลือกใช้รูเจาะที่เล็กกว่า $0.25 \text{ mm}$ เช่น $0.20 \text{ mm}$ ($AR = 11.25:1$) กระบวนการชุบจะไม่สามารถผลักไอออนทองแดงเข้าไปสะสมที่กึ่งกลางรูได้ตามเกณฑ์ ส่งผลให้ความหนาทองแดงกึ่งกลางบางเกินไปและเสี่ยงต่อการเกิด Barrel Cracking ระหว่างการประกอบ

---

### ข้อที่ 2 (ทำไม Staggered Microvia จึงมีความน่าเชื่อถือทางกลสูงกว่า Stacked Microvia?)
ในบอร์ด HDI (High Density Interconnect) ระดับไฮเอนด์ เหตุใดการจัดวาง Microvia แบบเยื้องศูนย์ (Staggered Microvias) จึงมีอัตราความน่าเชื่อถือต่อการทดสอบวัฏจักรอุณหภูมิ (Thermal Cycling Test: $-40^\circ\text{C}$ ถึง $+125^\circ\text{C}$) สูงกว่าการจัดวางแบบซ้อนทับกันตรงๆ (Stacked Microvias) อย่างมีนัยสำคัญ?

- **ก)** เพราะ Staggered Microvia มีต้นทุนค่าเจาะเลเซอร์ที่แพงกว่า
- **ข)** เพราะ Stacked Microvia มีรอยต่อระหว่างเนื้อทองแดงของแต่ละชั้นวางซ้อนกันเป็นแท่งยาวตรงในแนวดิ่ง ความเค้นจากการขยายตัวของเรซินในแนวแกน Z จะไปรวมศูนย์อยู่ที่รอยต่อระหว่าง Microvia เกิดการแยกตัว (Interface Separation / Cracking) ขณะที่ Staggered มีเนื้อเรซินคั่นช่วยกระจายและดูดซับความเค้น
- **ค)** เพราะ Stacked Microvia มีสนามแม่เหล็กไฟฟ้าเหนี่ยวนำสูงกว่า
- **ง)** เพราะ Staggered Microvia ไม่จำเป็นต้องชุบทองแดงในรู

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ปัญหาความล้มเหลวของ Stacked Microvia เป็นประเด็นวิจัยระดับโลกที่มีการประกาศเตือนใน IPC-WP-023:  
> เมื่อ Microvia ถูกวางซ้อนทับกันตรงๆ 3-4 ชั้น (เช่น 1-2, 2-3, 3-4): รอยเชื่อมระหว่างก้นหลุมของ Microvia ด้านบนกับหัว Pad ของ Microvia ด้านล่าง (Target Pad Interface) จะต้องรับแรงดึงในแนวดิ่งอย่างมหาศาลจากการขยายตัวของบอร์ด ($Z$-axis CTE ของ FR-4 สูงถึง $50 - 70 \text{ ppm/}^\circ\text{C}$ เหนือจุด $T_g$) ก่อให้เกิดการฉีกขาดที่รอยต่อ (Interface Void / Delamination)  
> ในทางตรงกันข้าม **Staggered Microvias** วางเยื้องศูนย์กันและมีชั้นทองแดงแนวนอนเชื่อมต่อ โครงสร้างแบบนี้ยอมให้แผ่นวงจรเกิดการโค้งงอและซับแรงเค้นทางกลได้ ยืดอายุการใช้งานต่อการทดสอบ Thermal Cycling ได้มากกว่าแบบ Stacked ถึง $5 - 10$ เท่า

### ข้อที่ 3 (ข้อแตกต่างด้านข้อกำหนด Annular Ring ระหว่าง IPC Class 2 และ Class 3)
ตามมาตรฐานการผลิต IPC-6012 ข้อกำหนดเรื่อง Annular Ring ของรูเจาะ Through-Hole ข้อใดระบุความแตกต่างระหว่าง Class 2 และ Class 3 ได้อย่างถูกต้องที่สุด?

- **ก)** Class 2 ห้ามเจาะรูหลุดขอบ Pad ขณะที่ Class 3 ยอมให้หลุดขอบได้ $180^\circ$
- **ข)** Class 2 ยอมให้เกิดการหลุดขอบของรูเจาะ (Breakout) ได้สูงสุดไม่เกิน $90^\circ$ ของเส้นรอบวง ตราบใดที่มีเนื้อทองแดงเหลือบริเวณรอยต่อลายวงจรไม่น้อยกว่า $50 \ \mu\text{m}$ ขณะที่ Class 3 สั่งห้ามเกิด Breakout เด็ดขาด (Zero Breakout) และต้องมีเนื้อทองแดงรอบรูสมบูรณ์อย่างน้อย $25 \ \mu\text{m}$ (ชั้นใน)
- **ค)** ทั้ง Class 2 และ Class 3 ใช้เกณฑ์เดียวกันทุกประการ
- **ง)** Class 3 อนุญาตให้ไม่มี Pad ล้อมรอบรูเจาะได้

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> มาตรฐาน IPC-6012 กำหนดเกณฑ์คุณภาพอย่างเข้มงวด:  
> - **Class 2 (เกรดสินค้าอุปโภคทั่วไป):** ยอมรับความคลาดเคลื่อนในการเจาะที่ทำให้รูเบี่ยงจนหลุดขอบ Pad (Tangential Breakout) ได้สูงสุดไม่เกิน $90^\circ$ ของมุมรอบวง โดยมีข้อแม้ว่าจุดที่สายวงจรวิ่งเข้ามาเชื่อมต่อ (Conductor Junction) ต้องมีเนื้อทองแดงเหลืออยู่อย่างน้อย $50 \ \mu\text{m} \ (2 \text{ mil})$ เพื่อไม่ให้กระแสไฟขาดตอน  
> - **Class 3 (เกรดความน่าเชื่อถือสูง/การแพทย์/ยานยนต์/การบิน):** **ไม่อนุญาตให้เกิด Breakout เลยแม้แต่จุดเดียว (100% Complete Annular Ring)** โดยต้องมีเนื้อทองแดงส่วนที่แคบที่สุดรอบรูเจาะในชั้นในไม่น้อยกว่า $25 \ \mu\text{m} \ (1 \text{ mil})$ และชั้นนอกไม่น้อยกว่า $50 \ \mu\text{m} \ (2 \text{ mil})$ เสมอ เพื่อรับประกันว่าจะไม่มีการแตกร้าวภายใต้สภาวะการสั่นสะเทือนและความร้อนสุดขั้ว
