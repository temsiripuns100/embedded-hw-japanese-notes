# Lesson 010: PCB Routing Part 10 - DFM/DFT for High-Density Interconnects (HDI)
*(プリント基板のHDI製造性・テスト性設計 - レーザーマイクロビアと基板反り対策)*

---

## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

เมื่อการออกแบบแผ่นวงจรพิมพ์ก้าวเข้าสู่เทคโนโลยี **HDI (High-Density Interconnect)** ตามมาตรฐาน IPC-2226 ข้อจำกัดทางด้านความสามารถในการผลิต (DFM - Design for Manufacturing) และความสามารถในการทดสอบ (DFT - Design for Testing) จะกลายเป็นตัวแปรวิกฤตที่ชี้ขาดความสำเร็จของผลิตภัณฑ์
วิศวกรระดับ Senior ต้องเข้าใจ **ข้อจำกัดเชิงกลและโลหะวิทยาของ Laser Microvia**, **ความล้มเหลวจากความเค้นเชิงความร้อน (CTE Mismatch Stress)**, **ทฤษฎีการควบคุมการโก่งตัวของบอร์ด (Warpage / Sori)**, และ **สถาปัตยกรรมทดสอบ In-Circuit Test (ICT)**

---

### 1.1 สถาปัตยกรรม IPC-2226 HDI และ Laser Microvia Aspect Ratio
ตามมาตรฐาน IPC-2226 โครงสร้าง HDI แบ่งออกเป็นระดับชั้น:
- **Type I (1+C+1):** มี Microvia ชั้นนอกสุด 1 ชั้นประกบแกนกลาง (Core)
- **Type II (2+C+2):** มี Microvia 2 ชั้นซ้อนกัน โดยมีทั้ง Blind และ Buried Vias ในแกนกลาง
- **Type III / ELIC (Any-Layer HDI):** ไม่มี Core แกนกลาง ทุก Layer สามารถเชื่อมต่อกันด้วย Microvia ได้อย่างอิสระ (Every Layer Interconnect)

```
   Layer 1  ──────┬───┬──────  (Laser Microvia, L1 -> L2)
                  │   │  H_diel
   Layer 2  ──────┴───┴──────
                    ▲
                    │ D_drill (เส้นผ่านศูนย์กลางเลเซอร์)
```

**กฎเรขาคณิตของ Microvia Aspect Ratio (AR):**
กระบวนการชุบทองแดงด้วยไฟฟ้า (Electroplating / Copper Filling) สำหรับรูบอด Microvia ถูกจำกัดด้วยอัตราส่วน:

$$\text{Aspect Ratio (AR)} = \frac{H_{diel}}{D_{drill}} \le 0.75 - 0.80$$

- $H_{diel}$: ความหนาของชั้นไดอิเล็กตริก (Dielectric Thickness เช่น $50 - 65 \ \mu\text{m}$)
- $D_{drill}$: ขนาดเส้นผ่านศูนย์กลางของรูเจาะเลเซอร์ ($CO_2$ หรือ UV Laser เช่น $75 - 100 \ \mu\text{m}$)

*ข้อควรระวังทางวิศวกรรม:* หากผู้ออกแบบเลือก Prepreg หนาเกินไปจนทำให้ค่า $\text{AR} > 0.80$ น้ำยาชุบทองแดงจะไม่สามารถไหลเวียนเข้าไปถึงก้นรูได้เต็มที่ ทำให้เนื้อทองแดงที่ชุบเกิดโพรงกลวง (Barrel Void) หรือความหนาทองแดงบริเวณขอบมุมก้นรู (Knee Thickness) บางเกินไปจนแตกร้าวเมื่อโดนความร้อน!

### 1.2 โลหะวิทยาและความเค้นจาก CTE Mismatch (Stacked vs. Staggered Vias)
ในกระบวนการบัดกรีไร้สารตะกั่ว (Lead-Free Reflow) ที่อุณหภูมิยอดคลื่นสูงถึง **$260^\circ\text{C}$** แผ่นวงจรพิมพ์จะเกิดการขยายตัวทางความร้อนอย่างรุนแรง:
- **ค่าสัมประสิทธิ์การขยายตัวในแนวแกน Z ของเนื้อ FR-4 ($\alpha_z$):**
  - ต่ำกว่า $T_g$: $\approx 45 - 60 \ \text{ppm}/^\circ\text{C}$
  - สูงกว่า $T_g$ (อุณหภูมิเปลี่ยนสถานะคล้ายแก้ว): **$\approx 250 - 350 \ \text{ppm}/^\circ\text{C}$!**
- **ค่าสัมประสิทธิ์การขยายตัวของทองแดงชุบ ($\alpha_{Cu}$):** $\approx 16 - 17 \ \text{ppm}/^\circ\text{C}$ เท่านั้น!

```
               [ Stacked Vias ]                        [ Staggered Vias ]
                                                
    L1 ───────────┌─────┐───────────         L1 ───────────┌─────┐───────────
                  │ Via │                                  │ Via │
    L2 ───────────┼─────┼───────────         L2 ───┌─────┐─┴─────┴───────────
     จุดแตกร้าว! ──► ✖   │ (ความเค้นดึงสูงมาก)             │ Via │ ◄── กระจายความเค้นได้ดี
    L3 ───────────┴─────┴───────────         L3 ───┴─────┴───────────────────
```

**คำเตือนความปลอดภัย IPC-WP-023:**
- **Stacked Microvias (ไมโครเวียวางซ้อนกันในแนวดิ่งตรงเป๊ะ):** รอยต่อระหว่างก้นของ Via ชั้นบนกับหลังคาของ Via ชั้นล่าง (Target Pad Interface) จะต้องรับแรงดึงในแนวแกน Z มหาศาล ($\Delta \alpha > 200 \ \text{ppm}/^\circ\text{C}$) เมื่อผ่านเตาอบ Reflow หรือการเปลี่ยนแปลงอุณหภูมิ (Thermal Cycling) รอยต่อนี้มักจะเกิดการฉีกขาดแบบแฝง (Latent Target Pad Separation) ซึ่งเครื่องวัดไฟฟ้าในโรงงานตรวจไม่พบ แต่จะขาดเมื่อลูกค้านำไปใช้งานจริง!
- **Staggered Microvias (ไมโครเวียแบบเยื้องสลับฟันปลา):** รูเจาะในแต่ละชั้นจะวางเยื้องกันอย่างน้อย **$D_{drill} + 0.1 \text{ mm}$** โครงสร้างนี้ยอมให้เนื้อทองแดงและเรซินสามารถยืดหยุ่นให้ตัวได้ จึงมีความน่าเชื่อถือทางกล (Thermal Fatigue Life) สูงกว่า Stacked Vias หลายเท่า

---

### 1.3 ทฤษฎีการควบคุมการโก่งตัวของบอร์ด (Warpage / Sori - 反り)
ตามมาตรฐาน IPC-6012 อัตราการโก่งงอ (Bow and Twist) สูงสุดที่ยอมรับได้สำหรับบอร์ดที่ลงอุปกรณ์ SMD คือ:
$$\text{Max Warpage} \le 0.75\% \quad (\text{และ } \le 0.50\% \text{ สำหรับ Fine-Pitch BGA})$$

**กฎความสมมาตรของ Stackup (Symmetrical Stackup Rule):**
1. **ความสมมาตรของความหนาไดอิเล็กตริก:** ความหนาของ Core และ Prepreg ในฝั่งครึ่งบน (Top Half) ต้องเท่ากับครึ่งล่าง (Bottom Half) เทียบกับแกนกึ่งกลางบอร์ด
2. **ความสมมาตรของปริมาณทองแดง (Copper Balance):** สัดส่วนพื้นที่ทองแดง (Copper Area Percentage) ระหว่างชั้น L1 กับ L(N), L2 กับ L(N-1) ต้องใกล้เคียงกันไม่ต่างกันเกิน $\pm 5\%$ หากชั้นหนึ่งเป็น Plane ทึบ แต่อีกชั้นเป็นลายเส้นโปร่ง ต้องสั่งใส่ **Thieving Copper (ลายทองแดงตาข่ายเติมเต็ม)** เพื่อปรับความตึงผิวให้เท่ากัน

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** กล่องควบคุมอิเล็กทรอนิกส์ยานยนต์ (Automotive ECU) ผ่านการทดสอบโรงงาน 100% แต่เมื่อส่งไปทดสอบ Thermal Shock Test ($-40^\circ\text{C} \leftrightarrow +125^\circ\text{C}$ จำนวน 500 รอบ) บอร์ดเกิดอาการดับและสื่อสารกับ CAN Bus ไม่ได้
**สาเหตุที่ตรวจพบ (検図での指摘):**
ส่องกล้องจุลทรรศน์อิเล็กตรอน (SEM Cross-Section) พบรอยแยกขนาด $2 \ \mu\text{m}$ ที่จุดเชื่อมต่อระหว่าง Microvia ชั้น L1 และ L2 ที่ถูกออกแบบเป็นแบบ **Stacked Microvia ซ้อนกัน 3 ชั้น (L1-L2-L3)** ร่วมกับการเลือกใช้เนื้อ FR-4 เกรดธรรมดาที่มีค่า $T_g = 135^\circ\text{C}$ แรงขยายตัวในแนวแกน Z ดึงให้รอยต่อทองแดงฉีกขาดออกจากกัน

---

### ขั้นตอนการออกแบบ DFM/DFT สไตล์ Senior Engineer (検図チェックリスト):
1. **การกำหนดระยะเยื้องของ Staggered Microvias:**
   - หลีกเลี่ยง Stacked Microvias ในผลิตภัณฑ์เกรดอุตสาหกรรมและยานยนต์ (เว้นแต่จะใช้เทคโนโลยี Any-Layer ทองแดงตันเต็มรูปแบบ)
   - ระยะห่างเยื้องระหว่างจุดกึ่งกลางของ Via สองชั้นที่ติดกัน (Offset Distance) ต้องมีขนาดอย่างน้อย:
     $$\text{Offset} \ge \frac{D_{pad1} + D_{pad2}}{2} + 0.10 \text{ mm}$$
2. **กฎทองของจุดทดสอบ ICT (In-Circuit Test Fixture Rules):**
   - **ขนาด Test Point Pad:** ต้องมีเส้นผ่านศูนย์กลางอย่างน้อย **$0.80 \text{ mm} \ (32 \text{ mil})$** สำหรับเข็มทดสอบเตียงตะปู (Bed-of-Nails) และอย่างน้อย **$0.50 \text{ mm}$** สำหรับ Flying Probe
   - **ระยะห่างระหว่างจุดทดสอบ (Pitch):** ห่างกันอย่างน้อย **$1.27 \text{ mm} \ (50 \text{ mil})$** (ดีที่สุดคือ $2.54 \text{ mm}$) เพื่อความแข็งแรงของสปริงเข็มทดสอบ
   - **ระยะห่างจากขอบอุปกรณ์ (Component Keepout):** ต้องอยู่ห่างจากตัวถังอุปกรณ์ SMD ที่สูงเกิน 1.5 mm เป็นระยะอย่างน้อย **$1.0 - 1.5 \text{ mm}$** เพื่อไม่ให้ก้านเข็มชนตัวถังอุปกรณ์
3. **การวางระเบียบ Fiducial Markers:**
   - ต้องวางจุดมาร์คเกอร์ทรงกลม (Global Fiducials) ขนาด $1.0 \text{ mm}$ พร้อมวงแหวน Clear Mask $2.0 \text{ mm}$ จำนวน 3 จุดที่มุมบอร์ดแบบไม่สมมาตร (เพื่อป้องกันการใส่บอร์ดกลับด้านในเครื่อง Pick-and-Place)
   - สำหรับชิป BGA Pitch $\le 0.5 \text{ mm}$ ต้องวาง Local Fiducials อย่างน้อย 2 จุดที่มุมทแยงของชิป

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「高密度BGA部において、L1-L2とL2-L3のマイクロビアがスタック（同軸積層）配置されています。車載環境下（熱衝撃試験）におけるターゲットパッド界面の断線リスク（IPC-WP-023警告）を回避するため、スタガード配置（オフセット距離0.25mm以上確保）へ変更してください。また、基板材料には高Tg材（Tg≧170℃）を指定のこと。」  
> *(บริเวณ BGA หนาแน่น มีการวาง Microvia L1-L2 และ L2-L3 ซ้อนกันแบบ Stacked เพื่อหลีกเลี่ยงความเสี่ยงจากการฉีกขาดของรอยต่อ Target Pad ในสภาวะแวดล้อมยานยนต์ กรุณาเปลี่ยนเป็นแบบ Staggered เยื้องระยะอย่างน้อย 0.25mm และระบุให้ใช้วัสดุแผ่นที่มีค่า Tg สูง 170°C ขึ้นไป)*

> **指摘事項 2:**  
> 「層構成（スタックアップ）において、L2層がベタ銅箔（残銅率95%）であるのに対し、対称層であるL7層は信号配線のみで残銅率が20%しかありません。熱プレス工程およびリフロー時の熱応力による基板の反り（反り量0.5%超過）を防止するため、L7層の空きエリアにダミー銅箔（メッシュベタ）を追加し、銅箔バランスを均等化してください。」  
> *(ในโครงสร้าง Stackup ชั้น L2 มีทองแดงทึบถึง 95% ขณะที่ชั้นสมมาตร L7 มีทองแดงเพียง 20% เพื่อป้องกันการโก่งตัวของบอร์ดจากความเค้นในเตาอบ Reflow กรุณาเติมทองแดง Dummy (Thieving Copper) ในพื้นที่ว่างบน L7 เพื่อปรับสมดุลปริมาณทองแดงให้เท่ากัน)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Laser Microvia Aspect Ratio)
ในการออกแบบบอร์ด HDI Type II หากชั้น Prepreg ไดอิเล็กตริกสำหรับ Laser Drill ระหว่าง Layer 1 ถึง Layer 2 มีความหนาหลังอัดบอร์ดเท่ากับ $H = 75 \ \mu\text{m}$ และโรงงาน PCB ใช้เครื่องเลเซอร์ UV ที่สามารถเจาะรูขนาดเส้นผ่านศูนย์กลาง $D = 70 \ \mu\text{m}$ ได้ ถามว่าอัตราส่วน Aspect Ratio มีค่าเท่าใด และโครงสร้างนี้ผ่านเกณฑ์มาตรฐานการชุบทองแดง (Plating Quality) หรือไม่?

- **ก)** $\text{AR} = 0.50$, ผ่านเกณฑ์อย่างสมบูรณ์แบบ
- **ข)** $\text{AR} \approx 1.07$, ไม่ผ่านเกณฑ์มาตรฐาน เพราะเกินขีดจำกัดสูงสุด $0.80$ มีความเสี่ยงสูงมากที่น้ำยาชุบทองแดงจะไม่สามารถเติมเต็มรูได้จนเกิดโพรงอากาศ (Plating Void)
- **ค)** $\text{AR} = 1.50$, ผ่านเกณฑ์เฉพาะในบอร์ดเครื่องบิน
- **ง)** $\text{AR} = 0.93$, ผ่านเกณฑ์เพราะเครื่องจักรเลเซอร์ปรับตัวได้

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> คำนวณ Aspect Ratio ของ Microvia:  
> $$\text{AR} = \frac{H}{D} = \frac{75 \ \mu\text{m}}{70 \ \mu\text{m}} \approx 1.071$$  
> ตามข้อกำหนดการผลิต HDI สากล ค่า Aspect Ratio สำหรับ Microvia แบบ Blind Via **ต้องไม่เกิน $0.75 - 0.80$** เนื่องจากคุณสมบัติของกระบวนการชุบทองแดงด้วยไฟฟ้า (Electroplating Throwing Power) หากรูเจาะแคบแต่ลึกเกินไป ($AR > 1.0$) สารเคมีชุบจะไม่สามารถแทรกซึมไปเคลือบผนังและก้นรูได้ทั่วถึง เกิดเป็นโพรงกลวงขนาดใหญ่และทำให้จุดเชื่อมต่อขาดวงจร วิศวกรต้องแก้ไขโดยการลดความหนาของ Prepreg ลงมาอยู่ที่ $50 - 55 \ \mu\text{m}$ หรือขยายขนาดรูเจาะเลเซอร์เป็น $100 \ \mu\text{m}$

---

### ข้อที่ 2 (การวิเคราะห์สาเหตุของความล้มเหลวใน Stacked Microvias)
เหตุใดการวาง Stacked Microvias ซ้อนกันตรงๆ หลายชั้นจึงมีความเสี่ยงต่อความน่าเชื่อถือระยะยาว (Reliability Hazard) สูงกว่าการวางแบบ Staggered Microvias เมื่อต้องเผชิญกับอุณหภูมิของเตาอบบัดกรี $260^\circ\text{C}$?

- **ก)** เพราะ Stacked Microvias ทำให้บอร์ดมีน้ำหนักถ่วงลงมาในแนวดิ่งมากเกินไป
- **ข)** เพราะความแตกต่างอย่างมหาศาลของอัตราการขยายตัวทางความร้อนในแนวแกน Z ($\alpha_z$) ของเรซินไดอิเล็กตริก (สูงกว่า $250 \ \text{ppm}/^\circ\text{C}$ เหนือ $T_g$) เมื่อเทียบกับทองแดง ($17 \ \text{ppm}/^\circ\text{C}$) จะทำให้เกิดแรงดึงกระชากมหาศาลบนแกนร่วมเดียวกัน ส่งผลให้รอยต่อระหว่างก้นของ Via กับ Pad ของชั้นล่างเกิดการฉีกขาด (Target Pad Separation)
- **ค)** เพราะ Stacked Microvias ปล่อยรังสีแม่เหล็กไฟฟ้าออกมาทำลายเนื้อทองแดง
- **ง)** เพราะเครื่องมือทดสอบ ICT ไม่สามารถแตะสัมผัส Stacked Microvias ได้

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> เมื่ออุณหภูมิสูงเกินค่า $T_g$ ของวัสดุ แผ่นเรซินของ PCB จะขยายตัวในแนวดิ่งอย่างรวดเร็ว (แกน Z ขยายตัวมากกว่าแนวราบ X-Y หลายเท่า) ในโครงสร้าง Stacked Vias ตัวกระบอกทองแดงจะเรียงตัวต่อกันเป็นเสาแข็งทึบต้นเดียว ขณะที่เนื้อเรซินรอบๆ ดันตัวสูงขึ้น ทำให้เกิดแรงเค้นเฉือนและแรงดึงกระชากสูงสุดตรงรอยประสานระหว่างชั้น (Microvia Interface)  
> ในทางตรงกันข้าม โครงสร้างแบบ **Staggered Vias** มีเนื้อทองแดงและเรซินคั่นสลับกันเป็นขั้นบันได ทำให้แรงเค้นถูกกระจายตัวออกไปในแนวราบ (Stress Distribution) จึงไม่เกิดแรงดึงกระจุกตัวที่จุดเดียวและมีความทนทานต่อความร้อนสูงกว่ามาก

### ข้อที่ 3 (การวางจุดทดสอบ In-Circuit Test - ICT บนบอร์ดความเร็วสูง)
ในการออกแบบจุดทดสอบ (Test Points) สำหรับสายสัญญาณความเร็วสูงระดับ Multi-Gigabit (เช่น PCIe หรือ DDR4) บนบอร์ด HDI ข้อใดเป็นแนวทางที่ถูกต้องทางวิศวกรรมที่สุดเพื่อไม่ให้ทำลาย Signal Integrity?

- **ก)** เพิ่ม Pad จุดทดสอบขนาดใหญ่ 1.5 mm ลงบนกลางเส้นทางสายสัญญาณความเร็วสูงทุกเส้น
- **ข)** ห้ามวาง Test Point Pad แบบมีติ่งแยก (Stub) ลงบนคู่สัญญาณความเร็วสูงโดยเด็ดขาด หากจำเป็นต้องทดสอบ ให้ทดสอบผ่านวงจรภายในชิป (JTAG Boundary Scan / BIST) หรือแตะวัดที่ขั้วของตัวต้านทาน Termination / AC Coupling Capacitor ที่มีอยู่แล้วในวงจร
- **ค)** เจาะ Via เพิ่มเติมอีก 3 รูขนานกันข้างๆ จุดทดสอบ
- **ง)** เดินสายสัญญาณให้ยาวขึ้นเป็นสองเท่าเพื่อสร้างพื้นที่ให้เครื่องมือจิ้มทดสอบได้

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> จุดทดสอบ (Test Pad ขนาด $\ge 0.8 \text{ mm}$) มีขนาดทางกายภาพใหญ่กว่าเส้น Trace มาก และหากเดินสายแยกออกไปหา Test Pad จะกลายเป็น **Open-Circuited Stub** ที่มีความจุแฝงสูง (Capacitive Discontinuity) ซึ่งจะสะท้อนคลื่นและทำลายรูปคลื่นความเร็วสูงจน Eye Diagram ปิดตัวลงทันที  
> ในการออกแบบระดับสูง สัญญาณ High-Speed จะไม่ใส่ Test Pad ภายนอก แต่จะพึ่งพาเทคโนโลยี **Boundary Scan (IEEE 1149.1 / 1149.6)** หรือใช้วงจร Built-In Self-Test (BIST) ภายในตัวชิปในการทดสอบความต่อเนื่องของสัญญาณแทน
