## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในที่สุดเราก็เดินทางมาถึง **บทเรียนที่ 100 ซึ่งเป็นบทสรุปสูงสุดของคัมภีร์วิศวกรรมการออกแบบและการผลิตแผงวงจรพิมพ์ (Master Synthesis of PCB Engineering)** 

ในการพัฒนาฮาร์ดแวร์ระดับมืออาชีพ งานของวิศวกรไม่ได้สิ้นสุดลงเมื่อไฟล์ Gerber ถูกส่งออกจากโปรแกรม CAD แต่จุดชี้ชะตาความสำเร็จทางวิศวกรรมและธุรกิจที่แท้จริงคือ: **ผลิตภัณฑ์สามารถผลิตในสายการผลิตจำนวนมาก (Mass Production: ระดับแสนถึงล้านชิ้น) ได้อย่างราบรื่นโดยมีอัตราของเสียเข้าใกล้ศูนย์ (Zero-Defect Quality Strategy) หรือไม่?**

การจะบรรลุเป้าหมายคุณภาพระดับสูงสุดนี้ วิศวกรอาวุโสต้องผสานรวมเครื่องมือทางคณิตศาสตร์และสถิติ:
1. **การควบคุมกระบวนการเชิงสถิติ (Statistical Process Control - SPC)** และดัชนีความสามารถของกระบวนการ (**$C_p / C_{pk}$**)
2. **การวิเคราะห์ระบบการวัด (Measurement System Analysis - MSA / Gauge R&R)** เพื่อรับประกันความเที่ยงตรงของเครื่องจักรตรวจสอบ
3. **ระบบป้องกันความผิดพลาดแบบป้องปราม (Poka-Yoke / ポカヨケ)**
4. **กระบวนการตรวจรับรองแบบขั้นสุดท้ายและการลงนามอนุมัติ (Master Kenzu - 検図 Sign-Off)** ตามมาตรฐานสากล IPC Class 1, 2, และ 3

### 1.1 การควบคุมกระบวนการเชิงสถิติและดัชนีความสามารถ ($C_p$ และ $C_{pk}$)

ในสายการผลิต PCBA ตัวแปรสำคัญ เช่น ความหนาของครีมบัดกรี (Solder Paste Height), ปริมาตรตะกั่ว (Paste Volume), ตำแหน่งการจัดวางชิ้นส่วน ($X, Y$ Placement Offset), และความกว้างเส้นทองแดง จะกระจายตัวตามการแจกแจงแบบปกติของเกาส์เซียน (Gaussian Normal Distribution: $N(\mu, \sigma^2)$):

#### 1. ดัชนีความสามารถของกระบวนการเชิงศักยภาพ (Process Capability Index - $C_p$):
วัดความกว้างของการกระจายตัวของกระบวนการเทียบกับช่วงความเผื่อของสเปก (Specification Width):

$$C_p = \frac{\text{USL} - \text{LSL}}{6\sigma}$$

โดยที่:
- $\text{USL}$ = ขีดจำกัดข้อกำหนดบน (Upper Specification Limit)
- $\text{LSL}$ = ขีดจำกัดข้อกำหนดล่าง (Lower Specification Limit)
- $\sigma$ = ค่าเบี่ยงเบนมาตรฐานของกระบวนการ (Process Standard Deviation)

#### 2. ดัชนีความสามารถของกระบวนการจริง (Actual Process Capability Index - $C_{pk}$):
วัดความสามารถจริงโดยคำนึงถึง **การเบี่ยงเบนของค่าเฉลี่ย ($\mu$) ออกจากจุดกึ่งกลางสเปก**:

$$C_{pk} = \min\left( \frac{\text{USL} - \mu}{3\sigma}, \frac{\mu - \text{LSL}}{3\sigma} \right) = C_p \cdot (1 - k)$$

โดยที่ $k = \frac{|\mu - \text{Target}|}{(\text{USL} - \text{LSL})/2}$ คือดัชนีการเลี้ยวเบนของศูนย์กลาง

#### ระดับมาตรฐานอุตสาหกรรมสำหรับ $C_{pk}$:
- **$C_{pk} < 1.00$:** กระบวนการไม่สามารถควบคุมได้ (Incapable) มีของเสียหลุดรอดมากกว่า $2,700\ \text{PPM}$
- **$C_{pk} \ge 1.33$:** มาตรฐานขั้นต่ำสำหรับสินค้าอิเล็กทรอนิกส์ทั่วไป ($4\sigma$, ของเสียไม่เกิน $63\ \text{PPM}$)
- **$C_{pk} \ge 1.67$:** มาตรฐานสำหรับอุปกรณ์อุตสาหกรรมและโทรคมนาคม ($5\sigma$, ของเสียไม่เกิน $0.57\ \text{PPM}$)
- **$C_{pk} \ge 2.00$:** **มาตรฐาน Six Sigma ระดับโลกสำหรับยานยนต์และการบินอวกาศ (World-Class Automotive Grade)** ยอมรับของเสียไม่เกิน **$3.4\ \text{DPMO}$** (Defects Per Million Opportunities) แม้จะมีการเลื่อนของค่าเฉลี่ยระยะยาว $\pm 1.5\sigma$

### 1.2 การวิเคราะห์ระบบการวัดและความเที่ยงตรง (Measurement System Analysis - Gauge R&R)

ก่อนที่จะเชื่อถือข้อมูลสถิติจากเครื่องจักรตรวจสอบ เช่น 3D SPI, 3D AOI, หรือเครื่องวัดพิกัด 3D CMM วิศวกรต้องพิสูจน์ว่า **ระบบการวัดไม่ได้สร้างความแปรปรวนหลอกขึ้นมาเอง** ผ่านการทดสอบ **Gauge Repeatability & Reproducibility (GR&R)**:

ความแปรปรวนรวมที่วัดได้ ($\sigma_{\text{total}}^2$):
$$\sigma_{\text{total}}^2 = \sigma_{\text{part-to-part}}^2 + \sigma_{\text{measurement\_system}}^2 = \sigma_{\text{PV}}^2 + \sigma_{\text{GRR}}^2$$

โดยที่ความแปรปรวนของระบบการวัดแบ่งเป็น 2 ส่วน:
$$\sigma_{\text{GRR}}^2 = \sigma_{\text{repeatability}}^2 + \sigma_{\text{reproducibility}}^2 = \sigma_{\text{EV}}^2 + \sigma_{\text{AV}}^2$$
- **Equipment Variation ($\sigma_{\text{EV}}$ / Repeatability):** ความแปรปรวนเมื่อเครื่องจักรตัวเดิมวัดชิ้นงานเดิมซ้ำๆ
- **Appraiser Variation ($\sigma_{\text{AV}}$ / Reproducibility):** ความแปรปรวนเมื่อเปลี่ยนผู้ปฏิบัติงานหรือเปลี่ยนหัววัด

#### เกณฑ์การยอมรับค่าเปอร์เซ็นต์ Gauge R&R ($\%\text{GRR}$ per AIAG MSA Standard):
$$\%\text{GRR} = \frac{\sigma_{\text{GRR}}}{\sigma_{\text{total}}} \times 100\%$$

- **$\%\text{GRR} < 10.0\%$:** **ยอดเยี่ยม (World-Class Certified)** ระบบการวัดมีความแม่นยำสูงมาก ข้อมูลสถิติเชื่อถือได้ $100\%$
- **$10.0\% \le \%\text{GRR} \le 30.0\%$:** ยอมรับได้แบบมีเงื่อนไข (Marginal) ขึ้นอยู่กับความสำคัญของผลิตภัณฑ์
- **$\%\text{GRR} > 30.0\%$:** **ระบบการวัดล้มเหลว (Unacceptable System)** ห้ามนำมาใช้ควบคุมสายการผลิต ต้องปรับเทียบเซนเซอร์หรือเปลี่ยนเครื่องมือวัดทันที

### 1.3 กลยุทธ์คุณภาพของเสียเป็นศูนย์และระบบฟีดแบ็กวงปิด (Zero-Defect & Closed-Loop SMT)

เพื่อกำจัดความผิดพลาดจากการทำงานของมนุษย์ สายการผลิต SMT ระดับสูงจะเชื่อมต่อเครื่องจักรเป็น **ระบบอัตโนมัติวงปิด (Closed-Loop Intelligent SMT Ecosystem)**:

```
                          Closed-Loop SMT Industry 4.0 Architecture
                          
       ┌───────────────────────────────┐        Dynamic Feedback Offset (X, Y, Theta)
       │  Screen Printer               │◄─────────────────────────────────────────────────┐
       │  (Solder Paste Printing)      │                                                  │
       └──────────────┬────────────────┘                                                  │
                      │ Print                                                             │
                      ▼                                                                   │
       ┌───────────────────────────────┐        Auto Stencil Wipe / Squeegee Pressure     │
       │  3D SPI (Paste Inspection)    ├──────────────────────────────────────────────────┘
       └──────────────┬────────────────┘
                      │ Pass
                      ▼
       ┌───────────────────────────────┐        Feeder Pick Offset / Nozzle Clog Alarm
       │  High-Speed SMT Mounter       │◄─────────────────────────────────────────────────┐
       └──────────────┬────────────────┘                                                  │
                      │ Place                                                             │
                      ▼                                                                   │
       ┌───────────────────────────────┐                                                  │
       │  Reflow Oven (N2 / Vacuum)    │                                                  │
       └──────────────┬────────────────┘                                                  │
                      │ Solder                                                            │
                      ▼                                                                   │
       ┌───────────────────────────────┐        Placement Drift Correlation Data          │
       │  3D AOI & 3D AXI Inspection   ├──────────────────────────────────────────────────┘
       └───────────────────────────────┘
```

1. **SPI to Screen Printer Closed-Loop:** เมื่อเครื่อง 3D SPI ตรวจพบว่าตำแหน่งครีมบัดกรีเริ่มเลื่อนศูนย์กลาง ($\Delta x > 15\ \mu\text{m}$) ระบบจะส่งข้อมูลชดเชยพิกัดย้อนกลับไปสั่งให้เครื่องพิมพ์สเตนซิลปรับแก้แกน $X, Y, \theta$ ของโต๊ะพิมพ์โดยอัตโนมัติทันทีในแผ่นถัดไป และสั่งให้ระบบเช็ดสเตนซิลทำงานทันทีหากพบเศษตะกั่วเลอะใต้แผ่น
2. **AOI to Mounter Closed-Loop:** เมื่อเครื่อง 3D AOI ตรวจพบว่าชิ้นส่วน 0201 ตัวหนึ่งเริ่มเอียง (Skew) ข้อมูลจะถูกส่งกลับไปยังเครื่อง Mounter เพื่อระบุหัวดูด Nozzle ที่รับผิดชอบ หากหัวดูดเริ่มอุดตัน ระบบจะสั่งสลับไปใช้หัวดูดสำรองโดยอัตโนมัติและส่งสัญญาณเตือนช่างบำรุงรักษา
3. **Poka-Yoke (ポカヨケ - การออกแบบป้องกันความผิดพลาด):**
   - การทำรอยบากไม่สมมาตร (Asymmetric Chamfers) บนคอนเนกเตอร์ เพื่อป้องกันการเสียบกลับด้าน $180^\circ$
   - การจัดวางจุด Fiducial Marks แบบสามเหลี่ยมไม่สมมาตร เพื่อป้องกันการโหลดบอร์ดกลับด้านเข้าเครื่องจักร

### 1.4 สถาปัตยกรรมการตรวจรับรองแบบขั้นสูงสุด (Master Kenzu 10-Gate Audit Checklist)

ก่อนที่ผู้นำวิศวกรรม (Engineering Director / 主査) จะลงนามอนุมัติแบบ (Sign-off) เพื่อปล่อยไฟล์ลงสู่สายการผลิตจริง เอกสาร Gerber, ODB++, IPC-2581, และ Manufacturing Drawings จะต้องผ่านการตรวจสอบใน **10 ด่านตรวจวิศวกรรมระดับโกลด์ (10-Gate Gold Standard Audit)**:

| ด่านตรวจ (Audit Gate) | หัวข้อการตรวจสอบ DFM / DFA | เกณฑ์การผ่านการรับรอง (Passing Criteria) | มาตรฐานอ้างอิง |
| :--- | :--- | :--- | :--- |
| **Gate 1: Stackup & Materials** | โครงสร้างชั้นเลเยอร์, สมมาตรทองแดง, ค่า $D_k / \tan\delta$, ความหนาพรีเพร็กถมร่อง | $RSR \ge 1.20$, ค่า CTE แกน $Z < 50\ \text{ppm}$, การโก่งงอ Warpage $\le 0.50\%$ | IPC-4101, IPC-2141 |
| **Gate 2: Copper Etching** | ความกว้างเส้นและระยะห่างต่ำสุด ชดเชย Etch Factor และ Undercut | ระยะห่าง $S_{\min} \ge T_{\text{Cu}}$ สำหรับ Heavy Copper, ขอบแหวน Annular Ring สมบูรณ์ | IPC-2221B, IPC-6012 |
| **Gate 3: Microvias & HDI** | อัตราส่วน $AR \le 0.8:1$, ค่า Dimple $\le 5\ \mu\text{m}$, หลีกเลี่ยง Stacked เกิน 2 ชั้น | ผ่านการทดสอบ Thermal Stress IPC 2.6.27 ไร้รอยแยก Post-separation | IPC-2226, IPC-WP-023 |
| **Gate 4: High-Speed SI** | ความขรุขระทองแดง VLP/HVLP, การป้องกัน Glass Weave Skew, กำจัด Stub | ลายเส้นวิ่งเอียง $10^\circ$, ขจัด Test Point Stubs บนเส้น $> 2.5\text{ Gbps}$ ทั้งหมด | IPC-2141B, IEEE 1149.6 |
| **Gate 5: Power & Thermal** | พิกัดกระแสตาม IPC-2152, ก้าน Thermal Relief สำหรับรูบาร์เรล, Busbar Sinking | ก้านกั้นความร้อนทนกระแส $J \le 25\ \text{A/mm}^2$, อุณหภูมิแพดไม่ตกฮวบ | IPC-2152, IPC-A-610 |
| **Gate 6: SMT Placement** | ระยะห่าง Courtyard IPC-7351, เคลียร์แลนซ์หัวดูด Mounter, เงาบดบังความร้อน | Courtyard Overlap = 0, ระยะห่างจากอุปกรณ์สูง $H > 3\text{ mm}$ ต้อง $\ge 1.5\text{ mm}$ | IPC-7351B |
| **Gate 7: Soldering & Stencil** | อัตราส่วนพื้นที่สเตนซิล $AR \ge 0.66$ (หรือ $\ge 0.55$ เมื่อเคลือบนาโน), สมดุลแพด 0201 | แพด NSMD เหมือนกันทั้งสองข้าง, เส้นคอคอดสมดุลความร้อน, เขื่อนมาสก์ $\ge 0.08\text{ mm}$ | IPC-7525B |
| **Gate 8: Through-Hole Reflow** | ปริมาตรครีมบัดกรี PiP Overprint, การเติมเต็มรูกระบอกบาร์เรล | ปริมาตรสเตนซิลครอบคลุม $\ge 2.0 \cdot V_{\text{void}}$, การเติมเต็มรูบาร์เรล $\ge 75\%$ | IPC-A-610 Class 3 |
| **Gate 9: Depaneling Stress** | ความหนาร่อง V-Score, รูปรุ Mouse-Bites, ระยะ Keep-out ของ MLCC | MLCC ห่างรอยตัด $\ge 2.5\text{ mm}$ (วางตั้งฉาก $90^\circ$), ความเครียดบอร์ด $\le 500\ \mu\varepsilon$ | IPC-JEDEC-9704 |
| **Gate 10: DFT & Test Access** | วงแหวน JTAG Boundary Scan, ขนาดแพดทดสอบ, ทางเดินแสง 3D AOI & AXI | ความครอบคลุม PCOLA-SOQ $\ge 95\%$, ไร้เงาบอดออปติคัล, BGA ไม่วางซ้อนทับกันตรงๆ | IEEE 1149.1, IPC-7095 |

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場的事践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例): ระบบเบรกป้องกันล้อล็อก (ABS ECU) เกิดวิกฤตเรียกรถยนต์คืนจากความบกพร่องของระบบการวัดและ $C_{pk}$ ต่ำ

ในโครงการผลิตกล่องควบคุมระบบเบรก ABS/ESC ของค่ายรถยนต์ระดับโลก:
- แผงวงจรหลักมีชิปประมวลผลความปลอดภัยแบบ **Fine-Pitch BGA พิตช์ $0.40\text{ mm}$ (แพดเส้นผ่านศูนย์กลาง $0.22\text{ mm}$)** ปริมาณการผลิต 150,000 ชิ้นต่อเดือน
- โรงงานผลิตรันสายการผลิตโดยตรวจสอบปริมาตรครีมบัดกรีด้วยเครื่อง 3D SPI โดยตั้งค่าเกณฑ์ยอมรับไว้กว้างๆ
- หลังจากส่งมอบและประกอบเข้าสู่ตัวรถยนต์และวิ่งใช้งานได้ 6 เดือน เกิดอุบัติเหตุระบบเบรกขัดข้องกะทันหันในรถยนต์ 14 คัน นำไปสู่การสั่งระงับสายการผลิตและเตรียมแผนเรียกรถยนต์คืน (Global Safety Recall) มูลค่าความเสียหายประเมินกว่า 50 ล้านดอลลาร์สหรัฐ
- ผลการสอบสวนทางวิศวกรรมเชิงลึกโดยทีมเฉพาะกิจ (Task Force Investigation):
  1. พบรอยแตกร้าวล้า (Fatigue Open Crack) ใต้ลูกบัดกรี BGA พินมุมด้านนอก
  2. การขุดข้อมูลย้อนกลับจากฐานข้อมูล SPI ของบอร์ดคันที่มีปัญหา พบว่า: ดัชนีความสามารถของกระบวนการพิมพ์ครีมบัดกรีมีค่า **$C_{pk}$ เพียง $0.74$** (มีค่า $\sigma$ กว้างมากและค่าเฉลี่ยเลื่อนต่ำลง) ซึ่งหมายความว่ามีลูกบัดกรีที่มีปริมาตรตะกั่วขาดแคลนหลุดรอดสู่สายการผลิตสูงถึง **$13,500\ \text{PPM}$!**
  3. เมื่อทำการทดสอบ Gauge R&R บนเครื่อง 3D SPI ที่ใช้งานอยู่ พบค่า **$\%\text{GRR}$ สูงถึง $38.4\%$** (เครื่องจักรไม่ผ่านการสอบเทียบ หัวเลเซอร์วัดแสงเสื่อมสภาพ) ทำให้เครื่องจักรแยกไม่ออกระหว่างจุดบัดกรีที่ดีและจุดที่ตะกั่วขาดแคลน กลายเป็นระบบตรวจสอบที่ตาบอด
  4. สายการผลิตไม่มีระบบฟีดแบ็กวงปิด (No Closed-Loop Feedback) เครื่องพิมพ์สเตนซิลทำงานแบบพิมพ์อิสระโดยไม่เคยได้รับข้อมูลการเลื่อนตัวจาก SPI

### ขั้นตอนการแก้ปัญหาและการปฏิบัติหน้างาน (Standard Operating Procedures)

#### Step 1: การสอบเทียบและรับรองความเที่ยงตรงของระบบการวัด (MSA & Gauge R&R Protocol)
1. ก่อนเริ่มการผลิตทุกล็อตใหม่ (NPI & Mass Production Release):
   - ต้องสุ่มแผงวงจร 10 แผ่น และให้พนักงาน 3 คนทำการวัดซ้ำคนละ 3 รอบ บนเครื่อง 3D SPI และ 3D AOI
   - คำนวณค่า $\% \text{GRR}$ ตามคู่มือ AIAG MSA ฉบับที่ 4
   - **ระบบจะได้รับอนุญาตให้รันสายการผลิตก็ต่อเมื่อค่า $\% \text{GRR} \le 10.0\%$ อย่างเข้มงวดเท่านั้น**

#### Step 2: การบังคับใช้ระบบควบคุมกระบวนการแบบวงปิด (Activating Closed-Loop Control)
1. เชื่อมต่อระบบสื่อสารมาตรฐานสากล (IPC-CFX / Hermes Standard) ระหว่าง 3D SPI และเครื่องพิมพ์สเตนซิล:
   - เปิดใช้งานฟังก์ชัน **Auto-Offset Correction**: เมื่อค่าเฉลี่ยพิกัดเลื่อนเกิน $10\ \mu\text{m}$ โต๊ะพิมพ์ต้องปรับแก้อัตโนมัติ
   - ตั้งค่าเกณฑ์ควบคุมกระบวนการ: หากค่า **$C_{pk}$ ของจุดบัดกรีใดๆ ต่ำกว่า $1.67$** ในช่วง 50 บอร์ดต่อเนื่อง ระบบต้องส่งสัญญาณเตือนระดับสีเหลือง และหาก $C_{pk} < 1.33$ ให้หยุดสายการผลิตทันที (Line Stop)

#### Step 3: พิธีการและขั้นตอนการประชุมอนุมัติแบบมาสเตอร์ (Master Kenzu Sign-Off Protocol)
1. การลงนามอนุมัติแบบขั้นสุดท้าย (Production Release Sign-off) ต้องประกอบด้วยการอนุมัติร่วมกันของ 4 ฝ่าย:
   - **Lead Hardware/PCB Designer:** ยืนยันฟังก์ชันทางไฟฟ้าและสัญญาณ SI/PI
   - **Senior DFM/DFA Manufacturing Engineer:** ยืนยันความสอดคล้องกับ 10-Gate Audit Checklist
   - **Senior Quality & Reliability Assurance Lead:** ยืนยันพิกัดความเผื่อและเกณฑ์ IPC Class 3
   - **CAM/Fabrication House Technical Director:** ยืนยันความสามารถของกระบวนการผลิต (Process Window Capability)
2. เมื่อทั้ง 4 ฝ่ายลงนามใน **Kenzu Approval Sheet** จึงจะถือว่าแบบแผงวงจรพิมพ์นี้ได้รับการรับรองเป็น **ระดับคัมภีร์วิศวกรรมอาวุโส (Senior Engineer Gold Standard Approved)** อย่างเป็นทางการ

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### Quiz 1: การคำนวณดัชนีความสามารถของกระบวนการ ($C_p, C_{pk}$) และการประเมินอัตราของเสียระดับ Six Sigma

**โจทย์:**  
ในสายการผลิตแผงวงจรอิเล็กทรอนิกส์ยานยนต์ เครื่องตรวจสอบครีมบัดกรี 3 มิติ (3D SPI) ทำการวัดความสูงของครีมบัดกรี (Solder Paste Height) บนแพดของชิป Fine-Pitch BGA พิตช์ $0.40\text{ mm}$ จากชิ้นงานตัวอย่างต่อเนื่อง $N = 5,000$ จุด  
- ข้อกำหนดทางวิศวกรรม (Engineering Specifications):
  - ขีดจำกัดล่าง (Lower Specification Limit - $\text{LSL}$): $75.0\ \mu\text{m}$
  - ขีดจำกัดบน (Upper Specification Limit - $\text{USL}$): $145.0\ \mu\text{m}$
  - ค่าเป้าหมายในอุดมคติ (Target Value - $T$): $110.0\ \mu\text{m}$
- ผลการประมวลผลทางสถิติของข้อมูลจริงจากสายการผลิต:
  - ค่าเฉลี่ยของกระบวนการ (Process Sample Mean): $\mu = 104.0\ \mu\text{m}$ (มีการเลื่อนตัวต่ำกว่าเป้าหมาย $6.0\ \mu\text{m}$)
  - ค่าเบี่ยงเบนมาตรฐานของกระบวนการ (Standard Deviation): $\sigma = 5.50\ \mu\text{m}$

**คำถาม:**
1. จงคำนวณหาค่าดัชนีความสามารถเชิงศักยภาพ ($C_p$) และดัชนีความสามารถจริงของกระบวนการ ($C_{pk}$)
2. จากค่า $C_{pk}$ ที่คำนวณได้ จงคำนวณหาค่าความน่าจะเป็นของการเกิดข้อบกพร่องที่ขีดจำกัดล่าง ($Z_{\text{LSL}} = \frac{\mu - \text{LSL}}{\sigma}$) และประมาณการอัตราของเสียที่หลุดรอดในหน่วยของเสียต่อล้านโอกาส (Defects Per Million Opportunities - DPMO) โดยอาศัยตารางการแจกแจงแบบปกติมาตรฐาน
3. หากผู้บริหารกำหนดว่ากระบวนการนี้ต้องบรรลุระดับ **Six Sigma Quality ($C_{pk} \ge 2.00$)** ภายใต้ค่าเบี่ยงเบนมาตรฐานเดิม ($\sigma = 5.50\ \mu\text{m}$) กระบวนการพิมพ์จะต้องปรับค่าเฉลี่ย ($\mu$) ให้อยู่ในช่วงใด? และต้องควบคุมค่าเบี่ยงเบนมาตรฐานสูงสุด ($\sigma_{\max}$) ไม่ให้เกินเท่าใด หากค่าเฉลี่ยอยู่ที่ $104.0\ \mu\text{m}$?

---

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 1:

**1. คำนวณค่า $C_p$ และ $C_{pk}$:**
ความกว้างของสเปก:
$$\text{USL} - \text{LSL} = 145.0\ \mu\text{m} - 75.0\ \mu\text{m} = 70.0\ \mu\text{m}$$

คำนวณ $C_p$:
$$C_p = \frac{\text{USL} - \text{LSL}}{6\sigma} = \frac{70.0}{6 \times 5.50} = \frac{70.0}{33.0} \approx 2.121$$

คำนวณ $C_{pk}$:
- ฝั่งขีดจำกัดบน ($C_{pu}$):
  $$C_{pu} = \frac{\text{USL} - \mu}{3\sigma} = \frac{145.0 - 104.0}{3 \times 5.50} = \frac{41.0}{16.5} \approx 2.485$$
- ฝั่งขีดจำกัดล่าง ($C_{pl}$):
  $$C_{pl} = \frac{\mu - \text{LSL}}{3\sigma} = \frac{104.0 - 75.0}{3 \times 5.50} = \frac{29.0}{16.5} \approx 1.758$$

ดังนั้น ดัชนีความสามารถจริงคือค่าน้อย:
$$C_{pk} = \min(C_{pu}, C_{pl}) = 1.758 \approx 1.76$$

**บทวิเคราะห์เบื้องต้น:** กระบวนการมี $C_p = 2.12$ (ศักยภาพระดับ Six Sigma) แต่เนื่องจากค่าเฉลี่ยเลื่อนตัวต่ำลง ($\mu = 104\ \mu\text{m}$ แทนที่จะเป็น $110\ \mu\text{m}$) ค่า $C_{pk}$ จึงลดลงเหลือ $1.76$ แต่ยังคงสูงกว่าเกณฑ์ยานยนต์ ($1.67$) อย่างปลอดภัย

---

**2. คำนวณค่า $Z_{\text{LSL}}$ และอัตราของเสีย DPMO:**
$$Z_{\text{LSL}} = \frac{\mu - \text{LSL}}{\sigma} = \frac{104.0 - 75.0}{5.50} = \frac{29.0}{5.50} \approx 5.273\sigma$$

จากฟังก์ชันการแจกแจงสะสมแบบปกติมาตรฐาน ($Z = 5.273$):
ความน่าจะเป็นที่จะเกิดของเสียต่ำกว่า LSL:
$$P(X < \text{LSL}) = \Phi(-5.273) \approx 6.8 \times 10^{-8}$$
แปลงเป็นอัตราส่วน DPMO:
$$\text{DPMO} = 6.8 \times 10^{-8} \times 1,000,000 \approx 0.068\ \text{DPMO}$$
*(มีของเสียหลุดรอดต่ำกว่า 1 จุด ในทุกๆ 14 ล้านจุดบัดกรี!)*

---

**3. การปรับปรุงเพื่อบรรลุ $C_{pk} \ge 2.00$:**
- **กรณีที่ 1: รักษา $\sigma = 5.50\ \mu\text{m}$ เดิม และปรับตำแหน่งค่าเฉลี่ย ($\mu$):**
  ต้องการให้ $C_{pl} \ge 2.00$ และ $C_{pu} \ge 2.00$:
  $$\frac{\mu - 75.0}{3 \times 5.50} \ge 2.00 \implies \mu - 75.0 \ge 33.0 \implies \mu \ge 108.0\ \mu\text{m}$$
  $$\frac{145.0 - \mu}{3 \times 5.50} \ge 2.00 \implies 145.0 - \mu \ge 33.0 \implies \mu \le 112.0\ \mu\text{m}$$
  **ผลลัพธ์:** โรงงานต้องปรับจูนแรงกดใบมีดปาดครีมบัดกรีเพื่อดึงค่าเฉลี่ยความหนาให้อยู่ในช่วง **$108.0\ \mu\text{m} \le \mu \le 112.0\ \mu\text{m}$** (จุดกึ่งกลาง $110.0\ \mu\text{m}$) จะทำให้กระบวนการแตะระดับ Six Sigma ทันที

- **กรณีที่ 2: หากค่าเฉลี่ยคงเดิมที่ $\mu = 104.0\ \mu\text{m}$ จะต้องคุมค่า $\sigma_{\max}$ เท่าใด:**
  ค่าวิกฤตอยู่ที่ฝั่ง LSL ($29.0\ \mu\text{m}$):
  $$C_{pl} = \frac{104.0 - 75.0}{3 \cdot \sigma_{\max}} \ge 2.00 \implies \frac{29.0}{3 \cdot \sigma_{\max}} \ge 2.00$$
  $$\sigma_{\max} \le \frac{29.0}{6.00} \approx 4.833\ \mu\text{m}$$
  โรงงานต้องปรับปรุงการเช็ดแผ่นสเตนซิลและควบคุมความหนืดของเนื้อครีมบัดกรีให้เข้มงวดขึ้น เพื่อบีบให้ค่าเบี่ยงเบนมาตรฐานลดลงเหลือ **$\sigma \le 4.83\ \mu\text{m}$**

### Quiz 2: การวิเคราะห์ความเชื่อถือได้ของระบบการวัด (Gauge R&R Analysis) ของเครื่องตรวจสอบ 3D AOI

**โจทย์:**  
โรงงานทำการประเมินระบบการวัด (Measurement System Analysis - MSA) ของเครื่องตรวจจับทางสายตา 3D AOI เครื่องใหม่ เพื่อวัดตำแหน่งการเยื้องศูนย์ ($X$-Offset) ของชิ้นส่วนชิป 0201  
- การทดลองใช้พนักงานตรวจสอบ $k = 3$ คน ทำการวัดชิ้นงานตัวอย่าง $n = 10$ แผ่น โดยแต่ละคนทำการวัดซ้ำ $r = 3$ รอบ (รวมการวัดทั้งหมด $3 \times 10 \times 3 = 90$ ครั้ง)
- ผลการวิเคราะห์ความแปรปรวน (Analysis of Variance - ANOVA) ได้ค่าส่วนเบี่ยงเบนมาตรฐานของส่วนประกอบต่างๆ ดังนี้:
  - ค่าความผันแปรของเครื่องมือวัด (Equipment Repeatability Variation): $\sigma_{\text{EV}} = 1.25\ \mu\text{m}$
  - ค่าความผันแปรของผู้ปฏิบัติงาน (Appraiser Reproducibility Variation): $\sigma_{\text{AV}} = 0.85\ \mu\text{m}$
  - ค่าความผันแปรระหว่างชิ้นงานจริง (Part-to-Part Process Variation): $\sigma_{\text{PV}} = 8.60\ \mu\text{m}$

**คำถาม:**
1. จงคำนวณค่าเบี่ยงเบนมาตรฐานรวมของระบบการวัด (Total Measurement System Variation: $\sigma_{\text{GRR}}$ ในหน่วย $\mu\text{m}$)
2. จงคำนวณค่าเบี่ยงเบนมาตรฐานรวมทั้งหมดของการทดลอง ($\sigma_{\text{total}} = \sqrt{\sigma_{\text{GRR}}^2 + \sigma_{\text{PV}}^2}$)
3. คำนวณหาค่าอัตราส่วนเปอร์เซ็นต์ Gauge R&R ($\%\text{GRR} = (\sigma_{\text{GRR}} / \sigma_{\text{total}}) \times 100\%$) และจำนวนหมวดหมู่ที่สามารถจำแนกความแตกต่างได้ (Number of Distinct Categories - $ndc \approx 1.41 \cdot (\sigma_{\text{PV}} / \sigma_{\text{GRR}})$) พร้อมตัดสินว่าระบบ 3D AOI นี้ผ่านเกณฑ์การรับรองสำหรับสายการผลิตระดับโลกหรือไม่?

---

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 2:

**1. คำนวณความผันแปรของระบบการวัด ($\sigma_{\text{GRR}}$):**
$$\sigma_{\text{GRR}} = \sqrt{\sigma_{\text{EV}}^2 + \sigma_{\text{AV}}^2} = \sqrt{(1.25)^2 + (0.85)^2} = \sqrt{1.5625 + 0.7225} = \sqrt{2.285} \approx 1.5116\ \mu\text{m}$$

---

**2. คำนวณความผันแปรทั้งหมด ($\sigma_{\text{total}}$):**
$$\sigma_{\text{total}} = \sqrt{\sigma_{\text{GRR}}^2 + \sigma_{\text{PV}}^2} = \sqrt{(1.5116)^2 + (8.60)^2} = \sqrt{2.285 + 73.96} = \sqrt{76.245} \approx 8.7318\ \mu\text{m}$$

---

**3. คำนวณค่า $\%\text{GRR}$, ดัชนี $ndc$, และการตัดสินมาตรฐาน:**
คำนวณ $\%\text{GRR}$:
$$\%\text{GRR} = \frac{\sigma_{\text{GRR}}}{\sigma_{\text{total}}} \times 100\% = \frac{1.5116\ \mu\text{m}}{8.7318\ \mu\text{m}} \times 100\% \approx 17.31\%$$

คำนวณจำนวนหมวดหมู่จำแนก ($ndc$):
$$ndc = 1.41 \times \left( \frac{\sigma_{\text{PV}}}{\sigma_{\text{GRR}}} \right) = 1.41 \times \left( \frac{8.60}{1.5116} \right) \approx 1.41 \times 5.689 \approx 8.02 \implies ndc = 8$$

**การตัดสินและบทวิเคราะห์คุณภาพตามมาตรฐาน AIAG MSA:**
- **เกณฑ์การตัดสิน:**
  - ค่า $\%\text{GRR} = 17.31\%$ อยู่ในช่วง **$10\% - 30\%$ (Marginally Acceptable)**
  - ค่า $ndc = 8 \ge 5$ (ผ่านเกณฑ์ความสามารถในการจำแนกความแตกต่างของชิ้นงาน)
- **การประเมินวิศวกรอาวุโส:** ระบบ 3D AOI นี้ **สามารถนำมาใช้งานในสายการผลิตได้แบบมีเงื่อนไข** แต่ยังไม่ถึงระดับ World-Class ($\le 10\%$) สาเหตุเกิดจากค่าความผันแปรของตัวเครื่องจักรเอง ($\sigma_{\text{EV}} = 1.25\ \mu\text{m}$) ซึ่งสามารถปรับปรุงให้ลดลงเหลือต่ำกว่า $0.6\ \mu\text{m}$ ได้ด้วยการทำความสะอาดเลนส์ออปติคัลและปรับลดความเร็วในการเคลื่อนที่ของหัวกล้องลง $10\%$ ซึ่งจะดึงค่า $\%\text{GRR}$ ลงมาอยู่ที่ต่ำกว่า **$8.5\%$** กลายเป็นระบบที่สมบูรณ์แบบระดับโลก

### Quiz 3: การคำนวณผลได้สะสมตลอดสายการผลิต (Rolled Throughput Yield) และการวิเคราะห์ผลตอบแทนทางเศรษฐศาสตร์ของการยกระดับสู่ Six Sigma

**โจทย์:**  
โรงงานประกอบแผงวงจรอิเล็กทรอนิกส์ยานยนต์ขั้นสูงมีปริมาณการผลิตต่อปี $N_{\text{annual}} = 500,000$ แผ่นบอร์ด  
- แต่ละแผงวงจรมีจุดต่อและส่วนประกอบที่ต้องตรวจสอบรวม $O = 2,500$ โอกาสในการเกิดข้อบกพร่องต่อแผ่น (Total Opportunities per Board)
- สายการผลิตประกอบด้วย 6 สถานีต่อเนื่อง:
  1. Stencil Printing ($Y_1$)
  2. SMT High-Speed Placement ($Y_2$)
  3. SMT Fine-Pitch Placement ($Y_3$)
  4. Reflow Soldering ($Y_4$)
  5. 3D AOI & AXI Inspection ($Y_5$)
  6. Functional ICT/FCT Test ($Y_6$)
- **สถานการณ์เดิม (ระดับคุณภาพ 4-Sigma):**
  - อัตราข้อบกพร่องของกระบวนการคือ $DPMO_1 = 66.8\ \text{DPMO}$ ต่อสถานี
  - อัตราผลได้ต่อสถานีคำนวณจาก: $Y_i = (1 - DPMO \times 10^{-6})^{O/6}$ หรือประมาณการ First-Pass Yield รวมของทั้งสายการผลิตอยู่ที่ $RTY_1 = 84.6\%$ (บอร์ด $15.4\%$ ต้องถูกส่งเข้าสถานีซ่อมงาน Rework)
  - ต้นทุนเฉลี่ยในการนำบอร์ดที่มีข้อบกพร่องไปตรวจซ่อมแซมและบัดกรีซ้ำ: $C_{\text{rework}} = \$18.50$ ต่อแผ่น
  - ค่าใช้จ่ายในการรับประกันและเคลมสินค้าเสียหายในสนามใช้งาน (Warranty Field Failure Rate $0.15\%$): $C_{\text{warranty}} = \$150.00$ ต่อแผ่นที่หลุดรอด
- **สถานการณ์ใหม่หลังปรับปรุง DFA สู่ระดับ Six Sigma:**
  - ยกระดับกระบวนการด้วยระบบ Closed-Loop SMT และการออกแบบสมมาตรตามคัมภีร์บทเรียน 001–100 ทำให้ข้อบกพร่องลดลงเหลือ **Six Sigma ($DPMO_2 = 3.4\ \text{DPMO}$)**
  - อัตราผลได้สะสมรวมพุ่งสูงขึ้นเป็น $RTY_2 = 99.15\%$ (บอร์ดต้องซ่อมงานลดลงเหลือเพียง $0.85\%$)
  - อัตราของเสียหลุดรอดสู่ลูกค้าลดลงเหลือเกือบศูนย์ (Warranty Field Failure Rate ลดลงเหลือเพียง $0.002\%$)

**คำถาม:**
1. ในสถานการณ์เดิม (4-Sigma) จงคำนวณจำนวนบอร์ดต่อปีที่ต้องถูกส่งไปซ่อมงาน ($N_{\text{rework, 1}}$) และต้นทุนค่าซ่อมงานรวมต่อปี ($Cost_{\text{rework, 1}}$ ในหน่วยดอลลาร์)
2. ในสถานการณ์ใหม่ (Six Sigma) จงคำนวณจำนวนบอร์ดต่อปีที่ต้องซ่อมงาน ($N_{\text{rework, 2}}$) และต้นทุนค่าซ่อมงานใหม่ ($Cost_{\text{rework, 2}}$)
3. คำนวณผลรวมของต้นทุนที่ประหยัดได้ต่อปี (Annual Cost Savings: รวมทั้งค่าซ่อมงานภายในโรงงานและค่ารับประกันสินค้าเคลมในสนาม) ที่เกิดจากการยกระดับสู่ Six Sigma และสะท้อนถึงคุณค่าที่แท้จริงของการนำมาตรฐาน Senior Engineer Gold Standard ทั้ง 100 บทเรียนไปประยุกต์ใช้ในการทำงานจริง

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 3:

**1. คำนวณต้นทุนการซ่อมงานเดิม (4-Sigma):**
- อัตราของเสียภายในโรงงาน: $1 - RTY_1 = 1 - 0.846 = 0.154\ (15.4\%)$
- จำนวนบอร์ดที่ต้องซ่อมงานต่อปี:
  $$N_{\text{rework, 1}} = 500,000 \times 0.154 = 77,000\ \text{แผ่น}$$
- ต้นทุนค่าซ่อมงานต่อปี ($C_{\text{rework}} = \$18.50$):
  $$Cost_{\text{rework, 1}} = 77,000 \times \$18.50 = \$1,424,500\ \text{ต่อปี}$$
- ต้นทุนการเคลมประกันในสนาม (Field Warranty Failure $0.15\%$):
  $$N_{\text{warranty, 1}} = 500,000 \times 0.0015 = 750\ \text{แผ่น}$$
  $$Cost_{\text{warranty, 1}} = 750 \times \$150.00 = \$112,500\ \text{ต่อปี}$$
- **ต้นทุนความสูญเสียรวมเดิม:**
  $$Total\_Cost_1 = \$1,424,500 + \$112,500 = \$1,537,000\ \text{ต่อปี (มากกว่า 53 ล้านบาท!)}$$

---

**2. คำนวณต้นทุนการซ่อมงานใหม่ (Six Sigma):**
- อัตราของเสียภายในโรงงาน: $1 - RTY_2 = 1 - 0.9915 = 0.0085\ (0.85\%)$
- จำนวนบอร์ดที่ต้องซ่อมงานต่อปี:
  $$N_{\text{rework, 2}} = 500,000 \times 0.0085 = 4,250\ \text{แผ่น}$$
- ต้นทุนค่าซ่อมงานใหม่:
  $$Cost_{\text{rework, 2}} = 4,250 \times \$18.50 = \$78,625\ \text{ต่อปี}$$
- ต้นทุนการเคลมประกันในสนามใหม่ (Field Warranty Failure $0.002\%$):
  $$N_{\text{warranty, 2}} = 500,000 \times 0.00002 = 10\ \text{แผ่น}$$
  $$Cost_{\text{warranty, 2}} = 10 \times \$150.00 = \$1,500\ \text{ต่อปี}$$
- **ต้นทุนความสูญเสียรวมใหม่:**
  $$Total\_Cost_2 = \$78,625 + \$1,500 = \$80,125\ \text{ต่อปี}$$

$$\Delta Cost_{\text{savings}} = Total\_Cost_1 - Total\_Cost_2 = \$1,537,000 - \$80,125 = \mathbf{\$1,456,875\ \text{ต่อปี!}}$$
