## 1. ทฤษฎีวิศวรรรมเชิงลึก (高度なエンジニアリング理論)

ในวงจรชีวิตของผลิตภัณฑ์ฮาร์ดแวร์ระดับมืออาชีพ ตั้งแต่การผลิตล็อตนำร่อง (NPI / Pilot Run) ไปจนถึงการผลิตจำนวนมาก (Mass Production) ตัวถัง Ball Grid Array (BGA) ถือเป็นอุปกรณ์ที่มีความซับซ้อนในการควบคุมคุณภาพสูงสุด เนื่องจาก **จุดบัดกรีทั้งหมดถูกซ่อนอยู่ใต้ตัวถัง (Concealed Solder Joints)**

การรับประกันคุณภาพจึงไม่สามารถพึ่งพาระบบตรวจสอบด้วยแสงทั่วไป (Automated Optical Inspection - AOI) ได้ แต่ต้องอาศัย **การตรวจสอบแบบไม่ทำลายด้วยรังสีเอ็กซ์สามมิติ (3D Automated X-Ray Inspection / Computed Tomography - AXI/CT)** ควบคู่ไปกับ **การทดสอบแบบทำลายชิ้นงานเพื่อวิเคราะห์รากเหง้าความล้มเหลว (Destructive Failure Analysis: Dye-and-Pry & SEM/EDX)**

นอกจากนี้ เมื่อพบชิปที่มีข้อบกพร่อง วิศวกรต้องควบคุมกระบวนการ **ถอดและซ่อมแซมชิป (BGA Rework & Reballing Process)** ตามมาตรฐาน **IPC-7711/7721** อย่างเคร่งครัด เพื่อไม่ให้ความร้อนทำลายลายทองแดงบนบอร์ดหรือหลอมละลายชิ้นส่วนข้างเคียง

### 1.1 ฟิสิกส์ของการตรวจสอบด้วยรังสีเอ็กซ์ (X-Ray Inspection Physics)

การตรวจสอบจุดบัดกรีใต้ BGA แบบไม่ทำลายชิ้นงานอาศัยหลักการลดทอนของลำรังสีเอ็กซ์ผ่านเนื้อสสารตาม **กฎของเบียร์-แลมเบิร์ต (Beer-Lambert Law)**:

$$I(x) = I_0 \cdot \exp(-\mu \cdot x)$$

โดยที่:
- $I_0$ = ความเข้มเริ่มต้นของลำรังสีเอ็กซ์ที่ยิงออกมาจากหลอดกำเนิด
- $I(x)$ = ความเข้มของรังสีเอ็กซ์ที่ทะลุผ่านชิ้นงานไปตกกระทบฉากรับภาพ
- $x$ = ความหนาของวัตถุที่รังสีเดินทางผ่าน ($\text{cm}$)
- $\mu$ = สัมประสิทธิ์การดูดกลืนเชิงเส้น (Linear Attenuation Coefficient, $\text{cm}^{-1}$) ซึ่งแปรผันตามเลขอะตอม ($Z$) และความหนาแน่นของสสาร ($\rho$):
  $$\mu \propto \rho \cdot Z^4$$

เนื่องจากธาตุดีบุกและเงินในตะกั่วบัดกรี SAC305 ($Z_{\text{Sn}} = 50$) มีความหนาแน่นและเลขอะตอมสูงกว่าทองแดง ($Z_{\text{Cu}} = 29$), ซิลิคอน ($Z_{\text{Si}} = 14$), และเรซิน FR-4 มาก ลำรังสีเอ็กซ์จึงถูกดูดกลืนอย่างเข้มข้น ปรากฏเป็นภาพเงาสีเข้มจัดบนตัวรับสัญญาณ:
- **การตรวจจับโพรงอากาศ (Solder Void Detection):** รังสีทะลุผ่านช่องโพรงอากาศได้ง่ายกว่าเนื้อโลหะ ปรากฏเป็นจุดสว่าง (Bright White Spots) ภายในวงกลมมืดของเม็ดบอล
- **การตรวจสอบ 3D AXI / CT Slice Reconstruction:** ใช้การหมุนกวาดลำรังสีในแนวเฉียง (Oblique Angle) และประมวลผลอัลกอริทึม Tomosynthesis ตัดภาพระนาบในแนวแกน Z เพื่อแยกแยะรอยต่อบัดกรีระหว่าง **ฝั่งชิ้นส่วน (Package Interface)**, **ใจกลางเม็ดบอล (Ball Center)**, และ **ฝั่งแผ่นวงจร (PCB Pad Interface)** ทำให้ตรวจพบข้อบกพร่อง Head-in-Pillow (HiP) และ Pad Cratering ได้อย่างแม่นยำ

### 1.2 วิศวกรรมการซ่อมแซมและถอดประกอบ BGA ตามมาตรฐาน IPC-7711/7721

การถอดเปลี่ยนชิป BGA ที่ชำรุด (BGA Rework) ถือเป็นกระบวนการที่มีความเสี่ยงต่อความเสียหายของแผงวงจรสูงสุด หากควบคุมอุณหภูมิไม่ถูกต้อง แผงบอร์ดจะเกิดการแอ่นตัวบิดเบี้ยว (Warpage) หรือลายทองแดงบน PCB จะหลุดร่อน (Pad Peeling):

```
+-----------------------------------------------------------------------------------------+
|                  IPC-7711/7721 BGA Rework Thermal Profiling Requirements                |
|                                                                                         |
|   Temperature (°C)                                                                      |
|     260 ──┬───────────────────────────────────────────────── Peak: 245°C - 255°C       |
|           │                                                 (TAL: 45 - 75 seconds)      |
|     217 ──┼─────────────────────────────────────────▲─────── Liquidus Temp (SAC305)     |
|           │                                        / \                                  |
|     180 ──┼───────────────────────────────────────/───\───── Adjacent Component Limit   |
|           │                         ┌────────────/     \     (Must NEVER exceed 180°C!) |
|     160 ──┼───────────/─────────────┘ Bottom Preheater       (Delta T_Z <= 40°C)        |
|           │          /                Soak Zone (150°C - 170°C)                         |
|      25 ──┼─────────/                                                                   |
|           └───┴───────────┴───────────┴───────────┴───────────┴───────────┴───────────  |
|               0          60          120         180         240         300   Sec      |
+-----------------------------------------------------------------------------------------+
```

#### 1. กฎการควบคุมความต่างอุณหภูมิแกนดิ่ง ($\Delta T_Z$ Control via Bottom Preheater):
- ในการถอด BGA ห้ามเป่าลมร้อนจากหัวฉีดด้านบน (Top Nozzle) เพียงด้านเดียวเด็ดขาด!
- ต้องใช้ **แผ่นความร้อนอินฟราเรดหรือลมร้อนขนาดใหญ่ด้านล่าง (Bottom Preheater)** ปรับอุณหภูมิแผงวงจรทั้งแผ่นขึ้นสู่ระดับพรีฮีต **$150^\circ\text{C} - 170^\circ\text{C}$** ก่อน
- ควบคุมผลต่างอุณหภูมิระหว่างผิวด้านบนและผิวด้านล่างของแผงวงจรให้มีค่า:
  $$\Delta T_Z = |T_{\text{top}} - T_{\text{bottom}}| \le 40^\circ\text{C}$$
  เพื่อขจัดความเค้นดัดงอจากความร้อน (Thermal Bending Moment) ป้องกันไม่ให้บอร์ดโก่งงอเกินขีดจำกัด ($> 0.25\text{ mm}$)

#### 2. เขตหวงห้ามชิ้นส่วนข้างเคียง (Adjacent Component Rework Keep-Out Zone):
ลมร้อนที่ระบายออกจากปากหัวฉีด (Nozzle Lip Spillover) มีพลังงานความร้อนสูง ชิ้นส่วนข้างเคียงที่อยู่รอบ BGA จะต้องได้รับความร้อน **ไม่เกิน $180^\circ\text{C}$** เสมอ (มีระยะเผื่อความปลอดภัย $\ge 37^\circ\text{C}$ ก่อนถึงจุดหลอมเหลวของ SAC305 ที่ $217^\circ\text{C}$) เพื่อป้องกัน:
1. การเกิด Secondary Reflow ทำให้จุดบัดกรีของชิ้นส่วนข้างเคียงหลอมละลายจนเกิดอาการกระดกเอียง (Tombstoning)
2. การเสื่อมสภาพของชิ้นส่วนที่ไวต่อความชื้นและความร้อน (MSL Failure per J-STD-020)

**สูตรคำนวณระยะเว้นว่างขั้นต่ำรอบ BGA (Rework Keep-out Clearance):**
$$D_{\text{keepout}} \ge W_{\text{nozzle\_wall}} + D_{\text{air\_clearance}} + \Delta_{\text{tool\_tolerance}} \approx 3.5\text{ mm} - 5.0\text{ mm}$$

### 1.3 ระเบียบวิธีการวิเคราะห์ความล้มเหลวแบบทำลายชิ้นงาน (Destructive Failure Analysis)

เมื่อเกิดปัญหาจุดบัดกรี BGA ขาดวงจรในภาคสนาม วิศวกรต้องใช้เครื่องมือวิเคราะห์เชิงลึกเพื่อระบุโหมดความล้มเหลว (Failure Modes):

| ระเบียบวิธีวิเคราะห์ (Method) | ขั้นตอนการทดสอบตามมาตรฐาน | ลักษณะภาพที่ตรวจพบ | โหมดความล้มเหลวที่บ่งชี้ (Identified Root Cause) |
| :--- | :--- | :--- | :--- |
| **Dye-and-Pry Test (IPC-9701)** | 1. หยดน้ำยาย้อมสีแดง (Dykem Red Dye) แทรกซึมใต้ BGA ในห้องสุญญากาศ<br>2. อบแห้งที่ $100^\circ\text{C}$ นาน 30 นาที<br>3. ใช้เครื่องกลงัดดึงตัวถัง BGA ให้หลุดร่อนออกจากแผงวงจร (Mechanical Prying)<br>4. ส่องกล้องจุลทรรศน์ตรวจดูคราบสีย้อมแดง | คราบสีย้อมสีแดงจะแทรกซึมเข้าไปเฉพาะในบริเวณที่มี **รอยแตกร้าวล้า (Fatigue Crack)** ก่อนการงัด | - **คราบสีแดงคลุม $> 80\%$ ของรอยต่อ:** จุดบัดกรีแตกร้าวสะสมมาก่อนการงัด (Field Failure)<br>- **ผิวทองแดง/ตะกั่วแวววาวไร้สีแดง:** รอยขาดเกิดจากแรงงัดในการทดสอบเอง |
| **Cross-Section SEM / EDX** | 1. หล่อชิ้นงานในเรซินอีพอกซีเย็น (Cold Mounting)<br>2. ตัดขวางผ่านระนาบกึ่งกลางของแถวบอลบัดกรี<br>3. ขัดผิวด้วยกระดาษทรายละเอียดและผงเพชร (Diamond Polish down to $0.05\ \mu\text{m}$)<br>4. ส่องกราดด้วยกล้อง SEM และยิงรังสีเอกซ์วิเคราะห์ธาตุ (EDX) | แสดงภาพผลึกชั้นโลหะผสมระหว่างโลหะ (IMC Layer) ระหว่างทองแดงและดีบุก | - **รอยแตกวิ่งตัดเนื้อตะกั่ว (Bulk Solder Crack):** ความล้าจากวงจรอุณหภูมิ (Thermal Fatigue)<br>- **รอยแตกวิ่งตัดชั้น IMC ($Cu_6Sn_5$ / $Cu_3Sn$):** แรงกระแทกตกหล่นฉับพลัน (Drop Shock / Brittle Cleavage)<br>- **เนื้อเรซิน FR-4 ใต้แพดฉีกขาด (Pad Cratering):** แผงบอร์ดโก่งงอเกินพิกัดเชิงกล |

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例 - Shippai Jirei)

**เหตุการณ์:** สายการผลิตบอร์ดประมวลผลสถานีฐาน 5G (5G Telecom Baseband Processing Unit) ที่ใช้ชิป High-end FPGA BGA 1,517 พิน ($40 \times 40\text{ mm}$, Pitch $1.0\text{ mm}$) พบอาการบูตไม่ติดในขั้นตอนการตรวจสอบฟังก์ชันขั้นสุดท้าย ช่างซ่อมบำรุงจึงนำบอร์ดเข้าสู่สถานี Rework เพื่อถอดเปลี่ยนชิป FPGA ตัวใหม่:
1. หลังจากการเปลี่ยนชิปและประกอบเสร็จสิ้น บอร์ดสามารถบูตเข้าสู่ระบบได้ แต่เมื่อส่งไปทดสอบความเครียดอุณหภูมิ (Burn-in Test) ชิปหน่วยความจำ DDR4 SDRAM ที่ติดตั้งอยู่ข้างเคียง (ห่างจากขอบ FPGA $1.8\text{ mm}$) เกิดข้อผิดพลาดบิตสุ่ม (Random Memory Corruption)
2. เมื่อทำการถอดชิป FPGA ออกมาตรวจสอบซ้ำอีกครั้ง พบว่า **แลนด์แพดทองแดงบนแผง PCB หลุดลอกติดออกมากับชิ้นส่วนถึง 14 พิน (Pad Peeling / Pad Cratering)** ทำให้แผงวงจรมูลค่ากว่า 150,000 บาทต้องถูกทิ้งกลายเป็นขยะอิเล็กทรอนิกส์ (Scrap)

#### การวิเคราะห์หาสาเหตุรากเหง้า (Root Cause Analysis - RCA):
1. **การละเมิดระยะ Keep-Out Zone ของหัวฉีด Rework:**
   - ชิป DDR4 BGA ถูกจัดวางห่างจากขอบของ FPGA เพียง $1.8\text{ mm}$ (ซึ่งต่ำกว่าเกณฑ์ความปลอดภัยขั้นต่ำ $4.0\text{ mm}$)
   - เมื่อสวมหัวฉีดลมร้อนขนาด $42 \times 42\text{ mm}$ ลงบนตัวถัง FPGA ปากขอบของหัวฉีดได้พ่นลมร้อนอุณหภูมิ $250^\circ\text{C}$ ล้นออกมารดลงบนตัวถัง DDR4 โดยตรง
   - การวัดอุณหภูมิด้วยเทอร์โมคัปเปิลพบว่า จุดบัดกรีของชิป DDR4 มีอุณหภูมิพุ่งสูงถึง **$228^\circ\text{C}$** ซึ่งเกินจุดหลอมเหลวของตะกั่ว SAC305 ($217^\circ\text{C}$) เม็ดบอลจึงหลอมละลายซ้ำสอง (Secondary Reflow) โดยไม่มีสารฟลักซ์คอยปกป้อง ก่อให้เกิดข้อบกพร่อง Head-in-Pillow และ Solder Bridging ใต้ชิปหน่วยความจำ
2. **สาเหตุของทองแดงแพดหลุดลอก (Pad Peeling):**
   - **การให้ความร้อนไม่สมดุล (Zero Bottom Pre-heat):** ช่างซ่อมบำรุงเปิดใช้เฉพาะหัวฉีดลมร้อนด้านบน โดยตั้งค่าเครื่องทำความร้อนด้านล่างไว้เพียง $80^\circ\text{C}$ ทำให้เกิดผลต่างอุณหภูมิ $\Delta T_Z > 160^\circ\text{C}$ แผงบอร์ดเกิดการโก่งตัวแอ่นขึ้นตรงจุดกึ่งกลาง สร้างแรงดึงเฉือนกระชากแพด
   - **การทำความสะอาดแพดผิดวิธี (Aggressive Pad Dressing):** ช่างใช้หัวแร้งปลายมีดปรับอุณหภูมิสูงถึง $380^\circ\text{C}$ ร่วมกับลวดซับตะกั่ว (Solder Braid) กดรูดลงบนหน้าสัมผัสอย่างรุนแรง ความร้อนสะสมที่สูงเกินไปทำลายพันธะกาวอีพอกซีที่ยึดแผ่นทองแดงกับใยแก้ว FR-4 ประกอบกับแรงกดครูดทางกล ส่งผลให้แลนด์แพดฉีกขาดหลุดลอยออกมา

#### มาตรการแก้ไขเชิงวิศวกรรม (Engineering Countermeasures):
1. **กำหนดกฎ DFM Rework Keep-Out Zone ในระบบ CAD อย่างเด็ดขาด:**
   - กำหนดกฎ DRC (Design Rule Check) บังคับระยะห่างรอบตัวถัง BGA ขนาดใหญ่ ($\ge 27 \times 27\text{ mm}$) ให้มีระยะเว้นว่างปลอดอุปกรณ์ (Clearance Zone) **ไม่น้อยกว่า $4.5\text{ mm}$** โดยรอบ
   - หากมีชิ้นส่วนจำเป็นต้องวางใกล้กว่านั้น ต้องระบุในคู่มือซ่อมบำรุงให้ปิดทับด้วย **แผ่นฟอยล์อะลูมิเนียมกันความร้อนร่วมกับเทปทนความร้อนแคปตอน (Kapton Tape Heat Shielding)** ก่อนทำการ Rework เสมอ
2. **ปรับปรุงโปรไฟล์เตา Rework และกระบวนการเตรียมผิวแพด:**
   - ล็อกโปรไฟล์ความร้อนของเครื่อง Rework Station: ปรับอุณหภูมิ Bottom Preheater ขึ้นเป็น $160^\circ\text{C}$ เพื่อคุมค่า $\Delta T_Z \le 35^\circ\text{C}$
   - ยกเลิกการใช้หัวแร้งขูดลวดซับตะกั่ว และเปลี่ยนมาใช้ **หัวดูดสุญญากาศลมร้อนแบบไร้การสัมผัส (Non-Contact Hot Air Solder Scavenger)** ในการดูดเก็บเศษตะกั่วส่วนเกิน ขจัดปัญหาแลนด์แพดหลุดลอกได้อย่างสิ้นเชิง ($100\%$ Zero Pad Peeling)

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณการกระจายความร้อนของหัวฉีดลมร้อนและระยะปลอดภัย Rework Keep-Out Distance

**โจทย์:**  
ในกระบวนการถอดเปลี่ยนชิป BGA ขนาด $35 \times 35\text{ mm}$ หัวฉีดลมร้อนเฉพาะจุด (Hot Air Nozzle) พ่นลมร้อนที่อุณหภูมิ $T_{\text{nozzle}} = 250^\circ\text{C}$ ลงบนตัวถัง โดยมีแผ่นพรีฮีตเตอร์ด้านล่างคุมอุณหภูมิบอร์ดไว้ที่ $T_{\text{preheat}} = 150^\circ\text{C}$  
เนื่องจากการรั่วไหลของกระแสลมร้อนออกจากขอบปากหัวฉีด (Heat Spillover) อุณหภูมิบนผิวแผงวงจรที่ระยะห่าง $r$ (มิลลิเมตร) วัดจากขอบนอกของหัวฉีด มีการกระจายตัวลดลงตามแบบจำลองเกาส์เซียน (Gaussian Thermal Dissipation Model):
$$T(r) = T_{\text{preheat}} + (T_{\text{nozzle}} - T_{\text{preheat}}) \cdot \exp\left( -\frac{r^2}{2\sigma^2} \right)$$
กำหนดค่าคงที่การแพร่กระจายความร้อนของลมร้อน: $\sigma = 2.10\text{ mm}$  
ตามมาตรฐาน IPC-7711 อุณหภูมิสูงสุดที่ยอมรับได้บนจุดบัดกรีของชิ้นส่วนข้างเคียงเพื่อป้องกันไม่ให้เกิด Secondary Reflow คือ **$T_{\text{safe, max}} = 180^\circ\text{C}$**

1. จงคำนวณหาค่า **ระยะห่างปลอดภัยขั้นต่ำ ($r_{\text{safe}}$)** จากขอบหัวฉีดถึงชิ้นส่วนข้างเคียงเพื่อให้อุณหภูมิไม่เกิน $180^\circ\text{C}$
2. หากปากขอบของหัวฉีดมีความหนาของผนังโลหะและระยะเผื่อสวม (Nozzle Wall Thickness + Clearance) รวม $W_{\text{lip}} = 1.25\text{ mm}$ จงคำนวณหา **ระยะ Keep-Out Zone รวม ($D_{\text{keepout}}$)** ที่ต้องกำหนดในไฟล์ CAD วัดจากขอบตัวถัง BGA
3. หากวิศวกร Layout วางตัวเก็บประจุ 0402 ไว้ห่างจากขอบ BGA เพียง $2.0\text{ mm}$ จงคำนวณอุณหภูมิที่ตัวเก็บประจุนี้จะต้องเผชิญ และวิเคราะห์ผลกระทบต่อคุณภาพจุดบัดกรีของตัวเก็บประจุ

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณหาระยะปลอดภัยขั้นต่ำ ($r_{\text{safe}}$):**
ตั้งสมการขีดจำกัดอุณหภูมิ:
$$T(r_{\text{safe}}) \le 180^\circ\text{C}$$
$$150 + (250 - 150) \cdot \exp\left( -\frac{r_{\text{safe}}^2}{2\sigma^2} \right) \le 180$$
$$100 \cdot \exp\left( -\frac{r_{\text{safe}}^2}{2\sigma^2} \right) \le 30$$
$$\exp\left( -\frac{r_{\text{safe}}^2}{2\sigma^2} \right) \le 0.30$$
ใส่ลอการิทึมธรรมชาติทั้งสองข้าง:
$$-\frac{r_{\text{safe}}^2}{2\sigma^2} \le \ln(0.30) \approx -1.20397$$
$$\frac{r_{\text{safe}}^2}{2\sigma^2} \ge 1.20397$$
$$r_{\text{safe}}^2 \ge 1.20397 \times 2 \times \sigma^2$$
แทนค่า $\sigma = 2.10\text{ mm}$ ($\sigma^2 = 4.41\text{ mm}^2$):
$$r_{\text{safe}}^2 \ge 1.20397 \times 2 \times 4.41 = 10.619\ \text{mm}^2$$
$$r_{\text{safe}} \ge \sqrt{10.619} \approx 3.2587\text{ mm} \approx 3.26\text{ mm}$$
**คำตอบส่วนที่ 1:** ระยะห่างปลอดภัยจากขอบหัวฉีดต้องไม่น้อยกว่า **$3.26\text{ mm}$**

---

**2. คำนวณระยะ Keep-Out Zone รวมใน CAD ($D_{\text{keepout}}$):**
วัดจากขอบตัวถัง BGA ออกไป:
$$D_{\text{keepout}} = W_{\text{lip}} + r_{\text{safe}} = 1.25\text{ mm} + 3.26\text{ mm} = 4.51\text{ mm}$$
เมื่อรวมค่าความคลาดเคลื่อนเชิงกลของหัวฉีด (Tolerance margin $+0.25\text{ mm}$):
$$D_{\text{keepout, CAD}} \ge 4.76\text{ mm} \approx 4.80\text{ mm}$$
**คำตอบส่วนที่ 2:** ต้องกำหนดกฎ Keep-Out Zone ในระบบ CAD ไว้ที่อย่างน้อย **$4.8\text{ mm}$** โดยรอบตัวถัง BGA

---

**3. คำนวณอุณหภูมิของตัวเก็บประจุที่ระยะ $2.0\text{ mm}$ จากขอบ BGA:**
- ระยะจากขอบปากหัวฉีด:
  $$r = 2.0\text{ mm} - W_{\text{lip}} = 2.0 - 1.25 = 0.75\text{ mm}$$
- คำนวณอุณหภูมิ:
  $$T(0.75) = 150 + 100 \cdot \exp\left( -\frac{(0.75)^2}{2 \times 4.41} \right) = 150 + 100 \cdot \exp\left( -\frac{0.5625}{8.82} \right)$$
  $$-\frac{0.5625}{8.82} \approx -0.06378$$
  $$\exp(-0.06378) \approx 0.9382$$
  $$T(0.75) = 150 + (100 \times 0.9382) = 150 + 93.82 = 243.82^\circ\text{C}$$

**บทวิเคราะห์ความเสียหาย:**  
อุณหภูมิที่ตัวเก็บประจุ 0402 ได้รับจะพุ่งสูงถึง **$243.8^\circ\text{C}$** ซึ่งสูงกว่าจุดหลอมเหลวของตะกั่ว SAC305 ($217^\circ\text{C}$) ไปอย่างมาก! ตะกั่วบัดกรีของตัวเก็บประจุจะ **หลอมละลายกลายเป็นของเหลวอย่างสมบูรณ์ (Complete Secondary Reflow)** และเนื่องจากไม่มีการทาฟลักซ์ใหม่ แรงตึงผิวจะดึงให้ตัวเก็บประจุกระดกตั้งขึ้น (Tombstoning) หรือตะกั่วไหลไปเชื่อมช็อตกับแพดข้างเคียง เกิดของเสียร้ายแรงทันที

</details>

### ข้อที่ 2: การวิเคราะห์ความเค้นดัดงอจากผลต่างอุณหภูมิบน-ล่าง ($\Delta T_Z$) ระหว่างการ Rework

**โจทย์:**  
แผงวงจรเซิร์ฟเวอร์ความหนา $T_{\text{PCB}} = 2.40\text{ mm}$ ($0.0024\text{ m}$) ผลิตจากวัสดุ FR-4 High-$T_g$ มีค่าโมดูลัสความยืดหยุ่นยังผล $E = 22\ \text{GPa}$ และสัมประสิทธิ์การขยายตัวในแนวราบ $\alpha = 15.0\ \text{ppm}/^\circ\text{C}$  
ขนาดของโซนที่ได้รับความร้อนเฉพาะจุดใต้หัวฉีด Rework มีความยาวกว้าง $L = 60\text{ mm}$ ($0.060\text{ m}$)  
ในขั้นตอนการถอดชิป BGA:
- ผิวด้านบนถูกความร้อนจากหัวฉีดลมร้อน: $T_{\text{top}} = 250^\circ\text{C}$
- กรณีที่ A (กระบวนการบกพร่อง / No Bottom Preheat): ผิวด้านล่างมีอุณหภูมิเพียง $T_{\text{bottom, A}} = 90^\circ\text{C}$ ($\Delta T_Z = 160^\circ\text{C}$)
- กรณีที่ B (กระบวนการตามมาตรฐาน IPC-7711): มีการเปิดพรีฮีตเตอร์ด้านล่าง ทำให้ผิวด้านล่างมีอุณหภูมิ $T_{\text{bottom, B}} = 165^\circ\text{C}$ ($\Delta T_Z = 85^\circ\text{C}$)

1. จากทฤษฎีการดัดงอของแผ่นระนาบเนื่องจากการกระจายอุณหภูมิไม่สม่ำเสมอ รัศมีความโค้งของการดัดงอ ($R$) คำนวณได้จาก:
   $$\frac{1}{R} = \frac{\alpha \cdot \Delta T_Z}{T_{\text{PCB}}}$$
   จงคำนวณหารัศมีความโค้ง $R_A$ และ $R_B$ ของทั้งสองกรณี
2. คำนวณหาระยะการโก่งตัวแอ่นสูงสุดที่จุดกึ่งกลาง (Maximum Deflection: $\delta \approx \frac{L^2}{8R}$) ของทั้งสองกรณี
3. ตามเกณฑ์ IPC-7711 ระยะการโก่งตัวแอ่นสูงสุดระหว่างการ Rework ต้องไม่เกิน **$\delta_{\text{limit}} = 0.25\text{ mm}$** เพื่อป้องกันไม่ให้เนื้อเรซิน FR-4 ฉีกขาด (Pad Cratering) จงตัดสินว่ากรณีใดผ่านเกณฑ์

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณหารัศมีความโค้ง $R$ ของทั้งสองกรณี:**
- **กรณีที่ A ($\Delta T_Z = 160^\circ\text{C}$):**
  $$\frac{1}{R_A} = \frac{(15.0 \times 10^{-6}\ /^\circ\text{C}) \times 160^\circ\text{C}}{2.40 \times 10^{-3}\ \text{m}} = \frac{2.40 \times 10^{-3}}{2.40 \times 10^{-3}} = 1.0\ \text{m}^{-1}$$
  $$R_A = \frac{1}{1.0} = 1.0\ \text{m}\ (1,000\ \text{mm})$$

- **กรณีที่ B ($\Delta T_Z = 85^\circ\text{C}$):**
  $$\frac{1}{R_B} = \frac{(15.0 \times 10^{-6}\ /^\circ\text{C}) \times 85^\circ\text{C}}{2.40 \times 10^{-3}\ \text{m}} = \frac{1.275 \times 10^{-3}}{2.40 \times 10^{-3}} \approx 0.53125\ \text{m}^{-1}$$
  $$R_B = \frac{1}{0.53125} \approx 1.8824\ \text{m}\ (1,882.4\ \text{mm})$$

---

**2. คำนวณระยะการโก่งตัวแอ่นสูงสุด ($\delta$):**
ความยาวของโซนความร้อน: $L = 60\text{ mm} \implies L^2 = 3,600\ \text{mm}^2$

- **กรณีที่ A:**
  $$\delta_A = \frac{L^2}{8 \cdot R_A} = \frac{3,600\ \text{mm}^2}{8 \times 1,000\ \text{mm}} = \frac{3,600}{8,000} = 0.450\ \text{mm}\ (450\ \mu\text{m})$$

- **กรณีที่ B:**
  $$\delta_B = \frac{L^2}{8 \cdot R_B} = \frac{3,600\ \text{mm}^2}{8 \times 1,882.4\ \text{mm}} = \frac{3,600}{15,059} \approx 0.239\ \text{mm}\ (239\ \mu\text{m})$$

---

**3. การตัดสินผลตามเกณฑ์ IPC-7711 ($\delta_{\text{limit}} = 0.25\text{ mm}$):**
- **กรณีที่ A (ไม่ใช้พรีฮีตเตอร์ด้านล่างที่เหมาะสม):**
  $$\delta_A = 0.450\text{ mm} > 0.25\text{ mm} \quad (\text{สอบตกอย่างรุนแรง - FAIL})$$
  แผงบอร์ดโก่งตัวถึง $0.45\text{ mm}$ ซึ่งจะสร้างความเค้นดึงฉีกขาด (Tensile Peeling Stress) มหาศาลใต้แพดทองแดง ส่งผลให้เกิด **Pad Cratering ทันที** เมื่อช่างดึงยกตัวถัง BGA ขึ้น
- **กรณีที่ B (ใช้พรีฮีตเตอร์ด้านล่าง $165^\circ\text{C}$):**
  $$\delta_B = 0.239\text{ mm} \le 0.25\text{ mm} \quad (\text{ผ่านเกณฑ์ - PASS})$$
  การควบคุมอุณหภูมิพรีฮีตเตอร์ช่วยลดระยะแอ่นตัวลงเหลือต่ำกว่า $0.25\text{ mm}$ ปกป้องโครงสร้างแลนด์แพดทองแดงและเนื้อเรซิน FR-4 ให้ปลอดภัยจากการฉีกขาด

</details>

### ข้อที่ 3: การแปลผลการทดสอบ Dye-and-Pry และการจำแนกโหมดความล้มเหลวตามมาตรฐาน IPC-9701

**โจทย์:**  
กล่องเซนเซอร์เรดาร์ยานยนต์ที่ล้มเหลวจากสนามทดสอบ (Field Failed Unit) ถูกส่งมาวิเคราะห์หาสาเหตุรากเหง้าด้วยการทดสอบ **Dye-and-Pry Test ตามมาตรฐาน IPC-9701**  
หลังจากการแทรกซึมของสีย้อมสีแดง (Red Dye Penetrant) และงัดดึงตัวถัง BGA ออก ภาพถ่ายจากกล้องจุลทรรศน์กำลังขยายสูงบนแลนด์แพดของเม็ดบอลมุม A1 (ซึ่งเป็นพินที่ตรวจพบวงจรเปิด) แสดงผลดังนี้:
- พื้นที่หน้าตัดทั้งหมดของแพด: $A_{\text{pad}} = 0.125\ \text{mm}^2$
- มีคราบสีย้อมสีแดงเข้มปกคลุมพื้นที่: $A_{\text{dye}} = 0.108\ \text{mm}^2$
- พื้นที่ส่วนที่เหลือ $A_{\text{bright}} = 0.017\ \text{mm}^2$ แสดงผิวเนื้อตะกั่วฉีกขาดใหม่ที่แวววาว (Fresh ductile tear)
- การตรวจสอบชั้นระนาบการแยกตัว (Fracture Plane Analysis): พบว่ารอยแตกย้อมสีแดงเกิดขึ้นที่ **ชั้นระหว่างเนื้อตะกั่ว SAC305 กับชั้นโลหะผสม $\text{Cu}_6\text{Sn}_5$ IMC ด้านบนผิวทองแดง**

1. จงคำนวณหาสัดส่วนเปอร์เซ็นต์ของพื้นที่รอยแตกร้าวล้าเดิมก่อนการทดสอบ ($\%A_{\text{crack}}$)
2. ตามเกณฑ์มาตรฐาน IPC-9701 ข้อใดต่อไปนี้คือข้อสรุปที่ถูกต้อง:
   - ก. ความล้มเหลวเกิดจากแรงกระแทกงัดในการทดสอบ Dye-and-Pry เอง
   - ข. ความล้มเหลวเกิดจากรอยแตกร้าวสะสมก่อนหน้าที่ใช้งานในภาคสนามจริง
3. จำแนกโหมดความล้มเหลวระหว่าง **Type 1 (Bulk Solder Fatigue)**, **Type 2 (Intermetallic IMC Cleavage)**, และ **Type 3 (Pad Cratering / Resin Tear)** พร้อมอธิบายสาเหตุรากเหง้าเชิงกลศาสตร์

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณและการวิเคราะห์:**

**1. คำนวณเปอร์เซ็นต์พื้นที่รอยแตกร้าวเดิม ($\%A_{\text{crack}}$):**
$$\%A_{\text{crack}} = \left( \frac{A_{\text{dye}}}{A_{\text{pad}}} \right) \times 100\% = \left( \frac{0.108\ \text{mm}^2}{0.125\ \text{mm}^2} \right) \times 100\% = 86.4\%$$
**คำตอบส่วนที่ 1:** รอยแตกเดิมที่ถูกสีย้อมแดงซึมผ่านคิดเป็น **$86.4\%$ ของพื้นที่หน้าตัดแพดทั้งหมด**

---

**2. การตัดสินผลตามมาตรฐาน IPC-9701:**
- ตามข้อกำหนด IPC-9701: หากมีคราบสีย้อมแดงปกคลุมพื้นที่หน้าตัดของจุดบัดกรีเกินกว่า **$25\%$** ถือว่าจุดบัดกรีนั้นได้เกิดความเสียหายจากการใช้งานมาก่อนแล้ว (Pre-existing Fatigue Damage) และหากเกิน **$70\%$** ถือว่าจุดบัดกรีนั้นได้ขาดวงจรทางไฟฟ้า (Electrical Open Circuit) ไปเรียบร้อยแล้วในภาคสนาม
- พื้นที่สีย้อมแดงสูงถึง $86.4\%$ ในขณะที่เนื้อตะกั่วสดที่ฉีกขาดจากการงัดมีเพียง $13.6\%$
- **ข้อสรุปที่ถูกต้อง:** **ข้อ ข (ความล้มเหลวเกิดจากรอยแตกร้าวสะสมจากการใช้งานในภาคสนามจริง)** การงัดในการทดสอบ Dye-and-Pry เพียงแค่ดึงเศษตะกั่ว $13.6\%$ ที่เหลืออยู่ให้ขาดออกจากกันเพื่อเปิดดูรอยโรคเท่านั้น

---

**3. การจำแนกโหมดความล้มเหลว (Failure Mode Classification):**
- **โหมดความล้มเหลวที่ตรวจพบ:** **Type 2: Intermetallic IMC Cleavage Fracture (การแตกหักแบบเปราะที่ชั้นโลหะผสม)**
- **การวิเคราะห์รากเหง้าเชิงกลศาสตร์ (Mechanics Root Cause):**
  1. รอยแตกร้าวไม่ได้เกิดขึ้นในเนื้อตะกั่ว (ไม่ใช่ Type 1 ซึ่งมักเกิดจาก Thermal Cycling ช้า ๆ) และเนื้อเรซิน FR-4 ไม่ได้ฉีกขาด (ไม่ใช่ Type 3 ซึ่งเกิดจากบอร์ดดัดงอ)
  2. การที่รอยแตกวิ่งเลียบตามแนวรอยต่อระหว่างเนื้อผลึก $\text{Cu}_6\text{Sn}_5$ IMC กับเนื้อทองแดง บ่งชี้ว่าจุดบัดกรีเผชิญกับ **แรงกระแทกเชิงกลฉับพลัน (Mechanical Shock & High Strain-Rate Vibration)** เช่น การตกหล่นหรือแรงสั่นสะเทือนความถี่สูงจากเครื่องยนต์
  3. ชั้น IMC มีความเปราะสูงตามธรรมชาติ (High Hardness, Low Fracture Toughness) เมื่อเกิดแรงกระแทกซ้ำ ๆ จะเกิดรอยแตกแบบ Cleavage วิ่งลุกลามข้ามรอยต่อ จนกระทั่งเหลือพื้นที่สัมผัสไม่ถึง $15\%$ และทำให้สัญญาณไฟฟ้าขาดหายในที่สุด

</details>
