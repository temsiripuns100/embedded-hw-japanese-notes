## 1. ทฤษฎีวิศวรรรมเชิงลึก (高度なエンジニアリング理論)

ในบรรดาโครงสร้างทั้งหมดบนแผงวงจรพิมพ์หลายชั้น (Multilayer PCB) **รูเจาะและกระบอกรูเวีย (Vias & Through-Holes)** ถือเป็นโครงสร้างที่มีความเสี่ยงต่อการพังทลายทางความร้อนและกลศาสตร์มากที่สุด เนื่องจากรูเวียต้องทำหน้าที่เชื่อมโยงสัญญาณและพลังงานข้ามระนาบต่าง ๆ ในแนวดิ่ง ท่ามกลางแรงขยายตัวในแนวแกน Z ของเนื้อเรซิน FR-4

วิศวกรอาวุโสต้องเข้าใจข้อจำกัดทางกายภาพของ **อัตราส่วนความลึกต่อขนาดรูเจาะ (Aspect Ratio Limits)**, **ความสามารถในการกระจายน้ำยาชุบทองแดง (Electroplating Throwing Power)**, **การคำนวณขนาด Annular Ring เพื่อป้องกันรูเจาะทะลุขอบ (Hole Breakout) ตามมาตรฐาน IPC-6012 Class 2 และ Class 3**, และการกำหนด **ระยะหวงห้ามของการคว้านล้างติ่งเวีย (Back-drilling Keep-out Geometries)**

### 1.1 นิยามของอัตราส่วน Aspect Ratio และขีดจำกัดการชุบทองแดง (Plating Throwing Power)

อัตราส่วน Aspect Ratio ($AR$) คือตัวชี้วัดความยากง่ายในการชุบโลหะทองแดงลงในรูเจาะ:

$$AR = \frac{\text{Board Thickness } (T)}{\text{Drill Diameter } (D_{\text{drill}})}$$

#### 1. ความสามารถในการซึมลึกของน้ำยาชุบ (Throwing Power - $TP$):
ในอ่างชุบทองแดงด้วยไฟฟ้า (Electroplating Tank) น้ำยาเคมีต้องไหลเวียนผ่านรูเจาะเพื่อนำไอออนทองแดง ($\text{Cu}^{2+}$) เข้าไปทำปฏิกิริยารีดักชันที่ผนังรู:
- ยิ่งรูมีขนาดเล็กและลึก ($AR$ สูง) ความต้านทานชลศาสตร์ (Hydraulic Flow Resistance) จะยิ่งสูง น้ำยาเคมีไม่สามารถไหลเวียนเข้าสู่กึ่งกลางของรูได้ทัน
- **นิยามของ Throwing Power:**
  $$TP = \frac{t_{\text{center}}}{t_{\text{surface}}} \times 100\%$$
  โดยที่ $t_{\text{center}}$ คือความหนาของทองแดงชุบที่กึ่งกลางรูเวีย และ $t_{\text{surface}}$ คือความหนาของทองแดงชุบบนผิวบอร์ด

#### 2. พฤติกรรมของความหนาทองแดงตามค่า Aspect Ratio:
- **$AR \le 6 : 1$:** กระบวนการชุบปกติ $TP \ge 85\% - 95\%$ ทองแดงเคลือบหนาสม่ำเสมอตลอดทั้งรู
- **$AR = 8 : 1 - 10 : 1$:** ระดับมาตรฐานอุตสาหกรรม ต้องใช้น้ำยาชุบชนิดพิเศษและการกวนน้ำยาแบบพัลส์ (Periodic Pulse Reverse Plating) ได้ $TP \approx 70\% - 80\%$
- **$AR > 10 : 1$ (เช่น $12:1 - 14:1$):** ขีดจำกัดขั้นสูง (Advanced / Extreme Capability) เกิดปรากฏการณ์ **Dog-bone Plating Profile** โดยทองแดงจะพอกหนาที่ปากรู แต่บางเฉียบที่กึ่งกลางกระบอกรู ($TP < 50\%$)
- หาก $t_{\text{center}} < 18\ \mu\text{m}$ (ต่ำกว่าเกณฑ์ IPC Class 2 ที่ $20\ \mu\text{m}$ หรือ Class 3 ที่ $25\ \mu\text{m}$) ปลอกทองแดงจะไม่สามารถทนทานต่อแรงดึงในแนวแกน Z ได้ และจะขาดสะบั้นทันทีในเตาอบ Reflow

### 1.2 มาตรฐานวงแหวนทองแดงรอบรูเจาะ (Annular Ring) ตามมาตรฐาน IPC-6012

วงแหวนทองแดง (Annular Ring) คือเนื้อทองแดงของแผ่นแลนด์แพดที่เหลืออยู่ล้อมรอบรูเจาะ หลังจากการเจาะและการกัดกรดเสร็จสิ้น:

$$AR_{\text{width}} = \frac{D_{\text{pad}} - D_{\text{drill}}}{2}$$

```
+-----------------------------------------------------------------------------------------+
|                  IPC-6012 Annular Ring Performance Classification                      |
|                                                                                         |
|   [ Class 1: General Consumer ]  [ Class 2: Dedicated Business ]  [ Class 3: High Rel ]|
|                                                                                         |
|       Up to 180° Breakout!            Up to 90° Breakout Allowed       ZERO BREAKOUT!   |
|       (Min spacing maintained)        (Tangency: 0 mil on inner)       Min 25 μm Inner  |
|                                                                        Min 50 μm Outer  |
|          ┌──────────────┐                ┌──────────────┐             ┌──────────────┐  |
|          │    Pad       │                │    Pad       │             │   Pad        │  |
|        ┌─┴────┐         │              ┌─┴────┐         │             │  ┌────────┐  │  |
|        │ Hole │         │              │ Hole │         │             │  │  Hole  │  │  |
|        └─┬────┘         │              └──┬───┘         │             │  └────────┘  │  |
|          └──────────────┘                 └─────────────┘             └──────────────┘  |
|         Hole cuts out 180°              Hole breaks out 90°           Uniform Ring All  |
+-----------------------------------------------------------------------------------------+
```

| เกณฑ์ตามมาตรฐาน IPC-6012 | Class 1 (General Electronics) | Class 2 (Industrial & Computing) | Class 3 (High Reliability / Automotive / Aerospace) |
| :--- | :--- | :--- | :--- |
| **วงแหวนชั้นใน (Internal Annular Ring)** | ยอมให้รูเจาะทะลุขอบ (Breakout) ได้ถึง $180^\circ$ | ยอมให้ทะลุขอบได้ถึง $90^\circ$ (อนุญาตให้ขอบรูสัมผัสขอบแพดพอดี: Tangency $0\ \text{mil}$) | **ห้ามรูเจาะทะลุขอบเด็ดขาด (Zero Breakout Allowed)** ต้องมีเนื้อทองแดงเหลือรอบรู $\ge 25\ \mu\text{m}$ ($1\ \text{mil}$) |
| **วงแหวนชั้นนอก (External Annular Ring)** | ยอมให้ทะลุขอบได้ $180^\circ$ | ความกว้างวงแหวนขั้นต่ำ $\ge 25\ \mu\text{m}$ ($1\ \text{mil}$) หรือทะลุขอบได้ $90^\circ$ | ความกว้างวงแหวนขั้นต่ำ $\ge 50\ \mu\text{m}$ ($2\ \text{mil}$) โดยห้ามทะลุขอบ |
| **ความหนาทองแดงในรู (Barrel Thickness)** | เฉลี่ย $\ge 18\ \mu\text{m}$ จุดต่ำสุด $\ge 13\ \mu\text{m}$ | เฉลี่ย $\ge 20\ \mu\text{m}$ จุดต่ำสุด $\ge 18\ \mu\text{m}$ | เฉลี่ย $\ge 25\ \mu\text{m}$ จุดต่ำสุด $\ge 20\ \mu\text{m}$ |

#### การคำนวณขนาดแลนด์แพดขั้นต่ำตามหลักการรวมความคลาดเคลื่อน (Tolerance Stackup):
เพื่อให้มั่นใจว่าแผงวงจร Class 3 จะปราศจาก Hole Breakout วิศวกรต้องคำนวณขนาด Capture Pad ขั้นต่ำจากผลรวมความคลาดเคลื่อนเชิงสถิติ (Root-Sum-Square - RSS):

$$D_{\text{pad, min}} = D_{\text{drill}} + 2 \cdot AR_{\text{req}} + 2 \cdot \sqrt{\Delta_{\text{drill}}^2 + \Delta_{\text{layer}}^2 + \Delta_{\text{artwork}}^2}$$

โดยที่:
- $D_{\text{drill}}$ = ขนาดดอกสว่านที่ใช้เจาะ ($\text{mm}$)
- $AR_{\text{req}}$ = ความกว้างวงแหวนขั้นต่ำที่มาตรฐานบังคับ ($0.025\text{ mm}$ สำหรับชั้นใน Class 3)
- $\Delta_{\text{drill}}$ = ความคลาดเคลื่อนของหัวสว่านเจาะ (Drill Wander $\approx \pm 25 - 40\ \mu\text{m}$)
- $\Delta_{\text{layer}}$ = ความคลาดเคลื่อนในการประกบชั้นเลเยอร์ (Layer Misregistration $\approx \pm 35 - 50\ \mu\text{m}$)
- $\Delta_{\text{artwork}}$ = ความคลาดเคลื่อนของการถ่ายฟิล์มและกัดกรด ($\approx \pm 15 - 25\ \mu\text{m}$)

### 1.3 วิศวกรรมการคว้านล้างติ่งเวีย (Back-Drilling DFM & Keep-Out Geometries)

ในช่องสัญญาณความเร็วสูงระดับ $\ge 25\text{ Gbps}$ (PCIe Gen4/5, PAM4 SerDes) รู Through-hole Via จะต้องผ่านกระบวนการ **Back-drilling (Controlled Depth Counterboring)** เพื่อขจัดติ่งเวียส่วนเกิน (Via Stub) ทิ้ง:

```
+-----------------------------------------------------------------------------------------+
|                  Back-Drill Geometry and Inner Layer Keep-Out Clearances                |
|                                                                                         |
|       Layer 1 (Top)      Signal Enters Here!                                            |
|       ══════════════════════════╪════════════════════════════════                       |
|       Layer 3 (Signal)   Signal Leaves via Stripline!                                   |
|       ══════════════════════════╪════════════════════════════════                       |
|                                 │ Residual Stub h_stub <= 0.15 mm                       |
|       Layer 4 (Reference GND)   ▼                                                       |
|       ═══════════════════       ═════════════════════════════════  Back-drill Clearance |
|       Layer 5 (Signal)   [░░░░░░░░░░░░░░] Trace must clear!       ◄───────────────────► |
|       ═══════════════════[              ]════════════════════════  D_BD = D_drill + 0.25|
|                          [ Back-drilled ]                                               |
|                          [ Oversized    ]                                               |
|                          [ Hole Cutout! ]                                               |
|       Layer 16 (Bottom)  [              ]                                               |
|       ═══════════════════┴──────────────┴════════════════════════                       |
|                          ▲ Back-drill Tool enters from bottom!                          |
+-----------------------------------------------------------------------------------------+
```

1. **ขนาดดอกสว่าน Back-Drill ($D_{\text{BD}}$):**
   - เพื่อตัดล้างปลอกทองแดงและรอยหยักด้านข้างออกให้หมดจด ดอกสว่าน Back-drill จะต้องมีขนาดใหญ่กว่ารูเจาะเดิมเสมอ:
     $$D_{\text{BD}} = D_{\text{drill}} + 0.20\text{ mm}\ \text{ถึง}\ 0.25\text{ mm}\ (8\text{ - }10\text{ mil})$$
   - หากรูเดิมเจาะขนาด $0.25\text{ mm}$ ดอกสว่าน Back-drill จะมีขนาดเส้นผ่านศูนย์กลางถึง **$0.45\text{ mm} - 0.50\text{ mm}$**
2. **ระยะหวงห้ามบนชั้นสัญญาณภายในที่ถูกคว้านทะลุผ่าน (Bypassed Layer Keep-Out Zone):**
   - ในชั้นสัญญาณภายในที่สว่าน Back-drill เจาะทะลุผ่าน (เช่น ชั้น L5 ถึง L16) รูเจาะจะมีขนาดใหญ่ขึ้นเป็น $D_{\text{BD}}$
   - เส้นสัญญาณหรือระนาบทองแดงใด ๆ ที่วิ่งอยู่ในชั้นเหล่านี้ จะต้องรักษาระยะห่างจากจุดกึ่งกลางของเวีย:
     $$R_{\text{keepout}} \ge \frac{D_{\text{BD}}}{2} + \Delta_{\text{BD\_wander}} + S_{\text{dielectric\_clearance}}$$
   - หากวิศวกรละเลยและเดินเส้นสัญญาณชิดเกินไป ดอกสว่าน Back-drill ที่มีขนาดใหญ่จะ **ตัดเฉือนเส้นสัญญาณข้างเคียงขาดสะบั้น** หรือก่อให้เกิดการลัดวงจรระหว่างชั้น

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例 - Shippai Jirei)

**เหตุการณ์:** การผลิตบอร์ดคอมพิวเตอร์ประมวลผลระบบขับเคลื่อนอัตโนมัติ (Automotive ADAS Domain Controller, บอร์ด 14 ชั้น ความหนา $2.40\text{ mm}$) ในล็อตการทดสอบความเชื่อถือได้ (Reliability Qualification Lot):
1. ในขั้นตอนการทดสอบ Thermal Shock ($-40^\circ\text{C} \leftrightarrow +125^\circ\text{C}$ จำนวน 500 รอบ) พบอัตราความล้มเหลวขาดวงจร (Open Circuit Failures) สูงถึง $21.4\%$ บนเส้นสัญญาณบัส CAN-FD และพินจ่ายไฟ
2. ช่องสัญญาณส่งข้อมูลกล้องความเร็วสูง MIPI CSI-2 (ทำงานผ่านคู่สายอนุพันธ์ความเร็วสูงที่ผ่านการ Back-drilling) เกิดอาการช็อตลัดวงจรแบบไม่คงที่ (Intermittent Short) ลงสู่ระนาบกราวด์ชั้น L8


#### การวิเคราะห์หาสาเหตุรากเหง้า (Root Cause Analysis - RCA):
1. **สาเหตุของปลอกทองแดงขาดทะลุ (High-AR Plating Thinning & Barrel Rupture):**
   - วิศวกรออกแบบเลือกใช้ขนาดรูเจาะ Through-hole Via เล็กพิเศษ $D_{\text{drill}} = 0.20\text{ mm}$ บนแผงบอร์ดที่มีความหนาถึง $2.40\text{ mm}$ คิดเป็น Aspect Ratio สูงถึง:
     $$AR = \frac{2.40\text{ mm}}{0.20\text{ mm}} = 12 : 1$$
   - โรงงานผู้ผลิตมีสายชุบทองแดงมาตรฐานที่รองรับค่า $AR$ ได้ไม่เกิน $8:1$ การหมุนเวียนของน้ำยาชุบเข้าไปในรูเจาะแคบไม่เพียงพอ (Throwing Power ต่ำเพียง $25\%$)
   - ผลการตัดตรวจหน้าตัด (Microsection Analysis) พบว่า ความหนาของทองแดงชุบบริเวณกึ่งกลางของรูเวียมีความหนาเฉลี่ยเพียง **$7.5 - 9.0\ \mu\text{m}$** (ต่ำกว่ามาตรฐาน Class 3 ที่กำหนด $\ge 25\ \mu\text{m}$ ไปถึง $64\%$)
   - เมื่อแผงวงจรเผชิญกับการขยายตัวทางความร้อนในแนวแกน Z แรงดึงมหาศาลได้ฉีกปลอกทองแดงบาง ๆ ให้ขาดออกจากกันตรงกึ่งกลางกระบอกรู
2. **สาเหตุของการลัดวงจรจากการ Back-drilling (Back-Drill Keep-Out Collision):**
   - ในชั้นใน L8 วิศวกร Layout ได้เดินเส้นทองแดงกราวด์เฉียดใกล้รูเวียของ MIPI CSI-2 โดยรักษาระยะห่างตามกฎทั่วไป ($0.125\text{ mm}$ จากขอบรูเจาะเดิม $0.20\text{ mm}$)
   - แต่ในการผลิต สว่าน Back-drill ขนาด $D_{\text{BD}} = 0.45\text{ mm}$ เจาะลงมาล้างติ่งเวีย ประกอบกับความคลาดเคลื่อนของการเจาะสว่าน ($\pm 0.05\text{ mm}$)
   - คมสว่าน Back-drill ได้กินเฉือนเข้าไปในเนื้อทองแดงของชั้น L8 และเศษเสี้ยนทองแดงที่แตกออก (Copper Smear / Burr) ได้ไปแตะช็อตเข้ากับเส้นสัญญาณ ก่อให้เกิดการลัดวงจร

#### มาตรการแก้ไขเชิงวิศวกรรม (Engineering Countermeasures):
1. **ปรับลดค่า Aspect Ratio สู่ขอบเขตปลอดภัย:**
   - ปรับขนาดรูเจาะ Through-hole Via ทั่วไปบนบอร์ดหนา $2.4\text{ mm}$ จาก $0.20\text{ mm}$ ขึ้นเป็น **$0.25\text{ mm}$ ($AR = 9.6 : 1$)**
   - สั่งล็อกสเปกให้โรงงานใช้ระบบชุบทองแดงแบบ Pulse Reverse Plating รับประกันความหนาทองแดงกึ่งกลางรูขั้นต่ำ $\ge 25\ \mu\text{m}$ ตามมาตรฐาน IPC-6012 Class 3 อย่างเคร่งครัด
2. **สร้างกฎ DRC Back-Drill Keep-Out อัตโนมัติใน CAD:**
   - กำหนดกฎ Clearance เฉพาะสำหรับ Back-drilling ในโปรแกรม Altium/Cadence โดยบังคับให้ในชั้นในที่ถูก Back-drill เจาะทะลุผ่าน ต้องรักษาระยะห่างทองแดงจากศูนย์กลางเวียไม่น้อยกว่า:
     $$\text{Clearance}_{\text{BD}} \ge \frac{0.45\text{ mm}}{2} + 0.15\text{ mm} = 0.375\text{ mm}\ (15\ \text{mil})$$
   - ขจัดความเสี่ยงที่สว่าน Back-drill จะเจาะเฉือนโดนลายวงจรข้างเคียงได้อย่างเด็ดขาด

### 3.2 ประโยคตรวจแบบที่ใช้จริงในโรงงานญี่ปุ่น (指摘事項 - Shiteki Jikō)

#### ตัวอย่างข้อคิดเห็นที่ 1: การตรวจพบค่า Aspect Ratio สูงเกินพิกัด และความเสี่ยงต่อ Barrel Crack
> **日本語:**  
> 「板厚2.4mmの高多層基板において、貫通スルーホールのドリル径がφ0.20mm（アスペクト比12:1）で設計されています。一般的なプリント基板製造ラインのめっきスローイングパワー（能力限界10:1）を著しく超過しており、バレル中央部のめっき銅厚が10μm以下に痩せ細る恐れがあります。車載環境のサーマルサイクル試験時にZ軸熱膨張ストレスによりバレルクラック（断線故障）が発生するリスクが極めて高いため、ドリル径をφ0.25mm以上（アスペクト比9.6:1以下）へ拡大するか、製造仕様書に高均一電解めっき（パルスめっき）の適用を必須条件として明記願います。」  
> **คำแปลภาษาไทย:**  
> "ในแผงวงจรหลายชั้นความหนา 2.4 มม. มีการออกแบบรูเจาะ Through-hole Via ด้วยขนาดดอกสว่านเพียง 0.20 มม. (คิดเป็น Aspect Ratio สูงถึง 12:1) ซึ่งเกินกว่าขีดความสามารถในการกระจายน้ำยาชุบ (Throwing Power ขีดจำกัด 10:1) ของสายการผลิตแผงวงจรทั่วไปอย่างมีนัยสำคัญ เสี่ยงต่อการที่ความหนาทองแดงชุบกึ่งกลางรูจะลีบเล็กลงต่ำกว่า 10 ไมครอน เนื่องจากมีความเสี่ยงสูงมากที่จะเกิดรอยแตกในกระบอกรู (Barrel Crack) จากความเค้นขยายตัวในแนวแกน Z ระหว่างการทดสอบ Thermal Cycle ในยานยนต์ ขอให้ขยายขนาดดอกสว่านขึ้นเป็นไม่ต่ำกว่า 0.25 มม. (Aspect Ratio ไม่เกิน 9.6:1) หรือระบุในแบบสั่งผลิตให้บังคับใช้กระบวนการชุบพัลส์ความสม่ำเสมอสูงอย่างเด็ดขาด"

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณขนาดแลนด์แพดชั้นในขั้นต่ำตามมาตรฐาน IPC-6012 Class 3 (Annular Ring Tolerance Stackup)

**โจทย์:**  
โรงงานผลิตแผงวงจรอิเล็กทรอนิกส์อากาศยานและยานยนต์ขั้นสูง (High-Reliability Class 3) กำลังกำหนดสเปกของเลเยอร์สแตกอัปสำหรับแผงวงจร 16 ชั้น:
- ขนาดของดอกสว่านเจาะกลไก (Mechanical Drill Bit Diameter): $D_{\text{drill}} = 0.250\text{ mm}$ ($250\ \mu\text{m}$)
- ตามข้อกำหนดของมาตรฐาน **IPC-6012 Class 3 (Targeted Zero Breakout)**: วงแหวนทองแดงคงเหลือภายในชั้นใน (Internal Annular Ring) ในสภาวะเลวร้ายที่สุดหลังการผลิต จะต้องมีความกว้างไม่น้อยกว่า **$AR_{\text{min}} = 25.0\ \mu\text{m}$ ($1.0\ \text{mil}$)** ตลอดแนวเส้นรอบวง $360^\circ$
- ค่าความคลาดเคลื่อนทางสถิติของกระบวนการผลิตในโรงงานมีดังนี้:
  - ความคลาดเคลื่อนจากการเยื้องศูนย์ของสว่าน (Drill Wander / Runout): $\Delta_{\text{drill}} = \pm 35.0\ \mu\text{m}$
  - ความคลาดเคลื่อนจากการประกบเลเยอร์และการยืดหดตัวของฟิล์ม (Layer Misregistration & Material Shrinkage): $\Delta_{\text{layer}} = \pm 45.0\ \mu\text{m}$
  - ความคลาดเคลื่อนจากการถ่ายภาพและการกัดกรดทองแดง (Phototool & Etch Tolerance): $\Delta_{\text{etch}} = \pm 15.0\ \mu\text{m}$

1. จงคำนวณหาค่าความคลาดเคลื่อนรวมเชิงรัศมี (Total Radial Registration Error: $\Delta R_{\text{total}}$) โดยใช้วิธีการรวมความคลาดเคลื่อนแบบสถิติ Root-Sum-Square (RSS)
2. คำนวณหา **ขนาดเส้นผ่านศูนย์กลางของ Capture Pad ชั้นในขั้นต่ำ ($D_{\text{pad, min}}$)** ที่วิศวกรต้องกำหนดในไฟล์ CAD เพื่อรับประกันการผ่านเกณฑ์ IPC-6012 Class 3 อย่างสมบูรณ์ $100\%$
3. หากวิศวกรใช้ขนาดแพดเดิมที่ $D_{\text{pad}} = 0.350\text{ mm}$ จงคำนวณว่าในกรณีเลวร้ายที่สุด รูเจาะจะเกิดอาการทะลุขอบแลนด์ (Breakout) ลึกเข้าไปกี่ไมครอน

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณความคลาดเคลื่อนรวมเชิงรัศมีแบบสถิติ (RSS):**
$$\Delta R_{\text{total}} = \sqrt{\Delta_{\text{drill}}^2 + \Delta_{\text{layer}}^2 + \Delta_{\text{etch}}^2}$$
แทนค่า:
$$\Delta R_{\text{total}} = \sqrt{(35.0)^2 + (45.0)^2 + (15.0)^2} = \sqrt{1,225 + 2,025 + 225} = \sqrt{3,475} \approx 58.95\ \mu\text{m}$$
**คำตอบส่วนที่ 1:** รัศมีของรูเจาะอาจเคลื่อนตัวเบี่ยงเบนจากจุดศูนย์กลางแพดได้สูงสุดถึง **$58.95\ \mu\text{m}$**

---

**2. คำนวณขนาด Capture Pad ขั้นต่ำ ($D_{\text{pad, min}}$):**
ในสภาวะที่รูเจาะเคลื่อนตัวเบี่ยงเบนไปในทิศทางหนึ่งมากที่สุดด้วยระยะ $\Delta R_{\text{total}}$:
ระยะห่างจากขอบรูเจาะถึงขอบแพดด้านที่ใกล้ที่สุด (Worst-case Annular Ring Width: $AR_{\text{actual}}$) ต้องไม่น้อยกว่า $AR_{\text{min}} = 25.0\ \mu\text{m}$:
$$AR_{\text{actual}} = \frac{D_{\text{pad}} - D_{\text{drill}}}{2} - \Delta R_{\text{total}} \ge AR_{\text{min}}$$
จัดรูปสมการเพื่อหา $D_{\text{pad}}$:
$$\frac{D_{\text{pad}} - D_{\text{drill}}}{2} \ge AR_{\text{min}} + \Delta R_{\text{total}}$$
$$D_{\text{pad}} \ge D_{\text{drill}} + 2 \cdot (AR_{\text{min}} + \Delta R_{\text{total}})$$
แทนค่า:
$$D_{\text{pad, min}} = 250.0\ \mu\text{m} + 2 \times (25.0\ \mu\text{m} + 58.95\ \mu\text{m})$$
$$D_{\text{pad, min}} = 250.0 + 2 \times (83.95) = 250.0 + 167.90 = 417.90\ \mu\text{m} \approx 0.420\text{ mm}\ (16.5\ \text{mil})$$

และหากใช้การบวกความคลาดเคลื่อนแบบเชิงเส้นตรงเลวร้ายสุด (Worst-Case Linear Sum):
$$\Delta R_{\text{linear}} = 35 + 45 + 15 = 95\ \mu\text{m}$$
$$D_{\text{pad, worst}} = 250 + 2 \times (25 + 95) = 250 + 240 = 490\ \mu\text{m}\ (0.490\text{ mm})$$

**คำตอบส่วนที่ 2:**  
ตามหลักการทางสถิติ RSS วิศวกรต้องกำหนดขนาด Internal Pad ใน CAD ไม่น้อยกว่า **$0.420\text{ mm}$ ($420\ \mu\text{m}$)** (หรือแนะนำที่ **$0.450\text{ mm}$** เพื่อให้มี Margin ปลอดภัยสำหรับ Class 3)

---

**3. การคำนวณกรณีใช้แพดเดิม $D_{\text{pad}} = 0.350\text{ mm}$ ($350\ \mu\text{m}$):**
- รัศมีของแพด: $R_{\text{pad}} = \frac{350}{2} = 175.0\ \mu\text{m}$
- รัศมีของรูเจาะ: $R_{\text{drill}} = \frac{250}{2} = 125.0\ \mu\text{m}$
- วงแหวนในอุดมคติ:
  $$AR_{\text{nominal}} = 175.0 - 125.0 = 50.0\ \mu\text{m}$$
- วงแหวนจริงเมื่อสว่านเยื้องตัวตามค่า RSS ($\Delta R = 58.95\ \mu\text{m}$):
  $$AR_{\text{worst}} = AR_{\text{nominal}} - \Delta R = 50.0 - 58.95 = -8.95\ \mu\text{m}$$

**ผลการวิเคราะห์ความเสียหาย:**  
ค่าวงแหวนติดลบ ($-8.95\ \mu\text{m}$) หมายความว่า รูเจาะได้ **ทะลุเลยขอบแลนด์แพดออกไป $8.95\ \mu\text{m}$ (เกิด Hole Breakout)**  
และหากคิดตามแบบ Linear Sum รูจะทะลุขอบถึง $-45.0\ \mu\text{m}$ (ทะลุขอบไปเกือบครึ่งหนึ่งของขนาดรูเจาะ!) ซึ่งจะไปตัดเฉือนเส้นสัญญาณที่เชื่อมต่ออยู่จนขาดวงจร และสอบตกเกณฑ์มาตรฐาน IPC-6012 Class 3 ทันที $100\%$

</details>

### ข้อที่ 2: การคำนวณความหนาทองแดงชุบกึ่งกลางรูเวียจากค่า Throwing Power (Plating Barrel Thickness vs. AR)

**โจทย์:**  
แผงวงจรเซิร์ฟเวอร์ความหนา $T_{\text{board}} = 2.80\text{ mm}$ ($2,800\ \mu\text{m}$) มีรูเจาะ Through-hole Via ขนาดเส้นผ่านศูนย์กลาง $D = 0.25\text{ mm}$ ($250\ \mu\text{m}$)  
ในกระบวนการชุบทองแดงด้วยไฟฟ้า (Galvanic Copper Plating):
- ความหนาของทองแดงชุบบนผิวหน้าบอร์ด (Surface Plating Thickness): $t_{\text{surface}} = 38.0\ \mu\text{m}$
- ประสิทธิภาพการกระจายน้ำยาชุบของอ่างเคมี (Throwing Power: $TP$) แปรผกผันกับ Aspect Ratio ($AR$) ตามสมการเชิงประจักษ์ของโรงงาน:
  $$TP = \frac{100\%}{1 + 0.065 \cdot (AR)^{1.5}}$$
- ตามมาตรฐาน **IPC-6012 Class 3** กำหนดให้:
  - ความหนาเฉลี่ยของปลอกทองแดงในรูเวีย (Average Barrel Thickness): ต้องไม่น้อยกว่า $25.0\ \mu\text{m}$
  - ความหนาขั้นต่ำสุดที่จุดใดจุดหนึ่งในรูเวีย (Minimum Isolated Thickness): ต้องไม่น้อยกว่า $20.0\ \mu\text{m}$

1. จงคำนวณหาค่า Aspect Ratio ($AR$) ของรูเจาะนี้
2. คำนวณหาค่า Throwing Power ($TP$) ของกระบวนการชุบ
3. คำนวณหาความหนาของปลอกทองแดงที่กึ่งกลางของรูเวีย ($t_{\text{center}} = t_{\text{surface}} \cdot TP$)
4. ตัดสินว่ากระบวนการนี้ผ่านเกณฑ์มาตรฐาน IPC-6012 Class 3 หรือไม่ และหากต้องการให้ $t_{\text{center}} \ge 25.0\ \mu\text{m}$ บนบอร์ดหนานี้ ดอกสว่านเจาะจะต้องมีขนาดเส้นผ่านศูนย์กลางขั้นต่ำเท่าใด?

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณค่า Aspect Ratio ($AR$):**
$$AR = \frac{T_{\text{board}}}{D} = \frac{2.80\text{ mm}}{0.25\text{ mm}} = 11.20 : 1$$

---

**2. คำนวณหาค่า Throwing Power ($TP$):**
พจน์ยกกำลัง:
$$(AR)^{1.5} = (11.20)^{1.5} = \sqrt{(11.20)^3} = \sqrt{1,404.928} \approx 37.482$$
คำนวณตัวหาร:
$$1 + 0.065 \times 37.482 = 1 + 2.4363 = 3.4363$$
คำนวณ $TP$:
$$TP = \frac{100\%}{3.4363} \approx 29.10\%$$
**คำตอบส่วนที่ 2:** ประสิทธิภาพการซึมลึกของน้ำยาชุบอยู่ที่เพียง **$29.10\%$**

---

**3. คำนวณความหนาทองแดงที่กึ่งกลางรูเวีย ($t_{\text{center}}$):**
$$t_{\text{center}} = t_{\text{surface}} \cdot TP = 38.0\ \mu\text{m} \times 0.2910 \approx 11.06\ \mu\text{m}$$
**คำตอบส่วนที่ 3:** ความหนาของทองแดงชุบกึ่งกลางรูมีค่าเพียง **$11.06\ \mu\text{m}$**

---

**4. การตัดสินผลและการคำนวณขนาดสว่านใหม่:**
- **การตัดสิน:** ค่าที่ได้ $11.06\ \mu\text{m}$ ต่ำกว่าเกณฑ์ขั้นต่ำสุดของ Class 3 ($20.0\ \mu\text{m}$) อย่างมาก $\to$ **สอบตกอย่างสิ้นเชิง (FAIL)** ปลอกทองแดงบางเกินไปและจะขาดทะลุทันทีเมื่อบอร์ดร้อน
- **คำนวณขนาดสว่านใหม่เพื่อให้ได้ $t_{\text{center}} \ge 25.0\ \mu\text{m}$:**
  ต้องการ $TP_{\text{req}}$:
  $$TP_{\text{req}} = \frac{t_{\text{center, req}}}{t_{\text{surface}}} = \frac{25.0\ \mu\text{m}}{38.0\ \mu\text{m}} \approx 0.6579 = 65.79\%$$
  ตั้งสมการหา $AR_{\text{max}}$:
  $$\frac{1}{1 + 0.065 \cdot (AR)^{1.5}} \ge 0.6579$$
  $$1 + 0.065 \cdot (AR)^{1.5} \le \frac{1}{0.6579} \approx 1.520$$
  $$0.065 \cdot (AR)^{1.5} \le 0.520$$
  $$(AR)^{1.5} \le \frac{0.520}{0.065} = 8.00$$
  ยกกำลัง $\frac{2}{3}$:
  $$AR_{\text{max}} \le (8.00)^{2/3} = (\sqrt[3]{8.00})^2 = 2^2 = 4.00$$

  คำนวณขนาดเส้นผ่านศูนย์กลางสว่านขั้นต่ำ ($D_{\text{min}}$):
  $$D_{\text{min}} = \frac{T_{\text{board}}}{AR_{\text{max}}} = \frac{2.80\text{ mm}}{4.00} = 0.70\text{ mm}$$

**บทวิเคราะห์ระดับ Senior:**  
- การขยายขนาดสว่าน Through-hole ถึง $0.70\text{ mm}$ บนบอร์ดความหนาแน่นสูงเป็นไปไม่ได้ทางกายภาพ
- **ทางออกทางวิศวกรรมที่แท้จริง (Real-World Solutions):**
  1. ยกระดับกระบวนการชุบของโรงงาน โดยใช้ **ระบบชุบเคมีไฟฟ้าแบบ Pulse Reverse Plating ร่วมกับน้ำยา High-Throwing Power Chemistry** ซึ่งสามารถผลักดันให้ $TP \ge 80\%$ ที่ $AR = 10:1$ ได้
  2. เปลี่ยนสถาปัตยกรรมบอร์ดจาก Through-hole ล้วน มาใช้ **สถาปัตยกรรม HDI (Blind & Buried Vias)** เพื่อลดความลึกของรูเจาะในแต่ละช่วงชั้น ทำให้ $AR$ ในแต่ละช่วงไม่เกิน $6:1$

### ข้อที่ 3: การคำนวณระยะหวงห้าม Back-Drilling Keep-Out Zone บนชั้นสัญญาณภายใน

**โจทย์:**  
บนแผงวงจรส่งสัญญาณ 56 Gbps PAM4 เลเยอร์สแตกอัป 20 ชั้น ความหนาบอร์ด $3.20\text{ mm}$  
สัญญาณความเร็วสูงเดินทางจากชั้นบน L1 มุดลงไปวิ่งในระนาบ Stripline ชั้น L4 (ความลึก $0.45\text{ mm}$)  
รู Through-hole Via เดิมเจาะด้วยดอกสว่านขนาด $D_{\text{drill}} = 0.25\text{ mm}$  
กระบวนการ Back-drilling จะเจาะคว้านล้างติ่งเวียจากผิวด้านล่าง L20 ขึ้นมาจนถึงใต้ชั้น L4 โดยมีพารามิเตอร์ของกระบวนการดังนี้:
- ดอกสว่าน Back-drill มีขนาดใหญ่กว่ารูเดิม: $D_{\text{BD}} = 0.45\text{ mm}$ ($450\ \mu\text{m}$)
- ความคลาดเคลื่อนตำแหน่งศูนย์กลางสว่าน Back-drill (Back-drill Registration Wander): $\Delta_{\text{BD}} = \pm 0.050\text{ mm}$ ($50\ \mu\text{m}$)
- ในชั้นใน L8 (ซึ่งเป็นชั้นที่สว่าน Back-drill เจาะทะลุผ่าน) มีเส้นสัญญาณไมโครสตริปอื่นวิ่งอยู่
- ข้อกำหนดด้านความเป็นฉนวน (Dielectric Electrical Clearance): ระยะห่างขั้นต่ำระหว่างขอบหลุมเจาะ Back-drill ถึงขอบทองแดงของเส้นสัญญาณ ต้องไม่น้อยกว่า $S_{\text{clearance}} = 0.125\text{ mm}$ ($125\ \mu\text{m}$)

1. จงคำนวณหารัศมีทางกายภาพสูงสุดที่คมสว่าน Back-drill สามารถกินขยายออกไปได้จากจุดกึ่งกลางพิกัดเดิม ($R_{\text{cut, max}}$)
2. คำนวณหา **รัศมีของเขตหวงห้ามปลอดทองแดง (Keep-Out Radius: $R_{\text{keepout}}$)** ในชั้นใน L8 ที่ต้องกำหนดในโปรแกรม CAD วัดจากจุดศูนย์กลางของเวีย
3. หากวิศวกร Layout กำหนดระยะ Keep-out วัดจากขอบของรูเจาะเดิม ($0.25\text{ mm}$) ออกไปเพียง $0.150\text{ mm}$ จงคำนวณระยะห่างจริงที่จะเกิดขึ้นระหว่างขอบสว่าน Back-drill กับเส้นสัญญาณ และตัดสินว่าเสี่ยงต่อการเกิดการลัดวงจรหรือความเสียหายทางกายภาพหรือไม่

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณหารัศมีตัดขยายสูงสุดของสว่าน Back-drill ($R_{\text{cut, max}}$):**
- รัศมีปกติของดอกสว่าน Back-drill:
  $$R_{\text{BD, nominal}} = \frac{D_{\text{BD}}}{2} = \frac{0.450\text{ mm}}{2} = 0.225\text{ mm}\ (225\ \mu\text{m})$$
- ในกรณีเลวร้ายที่สุดที่สว่านเบี่ยงเบนเยื้องศูนย์ด้วยระยะ $\Delta_{\text{BD}} = 0.050\text{ mm}$ ($50\ \mu\text{m}$):
  $$R_{\text{cut, max}} = R_{\text{BD, nominal}} + \Delta_{\text{BD}} = 0.225\text{ mm} + 0.050\text{ mm} = 0.275\text{ mm}\ (275\ \mu\text{m})$$
**คำตอบส่วนที่ 1:** คมสว่าน Back-drill สามารถกินขยายออกไปได้ไกลสุดถึงรัศมี **$0.275\text{ mm}$** จากศูนย์กลาง

---

**2. คำนวณหารัศมีเขตหวงห้ามปลอดทองแดงใน CAD ($R_{\text{keepout}}$):**
ต้องรวมระยะฉนวนปลอดภัย $S_{\text{clearance}} = 0.125\text{ mm}$:
$$R_{\text{keepout}} = R_{\text{cut, max}} + S_{\text{clearance}} = 0.275\text{ mm} + 0.125\text{ mm} = 0.400\text{ mm}\ (400\ \mu\text{m})$$
หรือคิดเป็นขนาดเส้นผ่านศูนย์กลางของวงกลม Keep-Out (Keep-Out Diameter):
$$D_{\text{keepout}} = 2 \cdot R_{\text{keepout}} = 2 \times 0.400\text{ mm} = 0.800\text{ mm}\ (31.5\ \text{mil})$$
**คำตอบส่วนที่ 2:** ในชั้นใน L8 ต้องกำหนดรัศมี Keep-Out ไม่น้อยกว่า **$0.400\text{ mm}$** (หรือ $D_{\text{keepout}} \ge 0.800\text{ mm}$)

---

**3. การวิเคราะห์กรณีวิศวกรเผื่อระยะเพียง $0.150\text{ mm}$ จากขอบรูเดิม:**
- รัศมีรูเดิม: $R_{\text{drill}} = \frac{0.250}{2} = 0.125\text{ mm}$
- ตำแหน่งของเส้นสัญญาณใน CAD วัดจากจุดศูนย์กลางเวีย:
  $$R_{\text{trace}} = R_{\text{drill}} + 0.150\text{ mm} = 0.125\text{ mm} + 0.150\text{ mm} = 0.275\text{ mm}$$
- เปรียบเทียบกับรัศมีคมสว่าน Back-drill สูงสุด ($R_{\text{cut, max}} = 0.275\text{ mm}$):
  $$ระยะห่างจริง = R_{\text{trace}} - R_{\text{cut, max}} = 0.275\text{ mm} - 0.275\text{ mm} = 0.000\text{ mm}\ (0\ \mu\text{m}!)$$

**บทสรุปความเสียหาย:**  
ระยะห่างเหลือศูนย์! คมสว่าน Back-drill จะ **พุ่งเข้าเฉือนตัดขอบของเส้นสัญญาณในชั้น L8 โดยตรง (Direct Mechanical Gouging)** ทำให้เส้นสัญญาณขาดวงจร หรือเกิดสะเก็ดทองแดงครูดไปแตะช็อตกับระนาบอ้างอิง เกิดของเสียร้ายแรงในทันที  
**กฎ DFM ที่ถูกต้อง:** ห้ามคำนวณ Keep-out จากรูเจาะเดิม แต่ต้องคำนวณจาก **ขนาดดอกสว่าน Back-drill รวมความคลาดเคลื่อนเสมอ!**

</details>
