## 1. ทฤษฎีวิศวรรรมเชิงลึก (高度なエンジニアリング理論)

ในกระบวนการผลิตแผงวงจรพิมพ์เชิงอุตสาหกรรม ลายเส้นทองแดง (Copper Traces) ที่ปรากฏในไฟล์ CAD/Gerber ไม่สามารถแปลงสภาพเป็นเส้นโลหะบนแผ่นบอร์ดได้แบบ $1 : 1$ ด้วยความสมบูรณ์แบบทางเรขาคณิต กระบวนการถ่ายภาพลายพิมพ์ (Photolithography), การชุบทองแดงด้วยไฟฟ้า (Electroplating), และการกัดกรดเคมี (Chemical Etching) ล้วนมีข้อจำกัดทางฟิสิกส์และเคมี

วิศวกรอาวุโสต้องเข้าใจ **กลไกการชดเชยการกัดกรด (Etch Compensation Mechanics)**, **การป้องกันหลุมดักกรด (Acid Trap Prevention)**, **การควบคุมการกระจายความหนาแน่นกระแสชุบด้วย Copper Thieving (Galvanic Current Density Leveling)**, และการเขียนข้อกำหนดควบคุมความต้านทานจำเพาะ (Controlled Impedance Notes) ตามมาตรฐาน IPC-2141 และ IPC-A-600

### 1.1 จลนพลศาสตร์การกัดกรดเคมีและการชดเชยลายเส้น (Chemical Etching & CAM Etch Compensation)

ในกระบวนการผลิตแผงวงจรส่วนใหญ่ แผ่นทองแดงจะถูกกัดออกด้วยน้ำยาเคมีอัลคาไลน์ (Alkaline Etching) หรือคิวปริกคลอไรด์ (Cupric Chloride):
- สเปรย์น้ำยาเคมีจะฉีดพ่นลงบนผิวทองแดงเพื่อละลายส่วนที่ไม่ได้ถูกปกคลุมด้วยฟิล์มโฟโตรีซิสต์ (Photoresist)
- น้ำยาเคมีจะกัดกินเนื้อทองแดงลงไปในแนวดิ่งพร้อมกับ **กัดเซาะขยายออกไปทางด้านข้างใต้แนวฟิล์ม (Lateral Undercut)**

#### 1. ดัชนี Etch Factor ($EF$):
$$EF = \frac{2 \cdot T_{\text{Cu}}}{W_{\text{bottom}} - W_{\text{top}}}$$

สำหรับทองแดงความหนามาตรฐาน $1\text{ oz}$ ($35\ \mu\text{m}$) ค่า $EF$ เฉลี่ยอยู่ที่ประมาณ $2.5 - 3.0$ ซึ่งหมายความว่า ในขณะที่น้ำยากัดลึกลงไป $35\ \mu\text{m}$ ด้านข้างของเส้นทองแดงจะถูกกัดเว้าเข้าไปข้างละ:
$$U_{\text{lateral}} = \frac{T_{\text{Cu}}}{EF} = \frac{35\ \mu\text{m}}{2.5} = 14\ \mu\text{m}\ \text{ต่อข้าง}$$

#### 2. การชดเชยขนาดเส้นในกระบวนการ CAM (Etch Compensation / Tooling Allowance):
เพื่อป้องกันไม่ให้เส้นทองแดงจริงในบอร์ดลีบเล็กลง วิศวกร CAM ของโรงงานผลิต PCB จะต้องทำการ **ขยายความกว้างของเส้นทองแดงในไฟล์โฟโตทูล (CAM Trace Broadening)** ล่วงหน้า:
$$W_{\text{CAM}} = W_{\text{design}} + \Delta W_{\text{comp}}$$

โดยทั่วไป $\Delta W_{\text{comp}} \approx 0.7\text{ ถึง }1.0 \times T_{\text{Cu}}$:
- สำหรับทองแดง $1/2\text{ oz}$ ($18\ \mu\text{m}$): $\Delta W_{\text{comp}} \approx +15\text{ ถึง }+20\ \mu\text{m}$ ($0.6 - 0.8\text{ mil}$)
- สำหรับทองแดง $1\text{ oz}$ ($35\ \mu\text{m}$): $\Delta W_{\text{comp}} \approx +25\text{ ถึง }+35\ \mu\text{m}$ ($1.0 - 1.4\text{ mil}$)
- สำหรับทองแดง $2\text{ oz}$ ($70\ \mu\text{m}$): $\Delta W_{\text{comp}} \approx +50\text{ ถึง }+65\ \mu\text{m}$ ($2.0 - 2.6\text{ mil}$)

#### 3. ขีดจำกัดระยะห่างการออกแบบ (Minimum Spacing Rule):
เนื่องจากเส้นทองแดงถูกขยายความกว้างออกในกระบวนการ CAM ช่องว่างระหว่างเส้น ($S_{\text{design}}$) จะถูกบีบให้แคบลง:
$$S_{\text{CAM}} = S_{\text{design}} - \Delta W_{\text{comp}}$$
หากวิศวกรออกแบบเส้นที่มีระยะห่างแคบเกินไป เช่น $S_{\text{design}} = 75\ \mu\text{m}$ บนทองแดง $2\text{ oz}$ ($\Delta W_{\text{comp}} = 55\ \mu\text{m}$):
$$S_{\text{CAM}} = 75 - 55 = 20\ \mu\text{m}$$
ช่องว่าง $20\ \mu\text{m}$ จะแคบเกินกว่าที่ฟิล์มโฟโตรีซิสต์จะยึดเกาะได้ ฟิล์มจะหลุดลอกและทำให้น้ำยาไม่สามารถซึมเข้าไปกัดกรดได้ เกิดปัญหา **เส้นทองแดงลัดวงจร (Short Circuit Bridging)** ทันที

### 1.2 ปรากฏการณ์หลุมดักกรด (Acid Traps) และการบำบัดด้วย Teardrops

หลุมดักกรด (Acid Trap) คือลักษณะทางเรขาคณิตที่รอยต่อของเส้นทองแดงทำมุมแหลมต่อกัน ($< 90^\circ$ โดยเฉพาะมุมที่แคบกว่า $45^\circ$):

```
+-----------------------------------------------------------------------------------------+
|                  Acid Trap Formation vs. Automated Teardrop Protection                  |
|                                                                                         |
|   [ 1. Severe Acid Trap Corner ]                [ 2. IPC Teardrop Fillet Filleted ]     |
|                                                                                         |
|          Pad / Bus Line                             Pad / Bus Line                      |
|         ┌──────────────┐                           ┌──────────────┐                     |
|         │              │                           │              │                     |
|         │              │                           │              │                     |
|         └──────┬───────┘                           └──────┬───────┘                     |
|                 \  Acute Angle < 45°                       \                            |
|                  \  Acid Trapped Here!                      \──┐ 45° Smooth Chamfer     |
|                   \                                            │ (No Acid Stagnation)   |
|                    \ Trace Line                                │ Trace Line             |
|                                                                                         |
|       Etchant pool cannot be rinsed!               Clean chemical rinse off!            |
|       Copper etches away during post-wash!         Uniform copper cross-section!        |
|       Result: Necking / Latent Open Circuit        Result: High-reliability joint       |
+-----------------------------------------------------------------------------------------+
```

1. **กลไกการเกิดความเสียหาย (Etchant Entrapment Mechanism):**
   - เมื่อแผงวงจรเคลื่อนผ่านรางน้ำยากัดกรด แรงตึงผิวของของเหลวจะทำให้สารเคมีเข้าไปขังตัวอยู่ในซอกมุมแหลม
   - ในขั้นตอนการล้างน้ำแรงดันสูง (High-pressure Rinsing) น้ำยาล้างไม่สามารถแทรกซึมเข้าไปเจือจางกรดที่ขังอยู่ในซอกแคบได้หมด
   - กรดที่ตกค้างจะยังคงกัดกร่อนเนื้อทองแดงอย่างต่อเนื่องในระหว่างกระบวนการถัดไป ก่อให้เกิดรอยคอดกิ่ว (Trace Necking) หรือรอยขาดแหว่งระดับไมโคร (Micro-notch)
2. **ความล้มเหลวแบบแฝง (Latent Field Failure):**
   - จุดที่เกิดรอยคอดกิ่วอาจวัดความต้านทานผ่านการทดสอบ ICT ได้ที่โรงงาน
   - แต่เมื่อผลิตภัณฑ์ถูกนำไปใช้งานและได้รับความร้อนหรือกระแสไฟฟ้าสูง จุดคอดจะมีความหนาแน่นกระแสพุ่งสูง ($J \propto 1/A$) เกิดความร้อนสะสมเฉพาะจุดและขาดวงจรในที่สุด (Thermal Fuse Effect)
3. **การป้องกันตามมาตรฐาน IPC-2221:**
   - ห้ามลากเส้นสัญญาณเข้ามุมที่แคบกว่า $90^\circ$ โดยเด็ดขาด
   - สั่งเปิดใช้ฟังก์ชัน **Automated Teardrop Filleting** ที่รอยต่อระหว่าง Trace กับ Via Pad และ Pin Pad ทุกจุด เพื่อสร้างระนาบสโลปโค้งมน ลบมุมแหลมทิ้งอย่างถาวร

### 1.3 ความสมดุลของเนื้อทองแดงและการชุบทองแดงเทียม (Copper Balance & Copper Thieving)

ในกระบวนการชุบทองแดงด้วยไฟฟ้า (Galvanic Electroplating) แผงวงจรจะทำหน้าที่เป็นขั้วแคโทด (Cathode) จุ่มอยู่ในอ่างน้ำยาเคมีคอปเปอร์ซัลเฟต:

#### 1. การกระจายความหนาแน่นกระแสชุบ (Plating Current Density Distribution):
$$\vec{J} = -\sigma \nabla \Phi$$

ตามกฎของสนามไฟฟ้า เส้นสนามแม่เหล็กไฟฟ้าจะกระจุกตัวหนาแน่นที่สุดในบริเวณขอบของแผงวงจร (Panel Borders) และบริเวณที่มีเส้นทองแดงอยู่อย่างโดดเดี่ยว (Isolated Traces):
- **Isolated Trace:** ไม่มีตัวนำข้างเคียงมาแย่งกระแส ความหนาแน่นกระแสชุบจะพุ่งสูง ($J_{\text{isolated}} \gg J_{\text{avg}}$) ทำให้ทองแดงถูกชุบพอกหนาเกินพิกัด (Over-plated: เช่น หนาถึง $50\ \mu\text{m}$ แทนที่จะเป็น $35\ \mu\text{m}$)
- **Dense Trace Area (เช่น กลุ่ม BGA / บัสหน่วยความจำ):** เส้นทองแดงเบียดกันแน่น แย่งกระแสไฟฟ้ากันเอง เกิดภาวะขาดแคลนกระแสชุบ (Plating Starvation: ทองแดงชุบได้บางเพียง $25\ \mu\text{m}$)

#### 2. กลไกของ Copper Thieving (แผ่นทองแดงขโมยกระแส):
- วิศวกร DFM จะสั่งเติมโครงสร้างทองแดงที่ไม่ได้ต่อวงจรไฟฟ้า (Non-functional Copper Pattern) ในพื้นที่ว่างเปล่าของแผงวงจร
- **รูปแบบที่นิยม:** ลายจุดวงกลม (Dot Grid: เส้นผ่านศูนย์กลาง $1.0\text{ mm}$, Pitch $1.5\text{ mm}$) หรือลายตารางแรเงา (Cross-hatched Pattern)
- **ประโยชน์เชิงวิศวกรรม:**
  1. ดูดซับความหนาแน่นกระแสชุบส่วนเกิน ทำให้ความหนาของทองแดงทั่วทั้งแผงบอร์ดมีความสม่ำเสมอ ($\pm 2.5\ \mu\text{m}$)
  2. รักษาขนาดหน้าตัดของเส้นสัญญาณความเร็วสูง ส่งผลให้อิมพีแดนซ์คงที่ตามแบบจำลอง
  3. สร้างสมดุลความเค้นเชิงกลระหว่างชั้น (Symmetric Copper Balance) ขจัดปัญหาแผงบอร์ดโก่งตัวแอ่น (Bow & Twist Warpage)

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例 - Shippai Jirei)

**เหตุการณ์:** การผลิตบอร์ดควบคุมหุ่นยนต์อุตสาหกรรม (Industrial Motion Control Board, 6 ชั้น, ทองแดงชั้นนอก $1\text{ oz}$ / ชั้นใน $1\text{ oz}$) ล็อตการผลิต 2,000 แผ่น:
1. ในขั้นตอนการทดสอบสัญญาณบัสความเร็วสูง SPI Clock ($50\ \text{MHz}$) และ USB 2.0 High-Speed ($480\ \text{Mbps}$) พบว่ามีบอร์ดจำนวน $8.2\%$ เกิดอาการเชื่อมต่อสัญญาณไม่ติด (Communication Drop) หรือมีสัญญาณ Jitter สูงผิดปกติ
2. แผงวงจรที่ผลิตเสร็จมีอาการแอ่นตัวแบบกระทะคว่ำ (Bow Warpage) สูงถึง $1.65\text{ mm}$ (ขีดจำกัดมาตรฐานยอมรับได้ไม่เกิน $1.15\text{ mm}$) ทำให้ไม่สามารถประกอบลงในเคสอะลูมิเนียมได้

```
+-----------------------------------------------------------------------------------------+
|                  RCA: Acute Acid Trap & Isolated Trace Over-Plating                     |
|                                                                                         |
|   [ ปัญหาที่ 1: มุมแหลม 30° กัดแหว่ง ]         [ ปัญหาที่ 2: Isolated Trace หนาเกินไป ]  |
|                                                                                         |
|       SPI Clock Trace (W = 100 μm)                  USB Differential Pair               |
|            \                                         (Isolated in Wide Opening!)        |
|             \ 30° Acute Entry!                      ┌──────┐      ┌──────┐              |
|              \ ┌────────────────┐                   │ D+   │      │ D-   │              |
|               ▼│ BGA Pad        │                   └──────┘      └──────┘              |
|       Acid Trap Over-etched to 34 μm!               ══════════════════════════════════  |
|       Thermal cycling causes micro-crack!           Cu Plated to 51 μm! (Target: 35 μm) |
|       (Intermittent Open Failure!)                  Z_diff drops from 90 to 76.5 Ohms!  |
|                                                     (Severe Reflection -> Packet Loss!) |
+-----------------------------------------------------------------------------------------+
```

#### การวิเคราะห์หาสาเหตุรากเหง้า (Root Cause Analysis - RCA):
1. **สาเหตุของสัญญาณ SPI ขาดวงจรเป็นช่วง ๆ (Acid Trap Necking):**
   - การตรวจสอบด้วยกล้องจุลทรรศน์กำลังขยายสูงบนเส้นสัญญาณ SPI Clock พบว่า เส้นทองแดงเลี้ยวเข้าหาขอบแพด BGA ด้วยมุมแหลม $30^\circ$
   - น้ำยากัดกรดขังตัวอยู่ในซอกมุมแหลมและไม่สามารถล้างออกได้หมด กัดกร่อนจนความกว้างเส้นทองแดงจากเดิม $100\ \mu\text{m}$ ลีบเล็กลงเหลือเพียง **$34\ \mu\text{m}$** (สูญเสียพื้นที่หน้าตัดไปถึง $66\%$)
   - เมื่อบอร์ดผ่านความร้อนในเตาอบ Reflow และการเปลี่ยนแปลงอุณหภูมิ จุดคอดนี้เกิดรอยแตกร้าวล้า (Micro-crack) ทำให้สัญญาณขาดหายเป็นช่วง ๆ
2. **สาเหตุของสัญญาณ USB สื่อสารล้มเหลว (Over-plating Impedance Collapse):**
   - คู่สายสัญญาณอนุพันธ์ USB ($D+/D-$) ถูกลากผ่านพื้นที่ว่างโล่งขนาดใหญ่บนชั้น L1 โดยรอบข้างไม่มีชิ้นส่วนหรือเส้นลายวงจรอื่นในรัศมี $15\text{ mm}$ และไม่มีการใส่ Copper Thieving
   - สนามไฟฟ้าในอ่างชุบทองแดงกระจุกตัวเข้าหาคู่สายนี้ (Current Crowding) ส่งผลให้ทองแดงถูกชุบหนาถึง **$51\ \mu\text{m}$** (ในขณะที่สเปกออกแบบกำหนดไว้ที่ $35\ \mu\text{m}$)
   - ความหนาทองแดงที่เพิ่มขึ้น ทำให้ความจุไฟฟ้าปรสิตเพิ่มสูงขึ้น ดึงให้อิมพีแดนซ์อนุพันธ์ตกฮวบลงจาก $90.0\ \Omega$ เหลือเพียง **$76.5\ \Omega$** (คลาดเคลื่อนถึง $-15\%$) สัญญาณสะท้อนกลับทำลายรูปตา Eye Diagram จนเกิด Packet Loss
3. **สาเหตุของบอร์ดแอ่นตัว (Copper Imbalance):**
   - ชั้น L1 มีพื้นที่ทองแดงเพียง $18\%$ ในขณะที่ชั้นล่างสุด L6 เป็นระนาบกราวด์ทึบที่มีทองแดงถึง $82\%$ ผลต่างทองแดงสูงถึง $64\%$ ก่อให้เกิดแรงเค้นจากการขยายตัวไม่สมดุลระหว่างผิวบนและล่าง ดึงให้บอร์ดโก่งงอ

#### มาตรการแก้ไขเชิงวิศวกรรม (Engineering Countermeasures):
1. **กำจัดมุมแหลมและเปิดใช้ Teardrops อัตโนมัติ:**
   - แก้ไขการเดินสายให้เข้าแพดด้วยมุม $90^\circ$ หรือ $45^\circ$ เท่านั้น และเปิดฟังก์ชัน Automated Teardrop ในโปรแกรม CAD เพื่อเชื่อมต่อรอยต่อทุกจุดอย่างราบเรียบ ขจัดหลุมดักกรดได้ $100\%$
2. **ติดตั้ง Copper Thieving และปรับสมดุลทองแดง:**
   - เติมลวดลายทองแดงเทียมแบบ Dot Grid (จุดกลม $\phi 1.0\text{ mm}$, ระยะพิตช์ $1.5\text{ mm}$) ในพื้นที่ว่างทั้งหมดของชั้น L1 เพื่อดึงเปอร์เซ็นต์ทองแดงขึ้นเป็น $72\%$ (สมดุลกับชั้น L6)
   - ความหนาแน่นกระแสชุบกระจายตัวสม่ำเสมอ ความหนาทองแดงของคู่สาย USB กลับคืนสู่สภาวะปกติที่ $35\ \mu\text{m} \pm 2\ \mu\text{m}$ และอิมพีแดนซ์กลับมาล็อกนิ่งที่ **$90.5\ \Omega$** ผ่านเกณฑ์ USB 2.0 อย่างสมบูรณ์
   - บอร์ดที่ผลิตเสร็จมีระยะแอ่นตัวลดลงเหลือเพียง **$0.42\text{ mm}$** (ผ่านเกณฑ์ Class 2 อย่างยอดเยี่ยม)

### รายการตรวจสอบวิศวกรรมลายวงจรและทองแดง (Trace & Copper DFM Checklist)

| ลำดับ | รายการตรวจสอบทางวิศวกรรม | เกณฑ์การยอมรับ (Acceptance Criteria) | ผลกระทบหากละเลย |
| :---: | :--- | :--- | :--- |
| 1 | **การเลี้ยวของเส้นทองแดง (Trace Corners)** | ห้ามทำมุมแหลม $< 90^\circ$ ต้องใช้มุม $45^\circ$ หรือส่วนโค้ง | กรดขังตัวกัดทองแดงแหว่ง (Acid Trap Open) |

| 3 | **ความสมดุลของเนื้อทองแดง (Copper Balance)**| ผลต่างเปอร์เซ็นต์ทองแดงระหว่างชั้นคู่สมมาตร $\le 15\%$ | บอร์ดโก่งงอแอ่นตัว (Bow & Twist Warpage) เกินเกณฑ์ |

| 6 | **ข้อกำหนด Controlled Impedance บนแบบ** | ระบุเลเยอร์, ความกว้างเส้น, ค่าโอห์ม, และพิกัด $\pm 10\%$ ชัดเจน | โรงงานผลิตบอร์ดไม่ได้มาตรฐานสัญญาณความเร็วสูง |
| 7 | **การต่อเส้นเข้าแพดขนาดใหญ่ (Thermal Relief)** | ใช้กากบาท 4 แฉก (Spoke Width สอดคล้องกับกระแส) เชื่อมต่อ Plane | บัดกรีไม่ติด (Cold Solder Joint) เพราะความร้อนไหลหนี |

### 3.2 ประโยคตรวจแบบที่ใช้จริงในโรงงานญี่ปุ่น (指摘事項 - Shiteki Jikō)

#### ตัวอย่างข้อคิดเห็นที่ 1: การตรวจพบมุมแหลม Acid Trap และคำสั่งใส่ Teardrops
> **日本語:**  
> 「L1層のSPI通信信号ラインにおいて、BGAランドへの進入角度が約30度の鋭角配線（アシッドトラップ）となっている箇所が散見されます。エッチング工程におけるエッチング液の液溜まり（残液）により、局所的な断線やネックダウン不良を引き起こす危険性が極めて高いです。進入角度は必ず90度または135度へ修正し、すべてのランドおよびビア接合部に対して涙滴処理（ティアドロップ）を施すようレイアウトを改訂してください。」  
> **คำแปลภาษาไทย:**  
> "ในเส้นสัญญาณสื่อสาร SPI ชั้น L1 พบจุดที่เส้นลายวงจรเลี้ยวเข้าสู่แลนด์แพด BGA ด้วยมุมแหลมประมาณ 30 องศา (เกิดหลุมดักกรด Acid Trap) อยู่หลายตำแหน่ง เนื่องจากมีความเสี่ยงสูงมากที่น้ำยากัดกรดจะขังตัวตกค้างระหว่างกระบวนการ Etching และก่อให้เกิดปัญหาเส้นขาดหรือเส้นคอดกิ่ว ขอให้แก้ไขมุมเลี้ยวให้เป็นมุม 90 องศา หรือ 135 องศาเสมอ และใส่หยดน้ำตาเสริม (Teardrops) ที่รอยต่อระหว่างเส้นกับแลนด์และเวียทุกจุดในการปรับปรุงเลย์เอาต์"

#### ตัวอย่างข้อคิดเห็นที่ 2: การสั่งเติม Copper Thieving เพื่อป้องกัน Over-plating และคุม Impedance
> **日本語:**  
> 「外層L1において、高速差動配線（USB_DP/DM、差動90Ω管理）が広大な孤立領域に配線されており、周辺に残銅パターンが存在しません。電気銅めっき工程において孤立パターンへの電流集中（Current Crowding）が発生し、導体厚が設計値（35μm）から50μm以上へ過剰めっきされる見込みです。これにより差動インピーダンスが規格下限（81Ω）を割り込み、反射障害を招く恐れがあります。差動ペアからクリアランス1.5mmを確保した上で、周囲のベタ領域にφ1.0mmピッチ1.5mmのダミーパターン（銅箔シービング）を配置し、めっき厚の均一化を図ってください。」  
> **คำแปลภาษาไทย:**  
> "ในชั้นนอก L1 คู่สายสัญญาณอนุพันธ์ความเร็วสูง (USB_DP/DM ควบคุม 90 โอห์ม) ถูกลากผ่านพื้นที่ว่างเปล่าขนาดใหญ่โดยไม่มีลายทองแดงข้างเคียง ในกระบวนการชุบทองแดงด้วยไฟฟ้าจะเกิดการกระจุกตัวของกระแสไฟฟ้า (Current Crowding) เข้าหาเส้นเดี่ยวนี้ และคาดว่าความหนาทองแดงจะถูกชุบหนาเกินพิกัดจากค่าออกแบบ 35 ไมครอน พุ่งเกินกว่า 50 ไมครอน ซึ่งจะฉุดให้อิมพีแดนซ์อนุพันธ์ตกต่ำกว่าเกณฑ์ขั้นต่ำ (81 โอห์ม) และนำไปสู่ความผิดพลาดจากสัญญาณสะท้อน ขอให้เว้นระยะห่างจากคู่สาย 1.5 มม. แล้วเติมลวดลายทองแดงเทียม (Copper Thieving ขนาดจุด 1.0 มม. ระยะพิตช์ 1.5 มม.) ลงในพื้นที่ว่างโดยรอบเพื่อปรับความหนาของทองแดงชุบให้สม่ำเสมอ"

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณการชดเชยขนาดเส้นในไฟล์ CAM และระยะห่างขั้นต่ำก่อนเกิดการลัดวงจร (CAM Etch Compensation & Minimum Space)

**โจทย์:**  
โรงงานผลิตแผ่นวงจร PCB ใช้กระบวนการกัดกรดเคมีแบบ Alkaline Etching บนแผ่นลามิเนตทองแดงฐานหนา $1\text{ oz}$ ($T_{\text{Cu}} = 35.0\ \mu\text{m}$):
- เครื่องกัดกรดมีค่าดัชนีการกัดกร่อน (Etch Factor): $EF = 2.50$
- การกัดเซาะด้านข้างเกิดขึ้นเท่ากันทั้งสองด้านของเส้นทองแดง ($U_{\text{lateral}} = \frac{T_{\text{Cu}}}{EF}$)
- เพื่อให้ความกว้างของเส้นทองแดงที่ฐานล่างของชิ้นงานจริง ($W_{\text{bottom, actual}}$) มีขนาดตรงตามค่าที่วิศวกรออกแบบไว้ในไฟล์ Gerber ($W_{\text{design}} = 100.0\ \mu\text{m}$) วิศวกร CAM จะต้องขยายขนาดเส้นบนแผ่นฟิล์มโฟโตทูลออกข้างละ $\Delta w$ (การขยายความกว้างรวม: $\Delta W_{\text{CAM}} = 2 \cdot \Delta w$)
- ในกระบวนการโฟโตลิโทกราฟี ฟิล์มโฟโตรีซิสต์มีความสามารถในการเปิดช่องว่างขั้นต่ำที่ปลอดภัย (Minimum Resolvable Resist Gap): $S_{\text{resist, min}} = 65.0\ \mu\text{m}$ (หากช่องว่างบนแผ่นฟิล์มแคบกว่านี้ น้ำยาพัฒนาฟิล์มจะไม่สามารถชะล้างออกได้หมด ทำให้เกิดการลัดวงจร)

1. จงคำนวณหาระยะการกัดเซาะด้านข้างต่อหนึ่งข้าง ($U_{\text{lateral}}$) และค่าการขยายขนาดเส้นรวมในไฟล์ CAM ($\Delta W_{\text{CAM}}$)
2. คำนวณหาความกว้างของเส้นบนแผ่นฟิล์มโฟโตทูล ($W_{\text{CAM}}$)
3. หากวิศวกรออกแบบเส้นสัญญาณสองเส้นคู่ขนานกันด้วยระยะห่างในการออกแบบ $S_{\text{design}}$ จงคำนวณหา **ระยะห่างในการออกแบบขั้นต่ำสุด ($S_{\text{design, min}}$)** ที่วิศวกรต้องกำหนดไว้ในโปรแกรม CAD เพื่อไม่ให้ช่องว่างบนฟิล์มโฟโตทูล ($S_{\text{CAM}}$) แคบกว่าขีดจำกัด $65.0\ \mu\text{m}$

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณหาระยะการกัดเซาะด้านข้าง ($U_{\text{lateral}}$) และค่าขยายเส้น ($\Delta W_{\text{CAM}}$):**
จากนิยามของ Etch Factor:
$$EF = \frac{T_{\text{Cu}}}{U_{\text{lateral}}} \implies U_{\text{lateral}} = \frac{T_{\text{Cu}}}{EF}$$
แทนค่า $T_{\text{Cu}} = 35.0\ \mu\text{m}$ และ $EF = 2.50$:
$$U_{\text{lateral}} = \frac{35.0\ \mu\text{m}}{2.50} = 14.0\ \mu\text{m}\ \text{ต่อข้าง}$$

เพื่อให้ฐานล่างของเส้นทองแดงหลังการกัดกรดมีขนาดกว้างเท่ากับ $W_{\text{design}}$:
เส้นบนฟิล์มจะต้องถูกขยายออกไปข้างละ $14.0\ \mu\text{m}$ เพื่อชดเชยเนื้อทองแดงที่จะถูกกัดหายไป:
$$\Delta W_{\text{CAM}} = 2 \cdot U_{\text{lateral}} = 2 \times 14.0\ \mu\text{m} = 28.0\ \mu\text{m}$$
**คำตอบส่วนที่ 1:** ต้องขยายขนาดเส้นใน CAM รวมเท่ากับ **$28.0\ \mu\text{m}$** ($1.10\ \text{mil}$)

---

**2. คำนวณความกว้างของเส้นบนฟิล์มโฟโตทูล ($W_{\text{CAM}}$):**
$$W_{\text{CAM}} = W_{\text{design}} + \Delta W_{\text{CAM}} = 100.0\ \mu\text{m} + 28.0\ \mu\text{m} = 128.0\ \mu\text{m}$$
**คำตอบส่วนที่ 2:** ความกว้างของเส้นบนฟิล์มคือ **$128.0\ \mu\text{m}$**

---

**3. คำนวณหาระยะห่างในการออกแบบขั้นต่ำสุด ($S_{\text{design, min}}$):**
เมื่อเส้นทองแดงสองเส้นที่อยู่ติดกันถูกขยายขนาดขึ้นในไฟล์ CAM:
เส้นที่ 1 ขยายออกข้างละ $\Delta w = 14.0\ \mu\text{m}$ เข้าหาช่องว่าง  
เส้นที่ 2 ก็ขยายออกข้างละ $\Delta w = 14.0\ \mu\text{m}$ เข้าหาช่องว่างเช่นกัน  
ส่งผลให้ช่องว่างบนฟิล์ม CAM ($S_{\text{CAM}}$) ถูกบีบให้แคบลงทั้งสองข้าง:
$$S_{\text{CAM}} = S_{\text{design}} - \Delta W_{\text{CAM}} = S_{\text{design}} - 28.0\ \mu\text{m}$$

กำหนดเงื่อนไขความปลอดภัย: ช่องว่างบนฟิล์มต้องไม่แคบกว่าขีดจำกัดความละเอียด:
$$S_{\text{CAM}} \ge S_{\text{resist, min}} = 65.0\ \mu\text{m}$$
$$S_{\text{design}} - 28.0\ \mu\text{m} \ge 65.0\ \mu\text{m}$$
$$S_{\text{design, min}} = 65.0\ \mu\text{m} + 28.0\ \mu\text{m} = 93.0\ \mu\text{m}\ (\approx 3.66\ \text{mil})$$

**บทสรุปทางวิศวกรรม:**  
หากวิศวกรกำหนดระยะห่างระหว่างเส้นใน CAD แคบกว่า **$93.0\ \mu\text{m}$** (เช่น ใช้สเปก $75\ \mu\text{m}$ หรือ $3\ \text{mil}$) เมื่อไฟล์ผ่านการขยายเส้นใน CAM ช่องว่างจริงจะเหลือเพียง $47\ \mu\text{m}$ ซึ่งจะส่งผลให้ฟิล์มโฟโตรีซิสต์ลอกหลุด และเกิดการลัดวงจรระหว่างเส้นทันทีในสายการผลิต

</details>

### ข้อที่ 2: การคำนวณความหนาแน่นกระแสชุบไฟฟ้าและผลกระทบต่ออิมพีแดนซ์ (Galvanic Plating & Microstrip Impedance)

**โจทย์:**  
ในกระบวนการชุบทองแดงด้วยไฟฟ้า (Pattern Electroplating) แผงวงจร 4 ชั้นถูกแช่อยู่ในอ่างชุบคอปเปอร์ซัลเฟตเป็นเวลา $t = 50\ \text{นาที}$ ($3,000\ \text{วินาที}$):
- ความหนาของทองแดงฟอยล์ตั้งต้น (Base Foil): $T_{\text{base}} = 12.0\ \mu\text{m}$
- กฎการชุบด้วยไฟฟ้าของฟาราเดย์ (Faraday's Law of Electrolysis): อัตราการเพิ่มความหนาทองแดงชุบแปรผันตรงกับความหนาแน่นกระแสไฟฟ้า ($J$ ในหน่วย $\text{A/dm}^2$):
  $$T_{\text{plated}}(\mu\text{m}) \approx 0.22 \cdot J \cdot t_{\text{min}}$$
  (โดยที่ $t_{\text{min}}$ คือเวลาในการชุบในหน่วยนาที)
- บนแผงวงจรมีเส้นส่งสัญญาณไมโครสตริป $50\ \Omega$ (ความกว้าง $W = 120.0\ \mu\text{m}$, ไดอิเล็กทริกหนา $H = 75.0\ \mu\text{m}$, $\epsilon_r = 4.0$) วางอยู่ใน 2 สภาวะ:
  - **เส้นที่ 1 (Balanced Trace with Thieving):** มีการเติม Copper Thieving อย่างสม่ำเสมอ ทำให้ความหนาแน่นกระแสคงที่ตามสเปก $J_1 = 2.0\ \text{A/dm}^2$
  - **เส้นที่ 2 (Isolated Trace without Thieving):** เป็นเส้นเดี่ยวโดดเดี่ยวในพื้นที่โล่งกว้าง เกิดการกระจุกตัวของกระแสไฟฟ้าชุบ (Current Crowding) สูงถึง $J_2 = 3.6\ \text{A/dm}^2$

1. จงคำนวณหาความหนาทองแดงรวม ($T_{\text{total}} = T_{\text{base}} + T_{\text{plated}}$) ของเส้นที่ 1 และ เส้นที่ 2
2. จากสมการประมาณการอิมพีแดนซ์ของไมโครสตริป อิมพีแดนซ์จะลดลงเมื่อความหนาทองแดง ($T$) เพิ่มขึ้น โดยมีค่าสัมประสิทธิ์ความไว $\frac{\Delta Z_0}{\Delta T} \approx -0.22\ \Omega/\mu\text{m}$  
   หากเส้นที่ 1 มีค่าอิมพีแดนซ์ตรงตามเป้าหมาย $Z_{0, 1} = 50.0\ \Omega$ จงคำนวณหาค่าอิมพีแดนซ์จริงของเส้นที่ 2 ($Z_{0, 2}$)
3. วิเคราะห์ว่าเส้นที่ 2 ผ่านเกณฑ์พิกัดความปลอดภัยอิมพีแดนซ์ $\pm 5\%$ ($\pm 2.5\ \Omega$) หรือไม่

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณความหนาทองแดงรวมของทั้งสองเส้น:**
กำหนดเวลาชุบ $t_{\text{min}} = 50\ \text{นาที}$:
- **สำหรับเส้นที่ 1 ($J_1 = 2.0\ \text{A/dm}^2$):**
  $$T_{\text{plated, 1}} = 0.22 \times 2.0 \times 50 = 22.0\ \mu\text{m}$$
  ความหนารวม:
  $$T_{\text{total, 1}} = T_{\text{base}} + T_{\text{plated, 1}} = 12.0\ \mu\text{m} + 22.0\ \mu\text{m} = 34.0\ \mu\text{m}\ (\approx 1\text{ oz Copper Standard})$$

- **สำหรับเส้นที่ 2 ($J_2 = 3.6\ \text{A/dm}^2$):**
  $$T_{\text{plated, 2}} = 0.22 \times 3.6 \times 50 = 39.6\ \mu\text{m}$$
  ความหนารวม:
  $$T_{\text{total, 2}} = T_{\text{base}} + T_{\text{plated, 2}} = 12.0\ \mu\text{m} + 39.6\ \mu\text{m} = 51.6\ \mu\text{m}$$

---

**2. คำนวณค่าอิมพีแดนซ์จริงของเส้นที่ 2 ($Z_{0, 2}$):**
ผลต่างของความหนาทองแดง:
$$\Delta T = T_{\text{total, 2}} - T_{\text{total, 1}} = 51.6\ \mu\text{m} - 34.0\ \mu\text{m} = +17.6\ \mu\text{m}$$

การเปลี่ยนแปลงของอิมพีแดนซ์:
$$\Delta Z_0 = \Delta T \times \left( \frac{\Delta Z_0}{\Delta T} \right) = (+17.6\ \mu\text{m}) \times (-0.22\ \Omega/\mu\text{m}) \approx -3.872\ \Omega$$

อิมพีแดนซ์ของเส้นที่ 2:
$$Z_{0, 2} = Z_{0, 1} + \Delta Z_0 = 50.0\ \Omega - 3.872\ \Omega \approx 46.13\ \Omega$$

---

**3. การตัดสินผลตามเกณฑ์ความปลอดภัย $\pm 5\%$ ($\pm 2.5\ \Omega$):**
- ขอบเขตที่ยอมรับได้สำหรับ $50.0\ \Omega \pm 5\%$: **$47.5\ \Omega$ ถึง $52.5\ \Omega$**
- ค่าที่เกิดขึ้นจริงในเส้นที่ 2: **$46.13\ \Omega$** (คลาดเคลื่อนไป $-3.87\ \Omega$ หรือ $-7.74\%$)
- **ผลการตัดสิน:** **สอบตก (FAIL)**  
  การกระจุกตัวของกระแสชุบบนเส้นโดดเดี่ยวทำให้ทองแดงพอกหนาเกินไป ดึงให้อิมพีแดนซ์หลุดกรอบมาตรฐานความปลอดภัย $\pm 5\%$ ส่งผลให้การเชื่อมต่อสัญญาณความเร็วสูงเกิดการสะท้อนกลับเกินเกณฑ์

</details>

### ข้อที่ 3: การวิเคราะห์ความล้มเหลวจาก Acid Trap และการฟื้นฟูด้วย Teardrop Filleting

**โจทย์:**  
บนแผงวงจรอิเล็กทรอนิกส์ยานยนต์ เส้นส่งสัญญาณเซนเซอร์ความกว้าง $W_0 = 120.0\ \mu\text{m}$ เชื่อมต่อเข้าสู่ Via Pad ทรงกลมเส้นผ่านศูนย์กลาง $D_{\text{pad}} = 450.0\ \mu\text{m}$  
ในไฟล์ออกแบบเดิม (ก่อนแก้ไข) เส้นทองแดงวิ่งเลี้ยวเข้าสู่แพดโดยทำมุมสัมผัสเฉียงแหลม $\theta = 30^\circ$ กับเส้นสัมผัสของแพด ก่อให้เกิดซอกลิ่มแหลม (Acid Trap Wedge):
- ในระหว่างการล้างน้ำยาเคมีหลังการกัดกรด กรดที่ตกค้างในซอก $30^\circ$ ทำให้เกิดการกัดกร่อนเกิน (Over-etching) กัดเซาะลึกเข้าไปในเนื้อทองแดงของเส้นสัญญาณเป็นรอยแหว่งทรงสามเหลี่ยมลึก $\delta = 65.0\ \mu\text{m}$ จากขอบด้านหนึ่ง
- ชั้นทองแดงหนา $T_{\text{Cu}} = 35.0\ \mu\text{m}$ ทำจากทองแดงชุบที่มีความต้านทานจำเพาะ $\rho = 1.72 \times 10^{-8}\ \Omega\cdot\text{m}$  
- สัญญาณนี้มีกระแสพัลส์กระตุ้นโหลดขนาด $I_{\text{pulse}} = 1.80\text{ A}$

1. จงคำนวณหาความกว้างคงเหลือของเส้นทองแดงที่จุดคอดกิ่ว ($W_{\text{neck}} = W_0 - \delta$) และคำนวณหาพื้นที่หน้าตัดที่จุดคอด ($A_{\text{neck}}$) เทียบกับพื้นที่หน้าตัดปกติ ($A_{\text{nominal}}$)
2. คำนวณหาความหนาแน่นกระแสไฟฟ้า ($J$ ในหน่วย $\text{A/mm}^2$) ที่จุดคอดกิ่ว และเปรียบเทียบกับเกณฑ์ความปลอดภัยตามมาตรฐาน IPC-2152 (ความหนาแน่นกระแสสูงสุดสำหรับตัวนำบน PCB ไม่ควรเกิน $30.0\ \text{A/mm}^2$)
3. หากวิศวกรทำการแก้ไขโดยเพิ่ม **Teardrop Fillet ทรง $45^\circ$ (Chamfered Teardrop)** ขจัดซอกมุมแหลมออกทั้งหมด จงอธิบายผลลัพธ์ทางกลศาสตร์และอุณหพลศาสตร์ที่จะเกิดขึ้น

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณหาความกว้างและพื้นที่หน้าตัดที่จุดคอดกิ่ว:**
- ความกว้างเส้นปกติ: $W_0 = 120.0\ \mu\text{m} = 0.120\text{ mm}$
- ความกว้างคงเหลือที่จุดคอด:
  $$W_{\text{neck}} = W_0 - \delta = 120.0\ \mu\text{m} - 65.0\ \mu\text{m} = 55.0\ \mu\text{m} = 0.055\text{ mm}$$
- พื้นที่หน้าตัดปกติ:
  $$A_{\text{nominal}} = W_0 \times T_{\text{Cu}} = (0.120\text{ mm}) \times (0.035\text{ mm}) = 0.0042\ \text{mm}^2$$
- พื้นที่หน้าตัดที่จุดคอด:
  $$A_{\text{neck}} = W_{\text{neck}} \times T_{\text{Cu}} = (0.055\text{ mm}) \times (0.035\text{ mm}) = 0.001925\ \text{mm}^2$$
- สัดส่วนพื้นที่คงเหลือ:
  $$\frac{A_{\text{neck}}}{A_{\text{nominal}}} = \frac{0.001925}{0.0042} \times 100\% \approx 45.83\%$$
(สูญเสียเนื้อทองแดงไปถึง $54.17\%$)

---

**2. คำนวณความหนาแน่นกระแสไฟฟ้า ($J$):**
- ความหนาแน่นกระแสในสภาวะปกติ:
  $$J_{\text{nominal}} = \frac{I_{\text{pulse}}}{A_{\text{nominal}}} = \frac{1.80\ \text{A}}{0.0042\ \text{mm}^2} \approx 428.57\ \text{A/mm}^2$$
- ความหนาแน่นกระแสที่จุดคอดกิ่ว (Neck Hotspot):
  $$J_{\text{neck}} = \frac{I_{\text{pulse}}}{A_{\text{neck}}} = \frac{1.80\ \text{A}}{0.001925\ \text{mm}^2} \approx 935.06\ \text{A/mm}^2$$

**การเปรียบเทียบและการวิเคราะห์ความเสียหาย:**  
ความหนาแน่นกระแสที่จุดคอดพุ่งสูงถึง **$935.1\ \text{A/mm}^2$** (สูงกว่าสภาวะปกติถึง $2.18$ เท่า และสูงกว่าขีดจำกัดปลอดภัย $30\ \text{A/mm}^2$ มหาศาล):
1. **ปรากฏการณ์ความร้อน Joule Heating เฉพาะจุด ($P = I^2 R$):** ความต้านทานที่เพิ่มขึ้นเฉพาะจุดจะสร้างความร้อนสะสมอย่างรวดเร็ว ทำให้อุณหภูมิที่จุดคอดพุ่งสูงกว่าพื้นที่โดยรอบหลายสิบองศาเซลเซียส
2. **การเคลื่อนย้ายของอะตอมโลหะ (Electromigration):** ความหนาแน่นกระแสที่สูงเกิน $10^5\ \text{A/cm}^2$ ร่วมกับความร้อนสูง จะเร่งให้อะตอมทองแดงเคลื่อนตัวตามทิศทางการไหลของอิเล็กตรอน เกิดโพรงอากาศ (Voids) สะสมและขาดวงจรอย่างถาวรในที่สุด

---

**3. ผลลัพธ์ของการเพิ่ม Teardrop Fillet ($45^\circ$):**
1. **ขจัดแรงตึงผิวของของเหลว:** แนวลาดเอียง $45^\circ$ ของ Teardrop ทำให้สารเคมีในกระบวนการกัดกรดและน้ำยาล้างสามารถไหลเวียนถ่ายเทได้อย่างอิสระ ไม่มีซอกแคบให้กรดตกค้าง ป้องกันการเกิดรอยแหว่งได้อย่างสมบูรณ์ ($\delta = 0$)
2. **รักษาความสมบูรณ์ของพื้นที่หน้าตัด:** พื้นที่หน้าตัดตัวนำจะคงรูปเต็มสเกล $100\%$ ($A = 0.0042\ \text{mm}^2$) กระจายความหนาแน่นกระแสได้อย่างปลอดภัย
3. **เพิ่มความทนทานต่อแรงกระแทกเชิงกล:** Teardrop ทำหน้าที่เป็นแนวค้ำยัน (Fillet Gusset) กระจายแรงเค้นดัดงอระหว่างเส้นทองแดงและแผ่นแลนด์แพด ป้องกันไม่ให้ทองแดงฉีกขาดที่รอยต่อเมื่อแผงบอร์ดเผชิญกับแรงสั่นสะเทือน (Vibration Shock)

</details>
