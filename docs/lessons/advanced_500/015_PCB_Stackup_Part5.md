## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในระบบวงจรความถี่สูง การทำความเข้าใจพฤติกรรมของกระแสย้อนกลับ (Return Current) ถือเป็นกฎข้อแรกสุดของวิศวกรรม Signal Integrity (SI) และ Electromagnetic Compatibility (EMC) 
กระแสไฟฟ้าต้องไหลครบวงจรเสมอ ($\oint I = 0$) แต่เมื่อความถี่ของสัญญาณสูงขึ้น กระแสย้อนกลับจะไม่ไหลผ่านเส้นทางที่มีความต้านทานต่ำสุด (Least Resistance) อีกต่อไป แต่จะวิ่งบีบตัวอยู่บนระนาบอ้างอิง (Reference Plane) ใต้ลายวงจรโดยตรงตาม **เส้นทางที่มีความเหนี่ยวนำต่ำสุด (Path of Least Inductance)**
วิศวกรระดับ Senior ต้องเข้าใจ **การเหนี่ยวนำระหว่างระนาบ (Inter-plane Capacitance)**, **ปรากฏการณ์เรโซแนนซ์ของโพรงระนาบ (Cavity Resonance)**, **การควบคุมการแผ่คลื่นที่ขอบบอร์ดด้วยกฎ 20H Rule**, และ **การรักษาความต่อเนื่องของ Return Path ข้ามเลเยอร์**

---

### 1.1 พลศาสตร์ของกระแสย้อนกลับ (Frequency-Dependent Return Current Distribution)
พฤติกรรมการไหลของกระแสย้อนกลับบนระนาบ Reference Plane แบ่งออกเป็น 2 สภาวะอย่างชัดเจนตามความถี่:

$$Z_{return}(f) = R(f) + j \omega L$$

1. **ที่ความถี่ต่ำ / กระแสตรง ($f < 10 \text{ kHz}$):**  
   เทอมความต้านทาน $R$ มีอิทธิพลเหนือกว่า ($R \gg \omega L$) กระแสย้อนกลับจะกระจายตัวแผ่กว้างไปทั่วทั้งแผ่นระนาบทองแดง โดยเลือกเส้นทางที่สั้นที่สุดทางเรขาคณิต (ตรงดิ่งจากโหลดกลับสู่ขั้วลบของแหล่งจ่ายไฟ)
2. **ที่ความถี่สูง ($f > 1 \text{ MHz}$ ขึ้นไป):**  
   เทอมความเหนี่ยวนำ $\omega L$ จะครอบงำระบบ ($j\omega L \gg R$) กระแสย้อนกลับจะถูกแรงผลักของสนามแม่เหล็ก (Mutual Inductive Coupling) ดึงดูดให้ **ไหลบีบตัวกระจุกอยู่บนผิวด้านในของระนาบ Reference Plane ที่อยู่ประชิดใต้เส้น Trace พอดิบพอดี** เพื่อลดพื้นที่วงลูป (Loop Area) ให้มีขนาดเล็กที่สุด

```
      Signal Trace (Is) ────► ┌───────┐
                              └───────┘
      Dielectric (h)
      ────────────────────────────────────────────────────────
      Reference Plane (Ir)   ◄▒▒▒▒▒▒▒▒► (กระแสย้อนกลับกระจุกตัวใต้ Trace)
                             ◄─── 3h ──► (80% ของกระแสอยู่ในระยะ 3h)
```

### 1.2 สมการคำนวณ Inter-plane Capacitance ($C_{plane}$)
หนึ่งในอาวุธลับที่ทรงพลังที่สุดของการออกแบบ Stackup ขั้นสูง คือการจัดวางระนาบ Power Plane และ Ground Plane ให้อยู่ **ประกบติดกันแนบชิดที่สุด** คั่นด้วยแผ่นไดอิเล็กตริกบางเฉียบ ($d \le 2 - 3 \text{ mil}$):

$$C_{plane} = \frac{\epsilon_0 \ \epsilon_r \ A}{d} \quad [\text{Farads}]$$

- $\epsilon_0$: ค่าคงที่สภาพยอมในสุญญากาศ ($8.854 \times 10^{-12} \ \text{F/m}$)
- $\epsilon_r$: Dielectric Constant ของแผ่นฉนวน (เช่น FR-4 $= 4.2$)
- $A$: พื้นที่ทับซ้อนกันระหว่างระนาบ Power และ Ground ($\text{m}^2$)
- $d$: ระยะห่างระหว่างระนาบทั้งสอง ($\text{m}$)

**ตัวอย่างการคำนวณจริง:**
กำหนดให้พื้นที่บอร์ด $A = 150 \text{ cm}^2 = 0.015 \text{ m}^2$, ใช้ Prepreg ชนิดบางพิเศษหนา $d = 2.0 \text{ mil} \ (50.8 \ \mu\text{m} = 5.08 \times 10^{-5} \text{ m})$ บนวัสดุ FR-4 ($\epsilon_r = 4.2$):
$$C_{plane} = \frac{8.854 \times 10^{-12} \times 4.2 \times 0.015}{5.08 \times 10^{-5}} \approx 1.098 \times 10^{-8} \ \text{F} = \mathbf{10.98 \ \text{nF}}$$

**ทำไมตัวเก็บประจุ $11 \text{ nF}$ นี้จึงมีค่ามากกว่าตัวเก็บประจุ SMD ภายนอกนับร้อยตัว?**
- ตัวเก็บประจุ SMD ทั่วไปมีขาและ Via เชื่อมต่อ ซึ่งสร้างความเหนี่ยวนำแฝง (ESL $\ge 0.5 - 1.5 \text{ nH}$) ทำให้หยุดทำงานที่ความถี่เกิน $50 - 100 \text{ MHz}$
- แต่ **Inter-plane Capacitance เป็นตัวเก็บประจุแบบระนาบกระจายตัว (Distributed Capacitor) ที่มีค่าความเหนี่ยวนำแฝงในแนวดิ่งเกือบเป็นศูนย์ (Spreading Inductance $< 10 \text{ pH}$)!** 
- มันจึงสามารถจ่ายพลังงานชดเชยการกระชากของกระแสในย่านความถี่ตั้งแต่ **$200 \text{ MHz}$ ไปจนถึงเกิน $1 \text{ GHz}$** ได้อย่างสมบูรณ์แบบ ช่วยลด Noise บนระนาบไฟได้ดีกว่าการเพิ่มตัวเก็บประจุ SMD ภายนอกอย่างมหาศาล

### 1.3 ปรากฏการณ์ Cavity Resonance และกฎ 20H Rule
ระนาบคู่ขนาน Power และ Ground ทำหน้าที่เสมือนโพรงคลื่นสะท้อนแม่เหล็กไฟฟ้า (Resonant Cavity) ซึ่งจะเกิดสภาวะเรโซแนนซ์ที่ความถี่ธรรมชาติ:

$$f_{m,n} = \frac{c}{2\sqrt{\epsilon_r}} \sqrt{\left(\frac{m}{L}\right)^2 + \left(\frac{n}{W}\right)^2}$$

- $L, W$: ความยาวและความกว้างของแผ่นระนาบ
- $m, n$: โหมดเรโซแนนซ์ ($1, 2, 3...$)

ที่ความถี่เรโซแนนซ์ สนามแม่เหล็กไฟฟ้าจะเกิดการกระเพื่อมรุนแรงและรั่วไหลออกทางขอบของแผ่นบอร์ด (Fringing Electric Field) กลายเป็นสายอากาศแผ่รังสี EMI สู่อากาศภายนอก!

```
     Top GND Plane    ────────────────────────────────────────────┐
                                          ▲                       │ Fringing E-Field
     Power Plane      ──────────────┐     │ h                     │ แผ่ออกขอบบอร์ด!
                      ◄──── 20h ────►     ▼                       ▼
     Bottom GND Plane ────────────────────────────────────────────┘
                         (ร่นขอบเข้ามา 20h เพื่อดึงสนามไฟฟ้าลง GND)
```

**กฎ 20H Rule ของ Dr. Mark Montrose:**
> *"ให้ร่นขอบของระนาบ Power Plane เข้ามาจากขอบของระนาบ Ground Plane โดยรอบ เป็นระยะทางอย่างน้อย 20 เท่าของระยะห่างระหว่างชั้น ($20 \times h$)"*

- การร่นขอบ Power Plane เข้ามา $20h$ จะทำให้เส้นแรงสนามไฟฟ้าที่ขอบถูกดึงดูดกลับเข้าหา Ground Plane ชั้นบนและชั้นล่างแทนที่จะรั่วออกไปสู่อากาศภายนอก ช่วยลดการแผ่รังสีคลื่นแม่เหล็กไฟฟ้าที่ขอบบอร์ดลงได้ถึง **$70\%$ (ประมาณ $-10 \text{ dB}$)**
- *(หากร่นขอบเข้ามา $100h$ จะลดการแผ่รังสีลงได้ถึง $98\%$)*

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** บอร์ดสวิตช์เราเตอร์เครือข่ายความเร็วสูง ล้มเหลวในการทดสอบมาตรฐาน CISPR 32 Class B Radiated Emissions ที่ความถี่ $480 \text{ MHz}$ โดยมีสัญญาณรบกวนเกินเกณฑ์กฎหมายถึง **$+9.5 \text{ dB}$** สแกนตรวจจับสนามแม่เหล็กด้วย Near-Field Probe พบว่าคลื่นแม่เหล็กไฟฟ้ารั่วไหลออกมาจากแนวขอบของแผ่นบอร์ดตลอดทั้ง 4 ด้าน
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. ระนาบ Power Plane $+1.2\text{V}$ และ Ground Plane ถูกเททองแดงจนชนขอบบอร์ด (0H Margin) ทั้งคู่ ทำให้ขอบบอร์ดทำหน้าที่เป็น Slot Antenna ปล่อยคลื่นเรโซแนนซ์ออกมา
2. สัญญาณ High-Speed Bus จำนวน 16 เส้นวิ่งมุดเปลี่ยน Layer จาก L1 (อ้างอิง GND) ไปยัง L6 (อ้างอิง $+1.2\text{V}$) โดยไม่มี **Stitching Capacitor** อยู่ใกล้เคียงเลย กระแสย้อนกลับจึงต้องวิ่งอ้อมไปหาตัวเก็บประจุ Decoupling ที่อยู่ห่างออกไป 30 mm เกิด Loop Area ขนาดใหญ่ยักษ์

---

### ขั้นตอนการควบคุม Return Path และขอบบอร์ดสไตล์ Senior (検図チェックリスト):
1. **การบังคับใช้กฎ 20H Rule บน Power Plane ทั้งหมด:**
   - วัดระยะห่าง Dielectric $h$ ระหว่าง Power กับ GND (เช่น $h = 3 \text{ mil} = 0.076 \text{ mm}$)
   - คำนวณระยะร่นขอบ: $20 \times h = 20 \times 0.076 \text{ mm} \approx \mathbf{1.52 \text{ mm} \ (60 \text{ mil})}$
   - สั่งร่นขอบทองแดงของ Power Plane ทุกระนาบให้ลึกเข้ามาจากขอบ Ground Plane อย่างน้อย **$1.5 - 2.0 \text{ mm}$** โดยรอบ
2. **การสร้างกำแพงกักกันคลื่นรอบขอบบอร์ด (GND Shielding Ring & Via Wall):**
   - ตีเส้นขอบทองแดง Ground ล้อมรอบขอบบอร์ดทุกชั้น และเจาะรู **GND Stitching Vias ล้อมรอบเป็นกำแพง** ด้วยระยะห่างระหว่าง Via:
     $$p \le \frac{\lambda}{20} \approx 5 - 8 \text{ mm}$$
3. **การจัดการจุดเปลี่ยน Layer ข้ามระนาบต่างศักย์ (Cross-Plane Transitions):**
   - เมื่อสัญญาณเปลี่ยนเลเยอร์ข้ามระหว่างระนาบคนละศักย์ (เช่น จาก Ground Plane ไปอ้างอิง Power Plane):
     - **ต้องวาง Stitching Capacitor (ขนาด $0.1\mu\text{F}$ 0201 ค่า ESL ต่ำพิเศษ)** ประชิด Signal Via ในระยะไม่เกิน **$0.5 \text{ mm}$** เสมอ เพื่อเป็นสะพานเชื่อมกระแส Displacement Current ข้ามระนาบ

> **指摘事項 2:**  
> 「高速差動クロック（NET: `REFCLK_P/N`）がビアでL1層からL6層へ層間遷移していますが、L2層（GND）とL5層（+1.8V）の間にリターンパスを確保するためのスティッチングコンデンサが配置されていません。層間変位電流のループ面積増大によるジッタ悪化を抑制するため、信号ビア直近（0.5mm以内）に0.1μFのスティッチングコンデンサ（GND-1.8V間）を追加してください。」  
> *(คู่สาย Clock ความเร็วสูงเปลี่ยนเลเยอร์จาก L1 ไป L6 แต่ไม่มีตัวเก็บประจุ Stitching เชื่อมระหว่าง L2 (GND) กับ L5 (1.8V) เพื่อป้องกันการเพิ่มขึ้นของ Loop Area และ Jitter กรุณาเพิ่ม Stitching Capacitor 0.1uF ชิดข้าง Signal Via ในระยะไม่เกิน 0.5mm)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Inter-plane Capacitance และค่า Impedance ที่ความถี่สูง)
โครงสร้าง Stackup ของบอร์ด 8 ชั้น มีการวาง Power Plane และ Ground Plane ประกบกันที่กึ่งกลางบอร์ดด้วยแผ่นฉนวน Prepreg บางเฉียบหนา $d = 2.5 \text{ mil} \ (63.5 \ \mu\text{m})$ บนพื้นที่ทับซ้อน $A = 100 \text{ cm}^2 = 0.01 \text{ m}^2$ ($\epsilon_r = 4.0$) ถามว่าค่าความจุไฟฟ้าระหว่างระนาบ ($C_{plane}$) มีค่าเท่าใดโดยประมาณ?

- **ก)** $C_{plane} \approx 5.58 \text{ nF}$
- **ข)** $C_{plane} \approx 55.8 \text{ pF}$
- **ค)** $C_{plane} \approx 0.55 \text{ \mu F}$
- **ง)** $C_{plane} \approx 1.20 \text{ nF}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ก)**  
> คำนวณ Inter-plane Capacitance:  
> $$C_{plane} = \frac{\epsilon_0 \ \epsilon_r \ A}{d}$$  
> แทนค่าพารามิเตอร์:  
> $$C_{plane} = \frac{(8.854 \times 10^{-12} \ \text{F/m}) \times 4.0 \times 0.01 \ \text{m}^2}{63.5 \times 10^{-6} \ \text{m}} = \frac{3.5416 \times 10^{-13}}{6.35 \times 10^{-5}} \approx \mathbf{5.577 \times 10^{-9} \ \text{F} \approx 5.58 \ \text{nF}}$$  
> ค่าความจุไฟฟ้า $5.58 \text{ nF}$ ที่กระจายตัวอยู่ทั่วทั้งระนาบนี้ให้ประสิทธิภาพในการจ่ายกระแสความถี่สูงระดับหลายร้อย MHz ได้ดีกว่าการใช้ตัวเก็บประจุเซรามิก 0402 นับสิบตัวรวมกัน เพราะมันไม่มีความเหนี่ยวนำอนุกรมแฝงจากก้านลีดหรือรูเจาะ Via

### ข้อที่ 2 (กลไกทางฟิสิกส์ของกฎ 20H Rule)
เหตุใดการร่นขอบของระนาบ Power Plane เข้ามาจากขอบของ Ground Plane เป็นระยะทาง $20 \times h$ จึงสามารถลดการแผ่รังสีคลื่นแม่เหล็กไฟฟ้า (Edge Radiation) ออกจากขอบของแผ่นวงจรพิมพ์ได้อย่างมีนัยสำคัญ?

- **ก)** เพราะความต้านทานของขอบบอร์ดจะเพิ่มขึ้นเป็น 20 เท่า
- **ข)** เพราะเส้นแรงสนามไฟฟ้า (Fringing E-Field) ที่ขอบของ Power Plane จะถูกเหนี่ยวนำให้โค้งงอกลับเข้าหาระนาบ Ground Plane ทั้งด้านบนและด้านล่างที่ยื่นยาวกว่า แทนที่จะกระจายตัวหลุดรอดออกสู่อากาศภายนอกแผ่นบอร์ด
- **ค)** เพื่อให้พนักงานประกอบสามารถจับถือขอบบอร์ดได้โดยไม่ถูกไฟดูด
- **ง)** เพื่อลดความร้อนที่สะสมบริเวณขอบบอร์ดเวลาโดนแดด

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> เมื่อระนาบ Power และ Ground มีขนาดเท่ากันพอดีเป๊ะ เส้นแรงสนามไฟฟ้าที่ขอบแผ่นจะโป่งพองออกสู่ภายนอก (Fringing Field) และแผ่คลื่นแม่เหล็กไฟฟ้าระดับฮาร์มอนิกออกสู่อากาศทำหน้าที่เสมือนสายอากาศแบบขอบ  
> การร่นขอบ Power Plane ลึกเข้ามา $20h$ จะเปลี่ยนรูปทรงเรขาคณิตของสนามไฟฟ้า โดยบังคับให้เส้นแรงสนามไฟฟ้าเกือบทั้งหมดถูกดูดซับลงสู่ระนาบ Ground Plane ด้านบนและล่างที่ยื่นเลยออกไป สนามไฟฟ้าจึงไม่เล็ดลอดออกไปนอกขอบแผ่นบอร์ด ช่วยลดการแผ่คลื่น EMI ลงได้ประมาณ $70\%$ ($-10 \text{ dB}$)

### ข้อที่ 3 (การจัดการกระแสย้อนกลับเมื่อสัญญาณเปลี่ยนเลเยอร์ข้ามระนาบต่างศักย์)
หากสัญญาณนาฬิกาความเร็วสูง $100 \text{ MHz}$ มุดเปลี่ยน Layer ผ่าน Via จาก Layer ที่มีระนาบ Ground เป็น Reference ไปยัง Layer ที่มีระนาบ **+3.3V Power** เป็น Reference หากไม่มีตัวเก็บประจุ Stitching Capacitor เชื่อมต่ออยู่ใกล้ๆ Via สัญญาณ ปรากฏการณ์ใดจะเกิดขึ้นกับกระแสย้อนกลับ?

- **ก)** กระแสย้อนกลับจะหยุดไหลทันทีและทำให้สัญญาณดับลง
- **ข)** กระแสย้อนกลับจะถูกบีบให้ไหลย้อนกลับผ่านตัวเก็บประจุ Decoupling ที่ใกล้ที่สุดในบริเวณนั้น ก่อให้เกิดวงลูปกระแสขนาดใหญ่ (Large Current Loop Area) ซึ่งสร้างความเหนี่ยวนำแฝงสูง เกิด Jitter บนสัญญาณ และแผ่รังสี EMI สูงมาก
- **ค)** ระนาบ Ground และ Power จะลัดวงจรเข้าหากันโดยอัตโนมัติ
- **ง)** สัญญาณ Clock จะเปลี่ยนความถี่กลายเป็น 200 MHz

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> สัญญาณความถี่สูงต้องการเส้นทางวนกลับที่มี Loop Inductance ต่ำที่สุด  
> เมื่อสัญญาณข้ามจากระนาบ GND ไปยังระนาบ +3.3V กระแสย้อนกลับไม่สามารถกระโดดข้ามระนาบต่างศักย์ได้โดยตรง มันจึงจำเป็นต้องเดินทางวนอ้อมไปหาตัวเก็บประจุ Decoupling ตัวที่ใกล้ที่สุดเพื่อข้ามระนาบผ่านกระแส Displacement Current  
> เส้นทางวนอ้อมนี้สร้าง **Loop Area มหาศาล** ซึ่งก่อให้เกิดค่าความเหนี่ยวนำแฝงขนาดใหญ่ ทำให้รูปคลื่นเกิด Overshoot, Ringing, Timing Jitter และปล่อยคลื่นสัญญาณรบกวน EMI ออกมาอย่างรุนแรง การวาง Stitching Capacitor ชิดกับ Via สัญญาณจึงเป็นกฎเหล็กในการกำจัดปัญหานี้
