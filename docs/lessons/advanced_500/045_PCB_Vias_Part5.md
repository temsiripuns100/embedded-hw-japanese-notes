## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการตรวจสอบคุณภาพและความน่าเชื่อถือของบอร์ดวงจรพิมพ์ระดับภารกิจวิกฤต (Mission-Critical PCBs เช่น ระบบควบคุมการบิน, รถยนต์ขับเคลื่อนอัตโนมัติ, และเซิร์ฟเวอร์ศูนย์ข้อมูล) การทดสอบทางไฟฟ้าขั้นต้น (ICT / Flying Probe) ไม่เพียงพอที่จะรับประกันว่าบอร์ดจะทำงานได้ตลอดอายุการใช้งาน 10-15 ปี 
วิศวกรระดับ Senior ต้องเชี่ยวชาญการวิเคราะห์ทางโลหะวิทยาผ่าน **การตัดชิ้นเนื้อตรวจภาพตัดขวาง (Microsection Metallurgical Analysis)** ตามมาตรฐาน **IPC-TM-650 2.1.1** เพื่อตรวจหาข้อบกพร่องระดับจุลภาค เช่น Barrel Cracking, Wedge Voiding, และ Inner-layer Separation

นอกจากนี้ ในมิติของ Signal Integrity การปล่อยให้มีติ่งทองแดงส่วนเกินของ Via ที่ไม่ได้ใช้งาน (**Via Stub**) จะกระตุ้นปรากฏการณ์ **Quarter-Wave Stub Resonance** ที่ดูดกลืนพลังงานสัญญาณจนเกิดหลุมลึก (Notch Dip) บนกราฟ $S_{21}$ ซึ่งจำเป็นต้องควบคุมด้วยกระบวนการ **Backdrilling (Controlled-Depth Drilling)** อย่างเข้มงวด

### 1.1 การวิเคราะห์ข้อบกพร่องระดับจุลภาคผ่าน Microsection Analysis (IPC-TM-650)

ขั้นตอนการเตรียมตัวอย่างชิ้นงาน (Coupon Cross-Sectioning):
1. หล่อชิ้นงานในเบ้าเรซินอีพอกซีสุญญากาศ (Vacuum Potting)
2. ขัดหยาบด้วยกระดาษทรายซิลิคอนคาร์ไบด์ และขัดละเอียดด้วยผงขัดเพชร/อลูมินาขนาด $0.05 \ \mu\text{m}$ จนถึงแนวกึ่งกลางของกระบอก Via พอดีเป๊ะ
3. กัดกรดด้วยสารละลายเคมี (Ammonium Hydroxide + Hydrogen Peroxide) เพื่อเปิดเผยรอยต่อเกรนของผลึกทองแดง (Copper Grain Boundaries)

```
        Typical PTH Microsection Failure Modes
        ───────────────────────────────────────────────────────────── Top Foil
        ┌───┐                 ▲                    ┌───┐
        │ C │                 │ Knee / Corner      │   │ ◄── [Mode 2: Corner Crack]
        │   └─────────────────┴────────────────────┘   │
        │   │                                      │   │
        │ B │ ◄── [Mode 1: Mid-Barrel Crack]       │   │
        │   │                                      │   │
        ├───┴──────────┐                ┌──────────┴───┤ ◄── [Mode 3: Inner Foil Separation]
        │ Inner Foil   │                │ Inner Foil   │
        ├──────────────┤                ├──────────────┤
        │ D │ ◄── [Mode 4: Wedge Voiding in Glass] │   │
        └───┴──────────────────────────────────────┴───┘
        ───────────────────────────────────────────────────────────── Bottom Foil
```

| รหัสข้อบกพร่อง | ชื่อเรียกทางเทคนิค | กลไกทางฟิสิกส์และสาเหตุหลัก | เกณฑ์การยอมรับ (IPC-6012 Class 3) |
|---|---|---|---|
| **Mode 1** | **Barrel Cracking (バレルクラック)** | กระบอกทองแดงฉีกขาดในแนวนอน (มักเกิดที่กึ่งกลางรูที่ชุบบางที่สุด) จากแรงดึง $Z$-axis CTE ระหว่างอบความร้อน | **ห้ามพบเด็ดขาด (Zero Defect Allowed)** |
| **Mode 2** | **Corner / Knee Cracking (コーナークラック)** | รอยแตกร้าวที่มุมหักระหว่างฟอยล์ผิวนอกกับกระบอกชุบ จากแรงเฉือนเชิงกล (Shear Stress Concentration) | **ห้ามพบเด็ดขาด (Zero Defect Allowed)** |
| **Mode 3** | **Inner Foil Separation (内層接続分離)** | รอยต่อระหว่างฟอยล์ชั้นในกับกระบอก Via แยกตัว จากการล้างคราบเรซิน (Desmear) ไม่สะอาด มีฟิล์มขวางกั้น | **ห้ามแยกตัวเด็ดขาด** (ต้องมีพันธะโลหะสมบูรณ์ 100%) |
| **Mode 4** | **Wedge Voiding (くさび形ボイド)** | คมสว่านดึงรั้งมัดใยแก้วจนเกิดโพรงรูปลิ่ม น้ำยาชุบแทรกซึมไม่ถึง เสี่ยงต่อการเกิดทางเดินลัดวงจร CAF | ยอมรับได้เฉพาะกรณีไม่เกิน $20\%$ ของความหนาชั้น |
| **Mode 5** | **Blowholes / Outgassing (ブローホール)** | ไอน้ำที่ขังในพรีเพร็กเดือดพล่านดันทะลุกระบอกทองแดงบางๆ ออกมาในระหว่างบัดกรี ก่อให้เกิดโพรงอากาศในจุดบัดกรี | พื้นที่ฟองอากาศต้องไม่เกินข้อกำหนด IPC-A-610 |

### 1.2 การทดสอบความเค้นอุณหภูมิขั้นสูง (Thermal Stress & Thermal Cycling: HATS)

เพื่อพิสูจน์ความทนทานของบอร์ดตามมาตรฐาน IPC-TM-650:
1. **Thermal Solder Float Test (Method 2.6.8):**  
   นำคูปองทดสอบลอยบนอ่างตะกั่วหลอมเหลวที่อุณหภูมิ **$288^\circ\text{C} \pm 5^\circ\text{C}$ เป็นเวลา 10 วินาที** (ทำซ้ำ $3 - 6$ รอบเพื่อจำลองการเข้าเตาอบ Reflow และ Rework) จากนั้นนำไปตัดขัด Microsection ตรวจหารอยร้าว
2. **Highly Accelerated Thermal Shock (HATS / OM-Tester):**  
   ทดสอบวัฏจักรอุณหภูมิแบบเร่งด่วน: ปรับอุณหภูมิสลับระหว่าง **$-40^\circ\text{C}$ ถึง $+145^\circ\text{C}$** ภายในเวลาไม่กี่นาที ต่อเนื่องกัน $1,000 - 2,000$ รอบ พร้อมวัดค่าความต้านทานไฟฟ้ากระแสตรง ($R_{dc}$) ของ Daisy Chain แบบ Real-time ตลอดเวลา:
   - **เกณฑ์การตัดสินตก:** หากค่าความต้านทานขยับเพิ่มขึ้น **$\Delta R > 5\%$** จะถือว่าเกิด Micro-crack ในกระบอก Via ทันที

### 1.3 ทฤษฎี Quarter-Wave Stub Resonance และสมการ Notch Frequency

เมื่อสัญญาณดิจิทัลความเร็วสูงเดินทางผ่าน Through-Hole Via จากเลเยอร์บน (Layer 1) มุดลงสู่เลเยอร์ชั้นใน (Layer 3) กระบอกทองแดงส่วนที่เหลือจาก Layer 3 ทอดยาวลงไปถึง Layer ล่างสุด (Layer Bottom) จะไม่มีกระแสไหลออกไปไหน ส่วนนี้เรียกว่า **Via Stub**:

```
        Layer 1 (Input Trace) ────────┐
                                      ▼ Active Barrel (Signal Flow)
        Layer 3 (Output Trace) ───────┤
                                      │
                                      │ ◄── VIA STUB (Open-Ended Resonator)
                                      │     Length L_stub
                                      ▼
        Layer 12 (Bottom Layer) ──────┘ (Open Tip: Reflection Γ = +1)
```

1. **กลไกการหักล้างของคลื่นสะท้อน (Destructive Interference):**
   - คลื่นสัญญาณส่วนหนึ่งจะแยกวิ่งลงไปตาม Via Stub จนถึงปลายเปิดที่ก้นบอร์ด
   - คลื่นจะสะท้อนกลับด้วยสัมประสิทธิ์ $\Gamma = +1$ ขึ้นมายังรอยต่อที่ Layer 3
   - เมื่อความยาว Stub ($L_{stub}$) มีขนาดเท่ากับ **1 ใน 4 ของความยาวคลื่น ($\lambda / 4$)** คลื่นที่วิ่งไปและกลับจะเดินทางเป็นระยะทางรวมเท่ากับครึ่งความยาวคลื่น ($\lambda / 2$) พอดี ส่งผลให้มี **มุมเฟสกลับทิศ $180^\circ$** หักล้างกับสัญญาณหลักจนหมดสิ้น!

2. **สมการคำนวณ Notch Frequency ($f_{notch}$):**

$$f_{notch} \approx \frac{c}{4 \times L_{stub} \times \sqrt{\epsilon_r}} \times (2n - 1) \quad [n = 1, 2, 3...]$$

**ตัวอย่างการคำนวณ:**  
บอร์ดหนา $2.4 \text{ mm}$, สัญญาณมุดจาก L1 ไป L2 เหลือความยาว Stub $L_{stub} = 2.1 \text{ mm}$ บนบอร์ด $\epsilon_r = 4.0$:

$$f_{notch} = \frac{3.0 \times 10^8 \text{ m/s}}{4 \times (0.0021 \text{ m}) \times \sqrt{4.0}} = \frac{3.0 \times 10^8}{0.0168} \approx \mathbf{17.85 \text{ GHz}}$$

กราฟ Insertion Loss ($S_{21}$) จะดิ่งเหวเกิดเป็นหลุมลึก (Deep Notch $> -30 \text{ dB}$) ที่ความถี่ 17.85 GHz ทำให้ฮาร์มอนิกของสัญญาณบัส 32Gbps / 56Gbps ถูกกลืนกินหายไป ขอบสัญญาณจะเบลอและ Eye Diagram ปิดสนิท

### 1.4 กระบวนการ Backdrilling (Controlled-Depth Drilling)

เพื่อกำจัด Via Stub อุตสาหกรรมใช้กระบวนการเจาะคว้านเอาเนื้อทองแดงส่วนเกินทิ้งไปจากฝั่งตรงข้าม:

```
        Structure A: Uncut Stub (Resonance Notch!)     Structure B: Backdrilled (Stub Removed)
        Layer 1 (In)  ────────┐                        Layer 1 (In)  ────────┐
                              │                                              │
        Layer 3 (Out) ────────┤                        Layer 3 (Out) ────────┤
                              │                                              │ ◄── Residual Stub (≤ 0.2mm)
                              │ Stub Length                                  ▼
                              │ (1.8 mm)                        ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
                              │                                 ░ Oversized Backdrill Void (Air)    ░
                              ▼                                 ░ (Drill Dia = Hole Dia + 0.2mm)    ░
        Layer 12 (Bottom) ────┘                                 ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
```

- **สเปก Backdrill Residual Stub ($L_{residual}$):**  
  มาตรฐานอุตสาหกรรมสำหรับสัญญาณที่เกิน $10 \text{ Gbps}$ บังคับให้ควบคุมความลึกของสว่าน Backdrill เพื่อให้เหลือติ่งทองแดงตกค้าง:
  $$L_{residual} \le 0.15 \text{ mm} \ - \ 0.20 \text{ mm} \ (6 - 8 \text{ mil})$$
  เมื่อ $L_{residual} \le 0.15 \text{ mm}$ ความถี่ Notch จะถูกผลักให้กระเด็นออกไปไกลกว่า **$60 - 80 \text{ GHz}$** พ้นจากย่านความถี่ใช้งานจริง ทำให้กราฟ $S_{21}$ เรียบเนียนตลอดช่วงแบนด์วิธ

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** สวิตช์เครือข่ายศูนย์ข้อมูลความเร็วสูง 32Gbps Fibre Channel (FC32) เกิดปัญหาพอร์ตเชื่อมต่อบางพอร์ตไม่สามารถซิงก์สัญญาณได้ (Link Sync Failed) และตรวจพบค่า Bit Error Rate สูงผิดปกติที่เฉพาะพอร์ตที่มีการเดินสายบน Layer 3 บนบอร์ดหนา 16 เลเยอร์ ($2.6 \text{ mm}$)
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **ลืมสั่งคำสั่ง Backdrilling ในแบบสั่งผลิต:** วิศวกรออกแบบเดินสาย SerDes จาก Top Layer (L1) มุดลงสู่ L3 โดยคิดว่า "ลงไปแค่ชั้นตื้นๆ น่าจะไม่มีปัญหา" แต่ไม่ได้ออกคำสั่ง Backdrill ใน Drawing ปล่อยให้เหลือ Via Stub ยาวถึง **$2.15 \text{ mm}$** ทอดยาวลงไปถึง L16
2. **Quarter-Wave Notch ตกที่ความถี่ 16.5 GHz:**  
   ความถี่ Nyquist ของสัญญาณ FC32 อยู่ที่ $14.025 \text{ GHz}$ โดยมีฮาร์มอนิกที่ 16.5 GHz ส่งผลให้คลื่นสะท้อนจาก Stub เกิดการหักล้างจนเกิดรอยบุ๋มลึกบนกราฟ $S_{21}$ ถึง **$-28 \text{ dB}$** พลังงานสัญญาณหายไปเกือบหมด
3. **ตรวจพบ Barrel Knee Crack ร่วมด้วย:** จากการทำ Microsection ยังพบรอยแตกร้าวที่มุมขอบปากรูเนื่องจากโรงงานเร่งสปีดสว่านเจาะจนเกิดความร้อนสูงสะสม

---

### ขั้นตอนการสั่งผลิตและการควบคุม Backdrill สไตล์ Senior (検図チェックリスト):
1. **การกำหนดตาราง Backdrill Table ในไฟล์ Drawing:**
   - ต้องสร้างตารางระบุคู่เลเยอร์ที่ต้องทำ Backdrill ให้ชัดเจน:
     - เช่น: *Signal Net: `FC32_TX_P/N` | Start Layer: L1 | End Layer: L3 | Backdrill from: Bottom (L16) up to Layer 4 | Max Residual Stub: 0.18 mm (7 mil)*
2. **การกำหนดขนาดเส้นผ่านศูนย์กลางดอกสว่าน Backdrill ($D_{backdrill}$):**
   - ดอกสว่าน Backdrill ต้องมีขนาดใหญ่กว่ารูเจาะเดิมอย่างน้อย:
     $$D_{backdrill} = D_{original\_drill} + 0.20 \text{ mm} \ (8 \text{ mil})$$
   - เพื่อขจัดเนื้อทองแดงและวงแหวน Pad ชั้นในออกอย่างหมดจด ไม่ให้เหลือเศษเกล็ดทองแดง (Copper Burrs) ค้างอยู่ในรู
3. **การตรวจสอบ Microsection ยืนยัน Residual Stub:**
   - บังคับให้โรงงานตัดชิ้นเนื้อ Microsection จากคูปองทดสอบที่แผงพาเนล (Panel Margin Coupon) ส่องวัดระยะติ่งทองแดงจริงส่งเป็นรายงาน First Article Inspection (FAI) ทุกครั้ง

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「32Gbps高速ラインにおいて、L1層からL3層へのビア遷移部（板厚2.6mm）にバックドリル加工の指示がありません。残存スタブ長が約2.1mmに達しており、1/4波長共振計算により17GHz近傍で-28dB以上の猛烈なS21ディップ（通過損失ノッチ）が発生して通信不能となる致命的設計ミスです。製造仕様書に「裏面（L16層）からの深さ制御バックドリル加工（残存スタブ長0.18mm以下）」を必須指示として追記し、製造承認図面を改訂してください。」  
> *(ในสาย 32Gbps จุดเปลี่ยนเลเยอร์จาก L1 ไป L3 บอร์ดหนา 2.6mm ไม่ได้สั่ง Backdrilling ทำให้เหลือ Stub ยาว 2.1mm เกิดรอยหลุม S21 ลึกกว่า -28dB ที่ 17GHz จนสื่อสารไม่ได้ กรุณาระบุในแบบสั่งผลิตให้ทำ Backdrilling จากด้านหลัง L16 โดยคุม Residual Stub ไม่เกิน 0.18mm ทันที)*

> **指摘事項 2:**  
> 「信頼性試験用テストクーポン（IPC Class 3仕様）の断面研磨観察（288℃/10秒ハンダフロート後）において、内層銅箔接続部にデスミア不良に起因する界面分離（インナーフォイルセパレーション）が複数観測されました。製造工場のプラズマデスミア工程パラメーターの見直しおよび、HATS熱衝撃試験（1000サイクル、ΔR≦5%）の合格証明書の提出を納入条件として義務付けてください。」  
> *(ในการตรวจ Microsection หลังการทดสอบ Solder Float 288°C/10s พบการแยกตัวของฟอยล์ชั้นในจากปัญหา Desmear หลายจุด ขอสั่งให้โรงงานทบทวนพารามิเตอร์ Plasma Desmear และกำหนดให้ส่งผลการทดสอบ HATS 1000 รอบ Delta R <= 5% เป็นเงื่อนไขการส่งมอบ)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Quarter-Wave Resonance ของ Via Stub)
บอร์ดเซิร์ฟเวอร์ความหนา $2.40 \text{ mm}$ ใช้วัสดุที่มีค่า $\epsilon_r = 3.80$ สัญญาณ PCIe Gen 5 (ความถี่ Nyquist $16.0 \text{ GHz}$) วิ่งจาก Layer 1 มุดลงสู่ Layer 2 ทำให้เหลือความยาว Via Stub ทอดยาวลงไปถึงด้านล่างคิดเป็นความยาว $L_{stub} = 2.10 \text{ mm}$ ถามว่าความถี่ Notch Frequency ($f_{notch}$) หลักของ Via Stub นี้จะตกลงที่ย่านความถี่ใด และจะส่งผลกระทบต่อสัญญาณ PCIe Gen 5 อย่างไร?

- **ก)** ตกที่ความถี่ $18.3 \text{ GHz}$ ซึ่งอยู่ใกล้กับความถี่หลัก 16 GHz พอดี ทำให้ Insertion Loss ดิ่งลงอย่างรุนแรงและ Eye Diagram ปิดสนิท
- **ข)** ตกที่ความถี่ $5.2 \text{ GHz}$ ซึ่งไม่มีผลกระทบต่อสัญญาณ 16 GHz
- **ค)** ตกที่ความถี่ $50.0 \text{ GHz}$ ซึ่งอยู่นอกย่านความถี่ใช้งาน
- **ง)** ตกที่ความถี่ $0.0 \text{ GHz}$ (สัญญาณกระแสตรง)

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ก)**  
> คำนวณความถี่ Quarter-Wave Stub Resonance ($f_{notch}$):  
> $$f_{notch} \approx \frac{c}{4 \times L_{stub} \times \sqrt{\epsilon_r}}$$  
> แทนค่าตัวเลข:  
> $$f_{notch} = \frac{3.0 \times 10^8 \text{ m/s}}{4 \times (0.0021 \text{ m}) \times \sqrt{3.80}} = \frac{3.0 \times 10^8}{0.0084 \times 1.949} = \frac{3.0 \times 10^8}{0.01637} \approx \mathbf{18.32 \times 10^9 \text{ Hz}} = \mathbf{18.32 \text{ GHz}}$$  
> ผลกระทบทางวิศวกรรม:  
> สัญญาณ PCIe Gen 5 มีความถี่ Nyquist อยู่ที่ $16.0 \text{ GHz}$  
> หลุม Notch ที่ $18.3 \text{ GHz}$ อยู่ประชิดติดกับความถี่หลักของสัญญาณอย่างยิ่งยวด! พลังงานของฮาร์มอนิกที่ควบคุมความชันของขอบสัญญาณ (Edge Transition Energy) จะถูกดูดกลืนหายไปในหลุมนี้ ($S_{21}$ ตกต่ำกว่า $-25 \text{ dB}$) ส่งผลให้รูปคลื่นสัญญาณเบลอ ไม่สามารถเปิด Eye Mask ได้ และบัส PCIe จะไม่สามารถฝึกอบรมสัญญาณ (Link Training Failed) ได้สำเร็จ จำเป็นต้องทำ Backdrill ทันที

---

### ข้อที่ 2 (ทำไมการขจัดเศษเสี้ยนทองแดง Copper Burrs ในขั้นตอน Backdrilling จึงมีความสำคัญอย่างยิ่ง?)
ในกระบวนการเจาะคว้าน Backdrilling เหตุใดวิศวกรโรงงานจึงต้องควบคุมไม่ให้เกิดเศษเสี้ยนทองแดงตกค้าง (Copper Burrs / Swarf) อยู่ภายในรูกลวงของ Backdrill Void?

- **ก)** เพราะเศษทองแดงจะทำให้น้ำหนักของบอร์ดเพิ่มขึ้น
- **ข)** เพราะเศษเสี้ยนทองแดงที่ติดค้างอยู่อาจหลุดร่อนออกมาระหว่างการสั่นสะเทือน ไปลัดวงจรระหว่างระนาบกราวด์และระนาบไฟชั้นใน หรือทำหน้าที่เป็นติ่งเสาอากาศปรสิตขนาดจิ๋วที่สร้างคลื่นรบกวนความถี่สูงที่คาดเดาไม่ได้
- **ค)** เพราะเศษทองแดงจะไปละลายเรซินอีพอกซี
- **ง)** เพราะจะทำให้บอร์ดไม่ผ่านเกณฑ์สีของ Solder Mask

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในระหว่างที่ดอกสว่าน Backdrill หมุนตัดเนื้อทองแดงของกระบอกและ Pad ชั้นในออก:  
> หากดอกสว่านทื่อหรือความเร็วรอบไม่ได้สัดส่วน จะเกิดเศษครีบทองแดงแหลมคม (Copper Burrs) ยื่นค้างอยู่ที่ขอบของชั้นใน  
> อันตรายมี 2 ประการหลัก:  
> 1. ด้านความน่าเชื่อถือทางกายภาพ: เศษทองแดงนี้อาจหลุดร่อนออกมาระหว่างการล้างบอร์ดหรือการสั่นสะเทือนใช้งานจริง ก่อให้เกิดการลัดวงจรข้ามชั้น (Inter-layer Short Circuit)  
> 2. ด้าน Signal Integrity: เศษครีบที่ยื่นออกมาจะทำหน้าที่เสมือนตัวเก็บประจุแฝงที่ไม่สมมาตร (Parasitic Fringing Tip) ดึงให้ค่าอิมพีแดนซ์ที่จุดรอยตัดเพี้ยน และอาจกลายเป็นตัวปล่อยคลื่นสั่นพ้องแปลกปลอม ดังนั้น โรงงานจึงต้องใช้ดอกสว่านคาร์ไบด์คมพิเศษและกระบวนการเป่าล้างแรงดันสูง (High-Pressure De-burring) ทุกครั้ง

### ข้อที่ 3 (เกณฑ์ความต้านทานที่ยอมรับได้ในการทดสอบ HATS Thermal Shock)
ในการทดสอบวัฏจักรอุณหภูมิแบบเร่งด่วน Highly Accelerated Thermal Shock (HATS) สำหรับตรวจสอบความสมบูรณ์ของกระบอก Through-Hole Via ตามมาตรฐาน IPC Class 3 ค่าการเปลี่ยนแปลงของความต้านทานไฟฟ้ากระแสตรง ($\Delta R$) สูงสุดที่ยอมรับได้ตลอด 1,000 รอบการทดสอบมีค่าเท่ากับข้อใด?

- **ก)** $\Delta R \le 5.0\%$ (หรือสูงสุดไม่เกิน $10\%$ ตามข้อตกลงพิเศษ)
- **ข)** $\Delta R \le 50.0\%$
- **ค)** $\Delta R \le 100.0\%$
- **ง)** ยอมรับค่าความต้านทานใดๆ ก็ได้ตราบใดที่ไม่เปิดวงจรสมบูรณ์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ก)**  
> ในการทดสอบ HATS หรือ OM-Tester:  
> สายทดสอบ Daisy Chain ที่ร้อยผ่าน Via นับพันรูจะถูกต่อเข้ากับเครื่องวัดความต้านทาน 4 สาย (4-Wire Kelvin Sensing) และทำการวัดค่าอย่างต่อเนื่องในระหว่างที่อุณหภูมิเหวี่ยงจาก $-40^\circ\text{C}$ ไปยัง $+145^\circ\text{C}$  
> หากกระบอกทองแดงเริ่มเกิดรอยแตกร้าวระดับไมโคร (Micro-crack Initiation):  
> พื้นที่หน้าตัดของทองแดงจะลดลง ดันให้ค่าความต้านทานไฟฟ้าขยับสูงขึ้น  
> มาตรฐาน IPC Class 3 กำหนดเกณฑ์เข้มงวดว่า: **หากความต้านทานขยับเพิ่มขึ้นเกิน $\Delta R > 5.0\%$ (หรือ $10\%$ ในบางสเปก) จะถือว่าตัวอย่างทดสอบล้มเหลวทันที (Failure)** เนื่องจากรอยร้าวขนาดเล็กนี้จะลุกลามกลายเป็นรอยขาดสะบั้นสมบูรณ์ (Catastrophic Open Circuit) ในระหว่างการใช้งานจริงภาคสนาม
