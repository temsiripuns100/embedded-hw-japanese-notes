## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในระบบส่งสัญญาณดิจิทัลความเร็วสูงที่เกิน $10 \text{ Gbps}$ (เช่น 25G/50G NRZ, 112G PAM4, PCIe Gen 5/6) ศัตรูตัวฉกาจอันดับหนึ่งที่สามารถทำลายลิงก์การสื่อสารได้อย่างเฉียบพลันคือ **Via Stub (ติ่งปลายเปิดของกระบอก Through-Hole Via ที่ไม่ได้ใช้งาน)**

ในมุมมองของฟิสิกส์คลื่นแม่เหล็กไฟฟ้า Via Stub ไม่ใช่แค่เส้นลวดทองแดงที่ไม่มีกระแสไหล แต่มันประพฤติตัวเป็น **วงจรกรองดักคลื่นปลายเปิด (Open-Circuited Transmission Line Resonator)** 
ที่ความถี่ $1/4$ ความยาวคลื่น (Quarter-Wave Resonance) อิมพีแดนซ์อินพุตของ Stub จะลดฮวบลงเหลือ **$0 \ \Omega$ (เสมือนการลัดวงจร AC Short Circuit ลงกราวด์ ณ จุดแยกสัญญาณ!)** ดูดกลืนพลังงานสัญญาณจนเกิดหลุมยุบขนาดใหญ่ (Deep Notch Filter) บนกราฟ $S_{21}$ 

วิศวกรระดับ Senior ต้องเข้าใจ **การวิเคราะห์อิมพีแดนซ์เชิงซ้อนของ Stub**, **การควบคุมพิกัดความเผื่อของสว่าน Backdrilling ในแนวแกน Z**, และ **การตัดสินใจเชิงสถาปัตยกรรมระหว่าง Blind Vias กับ Backdrilled PTH**

### 1.1 การพิสูจน์ทางคณิตศาสตร์: ทำไม Via Stub จึงกลายเป็นการลัดวงจร ($0 \ \Omega$) ที่ความถี่ 1/4 ความยาวคลื่น?

พิจารณา Via Stub ความยาว $L_{stub}$ ซึ่งเป็นสายส่งปลายเปิด (Open Circuit: โหลดที่ปลายทาง $Z_L = \infty$):

```
       Input Signal Line ───────────┬─────────── Output Signal Line
                                    │
                                    │ ◄── Branch Point (V_branch)
                                    │
                                   ┌┴┐
                                   │ │
                                   │ │ Stub Length L_stub
                                   │ │ (Characteristic Impedance Z_stub)
                                   └┬┘
                                    │
                                   ─── Open-Circuited Tip (Z_L = ∞, Γ = +1)
```

1. **สมการอิมพีแดนซ์อินพุตของสายส่งปลายเปิด (Input Impedance of Open Stub):**  
   จากสมการสายส่งกำลังมาตรฐาน (Transmission Line Equation):

$$Z_{in,stub} = Z_{stub} \left[ \frac{Z_L + j Z_{stub} \tan(\beta L_{stub})}{Z_{stub} + j Z_L \tan(\beta L_{stub})} \right]$$

เมื่อแทนค่าปลายเปิด $Z_L \to \infty$:

$$Z_{in,stub} = -j Z_{stub} \cot(\beta L_{stub}) = -j Z_{stub} \cot\left( \frac{2\pi f \sqrt{\epsilon_r}}{c} L_{stub} \right)$$

2. **สภาวะสั่นพ้องคลื่น 1 ใน 4 (Quarter-Wave Condition):**  
   เมื่อความยาวของ Stub มีขนาดเท่ากับ $1/4$ ของความยาวคลื่นในตัวกลาง ($L_{stub} = \frac{\lambda}{4} = \frac{c}{4 f \sqrt{\epsilon_r}}$):  
   มุมเฟสทางไฟฟ้าคือ $\beta L_{stub} = \left(\frac{2\pi}{\lambda}\right) \left(\frac{\lambda}{4}\right) = \frac{\pi}{2} \ (90^\circ)$

$$Z_{in,stub} = -j Z_{stub} \cot\left(\frac{\pi}{2}\right) = -j Z_{stub} \times (0) = \mathbf{0 \quad [\Omega]}$$

**ผลลัพธ์ทางฟิสิกส์อันน่าสะพรึงกลัว:**  
ณ ความถี่ $f_{notch} = \frac{c}{4 L_{stub} \sqrt{\epsilon_r}}$ อิมพีแดนซ์ของ Stub จะกลายเป็น **ศูนย์โอห์ม ($0 \ \Omega$) บริสุทธิ์!**  
เสมือนมีใครนำสายทองแดงมาบัดกรีชอร์ตจุดแยกสัญญาณลงระนาบกราวด์โดยตรง ส่งผลให้พลังงานของสัญญาณ ณ ย่านความถี่นั้นทั้งหมดถูกสะท้อนและดูดซับลงดิน เกิดเป็นหลุมลึก **$-30 \text{ dB}$ ถึง $-50 \text{ dB}$ บนกราฟ $S_{21}$**

### 1.2 การเปรียบเทียบเชิงสถาปัตยกรรม: Blind Vias vs Backdrilled PTH

ในการกำจัด Via Stub วิศวกรสามารถเลือกใช้ได้ 2 แนวทางหลัก:

```
        Structure A: Blind Via Architecture           Structure B: Backdrilled PTH Architecture
        L1 ───────────┐                               L1 ───────────┐
                      │ No stub!                                    │
        L3 ───────────┘                               L3 ───────────┘
        L4 ════════════════════════════               L4 ═══════════╪═══════════════
        (Solid dielectric, no drilling)                             │ Residual Stub (≤0.15mm)
                                                                    ▼
                                                       ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
                                                       ░ Backdrilled Air Void (Hole) ░
        L16 ───────────────────────────               L16 ───────────────────────────
```

| ปัจจัยการเปรียบเทียบ | Blind Vias (HDI Sequential Lamination) | Backdrilled PTH (Controlled-Depth Drill) |
|---|---|---|
| **การมีอยู่ของ Stub** | **ไม่มี Stub เลยโดยกำเนิด ($L_{stub} = 0$)** | มีติ่งตกค้างเล็กน้อย ($L_{residual} \le 0.15 \text{ mm}$)|
| **ขั้นตอนการอัดลามิเนต (Lamination)**| ต้องอัดซ้ำหลายรอบ (Sequential SBU Cycles) | **อัดลามิเนตเพียงรอบเดียวเสร็จ (Single Cycle)** |
| **ต้นทุนการผลิตแผ่นบอร์ด** | สูงมาก (เพิ่มขึ้น $+80\%$ ถึง $+150\%$) | **ประหยัดกว่ามาก (เพิ่มขึ้นเพียง $+15\%$ ถึง $+25\%$)** |
| **ความหนาของแผ่นบอร์ดที่รองรับ** | จำกัดเฉพาะบอร์ดบางและ HDI ($< 2.0 \text{ mm}$) | **รองรับบอร์ดหนาเซิร์ฟเวอร์/แบ็กเพลน ($2.0 - 5.0 \text{ mm}$)**|
| **การใช้งานในอุตสาหกรรม** | สมาร์ตโฟน, การ์ดโมดูลขนาดกะทัดรัด | **เซิร์ฟเวอร์, เราเตอร์เครือข่าย, PCIe Backplane** |

### 1.3 พิกัดความเผื่อของสว่าน Backdrilling (Z-axis CNC Drill Tolerances)

กระบวนการ Backdrilling อาศัยเครื่องเจาะ CNC ควบคุมความลึกด้วยระบบตรวจจับความจุไฟฟ้าหรือเซนเซอร์สัมผัสหน้าสัมผัส (Contact-Sensing Z-axis Control):

```
                       Layer 3 (Functional Trace Layer) ───[ Copper Pad ]───
                                                                   ▲
                                                                   │ Safety Buffer Margin (≥ 4 mil / 0.10mm)
                       Layer 4 (Must-Not-Cut Layer)     ───────────┼────────────────────────────────────────
                                                                   ▼ Drill Stop Point
                                                       ┌───────────────────────────┐
                                                       │\   Backdrill Tip Angle   /│
                                                       │ \     (130° - 140°)     / │
                                                       │  \                     /  │
```

1. **ความคลาดเคลื่อนในแนวแกน Z ($\Delta Z_{tolerance}$):**  
   เครื่องเจาะ Backdrill คุณภาพสูงในปัจจุบันมีความคลาดเคลื่อนในแนวดิ่งประมาณ **$\pm 0.05 \text{ mm} \ (\pm 2 \text{ mil})$**
2. **ขอบเขตปลอดภัย Must-Not-Cut Buffer:**  
   เพื่อป้องกันไม่ให้ปลายดอกสว่านเจาะทะลุเข้าไปตัดขาดเส้นลายวงจรหรือ Pad บนเลเยอร์ใช้งาน (Layer 3):  
   วิศวกรต้องกำหนดระยะเผื่อปลอดภัย (Dielectric Buffer) อย่างน้อย **$0.10 \text{ mm} \ (4 \text{ mil})$** ใต้ชั้นใช้งาน
3. **ระยะติ่งทองแดงตกค้าง (Residual Stub Length: $L_{residual}$):**  
   - กระบวนการมาตรฐานทั่วไป: $L_{residual} \le 0.25 \text{ mm} \ (10 \text{ mil})$
   - กระบวนการความแม่นยำสูง (High-Precision Server Spec): **$L_{residual} \le 0.12 - 0.15 \text{ mm} \ (5 - 6 \text{ mil})$**

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** บอร์ดการ์ดเชื่อมต่อเครือข่าย 100G NIC (25.78 Gbps ต่อเลน x 4) ทำงานไม่เสถียร มีค่า Bit Error Rate สูงจนไม่ผ่านการรับรอง โดยมีคำสั่ง Backdrilling ระบุใน Drawing แล้ว แต่เมื่อวัด VNA พบว่ากราฟ $S_{21}$ มีหลุม Notch ลึกถึง **$-24 \text{ dB}$ ที่ความถี่ 27.2 GHz** (ทับซ้อนกับฮาร์มอนิกหลักของสัญญาณ 25.78G NRZ)
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **วิศวกร CAM ตั้งค่าระยะหยุดสว่านเซฟเกินไป:** วิศวกร CAM ของโรงงานกลัวว่าดอกสว่านจะเจาะทะลุไปโดนเลเยอร์ L4 จึงตั้งจุดหยุดสว่านถอยห่างออกมามากเกินไป ทำให้เหลือติ่งทองแดงตกค้างจริงยาวถึง **$L_{residual} = 0.42 \text{ mm} \ (16.5 \text{ mil})$**
2. **การคำนวณ Notch Frequency ที่แท้จริง:**  
   $$f_{notch} = \frac{3 \times 10^8}{4 \times (0.42 \times 10^{-3}) \times \sqrt{3.8}} \approx \frac{3 \times 10^8}{1.68 \times 10^{-3} \times 1.95} \approx \mathbf{22.9 - 27.0 \text{ GHz}}$$  
   หลุม Notch ที่ควรจะถูกผลักออกไปไกลกว่า 60 GHz กลับตกลงมาอยู่ในย่านความถี่ทำงานพอดีเป๊ะ

---

### ขั้นตอนการสั่งผลิตและการควบคุม Backdrill เชิงลึก สไตล์ Senior (検図チェックリスト):
1. **การคำนวณและระบุขีดจำกัด Residual Stub สูงสุดใน Drawing:**
   - คำนวณความถี่ Nyquist สูงสุด ($f_{Nyquist}$) และฮาร์มอนิกที่ 3 ($3 \times f_{Nyquist}$):
     $$f_{notch,min} > 3 \times f_{Nyquist}$$
     $$L_{residual,max} < \frac{c}{4 \times (3 \cdot f_{Nyquist}) \times \sqrt{\epsilon_r}}$$
   - สำหรับสัญญาณ 25 Gbps ($f_{Nyquist} = 12.89 \text{ GHz}$, ฮาร์มอนิก $\sim 38 \text{ GHz}$):
     $$L_{residual,max} < \frac{3 \times 10^8}{4 \times (38 \times 10^9) \times \sqrt{3.6}} \approx \frac{300}{152 \times 1.897} \approx \mathbf{0.26 \text{ mm}}$$
   - กำหนดในแบบสั่งผลิตให้ชัดเจน: **"Residual Stub MUST NOT exceed 0.15 mm (6 mil)"**
2. **การเลือกมุมปลายดอกสว่าน Backdrill (Drill Point Angle):**
   - ระบุให้โรงงานใช้ดอกสว่านปลายแบน (Flat-bottom drill) หรือมุมป้านพิเศษ ($140^\circ - 150^\circ$) แทนสว่านมาตรฐานมุมแหลม $118^\circ$
   - ช่วยลดความยาวส่วนแหลมของปลายสว่าน (Drill Tip Depth) ทำให้สามารถเจาะเอาทองแดงออกได้เกือบติดชั้นเป้าหมายโดยไม่ต้องเสี่ยงต่อการเจาะทะลุ
3. **การลบ Pad ของชั้นที่ถูกเจาะทิ้งในไฟล์ CAM (Backdrill Pad Removal):**
   - ตรวจสอบให้แน่ใจว่าในชั้นเลเยอร์ที่สว่าน Backdrill เจาะผ่าน วงแหวนทองแดง (Pads) ได้ถูกลบออกทั้งหมด เพื่อไม่ให้เกิดเศษขอบทองแดง (Swarf / Slivers) ค้างอยู่ในรู

> **指摘事項 1:**  
> 「25Gbps NRZ伝送路において、裏面バックドリル深さの指定マージンが過大であり、断面研磨実測で残存スタブ長が0.42mm（約16.5mil）検出されました。この残存スタブに起因する1/4波長共振ノッチがNyquist第2高調波近傍（26.8GHz）に発生し、S21通過損失が-24dBまで激しく落ち込んでいます。バックドリル深さのCNC制御公差（±0.05mm）を見直し、残存スタブ長を0.15mm以下（推奨0.10mm、先端角140°ドリル使用）へ厳格に追い込むよう製造指示書を改訂してください。」  
> *(ในสาย 25Gbps NRZ ระยะเผื่อ Backdrill มากเกินไป ตรวจพบ Residual Stub จริงยาว 0.42mm ทำให้เกิด Quarter-Wave Resonance Notch ลึก -24dB ที่ 26.8GHz ใกล้ฮาร์มอนิกที่ 2 กรุณาปรับการคุมความลึก CNC ให้คุม Stub ตกค้างไม่เกิน 0.15mm โดยใช้ดอกสว่านมุม 140 องศา)*

> **指摘事項 2:**  
> 「高多層バックプレーン（板厚3.2mm、24層）における高速差動信号のビア設計において、高価なシーケンシャル積層ブラインドビアが採用されていますが、製造コストが通常の2.4倍に跳ね上がっています。貫通ビア＋両面深さ制御バックドリル（残存スタブ長0.18mm以下）の構造へ変更することで、高周波SI特性（40GHz帯までノッチフリー）を同等以上に維持しつつ、基板製造コストを約40%削減してください。」  
> *(ในการออกแบบบอร์ด Backplane หนา 3.2mm 24 ชั้น มีการใช้ Blind Via หลายขั้นตอนทำให้ต้นทุนพุ่ง 2.4 เท่า การเปลี่ยนมาใช้ Through-Hole ร่วมกับ Backdrilling ควบคุม Stub ต่ำกว่า 0.18mm จะคงประสิทธิภาพความถี่สูงไร้รอย Notch ได้ถึง 40GHz เท่ากัน แต่ประหยัดต้นทุนบอร์ดได้ถึง 40%)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณความยาว Residual Stub สูงสุดที่ไม่ให้เกิด Notch ก่อน 40 GHz)
วิศวกรกำลังออกแบบช่องสัญญาณ PAM4 ความเร็วสูงที่ต้องการให้แบนด์วิธตอบสนองของกราฟ $S_{21}$ ปราศจากรอยบุ๋มเรโซแนนซ์ (Notch-free) ไปจนถึงความถี่อย่างน้อย $f_{target} = 40.0 \text{ GHz}$ บนบอร์ดความเร็วสูงที่มีค่า $\epsilon_r = 3.61$ ถามว่าความยาวของติ่งทองแดงตกค้างหลังทำ Backdrill (Residual Stub Length: $L_{residual}$) จะต้องถูกควบคุมให้สั้นกว่าค่าใด?

- **ก)** $L_{residual} \le 1.50 \text{ mm}$
- **ข)** $L_{residual} \le 0.98 \text{ mm} \ (38.6 \text{ mil})$
- **ค)** $L_{residual} \le 0.50 \text{ mm}$
- **ง)** $L_{residual} \le 0.98 \text{ mm} \times \frac{1}{10} \approx \mathbf{0.098 \text{ mm} \ (3.86 \text{ mil})}$ (หรือไม่เกิน $0.10 \text{ mm}$)

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ง)** (หรือ $L \le 0.984 \text{ mm}$ สำหรับความยาวคลื่นเต็ม แต่สำหรับ $\lambda/4$):  
> ลองคำนวณอย่างละเอียดจากสมการ Quarter-Wave Resonance:  
> $$f_{notch} = \frac{c}{4 \times L_{stub} \times \sqrt{\epsilon_r}} \ge 40.0 \times 10^9 \text{ Hz}$$  
> ย้ายข้างเพื่อหาความยาวสูงสุด $L_{stub,max}$:  
> $$L_{stub,max} \le \frac{c}{4 \times f_{notch} \times \sqrt{\epsilon_r}}$$  
> แทนค่าตัวเลข:  
> $$L_{stub,max} \le \frac{3.0 \times 10^8 \text{ m/s}}{4 \times (40.0 \times 10^9 \text{ Hz}) \times \sqrt{3.61}} = \frac{3.0 \times 10^8}{160.0 \times 10^9 \times 1.90}$$  
> $$L_{stub,max} \le \frac{3.0 \times 10^8}{3.04 \times 10^{11}} = 0.9868 \times 10^{-3} \text{ m} = \mathbf{0.987 \text{ mm} \ (38.8 \text{ mil})}$$  
> เดี๋ยวก่อน! หาก $L_{stub} = 0.987 \text{ mm}$ เรโซแนนซ์จะตกที่ $40 \text{ GHz}$ พอดีเป๊ะ  
> แต่ในทางวิศวกรรมอาวุโส ความชันของหลุม Notch กว้างมาก ($Q$-factor) รอยบุ๋มจะเริ่มดึงค่า $S_{21}$ ให้ตกลงมาตั้งแต่ความถี่ **ครึ่งหนึ่งของ Notch ($f_{notch}/2 = 20 \text{ GHz}$)**  
> ดังนั้น เพื่อรับประกันว่าที่ 40 GHz จะไม่ได้รับผลกระทบจากเชิงลาดของ Notch เลย ความถี่เรโซแนนซ์จริงควรถูกผลักออกไปที่อย่างน้อย $80 - 100 \text{ GHz}$  
> ซึ่งต้องใช้ความยาว Stub จริง:  
> $$L_{safe} \le \frac{0.987 \text{ mm}}{2.5} \approx \mathbf{0.15 \text{ mm} \ - \ 0.20 \text{ mm}}$$  
> ดังนั้น หากคำนวณตามสูตรทฤษฎี $f_{notch} = 40\text{GHz}$ ค่าสูงสุดคือ $0.98 \text{ mm}$ แต่ในสเปกผลิตจริงเพื่อความปลอดภัยระดับอุตสาหกรรม ต้องคุมให้ต่ำกว่า $0.15 \text{ mm}$ เสมอ

### ข้อที่ 2 (กลไกทางฟิสิกส์ที่ทำให้อิมพีแดนซ์ของ Stub กลายเป็น 0 โอห์มที่ความถี่ 1/4 ความยาวคลื่น)
ข้อใดอธิบายปรากฏการณ์ที่ทำให้ Via Stub ปลายเปิด (Open Circuit) ประพฤติตัวเสมือนการลัดวงจรสมบูรณ์แบบ ($0 \ \Omega$) ที่ความถี่ Quarter-Wave Resonance ได้อย่างถูกต้องตามทฤษฎีคลื่นนิ่ง?

- **ก)** คลื่นเดินทางไปถึงปลายเปิดและสะท้อนกลับด้วยมุมเฟสเดิม ($\Gamma = +1$) โดยการเดินทางไปและกลับคิดเป็นระยะทางรวมเท่ากับครึ่งความยาวคลื่น ($\lambda/2$) ซึ่งทำให้คลื่นสะท้อนเกิดการเลื่อนเฟสไป $180^\circ$ หักล้างกับแรงดันของคลื่นตกกระทบที่จุดแยกจนแรงดันรวมกลายเป็นศูนย์โวลต์ ($V=0 \implies Z = V/I = 0 \ \Omega$)
- **ข)** ปลายเปิดของ Via ดึงดูดประจุไฟฟ้าอิสระจากอากาศเข้ามาเติมเต็มในรูเจาะ
- **ค)** คลื่นแม่เหล็กไฟฟ้าเหนี่ยวนำให้ทองแดงในกระบอก Via เกิดสภาวะตัวนำยิ่งยวด (Superconductivity)
- **ง)** สนามไฟฟ้าในเนื้อฉนวนเรซินเกิดการสลายตัวแบบไดอิเล็กทริกเบรกดาวน์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ก)**  
> นี่คือแก่นแท้ของทฤษฎีคลื่นนิ่ง (Standing Wave Theory):  
> 1. ที่ปลายเปิดของสายส่ง คลื่นแรงดันจะสะท้อนกลับแบบเต็มกำลังโดยไม่มีการกลับขั้ว ($\Gamma = +1$, เฟสสะท้อน $0^\circ$)  
> 2. คลื่นสะท้อนเดินทางย้อนกลับมาตามความยาว Stub เป็นระยะทาง $L = \lambda/4$  
> 3. ระยะทางไป-กลับรวมกันคือ $2 \times (\lambda/4) = \lambda/2$ (ครึ่งความยาวคลื่นพอดี)  
> 4. การเดินทางระยะทาง $\lambda/2$ ทำให้มุมเฟสของคลื่นหน่วงไป $2\pi \times (\frac{1}{2}) = \pi \ \text{rad} = 180^\circ$  
> 5. เมื่อคลื่นสะท้อนที่มีมุมเฟส $180^\circ$ เดินทางมาถึงจุดแยกสัญญาณหลัก มันจะซ้อนทับแบบหักล้าง (Destructive Interference) กับแรงดันอินพุตเดิม ทำให้ศักย์ไฟฟ้าที่จุดนั้นตกเป็นศูนย์โวลต์ทันที ($V_{total} = 0\text{V}$) จึงมีพฤติกรรมเสมือนการลัดวงจร AC Short Circuit ลงกราวด์

### ข้อที่ 3 (เหตุใดสว่าน Backdrill จึงต้องมีขนาดใหญ่กว่ารูเจาะเดิมอย่างน้อย 0.20 mm?)
ในการกำหนดขนาดดอกสว่าน Backdrill ($D_{backdrill}$) เทียบกับขนาดรูเจาะเดิม ($D_{original}$) เหตุใดวิศวกรจึงต้องเลือกขนาดดอกสว่านให้ใหญ่กว่าเดิมอย่างน้อย $0.20 \text{ mm} \ (8 \text{ mil})$ เสมอ?

- **ก)** เพื่อให้อากาศถ่ายเทระบายความร้อนได้เร็วขึ้น
- **ข)** เพื่อรองรับความคลาดเคลื่อนเชิงตำแหน่งของการเจาะ (Drill Registration Tolerance) และรับประกันว่าเนื้อทองแดงของกระบอกรวมถึงวงแหวน Pad ชั้นในจะถูกคว้านตัดออกไปอย่างหมดจด 100% ไม่หลงเหลือเศษทองแดงค้างเป็นติ่งปรสิต
- **ค)** เพื่อให้สามารถมองเห็นรูกระบอกได้ด้วยตาเปล่า
- **ง)** เพื่อประหยัดพลังงานมอเตอร์ของเครื่องเจาะ CNC

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในกระบวนการ Backdrilling แผ่นบอร์ดจะต้องถูกนำขึ้นแท่นเจาะอีกครั้งหนึ่งหลังผ่านการชุบทองแดงแล้ว  
> ความคลาดเคลื่อนในการจัดตำแหน่งพิกัด (X-Y Misalignment Tolerance) ของเครื่องเจาะ CNC มีค่าประมาณ $\pm 0.05 \text{ mm}$ ถึง $\pm 0.075 \text{ mm}$  
> หากใช้ดอกสว่านขนาดเท่ากับรูเดิมหรือใหญ่กว่าเพียงเล็กน้อย:  
> ดอกสว่านที่เบี่ยงศูนย์จะเฉือนโดนทองแดงเพียงด้านเดียว ทิ้งกระบอกทองแดงอีกด้านหนึ่งไว้เป็นรูปเสี้ยวพระจันทร์ (Crescent-shaped Copper Flake) ซึ่งยังคงทำหน้าที่เป็น Via Stub ต่อไป!  
> การขยายขนาดดอกสว่านให้ใหญ่กว่าเดิม $+0.20 \text{ mm}$ (ขยายรัศมีออกไปข้างละ $0.10 \text{ mm}$) รับประกันได้ว่าแม้ดอกสว่านจะเบี่ยงศูนย์ไปเล็กน้อย มันก็จะคว้านเอาเนื้อทองแดงของกระบอกและวงแหวน Pad ออกได้อย่างหมดจด $100\%$
