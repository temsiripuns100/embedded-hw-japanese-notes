## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการออกแบบแผ่นวงจรพิมพ์สำหรับสภาพแวดล้อมสุดขั้ว (Extreme Environments) เช่น ห้องเครื่องยนต์ยานยนต์ (Automotive Under-the-Hood: $-40^\circ\text{C} \leftrightarrow +140^\circ\text{C}$), ระบบควบคุมการบินและอวกาศ (Aerospace), และระบบโซลาร์อินเวอร์เตอร์กำลังสูง ความเค้นเชิงความร้อนสะสม (Thermomechanical Fatigue) เป็นตัวการทำลายความสมบูรณ์ของจุดเชื่อมต่อผ่านรูเจาะทะลุ (Plated Through Hole - PTH)
วิศวกรระดับ Senior ต้องเข้าใจ **ฟิสิกส์การเปลี่ยนสถานะคล้ายแก้ว ($T_g$)**, **สมการคำนวณการยืดตัวรวมในแนวแกน Z ($\Delta L_z$)**, **เวลาการทนทานต่อการระเบิดแยกชั้น ($T_{260}, T_{288}$)**, และ **กลไกการแตกร้าวของผนังกระบอกทองแดง (PTH Barrel Cracking)**

---

### 1.1 การคำนวณการยืดตัวในแนวแกน Z และความเครียดบนผนังกระบอก Via ($\Delta L_z$)
พฤติกรรมการขยายตัวทางความร้อนของเนื้อเรซินอีพอกซีในแนวแกน Z จะเปลี่ยนไปอย่างฉับพลันเมื่ออุณหภูมิข้ามผ่านจุด **Glass Transition Temperature ($T_g$)**:
- **สภาวะของแข็งคล้ายแก้ว ($T < T_g$):** โมเลกุลถูกล็อกแน่นหนา ค่าสัมประสิทธิ์การขยายตัว $\alpha_{z1} \approx 40 - 55 \ \text{ppm}/^\circ\text{C}$
- **สภาวะเหนียวคล้ายยาง ($T > T_g$):** พันธะโมเลกุลคลายตัว ค่าสัมประสิทธิ์การขยายตัวพุ่งสูงขึ้นเป็น **$\alpha_{z2} \approx 250 - 350 \ \text{ppm}/^\circ\text{C}$!**

```
   Z-Axis Expansion
         ▲
         │                                       /  Slope = α_z2 (250-350 ppm/°C)
         │                                      /   (ขยายตัวรุนแรงมาก!)
         │                                     /
         │                                    ┌
         │                                   /
         │            Slope = α_z1          /
         │            (40-55 ppm/°C)       /
         │       ─────────────────────────┴─────────────────────► Temperature [°C]
                T_0 (25°C)                T_g (135°C vs 180°C)   T_reflow (260°C)
```

**สมการคำนวณการยืดตัวรวมในแนวแกน Z จากอุณหภูมิห้อง ($T_0$) ถึงอุณหภูมิยอดคลื่น Reflow ($T_{peak}$):**

$$\Delta L_z = H_0 \left[ \alpha_{z1} (T_g - T_0) + \alpha_{z2} (T_{peak} - T_g) \right]$$

- $H_0$: ความหนาตั้งต้นของแผ่นบอร์ด (เช่น $1.6 \text{ mm} = 1600 \ \mu\text{m}$)
- $T_0 = 25^\circ\text{C}$, $T_{peak} = 260^\circ\text{C}$ (เตาอบไร้สารตะกั่ว)

**การคำนวณเปรียบเทียบเชิงวิศวกรรม:**
1. **กรณี Standard FR-4 ($T_g = 135^\circ\text{C}, \alpha_{z1} = 55 \ \text{ppm}, \alpha_{z2} = 300 \ \text{ppm}$):**
   $$\Delta L_{z1} = 1600 \times [55 \times 10^{-6} \times (135 - 25)] = 9.68 \ \mu\text{m}$$
   $$\Delta L_{z2} = 1600 \times [300 \times 10^{-6} \times (260 - 135)] = 60.00 \ \mu\text{m}$$
   $$\Delta L_{z,total} = 9.68 + 60.00 = \mathbf{69.68 \ \mu\text{m}} \quad \left(\text{คิดเป็นความเครียด } \epsilon_z = \frac{69.68}{1600} \approx \mathbf{4.35\%}\right)$$

2. **กรณี High-$T_g$ Low-CTE Material ($T_g = 180^\circ\text{C}, \alpha_{z1} = 40 \ \text{ppm}, \alpha_{z2} = 220 \ \text{ppm}$):**
   $$\Delta L_{z1} = 1600 \times [40 \times 10^{-6} \times (180 - 25)] = 9.92 \ \mu\text{m}$$
   $$\Delta L_{z2} = 1600 \times [220 \times 10^{-6} \times (260 - 180)] = 28.16 \ \mu\text{m}$$
   $$\Delta L_{z,total} = 9.92 + 28.16 = \mathbf{38.08 \ \mu\text{m}} \quad \left(\text{คิดเป็นความเครียด } \epsilon_z = \frac{38.08}{1600} \approx \mathbf{2.38\%}\right)$$

*ข้อสรุปทางโลหะวิทยา:*  
ทองแดงชุบไฟฟ้า (Electroplated Copper) ทั่วไปมีขีดจำกัดการยืดตัวก่อนขาด (Elongation at Break) อยู่ที่เพียง **$3.0\% - 3.5\%$**  
- ในบอร์ด Standard FR-4 ความเครียด $4.35\%$ เกินขีดจำกัดของทองแดง ผนังกระบอก Via จะถูกกระชากจนเกิด **รอยร้าวรอบวง (Barrel Crack / Knee Crack)** ทันที!
- ในขณะที่วัสดุ High-$T_g$ ค่าความเครียดลดลงเหลือเพียง $2.38\%$ ซึ่งอยู่ในขอบเขตปลอดภัยที่ทองแดงสามารถคืนรูปได้

---

### 1.2 เวลาทนทานต่อการแยกชั้น (Time to Delamination: $T_{260}, T_{288}, T_{300}$)
การทดสอบตามมาตรฐาน IPC-TM-650 2.4.24.1 โดยใช้เครื่องวิเคราะห์ทางกลเชิงความร้อน (Thermomechanical Analyzer - TMA):
- ให้ความร้อนแก่ชิ้นทดสอบจนถึงอุณหภูมิคงที่ เช่น $288^\circ\text{C}$ และจับเวลาจนกว่าแผ่นฉนวนจะเกิดการระเบิดพองหรือแยกชั้นออกจากฟอยล์ทองแดง (Blistering / Delamination):
  - **Standard FR-4:** ทนได้เพียง **$1 - 2 \text{ นาที}$** ก่อนระเบิดพอง
  - **High-Reliability FR-4 (เช่น Isola 370HR / Shengyi S1000-2):** ทนได้นาน **$> 30 \text{ นาที}$ ที่ $288^\circ\text{C}$**
  - **Polyimide (สำหรับงานอากาศยาน):** ทนได้นาน **$> 60 \text{ นาที}$ ที่ $300^\circ\text{C}$**

---

### 1.3 การนำความร้อนของแผ่นบอร์ดทองแดงหนา (Heavy Copper Thermal Stackup)
สำหรับอุปกรณ์ Power Inverter ที่มีกระแสไหลต่อเนื่อง $50 - 150\text{A}$ การใช้ทองแดงหนาพิเศษ (Heavy Copper: 2 oz, 3 oz, หรือ 4 oz) จะช่วยเพิ่มการนำความร้อนในแนวราบ ($k_{x-y}$):

$$k_{eff, x-y} \approx k_{Cu} \times \left(\frac{\sum t_{Cu}}{H_{total}}\right) + k_{FR4} \times \left(\frac{\sum t_{diel}}{H_{total}}\right) \quad [\text{W/(m}\cdot\text{K)}]$$

- การเพิ่มทองแดงเป็น 3 oz ($105 \ \mu\text{m}$) บนระนาบ Power และ Ground ทั้งหมด จะช่วยเพิ่มค่า $k_{eff}$ ของแผ่นบอร์ดจากปกติ $0.8 \ \text{W/(m}\cdot\text{K)}$ พุ่งขึ้นเป็น **$> 25 - 35 \ \text{W/(m}\cdot\text{K)}$** ช่วยกระจายความร้อนจากจุดศูนย์รวม (Hot Spot) ออกสู่ขอบบอร์ดได้เร็วขึ้นถึง 30 เท่า!

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** กล่องควบคุมระบบปั๊มเชื้อเพลิงยานยนต์ (Automotive Fuel Pump Controller) ที่ติดตั้งอยู่ข้างเครื่องยนต์ ($T_A \approx 110^\circ\text{C}$) เกิดอาการเครื่องดับแบบติดๆ ดับๆ หลังจากรถวิ่งไปได้ประมาณ 45,000 กิโลเมตร
**สาเหตุที่ตรวจพบ (検図での指摘):**
ส่องกล้องตัดขวาง Microsection ของรูเจาะ Through-hole Via ใต้ชิปควบคุม พบ **รอยแตกร้าวรอบตัวถังกระบอกทองแดง (Circumferential Barrel Crack)** ที่บริเวณกึ่งกลางความหนาของบอร์ด:
1. แผ่นบอร์ดใช้วัสดุ FR-4 เกรดธรรมดาที่มีค่า $T_g = 135^\circ\text{C}$ ซึ่งเมื่อรถวิ่ง อุณหภูมิจะแกว่งข้ามผ่านจุด $T_g$ นับพันๆ รอบ ทำให้เรซินยืดและหดตัวกระชากกระบอก Via ตลอดเวลา
2. ความหนาของชั้นชุบทองแดงในผนังรู Via (Plating Thickness) มีค่าเฉลี่ยเพียง **$18 \ \mu\text{m}$** (สเปก IPC Class 3 ยานยนต์กำหนดให้ไม่น้อยกว่า $25 \ \mu\text{m}$) ความล้าเชิงกล (Thermal Fatigue) จึงฉีกผนังทองแดงขาดในที่สุด

---

### ขั้นตอนการสั่งผลิตบอร์ดสำหรับงานสภาวะสุดโหด (検図チェックリスト):
1. **การบังคับใช้ข้อกำหนด IPC Class 3 สำหรับความหนาชุบทองแดงในรู:**
   - ใน Master Drawing ต้องระบุชัดเจน:
     *"All plated through-holes (PTH) must meet IPC-6012 Class 3 requirements: Minimum copper plating thickness in the barrel shall be $\ge 25 \ \mu\text{m} \ (1.0 \text{ mil})$ at any point, with average thickness $\ge 28 \ \mu\text{m}$."*
2. **การคัดเลือกเกรดวัสดุสำหรับยานยนต์ (Automotive Grade Specification):**
   - **$T_g \ge 175^\circ\text{C}$** (วัดด้วยวิธี DSC หรือ TMA)
   - **$T_d \ge 340^\circ\text{C}$** (น้ำหนักสูญเสีย 5% ด้วยวิธี TGA)
   - **$T_{288} \ge 15 \text{ นาที}$** (ทนทานต่อการแยกชั้นที่ 288°C)
   - **$\alpha_z \le 40 \ \text{ppm}/^\circ\text{C}$** (ค่า CTE ในแนวแกน Z ต่ำกว่า $T_g$)
3. **การป้องกันมุมหักงอที่ขอบรู (Knee Crack Prevention):**
   - กำหนดให้โรงงานควบคุมกระบวนการขัดลบเหลี่ยมมุมที่ปากรู (Hole Chamfer / De-burring) เพื่อไม่ให้ขอบมุมทองแดงมีความเค้นกระจุกตัว ซึ่งเป็นจุดตั้งต้นของการเกิด Knee Cracking

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「車載エンジンルーム配置（動作温度範囲：-40℃～+125℃）のECU基板において、材料仕様に汎用FR-4材（Tg=140℃）が選定されています。長期間の冷熱サイクル負荷によるスルーホールバレルクラック（断線不具合）を防止するため、車載高信頼性材（Tg≧175℃、Td≧340℃、T288≧15分、αz≦40ppm/℃）であるIsola 370HRまたは同等材へ変更してください。」  
> *(ในบอร์ด ECU ที่ติดตั้งในห้องเครื่องยนต์ มีการระบุใช้วัสดุ FR-4 ทั่วไป เพื่อป้องกันการแตกร้าวของผนังกระบอก Through-hole จากความเค้นความร้อนระยะยาว กรุณาเปลี่ยนเป็นวัสดุมาตรฐานยานยนต์ที่มี Tg ไม่ต่ำกว่า 175°C, Td ไม่ต่ำกว่า 340°C และ CTE แกน Z ต่ำ)*

> **指摘事項 2:**  
> 「高信頼性要求製品（IPC Class 3）に対し、製造図面のスルーホール銅めっき厚指定が『平均20μm』となっており規格値（最薄部25μm以上、平均28μm以上）を満たしていません。リフロー熱応力および車載振動耐性を確保するため、図面注記を『IPC-6012 Class 3準拠、最薄部銅めっき厚25μm以上』へ厳格化してください。」  
> *(สำหรับผลิตภัณฑ์มาตรฐาน IPC Class 3 ในแบบสั่งผลิตระบุความหนาทองแดงชุบเฉลี่ยเพียง 20 ไมครอน ซึ่งต่ำกว่าเกณฑ์มาตรฐาน กรุณาแก้ไขข้อความในแบบให้เป็นไปตาม IPC-6012 Class 3 โดยมีความหนาทองแดงจุดที่บางที่สุดไม่น้อยกว่า 25 ไมครอน)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณความเครียดเชิงความร้อนบนกระบอกทองแดง)
แผ่นวงจรพิมพ์หนา $H = 2.0 \text{ mm}$ ผลิตด้วยวัสดุ Standard FR-4 ($T_g = 130^\circ\text{C}, \alpha_{z1} = 50 \ \text{ppm}/^\circ\text{C}, \alpha_{z2} = 280 \ \text{ppm}/^\circ\text{C}$) เมื่อเข้าสู่เตาอบบัดกรีไร้สารตะกั่วที่อุณหภูมิ $260^\circ\text{C}$ (จากอุณหภูมิห้อง $25^\circ\text{C}$) หากทองแดงชุบไฟฟ้ามีค่าการยืดตัวสูงสุดก่อนขาด (Elongation Limit) เท่ากับ $3.0\%$ ถามว่าแผ่นบอร์ดนี้จะเกิดความเครียดดึงยืด ($\epsilon_z$) กี่เปอร์เซ็นต์ และผนัง Via จะขาดหรือไม่?

- **ก)** $\epsilon_z = 1.85\%$, ปลอดภัยไม่ขาด
- **ข)** $\epsilon_z \approx 4.16\%$, ขาดแน่นอน เพราะความเครียดจากการยืดตัว ($4.16\%$) เกินขีดจำกัดการยืดตัวของทองแดง ($3.0\%$) ก่อให้เกิด Barrel Cracking
- **ค)** $\epsilon_z = 0.50\%$, ไม่มีความเครียดเกิดขึ้น
- **ง)** $\epsilon_z = 8.50\%$, แผ่นบอร์ดจะละลายกลายเป็นของเหลว

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> คำนวณการยืดตัวในช่วงต่ำกว่า $T_g$ ($25^\circ\text{C} \rightarrow 130^\circ\text{C}, \Delta T_1 = 105^\circ\text{C}$):  
> $$\Delta L_{z1} = 2000 \ \mu\text{m} \times (50 \times 10^{-6}) \times 105 = \mathbf{10.5 \ \mu\text{m}}$$  
> คำนวณการยืดตัวในช่วงสูงกว่า $T_g$ ($130^\circ\text{C} \rightarrow 260^\circ\text{C}, \Delta T_2 = 130^\circ\text{C}$):  
> $$\Delta L_{z2} = 2000 \ \mu\text{m} \times (280 \times 10^{-6}) \times 130 = \mathbf{72.8 \ \mu\text{m}}$$  
> การยืดตัวรวม: $\Delta L_z = 10.5 + 72.8 = \mathbf{83.3 \ \mu\text{m}}$  
> คิดเป็นความเครียดรวมในแนวแกน Z:  
> $$\epsilon_z = \frac{\Delta L_z}{H} \times 100\% = \frac{83.3 \ \mu\text{m}}{2000 \ \mu\text{m}} \times 100\% = \mathbf{4.165\%}$$  
> เนื่องจาก $\epsilon_z = 4.165\% > 3.0\%$ ผนังกระบอกทองแดงจะรับแรงดึงเกินจุดครากและขาดออกจากกันทันทีในระหว่างการบัดกรี จึงต้องเปลี่ยนไปใช้วัสดุ High-$T_g$ ทันที

---

### ข้อที่ 2 (ความหมายเชิงวิศวกรรมของพารามิเตอร์ $T_{288}$)
เหตุใดวิศวกรผู้เชี่ยวชาญด้านความน่าเชื่อถือจึงให้ความสำคัญกับค่า $T_{288}$ (Time to Delamination at 288°C) มากกว่าค่า $T_g$ เพียงอย่างเดียวในการเลือกวัสดุสำหรับบอร์ดหนาในงานยานยนต์?

- **ก)** เพราะค่า $T_{288}$ เป็นตัวกำหนดราคาของแผ่นบอร์ด
- **ข)** เพราะค่า $T_g$ บอกเพียงแค่อุณหภูมิที่เรซินเริ่มอ่อนตัว แต่ค่า $T_{288}$ เป็นการวัดความแข็งแรงของพันธะทางเคมีและการต้านทานการสลายตัวของเรซินภายใต้อุณหภูมิสูงจริง โดยวัดเวลาเป็นนาทีว่าโครงสร้างลามิเนตจะทนทานได้นานแค่ไหนก่อนจะเกิดฟองพองแยกชั้น (Delamination)
- **ค)** เพราะ $T_{288}$ มีค่าคงที่เสมอในทุกวัสดุ
- **ง)** เพราะ $T_{288}$ วัดค่าด้วยความดันบรรยากาศ

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> วัสดุบางชนิดอาจมีค่า $T_g$ สูง (เช่น $175^\circ\text{C}$) แต่พันธะเคมีของเรซินอีพอกซีอาจมีความต้านทานความร้อนต่ำ ทำให้เกิดการสลายตัวและปล่อยก๊าซออกมาได้ง่ายเมื่อเจอกับอุณหภูมิ $260^\circ\text{C}+$ ซ้ำหลายๆ รอบ  
> การทดสอบ **$T_{288}$** เป็นการทดสอบความทนทานในสภาวะการผลิตจริง โดยแช่ชิ้นงานไว้ที่ $288^\circ\text{C}$ และตรวจวัดเวลา วัสดุเกรดพรีเมียมจะทนได้นานกว่า $30$ นาทีโดยไม่มีการแยกชั้น ซึ่งรับประกันว่าบอร์ดจะสามารถผ่านเตาอบ Reflow และกระบวนการ Rework ได้อย่างปลอดภัย 100%

### ข้อที่ 3 (ข้อกำหนดความหนาชุบทองแดงตามมาตรฐาน IPC-6012 Class 3)
ตามมาตรฐานสากล IPC-6012 Class 3 สำหรับอุปกรณ์ที่มีความน่าเชื่อถือสูงสุด (High Reliability / Automotive / Medical) ความหนาของการชุบทองแดงในผนังรูเจาะทะลุ (Through-Hole Copper Plating Thickness) ต้องมีค่าไม่น้อยกว่าเท่าใด?

- **ก)** จุดที่บางที่สุดไม่น้อยกว่า $10 \ \mu\text{m}$ และค่าเฉลี่ยไม่น้อยกว่า $15 \ \mu\text{m}$
- **ข)** จุดที่บางที่สุดต้องไม่น้อยกว่า $25 \ \mu\text{m} \ (1.0 \text{ mil})$ และค่าเฉลี่ยต้องไม่น้อยกว่า $28 \ \mu\text{m}$
- **ค)** ต้องมีความหนาเท่ากับ 2.0 mm
- **ง)** จุดใดก็ได้ขอเพียงแค่วัดความต้านทานผ่าน

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> มาตรฐาน IPC-6012 แบ่งระดับคุณภาพออกเป็น Class 1 (ทั่วไป), Class 2 (อุปกรณ์สำนักงาน/อุตสาหกรรมทั่วไป: ต่ำสุด $18 \ \mu\text{m}$ เฉลี่ย $20 \ \mu\text{m}$), และ **Class 3 (ยานยนต์, การแพทย์, อวกาศ)**  
> สำหรับ Class 3 ข้อกำหนดบังคับคือ: **ความหนาทองแดงจุดที่บางที่สุดในกระบอกรูต้อง $\ge 25 \ \mu\text{m}$ และค่าเฉลี่ยต้อง $\ge 28 \ \mu\text{m}$** ความหนาระดับนี้จะช่วยสร้างโครงสร้างกระบอกโลหะที่แข็งแรงพอที่จะต้านทานแรงดึงในแนวแกน Z ของเนื้อเรซินได้ตลอดอายุการใช้งาน 15 ปีของรถยนต์
