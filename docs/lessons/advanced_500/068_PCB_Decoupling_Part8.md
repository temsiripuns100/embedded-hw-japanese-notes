## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

เมื่อความถี่ของสัญญาณสลับและฮาร์โมนิกของสัญญาณนาฬิกาพุ่งสูงเกินกว่า **$100\text{ MHz} - 200\text{ MHz}$** ตัวเก็บประจุแบบแยกชิ้น (Discrete MLCCs) จะเริ่มสูญเสียประสิทธิภาพในการจ่ายกระแสอย่างรวดเร็ว เนื่องจากความเหนี่ยวนำของการติดตั้ง (Mounting Inductance: $ESL + L_{via}$) จะกั้นขวางการจ่ายกระแส ณ จุดนี้ แหล่งพลังงานเพียงหนึ่งเดียวบนแผ่นวงจรพิมพ์ที่สามารถส่งมอบประจุไฟฟ้าได้ทันเวลาในระดับ Sub-nanosecond คือ **ความจุไฟฟ้าระหว่างระนาบ (Inter-plane Capacitance หรือ Plane Capacitance)**

```
+-------------------------------------------------------------------------+
|                  Plane Capacitance & Cavity Waveguide                   |
|                                                                         |
|  [ Power Copper Plane (Solid 1 oz)                                    ] |
|  [ Ultra-Thin Dielectric Layer (d = 12 - 50 µm, ε_r = 4.2 - 20)       ] |
|  [ Ground Copper Plane (Solid 1 oz)                                   ] |
|                                                                         |
|  Key Physical Property: Zero Package ESL! Pure Distributed Charge!     |
|  Boundary Condition: Open Circuit at PCB Edges ---> Cavity Resonator!   |
+-------------------------------------------------------------------------+
```

### 1.1 ฟิสิกส์ของความจุไฟฟ้าระหว่างระนาบและวัสดุความจุฝังตัว (Embedded Capacitance Material: ECM)

ระนาบคู่ขนานระหว่าง Power และ Ground ทำหน้าที่เป็นตัวเก็บประจุแบบแผ่นขนานในอุดมคติ (Ideal Parallel-Plate Capacitor):

$$C_{plane} = \frac{\varepsilon_0 \cdot \varepsilon_r \cdot A}{d} \quad [\text{F}]$$

โดยที่:
- $\varepsilon_0 = 8.854 \times 10^{-12}\text{ F/m}$ (Permittivity of Free Space)
- $\varepsilon_r$ คือ ค่าคงที่ไดอิเล็กทริกสัมพัทธ์ของฉนวนคั่นกลาง (Relative Permittivity / Dk)
- $A$ คือ พื้นที่ทับซ้อนของระนาบทั้งสอง ($\text{m}^2$)
- $d$ คือ ความหนาของชั้นฉนวนคั่นกลาง (**Dielectric Thickness**, $\text{m}$)

#### การเปรียบเทียบระหว่าง Standard FR-4 กับ Ultra-Thin ECM
ในอุตสาหกรรมแผ่นวงจรพิมพ์มาตรฐาน ชั้น Prepreg ทั่วไปมีความหนา $d \approx 75\ \mu\text{m} - 125\ \mu\text{m}$ ($3 - 5\text{ mils}$) มี $\varepsilon_r \approx 4.2$ ซึ่งให้ค่าความจุระหว่างระนาบเพียง **$30 - 50\text{ pF/cm}^2$** (หรือประมาณ $0.2 - 0.3\text{ nF/in}^2$) ซึ่งไม่เพียงพอต่อการจ่ายพลังงานให้กับโปรเซสเซอร์กำลังสูง

เพื่อก้าวข้ามขีดจำกัดนี้ อุตสาหกรรมอากาศยาน เซิร์ฟเวอร์ และอุปกรณ์สื่อสารความเร็วสูงจึงใช้วัสดุพิเศษที่เรียกว่า **Buried Capacitance Material (BCM)** หรือ **Embedded Capacitance Material (ECM)** เช่น Oak-Mitsui FaradFlex หรือ 3M Embedded Capacitance Material (C-Ply):
- ลดความหนาฉนวนลงเหลือเพียง **$d = 12\ \mu\text{m}, 8\ \mu\text{m},$ หรือ $6\ \mu\text{m}$**
- ผสมอนุภาคเซรามิกความจุสูง (เช่น Barium Titanate: $\text{BaTiO}_3$) ในเนื้อเรซิน ทำให้ค่า $\varepsilon_r$ พุ่งสูงขึ้นเป็น **$12 - 25$**
- ให้ค่าความจุไฟฟ้าสูงถึง **$1.5 - 5.0\text{ nF/cm}^2$** (เพิ่มขึ้นกว่า FR-4 เดิมถึง **$50 - 100$ เท่า!**)

| ชนิดวัสดุคั่นกลางระนาบ | ความหนา ($d$) | ค่าคงที่ไดอิเล็กทริก ($\varepsilon_r$) | ความจุต่อหน่วยพื้นที่ ($C/A$) | อิมพีแดนซ์ระนาบที่ 500 MHz |
| :--- | :--- | :--- | :--- | :--- |
| **Standard FR-4 Core** | 100 µm (4 mils) | 4.2 | 37 pF/cm² | ปานกลาง-สูง |
| **Thin FR-4 Prepreg** | 50 µm (2 mils) | 4.0 | 71 pF/cm² | ปานกลาง |
| **FaradFlex MC24M** | 24 µm (0.95 mil) | 4.5 | 166 pF/cm² | ต่ำ |
| **FaradFlex BC12TM** | 12 µm (0.47 mil) | 5.5 | 406 pF/cm² | ต่ำมาก |
| **3M ECM (Barium Titanate)**| 14 µm (0.55 mil) | 16.0 | 1,012 pF/cm² (1.0 nF/cm²) | ต่ำที่สุด |

### 1.2 ทฤษฎีเรโซแนนซ์ของโพรงคลื่นระนาบ (Plane Cavity Resonance Modes)

แม้ว่าคู่ระนาบ Power/Ground จะทำหน้าที่เป็นตัวเก็บประจุที่ความถี่ต่ำ แต่ที่ความถี่สูงระดับหลายร้อยเมกะเฮิรตซ์ขึ้นไป ระนาบที่มีขอบเขตสิ้นสุดทางกายภาพ (ขนาดกว้าง $a$ ยาว $b$) จะกลายสภาพเป็น **โพรงคลื่นแม่เหล็กไฟฟ้า 2 มิติ (2D Electromagnetic Cavity Resonator)** ที่มีขอบเป็นวงจรเปิด (Open-Circuit Magnetic Wall Boundary Conditions)

คลื่นแม่เหล็กไฟฟ้าที่เดินทางสะท้อนไปมาระหว่างขอบบอร์ดทั้งสี่ด้าน จะแทรกสอดกันเกิดเป็นคลื่นนิ่ง (Standing Wave Resonance) ตามสมการความถี่เรโซแนนซ์ของโพรงคลื่น:

$$f_{m, n} = \frac{c_0}{2\sqrt{\varepsilon_r}} \sqrt{\left( \frac{m}{a} \right)^2 + \left( \frac{n}{b} \right)^2} \quad [\text{Hz}]$$

โดยที่:
- $c_0 = 3 \times 10^8\text{ m/s}$ (ความเร็วแสงในสุญญากาศ)
- $\varepsilon_r$ คือ ค่าคงที่ไดอิเล็กทริกของฉนวนคั่นระนาบ
- $a, b$ คือ ขนาดความกว้างและความยาวของแผ่นระนาบ ($\text{m}$)
- $m, n$ คือ เลขโหมดเรโซแนนซ์จำนวนเต็ม ($m, n = 0, 1, 2, 3, \dots$ โดยที่ $m$ และ $n$ ห้ามเป็นศูนย์พร้อมกัน)

```
Standing Wave Voltage Distribution in Cavity Mode (m=1, n=0):
Voltage (V)
   ▲
+V ├───.                                         .─── High E-field at edge!
   │    \                                       /     (Radiates EMI!)
 0 ┼─────\─────────────────┼───────────────────/───── Node at center (V=0)
   │      ' .                               . '
-V ├─── ─ ─ ─ ' ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ' ─ ─ ─ ─ ─ High E-field at edge!
   └──────┴────────────────┴───────────────────┴────► x-axis position
         x=0             x=a/2                x=a
```

ณ ความถี่เรโซแนนซ์ของโพรงคลื่น ($f_{m,n}$):
1. **อิมพีแดนซ์ของรางจ่ายไฟจะพุ่งสูงขึ้นอย่างมหาศาลเฉพาะจุด:** จุดที่เป็นยอดคลื่น (Anti-nodes) จะมีอิมพีแดนซ์สูงขึ้นนับสิบเท่า ทำให้ชิปที่วางอยู่ตรงตำแหน่งนั้นเกิดแรงดันตกคร่อมรุนแรง
2. **ขอบบอร์ดกลายเป็นสายอากาศแพร่คลื่นแม่เหล็กไฟฟ้า (Edge Radiation Antennas):** สนามไฟฟ้าที่ขอบบอร์ดจะมีขนาดสูงสุด ($E_{edge} = \text{max}$) รั่วไหลออกสู่อากาศและเหนี่ยวนำเข้าสู่สายเคเบิลภายนอก ส่งผลให้ตกการทดสอบการแผ่คลื่นแม่เหล็กไฟฟ้า **CISPR 32 / FCC Class B Radiated Emissions** ทันที

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน: 失敗事例 (Shippai Jirei)

**เหตุการณ์:** บอร์ดควบคุมการส่งสัญญาณวิดีโอ 4K ทางการแพทย์ (Medical Imaging Video Processing Unit) ใช้บอร์ด 10-Layer ขนาด $200\text{ mm} \times 150\text{ mm}$ มีชิปประมวลผล FPGA วิ่งที่สัญญาณนาฬิกา $150\text{ MHz}$ 

**อาการล้มเหลว:**
1. ในขั้นตอนการทดสอบความเข้ากันได้ทางแม่เหล็กไฟฟ้า (EMC Chamber Test) บอร์ดตกการทดสอบ Radiated Emissions อย่างรุนแรงที่ความถี่ **$435\text{ MHz}$ และ $870\text{ MHz}$** โดยมีสัญญาณรบกวนเกินขีดจำกัดมาตรฐาน CISPR 32 Class B สูงถึง **$+16\text{ dB}\mu\text{V/m}$**
2. ทีมวิศวกรพยายามแก้ปัญหาด้วยการเพิ่มตัวเก็บประจุ 0402 Decoupling รอบตัวถัง FPGA อีก 40 ตัว และเปลี่ยนสายสัญญาณเป็นแบบมีชีลด์สองชั้น แต่ระดับสัญญาณรบกวนที่ $435\text{ MHz}$ ไม่ลดลงเลยแม้แต่เดซิเบลเดียว
3. เมื่อส่องโพรบสนามแม่เหล็กไฟฟ้าแบบ Near-Field Probe รอบขอบบอร์ด พบว่าสัญญาณรบกวนความถี่ $435\text{ MHz}$ ไม่ได้แผ่ออกมาจากตัวชิป FPGA แต่ **แผ่ออกมาจากขอบแผ่น PCB (Board Perimeter Edges) ทั้ง 4 ด้านอย่างสม่ำเสมอ!**

```
[Defect Mechanism: Power Plane Cavity Edge Radiation]
               Top / Signal Layers
    ═══════════════════════════════════════════════
    [ Layer 4: Power Plane (200mm x 150mm)        ] ──► LEAKAGE RF
    [ Dielectric d = 100 µm, ε_r = 4.3            ] ──► RADIATION!
    [ Layer 5: Ground Plane                       ] ──► (435 MHz Spikes!)
    ═══════════════════════════════════════════════
               Bottom Layers
    Edge of PCB behaves as an open-slot patch antenna!
```

**Root Cause Analysis (RCA):**
1. **การเกิด Cavity Resonance Mode (1, 1) ของระนาบ Power/GND:**
   - ขนาดของระนาบคือ $a = 0.20\text{ m}, b = 0.15\text{ m}$, ไดอิเล็กทริก FR-4 มี $\varepsilon_r = 4.3$
   - คำนวณความถี่โหมดเรโซแนนซ์ $(1, 1)$:
     $$f_{1, 1} = \frac{3 \times 10^8\text{ m/s}}{2\sqrt{4.3}} \sqrt{\left(\frac{1}{0.20}\right)^2 + \left(\frac{1}{0.15}\right)^2} \approx (72.34 \times 10^6) \times \sqrt{25 + 44.44} \approx 435.5\text{ MHz}!$$
   - ความถี่เรโซแนนซ์ของระนาบคือ **$435.5\text{ MHz}$** ซึ่งไปตรงกับ **ฮาร์โมนิกที่ 3 ของสัญญาณนาฬิกา $150\text{ MHz}$ ($3 \times 145\text{ MHz} \approx 435\text{ MHz}$)** พอดีเป๊ะ!
2. **การขยายสัญญาณรบกวนด้วยค่า $Q$ ของโพรงคลื่น:** ฮาร์โมนิกของสัญญาณนาฬิกาฉีดกระแสกระตุ้นโพรงคลื่น ทำให้เกิดการสั่นพริ้วขยายขนาดความแรงของสนามไฟฟ้าขึ้นกว่าปกติถึง $25\text{ dB}$ และแผ่รังสีออกจากขอบบอร์ดที่ทำหน้าที่เป็น Slot Antenna
3. **Discrete MLCC ไม่สามารถกำจัด Cavity Resonance ได้:** ตัวเก็บประจุแบบแยกชิ้นมีค่าความเหนี่ยวนำของ Via มากเกินไปที่จะทำงานที่ความถี่ $435\text{ MHz}$ จึงไม่สามารถดูดซับคลื่นนิ่งในโพรงระนาบได้

### Step-by-Step Engineering Checklist: กลยุทธ์การออกแบบ Plane Capacitance และการสกัดกั้น Cavity Modes

#### ขั้นตอนที่ 1: การลดความหนาของชั้นฉนวนระนาบคู่ (Dielectric Thinning)
- **ปรับลดความหนาฉนวนลงเหลือน้อยกว่า $50\ \mu\text{m}$ ($2\text{ mils}$):** การลดระยะห่างระหว่าง Power และ Ground จะช่วย:
  1. เพิ่มค่า Plane Capacitance แบบผกผัน ($C \propto 1/d$)
  2. ลดความเหนี่ยวนำการกระจายตัวของระนาบ ($L_{spread} \propto d$)
  3. ลดพื้นที่หน้าตัดช่องเปิดที่ขอบบอร์ด ($A_{edge} = \text{Perimeter} \times d$) ส่งผลให้อัตราการแผ่รังสีแม่เหล็กไฟฟ้า (Radiated Power) ลดลงตามสัดส่วน $d^2$
- **พิจารณาใช้ Embedded Capacitance Material (ECM):** สำหรับบอร์ดที่มีสัญญาณ SerDes $> 25\text{ Gbps}$ หรือชิปประมวลผล $> 100\text{ W}$ ให้ระบุการใช้วัสดุ FaradFlex หนา $12\ \mu\text{m}$ หรือ 3M ECM หนา $14\ \mu\text{m}$ ในแบบสั่งผลิต Stackup ทันที

```
+-------------------------------------------------------------+
|  Layer Stackup with Embedded Capacitance Material (ECM):     |
|                                                             |
|  Layer 3: Ground Plane (Solid 1 oz)                         |
|  ---------------------------------------------------------  |
|  [ Ultra-Thin ECM Dielectric: 12 µm FaradFlex, Dk = 5.5 ]   |
|  ---------------------------------------------------------  |
|  Layer 4: Power Plane (Solid 1 oz)                          |
|                                                             |
|  Result: Inter-plane C increases by 800%! Zero package ESL! |
+-------------------------------------------------------------+
```

#### ขั้นตอนที่ 2: การทำแนวกั้นกราวด์รอบขอบบอร์ด (Perimeter Ground Stitching Vias)
เพื่อทำลายคลื่นนิ่งและปิดกั้นไม่ให้สนามแม่เหล็กไฟฟ้ารั่วไหลออกจากขอบบอร์ด:
- **สร้าง Via Shielding Fence:** เจาะรูเจาะกราวด์ (GND Stitching Vias) เรียงเป็นแถวตลอดแนวขอบบอร์ดทั้ง 4 ด้าน เพื่อเชื่อมต่อระนาบกราวด์ทุกชั้นเข้าด้วยกัน
- **กฎระยะห่างระหว่าง Via ($\lambda / 20$ Rule):**
  $$s_{via} \le \frac{\lambda_{min}}{20} = \frac{c_0}{20 \cdot f_{max} \cdot \sqrt{\varepsilon_r}}$$
  - สำหรับการป้องกันสัญญาณรบกวนที่ความถี่สูงสุด $3\text{ GHz}$ บน FR-4 ($\varepsilon_r \approx 4.0$):
    $$s_{via} \le \frac{3 \times 10^8\text{ m/s}}{20 \times (3 \times 10^9\text{ Hz}) \times 2.0} = \frac{3 \times 10^8}{1.2 \times 10^{11}} = 0.0025\text{ m} = 2.5\text{ mm} \ (100\text{ mils})$$
  - ดังนั้น ระยะห่างระหว่างรูเจาะกราวด์รอบขอบบอร์ดต้อง **ไม่เกิน $2.0 - 2.5\text{ mm}$**

```
+-------------------------------------------------------------+
|  Perimeter GND Stitching Via Shielding:                     |
|                                                             |
|   (GND)─── s <= 2.0mm ───(GND)─── s <= 2.0mm ───(GND)       |
|     │                      │                      │         |
|   ══╪══════════════════════╪══════════════════════╪══════   |
|     │   Power Plane Edge (Pulled back by 1.0mm)   │         |
|   ──┴──────────────────────┴──────────────────────┴──────   |
|   Acts as a Faraday cage wall, blocking edge radiation!     |
+-------------------------------------------------------------+
```

#### ขั้นตอนที่ 3: กฎการดึงขอบระนาบไฟร่นเข้ามา (20-H Rule / Power Plane Pullback)
- **Power Plane Setback:** ร่นขอบของระนาบ Power Plane ให้ถอยร่นลึกเข้ามาจากขอบของระนาบ Ground Plane โดยรอบอย่างน้อย **$1.0\text{ mm} - 1.5\text{ mm}$ (หรือ $20 \times d$)**
- เส้นแรงสนามไฟฟ้า (Fringing Electric Fields) จากขอบระนาบไฟจะโค้งงอตกกระทบลงสู่ระนาบกราวด์ที่ยื่นออกไปแทนที่จะแผ่กระจายออกสู่อากาศ ช่วยลดการแผ่รังสีสนามแม่เหล็กไฟฟ้าลงได้อีก $10 - 15\text{ dB}$

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### คำถามที่ 1: การคำนวณเปรียบเทียบ Plane Capacitance ระหว่าง Standard FR-4 กับ Ultra-Thin ECM

บอร์ดควบคุมระบบโทรคมนาคมมีระนาบไฟหลัก $V_{DD} = 1.0\text{ V}$ ขนาดพื้นที่สี่เหลี่ยมผืนผ้าทับซ้อนกับระนาบกราวด์ $A = 180\text{ cm}^2 = 0.018\text{ m}^2$ 

วิศวกรเปรียบเทียบการเลือกวัสดุคั่นกลางระนาบ 2 ชนิด:
- **ชนิด A (Standard Thin FR-4):** ความหนา $d_A = 60\ \mu\text{m} = 6.0 \times 10^{-5}\text{ m}$, มีค่าคงที่ไดอิเล็กทริก $\varepsilon_{r, A} = 4.2$
- **ชนิด B (Buried Capacitance Material - FaradFlex):** ความหนาบางพิเศษ $d_B = 12\ \mu\text{m} = 1.2 \times 10^{-5}\text{ m}$, มีค่าคงที่ไดอิเล็กทริก $\varepsilon_{r, B} = 5.5$

กำหนดให้ค่าคงที่ไดอิเล็กทริกในสุญญากาศ $\varepsilon_0 = 8.854 \times 10^{-12}\text{ F/m}$

จงคำนวณ:
1. ค่าความจุไฟฟ้าต่อหนึ่งตารางเซนติเมตร ($C/A$) ของชนิด A และชนิด B ในหน่วย $\text{pF/cm}^2$
2. ค่าความจุไฟฟ้ารวม ($C_{total}$) ของระนาบทั้งแผ่นสำหรับชนิด A และชนิด B
3. ที่ความถี่ $300\text{ MHz}$ จงคำนวณขนาดอิมพีแดนซ์ของความจุระนาบ ($|Z_{plane}| = \frac{1}{2\pi f C}$) ของทั้งสองชนิด เปรียบเทียบกับค่า Target Impedance $Z_{target} = 5.0\text{ m}\Omega$?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความจุไฟฟ้าต่อหนึ่งตารางเซนติเมตร ($C/A$):**
- **ชนิด A (Standard FR-4, $d = 60\ \mu\text{m}$):**
  $$\frac{C_A}{A} = \frac{\varepsilon_0 \cdot \varepsilon_{r, A}}{d_A} = \frac{(8.854 \times 10^{-12}\text{ F/m}) \times 4.2}{60 \times 10^{-6}\text{ m}} = \frac{3.7187 \times 10^{-11}}{6.0 \times 10^{-5}} \approx 6.198 \times 10^{-7}\text{ F/m}^2$$
  แปลงเป็น $\text{pF/cm}^2$ ($1\text{ m}^2 = 10,000\text{ cm}^2$):
  $$\frac{C_A}{A} = \frac{6.198 \times 10^{-7}\text{ F}}{10^4\text{ cm}^2} = 6.198 \times 10^{-11}\text{ F/cm}^2 \approx 61.98\text{ pF/cm}^2$$

- **ชนิด B (FaradFlex, $d = 12\ \mu\text{m}$):**
  $$\frac{C_B}{A} = \frac{\varepsilon_0 \cdot \varepsilon_{r, B}}{d_B} = \frac{(8.854 \times 10^{-12}\text{ F/m}) \times 5.5}{12 \times 10^{-6}\text{ m}} = \frac{4.8697 \times 10^{-11}}{1.2 \times 10^{-5}} \approx 4.058 \times 10^{-6}\text{ F/m}^2$$
  $$\frac{C_B}{A} = \frac{4.058 \times 10^{-6}\text{ F}}{10^4\text{ cm}^2} \approx 4.058 \times 10^{-10}\text{ F/cm}^2 \approx 405.8\text{ pF/cm}^2$$
  *(ความจุต่อหน่วยพื้นที่สูงขึ้นกว่าชนิด A ถึง **$6.55$ เท่า!**)*

**2. คำนวณความจุรวมของแผ่นบอร์ด ($A = 180\text{ cm}^2$):**
- **ชนิด A:**
  $$C_{total, A} = 180\text{ cm}^2 \times 61.98\text{ pF/cm}^2 \approx 11,156\text{ pF} \approx 11.16\text{ nF}$$
- **ชนิด B:**
  $$C_{total, B} = 180\text{ cm}^2 \times 405.8\text{ pF/cm}^2 \approx 73,044\text{ pF} \approx 73.04\text{ nF}$$

**3. คำนวณอิมพีแดนซ์ที่ความถี่ $300\text{ MHz}$ ($f = 300 \times 10^6\text{ Hz}$):**
เนื่องจาก Plane Capacitance เป็นความจุที่กระจายตัวสม่ำเสมอและไม่มีขั้วต่อแพ็กเกจ ค่า ESL ของระนาบจึงเข้าใกล้ศูนย์ ($ESL \approx 0$):
- **ชนิด A ($C = 11.16\text{ nF}$):**
  $$|Z_{plane, A}| = \frac{1}{2\pi \times (300 \times 10^6\text{ Hz}) \times (11.16 \times 10^{-9}\text{ F})} = \frac{1}{2\pi \times 3.348} \approx 0.0475\ \Omega = 47.5\text{ m}\Omega$$
  *(สูงกว่า $Z_{target} = 5.0\text{ m}\Omega$ ถึงเกือบ 10 เท่า ไม่สามารถกดอิมพีแดนซ์ได้)*
- **ชนิด B ($C = 73.04\text{ nF}$):**
  $$|Z_{plane, B}| = \frac{1}{2\pi \times (300 \times 10^6\text{ Hz}) \times (73.04 \times 10^{-9}\text{ F})} = \frac{1}{2\pi \times 21.912} \approx 0.00726\ \Omega = 7.26\text{ m}\Omega$$

**บทวิเคราะห์ของ Senior Engineer:**
- ชนิด B ให้ค่าอิมพีแดนซ์ต่ำเพียง **$7.26\text{ m}\Omega$** ซึ่งเมื่อทำงานร่วมกับตัวเก็บประจุ 0201 เพียงไม่กี่ตัว อิมพีแดนซ์รวมจะลดต่ำกว่า $5.0\text{ m}\Omega$ ได้อย่างง่ายดาย
- การใช้วัสดุ ECM ช่วยแก้ปัญหาที่ความถี่สูงเกิน $100\text{ MHz}$ ได้อย่างสมบูรณ์แบบ ซึ่งตัวเก็บประจุแบบ Discrete ไม่สามารถทำได้

### คำถามที่ 2: การคำนวณโหมดเรโซแนนซ์ของโพรงระนาบ (Cavity Modes) และการวิเคราะห์ตำแหน่ง Hotspot

แผ่นบอร์ดคอมพิวเตอร์อุตสาหกรรมมีขนาดระนาบ Power/GND สี่เหลี่ยมผืนผ้า กว้าง $a = 240\text{ mm} = 0.24\text{ m}$ ยาว $b = 180\text{ mm} = 0.18\text{ m}$ ฉนวนคั่นกลางมีค่าคงที่ไดอิเล็กทริก $\varepsilon_r = 4.0$ ($\sqrt{\varepsilon_r} = 2.0$)

จงคำนวณ:
1. ความถี่เรโซแนนซ์ธรรมชาติของ 3 โหมดแรก: โหมด $(1, 0)$, โหมด $(0, 1)$, และโหมด $(1, 1)$
2. หากบอร์ดมีไมโครโปรเซสเซอร์ส่งข้อมูลด้วยสัญญาณนาฬิกา $312.5\text{ MHz}$ จงตรวจสอบว่าความถี่สัญญาณนาฬิกานี้ตรงกับโหมดใดในโพรงระนาบหรือไม่
3. อธิบายการกระจายตัวของแรงดันไฟฟ้า (Voltage Spatial Distribution) ในโหมด $(1, 0)$ และระบุว่าจุดใดบนบอร์ดที่มีความผันผวนของแรงดันสูงสุด และจุดใดที่เงียบสงบที่สุด?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความถี่โหมดเรโซแนนซ์ ($f_{m, n} = \frac{c_0}{2\sqrt{\varepsilon_r}} \sqrt{(m/a)^2 + (n/b)^2}$):**
- สัมประสิทธิ์ความเร็วคลื่น:
  $$\frac{c_0}{2\sqrt{\varepsilon_r}} = \frac{3 \times 10^8\text{ m/s}}{2 \times 2.0} = 75 \times 10^6\text{ m/s} = 75\text{ MHz}\cdot\text{m}$$

- **โหมด $(1, 0)$ (เรโซแนนซ์ตามแนวความกว้าง $a = 0.24\text{ m}$):**
  $$f_{1, 0} = 75 \times 10^6 \times \sqrt{\left(\frac{1}{0.24}\right)^2 + 0} = \frac{75 \times 10^6}{0.24} = 312.50\text{ MHz}!$$
- **โหมด $(0, 1)$ (เรโซแนนซ์ตามแนวความยาว $b = 0.18\text{ m}$):**
  $$f_{0, 1} = 75 \times 10^6 \times \sqrt{0 + \left(\frac{1}{0.18}\right)^2} = \frac{75 \times 10^6}{0.18} \approx 416.67\text{ MHz}$$
- **โหมด $(1, 1)$ (เรโซแนนซ์แนวทแยงมุม):**
  $$f_{1, 1} = 75 \times 10^6 \times \sqrt{\left(\frac{1}{0.24}\right)^2 + \left(\frac{1}{0.18}\right)^2} = 75 \times 10^6 \times \sqrt{17.361 + 30.864} = 75 \times 10^6 \times \sqrt{48.225}$$
  $$f_{1, 1} \approx 75 \times 10^6 \times 6.9444 \approx 520.83\text{ MHz}$$

**2. การวิเคราะห์ความเสี่ยงของสัญญาณนาฬิกา $312.5\text{ MHz}$:**
- สัญญาณนาฬิกา $312.5\text{ MHz}$ **ตรงกับความถี่โหมด $(1, 0)$ ของระนาบแบบ $100\%$ พอดีเป๊ะ! ($f_{clock} = f_{1,0} = 312.50\text{ MHz}$)**
- สิ่งนี้จะก่อให้เกิด **Severe Cavity Resonance Amplification**: พลังงานสวิตชิ่งจากชิปจะปั๊มคลื่นนิ่งเข้าสู่ระนาบอย่างต่อเนื่อง ทำให้เกิดคลื่นสั่นพริ้วขนาดยักษ์บนระนาบไฟ และแผ่รังสีสนามแม่เหล็กไฟฟ้าออกจากขอบบอร์ดซ้าย-ขวาอย่างรุนแรง

**3. การกระจายตัวของแรงดันไฟฟ้าในโหมด $(1, 0)$:**
- การกระจายตัวของแรงดันไฟฟ้าในแนวแกน $x$ (ขนานกับด้าน $a$):
  $$V(x) = V_0 \cdot \cos\left( \frac{\pi x}{a} \right)$$
- **จุดที่แรงดันผันผวนสูงสุด (Anti-nodes / Maximum Voltage Noise):**
  อยู่ที่ขอบบอร์ดทั้งสองฝั่ง คือที่ $x = 0$ ($V = +V_0$) และที่ $x = a = 240\text{ mm}$ ($V = -V_0$) บริเวณขอบบอร์ดนี้จะมีสนามไฟฟ้าเข้มข้นสูงสุดและแผ่รังสี EMI สูงสุด
- **จุดที่เงียบสงบที่สุด (Node / Zero Voltage Noise):**
  อยู่ที่กึ่งกลางบอร์ดพอดี คือที่ $x = \frac{a}{2} = 120\text{ mm}$ ($\cos(\pi/2) = 0 \implies V = 0\text{ V}$)
- **ข้อคิดสำหรับ Senior Engineer:** หากไม่สามารถเปลี่ยนขนาดบอร์ดได้ ให้ย้ายชิปประมวลผลที่อ่อนไหวมาวางไว้ตรงแนวเส้นกึ่งกลาง $x = 120\text{ mm}$ ซึ่งเป็นจุด Node ของคลื่นนิ่ง จะช่วยลดผลกระทบจากสัญญาณรบกวนเรโซแนนซ์นี้ได้มากที่สุด

### คำถามที่ 3: การคำนวณระยะพิทช์ของแนวกั้นกราวด์ (Stitching Via Fence) เพื่อปิดกั้นการแผ่รังสี EMI สูงถึง 5 GHz

ในระบบคอมพิวเตอร์ระดับยานยนต์ มีสัญญาณรบกวนความถี่สูงที่ต้องการปิดกั้นไม่ให้รั่วไหลออกจากขอบบอร์ด โดยมีเป้าหมายความถี่สูงสุดที่ต้องป้องกันคือ $f_{max} = 5.0\text{ GHz}$ แผ่นบอร์ดใช้ฉนวนลามิเนตเกรดยานยนต์ที่มีค่า $\varepsilon_r = 3.6$

ตามหลักการทางวิศวกรรมแม่เหล็กไฟฟ้า แนวกั้นรูเจาะกราวด์ (Via Fence) จะทำหน้าที่เสมือนผนังโลหะทึบได้ ก็ต่อเมื่อระยะห่างระหว่างรูเจาะกึ่งกลางถึงกึ่งกลาง ($s$) สอดคล้องกับกฎ $\lambda / 20$:

$$s \le \frac{\lambda_{diel}}{20}$$

จงคำนวณ:
1. ความยาวคลื่นของสัญญาณในเนื้อไดอิเล็กทริก ($\lambda_{diel}$) ที่ความถี่ $5.0\text{ GHz}$
2. ระยะห่างสูงสุดระหว่างรูเจาะกราวด์ ($s_{max}$) ในหน่วยมิลลิเมตรและมิล (mils)
3. หากขอบบอร์ดมีเส้นรอบรูปความยาวรวม $P = 600\text{ mm}$ จะต้องเจาะรู GND Stitching Vias รอบขอบบอร์ดทั้งหมดอย่างน้อยกี่ตัว ($N_{vias}$)?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความยาวคลื่นในเนื้อไดอิเล็กทริก ($\lambda_{diel}$):**
- ความเร็วการแพร่คลื่นในเนื้อฉนวน:
  $$v = \frac{c_0}{\sqrt{\varepsilon_r}} = \frac{3 \times 10^8\text{ m/s}}{\sqrt{3.6}} = \frac{3 \times 10^8}{1.8974} \approx 1.581 \times 10^8\text{ m/s}$$
- ความยาวคลื่นที่ $5.0\text{ GHz} = 5.0 \times 10^9\text{ Hz}$:
  $$\lambda_{diel} = \frac{v}{f_{max}} = \frac{1.581 \times 10^8\text{ m/s}}{5.0 \times 10^9\text{ Hz}} = 0.03162\text{ m} = 31.62\text{ mm}$$

**2. คำนวณระยะห่างสูงสุดระหว่างรูเจาะ ($s_{max}$):**
จากกฎ $\lambda / 20$:
$$s_{max} = \frac{\lambda_{diel}}{20} = \frac{31.62\text{ mm}}{20} \approx 1.581\text{ mm}$$

แปลงเป็นหน่วย mils ($1\text{ mm} \approx 39.37\text{ mils}$):
$$s_{max} \approx 1.581 \times 39.37 \approx 62.24\text{ mils}$$
*(ในทางปฏิบัติ วิศวกรจะกำหนดระยะพิทช์มาตรฐานที่ **$1.5\text{ mm}$ หรือ $50 - 60\text{ mils}$**)*

**3. คำนวณจำนวนรูเจาะรอบขอบบอร์ด ($N_{vias}$):**
$$N_{vias} = \frac{P}{s_{max}} = \frac{600\text{ mm}}{1.50\text{ mm}} = 400\text{ รู}$$

**บทสรุปของ Senior Engineer:**
- การวางแนวกั้นกราวด์รอบขอบบอร์ดด้วยรูเจาะ Via จำนวน 400 รู ที่ระยะห่าง $1.5\text{ mm}$ จะทำหน้าที่เป็นกรงฟาราเดย์ 2 มิติ (2D Faraday Cage) ขังคลื่นแม่เหล็กไฟฟ้าความถี่สูงถึง $5.0\text{ GHz}$ ให้อยู่ภายในแผ่นวงจร
- ช่วยลดการรั่วไหลของสัญญาณรบกวนที่ขอบบอร์ด (Edge Radiation) ลงได้มากกว่า **$25 - 30\text{ dB}$** ทำให้บอร์ดผ่านเกณฑ์มาตรฐานยานยนต์ CISPR 25 Class 5 ได้อย่างมั่นใจ
