# Lesson 004: PCB Routing Part 4 - Via Placement, Stub Resonance & Backdrilling
*(プリント基板のビア配置設計 - スタブ共振とバックドリル技術)*

---

## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในวงจรดิจิทัลความเร็วสูงระดับ Multi-Gigabit (เช่น PCIe Gen 4/5, 25G/56G SerDes, USB4) จุดเปลี่ยนผ่านของเลเยอร์ผ่านรูเจาะ Via ไม่สามารถมองเป็นจุดเชื่อมต่ออุดมคติ (Ideal Node) ได้อีกต่อไป แต่มีพฤติกรรมเป็น **โครงสร้างสามมิติที่มีความจุและความเหนี่ยวนำแฝง (3D Parasitic LC Discontinuity)** และเป็นแหล่งกำเนิดสัญญาณสะท้อนที่สำคัญที่สุดบนบอร์ด

---

### 1.1 ค่าความจุและความเหนี่ยวนำแฝงของ Via ($C_v$ และ $L_v$)
โครงสร้างของ Via ประกอบด้วย Barrel (กระบอกทองแดง), Pad (ห่วงทองแดง), และ Anti-pad (ช่องว่างฉลุรอบห่วงบนระนาบ Ground/Power):

#### 1. ความจุแฝงของ Via (Via Capacitance, $C_v$):
เกิดจากความจุไฟฟ้าระหว่าง Via Pad/Barrel กับระนาบ Ground ที่อยู่รอบๆ คำนวณโดยประมาณได้จากสูตรของ Dr. Howard Johnson:

$$C_v \approx \frac{1.41 \ \epsilon_r \ T \ D_1}{D_2 - D_1} \quad [\text{pF}]$$

- $T$: ความหนาของแผ่น PCB (Board Thickness ในหน่วยนิ้ว)
- $D_1$: เส้นผ่านศูนย์กลางของ Via Pad (นิ้ว)
- $D_2$: เส้นผ่านศูนย์กลางของ Anti-pad บนระนาบ Ground (นิ้ว)
- $\epsilon_r$: Dielectric Constant ของวัสดุ

#### 2. ความเหนี่ยวนำแฝงของ Via (Via Inductance, $L_v$):
เกิดจากการที่กระแสไหลในแนวดิ่งผ่านกระบอก Barrel:

$$L_v \approx 5.08 \ h \left[ \ln\left(\frac{4h}{d}\right) + 1 \right] \quad [\text{nH}]$$

- $h$: ความยาวของกระบอก Via ที่กระแสไหลผ่าน (นิ้ว)
- $d$: เส้นผ่านศูนย์กลางของรูเจาะ Via Drill (นิ้ว)

**ผลลัพธ์ทาง Signal Integrity:**
ค่า $C_v$ (มักอยู่ที่ $0.3 - 0.7 \text{ pF}$) และ $L_v$ (มักอยู่ที่ $0.8 - 1.5 \text{ nH}$) จะทำให้เกิดการดิ่งลงของค่า Impedance ทันที (Capacitive Impedance Dip) โดยค่า $Z_{via}$ มักจะตกลงมาอยู่ที่ **$35 - 42 \ \Omega$** สำหรับบอร์ด $50 \ \Omega$ ทั่วไป

---

### 1.2 ปรากฏการณ์เรโซแนนซ์ของ Via Stub (Quarter-Wave Resonance)
เมื่อสัญญาณความถี่สูงวิ่งเข้าสู่ Via จาก Layer บน (เช่น L1) และมุดออกไปยัง Layer กลาง (เช่น L4) ส่วนของลำตัวกระบอก Via ที่ยื่นเกินลงไปจนถึง Layer ล่างสุด (L4 ถึง L16) จะถูกเรียกว่า **"Via Stub"**

```
     L1 (Signal In) ─────┐
                         │
     L4 (Signal Out) ────┼────────>
                         │
                         │ ◄─── Via Stub (Length = L_stub)
                         │      ทำหน้าที่เป็น Open-Circuit Stub
     L16 (Bottom) ───────┘
```

Via Stub นี้จะประพฤติตัวเสมือนสายส่งปลายเปิด (Open-Circuited Transmission Line) ซึ่งจะกลายเป็นวงจรลัดวงจรเสมือน (Virtual Short Circuit) ที่ความถี่เรโซแนนซ์คลื่น 1 ใน 4 ($\frac{\lambda}{4}$):

$$f_{notch} \approx \frac{c}{4 \times L_{stub} \times \sqrt{\epsilon_r}}$$

- $c$: ความเร็วแสงในสุญญากาศ ($3 \times 10^8 \text{ m/s}$)
- $L_{stub}$: ความยาวของ Via Stub
- $\epsilon_r$: Dielectric Constant

**การคำนวณจริงเทียบความเร็วบัส:**
หากบอร์ดหนา $2.0 \text{ mm}$ และมี Stub ยาว $L_{stub} = 1.2 \text{ mm} \ (47 \text{ mil})$ บนวัสดุ FR-4 ($\epsilon_r = 4.0$):
$$f_{notch} = \frac{3 \times 10^8}{4 \times 0.0012 \times \sqrt{4.0}} = \frac{3 \times 10^8}{0.0096} \approx 31.25 \text{ GHz}$$
แต่หากบอร์ดหนา $2.4 \text{ mm}$ และสัญญาณวิ่งจาก L1 ไป L2 ทำให้เหลือ Stub ยาว $L_{stub} = 2.2 \text{ mm}$:
$$f_{notch} = \frac{3 \times 10^8}{4 \times 0.0022 \times 2.0} \approx 17.0 \text{ GHz}$$

*ข้อควรระวัง:* สำหรับสัญญาณ PCIe Gen 5 (ความถี่ Nyquist อยู่ที่ $16 \text{ GHz}$) หรือ 56G PAM4 ค่า Notch Frequency ที่ $17 \text{ GHz}$ จะดูดกลืนพลังงานของสัญญาณไปเกือบหมด (Insertion Loss $S_{21}$ ตกฮวบมากกว่า $-25 \text{ dB}$) ทำให้บัสสื่อสารล่มโดยสิ้นเชิง!

---

### 1.3 เทคโนโลยี Backdrilling (Controlled-Depth Drilling)
เพื่อกำจัด Via Stub โดยไม่ต้องเปลี่ยนโครงสร้างไปใช้บอร์ด HDI Blind/Buried Vias ราคาแพง วิศวกรจะใช้เทคนิค **Backdrilling** คือการใช้ดอกสว่านที่มีขนาดใหญ่กว่ารูเดิมเล็กน้อย เจาะสวนจากด้านล่างของบอร์ดขึ้นมาเพื่อคว้านเนื้อทองแดงของ Stub ทิ้งไป:

- **Must-Not-Cut Layer:** ชั้นที่มีสัญญาณใช้งานจริง (ห้ามโดนสว่านตัดเด็ดขาด)
- **Stub Allowance ($L_{rem}$):** ความยาว Stub ที่ยอมให้หลงเหลือได้ตามพิกัดคลาดเคลื่อนของเครื่องจักร โดยทั่วไปอยู่ที่ **$\le 8 \text{ mil} \ (0.20 \text{ mm})$**

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** โมดูลรับส่งสัญญาณแสงความเร็ว 25 Gbps (SFP28) ไม่สามารถเปิด Link ได้ วัด Eye Diagram พบว่า Eye Height ปิดสนิทเกือบเป็นเส้นตรง และตรวจวัด $S_{21}$ ด้วย VNA พบรอยบุ๋มลึก (Deep Notch) ที่ความถี่ $12.5 \text{ GHz}$
**สาเหตุที่ตรวจพบ (検図での指摘):**
บอร์ดหนา 12 Layer มีการเดินสายส่งข้อมูล SerDes จาก Top Layer (L1) มุดลงไปยัง L3 โดยผ่าน Thru-hole Via ธรรมดา เหลือความยาว Stub จาก L3 ถึง L12 ยาวถึง $1.8 \text{ mm}$ ซึ่งทำให้เกิด Quarter-wave Resonance ดักกลืนพลังงานที่ความถี่หลักของ 25 Gbps ($12.5 \text{ GHz}$) พอดี!

### ขั้นตอนการวาง Via และแก้ปัญหาหน้างาน (検図チェックリスト):
1. **การวาง Ground Return Stitching Via:**
   - เมื่อสัญญาณความเร็วสูงมุดเปลี่ยน Layer ผ่าน Signal Via กระแสย้อนกลับบน Reference Plane จะต้องเปลี่ยนระนาบตามไปด้วย
   - *กฎบังคับ:* ต้องวาง **GND Stitching Via อย่างน้อย 1 ตัว (ดีที่สุดคือ 2 ตัวประกบหน้าหลัง)** ห่างจาก Signal Via ไม่เกิน **$0.4 - 0.5 \text{ mm}$**
   - หากเปลี่ยน Layer ข้ามระหว่าง Reference Plane ต่างชนิดกัน (เช่น จาก Ground Plane ไปอ้างอิง Power Plane) จะต้องวาง **Stitching Capacitor (0.1 $\mu$F 0201)** ข้างๆ Via ทันทีเพื่อเชื่อมต่อกระแส Displacement Current ข้ามระนาบ
2. **การทำ Anti-pad Optimization:**
   - เพื่อชดเชยค่าความจุแฝง ($C_v$) ที่ทำให้ Impedance ดิ่งลง ให้สั่งขยายขนาดเส้นผ่านศูนย์กลางของ Anti-pad บนระนาบ Reference Plane จากปกติ 18 mil เป็น 24–28 mil ซึ่งจะช่วยลด Capacitance และดึงค่า $Z_{via}$ กลับขึ้นมาใกล้เคียง $50 \ \Omega$
3. **การกำหนด Backdrill ใน Drawing:**
   - ในตาราง Drill Chart ต้องแยกสัญลักษณ์รูเจาะเฉพาะสำหรับ Backdrill พร้อมระบุคู่ Layer ต้นทางและปลายทางให้ชัดเจน เช่น:
     `Backdrill from Bottom Layer to Layer 4, Max Remaining Stub = 0.20 mm`

> 「10Gbpsイーサネット差動配線（NET: `ETH_TX_P/N`）がL1層からL3層へビアで遷移していますが、L3～L10層間に約1.5mmの残存スタブが存在します。ナイキスト周波数近傍でスタブ共振によるS21ディップが発生する懸念があるため、裏面からのバックドリル（残存スタブ0.2mm以下）を指示するか、L10層配線へ変更してください。」  
> *(สัญญาณ 10Gbps Ethernet มุดเปลี่ยนเลเยอร์จาก L1 ไป L3 ทำให้เหลือ Stub ระหว่าง L3 ถึง L10 ยาวถึง 1.5 mm มีความเสี่ยงที่จะเกิด S21 Dip จาก Stub Resonance ใกล้ความถี่ Nyquist กรุณาสั่งทำ Backdrill จากด้านหลังบอร์ด (จำกัด Stub ไม่เกิน 0.2 mm) หรือเปลี่ยนไปเดินสายบน L10 แทน)*

> **指摘事項 2:**  
> 「高速クロック（CLK_100M）の層間移動ビアに対して、リターンGNDビアが周囲1.0mm以内に配置されていません。リターンパス不連続による不要輻射（EMI）を防止するため、信号ビアの隣接位置（中心間距離0.5mm以内）にGNDビアを追加配置してください。」  
> *(Via เปลี่ยนชั้นของ Clock 100MHz ไม่มี Ground Return Via อยู่ในระยะ 1.0 mm เพื่อป้องกันการแผ่คลื่นแม่เหล็กไฟฟ้า (EMI) จากรอยต่อระนาบกระแสย้อนกลับ กรุณาเพิ่ม GND Via ชิดข้าง Signal Via โดยมีระยะห่างกึ่งกลางไม่เกิน 0.5 mm)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Quarter-Wave Notch Frequency)
ในการออกแบบบอร์ดความหนา $2.4 \text{ mm}$ สำหรับชิป SerDes $16 \text{ Gbps}$ (ความถี่ Nyquist $= 8.0 \text{ GHz}$, $\epsilon_r = 4.0$) วิศวกรเดินสายสัญญาณความเร็วสูงจาก Top Layer (L1) มุดลงมาที่ Layer 2 (L2) ทันที ทำให้มี Via Stub ทอดยาวตั้งแต่ L2 ลงไปจนถึงขอบล่างสุดของบอร์ด คิดเป็นความยาว $L_{stub} = 2.1 \text{ mm}$ ถามว่า:
ความถี่ Notch Frequency ($f_{notch}$) ของ Via Stub นี้จะตกลงที่ย่านความถี่ใด และจะส่งผลกระทบต่อสัญญาณ 16 Gbps หรือไม่?

- **ก)** ตกที่ความถี่ $35.7 \text{ GHz}$ ไม่มีผลกระทบใดๆ ต่อสัญญาณ 16 Gbps
- **ข)** ตกที่ความถี่ $17.85 \text{ GHz}$ ซึ่งใกล้เคียงกับฮาร์มอนิกที่ 2 ($2 \times 8 \text{ GHz} = 16 \text{ GHz}$) ทำให้ Rise Time ของสัญญาณเบลอและ Eye Height ลดลง
- **ค)** ตกที่ความถี่ $1.2 \text{ GHz}$ ทำให้สัญญาณ DC ผ่านไม่ได้
- **ง)** ตกที่ความถี่ $8.0 \text{ GHz}$ พอดีเป๊ะ ทำให้สัญญาณหายไปทั้งหมด 100%

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> คำนวณความถี่ Notch:  
> $$f_{notch} = \frac{c}{4 \times L_{stub} \times \sqrt{\epsilon_r}} = \frac{3 \times 10^8 \text{ m/s}}{4 \times 0.0021 \text{ m} \times \sqrt{4.0}} = \frac{3 \times 10^8}{0.0168} \approx 17.85 \text{ GHz}$$  
> สำหรับสัญญาณดิจิทัล 16 Gbps (Nyquist fundamental = $8 \text{ GHz}$) ขอบสัญญาณ (Rise time) ประกอบด้วยความถี่ฮาร์มอนิกตั้งแต่ $16 - 24 \text{ GHz}$ การที่มี Notch ลึกที่ $17.85 \text{ GHz}$ จะกลืนพลังงานของฮาร์มอนิก ส่งผลให้ขอบสัญญาณลาดชันช้าลง (Rise time degradation) ก่อให้เกิด Jitter และ Eye Diagram ปิดตัวลงอย่างมีนัยสำคัญ

---

### ข้อที่ 2 (กลไกของ Return Path ผ่านระนาบต่างศักย์)
หากจำเป็นต้องเดินสายสัญญาณความเร็วสูงเปลี่ยน Layer จาก Layer ที่อ้างอิงระนาบ **GND Plane** ไปยัง Layer ที่อ้างอิงระนาบ **+1.8V Power Plane** วิศวกรควรออกแบบโครงสร้างจุดเปลี่ยน Layer อย่างไรเพื่อให้กระแสย้อนกลับเดินทางได้สมบูรณ์ที่สุด?

- **ก)** ไม่ต้องทำอะไรเลย เพราะสนามแม่เหล็กไฟฟ้าจะเดินทางผ่านอากาศได้เอง
- **ข)** ต่อ Via เชื่อมตรงระหว่าง GND Plane กับ +1.8V Power Plane เข้าด้วยกันโดยตรง
- **ค)** วางตัวเก็บประจุ Stitching Capacitor (เช่น $0.1 \ \mu\text{F}$ 0201 ค่า ESL ต่ำ) คร่อมระหว่าง GND กับ +1.8V ให้ชิดกับ Signal Via มากที่สุด เพื่อให้กระแส Displacement Current ไหลข้ามระนาบได้
- **ง)** ตัดระนาบ Power Plane ออกให้หมดแล้วเปลี่ยนมาเดินสายไฟแบบเส้นเดี่ยวแทน

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ค)**  
> กระแสย้อนกลับ (Return Current) ของสัญญาณความถี่สูงต้องการเส้นทางวนกลับที่มี Impedance ต่ำที่สุด เมื่อเปลี่ยนระนาบจาก GND ไปยัง Power Plane ที่มีระดับแรงดันต่างกัน เราไม่สามารถต่อช็อตด้วย Via โดยตรงได้ (จะเกิดการลัดวงจรไฟฟ้ากระแสตรง!)  
> วิธีที่ถูกต้องทางวิศวกรรมคือการใช้ **Stitching Capacitor** ซึ่งทำหน้าที่เป็นตัวต้านทานต่ำมากในย่านความถี่สูง ($X_c = \frac{1}{2\pi f C} \approx 0$) ยอมให้กระแสความถี่สูง (Displacement Current) กระโดดข้ามระนาบระหว่าง GND และ Power ได้อย่างราบรื่นโดยไม่เกิด Loop Inductance ขนาดใหญ่

### ข้อที่ 3 (มาตรฐานการควบคุม Backdrilling)
เหตุใดในข้อกำหนดการผลิตบอร์ดความเร็วสูงระดับ 25G+ จึงไม่อนุญาตให้ Backdrilling เจาะจนเสมอกับรอยทองแดงของ Signal Layer พอดีเป๊ะ ($L_{stub} = 0$) แต่ต้องกำหนดค่า Residual Stub เผื่อไว้เสมอ (เช่น Max 0.20 mm)?

- **ก)** เพื่อประหยัดพลังงานไฟฟ้าของเครื่องเจาะสว่าน
- **ข)** เนื่องจากเครื่องเจาะ CNC มีพิกัดความคลาดเคลื่อนในแนวดิ่ง (Z-axis Tolerance) หากสั่งเจาะเสมอกับ Layer สัญญาณ มีความเสี่ยงสูงมากที่ปลายสว่านจะกินลึกเกินไปและตัดลายวงจรสัญญาณขาด (Traces Cut / Open Defect)
- **ค)** เพราะทองแดงที่เหลืออยู่ช่วยเป็นฉนวนกันคลื่นแม่เหล็กไฟฟ้า
- **ง)** เพื่อให้โรงงานสามารถใช้สว่านทู่ในการเจาะได้

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ความคลาดเคลื่อนทางกลของเครื่องเจาะควบคุมความลึก (Controlled-Depth Drilling) ประกอบด้วยค่าเผื่อความหนาของแผ่นบอร์ด ($\pm 10\%$) และความแม่นยำแกน Z ของเครื่องจักร ($\pm 1 - 2 \text{ mil}$)  
> หากโรงงานพยายามเจาะให้ได้ความลึกเสมอกับ Signal Pad พอดี ปลายสว่านจะตัดทะลุ Pad ขาด ทำให้บอร์ดเสีย 100% (Yield ตกทันที) วิศวกรจึงต้องยอมให้มี **Residual Stub Allowance** อยู่ที่ประมาณ **$4 - 8 \text{ mil} \ (0.10 - 0.20 \text{ mm})$** ซึ่งเป็นค่าที่ไม่ก่อให้เกิดผลกระทบต่อสัญญาณในย่านความถี่ต่ำกว่า 30 GHz
