*(プリント基板のインピーダンス制御 - ビア不連続点とTDR波形・アンチパッド最適化)*

## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในระบบส่งสัญญาณดิจิทัลความเร็วสูงระดับ Multi-Gigabit (เช่น PCIe Gen 4/5/6, 56G/112G PAM4, USB4) รูเจาะเปลี่ยนเลเยอร์ (Via) ถือเป็น **จุดสะดุดของอิมพีแดนซ์ (Impedance Discontinuity)** ที่สร้างความเสียหายต่อรูปคลื่นสัญญาณมากที่สุดบนบอร์ด 
การเปลี่ยนผ่านจากโครงสร้างสองมิติ (2D Planar Trace) ไปสู่โครงสร้างสามมิติในแนวดิ่ง (3D Vertical Barrel) ก่อให้เกิดปรสิตทางไฟฟ้าทั้งความจุแฝง ($C_v$) และความเหนี่ยวนำแฝง ($L_v$)
วิศวกรระดับ Senior ต้องเข้าใจ **การวิเคราะห์รูปคลื่นสะท้อน TDR (Time Domain Reflectometry Signatures)**, **กลไกการเกิดเรโซแนนซ์คลื่น 1 ใน 4 (Quarter-Wave Resonance)**, และ **เทคนิคการปรับจูนรูปทรง Anti-Pad (Anti-Pad Co-Optimization)**

---

### 1.1 วงจรสมมูลของ Via และค่า Characteristic Impedance ของกระบอกเวีย ($Z_{via}$)
โครงสร้างทางกายภาพของ Via ประกอบด้วย Barrel, Pad, และ Anti-Pad ซึ่งสามารถจำลองเป็นวงจรกรองความถี่ต่ำผ่านแบบ $\pi$-Network หรือ T-Network:

```
               L_via / 2               L_via / 2
   Trace ───────( ( ( )───────┬─────────( ( ( )─────── Trace
                              │
                            ──┴── C_via (Parasitic Capacitance)
                            ──┬──
                              │
   ───────────────────────────┴─────────────────────── Ground Reference
```

- ความจุแฝง ($C_{via}$): เกิดจากพื้นที่ผิวของ Pad และ Barrel เทียบกับระนาบ Ground โดยรอบ (ปกติอยู่ที่ $0.3 - 0.8 \text{ pF}$)
- ความเหนี่ยวนำแฝง ($L_{via}$): เกิดจากเส้นทางการไหลของกระแสในแนวดิ่ง (ปกติอยู่ที่ $0.5 - 1.5 \text{ nH}$)

**ปรากฏการณ์ Capacitive Impedance Dip:**
ค่า Characteristic Impedance ชั่วขณะของกระบอก Via ($Z_{via}$) คำนวณได้จาก:

$$Z_{via} = \sqrt{\frac{L_{via}}{C_{via}}} \quad [\Omega]$$

ในโครงสร้าง Through-Hole Via มาตรฐานทั่วไป ค่าความจุแฝง $C_{via}$ มักจะมีสัดส่วนที่สูงกว่าความเหนี่ยวนำ ส่งผลให้ค่า $Z_{via}$ **ดิ่งฮวบลงมาอยู่ที่เพียง $32 - 42 \ \Omega$** (เทียบกับเป้าหมาย $50 \ \Omega$) ปรากฏเป็นหลุมลึก (Capacitive Dip) ในการตรวจวัดด้วยเครื่อง TDR

---

### 1.2 ลายเซ็นของรูปคลื่น TDR (TDR Discontinuity Signatures)
เครื่องวัด Time Domain Reflectometer (TDR) ส่งคลื่นสเต็ปพัลส์ที่มี Rise Time เร็วระดับพิโกวินาที ($t_r < 20 - 35 \text{ ps}$) เข้าไปในสายส่ง การเปลี่ยนแปลงของค่า Impedance ในแต่ละจุดบนบอร์ดจะสะท้อนกลับมาเป็นรูปคลื่นเฉพาะตัว:

```
  Impedance [Ω]
    ▲
    │         Inductive Peak (L) ──►  /\
 50 ┼─────────\                      /  \──────────────── Matched Z0 = 50Ω
    │          \                    /
    │           \                  /
    │            \/ ◄── Capacitive Dip (C)
    └───────────────────────────────────────────────────► Time / Distance
```

| พฤติกรรมของรอยต่อบนบอร์ด | ลายเซ็นบนรูปคลื่น TDR (Signature) | สาเหตุทางกายภาพในงาน Layout |
|---|---|---|
| **Capacitive Discontinuity ($C_{parasitic}$)** | **แรงดันดิ่งเป็นหลุมลึก (Negative Dip)** | รูเจาะ Via Pad ขนาดใหญ่, Anti-pad แคบเกินไป, Pad ของคอนเนคเตอร์ SMD |
| **Inductive Discontinuity ($L_{parasitic}$)** | **แรงดันพุ่งเป็นยอดเขา (Positive Peak)** | รอยคอดของสาย (Neckdown ใต้ BGA), สายกราวด์อ้อม, Via ขาด Return Via |
| **Via Stub (Open Quarter-Wave)** | **หลุมลึกตามด้วยยอดพุ่งและ Ringing** | ติ่งปลายเปิดของ Via ที่ไม่ได้ทำ Backdrilling |

---

### 1.3 ทฤษฎี Quarter-Wave Stub Resonance และสมการ Notch Frequency
เมื่อสัญญาณมุดเข้า Via จาก Layer 1 ไปยัง Layer 3 ส่วนของกระบอก Via จาก Layer 3 ถึง Layer ล่างสุด (Bottom) ที่ไม่มีกระแสไหลออกไปไหน จะกลายเป็น **Via Stub (สายส่งปลายเปิด)**
คลื่นสัญญาณความถี่สูงส่วนหนึ่งจะวิ่งลงไปที่ปลาย Stub สะท้อนกลับขึ้นมาที่จุดเชื่อมต่อด้วยมุมเฟสที่เปลี่ยนไป $180^\circ$ เกิดการหักล้างกับสัญญาณหลักจนเกิดรอยบุ๋มลึก (Deep Notch) บนกราฟ Insertion Loss ($S_{21}$):

$$f_{notch} \approx \frac{c}{4 \times L_{stub} \times \sqrt{\epsilon_r}} \times (2n - 1) \quad [n = 1, 2, 3...]$$

**ตัวอย่างการคำนวณจริง:**
กำหนดให้บอร์ดหนา $2.4 \text{ mm}$ สัญญาณ PCIe Gen 4 (ความถี่ Nyquist $8.0 \text{ GHz}$) วิ่งจาก L1 ไป L2 ทำให้เหลือความยาว Stub:
$$L_{stub} = 2.1 \text{ mm} \ (82.7 \text{ mil}) \quad (\text{บนวัสดุ } \epsilon_r = 4.0)$$

$$f_{notch} = \frac{3 \times 10^8 \text{ m/s}}{4 \times 0.0021 \text{ m} \times \sqrt{4.0}} = \frac{3 \times 10^8}{0.0168} \approx \mathbf{17.85 \text{ GHz}}$$

*ผลกระทบทางวิศวกรรม:*  
แม้ว่าความถี่หลักจะอยู่ที่ 8 GHz แต่ฮาร์มอนิกที่ 2 ($2 \times 8 = 16 \text{ GHz}$) ซึ่งเป็นตัวกำหนดความชันของขอบสัญญาณ (Rise Time) จะตกลงตรงหลุม Notch ที่ $17.85 \text{ GHz}$ พอดีเป๊ะ! พลังงานของฮาร์มอนิกจะถูกดูดกลืนหายไป ($S_{21}$ ตกฮวบกว่า $-25 \text{ dB}$) ทำให้ขอบสัญญาณเบลอ Eye Diagram ปิดสนิท และบัส PCIe ไม่สามารถเชื่อมต่อได้

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** การ์ดเร่งความเร็ว AI (PCIe Gen 4 x16 AIC) ล้มเหลวในการทดสอบ Eye Mask Margin ที่ Golden Receiver โดยตรวจวัด TDR พบว่าที่จุดเปลี่ยนผ่านของ Via บริเวณขั้วต่อขอบการ์ด (Gold Finger Transition) ค่า Differential Impedance ดิ่งลงเหลือเพียง **$67 \ \Omega$** (สเปกบังคับ $85 \ \Omega \pm 10\% \rightarrow 76.5 - 93.5 \ \Omega$)
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **ขนาด Anti-Pad แคบเกินไป:** รอยฉลุ Anti-pad บนระนาบ Ground ชั้น L2 มีเส้นผ่านศูนย์กลางเพียง $18 \text{ mil}$ โดยเป็นรูกลมแยกเดี่ยว 2 รู ทำให้สนามไฟฟ้าระหว่าง Via Pad กับระนาบ Ground ชิดกันเกินไป ดึงค่าความจุ $C_v$ สูงลิ่ว
2. **มี Via Stub ยาว $1.6 \text{ mm}$:** สัญญาณมุดจาก L1 ไป L4 บนบอร์ดหนา 12 เลเยอร์ โดย **ไม่ได้สั่ง Backdrilling** ในกระบวนการผลิต

---

### ขั้นตอนการปรับจูน Anti-Pad และ Via สไตล์ Senior (検図チェックリスト):
1. **การรวม Anti-Pad เป็นรูปสนามแข่งม้า (Racetrack Anti-Pad Optimization):**
   - สำหรับคู่สาย Differential **ห้ามใช้ Anti-pad ทรงกลมเดี่ยวแยกกันเด็ดขาด**
   - ให้ผสานรอยฉลุของทั้งสองรูเข้าด้วยกันเป็น **รูปวงรีทรงยาว (Racetrack / Oval Anti-Pad)**:
     - การรวมช่องว่างจะช่วยขจัดเนื้อทองแดงที่อยู่คั่นตรงกลางระหว่างคู่ Via ออกไป ช่วยลดความจุไฟฟ้าแฝงระหว่างขั้วคู่ ($C_{pair}$) และดึงค่า Differential Impedance กลับขึ้นมาอยู่ที่ **$85 \ \Omega$ หรือ $100 \ \Omega$** ได้อย่างราบรื่น
2. **การสั่งทำ Backdrilling (Controlled-Depth Drilling):**
   - กำหนดในแบบสั่งผลิตให้ชัดเจนสำหรับสัญญาณที่เร็วเกิน $5 \text{ Gbps}$:
     - เจาะเอาเนื้อทองแดงส่วนที่ไม่ได้ใช้งานทิ้งไป โดยกำหนดค่า **Residual Stub $\le 0.20 \text{ mm} \ (8 \text{ mil})$**
3. **การตัด Pad ที่ไม่ได้เชื่อมต่อในชั้นใน (Non-Functional Pad Removal - NFPR):**
   - สั่งให้โรงงานลบวงแหวนทองแดง (Unused Inner Pads) บนเลเยอร์ที่ไม่มีการต่อลายวงจรออกทั้งหมด เพื่อลดค่าความจุแฝงต่อชั้นกราวด์ลงอีก $15\% - 20\%$

> *(สาย 25Gbps SerDes มุดจาก L1 ไป L3 เหลือ Stub ยาวถึง 1.6mm ระหว่าง L3-L12 เพื่อกำจัด S21 Dip จากการสั่นพ้อง Quarter-Wave กรุณาสั่งทำ Backdrilling จากด้านหลังโดยจำกัด Stub ไม่เกิน 0.2mm ในแบบสั่งผลิต)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Quarter-Wave Resonance ของ Via Stub)
บอร์ดเซิร์ฟเวอร์ความหนา $2.0 \text{ mm}$ ใช้วัสดุที่มีค่า $\epsilon_r = 3.6$ มีการเดินสายส่งข้อมูล SerDes ความเร็วสูงจาก Top Layer (L1) มุดลงมายัง Layer 3 (L3) ทำให้เหลือความยาว Via Stub ทอดยาวลงไปถึง Bottom Layer คิดเป็นความยาว $L_{stub} = 1.65 \text{ mm}$ ถามว่าความถี่ Notch Frequency ($f_{notch}$) หลักของ Via Stub นี้จะตกลงที่ย่านความถี่ใดโดยประมาณ?

- **ก)** ตกที่ความถี่ $5.2 \text{ GHz}$
- **ข)** ตกที่ความถี่ $23.96 \text{ GHz}$
- **ค)** ตกที่ความถี่ $45.0 \text{ GHz}$
- **ง)** ตกที่ความถี่ $1.2 \text{ GHz}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> จากสมการ Quarter-Wave Stub Resonance:  
> $$f_{notch} \approx \frac{c}{4 \times L_{stub} \times \sqrt{\epsilon_r}}$$  
> แทนค่าพารามิเตอร์:  
> $$f_{notch} = \frac{3 \times 10^8 \text{ m/s}}{4 \times (0.00165 \text{ m}) \times \sqrt{3.6}} = \frac{3 \times 10^8}{0.0066 \times 1.897} = \frac{3 \times 10^8}{0.01252} \approx \mathbf{23.96 \times 10^9 \text{ Hz} \approx 23.96 \text{ GHz}}$$  
> สำหรับสัญญาณดิจิทัลระดับ 25 Gbps หรือ 56G PAM4 ความถี่เรโซแนนซ์ที่ $24 \text{ GHz}$ จะดูดกลืนพลังงานของสัญญาณไปเกือบหมด ทำให้ขอบสัญญาณล้มเหลวและ Eye Diagram ปิดตัวลงอย่างสมบูรณ์ จึงจำเป็นต้องสั่ง Backdrilling ทิ้งทันที

---

### ข้อที่ 2 (การแปลความหมายของรูปคลื่น TDR บนจุดเชื่อมต่อคอนเนคเตอร์)
เมื่อยิงพัลส์ TDR เข้าไปในสายส่ง $50 \ \Omega$ และสังเกตเห็นรูปคลื่นสะท้อนเกิดยอดพุ่งขึ้นเป็นภูเขาแหลม (Positive Peak สูงถึง $62 \ \Omega$) ณ ตำแหน่งรอยต่อของขั้วคอนเนคเตอร์ ปรากฏการณ์นี้บ่งชี้ถึงข้อบกพร่องทางกายภาพใด และควรแก้ไขอย่างไร?

- **ก)** มีค่าความจุไฟฟ้าแฝง ($C$) สูงเกินไป ให้เพิ่มขนาด Pad ให้ใหญ่ขึ้น
- **ข)** มีค่าความเหนี่ยวนำแฝงอนุกรม ($L$) สูงเกินไป อันเนื่องมาจากเส้นทางการเชื่อมต่อแคบเกินไปหรือขาดระนาบกราวด์อ้างอิงที่ต่อเนื่อง ควรแก้ไขโดยการลดความยาวของขาลีดและเพิ่ม Ground Return Stitching Vias ประกบประชิดขั้วสัญญาณ
- **ค)** สัญญาณวิ่งเร็วกว่าความเร็วแสง
- **ง)** เกิดการลัดวงจรไฟฟ้าลงกราวด์อย่างสมบูรณ์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ยอดพุ่งขึ้นในทางบวกบนกราฟ TDR ($\rho > 0, Z > Z_0$) คือสัญลักษณ์ทางฟิสิกส์ของ **Inductive Discontinuity (ความเหนี่ยวนำแฝงพุ่งสูง)**  
> สาเหตุหลักเกิดจากการที่กระแสสัญญาณต้องวิ่งผ่านขาลีดคอนเนคเตอร์ที่ยาว หรือระนาบ Ground ใต้คอนเนคเตอร์ถูกตัดขาด ทำให้กระแสย้อนกลับต้องเดินทางวนอ้อมขยายพื้นที่ Loop Area

### ข้อที่ 3 (ผลกระทบของการใช้ Racetrack Anti-Pad บนคู่สาย Differential)
เหตุใดการผสานรอยฉลุ Anti-pad ของคู่สาย Differential Via ให้กลายเป็นรูปทรงสนามแข่งม้ารวมช่องเดียว (Racetrack Void) จึงสามารถเพิ่มประสิทธิภาพ Signal Integrity ได้ดีกว่าการใช้รูกลมแยกเดี่ยวสองรู?

- **ก)** เพราะช่วยให้เครื่องเจาะสว่านทำงานได้เร็วขึ้น
- **ข)** ช่วยขจัดติ่งทองแดงคั่นกลางระหว่างคู่ Via ซึ่งเป็นแหล่งกักเก็บความจุไฟฟ้าแฝงส่วนเกิน (Excess Mutual Capacitance) ช่วยลดหลุม Capacitive Dip และช่วยรักษาความต่อเนื่องของสนามแม่เหล็กไฟฟ้าระหว่างขั้วบวกและลบให้สมดุล
- **ค)** เพื่อลดน้ำหนักของแผ่นวงจรพิมพ์ให้เบาลง
- **ง)** ช่วยป้องกันไม่ให้น้ำยาบัดกรีไหลทะลุแผ่นบอร์ด

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> เมื่อเจาะ Via สองรูติดกันสำหรับสัญญาณ Differential หากปล่อยให้มีเนื้อทองแดงของระนาบ Ground แทรกคั่นอยู่ตรงกลางระหว่าง Via ทั้งสอง (Individual Round Pads) เนื้อทองแดงชิ้นเล็กๆ นั้นจะทำหน้าที่เสมือนแผ่นเก็บประจุที่ดึงดูดสนามไฟฟ้าจาก Via ทั้งสองลง Ground ทำให้เกิดหลุมความจุแฝงขนาดใหญ่  
> การขวานเนื้อทองแดงตรงกลางออกและรวมเป็น **Racetrack Anti-Pad** จะเปิดทางให้สนามแม่เหล็กไฟฟ้าระหว่างคู่สายเชื่อมโยงถึงกันได้อย่างเป็นธรรมชาติ (Mutual Coupling) และลดความจุเทียบกราวด์ลง ทำให้ค่า Differential Impedance ราบเรียบต่อเนื่องตลอดรอยต่อ
