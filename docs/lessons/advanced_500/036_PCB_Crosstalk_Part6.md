## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในวงจรอิเล็กทรอนิกส์ความถี่สูง สัญญาณไฟฟ้าไม่ได้เดินทางอยู่บนเส้นลวดตัวนำเพียงเส้นเดียว แต่เดินทางเป็นคู่ของคลื่นแม่เหล็กไฟฟ้าเสมอ (Signal Path และ Return Path) 
วิศวกรมือใหม่มักสนใจเฉพาะเส้นทางของสัญญาณบนเลเยอร์ตัวนำ แต่ละเลย **เส้นทางการไหลกลับของกระแส (Return Current Path)** บนระนาบ Ground หรือ Power 

เมื่อระนาบอ้างอิงเกิดรอยแตก (Split Plane), รอยฉลุร่อง (Slots/Moats), หรือการเปลี่ยนเลเยอร์โดยไม่มี Return Via จะก่อให้เกิด **Return Path Discontinuity (RPD - จุดสะดุดของเส้นทางไหลกลับ)** 
กระแสไหลกลับจะถูกบังคับให้อ้อมรอยแตก ก่อให้เกิดลูปเหนี่ยวนำขนาดยักษ์ กลายสภาพเป็นเสาอากาศแผ่คลื่นแม่เหล็กไฟฟ้า (Slot Antenna EMI) และที่ร้ายแรงที่สุดคือ กระแสไหลกลับของสัญญาณหลายๆ เส้นจะถูกบีบให้ไหลผ่านคอคอดเดียวกัน เกิดเป็น **Common Return Impedance Crosstalk** ที่ทำลายระบบทั้งหมด

### 1.1 การกระจายตัวของความหนาแน่นกระแสไหลกลับ (Return Current Density Distribution)

ที่ความถี่สูงเกิน $100 \text{ kHz}$ กระแสไหลกลับจะไม่เลือกเดินทางตามเส้นทางที่มีความต้านทานต่ำสุด (DC Path: เส้นตรงที่สั้นที่สุด) แต่จะเดินทางตาม **เส้นทางที่มีความเหนี่ยวนำต่ำสุด (Path of Least Inductance)** ซึ่งก็คือการเบียดตัวขึ้นมาไหลบนผิวหน้าของระนาบกราวด์ที่อยู่ใต้ลายวงจรสัญญาณพอดิบพอดี

```
           Signal Trace (Width W, Current +I)
        ┌──────────────────────────────────────┐
        │                                      │
        └──────────────────────────────────────┘
                           ▲
                           │ Height H (Dielectric)
                           ▼
   ────────────────────────────────────────────────────────────────── Ground Plane
                  Return Current Profile J(x)
                        ▲
                       /│\
                      / │ \
                     /  │  \   ◄── High Current Density directly under the trace
   ─────────────────┴───┴───┴────────────────────────────────────────
```

ความหนาแน่นของกระแสไหลกลับต่อหนึ่งหน่วยความกว้างบนระนาบกราวด์ ($J(x)$) อธิบายได้ด้วยสมการลอเรนซ์เซียน (Gaussian/Lorentzian Distribution):

$$J(x) = \frac{I_0}{\pi \cdot H} \times \frac{1}{1 + \left( \frac{x}{H} \right)^2} \quad [\text{A/m}]$$

โดยที่:
- $I_0$ คือกระแสสัญญาณรวม
- $H$ คือความสูงของชั้นไดอิเล็กทริกจากสายไปยังระนาบกราวด์
- $x$ คือระยะห่างในแนวนอนจากแนวกึ่งกลางของสายสัญญาณ

**ข้อสรุปทางฟิสิกส์:**
1. **$50\%$ ของกระแสไหลกลับทั้งหมด** จะกระจุกตัวอยู่ในแถบแคบๆ เพียงระยะ $\pm H$ จากกึ่งกลางสาย
2. **$80\%$ ของกระแสไหลกลับ** จะอยู่ภายในขอบเขต $\pm 3H$
3. **เกือบ $95\%$** จะอยู่ภายในขอบเขต $\pm 5H$  
หากมีสิ่งกีดขวางหรือรอยตัดบนระนาบกราวด์ในบริเวณนี้ กระแสไหลกลับจะถูกรบกวนทันที

### 1.2 ปรากฏการณ์การวิ่งข้ามรอยแตก (Split Plane Crossing & Slot Antenna Radiation)

เมื่อลายวงจรวิ่งข้ามร่องแยกบนระนาบกราวด์ (เช่น รอยผ่าแยกระหว่าง Digital Ground และ Analog Ground, หรือร่อง Power Split):

```
       Top Layer: High-Speed Trace ──────────────────────────────────────────►
                                                   │
                                                   ▼ Crossing Zone
       Ground Plane with Split:                    
       ═══════════════════════╗                 ╔══════════════════════════════
       Digital Ground Plane   ║  Moat / Split   ║  Analog Ground Plane
                              ║  Width G        ║
                              ║                 ║
       ───────────────────────╝                 ╚──────────────────────────────
         ◄── Detour Current Path (Large Loop Area = Severe Inductive Spike & EMI)
```

1. **การเกิด Loop Inductance ขนาดใหญ่ ($\Delta L_{loop}$):**  
   กระแสไหลกลับความถี่สูงไม่สามารถกระโดดข้ามช่องว่างอากาศ/ไดอิเล็กทริกที่มีความต้านทานสูงได้ มันจึงถูกบีบให้เลี้ยวเลาะไปตามขอบของร่องแยก (Detour Path) จนกว่าจะพบจุดเชื่อมต่อ:

$$\Delta L_{loop} \approx \mu_0 \cdot \frac{\text{Area}_{loop}}{W_{path}}$$

2. **Impedance Discontinuity พุ่งสูง:**  
   ค่าความเหนี่ยวนำที่เพิ่มขึ้นชั่วขณะทำให้ค่า Characteristic Impedance ของสายส่งบริเวณรอยข้ามดีดตัวพุ่งสูงขึ้นจาก $50 \ \Omega$ กลายเป็น **$120 - 180 \ \Omega$** ก่อให้เกิดคลื่นสะท้อนและ Ringing ขนาดใหญ่

3. **การแปลงร่างเป็นเสาอากาศแม่เหล็กไฟฟ้า (Slot Antenna Radiation):**  
   รอยผ่าบนระนาบกราวด์ที่มีกระแสความถี่สูงไหลเลาะขอบ จะประพฤติตัวตามทฤษฎี Babinet's Principle กลายเป็น **เสาอากาศแบบสล็อต (Slot Antenna)** ที่มีประสิทธิภาพการแผ่คลื่นสูงมาก ปลดปล่อยสนามแม่เหล็กไฟฟ้าพลังงานสูงแผ่กระจายสู่อากาศ ทะลุผ่านการทดสอบ CISPR/FCC EMI Radiated Emission ทันที

### 1.3 กลไกการเกิด Common Return Impedance Crosstalk

เมื่อมีสัญญาณดิจิทัลมากกว่าหนึ่งเส้นวิ่งข้ามรอยแยกเดียวกัน หรือใช้เส้นทางไหลกลับร่วมกัน:

```
        Trace A (Aggressor) ─────────┐
                                     │ Crossing the same slot
        Trace B (Victim)    ─────────┤
                                     ▼
        Ground Plane Detour: [======= Shared Inductance L_shared =======]
                                            │
                                            ▼ V_noise = L_shared * dI_A/dt
```

กระแสไหลกลับของสัญญาณ Aggressor ($I_A$) และ Victim ($I_B$) จะต้องไหลเบียดเสียดผ่านเนื้อทองแดงบริเวณขอบรอยแยกเดียวกัน ก่อให้เกิดแรงดันตกคร่อมบนความเหนี่ยวนำร่วม ($L_{shared}$):

$$V_{noise} = L_{shared} \frac{dI_A}{dt}$$

แรงดันสัญญาณรบกวนนี้จะถูกฉีดเข้าสู่ลูปของสาย Victim โดยตรงโดยไม่ต้องพึ่งพาความจุแฝงระหว่างสายเลยแม้แต่น้อย ปรากฏการณ์นี้เรียกว่า **Common Return Impedance Crosstalk** ซึ่งสามารถสร้างสัญญาณรบกวนขนาดใหญ่หลายร้อยมิลลิโวลต์ได้ในพริบตา

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** บอร์ดควบคุมระบบขับเคลื่อนมอเตอร์ไฟฟ้า (Motor Inverter Controller) เกิดปัญหา ADC 24-bit Sigma-Delta อ่านค่ากระแสมอเตอร์เพี้ยนอย่างรุนแรง และบอร์ดตกการทดสอบ EMI Radiated Emissions ที่ความถี่ 100 MHz และ 300 MHz สูงเกินเกณฑ์มาตรฐานถึง **$16 \text{ dB}\mu\text{V/m}$**
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **ตัดผ่ากราวด์แยก AGND และ DGND:** วิศวกรทำตามแนวคิดดั้งเดิมที่ล้าสมัย โดยผ่าร่องแยก (Split Moat) บนระนาบกราวด์ระหว่างโซน Analog และ Digital
2. **ลากสาย SPI Clock 100 MHz ข้ามร่องแยก:** มีสัญญาณนาฬิกา $100 \text{ MHz}$ ($t_r = 1.2 \text{ ns}$) เดินจากไมโครคอนโทรลเลอร์ข้ามรอยผ่ากราวด์เข้าไปยังชิป ADC โดยตรง
3. **กระแสไหลกลับอ้อมไกล $45 \text{ mm}$:** กระแสไหลกลับต้องวิ่งอ้อมร่องแยกเป็นระยะทางไกลถึง $45 \text{ mm}$ เพื่อหาทางกลับผ่านจุดต่อ Star Ground จุดเดียว เกิดลูปเสาอากาศขนาดใหญ่ที่แผ่คลื่น 100 MHz และสร้าง Common Return Noise ขนาด **$220 \text{ mV}$** กวนลงบนขากราวด์ของวงจรอนาล็อก ทำให้ SNR ของระบบร่วงหล่นลงถึง $38 \text{ dB}$

---

### ขั้นตอนการแก้ปัญหาและควบคุม Return Path สไตล์ Senior (検図チェックリスト):
1. **ยกเลิกการตัดผ่า Split Ground Plane (Unified Solid Ground Best Practice):**
   - **กฎเหล็กของระบบ High-Speed ยุคใหม่:** ห้ามตัดผ่าร่องกราวด์แยก AGND/DGND เด็ดขาด! ให้ใช้ **Solid Ground Plane ผืนเดียวต่อเนื่อง $100\%$** ทั่วทั้งบอร์ด
   - การแยกโซน Analog และ Digital ให้ใช้วิธี **"Partitioning by Placement (การจัดวางตำแหน่งเชิงกายภาพ)"** โดยวางอุปกรณ์ Analog ไว้ฝั่งหนึ่ง และ Digital ไว้อีกฝั่งหนึ่ง กระแสไหลกลับความถี่สูงจะวิ่งอยู่ใต้ลายวงจรของตัวเองโดยธรรมชาติ ไม่ไหลข้ามไปรบกวนโซนอื่น
2. **กรณีจำเป็นต้องเปลี่ยนเลเยอร์ข้ามระนาบอ้างอิง (Layer Transition Rule):**
   - **กรณีเปลี่ยนเลเยอร์ระหว่างกราวด์เดียวกัน (GND to GND Transition):**  
     ต้องเจาะ **GND Return Stitching Via** ขนาบข้าง Signal Via ในระยะห่างไม่เกิน **$0.5 \text{ mm} \ (20 \text{ mil})$**
   - **กรณีเปลี่ยนเลเยอร์ข้ามระนาบต่างชนิด (GND to PWR Plane Transition):**  
     ต้องวาง **Stitching Capacitor (ขนาด 0.1 $\mu$F หรือ 0.01 $\mu$F ในตัวถัง 0201/0402)** เชื่อมระหว่าง GND และ PWR ในจุดที่ใกล้กับ Signal Via มากที่สุด เพื่อสร้างทางผ่านความถี่สูง (AC Return Path)
3. **การตรวจสอบ DRC "Net Antenna" และ "Return Path Violation":**
   - เปิดฟังก์ชัน Return Path Analysis ในโปรแกรม EDA (เช่น Altium / Cadence Allegro Sigrity) เพื่อสแกนหาจุดที่ลายวงจรวิ่งเฉียดขอบระนาบ หรือวิ่งข้ามรูเจาะกลุ่มก้อน (Void / Anti-pad Cluster) และแก้ไขทันทีก่อนปล่อยแบบ

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「100MHz SPIクロック配線がL2層スリット部（AGNDとDGNDの分離溝：幅1.0mm）を直交して跨いで配線されています。高周波帰還電流の最短経路が物理的に遮断され、約45mmの巨大な迂回ループが形成されています。これにより、ループインダクタンス急増に伴うインピーダンス不連続（TDR実測値130Ω）およびスロットアンテナ放射による放射ノイズ（100MHz高調波で規格値+15dB超過）が発生しています。プレーンスリットを廃止してベタGNDを一体化（結合）するか、配線層を完全なGNDプレーンで挟まれた内層L3層へ変更してください。」  
> *(สาย SPI Clock 100MHz วิ่งข้ามรอยผ่ากราวด์ L2 กว้าง 1.0mm ระหว่าง AGND และ DGND ทำให้กระแสไหลกลับถูกตัดขาด เกิดลูปอ้อมไกลถึง 45mm ดึงให้อิมพีแดนซ์พุ่งเป็น 130 โอห์มและแผ่คลื่น EMI เกินเกณฑ์ 15dB กรุณายกเลิกการผ่ากราวด์แล้วรวมเป็นผืนเดียวกัน หรือย้ายสายลงชั้นใน L3 ที่มีกราวด์สมบูรณ์ประกบ)*

> **指摘事項 2:**  
> 「高速差動SerDesライン（L1層からL6層へのビア遷移部）において、隣接するGNDステッチングビアが配置されていません。参照プレーンがL2層GNDからL5層PWRプレーンへ切り替わる際、帰還電流が層間キャビティを迂回充放電するため、コモンリターンインピーダンスを介して隣接ビアへ強烈なクロストークを誘発しています。信号ビア対から0.4mm以内にGND-PWR間ステッチングキャパシタ（0.1μF/0201サイズ）を直近配置し、ACリターンパスを最短で確保してください。」  
> *(ในจุดเปลี่ยนเลเยอร์ของ SerDes จาก L1 ไป L6 ขาด Stitching Via ประกบข้าง เมื่อระนาบอ้างอิงเปลี่ยนจาก L2 GND ไปเป็น L5 PWR กระแสไหลกลับต้องเดินทางผ่าน Cavity ก่อให้เกิด Common Return Crosstalk สู่เวียข้างเคียง กรุณาวาง Stitching Capacitor 0.1uF ขนาด 0201 ระหว่าง GND-PWR ภายในระยะ 0.4mm จากเวียเพื่อสร้างทางไหลกลับที่สั้นที่สุด)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณการกระจายตัวของกระแสไหลกลับตามฟังก์ชัน Lorentzian)
ลายวงจรไมโครสตริปความเร็วสูงลากอยู่เหนือระนาบ Ground Plane โดยมีความสูงของชั้นไดอิเล็กทริก $H = 0.15 \text{ mm} \ (6 \text{ mil})$ จากสมการการกระจายตัวของกระแสไหลกลับ $J(x) = \frac{I_0}{\pi H} \frac{1}{1 + (x/H)^2}$ ถามว่าสัดส่วนของกระแสไหลกลับทั้งหมดที่ไหลอยู่ภายในกรอบความกว้างระหว่าง $x = -H$ ถึง $x = +H$ (ความกว้างรวม $2H = 0.30 \text{ mm}$) คิดเป็นเปอร์เซ็นต์เท่าใดของกระแสรวมทั้งหมด ($I_0$)?

- **ก)** คิดเป็น $25.0\%$ ของกระแสทั้งหมด
- **ข)** คิดเป็น $50.0\%$ ของกระแสทั้งหมด
- **ค)** คิดเป็น $75.0\%$ ของกระแสทั้งหมด
- **ง)** คิดเป็น $99.9\%$ ของกระแสทั้งหมด

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> คำนวณหาปริมาณกระแสรวมที่ไหลในช่วง $-H$ ถึง $+H$ โดยการอินทิเกรตฟังก์ชันความหนาแน่น $J(x)$:  
> $$I_{(-H \to H)} = \int_{-H}^{+H} J(x) \, dx = \int_{-H}^{+H} \frac{I_0}{\pi H} \frac{1}{1 + (x/H)^2} \, dx$$  
> กำหนดให้ตัวแปร $u = x/H \implies dx = H \, du$:  
> $$I_{(-H \to H)} = \frac{I_0}{\pi H} \int_{-1}^{+1} \frac{1}{1 + u^2} (H \, du) = \frac{I_0}{\pi} \left[ \arctan(u) \right]_{-1}^{+1}$$  
> แทนค่าขอบเขตบนและล่าง:  
> $$I_{(-H \to H)} = \frac{I_0}{\pi} \left[ \arctan(1) - \arctan(-1) \right] = \frac{I_0}{\pi} \left[ \frac{\pi}{4} - \left( -\frac{\pi}{4} \right) \right] = \frac{I_0}{\pi} \left( \frac{\pi}{2} \right) = \mathbf{\frac{1}{2} I_0 = 50.0\%}$$  
> ผลลัพธ์นี้พิสูจน์ให้เห็นอย่างชัดเจนว่า **ครึ่งหนึ่งของกระแสไหลกลับทั้งหมด (50%)** กระจุกตัวอยู่ใต้สายส่งในแถบแคบๆ เพียงระยะ $\pm H$ เท่านั้น! หากมีรอยตัดหรือรอยเว้าในระยะนี้ สนามแม่เหล็กไฟฟ้าจะเสียสมดุลทันที

---

### ข้อที่ 2 (ทำไมการผ่าแยกระนาบกราวด์ AGND และ DGND จึงกลายเป็น Bad Practice ในระบบไฮสปีด?)
เหตุใดในทฤษฎีการออกแบบบอร์ดความเร็วสูงและสัญญาณผสม (Mixed-Signal PCB) ในปัจจุบัน การผ่าร่องแยก Ground Plane ออกเป็นสองชิ้น (Split AGND/DGND) จึงถูกจัดให้เป็นแนวปฏิบัติที่อันตรายและไม่แนะนำให้ทำ (Anti-Pattern / Bad Practice)?

- **ก)** เพราะโรงงานคิดราคาค่าผลิตแผ่นวงจรแพงขึ้นหากมีการตัดระนาบกราวด์
- **ข)** เพราะหากมีสายสัญญาณดิจิทัลใดๆ เผลอวิ่งข้ามรอยแยก กระแสไหลกลับจะถูกบังคับให้อ้อมไกล เกิดลูปเหนี่ยวนำขนาดยักษ์ กลายเป็นเสาอากาศปล่อยคลื่นรบกวน EMI มหาศาล และฉีดสัญญาณรบกวนผ่าน Common Return Impedance เข้าสู่กราวด์อนาล็อกโดยตรง
- **ค)** เพราะทองแดงบนระนาบกราวด์จะเกิดการออกซิไดซ์อย่างรวดเร็วที่ขอบร่อง
- **ง)** เพราะตัวประมวลผล ADC จะไม่ยอมบูตหากตรวจพบรอยผ่ากราวด์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในอดีตยุคสัญญาณความถี่ต่ำ การแยกกราวด์ช่วยป้องกันกระแส DC กวนกัน  
> แต่ในยุคดิจิทัลความเร็วสูง ($dV/dt$ และ $dI/dt$ สูง):  
> เมื่อใดก็ตามที่มีสัญญาณดิจิทัล (แม้แต่สายควบคุมธรรมดา เช่น CS, RESET, SPI) วิ่งข้ามรอยผ่า กระแสไหลกลับความถี่สูงจะไม่สามารถวิ่งข้ามร่องได้ และถูกบังคับให้อ้อมไปตามขอบร่องเป็นระยะทางหลายเซนติเมตร  
> ลูปขนาดมหึมานี้จะทำหน้าที่เป็นเสาอากาศแบบ Slot Antenna แผ่รังสีคลื่นแม่เหล็กไฟฟ้าพลังงานสูง และสร้างแรงดันตกคร่อม $\Delta V = L \frac{dI}{dt}$ ผลักสัญญาณรบกวนความถี่สูงกระจายไปทั่วทั้งระนาบกราวด์อนาล็อก  
> แนวทางที่ถูกต้องตามมาตรฐาน Senior Engineer คือการใช้ **Solid Ground ผืนเดียวต่อเนื่อง** และควบคุมกระแสด้วยการจัดวางตำแหน่งอุปกรณ์ (Layout Partitioning) ให้เป็นสัดส่วน

### ข้อที่ 3 (การทำหน้าที่ของ Stitching Capacitor เมื่อสัญญาณเปลี่ยนเลเยอร์ข้ามระนาบ Ground ไป Power)
เมื่อสายสัญญาณความเร็วสูงมุดเปลี่ยนเลเยอร์จาก Layer 1 (ซึ่งอ้างอิงระนาบ Ground บน Layer 2) ไปยัง Layer 6 (ซึ่งอ้างอิงระนาบ Power Plane บน Layer 5) การต่อตัวเก็บประจุ Stitching Capacitor เชื่อมระหว่าง Ground และ Power ใกล้จุดเจาะ Via ช่วยป้องกัน Crosstalk ได้อย่างไร?

- **ก)** ช่วยลดระดับแรงดันของ Power Plane ให้กลายเป็นศูนย์โวลต์เท่ากับ Ground
- **ข)** ทำหน้าที่เป็นทางผ่านอิมพีแดนซ์ต่ำสำหรับความถี่สูง (Low-Impedance AC Return Path) ให้กระแสไหลกลับสามารถเปลี่ยนผ่านระหว่างระนาบ Ground และ Power ได้ทันทีในจุดนั้น โดยไม่ต้องวิ่งกระจัดกระจายไปทั่วทั้งบอร์ด
- **ค)** ช่วยกรองสัญญาณฮาร์มอนิกของสัญญาณหลักทิ้งไปลงกราวด์
- **ง)** ช่วยป้องกันไม่ให้ทองแดงในกระบอก Via เกิดความร้อนสะสม

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> เมื่อสัญญาณเปลี่ยนเลเยอร์ กระแสไหลกลับก็ต้องเปลี่ยนระนาบอ้างอิงตามไปด้วย  
> แต่เนื่องจากระนาบทั้งสองมีระดับศักย์ไฟตรงต่างกัน (GND $= 0\text{V}$, PWR $= 3.3\text{V}$) จึงไม่สามารถใช้ Via ต่อชอร์ตเข้าหากันตรงๆ ได้  
> หากไม่มีตัวเชื่อมต่อ กระแสไหลกลับความถี่สูงจะต้องเดินทางไปหาตัวเก็บประจุ Decoupling Capacitor ที่อยู่ไกลออกไป หรือวิ่งอัดประจุผ่านระนาบคู่ขนาน (Cavity Resonance) เกิดการเหนี่ยวนำข้ามไประเบิดสัญญาณรบกวนใส่ทุก Via ในบริเวณนั้น  
> การวาง **Stitching Capacitor** (ขนาด $0.1 \ \mu\text{F}$) ไว้ประชิดกับ Signal Via จะทำหน้าที่เสมือน "สะพานเชื่อมไฟฟ้ากระแสสลับ (AC Short Circuit)" ที่มีความต้านทานเชิงซ้อนต่ำมากที่ความถี่สูง ($Z = \frac{1}{2\pi f C} \approx 0$) เปิดทางให้กระแสไหลกลับกระโดดข้ามระหว่างระนาบได้อย่างราบรื่น กำจัดลูปเหนี่ยวนำและป้องกัน Common Return Crosstalk ได้อย่างสมบูรณ์
