## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในวงจรอิเล็กทรอนิกส์ดิจิทัลความเร็วสูง ตัวเก็บประจุเซรามิกหลายชั้น (Multilayer Ceramic Capacitor: MLCC) ไม่สามารถมองเป็นตัวเก็บประจุในอุดมคติ ($C$) ได้ แต่เป็นโครงสร้างทางกายภาพที่ประกอบด้วยแผ่นอิเล็กโทรดโลหะซ้อนทับกัน คั่นด้วยชั้นไดอิเล็กทริกเซรามิก ซึ่งแสดงพฤติกรรมเป็น **อนุกรม RLC (Series RLC Equivalent Circuit)** ตามสมการอิมพีแดนซ์เชิงซ้อน:

$$Z(s) = ESR + s \cdot ESL + \frac{1}{s \cdot C_{eff}} \quad \text{โดยที่ } s = j\omega = j 2\pi f$$

$$|Z(f)| = \sqrt{ ESR^2 + \left( 2\pi f \cdot ESL - \frac{1}{2\pi f \cdot C_{eff}} \right)^2 }$$

```
+-------------------------------------------------------------+
|               Real MLCC Equivalent Circuit                  |
|                                                             |
|           ESL             ESR             C_eff             |
|   ───o───UUUUU──────────/\/\/\─────────────┤├───o───        |
|      (0.1 - 1.5 nH)  (1 - 50 mOhm)    (DC-Biased C)         |
|                                                             |
|   At Low Frequency (f < SRF)  : Dominantly Capacitive (1/ωC)|
|   At Resonant Point (f = SRF) : Minimum Impedance = ESR     |
|   At High Frequency (f > SRF) : Dominantly Inductive (ω·ESL)|
+-------------------------------------------------------------+
```

### 1.1 ความถี่เรโซแนนซ์เฉพาะตัว (Self-Resonant Frequency: SRF) และพฤติกรรมสองบุคลิก

ที่ความถี่เรโซแนนซ์เฉพาะตัว (SRF) ค่ารีแอกแตนซ์ของความจุ ($X_C = \frac{1}{2\pi f C}$) จะหักล้างกับค่ารีแอกแตนซ์ของความเหนี่ยวนำ ($X_L = 2\pi f ESL$) พอดี:

$$f_{SRF} = \frac{1}{2\pi \sqrt{ESL \cdot C_{eff}}}$$

- **ต่ำกว่า $f_{SRF}$ ($f < f_{SRF}$):** ตัวเก็บประจุทำงานเป็นตัวเก็บประจุแท้ โดยอิมพีแดนซ์ลดลงด้วยความชัน $-20\text{ dB/decade}$
- **ณ จุด $f_{SRF}$ ($f = f_{SRF}$):** อิมพีแดนซ์มีค่าต่ำสุดเท่ากับ **$ESR$ (Equivalent Series Resistance)** ล้วนๆ
- **สูงกว่า $f_{SRF}$ ($f > f_{SRF}$):** **ตัวเก็บประจุจะกลายสภาพเป็นตัวเหนี่ยวนำ (Inductor)** โดยอิมพีแดนซ์จะไต่ระดับสูงขึ้นด้วยความชัน $+20\text{ dB/decade}$ ตามกฎของ $2\pi f \cdot ESL$ ซึ่งหมายความว่า ตัวเก็บประจุจะไม่สามารถดึงสัญญาณรบกวนความถี่สูงลงกราวด์ได้อีกต่อไป!

### 1.2 ฟิสิกส์ของสารไดอิเล็กทริกและหายนะของ DC Bias Derating

ไดอิเล็กทริกเซรามิกที่ใช้ในอุตสาหกรรมแบ่งออกเป็น 2 กลุ่มหลักตามมาตรฐาน EIA:

1. **Class I Dielectrics (เช่น C0G / NP0):**
   - ใช้วัสดุพาราอิเล็กทริก (Titanium Dioxide: $\text{TiO}_2$)
   - ความจุไฟฟ้ามีความเสถียรสูงสุด: ไม่เปลี่ยนแปลงตามแรงดันไฟตรง ($\Delta C_{DC} = 0\%$), ไม่เปลี่ยนตามอุณหภูมิ ($\pm 30\text{ ppm/}^{\circ}\text{C}$), และไม่มี Aging
   - ข้อจำกัด: ค่าคงที่ไดอิเล็กทริกต่ำ ($\varepsilon_r \approx 20 - 100$) ทำให้ทำค่าความจุได้น้อย (มักไม่เกิน $10 - 100\text{ nF}$) จึงไม่เหมาะกับงาน Power Rail Decoupling ที่ต้องการความจุสูง

2. **Class II Dielectrics (เช่น X5R, X7R, X8R):**
   - ใช้วัสดุเฟอร์โรอิเล็กทริก (Barium Titanate: $\text{BaTiO}_3$)
   - ให้ค่าคงที่ไดอิเล็กทริกสูงมาก ($\varepsilon_r \approx 1,500 - 3,000$) ทำให้ผลิตตัวเก็บประจุความจุสูงในขนาดจิ๋วได้ ($1\ \mu\text{F} - 100\ \mu\text{F}$)
   - **กลไกความล้มเหลวทางฟิสิกส์ (DC Bias Degradation):** โครงสร้างผลึกของ $\text{BaTiO}_3$ ประกอบด้วยสปอนทาเนียสดิโพล (Spontaneous Electric Dipoles) เมื่อถูกป้อนแรงดันไฟฟ้ากระแสตรง (DC Bias Voltage) ขั้วไฟฟ้าจะถูกสนามไฟฟ้าบังคับให้หมุนไปในทิศทางเดียวกันจนเกิดการอิ่มตัว (Dipole Saturation) ส่งผลให้ความสามารถในการสะสมประจุเพิ่มเติมลดฮวบลงอย่างรุนแรง

```
Capacitance Retention (%)
  100% ────┐
           │ (C0G / NP0: Flat 100% stable)
   80% ────┼─────────────────────────────────────────────
           │\
   60% ────┼─\
           │  \  (X7R / X5R in Large Package e.g. 1206)
   40% ────┼───\
           │    \──────────────── (X7R in Small Package 0402/0603)
   20% ────┼─────\_______________ (Drops by 70% - 85% at Rated Voltage!)
           │
    0% ────┴──────┬────────┬────────┬────────► DC Bias Voltage (V)
                 0V       2.5V     5.0V
```

**ตัวอย่างจริงในอุตสาหกรรม:**
ตัวเก็บประจุ MLCC เกรด X5R ขนาด 0402 ค่า $10\ \mu\text{F}$ พิกัดแรงดัน $6.3\text{ V}$:
- เมื่อทำงานที่แรงดัน $0\text{ V DC}$: ความจุ $= 10.0\ \mu\text{F}$ ($100\%$)
- เมื่อป้อนแรงดัน $1.8\text{ V DC}$: ความจุลดลงเหลือ $\approx 5.5\ \mu\text{F}$ (หายไป $45\%$)
- เมื่อป้อนแรงดัน $3.3\text{ V DC}$: ความจุลดลงเหลือ $\approx 2.8\ \mu\text{F}$ (หายไป $72\%$)
- เมื่อป้อนแรงดัน $5.0\text{ V DC}$: ความจุลดลงเหลือเพียง $\approx 1.6\ \mu\text{F}$ **(ความจุหายไปถึง $84\%$!)**

หากวิศวกรออกแบบระบบจ่ายไฟ $3.3\text{ V}$ โดยสมมติว่ามีตัวเก็บประจุ $10\ \mu\text{F}$ แต่ความจุจริงเหลือเพียง $2.8\ \mu\text{F}$ ระบบจะเกิดแรงดันตกคร่อมรุนแรงจนบอร์ดล้มเหลวทันที

### 1.3 ปัญหาเสียงร้องของตัวเก็บประจุ (Acoustic Noise / Singing Capacitors)

สารเฟอร์โรอิเล็กทริก $\text{BaTiO}_3$ มีคุณสมบัติไพอีโซอิเล็กทริกและอิเล็กโทรสตริกชัน (Piezoelectric & Electrostriction Effect) เมื่อมีแรงดันริปเปิลความถี่เสียง ($20\text{ Hz} - 20\text{ kHz}$) เช่น ความถี่ประหยัดพลังงาน Pulse-Skipping Mode (PSM) ของชิปสวิตชิ่ง ตัวถังเซรามิกจะเกิดการยืดหดตัวในแนวแกน $z$ และ $x-y$ 

การสั่นสะเทือนระดับไมโครมิเตอร์นี้จะถูกส่งผ่านจุดบัดกรีลงสู่แผ่น PCB โดยแผ่น PCB จะทำตัวเสมือน "แผ่นไดอะแฟรมของลำโพง" แผ่คลื่นเสียงความถี่สูง ($3\text{ kHz} - 10\text{ kHz}$) ออกมาเป็นเสียงหวีดแหลมที่มนุษย์ได้ยิน (Acoustic Noise / 鳴き - Naki) ซึ่งเป็นข้อบกพร่องที่ยอมรับไม่ได้ในอุปกรณ์พกพาและยานยนต์ระดับพรีเมียม

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน: 失敗事例 (Shippai Jirei)

**เหตุการณ์:** บอร์ดกล้องอัจฉริยะช่วยขับขี่ระดับยานยนต์ (Automotive ADAS Forward Camera Module) ใช้เซนเซอร์ภาพ CMOS ระดับ 8 ล้านพิกเซล รางไฟแอนะล็อก $V_{DDA} = 2.8\text{ V}$ มีวงจร Point-of-Load (PoL) Step-down Regulator จ่ายกระแส $1.2\text{ A}$ 

**อาการล้มเหลว:**
1. ในขั้นตอนการประเมินคุณภาพของภาพ (Image Quality Verification) พบสัญญาณรบกวนลายทางแนวนอนเคลื่อนที่ (Horizontal Rolling Banding Noise) ปรากฏบนเฟรมภาพอย่างเด่นชัด โดยเฉพาะเมื่อกล้องทำงานในสภาพแสงน้อย
2. เมื่อทดสอบในห้องเก็บเสียง (Anechoic Chamber) ขณะที่ระบบปรับอัตราประมวลผลตามโหลด มีเสียงหวีดความถี่ประมาณ $6.5\text{ kHz}$ ดังออกมาจากบริเวณตัวเก็บประจุเอาต์พุตของภาคจ่ายไฟ
3. เมื่อตรวจสอบแรงดันริปเปิลบนเส้น $V_{DDA}$ ด้วยออสซิลโลสโคป พบว่ามีแรงดันกระเพื่อมสูงถึง $48\text{ mV}_{\text{p-p}}$ (สเปกของ Image Sensor ระบุว่าต้องไม่เกิน $15\text{ mV}_{\text{p-p}}$) ทั้งที่ในแบบแปลนมีตัวเก็บประจุ MLCC ขนาด 0603 ค่า $22\ \mu\text{F}$ ติดตั้งอยู่ถึง 3 ตัว (ความจุรวมตามแบบ $= 66\ \mu\text{F}$)

```
[Failure Mechanism: Extreme DC Bias Drop & Acoustic Sing]
  Schematic Design:   3x 22µF (0603, 6.3V, X5R) = 66µF Nominal
  Actual 2.8V Bias:   Each drops to only 4.2µF!
  True Capacitance:   3x 4.2µF = 12.6µF Total! (Lost 81% capacitance!)
  Result:             Ripple tripled (15mV -> 48mV) + 6.5kHz Piezo Whine!
```

**Root Cause Analysis (RCA):**
1. **การละเลย DC Bias Characteristic:** วิศวกรเลือกใช้ตัวเก็บประจุเกรดราคาประหยัด $22\ \mu\text{F}$ ขนาดกะทัดรัด 0603 พิกัดแรงดันเพียง $6.3\text{ V}$ เมื่อนำมาใช้งานที่แรงดันจริง $V_{DDA} = 2.8\text{ V}$ ผลกระทบจาก DC Bias ทำให้ความจุต่อตัวร่วงลงจาก $22\ \mu\text{F}$ เหลือเพียง **$4.2\ \mu\text{F}$** เท่านั้น ความจุรวมจริงทั้งบอร์ดจึงเหลือเพียง $12.6\ \mu\text{F}$ ส่งผลให้แรงดันริปเปิลของวงจรเรกูเลเตอร์พุ่งสูงขึ้นกว่าที่คำนวณไว้ในแบบจำลองถึง 3 เท่า
2. **การสั่นสะเทือนแบบ Piezoelectric ที่ความถี่สวิตชิ่ง:** ตัวแปลงแรงดันทำงานในโหมดประหยัดพลังงานที่ความถี่โหลดต่ำ $6.5\text{ kHz}$ แรงดันริปเปิลกระตุ้นให้ผลึกเซรามิกสั่นสะเทือน และเนื่องจากตัวเก็บประจุทั้งสามตัวถูกวางหันหน้าในทิศทางเดียวกันตรงกึ่งกลางบอร์ด PCB ซึ่งเป็นจุดที่มีค่าความแข็งเกร็งเชิงกลต่ำสุด (Mechanical Anti-node) แผ่นบอร์ดจึงขยายเสียงสั่นสะเทือนกลายเป็นเสียงหวีดแหลม

### Step-by-Step Engineering Checklist: การเลือก MLCC และการลดทอน ESL/Acoustic Noise

#### ขั้นตอนที่ 1: การคำนวณชดเชยค่าความจุจาก DC Bias (Derating Calculation Protocol)
ก่อนกำหนดรหัสชิ้นส่วน (Part Number) ลงใน BOM:
- **ห้ามเชื่อค่า Nominal บน Datasheet:** ให้เข้าไปดาวน์โหลดกราฟ DC Bias Characteristics จากเว็บไซต์ผู้ผลิต (เช่น Murata SimSurfing, TDK Components Center, Taiyo Yuden)
- **กฎ 2 เท่าของแรงดันใช้งาน (Voltage Rating Margin Rule):**
  - รางไฟ $1.2\text{ V} - 1.8\text{ V} \implies$ เลือกพิกัดแรงดันขั้นต่ำอย่างน้อย **$6.3\text{ V}$ หรือ $10\text{ V}$**
  - รางไฟ $3.3\text{ V} \implies$ เลือกพิกัดแรงดันขั้นต่ำอย่างน้อย **$10\text{ V}$ หรือ $16\text{ V}$**
  - รางไฟ $5.0\text{ V} \implies$ เลือกพิกัดแรงดันขั้นต่ำอย่างน้อย **$16\text{ V}$ หรือ $25\text{ V}$**
- **เลือก Package Size ให้เหมาะสม:** หากบอร์ดมีพื้นที่ว่าง การขยับขนาดตัวถังจาก 0402 เป็น 0603 หรือจาก 0603 เป็น 0805 ที่ค่าความจุเท่ากัน จะทำให้ความหนาของชั้นไดอิเล็กทริกหนาขึ้น สนามไฟฟ้า ($E = V/d$) อ่อนลง ส่งผลให้อัตราการสูญเสียความจุจาก DC Bias ลดลงอย่างมีนัยสำคัญ

```
+-------------------------------------------------------------+
|  Package Size vs DC Bias Retention (at 5V DC Bias, 10µF Cap)|
|                                                             |
|  0402 Package: Retains only ~15% - 20% (C_eff ~ 1.8 µF)     |
|  0603 Package: Retains ~35% - 45%       (C_eff ~ 4.0 µF)    |
|  0805 Package: Retains ~60% - 70%       (C_eff ~ 6.5 µF)    |
|  1206 Package: Retains ~75% - 85%       (C_eff ~ 8.0 µF)    |
+-------------------------------------------------------------+
```

#### ขั้นตอนที่ 2: การเลือกใช้ตัวเก็บประจุแบบลดความเหนี่ยวนำ (Low-ESL Architectures)
สำหรับจุด Decoupling ความถี่สูงบนรางไฟคอร์ความเร็วสูง:
- **Standard Geometry (0603):** ขั้วต่ออยู่ด้านสั้น ระยะทางที่กระแสเดินทางยาว $\implies ESL \approx 0.8 - 1.0\text{ nH}$
- **Reverse Geometry (0306):** ขั้วต่ออยู่ด้านยาว (Wide Terminations) ระยะทางที่กระแสเดินทางสั้นลงและพื้นที่หน้าตัดกว้างขึ้น $\implies ESL \approx 0.15 - 0.25\text{ nH}$ **(ลดลงได้ถึง $70\%$!)**
- **Three-Terminal Feedthrough MLCCs:** ออกแบบให้กระแสโหลดไหลทะลุผ่านตัวเก็บประจุ ก่อให้เกิดการหักล้างของสนามแม่เหล็ก (Flux Cancellation) มีค่า ESL ต่ำเป็นพิเศษ ($< 0.05\text{ nH}$) ตอบสนองความถี่ได้ลึกถึงระดับหลายร้อยเมกะเฮิรตซ์

```
Standard (0603):                  Reverse Geometry (0306):
┌──────┬──────────────┬──────┐    ┌──────────────────────────┐
│ Term │              │ Term │    │     Top Termination      │
│  (+) │   Dielectric │  (-) │    ├──────────────────────────┤
│      │              │      │    │        Dielectric        │
└──────┴──────────────┴──────┘    ├──────────────────────────┤
 <─── Current travels ───>        │    Bottom Termination    │
        Long path!                └──────────────────────────┘
       (High ESL)                   Current travels short path!
                                           (Ultra-Low ESL!)
```

#### ขั้นตอนที่ 3: มาตรการป้องกันและกำจัดเสียงร้องของตัวเก็บประจุ (Anti-Acoustic Solutions)
- **การจัดวางแบบสมมาตรหันหลังชนกัน (Back-to-Back Layout):** วางตัวเก็บประจุ 2 ตัวขนานกันโดยตัวหนึ่งอยู่บน Top Layer และอีกตัวอยู่ตรงข้ามกันพอดีบน Bottom Layer แรงสั่นสะเทือนจะหักล้างกันเองในเนื้อบอร์ด
- **วางในแนวขนานกับขอบบอร์ด:** หลีกเลี่ยงการวางตัวเก็บประจุตรงกึ่งกลางแผ่น PCB ซึ่งเป็นจุดที่มีการโก่งตัวสูงสุด ให้เลื่อนไปวางใกล้จุดยึดสกรู (Mounting Holes) ที่มีความแข็งเกร็งสูง
- **ใช้ตัวเก็บประจุประเภท Metal Cap / Interposer Frame:** เลือกใช้ MLCC ที่มีขาโลหะรองรับ (Metal Terminal / Lead-frame MLCC) หรือรุ่น Acoustic Noise Suppressed ซึ่งขารองรับจะทำหน้าที่เป็นโช้คอัพดูดซับแรงสั่นสะเทือน ไม่ให้ส่งผ่านลงสู่แผ่น PCB

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### คำถามที่ 1: การคำนวณความจุประสิทธิผลจริงและจุดเรโซแนนซ์ใหม่ภายใต้อิทธิพลของ DC Bias

วิศวกรออกแบบระบบจ่ายไฟสำหรับชิป FPGA รางไฟ $V_{CCO} = 3.3\text{ V}$ โดยเลือกใช้ตัวเก็บประจุ MLCC เกรด X7R ขนาด 0603 ค่าความจุระบุ $C_{nom} = 10\ \mu\text{F}$ พิกัดแรงดัน $V_{rated} = 6.3\text{ V}$ มีค่าความเหนี่ยวนำภายในตัวถัง $ESL = 0.5\text{ nH}$ และมีค่าความต้านทาน $ESR = 4.0\text{ m}\Omega$

จากกราฟสเปก DC Bias ของผู้ผลิต สมการประมาณการการลดลงของความจุภายใต้แรงดันไบแอส $V$ คือ:

$$\frac{C(V)}{C_{nom}} = \frac{1}{1 + \left( \frac{V}{V_{0.5}} \right)^2}$$

โดยที่พารามิเตอร์ของตัวถังนี้คือ $V_{0.5} = 2.2\text{ V}$ (แรงดันที่ทำให้ความจุลดลงเหลือ $50\%$)

จงคำนวณ:
1. ค่าความจุประสิทธิผลจริง ($C_{eff}$) เมื่อตัวเก็บประจุทำงานที่แรงดันไฟตรง $3.3\text{ V}$
2. ความถี่เรโซแนนซ์เฉพาะตัวในอุดมคติ ($f_{SRF, ideal}$) ที่แรงดัน $0\text{ V}$ เทียบกับความถี่เรโซแนนซ์จริง ($f_{SRF, biased}$) ที่แรงดัน $3.3\text{ V}$
3. อิมพีแดนซ์ของตัวเก็บประจุที่ความถี่ $1.0\text{ MHz}$ เปรียบเทียบระหว่างสภาวะไม่มีไฟตรง ($0\text{ V}$) กับสภาวะมีไฟตรง ($3.3\text{ V}$)?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความจุประสิทธิผลจริงที่ $3.3\text{ V}$ ($C_{eff}$):**
$$C_{eff} = C_{nom} \cdot \frac{1}{1 + \left( \frac{V}{V_{0.5}} \right)^2}$$
- อัตราส่วนแรงดัน:
  $$\frac{V}{V_{0.5}} = \frac{3.3\text{ V}}{2.2\text{ V}} = 1.50$$
- ตัวหาร:
  $$1 + (1.50)^2 = 1 + 2.25 = 3.25$$
- ความจุประสิทธิผล:
  $$C_{eff} = \frac{10\ \mu\text{F}}{3.25} \approx 3.077\ \mu\text{F}$$
  *(ความจุหายไปเกือบ $70\%$!)*

**2. คำนวณความถี่ Self-Resonant Frequency (SRF):**
- **สภาวะในอุดมคติที่ $0\text{ V}$ ($C = 10\ \mu\text{F} = 1.0 \times 10^{-5}\text{ F}$, $ESL = 0.5\text{ nH} = 5.0 \times 10^{-10}\text{ H}$):**
  $$f_{SRF, ideal} = \frac{1}{2\pi \sqrt{ESL \cdot C_{nom}}} = \frac{1}{2\pi \sqrt{(5.0 \times 10^{-10}) \cdot (1.0 \times 10^{-5})}} = \frac{1}{2\pi \sqrt{5.0 \times 10^{-15}}}$$
  $$f_{SRF, ideal} \approx \frac{1}{2\pi \times 7.071 \times 10^{-8}} \approx 2.251\text{ MHz}$$

- **สภาวะจริงที่ $3.3\text{ V}$ ($C_{eff} = 3.077\ \mu\text{F} = 3.077 \times 10^{-6}\text{ F}$):**
  $$f_{SRF, biased} = \frac{1}{2\pi \sqrt{ESL \cdot C_{eff}}} = \frac{1}{2\pi \sqrt{(5.0 \times 10^{-10}) \cdot (3.077 \times 10^{-6})}} = \frac{1}{2\pi \sqrt{1.5385 \times 10^{-15}}}$$
  $$f_{SRF, biased} \approx \frac{1}{2\pi \times 3.922 \times 10^{-8}} \approx 4.058\text{ MHz}$$

ความถี่เรโซแนนซ์เลื่อนขึ้นจาก $2.25\text{ MHz}$ ไปเป็น **$4.06\text{ MHz}$** ซึ่งจะทำให้แผนผังการควบคุมอิมพีแดนซ์ที่วางไว้เบี่ยงเบนไปทั้งหมด!

**3. คำนวณอิมพีแดนซ์ที่ความถี่ $1.0\text{ MHz}$ ($f = 10^6\text{ Hz}$):**
ที่ความถี่ $1.0\text{ MHz}$ (ต่ำกว่า SRF ทั้งคู่) ค่าอิมพีแดนซ์ถูกครอบงำด้วยคาปาซิทีฟรีแอกแตนซ์เป็นหลัก ($|Z| \approx \frac{1}{2\pi f C}$):
- **กรณี $0\text{ V}$ ($C = 10\ \mu\text{F}$):**
  $$|Z_{ideal}| \approx \frac{1}{2\pi \times (10^6) \times (10 \times 10^{-6})} = \frac{1}{2\pi \times 10^{-1}} \approx 0.0159\ \Omega = 15.9\text{ m}\Omega$$
- **กรณี $3.3\text{ V}$ ($C_{eff} = 3.077\ \mu\text{F}$):**
  $$|Z_{biased}| \approx \frac{1}{2\pi \times (10^6) \times (3.077 \times 10^{-6})} = \frac{1}{2\pi \times 3.077 \times 10^{-2}} \approx 0.0517\ \Omega = 51.7\text{ m}\Omega$$

**บทสรุปของ Senior Engineer:**
- ที่ความถี่ $1.0\text{ MHz}$ อิมพีแดนซ์ของตัวเก็บประจุ **พุ่งสูงขึ้นกว่าเดิมถึง $3.25$ เท่า** (จาก $15.9\text{ m}\Omega$ เป็น $51.7\text{ m}\Omega$)
- การไม่คิดผลกระทบของ DC Bias จะทำให้ความสามารถในการบายพาสกระแสริปเปิลแย่ลงกว่าการคำนวณทางทฤษฎีมากกว่า 3 เท่าตัว

### คำถามที่ 2: การเปรียบเทียบเชิงปริมาณของ ESL ระหว่าง Standard MLCC, Reverse Geometry, และ 3-Terminal Cap

ระบบประมวลผลความเร็วสูงทำงานที่ความถี่ฮาร์โมนิกของสัญญาณนาฬิกา $f = 80\text{ MHz}$ วิศวกรกำลังพิจารณาตัวเลือกตัวเก็บประจุ 3 ชนิดที่มีความจุระบุเท่ากันคือ $C = 1.0\ \mu\text{F}$ เพื่อนำมาต่อเป็น Decoupling:

1. **ชนิด A (Standard 0603 MLCC):** มีค่า $ESL_A = 0.85\text{ nH}$, $ESR_A = 8\text{ m}\Omega$
2. **ชนิด B (Reverse Geometry 0306 MLCC):** มีค่า $ESL_B = 0.18\text{ nH}$, $ESR_B = 4\text{ m}\Omega$
3. **ชนิด C (Three-Terminal Feedthrough MLCC):** มีค่า $ESL_C = 0.04\text{ nH}$, $ESR_C = 3\text{ m}\Omega$

สมมติให้โครงสร้างรูเจาะ Via บนบอร์ดสร้างความเหนี่ยวนำเพิ่มขึ้นอีก $L_{mounting} = 0.30\text{ nH}$ เท่ากันทุกชนิด (ยกเว้นชนิด C ที่ใช้โครงสร้าง Feedthrough พิเศษทำให้ $L_{mounting, C} \approx 0.08\text{ nH}$)

จงคำนวณ:
1. ความเหนี่ยวนำรวมจริงเมื่อประกอบลงบอร์ด ($L_{total} = ESL + L_{mounting}$) ของทั้ง 3 ชนิด
2. อิมพีแดนซ์รวม ($|Z|$) ของแต่ละชนิดที่ความถี่ $80\text{ MHz}$
3. หากรางไฟมี Target Impedance ที่ $80\text{ MHz}$ เท่ากับ $Z_{target} = 50\text{ m}\Omega$ จะต้องใช้ตัวเก็บประจุชนิด A, B, และ C ขนานกันกี่ตัวจึงจะกดให้อิมพีแดนซ์ต่ำกว่าเกณฑ์ได้?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความเหนี่ยวนำรวม ($L_{total}$):**
- ชนิด A: $L_{total, A} = 0.85\text{ nH} + 0.30\text{ nH} = 1.15\text{ nH} = 1.15 \times 10^{-9}\text{ H}$
- ชนิด B: $L_{total, B} = 0.18\text{ nH} + 0.30\text{ nH} = 0.48\text{ nH} = 4.80 \times 10^{-10}\text{ H}$
- ชนิด C: $L_{total, C} = 0.04\text{ nH} + 0.08\text{ nH} = 0.12\text{ nH} = 1.20 \times 10^{-10}\text{ H}$

**2. คำนวณอิมพีแดนซ์ที่ความถี่ $80\text{ MHz}$ ($f = 80 \times 10^6\text{ Hz}$):**
ที่ความถี่ $80\text{ MHz}$ ค่ารีแอกแตนซ์ของความจุ $X_C = \frac{1}{2\pi \times (80 \times 10^6) \times (1.0 \times 10^{-6})} \approx 0.00199\ \Omega \approx 2.0\text{ m}\Omega$ (มีค่าน้อยมากจนละเลยได้)
อิมพีแดนซ์ถูกครอบงำด้วยความเหนี่ยวนำ ($|Z| \approx \sqrt{ESR^2 + (2\pi f L_{total})^2} \approx 2\pi f L_{total}$):

- **สำหรับชนิด A (Standard 0603):**
  $$X_{L, A} = 2\pi \times (80 \times 10^6\text{ Hz}) \times (1.15 \times 10^{-9}\text{ H}) \approx 0.578\ \Omega = 578\text{ m}\Omega$$
  $$|Z_A| \approx \sqrt{(0.008)^2 + (0.578)^2} \approx 578.1\text{ m}\Omega$$
- **สำหรับชนิด B (Reverse Geometry 0306):**
  $$X_{L, B} = 2\pi \times (80 \times 10^6\text{ Hz}) \times (0.48 \times 10^{-9}\text{ H}) \approx 0.241\ \Omega = 241\text{ m}\Omega$$
  $$|Z_B| \approx \sqrt{(0.004)^2 + (0.241)^2} \approx 241.0\text{ m}\Omega$$
- **สำหรับชนิด C (Three-Terminal Feedthrough):**
  $$X_{L, C} = 2\pi \times (80 \times 10^6\text{ Hz}) \times (0.12 \times 10^{-9}\text{ H}) \approx 0.0603\ \Omega = 60.3\text{ m}\Omega$$
  $$|Z_C| \approx \sqrt{(0.003)^2 + (0.0603)^2} \approx 60.4\text{ m}\Omega$$

**3. คำนวณจำนวนตัวเก็บประจุขนานกันเพื่อให้อิมพีแดนซ์ $\le 50\text{ m}\Omega$:**
$$Z_{parallel} = \frac{|Z_{single}|}{N} \le 50\text{ m}\Omega \implies N \ge \frac{|Z_{single}|}{50\text{ m}\Omega}$$

- **ชนิด A:**
  $$N_A \ge \frac{578.1\text{ m}\Omega}{50\text{ m}\Omega} = 11.56 \implies \mathbf{12\ \text{ตัว}}$$
- **ชนิด B:**
  $$N_B \ge \frac{241.0\text{ m}\Omega}{50\text{ m}\Omega} = 4.82 \implies \mathbf{5\ \text{ตัว}}$$
- **ชนิด C:**
  $$N_C \ge \frac{60.4\text{ m}\Omega}{50\text{ m}\Omega} = 1.21 \implies \mathbf{2\ \text{ตัว}}$$

**บทสรุปของ Senior Engineer:**
- การใช้ Three-Terminal Feedthrough MLCC เพียง **2 ตัว** สามารถทำงานทดแทนตัวเก็บประจุมาตรฐาน 0603 จำนวน **12 ตัว** ได้อย่างสมบูรณ์
- ช่วยประหยัดพื้นที่บนแผ่น PCB ใต้ชิป BGA ได้มากกว่า $80\%$ และลดความซับซ้อนของเส้นทาง Routing ได้อย่างมหาศาล

### คำถามที่ 3: การวิเคราะห์ความเค้นและกลไกการสั่นสะเทือนของ Singing Capacitor

ตัวเก็บประจุเซรามิก 0805 ทำจากสาร $\text{BaTiO}_3$ มีค่าสัมประสิทธิ์การยืดตัวเนื่องจากสนามไฟฟ้า (Electrostrictive / Piezoelectric Coefficient) $d_{33} \approx 200\text{ pm/V} = 200 \times 10^{-12}\text{ m/V}$ ตัวถังมีความหนาของชั้นไดอิเล็กทริกระหว่างอิเล็กโทรด $t_{diel} = 10\ \mu\text{m}$ มีจำนวนชั้นซ้อนทับกัน $N = 100\text{ ชั้น}$ 

ตัวเก็บประจุนี้ติดตั้งอยู่บนรางไฟที่ถูกขับด้วยคลื่นความถี่สลับของโหมดประหยัดพลังงาน โดยมีแรงดันกระเพื่อมสลับ (AC Ripple Voltage) ขนาด $\Delta V_{AC} = 0.5\text{ V}_{\text{peak}}$ ที่ความถี่ $f = 5.0\text{ kHz}$

จงวิเคราะห์:
1. ความเครียดเชิงกล (Mechanical Strain: $\varepsilon_z = d_{33} \cdot E$) ที่เกิดขึ้นในเนื้อเซรามิก
2. ขนาดการเปลี่ยนแปลงความยาว (Displacement Amplitude: $\Delta L$) ของตัวถังในแนวแกน $z$
3. อธิบายกลไกที่ทำให้การสั่นระดับ Sub-nanometer นี้ถูกขยายจนกลายเป็นเสียงดังชัดเจนในห้องโดยสารรถยนต์ และชี้แนะ 3 แนวทางแก้ไขเชิงโครงสร้าง PCB?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความเข้มสนามไฟฟ้าและความเครียดเชิงกล:**
- สนามไฟฟ้าสลับที่เกิดขึ้นระหว่างชั้นไดอิเล็กทริก:
  $$E_{AC} = \frac{\Delta V_{AC}}{t_{diel}} = \frac{0.5\text{ V}}{10 \times 10^{-6}\text{ m}} = 50,000\text{ V/m} = 5.0 \times 10^4\text{ V/m}$$
- ความเครียดเชิงกลในแนวแกน $z$:
  $$\varepsilon_z = d_{33} \cdot E_{AC} = (200 \times 10^{-12}\text{ m/V}) \cdot (5.0 \times 10^4\text{ V/m}) = 1.0 \times 10^{-5}$$
  *(คิดเป็น $10\text{ ppm}$)*

**2. คำนวณขนาดการเปลี่ยนแปลงความยาว ($\Delta L$):**
ความหนารวมของเนื้อเซรามิกที่มีสนามไฟฟ้ากระทำ:
$$L_{total} = N \cdot t_{diel} = 100 \times (10 \times 10^{-6}\text{ m}) = 1.0 \times 10^{-3}\text{ m} = 1.0\text{ mm}$$

ขนาดการสั่นสะเทือนชั่วขณะ:
$$\Delta L = \varepsilon_z \cdot L_{total} = (1.0 \times 10^{-5}) \cdot (1.0 \times 10^{-3}\text{ m}) = 1.0 \times 10^{-8}\text{ m} = 10\text{ nm}$$

**3. กลไกการขยายเสียงและการแก้ปัญหาเชิงวิศวกรรม:**
- **ทำไมการสั่นเพียง 10 nm จึงเกิดเสียงดัง:** 
  ตัวเก็บประจุเชื่อมต่อกับแผ่น PCB อย่างแน่นหนาผ่านจุดบัดกรี แรงสั่นสะเทือนระดับนาโนเมตรจากตัวถังจะถ่ายโอนโมเมนตัมลงสู่แผ่น PCB แผ่น PCB ซึ่งมีพื้นที่กว้างใหญ่ ($>100\text{ cm}^2$) มีความถี่เรโซแนนซ์เชิงกลธรรมชาติ (Natural Structural Bending Modes) อยู่ในช่วง $1\text{ kHz} - 8\text{ kHz}$ พอดี เมื่อความถี่กระตุ้นตรงกับโหมดการดัดงอของบอร์ด แผ่นบอร์ดจะทำตัวเป็น **Acoustic Diaphragm** ดันอากาศรอบข้างให้เกิดคลื่นเสียงความดัน (Sound Pressure Level: SPL) ที่ดังเกิน $45\text{ dBA}$ ซึ่งได้ยินอย่างชัดเจนในสภาพแวดล้อมที่เงียบ
- **3 แนวทางแก้ไขเชิงโครงสร้างระดับ Senior Engineer:**
  1. **Interposer / Metal Frame Caps:** ใช้ตัวเก็บประจุที่มีโครงขารองรับโลหะ (Metal Cap Type) ขาโลหะที่มีความยืดหยุ่นจะทำหน้าที่เป็นสปริง ดูดซับแรงสั่นสะเทือน $\Delta L$ ไม่ให้ส่งผ่านลงสู่ผิวแผ่น PCB
  2. **Back-to-Back Symmetrical Placement:** ออกแบบวางตัวเก็บประจุ 2 ตัวขนาดเท่ากันประกบกันทั้งฝั่ง Top และ Bottom Layer เมื่อตัวหนึ่งยืด บอร์ดฝั่งตรงข้ามจะถูกดึงในทิศทางตรงกันข้าม ทำให้โมเมนต์ดัดงอ (Bending Moment) ของแผ่น PCB หักล้างกันเองเกือบสมบูรณ์
  3. **Milled Anti-Vibration Slots:** เจาะร่องตัด (Milled Slit) รอบบริเวณ Pad ของตัวเก็บประจุ เพื่อตัดขาดการถ่ายโอนคลื่นสั่นสะเทือนไม่ให้แพร่กระจายไปยังพื้นที่ส่วนใหญ่ของแผ่นวงจร
