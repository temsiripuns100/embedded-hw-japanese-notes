## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในกระบวนการประกอบแผงวงจรพิมพ์ (PCBA - Printed Circuit Board Assembly) เครื่องจักรจัดวางอุปกรณ์ติดตั้งบนผิว (SMT Pick-and-Place Machine หรือ **マウンター - Mounter**) ในสายการผลิตความเร็วสูงทำงานด้วยอัตราการหยิบวางสูงถึง **40,000 ถึง 100,000 ส่วนประกอบต่อชั่วโมง (CPH - Components Per Hour)** โดยหัวจับสุญญากาศ (Vacuum Nozzles) เคลื่อนที่ด้วยความเร่งสูงถึง **$5\text{ g} - 10\text{ g}$**

หากวิศวกรจัดวางตำแหน่งชิ้นส่วน (Component Placement) โดยคำนึงถึงเฉพาะการเดินลายวงจร (Routing) แต่ละเลยข้อจำกัดทางกายภาพของการผลิตตามหลัก **การออกแบบเพื่อการประกอบ (Design for Assembly - DFA)** จะก่อให้เกิดความล้มเหลวร้ายแรงในสายการผลิต เช่น:
1. **การชนกันของหัวดูดสุญญากาศกับชิ้นส่วนข้างเคียง (Nozzle Mechanical Interference & Collision)**
2. **เงาบดบังความร้อนและการไหลของคลื่นบัดกรี (Thermal Shadowing in Reflow / Wave Solder Skipping)**
3. **การหลุดร่อนหรือเบี้ยวของชิ้นส่วนจากแรงสั่นสะเทือน (Placement Shock Misalignment)**
4. **ความผิดพลาดในการตรวจจับของระบบกล้องตรวจสอบอัตโนมัติ (AOI Optical Shadowing & False Calls)**

มาตรฐาน **IPC-7351 (Generic Requirements for Surface Mount Design and Land Pattern Standard)** ได้กำหนดนิยามของ **ลานเว้นระยะปลอดภัยรอบชิ้นส่วน (Courtyard Boundary)** เพื่อเป็นเกราะป้องกันความผิดพลาดในกระบวนการผลิตจริง

### 1.1 จลนพลศาสตร์ของหัวดูดเครื่องจักรและขอบเขตการชน (Nozzle Envelope & Z-Stroke Dynamics)

หัวจับอุปกรณ์ของเครื่อง Pick-and-Place ประกอบด้วยแกนหมุน (Theta Axis), เซนเซอร์วัดแรงกด (Z-Force Sensor), และหัวดูดสุญญากาศ (Nozzle Tip):
- ในขณะที่หัวดูดนำชิ้นส่วนขนาดเล็ก (เช่น คาปาซิเตอร์ 0201 หรือ 0402) พุ่งลงมาวางบนครีมบัดกรีด้วยความเร็วในแนวดิ่ง $V_z \approx 0.5 - 1.0\text{ m/s}$ หัวดูดจะต้องหยุดอย่างนุ่มนวลและออกแรงกดคงที่ $F_{\text{press}} \approx 0.5 - 1.5\text{ N}$ ลงบนเนื้อตะกั่ว
- ตัวเรือนของหัวดูดสุญญากาศ (Nozzle Body / Outer Skirt) มีเส้นผ่านศูนย์กลางภายนอก ($D_{\text{nozzle}}$) ขนาดประมาณ **$2.5\text{ mm}$ ถึง $5.0\text{ mm}$** ซึ่งมีขนาดใหญ่กว่าตัวชิ้นส่วน 0201 ($0.6\text{ mm} \times 0.3\text{ mm}$) หลายเท่า

#### 1. เงื่อนไขการชนในแนวดิ่ง (Mechanical Interference Condition):
หากมีชิ้นส่วนที่มีความสูง ($H_{\text{tall}}$) ติดตั้งอยู่ก่อนหน้าบนแผงวงจรในตำแหน่งใกล้เคียง ระยะห่างในแนวราบ ($S_{\text{clearance}}$) ระหว่างขอบชิ้นส่วนทั้งสองจะต้องเป็นไปตามสมการความปลอดภัย:

$$S_{\text{clearance}} \ge \frac{D_{\text{nozzle}} - W_{\text{chip}}}{2} + \delta_{\text{tooling}} + \delta_{\text{board\_tilt}}$$

โดยที่:
- $D_{\text{nozzle}}$ = เส้นผ่านศูนย์กลางขอบนอกของหัวดูดชิ้นส่วนขนาดเล็ก
- $W_{\text{chip}}$ = ความกว้างของชิ้นส่วนขนาดเล็กที่กำลังวาง
- $\delta_{\text{tooling}}$ = ค่าความเผื่อตำแหน่งของเครื่องจักร ($X-Y$ Placement Tolerance $\approx \pm 25\ \mu\text{m}$)
- $\delta_{\text{board\_tilt}}$ = ระยะเคลื่อนที่ด้านข้างเนื่องจากการแอ่นตัวของแผงวงจร ($\approx \pm 50\ \mu\text{m}$)

หาก $S_{\text{clearance}}$ น้อยกว่าเกณฑ์นี้ ปลอกโลหะของหัวดูดจะกระแทกเข้ากับมุมของอุปกรณ์ตัวสูง ทำให้หัวดูดหักงอ ชิ้นส่วนขนาดเล็กกระเด็นหลุด และกลไกแกน $Z$ ของเครื่องจักรเสียหายรุนแรง

### 1.2 ขอบเขตลานเว้นระยะปลอดภัยตามมาตรฐาน IPC-7351 (Courtyard Boundary Definition)

มาตรฐาน **IPC-7351B** กำหนดให้แพทเทิร์นแพดของชิ้นส่วน SMT ทุกตัวต้องมีเส้นขอบเขตจำกัดเชิงกายภาพ เรียกว่า **Courtyard (コートヤード)** ซึ่งประกอบด้วยพื้นที่ของตัวถังอุปกรณ์ (Component Body), พื้นที่ของแพดทองแดงรวมระยะตะกั่วแผ่ (Land Pattern Boundary), บวกด้วยค่าเผื่อลานปลอดภัยส่วนเกิน (Courtyard Excess):

```
       ┌────────────────────────────────────────────────────────┐ ◄── Courtyard Outer Boundary
       │                      Courtyard Excess                  │
       │     ┌────────────────────────────────────────────┐     │
       │     │  ┌──────┐        Body        ┌──────┐      │     │
       │     │  │ Pad  │ ┌────────────────┐ │ Pad  │      │     │
       │     │  │  L   │ │   Component    │ │  R   │      │     │
       │     │  │      │ │   Package      │ │      │      │     │
       │     │  │      │ └────────────────┘ │      │      │     │
       │     │  └──────┘                    └──────┘      │     │
       │     └────────────────────────────────────────────┘     │
       │                     Land Pattern Extension             │
       └────────────────────────────────────────────────────────┘
```

#### ระดับมาตรฐาน Courtyard 3 ระดับตาม IPC-7351:

1. **Level A (Most Material Condition - ทนทานสูงสุด):**
   - ระยะ Courtyard Excess: **$+0.50\text{ mm}$** รอบทุกด้าน
   - เหมาะสำหรับ: ผลิตภัณฑ์ทางการทหาร, การบินอวกาศ, และยานยนต์ใต้ฝากระโปรง (Under-the-hood Automotive) ซึ่งต้องการพื้นที่กว้างสำหรับการตรวจสอบด้วยสายตา การเคลือบน้ำยาวานิช (Conformal Coating) และการซ่อมแซมด้วยมือ (Manual Rework)
2. **Level B (Nominal Material Condition - มาตรฐานอุตสาหกรรม):**
   - ระยะ Courtyard Excess: **$+0.25\text{ mm}$** รอบทุกด้าน
   - เหมาะสำหรับ: อุปกรณ์อิเล็กทรอนิกส์สำหรับผู้บริโภคทั่วไป, เซิร์ฟเวอร์, อุปกรณ์เครือข่าย ให้ความสมดุลระหว่างความหนาแน่นและอัตราผลได้ในการประกอบ
3. **Level C (Least Material Condition - ความหนาแน่นสูงสุด):**
   - ระยะ Courtyard Excess: **$+0.10 - 0.12\text{ mm}$** รอบทุกด้าน
   - เหมาะสำหรับ: สมาร์ตโฟน, อุปกรณ์สวมใส่ (Wearables), โมดูลกล้อง ซึ่งพื้นที่บอร์ดมีจำกัดอย่างยิ่งยวด ต้องใช้เครื่องจักร Mounter ที่มีความแม่นยำสูงพิเศษและหัวดูดขนาดเล็กแบบสั่งทำเฉพาะ

> [!IMPORTANT]
> **กฎเหล็กการตรวจ DFA ในระบบ CAD:** เส้นขอบเขต Courtyard ของชิ้นส่วนสองชิ้นใดๆ **ต้องไม่ทับซ้อนกันโดยเด็ดขาด (Zero Courtyard Violation: Overlap Distance $\le 0$)** หากเส้น Courtyard ชนกัน แปลว่าระยะห่างระหว่างชิ้นส่วนต่ำกว่าขีดจำกัดความปลอดภัยของกระบวนการประกอบ

### 1.3 ผลกระทบเงาบังความร้อนและเงาบังคลื่นตะกั่ว (Thermal & Wave Solder Shadowing)

#### 1. การบังความร้อนในเตาอบ Reflow (Convection Thermal Shadowing):
ในเตาอบลมร้อน (Convection Reflow Oven) ลมร้อนจะพัดผ่านผิวหน้าบอร์ดด้วยมุมตกกระทบต่ำ:
- หากวางชิ้นส่วนตัวเล็ก (เช่น 0402 Chip Capacitor) อยู่ด้านหลังของอุปกรณ์ตัวสูงและมีมวลความร้อนขนาดใหญ่ (เช่น ขดลวดชิลด์ Power Inductor หนา $5.0\text{ mm}$ หรือตัวเก็บประจุอลูมิเนียมอิเล็กโทรไลต์):
  - อุปกรณ์ตัวสูงจะบล็อกกระแสลมร้อน ทำให้เกิด **เขตเงาความร้อนต่ำ (Thermal Cold Spot)** ด้านหลัง
  - อุณหภูมิบนแพดของชิ้นส่วนตัวเล็กจะขึ้นช้ากว่าแพดฝั่งตรงข้ามถึง $10 - 15^\circ\text{C}$
  - ตะกั่วที่แพดด้านนอกจะหลอมละลายก่อน ดึงให้ชิ้นส่วนลอยตัวตั้งขึ้น เกิดเป็นข้อบกพร่อง **หินป้ายหลุมศพ (Tombstoning หรือ แมนฮัตตันเอฟเฟกต์)**

#### 2. การบังคลื่นในการบัดกรีคลื่น (Wave Soldering Shadowing):
สำหรับการบัดกรีด้านล่างของบอร์ดด้วยคลื่นตะกั่วหลอมเหลว (Dual Wave Solder):
- คลื่นตะกั่วจะไหลผ่านผิวบอร์ดด้วยมุมเอียงประมาณ $5^\circ - 7^\circ$
- อุปกรณ์ตัวสูงจะทำหน้าที่เสมือนเขื่อนกั้นคลื่น ก่อให้เกิดบริเวณอับตะกั่ว (Shadow Zone) ท้ายเขื่อน
- ชิ้นส่วนที่อยู่หลังเขื่อนจะไม่สัมผัสกับยอดคลื่นตะกั่ว ส่งผลให้เกิด **จุดข้ามการบัดกรี (Solder Skips / ขาไม่ติดตะกั่ว $100\%$)**

$$\text{Minimum Shadow Clearance } L_{\text{shadow}} \ge H_{\text{tall}} \cdot \tan\theta_{\text{flow}} + K_{\text{surface\_tension}}$$

โดยทั่วไปสำหรับ Wave Soldering:
$$L_{\text{shadow}} \ge 2.5 \cdot H_{\text{tall}} \quad (\text{หากตัวสูง } 2.0\text{ mm} \implies \text{ต้องเว้นระยะห่างอย่างน้อย } 5.0\text{ mm})$$

### 1.4 การจัดทิศทางและการวางชิ้นส่วนเพื่อเพิ่มอัตราการตรวจจับของกล้อง AOI

เพื่อลดอัตราการแจ้งเตือนผิดพลาด (False Calls) ของเครื่องตรวจจับทางสายตาอัตโนมัติ (Automated Optical Inspection - AOI) และลดความผิดพลาดของช่างในขั้นตอนการวางอุปกรณ์:

```
    [ POOR DFA: Mixed Random Polarities ]          [ GOOD DFA: Unified Uniform Polarity ]
         C1         C2         C3                       C1         C2         C3
       ┌─────┐    ┌─────┐    ┌─────┐                  ┌─────┐    ┌─────┐    ┌─────┐
       │ - + │    │ + - │    │ - + │                  │ + - │    │ + - │    │ + - │
       └─────┘    └─────┘    └─────┘                  └─────┘    └─────┘    └─────┘
     Confuses AOI algorithms & manual techs!    100% Consistent optical reflection & polarity!
```

1. **การรวมศูนย์ทิศทางขั้ว (Unidirectional Polarity Alignment):**
   - ชิ้นส่วนที่มีขั้ว เช่น ตัวเก็บประจุแทนทาลัม, ไดโอด, ไอซี, ตัวเก็บประจุอิเล็กโทรไลต์ ต้องจัดวางให้ขั้วบวก (Anode / Pin 1) ชี้ไปในทิศทางเดียวกันทั้งหมดในแต่ละกลุ่มวงจร (เช่น ชี้ไปทางทิศเหนือ หรือทิศตะวันตกเท่านั้น)
2. **การจัดแนวแกนของตัวต้านทานและตัวเก็บประจุ (Orthogonal Grid Alignment):**
   - อุปกรณ์ชิปสองขา (0402, 0603, 0805) ควรวางขนานกับแนวแกน $X$ หรือแกน $Y$ เท่านั้น ห้ามหมุนทำมุมเอียง $45^\circ$ เนื่องจากหัวดูดของเครื่อง Mounter ต้องหมุนแกนชดเชยซึ่งลดความเร็ว CPH ลง $15\% - 25\%$ และระบบแสงไฟมุมตกกระทบของกล้อง AOI จะเกิดเงาสะท้อนผิดเพี้ยน

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例): หัวดูด Mounter ชนหัก และ Tombstoning พุ่ง $8.5\%$ ในบอร์ดขับมอเตอร์โดรน

ในสายการผลิตแผงวงจรควบคุมสปีดมอเตอร์โดรนความเร็วสูง (ESC Module) ขนาดกะทัดรัด $30\text{ mm} \times 30\text{ mm}$:
- วิศวกรจัดวางตัวเก็บประจุบายพาสขนาด 0201 ($0.6\text{ mm} \times 0.3\text{ mm}$) ห่างจากขอบของขดลวดตัวเหนี่ยวนำกำลังสูง (Power Inductor ขนาด $6\text{ mm} \times 6\text{ mm}$, ความสูง $H = 4.2\text{ mm}$) เพียง **$0.35\text{ mm}$** เพื่อให้ลูปกระแสสั้นที่สุด
- เมื่อนำไฟล์เข้าสายการผลิตจริงที่ความเร็ว 35,000 CPH เกิดปัญหาต่อเนื่อง 2 ระลอก:
  1. หัวดูดสุญญากาศ Nozzle Type 922 (เส้นผ่านศูนย์กลางกระบอกสูบภายนอก $3.4\text{ mm}$) ซึ่งกำลังพุ่งลงมาวางชิ้นส่วน 0201 ได้ชนกระแทกเข้ากับมุมบนของ Power Inductor อย่างรุนแรง ทำให้หัวดูดหักงอไป 3 หัวในกะแรก และเครื่อง Mounter หยุดทำงานฉุกเฉิน (Line Stop) สูญเสียเวลาการผลิตไปกว่า 4 ชั่วโมง
  2. หลังจากช่างฝ่ายผลิตแก้ปัญหาด้วยการเปลี่ยนลำดับการวาง (Sequence Optimization) โดยวางตัวเก็บประจุ 0201 ก่อน แล้วจึงวาง Inductor ในลำดับถัดไป ปรากฏว่าเมื่อบอร์ดเข้าเตาอบ Reflow ตัวเก็บประจุ 0201 เกิดอาการกระดกตั้งเป็นหินป้ายหลุมศพ (Tombstoning) สูงถึง **$8.5\%$** เนื่องจากมวลโลหะของ Inductor ดูดความร้อนหนีและบังลมร้อน ทำให้แพดของ 0201 ฝั่งที่ชิด Inductor ร้อนช้ากว่าอีกฝั่งถึง $18^\circ\text{C}$

```
                                Root Cause Breakdown (Ishikawa)
                                
       Placement Geometry Defect                      Thermal Layout Defect
    ┌─────────────────────────────┐                ┌─────────────────────────────┐
```

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### Quiz 1: การคำนวณระยะห่างปลอดภัยเพื่อป้องกันหัวดูด Mounter ชนอุปกรณ์สูง (Nozzle Collision Dynamic Clearance)

**โจทย์:**  
โรงงานผลิตแผงวงจรกำลังติดตั้งเครื่อง Pick-and-Place ความเร็วสูง (Rotary Placement Head) เพื่อวางตัวเก็บประจุเซรามิกขนาด **0402 ($L = 1.00\text{ mm}, W = 0.50\text{ mm}, H = 0.50\text{ mm}$)** ใกล้เคียงกับชิ้นส่วนตัวแปลงสัญญาณพัลส์ (Pulse Transformer) ซึ่งมีความสูง **$H_{\text{trans}} = 4.80\text{ mm}$**  
- หัวดูดสุญญากาศที่ใช้สำหรับชิ้นส่วน 0402 มีขนาดเส้นผ่านศูนย์กลางภายนอกของปลอกหัวดูด (Nozzle Collet Outer Diameter) $D_{\text{nozzle}} = 3.60\text{ mm}$
- ในขณะที่หัวดูดกำลังวางชิ้นส่วน 0402 บนผิวแผงวงจร ปลายหัวดูดจะยื่นลงมาจับชิ้นส่วน โดยมีระยะเคลียร์แลนซ์จากปลายสัมผัสชิ้นส่วนถึงขอบล่างของปลอกหัวดูดเท่ากับ $h_{\text{tip}} = 1.20\text{ mm}$ (หมายความว่า เมื่อวางชิ้นส่วน 0402 ลงบนบอร์ด ปลอกหัวดูดจะอยู่ที่ความสูงเหนือผิวบอร์ดเท่ากับ $H_{\text{collar}} = H_{0402} + h_{\text{tip}} = 0.50 + 1.20 = 1.70\text{ mm}$)
- เนื่องจากหม้อแปลงมีความสูง $4.80\text{ mm}$ ซึ่งสูงกว่า $1.70\text{ mm}$ ปลอกหัวดูดจึงมีโอกาสชนเข้ากับผนังด้านข้างของหม้อแปลงในระนาบแนวนอน
- ข้อมูลความเผื่อเชิงกลของระบบ:
  - ความคลาดเคลื่อนตำแหน่งในแนวราบของเครื่องจักร: $\pm \Delta_{\text{mounter}} = \pm 35\ \mu\text{m}$
  - ความคลาดเคลื่อนขนาดตัวถังของหม้อแปลงจากการผลิต: $\pm \Delta_{\text{part}} = \pm 0.15\text{ mm}$ ($150\ \mu\text{m}$)
  - การบิดเอียงของแผงวงจรขณะถูกจับยึด (Board Warpage/Tilt Angle): สูงสุด $\theta_{\text{tilt}} = 2.0^\circ$ (ทำให้หัวดูดเอียงเข้าหาชิ้นส่วนหม้อแปลง)
  - กำหนดให้ต้องมีระยะปลอดภัยสุทธิ (Safety Clearance Margin) หลังหักความคลาดเคลื่อนทั้งหมดอย่างน้อย $\delta_{\text{safe}} = 0.25\text{ mm}$

**คำถาม:**
1. จงคำนวณระยะขยายด้านข้างของปลอกหัวดูด ($R_{\text{nozzle\_skirt}}$) เมื่อวัดจากจุดศูนย์กลางของชิ้นส่วน 0402
2. จงคำนวณการเบี่ยงเบนด้านข้างเพิ่มเติม ($\Delta x_{\text{tilt}}$) ของปลอกหัวดูดที่ความสูง $4.80\text{ mm}$ อันเนื่องมาจากมุมเอียงของบอร์ด $2.0^\circ$
3. จงคำนวณหาระยะห่างขั้นต่ำจากขอบถึงขอบ (Edge-to-Edge Minimum Clearance $S_{\min}$) ที่ต้องกำหนดระหว่างตัวถังของ 0402 และตัวถังของ Transformer ในไฟล์ CAD Layout เพื่อรับประกันว่าจะไม่เกิดการชนกัน $100\%$

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 1:

**1. คำนวณรัศมีปลอกหัวดูดจากเซนเตอร์ชิ้นส่วน ($R_{\text{nozzle\_skirt}}$):**
หัวดูดจับชิ้นส่วนที่จุดกึ่งกลางพอดี:
รัศมีของปลอกหัวดูด:
$$R_{\text{nozzle}} = \frac{D_{\text{nozzle}}}{2} = \frac{3.60\text{ mm}}{2} = 1.80\text{ mm}$$
ครึ่งหนึ่งของความกว้างชิ้นส่วน 0402:
$$W_{\text{half}} = \frac{W_{0402}}{2} = \frac{0.50\text{ mm}}{2} = 0.25\text{ mm}$$
ระยะที่ปลอกหัวดูดยื่นล้นเลยขอบชิ้นส่วน 0402 ออกมาในแนวราบ:
$$d_{\text{overhang}} = R_{\text{nozzle}} - W_{\text{half}} = 1.80\text{ mm} - 0.25\text{ mm} = 1.55\text{ mm}$$

---

**2. คำนวณการเบี่ยงเบนด้านข้างเนื่องจากมุมเอียงของบอร์ด ($\Delta x_{\text{tilt}}$):**
ที่ความสูงของหม้อแปลง $H_{\text{trans}} = 4.80\text{ mm}$ เมื่อเกิดการเอียง $\theta_{\text{tilt}} = 2.0^\circ$:
$$\Delta x_{\text{tilt}} = H_{\text{trans}} \cdot \sin(2.0^\circ) = 4.80\text{ mm} \cdot 0.03490 \approx 0.1675\text{ mm}$$

---

**3. คำนวณระยะห่างขอบถึงขอบขั้นต่ำ ($S_{\min}$):**
ระยะห่างขอบถึงขอบที่ปลอดภัยต้องครอบคลุม:
$$S_{\min} = d_{\text{overhang}} + \Delta x_{\text{tilt}} + \Delta_{\text{mounter}} + \Delta_{\text{part}} + \delta_{\text{safe}}$$
แทนค่าตัวแปรทั้งหมดในหน่วยมิลลิเมตร:
- $d_{\text{overhang}} = 1.55\text{ mm}$
- $\Delta x_{\text{tilt}} = 0.1675\text{ mm}$
- $\Delta_{\text{mounter}} = 0.035\text{ mm}$
- $\Delta_{\text{part}} = 0.150\text{ mm}$
- $\delta_{\text{safe}} = 0.250\text{ mm}$

$$S_{\min} = 1.55 + 0.1675 + 0.035 + 0.150 + 0.250 = 2.1525\text{ mm} \approx 2.16\text{ mm}\ (85\text{ mil})$$

**บทวิเคราะห์ทางวิศวกรรม:** หากวิศวกรใช้กฎทั่วไปที่เว้นระยะเพียง $0.5\text{ mm}$ หรือ $1.0\text{ mm}$ ปลอกหัวดูดจะพุ่งชนหม้อแปลงอย่างแน่นอน การคำนวณฟิสิกส์เชิงกลยืนยันว่าต้องเว้นระยะห่างในไฟล์ Layout ไม่น้อยกว่า **$2.16\text{ mm}$** เพื่อความปลอดภัยสูงสุดของเครื่องจักร

### Quiz 2: การคำนวณระยะเว้นเงาบังคลื่นตะกั่วเพื่อป้องกัน Solder Skips ในกระบวนการ Wave Soldering

**โจทย์:**  
แผงวงจรอิเล็กทรอนิกส์ยานยนต์กำลังถูกออกแบบเพื่อผ่านกระบวนการบัดกรีคลื่นแบบสองยอดคลื่น (Dual Wave Soldering Machine)  
- บนชั้นล่างของแผงวงจร มีการติดตั้งคอนเนกเตอร์แบบผ่านรูที่มีตัวเรือนพลาสติกยื่นสูงลงมาด้านล่าง $H_{\text{conn}} = 6.00\text{ mm}$
- ด้านหลังของคอนเนกเตอร์ในทิศทางการเคลื่อนที่ของสายพานลำเลียง (Conveyor Flow Direction) มีการวางตัวต้านทานชิปขนาด 0805 แบบ SMT ยึดด้วยกาวชิป (SMT Glue Adhesive)
- ข้อมูลพารามิเตอร์ของเตาบัดกรีคลื่น:
  - สายพานลำเลียงทำมุมเอียง $\alpha = 6.0^\circ$ กับแนวนอน
  - ยอดคลื่นตะกั่วเหลวแบบราบ (Smooth Main Wave) มีการไหลวนที่ทำให้มุมตกกระทบของของเหลวเบี่ยงเบนไปเป็นมุมวิกฤต $\theta_{\text{wave}} = 18.0^\circ$ สัมพันธ์กับขอบหลังของสิ่งกีดขวาง
  - แรงตึงผิวของน้ำตะกั่วเหลว (Surface Tension Meniscus) ทำให้เกิดฟองคลื่นเว้า (Meniscus Curvature) ส่งผลให้ของเหลวไม่สามารถเกาะติดกับผิวบอร์ดได้ภายในระยะห่าง $d_{\text{meniscus}} = 1.80\text{ mm}$ จากจุดที่คลื่นตกกระทบผิวบอร์ด

**คำถาม:**
1. จงคำนวณความยาวของเขตเงาบังคลื่นตะกั่วในแนวราบ ($L_{\text{shadow}}$ ในหน่วย $\text{mm}$) ที่เกิดจากความสูงของคอนเนกเตอร์ $6.00\text{ mm}$
2. รวมผลของแรงตึงผิวและค่าเผื่อความผันผวนของความสูงยอดคลื่น ($\pm 15\%$) จงคำนวณหาระยะห่างขั้นต่ำ (Keep-Out Clearance $S_{\text{wave\_min}}$) ระหว่างขอบคอนเนกเตอร์และแพดของชิป 0805
3. หากจำเป็นต้องวางชิป 0805 ในบริเวณดังกล่าวโดยไม่มีพื้นที่ถอยร่น วิศวกรควรปรับแนวทิศทางการวาง (Orientation) ของชิ้นส่วน 0805 อย่างไรเพื่อลดความเสี่ยงของการเกิดตะกั่วลัดวงจร (Bridging) หรือตะกั่วไม่ติด (Skips)?

---

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 2:

**1. คำนวณความยาวเขตเงาบังคลื่น ($L_{\text{shadow}}$):**
จากตรีโกณมิติของการไหลของคลื่นตกกระทบที่มุม $\theta_{\text{wave}} = 18.0^\circ$:
$$L_{\text{shadow}} = \frac{H_{\text{conn}}}{\tan(\theta_{\text{wave}})} = \frac{6.00\text{ mm}}{\tan(18.0^\circ)} = \frac{6.00}{0.3249} \approx 18.47\text{ mm}$$

---

**2. คำนวณระยะ Keep-Out Clearance ขั้นต่ำ ($S_{\text{wave\_min}}$):**
เมื่อคิดค่าความผันผวนของความสูงยอดคลื่น $+15\%$ (ซึ่งทำให้เงายาวขึ้น $15\%$):
$$L_{\text{shadow, worst}} = 18.47\text{ mm} \times 1.15 \approx 21.24\text{ mm}$$

รวมผลของระยะแรงตึงผิว $d_{\text{meniscus}} = 1.80\text{ mm}$:
$$S_{\text{wave\_min}} = L_{\text{shadow, worst}} + d_{\text{meniscus}} = 21.24\text{ mm} + 1.80\text{ mm} = 23.04\text{ mm}$$

**ข้อสรุป DFM:** เพื่อป้องกันปัญหาตะกั่วไม่ติด (Solder Skips) ชิ้นส่วน SMT ใดๆ ที่อยู่ท้ายคอนเนกเตอร์ตัวสูง $6\text{ mm}$ จะต้องถูกผลักออกไปห่างอย่างน้อย **$23.0\text{ mm}$** ตามแนวสายพาน!

---

**3. การปรับแนวทิศทาง (Orientation Optimization):**
หากจำเป็นต้องวางในบริเวณใกล้เคียง:
1. **ขนานกับทิศทางการไหล:** ต้องหมุนแกนยาวของตัวต้านทาน 0805 ให้ **ขนานกับทิศทางการเคลื่อนที่ของสายพาน (Parallel to Solder Flow Direction)** เพื่อให้แพดทั้งสองผ่านยอดคลื่นต่อเนื่องกันตามลำดับ
2. **ใส่ Thief Pad:** ต้องเพิ่มแพดทองแดงเปล่า (Solder Thief / Solder Robber Pad) ขนาดเล็กไว้ที่ขอบท้ายสุดของรอยบัดกรี เพื่อดึงตะกั่วส่วนเกินไม่ให้ลัดวงจรระหว่างสองแพด (Bridging Prevention)

### Quiz 3: การวิเคราะห์และเปรียบเทียบการจัดสรรพื้นที่แผงวงจรตามมาตรฐาน IPC-7351 Courtyard Level A, B, และ C

**โจทย์:**  
วิศวกรกำลังจัดวางโมดูลหน่วยความจำแบบพกพาขนาดกะทัดรัด แผงวงจรมีพื้นที่จัดวางส่วนประกอบทั้งหมด $A_{\text{board}} = 20.0\text{ mm} \times 30.0\text{ mm} = 600.0\text{ mm}^2$  
- ชิปเซตประกอบด้วยอุปกรณ์ตัวต้านทานและตัวเก็บประจุขนาด **0603** จำนวน $N = 40$ ชิ้น
- ตัวถังชิ้นส่วน 0603 มีขนาดทางกายภาพ: ความยาว $L_c = 1.60\text{ mm}$, ความกว้าง $W_c = 0.80\text{ mm}$
- ขนาดแพทเทิร์นแพดทองแดงบนบอร์ด (Land Pattern Outer Bounds):
  - ความยาวรวมจากขอบแพดซ้ายถึงขอบแพดขวา: $L_p = 2.40\text{ mm}$
  - ความกว้างของแต่ละแพด: $W_p = 1.00\text{ mm}$
- ข้อกำหนด Courtyard Excess per side ตามมาตรฐาน IPC-7351:
  - **Level A (Most):** $+0.50\text{ mm}$ ต่อข้าง
  - **Level B (Nominal):** $+0.25\text{ mm}$ ต่อข้าง
  - **Level C (Least):** $+0.12\text{ mm}$ ต่อข้าง

**คำถาม:**
1. จงคำนวณพื้นที่ Courtyard ต่อหนึ่งชิ้นส่วน ($A_{\text{courtyard}}$ ในหน่วย $\text{mm}^2$) สำหรับทั้ง 3 ระดับ (Level A, B, และ C)
2. จงคำนวณพื้นที่รวมที่ชิ้นส่วนทั้ง 40 ชิ้นต้องการใช้บนแผงวงจรสำหรับแต่ละระดับ และคิดเป็นสัดส่วนร้อยละเทียบกับพื้นที่บอร์ดรวม ($600\text{ mm}^2$)
3. หากแผงวงจรนี้เป็นอุปกรณ์ประเภท Wearable Healthcare Device ซึ่งต้องการพื้นที่สำหรับชิปประมวลผลหลักและสายอากาศเพิ่มเติมอย่างน้อย $450\text{ mm}^2$ จงวิเคราะห์ว่าระดับ Courtyard ใดที่สามารถนำมาใช้งานได้จริงโดยไม่ทำให้พื้นที่บอร์ดล้น?

---

#### เฉลยและบทวิเคราะห์ทางวิศวกรรม Quiz 3:

**1. คำนวณพื้นที่ Courtyard ต่อหนึ่งชิ้นส่วน:**
พื้นที่ฐานของ Land Pattern: $L_p = 2.40\text{ mm}$, $W_p = 1.00\text{ mm}$
- **Level A (Excess = $+0.50\text{ mm}$ ต่อข้าง):**
  $$L_A = L_p + 2(0.50) = 2.40 + 1.00 = 3.40\text{ mm}$$
  $$W_A = W_p + 2(0.50) = 1.00 + 1.00 = 2.00\text{ mm}$$
  $$A_{\text{courtyard, A}} = 3.40\text{ mm} \times 2.00\text{ mm} = 6.80\text{ mm}^2$$

- **Level B (Excess = $+0.25\text{ mm}$ ต่อข้าง):**
  $$L_B = L_p + 2(0.25) = 2.40 + 0.50 = 2.90\text{ mm}$$
  $$W_B = W_p + 2(0.25) = 1.00 + 0.50 = 1.50\text{ mm}$$
  $$A_{\text{courtyard, B}} = 2.90\text{ mm} \times 1.50\text{ mm} = 4.35\text{ mm}^2$$

- **Level C (Excess = $+0.12\text{ mm}$ ต่อข้าง):**
  $$L_C = L_p + 2(0.12) = 2.40 + 0.24 = 2.64\text{ mm}$$
  $$W_C = W_p + 2(0.12) = 1.00 + 0.24 = 1.24\text{ mm}$$
  $$A_{\text{courtyard, C}} = 2.64\text{ mm} \times 1.24\text{ mm} = 3.2736\text{ mm}^2$$

---

**2. คำนวณพื้นที่รวมของ 40 ชิ้นส่วนและสัดส่วนพื้นที่บอร์ด:**
- **Level A:**
  $$A_{\text{total, A}} = 40 \times 6.80\text{ mm}^2 = 272.0\text{ mm}^2 \implies \frac{272.0}{600.0} \times 100\% = 45.33\%$$
- **Level B:**
  $$A_{\text{total, B}} = 40 \times 4.35\text{ mm}^2 = 174.0\text{ mm}^2 \implies \frac{174.0}{600.0} \times 100\% = 29.00\%$$
- **Level C:**
  $$A_{\text{total, C}} = 40 \times 3.2736\text{ mm}^2 = 130.94\text{ mm}^2 \implies \frac{130.94}{600.0} \times 100\% = 21.82\%$$

---

**3. การตัดสินใจเชิงวิศวกรรมสำหรับ Wearable Device:**
- เงื่อนไข: บอร์ดมีพื้นที่รวม $600\text{ mm}^2$ และต้องเหลือพื้นที่สำหรับชิปหลักและสายอากาศอย่างน้อย $450\text{ mm}^2$
- ดังนั้น พื้นที่สูงสุดที่ยอมให้อุปกรณ์พาสซีฟทั้ง 40 ตัวใช้งานได้คือ:
  $$A_{\text{allowable}} = 600.0\text{ mm}^2 - 450.0\text{ mm}^2 = 150.0\text{ mm}^2$$
- **การเปรียบเทียบ:**
  - Level A ($272.0\text{ mm}^2 > 150.0\text{ mm}^2$) $\to$ **ไม่ผ่าน** (กินพื้นที่เกินไปถึง $81\%$)
  - Level B ($174.0\text{ mm}^2 > 150.0\text{ mm}^2$) $\to$ **ไม่ผ่าน** (เกินโควตาพื้นที่ $24\text{ mm}^2$)
  - Level C ($130.94\text{ mm}^2 < 150.0\text{ mm}^2$) $\to$ **ผ่านเกณฑ์เพียงตัวเลือกเดียว!** โดยยังมีพื้นที่เหลือสำรองอีก $19.06\text{ mm}^2$
- **บทสรุปวิศวกรอาวุโส:** โครงการนี้จำเป็นต้องเลือกใช้ **IPC-7351 Level C (Least Material)** และต้องประสานงานกับโรงงานประกอบเพื่อเลือกใช้หัวดูดขนาดเล็กพิเศษและเพิ่มการตรวจสอบออปติคัล $100\%$ เพื่อให้สามารถบรรลุการออกแบบขนาดจิ๋วได้สำเร็จโดยยังคงรักษาผลได้ในการผลิต
