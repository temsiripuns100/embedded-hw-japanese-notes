## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ด้วยการถือกำเนิดของชิปประมวลผลขนาดจิ๋วที่มีระยะพิตช์ของลูกบอลระดับ Ultra-Fine Pitch BGA (เช่น พิตช์ $0.4 \text{ mm}, 0.35 \text{ mm}$ ในสมาร์ตโฟน, อุปกรณ์สวมใส่, และโมดูล AI ขอบภาพ) เทคโนโลยีการเจาะรูด้วยสว่านกลไกแบบดั้งเดิม (Mechanical Drilling) ได้มาถึงทางตันทางกายภาพ 
อุตสาหกรรมจึงก้าวเข้าสู่ยุคของ **High Density Interconnect (HDI)** ซึ่งใช้การเจาะรูด้วยแสงเลเซอร์ (Laser Microvia) ขนาดเส้นผ่านศูนย์กลางเล็กกว่า $100 - 150 \ \mu\text{m}$

อย่างไรก็ดี ในช่วงไม่กี่ปีที่ผ่านมา องค์กร IPC ได้ออกประกาศเตือนภัยระดับอุตสาหกรรม **IPC-WP-023** เกี่ยวกับ **"ความล้มเหลวแฝงของ Microvia (Latent Microvia Failures)"** 
ซึ่งเกิดจากการแยกตัวของรอยต่อระหว่างก้นหลุมของ Microvia กับแผ่น Target Pad ด้านล่าง (Target Pad Separation) ระหว่างกระบวนการบัดกรีไร้สารตะกั่ว (Lead-Free Reflow $260^\circ\text{C}$) วิศวกรระดับ Senior จึงต้องเข้าใจฟิสิกส์ของการเจาะเลเซอร์, กลไกความเค้นเทอร์โมเมคานิกส์, และการเลือกใช้โครงสร้างระหว่าง **Stacked Microvias** กับ **Staggered Microvias** อย่างลึกซึ้ง

### 1.1 กระบวนการเจาะด้วยแสงเลเซอร์ (Laser Drilling Physics) และรูปทรงกรวยคอด

การเจาะรู Microvia อาศัยพลังงานโฟตอนความเข้มสูงจากเลเซอร์ 2 ชนิดหลัก:
1. **$CO_2$ Laser ($\lambda \approx 9.4 - 10.6 \ \mu\text{m}$):** ความยาวคลื่นย่านอินฟราเรด ดูดกลืนพลังงานได้ดีเลิศในเนื้อฉนวนเรซินและใยแก้ว แต่สะท้อนออกจากผิวทองแดง จึงต้องใช้ร่วมกับกระบวนการกัดกรดเปิดหน้าต่างทองแดงล่วงหน้า (Conformal Mask) หรือการยิงทะลุทองแดงบางพิเศษ
2. **UV Laser ($\lambda \approx 355 \text{ nm}$ - Tripled Nd:YAG):** ความยาวคลื่นย่านอัลตราไวโอเลต มีพลังงานโฟตอนสูงมาก สามารถตัดพันธะโมเลกุล (Photochemical Ablation) เจาะทะลุได้ทั้งแผ่นฟอยล์ทองแดงและเนื้อไดอิเล็กทริก ให้ขอบรูที่คมกริบขนาดเล็กถึง $50 - 75 \ \mu\text{m}$

```
                Capture Pad (Top Surface: Diameter D_cap)
             ┌────────────────────────────────────────────────────────┐
             │                                                        │
             │     ┌────────────────────────────────────┐             │
             │     │\  Top Diameter D_top (100-125 μm) /│             │ ▲
             │     │ \                                / │             │ │ Dielectric Depth H
             │     │  \   Copper Plated Fill         /  │             │ │ (Aspect Ratio ≤ 0.8:1)
             │     │   \                            /   │             │ │
             │     │    \ Bottom Dia D_bot (70-90μm/    │             │ ▼
             └─────┴─────┴────────────────────────┴─────┴─────────────┘
                         ┌────────────────────────┐
                         │   Target Pad (Base)    │ ◄── Critical Failure Interface!
                         └────────────────────────┘
```

**รูปทรงกรวยคว่ำ (Trapezoidal / Tapered Hole Profile):**  
เนื่องจากลำแสงเลเซอร์มีการกระจายตัวของพลังงานแบบเกาส์เซียน (Gaussian Beam Profile) และสูญเสียพลังงานเมื่อเจาะลึกลงไป รูเจาะ Microvia จะมีลักษณะเป็นทรงกรวยคว่ำเสมอ:
- ปากรูด้านบน ($D_{top}$): ประมาณ $100 - 125 \ \mu\text{m}$
- ก้นรูด้านล่าง ($D_{bot}$): แคบลงเหลือประมาณ $70 - 90 \ \mu\text{m}$ (มุมเอียงของผนังประมาณ $70^\circ - 85^\circ$)
- **กฎอัตราส่วนความลึก (Aspect Ratio Rule):**  
  ตามมาตรฐาน IPC-2226 ค่า Aspect Ratio ของ Microvia ต้อง **ไม่เกิน $1:1$ (แนะนำอย่างยิ่งให้จำกัด $AR_{\mu via} \le 0.75:1$)**  
  หากความหนาของชั้นฉนวน ($H$) มากกว่าเส้นผ่านศูนย์กลางรูเจาะ น้ำยาเคมีไฟฟ้าจะไม่สามารถเติมเนื้อทองแดง (Copper Electroplating) ได้เต็มรู จะเกิดโพรงอากาศกลวง (Void) ขังอยู่ภายในก้นหลุมทันที

### 1.2 การเตือนภัยระดับโลก IPC-WP-023: กลไกการฉีกขาดของ Target Pad Interface

เอกสาร **IPC-WP-023 (IPC White Paper on Microvia Failures)** ระบุถึงโหมดความล้มเหลวแบบแฝง (Latent Defects) ที่ไม่สามารถตรวจพบได้ด้วยการทดสอบทางไฟฟ้าที่โรงงาน (ผ่าน ICT และ Flying Probe $100\%$) แต่กลับไปขาดเปิดวงจร (Open Circuit) เมื่อประกอบชิ้นส่วนหรือส่งมอบให้ลูกค้าใช้งาน:

```
       Structure A: Normal Intact Microvia         Structure B: IPC-WP-023 Interface Separation
          ┌───────────────────────────┐               ┌───────────────────────────┐
          │      Microvia Barrel      │               │      Microvia Barrel      │
          │      (Electrolytic Cu)    │               │      (Electrolytic Cu)    │
          ├───────────────────────────┤               └───┬───────────────────┬───┘
          │ Electroless Cu Seed Layer │                   │   CRACK / VOID    │  ◄── Type A Failure!
          ├───────────────────────────┤               ┌───┴───────────────────┴───┐
          │     Target Pad Copper     │               │     Target Pad Copper     │
          └───────────────────────────┘               └───────────────────────────┘
```

1. **โหมดความล้มเหลวหลัก (Failure Modes):**
   - **Type A (Target Pad Separation):** การแยกตัวของรอยต่อระหว่างก้นหลุม Microvia กับผิวหน้าของ Target Pad ด้านล่าง (พบมากที่สุดและอันตรายที่สุด!)
   - **Type B (Barrel Shear / Fatigue):** การขาดสะบั้นของเนื้อกระบอก Microvia จากแรงเฉือน
   - **Type C (Corner / Knee Crack):** การแตกร้าวที่มุมขอบปากรูระหว่าง Microvia กับ Capture Pad
2. **กลไกทางฟิสิกส์ (Root Cause Mechanism):**
   - **Z-axis CTE Mismatch:** เมื่อบอร์ดผ่านเตาอบ Reflow ที่อุณหภูมิ $260^\circ\text{C}$ อุณหภูมิจะพุ่งทะลุจุดกลายเป็นแก้ว ($T_g \approx 150 - 175^\circ\text{C}$) ของเนื้อฉนวนเรซิน ส่งผลให้อัตราการขยายตัวในแนวแกนดิ่ง ($CTE_z$) พุ่งสูงแตะ **$200 - 300 \text{ ppm/}^\circ\text{C}$** ในขณะที่ทองแดงขยายตัวเพียง $17 \text{ ppm/}^\circ\text{C}$
   - ความต่างของการขยายตัวถึง 15 เท่านี้นี้ สร้างแรงดึงกระชากในแนวดิ่ง (Tensile Stress มหาศาลระดับร้อยเมกะปาสคาล)
   - หากขั้นตอนการทำความสะอาดคราบเรซินก้นหลุม (Desmear Process) ทำได้ไม่สมบูรณ์ หรือชั้นทองแดงเคมี (Electroless Copper Seed Layer) บางและมีสิ่งเจือปน รอยต่อนี้จะฉีกขาดออกจากกันในระดับไมครอน ก่อให้เกิดอาการเครื่องดับแบบสุ่ม (Intermittent Disconnection)

### 1.3 การประเมินความเสี่ยง: Stacked Microvias vs Staggered Microvias

```
     Structure A: Stacked (High Risk!)             Structure B: Staggered (High Reliability)
        L1-L2 μVia ──► [===]                          L1-L2 μVia ──► [===]
        L2-L3 μVia ──► [===]                                         ▲
        L3-L4 μVia ──► [===]                                         │ Staggered Offset d
                       Solid Copper Column                           ▼
                       (Stress Concentration!)                       [===] ◄── L2-L3 μVia
                                                                               ▲
                                                                               │ Offset d
                                                                               ▼
                                                                             [===] ◄── L3-L4 μVia
```

| ปัจจัยการเปรียบเทียบ | Stacked Microvias (ซ้อนตรง) | Staggered Microvias (เยื้องศูนย์) |
|---|---|---|
| **พื้นที่การทำ Layout** | **ประหยัดพื้นที่สูงสุด** (กินพื้นที่พิกัดเดียว) | ต้องใช้พื้นที่กระจายตัวในแนวนอน |
| **ระดับความเค้นรวม (Stress)** | **รุนแรงสูงสุด** (แรงดึงสะสมตลอดความสูงของแท่งทองแดง) | **ต่ำมาก** (เนื้อฉนวนระหว่างชั้นช่วยดูดซับแรงดึง) |
| **ความทนทานต่อ Reflow ($260^\circ\text{C}$)** | แตกหักง่ายหากซ้อนกันเกิน 2 ชั้น ($> 2$ Stacks) | **ทนทานยอดเยี่ยม ผ่าน 6x Reflow สบายๆ** |
| **ความยากในกระบวนการผลิต** | สูงมาก (ต้องเติมทองแดงแบนราบ $100\%$ ทุกชั้น) | ปานกลาง (ควบคุมพิกัดการจัดวางตำแหน่ง) |
| **คำแนะนำระดับมาตรฐาน IPC** | **ห้ามใช้เกิน 2 ชั้นในงาน High-Reliability** | **เป็นตัวเลือกอันดับหนึ่งสำหรับยานยนต์/การแพทย์** |

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** อุปกรณ์ตรวจวัดทางการแพทย์แบบพกพาที่ใช้บอร์ด HDI โครงสร้าง 3+8+3 (Any-Layer Stacked Microvias) ผ่านการทดสอบจากโรงงาน $100\%$ แต่เมื่อส่งไปใช้งานจริงในโรงพยาบาลได้ 4 เดือน เกิดปัญหาเครื่องดับและรีบูตตัวเองแบบสุ่ม (Intermittent System Crashes) คิดเป็นอัตราเคลมสูงถึง **$14.2\%$**
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **ออกแบบ Stacked Microvia ซ้อนตรงกัน 3 เลเยอร์ (L1-L2, L2-L3, L3-L4):** เพื่อประหยัดพื้นที่ใต้ BGA พิตช์ $0.4 \text{ mm}$ วิศวกรวาง Microvia ซ้อนทับกันตรงๆ 3 ชั้น
2. **เกิด Type A Target Pad Separation ใต้ L2-L3 Interface:**  
   ภาพถ่ายกล้องจุลทรรศน์อิเล็กตรอนแบบส่องกราด (SEM Cross-Section) เผยให้เห็นรอยแยกขาด (Crack Void ขนาด $1.2 \ \mu\text{m}$) ที่รอยต่อระหว่างก้นหลุม L2-L3 กับผิวหน้า L3 Pad
3. **การสัมผัสแบบแตะปล่อยตามอุณหภูมิ:** เมื่อชิปทำงานและมีความร้อน บอร์ดขยายตัวทำให้รอยแยกอ้าออก (วงจรเปิด) และเมื่อเครื่องเย็นลง บอร์ดหดตัวทำให้รอยต่อแตะกลับมาทำงานได้ใหม่ จึงตรวจไม่พบด้วยมิเตอร์ทั่วไป

---

### ขั้นตอนการออกแบบและควบคุม HDI สไตล์ Senior Engineer (検図チェックリスト):
1. **กฎการจำกัด Stacked Microvia (Maximum 2-Layer Stack Rule):**
   - **กฎเหล็กความปลอดภัย:** ห้ามออกแบบ Stacked Microvias ซ้อนกันเกิน **2 เลเยอร์** เด็ดขาดในทุกผลิตภัณฑ์
   - หากจำเป็นต้องเชื่อมต่อลงสู่ชั้นในเกิน 2 เลเยอร์ขึ้นไป ให้เปลี่ยนไปใช้โครงสร้าง **Staggered Microvias (เยื้องศูนย์)**
2. **การกำหนดระยะเยื้องศูนย์ปลอดภัยของ Staggered Microvia ($d_{offset}$):**
   - กำหนดระยะห่างระหว่างศูนย์กลางของ Microvia ชั้นบนและชั้นล่าง:
     $$d_{offset} \ge D_{pad} + 0.05 \text{ mm} \ (2 \text{ mil})$$
   - เพื่อรับประกันว่าขอบของรูเจาะเลเซอร์ชั้นบนจะไม่ไปเหยียบหรือทับซ้อนกับขอบหลุมของชั้นล่าง ซึ่งจะทำให้เกิดจุดรวมความเค้น (Stress Concentration)
3. **การเลือกใช้วัสดุ Low-CTE Substrate สำหรับงาน HDI:**
   - สำหรับบอร์ดที่มีโครงสร้างเลเซอร์ Microvia หลายชั้น ต้องระบุสเปกวัสดุแกนและพรีเพร็กที่มีค่าการขยายตัวในแนวแกนดิ่งต่ำพิเศษ:
     > *"Dielectric material MUST have low Z-axis CTE: alpha-1 (below Tg) <= 40 ppm/C, alpha-2 (above Tg) <= 200 ppm/C, with Tg >= 170 C (e.g. Isola FR408HR, Panasonic Megtron 6, or Shengyi S1000-2M)."*
4. **การตรวจสอบคุณภาพการเติมทองแดง (Copper Dimple Requirement):**
   - สั่งให้โรงงานควบคุมความลึกของรอยบุ๋มกึ่งกลาง Microvia (Dimple Depth) ให้ **ไม่เกิน $10 - 15 \ \mu\text{m}$** (และต้อง $\le 5 \ \mu\text{m}$ หากเป็นจุดวางลูกบอล BGA) เพื่อป้องกันไม่ให้เกิดฟองอากาศใต้รอยต่อบัดกรี

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「0.4mmピッチBGAファンアウト部において、L1-L2、L2-L3、L3-L4の3層連続スタックマイクロビア（Stacked μVia）が適用されています。IPC-WP-023警告白書に示される通り、鉛フリーリフロー（260℃）時のZ軸方向の熱膨張応力集中により、L2-L3間ターゲットパッド界面剥離（Type A断線故障）が発生するリスクが極めて高いです。信頼性を担保するため、3層スタック構造を禁止し、L2-L3以降をオフセット配置（中心間距離d≧0.25mm）とする「スタガードマイクロビア構造」へ設計変更してください。」  
> *(ในบริเวณ BGA พิตช์ 0.4mm มีการใช้ Stacked Microvia ซ้อนตรงกัน 3 ชั้น L1-L2-L3-L4 ตามประกาศเตือน IPC-WP-023 ความเค้นดึงในแนวแกน Z ในเตาอบ 260°C จะทำให้เกิดการฉีกขาดของ Target Pad ที่รอยต่อ L2-L3 ขอสั่งห้ามซ้อน 3 ชั้น และให้เปลี่ยนไปใช้ Staggered Microvia เยื้องศูนย์ระยะห่าง d>=0.25mm แทน)*

> **指摘事項 2:**  
> 「車載ミリ波レーダー向けHDI基板仕様書において、プリプレグ材のZ軸CTEに関する規定が欠落しています。レーザービア接合部の長期信頼性（冷熱サイクル試験-40℃～125℃/2000サイクル）を保証するため、基板材料仕様に「高Tg（Tg≧175℃）かつ低Z軸CTE（Tg以下で35ppm/℃以下、Tg以上で180ppm/℃以下）」を必須製造条件として明記してください。」  
> *(ในสเปกบอร์ด HDI เรดาร์ยานยนต์ขาดการกำหนดค่า Z-axis CTE ของพรีเพร็ก เพื่อรับประกันความทนทานต่อ Thermal Cycling -40°C ถึง 125°C 2000 รอบ กรุณาระบุในสเปกบังคับให้ใช้วัสดุ High-Tg >= 175°C และ Low Z-CTE <= 35 ppm/°C ใต้จุด Tg และ <= 180 ppm/°C เหนือจุด Tg)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณการยืดตัวของแผ่นบอร์ดในแนวแกน Z ระหว่างบัดกรี 260°C)
บอร์ด Multi-layer HDI มีความหนาของชั้นฉนวนเรซินรวม $H = 1.0 \text{ mm}$ อุณหภูมิห้องทดสอบอยู่ที่ $25^\circ\text{C}$ วัสดุมีค่าจุดหลอมแก้ว $T_g = 150^\circ\text{C}$ โดยมีอัตราการขยายตัวความร้อนแนวแกน Z ช่วงต่ำกว่า $T_g$ เท่ากับ $\alpha_1 = 40 \text{ ppm/}^\circ\text{C}$ และช่วงสูงกว่า $T_g$ พุ่งขึ้นเป็น $\alpha_2 = 250 \text{ ppm/}^\circ\text{C}$ หากนำบอร์ดเข้าเตาอบ Reflow ที่อุณหภูมิสูงสุด $260^\circ\text{C}$ ถามว่าความหนาของบอร์ดในแนวแกน Z จะยืดตัวขยายออก ($\Delta H_{total}$) เป็นระยะทางกี่ไมครอน ($\mu\text{m}$)?

- **ก)** $\Delta H_{total} \approx 5.0 \ \mu\text{m}$
- **ข)** $\Delta H_{total} \approx 32.5 \ \mu\text{m}$
- **ค)** $\Delta H_{total} \approx 65.0 \ \mu\text{m}$
- **ง)** $\Delta H_{total} \approx 10.4 \ \mu\text{m}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> แบ่งการคำนวณการขยายตัวออกเป็น 2 ช่วงอุณหภูมิ:  
> 1. ช่วงที่ 1: จาก $25^\circ\text{C}$ ถึง $T_g = 150^\circ\text{C}$ ($\Delta T_1 = 125^\circ\text{C}$):  
> $$\Delta H_1 = H \times \alpha_1 \times \Delta T_1 = (1.0 \times 10^{-3} \text{ m}) \times (40 \times 10^{-6} \text{ /}^\circ\text{C}) \times 125^\circ\text{C}$$  
> $$\Delta H_1 = 5.0 \times 10^{-6} \text{ m} = \mathbf{5.0 \ \mu\text{m}}$$  
> 2. ช่วงที่ 2: จาก $150^\circ\text{C}$ ถึง $260^\circ\text{C}$ ($\Delta T_2 = 110^\circ\text{C}$):  
> $$\Delta H_2 = H \times \alpha_2 \times \Delta T_2 = (1.0 \times 10^{-3} \text{ m}) \times (250 \times 10^{-6} \text{ /}^\circ\text{C}) \times 110^\circ\text{C}$$  
> $$\Delta H_2 = 27.5 \times 10^{-6} \text{ m} = \mathbf{27.5 \ \mu\text{m}}$$  
> 3. การยืดตัวรวมทั้งหมด ($\Delta H_{total}$):  
> $$\Delta H_{total} = \Delta H_1 + \Delta H_2 = 5.0 \ \mu\text{m} + 27.5 \ \mu\text{m} = \mathbf{32.5 \ \mu\text{m}}$$  
> การที่บอร์ดยืดตัวหนาขึ้นถึง $32.5 \ \mu\text{m}$ ในแนวดิ่ง ในขณะที่กระบอก Microvia เลเซอร์มีความสูงเพียงไม่กี่ร้อยไมครอน จะสร้างแรงดึงกระชากในแนวดิ่งอย่างมหาศาล หากใช้โครงสร้าง Stacked ซ้อนตรงกัน รอยต่อก้นหลุมของ Microvia จะถูกดึงจนขาดสะบั้นออกจาก Target Pad ทันที

---

### ข้อที่ 2 (ทำไม IPC-WP-023 จึงจัดว่า Target Pad Separation เป็น Latent Defect ที่อันตรายที่สุด?)
เหตุใดความล้มเหลวแบบ Target Pad Separation (Type A) ตามเอกสารเตือนภัย IPC-WP-023 จึงถูกจัดเป็น "ความบกพร่องแฝง (Latent Defect)" ที่สร้างความเสียหายร้ายแรงที่สุดในวงการอุตสาหกรรม?

- **ก)** เพราะทำให้เกิดควันพิษระหว่างการใช้งาน
- **ข)** เพราะในขั้นตอนการทดสอบไฟฟ้าที่โรงงานผลิตบอร์ด (ICT / Flying Probe) รอยต่อที่ฉีกขาดระดับไมครอนอาจยังคงถูกแรงกดทางกลหรือความเค้นบีบให้แตะสัมผัสกันอยู่ จึงวัดค่าความต้านทานผ่าน $100\%$ แต่เมื่อส่งมอบไปประกอบเป็นผลิตภัณฑ์และมีการเปลี่ยนแปลงของอุณหภูมิใช้งานจริง รอยต่อจะอ้าขาดออกจากกัน ทำให้เครื่องดับแบบสุ่มและไม่สามารถหาสาเหตุได้ง่าย
- **ค)** เพราะเครื่องเอกซเรย์ X-ray ไม่สามารถมองเห็นทองแดงได้
- **ง)** เพราะทำให้บอร์ดเปลี่ยนสีเป็นสีดำ

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ความน่ากลัวที่สุดของ Type A Target Pad Separation คือ "มันผ่านการทดสอบที่โรงงานทั้งหมด!":  
> ในระหว่างการทดสอบ Electrical Test ที่โรงงาน บอร์ดอยู่ในสภาวะอุณหภูมิห้อง ($25^\circ\text{C}$) รอยฉีกขาดระดับไมครอนที่ก้นหลุมยังคงถูกความยืดหยุ่นของเนื้อเรซินกดให้สัมผัสกันทางกล (Mechanical Contact) กระแสไฟฟ้าจึงยังคงไหลผ่านได้ตามปกติ  
> แต่เมื่อนำบอร์ดไปประกอบชิ้นส่วน หรือเมื่อผู้ใช้งานเปิดเครื่องจนเกิดความร้อนสะสม บอร์ดจะขยายตัวและดันให้รอยต่อแยกอ้าออกจากกัน เกิดสภาวะ Open Circuit ทันที และเมื่อปิดเครื่องจนเย็นลง รอยต่อจะหดกลับมาแตะกันใหม่  
> อาการ "ติดๆ ดับๆ ตามอุณหภูมิ" นี้สร้างความเสียหายต่อชื่อเสียงและค่าใช้จ่ายในการเคลมสินค้าระดับมหาศาล เอกสาร IPC-WP-023 จึงถูกร่างขึ้นเพื่อบังคับใช้วิธีทดสอบแบบ OM-Test (วัดความต้านทานต่อเนื่องระหว่างอบความร้อน)

### ข้อที่ 3 (กฎอัตราส่วน Aspect Ratio สำหรับ Laser Microvia ตาม IPC-2226)
ตามมาตรฐานการออกแบบบอร์ดความหนาแน่นสูง IPC-2226 สำหรับ Laser Microvia ค่าขีดจำกัดของอัตราส่วน Aspect Ratio ($AR_{\mu via} = H_{layer} / D_{laser}$) สูงสุดที่แนะนำให้ใช้เพื่อรับประกันความสมบูรณ์ของการชุบทองแดงเต็มหลุม (Void-free Copper Plating) มีค่าเท่ากับข้อใด?

- **ก)** $AR_{\mu via} \le 8:1$
- **ข)** $AR_{\mu via} \le 0.75:1$ (หรือไม่เกิน $1.0:1$ เป็นเกณฑ์สูงสุด)
- **ค)** $AR_{\mu via} \ge 3:1$
- **ง)** ไม่มีข้อจำกัดด้าน Aspect Ratio สำหรับเลเซอร์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> แตกต่างจากการเจาะรูทะลุ Through-Hole ซึ่งเป็นท่อเปิดสองด้าน:  
> Laser Microvia เป็น **"หลุมปลายตัน (Blind Hole / Blind Via)"** ที่มีก้นหลุมปิดสนิท  
> ในกระบวนการชุบเคมีไฟฟ้า สารละลายคอปเปอร์ซัลเฟตและสารเร่งปฏิกิริยา (Brightener / Leveler) จะต้องไหลเวียนเข้าไปแทนที่ฟองอากาศและพอกทองแดงจากก้นหลุมขึ้นมาสู่ปากหลุม (Bottom-up Superfilling)  
> หากหลุมมีความลึกมากกว่าความกว้าง ($AR > 1:1$ เช่น รูเจาะกว้าง $80 \ \mu\text{m}$ แต่เจาะลึก $120 \ \mu\text{m}$):  
> ปากหลุมด้านบนจะถูกทองแดงชุบปิดทางเข้าก่อนที่ทองแดงก้นหลุมจะโตทัน เกิดเป็นโพรงอากาศขนาดใหญ่ (Entrapped Air Void) ฝังอยู่ภายในหลุม  
> ดังนั้น มาตรฐาน IPC-2226 จึงกำหนดเกณฑ์ปลอดภัยสูงสุดไว้ที่ **$AR_{\mu via} \le 0.75:1$ ถึง $1.0:1$** อย่างเคร่งครัด
