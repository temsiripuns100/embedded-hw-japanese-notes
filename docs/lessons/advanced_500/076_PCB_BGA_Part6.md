## 1. ทฤษฎีวิศวรรรมเชิงลึก (高度なエンジニアリング理論)

ในวงการออกแบบอุปกรณ์พกพาขนาดเล็ก (Mobile & Wearable Devices), กล้องความเร็วสูง, และโมดูลปัญญาประดิษฐ์ฝังตัว (Edge AI Embedded Modules) ตัวถัง BGA ได้วิวัฒนาการไปสู่พิกัดความละเอียดระดับสูงมากที่เรียกว่า **Ultra-Fine Pitch BGA (ระยะพิตช์ $P \le 0.40\text{ mm}$ และลงไปถึง $0.35\text{ mm} - 0.30\text{ mm}$)**

ที่พิตช์ระดับนี้ กฎเกณฑ์การออกแบบและการผลิตแผงวงจรแบบเดิม (Conventional Subtractive Process) ไม่สามารถตอบสนองความต้องการได้อีกต่อไป วิศวกรอาวุโสต้องเปลี่ยนผ่านกระบวนทัศน์ทางวิศวกรรมไปสู่ **เทคโนโลยี Semi-Additive Process (mSAP)** และ **Any-Layer High-Density Interconnect (Every Layer Interconnect - ELIC)** เพื่อจัดการกับข้อจำกัดทางเรขาคณิต, ปรากฏการณ์การกัดกร่อนใต้แนวทองแดง (Etch Undercut), และค่าความคลาดเคลื่อนของการวางหน้ากากประสาน (Solder Mask Registration Tolerance)

```
+-----------------------------------------------------------------------------------------+
|                  Subtractive Etching vs. Semi-Additive Process (mSAP)                   |
|                                                                                         |
|   [ 1. Conventional Subtractive Process ]       [ 2. Semi-Additive Process (mSAP) ]     |
|       (Severe Undercut / Trapezoidal Trace)         (Near-Vertical 90° Rectangular Walls)|
|                                                                                         |
|       Dry Film Photoresist                           Dry Film Photoresist Pattern       |
|            ┌──────────┐                                   ┌────┐     ┌────┐             |
|            │   Resist │                                   │ R  │     │ R  │             |
|       ─────┴──────────┴─────                        ──────┴────┴─────┴────┴──────       |
|         / Etch Undercut \                             │ Plated Cu │ Plated Cu │         |
|        /                 \                            │  (Trace)  │  (Trace)  │         |
|       ┌───────────────────┐                         ──┴───────────┴───────────┴──       |
|       │  Thick Base Cu    │                         Thin Seed Copper Layer (1.5 μm)     |
|       ═════════════════════                         ═════════════════════════════       |
|         Dielectric Core                                Dielectric Core                  |
|                                                                                         |
|       Etch Factor EF = 2.0 - 2.5                    Etch Factor EF >= 5.0               |
|       Min Line/Space: 75 / 75 μm                    Min Line/Space: 25 / 25 μm          |
+-----------------------------------------------------------------------------------------+
```

### 1.1 ข้อจำกัดทางฟิสิกส์ของการกัดกรดทองแดง และดัชนี Etch Factor ($EF$)

ในกระบวนการกัดกรดทองแดงแบบลบออก (Subtractive Process) แผ่นทองแดงหนาตั้งต้น (เช่น $18\ \mu\text{m}$ หรือ $1/2\text{ oz}$) จะถูกกัดกรดเคมี (Chemical Etching) ออกจากด้านบนลงสู่ด้านล่าง:

#### 1. การกัดเซาะด้านข้าง (Isotropic Undercutting):
น้ำยาเคมีกัดกรดจะกัดลงในแนวดิ่งพร้อมกับกัดเซาะขยายออกไปทางด้านข้างใต้แผ่นฟิล์มแห้ง (Resist) ในอัตราที่ใกล้เคียงกัน ส่งผลให้เส้นทองแดงมีหน้าตัดเป็น **รูปสี่เหลี่ยมคางหมู (Trapezoidal Cross-section)**

#### 2. นิยามของ Etch Factor ($EF$):
$$EF = \frac{2 \cdot T_{\text{Cu}}}{W_{\text{bottom}} - W_{\text{top}}}$$

โดยที่:
- $T_{\text{Cu}}$ = ความหนาของชั้นทองแดง ($\mu\text{m}$)
- $W_{\text{bottom}}$ = ความกว้างของเส้นทองแดงที่ฐานล่าง ($\mu\text{m}$)
- $W_{\text{top}}$ = ความกว้างของเส้นทองแดงที่ผิวด้านบน ($\mu\text{m}$)

ในกระบวนการ Subtractive ค่า $EF$ เฉลี่ยอยู่ที่เพียง $2.0 - 2.5$ หากต้องการทำเส้นกว้าง $30\ \mu\text{m}$ บนทองแดงหนา $18\ \mu\text{m}$:
$$W_{\text{bottom}} - W_{\text{top}} = \frac{2 \times 18}{2.0} = 18\ \mu\text{m}$$
นั่นหมายความว่า หากผิวด้านบนกว้าง $30\ \mu\text{m}$ ฐานล่างจะกว้างถึง $48\ \mu\text{m}$ ซึ่งจะไปชนลัดวงจรกับเส้นข้างเคียงทันที ทำให้กระบวนการ Subtractive ติดขีดจำกัดทางกายภาพที่ไม่สามารถทำ Line/Space ต่ำกว่า $75/75\ \mu\text{m}$ ($3/3\text{ mil}$) ได้อย่างคุ้มค่าผลผลิต (Yield)

#### 3. สถาปัตยกรรม Semi-Additive Process (mSAP):
- ใช้แผ่นไดอิเล็กทริกที่เคลือบด้วยชั้นทองแดงตั้งต้นบางเฉียบระดับไมครอน (Ultra-thin Seed Copper Layer หนาเพียง $1.5 - 2.0\ \mu\text{m}$)
- วางฟิล์มกันแสงฉลุลาย แล้วใช้การชุบโลหะด้วยไฟฟ้า (Electroplating) เติมเนื้อทองแดงขึ้นมาเฉพาะในช่องเปิด
- ลอกฟิล์มกันแสงออกแล้วกัดล้างชั้น Seed Layer บาง ๆ ออกอย่างรวดเร็ว (Flash Etching)
- **ผลลัพธ์:** ผนังด้านข้างของเส้นทองแดงตั้งฉากเกือบ $90^\circ$ ค่า $EF \ge 5.0$ และสามารถผลิตเส้นทองแดงและช่องว่างได้แคบถึง **$25/25\ \mu\text{m}$ ($1/1\text{ mil}$)** ด้วยความแม่นยำทางอิมพีแดนซ์สูงมาก

### 1.2 เรขาคณิตของช่องสัญญาณรอดใต้ Ultra-Fine Pitch BGA ($0.40\text{ mm}$ และ $0.35\text{ mm}$)

มาวิเคราะห์พื้นที่ช่องสัญญาณลอด (Routing Channel) ทางเรขาคณิตสำหรับ BGA พิตช์แคบ:

```
+-----------------------------------------------------------------------------------------+
|                  0.40 mm & 0.35 mm Pitch Geometric Channel Breakdown                    |
|                                                                                         |
|       <──────────────────── Pitch P = 0.40 mm (400 μm) ───────────────────>             |
|                                                                                         |
|       ┌──────────────┐         Routing Channel W_ch         ┌──────────────┐            |
|       │   BGA Pad    │◄────────────────────────────────────►│   BGA Pad    │            |
|       │ D_pad=220 μm │  Clearance  Trace Width  Clearance   │ D_pad=220 μm │            |
|       │              │    C_clr       W_tr        C_clr     │              │            |
|       └──────────────┘◄──────────►◄──────────►◄──────────►  └──────────────┘            |
|              ▲           65 μm        50 μm       65 μm            ▲                    |
|              │                                                     │                    |
|       Pad Center Line                                       Pad Center Line             |
+-----------------------------------------------------------------------------------------+
```

#### การคำนวณช่องว่างสำหรับ BGA Pitch $0.40\text{ mm}$ ($400\ \mu\text{m}$):
- กำหนดขนาด BGA Pad ขั้นต่ำ: $D_{\text{pad}} = 220\ \mu\text{m}$ ($0.22\text{ mm}$)
- ระยะช่องเปิดว่างระหว่างขอบแพด:
  $$W_{\text{clearance}} = P - D_{\text{pad}} = 400\ \mu\text{m} - 220\ \mu\text{m} = 180\ \mu\text{m}$$
- หากใช้มาตรฐาน Subtractive ขั้นสูง ($W_{\text{trace}} = 60\ \mu\text{m}, C_{\text{clr}} = 60\ \mu\text{m}$):
  $$W_{\text{required}} = 60 + (2 \times 60) = 180\ \mu\text{m}$$
  (สามารถลากเส้นเดี่ยวรอดได้ 1 เส้นแบบแตะขีดจำกัดพอดี แต่เสี่ยงต่อการลัดวงจรสูงมากเมื่อบอร์ดขยายตัว)

#### การคำนวณช่องว่างสำหรับ BGA Pitch $0.35\text{ mm}$ ($350\ \mu\text{m}$):
- กำหนดขนาด BGA Pad ขั้นต่ำ: $D_{\text{pad}} = 200\ \mu\text{m}$ ($0.20\text{ mm}$)
- ระยะช่องเปิดว่างระหว่างขอบแพด:
  $$W_{\text{clearance}} = 350\ \mu\text{m} - 200\ \mu\text{m} = 150\ \mu\text{m}$$
- หากไม่ใช้กระบวนการ mSAP ($W_{\text{trace}} \le 35\ \mu\text{m}, C_{\text{clr}} \le 55\ \mu\text{m}$):
  จะไม่สามารถลากเส้นสัญญาณออกจากชั้นผิวนอกได้เลย!
- **กฎเหล็กของวิศวกร:** สำหรับ BGA Pitch $\le 0.40\text{ mm}$ พินสัญญาณตั้งแต่แถวที่ 2 เป็นต้นไป **ต้องมุดลงแนวดิ่งด้วยโครงสร้าง Micro-via in Pad (VIPPO) ทันที 100%** ไม่สามารถทำ Dog-bone Fanout บนผิวด้านนอกได้

### 1.3 สถาปัตยกรรม Any-Layer HDI (Every Layer Interconnect - ELIC)

ในโครงสร้าง HDI ทั่วไป (เช่น $1+N+1$ หรือ $2+N+2$) จะมีแกนกลางเป็น Through-hole Core แต่สำหรับ Ultra-fine Pitch BGA แกนกลางนี้จะกลายเป็นสิ่งกีดขวางการเดินสาย จึงต้องใช้ **Any-Layer HDI**:

```
[ 10-Layer Any-Layer HDI (ELIC) Cross-Section ]
   L1  [Pad]──┐ (Laser Micro-via filled with Solid Cu)
   L2        [Via]──┐
   L3              [Via]──┐
   L4                    [Via]──┐
   L5                          [Via] (Arbitrary Any-to-Any Layer Connection!)
   L6                          [Via]
   L7                    [Via]──┘
   L8              [Via]──┘
   L9        [Via]──┘
   L10 [Pad]──┘
```

1. **โครงสร้างแบบไร้แกน Through-hole (Coreless / Full Micro-via):** ทุกเลเยอร์เชื่อมต่อกันด้วย Laser Micro-vias ที่ผ่านการชุบทองแดงเต็มหลุม (Solid Copper Filled Vias)
2. **อิสระในการวางเวีย (Zero Stub & Any-to-Any Interconnect):** วิศวกรสามารถวาง Micro-via ซ้อนทับกัน (Stacked) จากเลเยอร์ใดไปยังเลเยอร์ใดก็ได้โดยตรง ไม่มีติ่งเวีย (Via Stub $= 0$) และไม่มีรอยเจาะทะลุไปรบกวนเลเยอร์อื่น
3. **การชุบทองแดงปิดหลุมเวียในแพด (Micro-via in Pad Dimple Spec):**
   - ใน BGA Pitch $0.35\text{ mm}$ ปริมาตรครีมบัดกรีที่พิมพ์ลงบนแพดมีขนาดเล็กมากเพียง $\approx 0.003\text{ mm}^3$
   - หากผิวหน้าของ Micro-via in Pad มีรอยเว้าบุ๋ม (Dimple Depth) เกินกว่า $5\ \mu\text{m}$ ครีมบัดกรีจะถูกกักขังในหลุม ทำให้ปริมาณเนื้อตะกั่วสำหรับเชื่อมกับบอล BGA ไม่เพียงพอ เกิดเป็นข้อบกพร่อง Open Joint ทันที

### 1.4 ค่าความคลาดเคลื่อนของการเปิดหน้ากาก Solder Mask (Registration Tolerance)

ในการผลิต Ultra-Fine Pitch BGA ปัญหาคอขวดที่แท้จริงมักไม่ได้อยู่ที่การทำเส้นทองแดง แต่อยู่ที่ **ความแม่นยำในการเปิดช่อง Solder Mask**:

| พารามิเตอร์ของ Solder Mask | การผลิตมาตรฐาน (Standard Film Tooling) | การผลิตขั้นสูง (Laser Direct Imaging - LDI) | ผลกระทบต่อ BGA Pitch $\le 0.40\text{ mm}$ |
| :--- | :--- | :--- | :--- |
| **ความคลาดเคลื่อนตำแหน่ง (Registration)** | $\pm 35\ \mu\text{m}$ ($1.4\text{ mil}$) | $\pm 10\ \mu\text{m}$ ($0.4\text{ mil}$) | หากใช้ Film Mask ช่องเปิดจะเบี้ยวไปทับแพดข้างเคียง |
| **ความกว้างเขื่อนกั้นขั้นต่ำ (Dam Width)** | $\ge 75\ \mu\text{m}$ ($3.0\text{ mil}$) | $\ge 45\ \mu\text{m}$ ($1.8\text{ mil}$) | หาก Dam หลุดลอก ตะกั่วจะไหลข้ามช็อต (Solder Bridging) |
| **ช่องว่างเปิดรอบแพด (Mask Clearance)** | $50 - 75\ \mu\text{m}$ ต่อข้าง | $20 - 25\ \mu\text{m}$ ต่อข้าง | ตัดสินว่าแผงบอร์ดสามารถใช้โครงสร้าง NSMD ได้หรือไม่ |

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例 - Shippai Jirei)

**เหตุการณ์:** การพัฒนาสมาร์ตวอตช์ระดับพรีเมียม (Next-Gen 5G Cellular Smartwatch) ที่ใช้ชิปประมวลผลหลัก System-on-Chip (SoC) ในตัวถัง Ultra-Fine Pitch WLCSP/BGA ขนาด $6.5 \times 6.5\text{ mm}$ จำนวน 496 พิน ระยะพิตช์แคบเพียง $0.35\text{ mm}$ บนแผงวงจร Any-Layer HDI หนา $0.60\text{ mm}$ (10 ชั้นเลเยอร์):
1. ในขั้นตอนการผลิตแผง PCB เปล่าที่โรงงาน พบอัตราผลผลิตต่ำเตี้ยเรี่ยดินเพียง $44\%$ เนื่องจากเกิดการขาดวงจร (Open Circuit) บนเส้นส่งสัญญาณ LPDDR4X ความกว้าง $35\ \mu\text{m}$ และพบอาการแตกรอยหยัก (Copper Necking)
2. เมื่อนำบอร์ดที่ผ่านการทดสอบไฟฟ้าไปประกอบ SMT พบข้อบกพร่องการลัดวงจรใต้ BGA (Solder Bridging) สูงถึง $28\%$ บริเวณแถวพินด้านนอก

```
+-----------------------------------------------------------------------------------------+
|                  RCA: Ultra-Fine Pitch Subtractive Failure & Mask Shift                 |
|                                                                                         |
|   [ ปัญหาที่ 1: Subtractive Undercut & Necking ]  [ ปัญหาที่ 2: Solder Mask Dam Peeling]|
|                                                                                         |
|       Resist Film (Nominal: 35 μm)                  BGA Pad 1           BGA Pad 2       |
|            ┌──────────┐                            ┌─────────┐         ┌─────────┐      |
|            │          │                            │ Cu Pad  │         │ Cu Pad  │      |
|       ─────┴──────────┴─────                       └────┬────┘         └────┬────┘      |
|        / Severe Acid Trap \                             │  Mask Shift 35 μm │           |
|       /   Etch Undercut!   \                       ═════╧═══════       ═════╧══════     |
|      (    Open Circuit!     )                      Dam Width collapsed from 50 to 15 μm!|
|       \                    /                       Solder Mask Dam Broken / Flaked!     |
|       ══════════════════════                       Molten Solder Bridges Pads 1 & 2!    |
|         Dielectric Substrate                       (Short Circuit Defect!)              |
+-----------------------------------------------------------------------------------------+
```

#### การวิเคราะห์หาสาเหตุรากเหง้า (Root Cause Analysis - RCA):
1. **สาเหตุของเส้นสัญญาณขาดและบอบบาง (Trace Necking & Opens):**
   - ทีมออกแบบสั่งผลิตบอร์ดด้วยกระบวนการ Subtractive ขั้นสูง (Advanced Subtractive) โดยใช้ทองแดงฐาน $12\ \mu\text{m}$ ($1/3\text{ oz}$) เพื่อประหยัดต้นทุนบอร์ดเทียบกับ mSAP
   - การกัดกรดทองแดงหนา $12\ \mu\text{m}$ เพื่อสร้างเส้นขนาด $35\ \mu\text{m}$ ก่อให้เกิดอัตราการกัดกร่อนด้านข้าง (Lateral Undercut) สูงมาก ทำให้หน้าตัดเส้นกลายเป็นรูปสี่เหลี่ยมคางหมูยอดแหลมที่มีความกว้างผิวด้านบนเหลือเพียง $18 - 22\ \mu\text{m}$
   - ในจุดที่มีการเลี้ยวโค้งหรือรอยต่อของแพด น้ำยาเคมีเกิดการขังตัว (Acid Trap Effect) กัดกร่อนจนเนื้อทองแดงขาดสะบั้น ส่งผลให้อิมพีแดนซ์กระโดดขึ้นไปถึง $68\ \Omega$ (เป้าหมายคือ $50\ \Omega$) และขาดวงจรในหลายจุด
2. **สาเหตุของการลัดวงจรใต้เม็ดบอล BGA (Solder Bridging):**
   - ที่ระยะพิตช์ $0.35\text{ mm}$ ($350\ \mu\text{m}$) ขนาดแลนด์แพดคือ $200\ \mu\text{m}$ ช่องว่างระหว่างแพดมีขนาดเพียง $150\ \mu\text{m}$
   - โรงงานใช้กระบวนการทาหน้ากาก Solder Mask แบบดั้งเดิมที่ใช้ฟิล์มโฟโตมาสก์ (Mylar Film Tooling) ซึ่งมีค่าความคลาดเคลื่อนของการจัดวางสูงถึง $\pm 35\ \mu\text{m}$
   - เมื่อหน้ากากขยับเคลื่อนตัว เขื่อนกั้น Solder Mask Dam ระหว่างแพดสองตัวที่ออกแบบไว้กว้าง $50\ \mu\text{m}$ ถูกบีบเหลือความกว้างจริงเพียง $15\ \mu\text{m}$
   - เขื่อนที่บางเกินไปไม่สามารถทนทานต่อแรงตึงผิวในเตาอบ Reflow และหลุดร่อนออก ทำให้ตะกั่วหลอมเหลวของเม็ดบอลทั้งสองไหลรวมกันข้ามสะพานเชื่อม เกิดการลัดวงจรทันที

#### มาตรการแก้ไขเชิงวิศวกรรม (Engineering Countermeasures):
1. **เปลี่ยนผ่านเทคโนโลยีสู่ mSAP (Semi-Additive Process):**
   - ยกระดับข้อกำหนดการผลิตแผ่น PCB เป็นกระบวนการ mSAP บนชั้นทองแดง Seed Layer หนา $1.5\ \mu\text{m}$ เพื่อสร้างเส้นสัญญาณ $35\ \mu\text{m}$ ที่มีผนังตั้งฉาก $90^\circ$ ค่า $EF \ge 5.0$ ความกว้างเส้นคงที่สม่ำเสมอ $\pm 2.5\ \mu\text{m}$ คืนค่าผลผลิตการผลิตแผ่นบอร์ดกลับสู่ระดับ $> 92\%$
2. **บังคับใช้ Laser Direct Imaging (LDI) สำหรับ Solder Mask:**
   - สั่งห้ามใช้ฟิล์ม Mylar ในการฉายแสงหน้ากาก และกำหนดให้ใช้ระบบเลเซอร์ฉายตรงดิจิทัล (LDI) ควบคุมค่า Registration Tolerance ให้อยู่ภายใน $\pm 10\ \mu\text{m}$
   - ปรับการออกแบบแพด BGA เป็นแบบ NSMD พร้อมกำหนดช่องเปิดหน้ากากแบบขยายขอบเพียง $25\ \mu\text{m}$ เพื่อการันตีว่าเขื่อนกั้น Solder Mask Dam จะมีความกว้างจริงในสายการผลิตไม่น้อยกว่า $45\ \mu\text{m}$ ตลอดเวลา ขจัดปัญหา Solder Bridging ได้ $100\%$

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณผลกระทบของ Etch Factor ต่อรูปทรงหน้าตัดและความต้านทานจำเพาะ (Trace Geometry & Impedance)

**โจทย์:**  
วิศวกรต้องการสร้างเส้นส่งสัญญาณไมโครสตริป (Microstrip) ความต้านทานเป้าหมาย $Z_0 = 50\ \Omega$ เชื่อมต่อเข้ากับพินของ Ultra-Fine Pitch BGA  
ในไฟล์ CAD ออกแบบกำหนดความกว้างเส้นทองแดงในอุดมคติเป็นสี่เหลี่ยมผืนผ้า (Ideal Rectangular Trace) กว้าง $W_{\text{ideal}} = 35.0\ \mu\text{m}$ บนชั้นทองแดงความหนา $T_{\text{Cu}} = 18.0\ \mu\text{m}$ ไดอิเล็กทริกหนา $H = 45.0\ \mu\text{m}$ ค่าคงที่ไดอิเล็กทริก $\epsilon_r = 3.8$

1. หากโรงงานผลิตด้วย **กระบวนการ Subtractive ทั่วไป** ซึ่งมีค่า Etch Factor $EF = 2.0$ โดยเครื่องกัดกรดถูกควบคุมให้ฐานล่างของเส้นทองแดงตรงตามแบบ ($W_{\text{bottom}} = 35.0\ \mu\text{m}$) จงคำนวณหาความกว้างของผิวด้านบนของเส้นทองแดง ($W_{\text{top}}$) และพื้นที่หน้าตัดจริงของเส้นทองแดง ($A_{\text{subtractive}}$)
2. หากโรงงานเปลี่ยนมาใช้ **กระบวนการ mSAP** ซึ่งมีค่า Etch Factor $EF = 6.0$ และควบคุมให้ฐานล่างของเส้นเท่าเดิม ($W_{\text{bottom}} = 35.0\ \mu\text{m}$) จงคำนวณหาความกว้างผิวด้านบน ($W_{\text{top, mSAP}}$) และพื้นที่หน้าตัดจริง ($A_{\text{mSAP}}$)
3. ค่าอิมพีแดนซ์ของเส้นไมโครสตริปแปรผกผันกับความกว้างเฉลี่ยของเส้นตัวนำ ($W_{\text{avg}} = \frac{W_{\text{top}} + W_{\text{bottom}}}{2}$) โดยมีสัมประสิทธิ์ความไว $\frac{\Delta Z_0}{\Delta W_{\text{avg}}} \approx -0.45\ \Omega/\mu\text{m}$ จงคำนวณหาค่าความคลาดเคลื่อนของอิมพีแดนซ์ ($\Delta Z_0$) ที่เกิดขึ้นในกระบวนการ Subtractive เทียบกับ mSAP และวิเคราะห์ว่ากระบวนการใดที่ผ่านเกณฑ์พิกัดความปลอดภัยความคลาดเคลื่อนอิมพีแดนซ์ $\pm 10\%$ ($\pm 5\ \Omega$)

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณกระบวนการ Subtractive ($EF = 2.0$):**
จากนิยามของ Etch Factor:
$$EF = \frac{2 \cdot T_{\text{Cu}}}{W_{\text{bottom}} - W_{\text{top}}} \implies W_{\text{bottom}} - W_{\text{top}} = \frac{2 \cdot T_{\text{Cu}}}{EF}$$
แทนค่า:
$$35.0\ \mu\text{m} - W_{\text{top}} = \frac{2 \times 18.0\ \mu\text{m}}{2.0} = \frac{36.0}{2.0} = 18.0\ \mu\text{m}$$
$$W_{\text{top}} = 35.0 - 18.0 = 17.0\ \mu\text{m}$$

- ความกว้างเฉลี่ยของเส้น:
  $$W_{\text{avg, sub}} = \frac{35.0 + 17.0}{2} = 26.0\ \mu\text{m}$$
- พื้นที่หน้าตัดรูปสี่เหลี่ยมคางหมู:
  $$A_{\text{subtractive}} = \frac{W_{\text{top}} + W_{\text{bottom}}}{2} \times T_{\text{Cu}} = 26.0\ \mu\text{m} \times 18.0\ \mu\text{m} = 468.0\ \mu\text{m}^2$$

---

**2. คำนวณกระบวนการ mSAP ($EF = 6.0$):**
$$W_{\text{bottom}} - W_{\text{top, mSAP}} = \frac{2 \times 18.0\ \mu\text{m}}{6.0} = \frac{36.0}{6.0} = 6.0\ \mu\text{m}$$
$$W_{\text{top, mSAP}} = 35.0 - 6.0 = 29.0\ \mu\text{m}$$

- ความกว้างเฉลี่ยของเส้น:
  $$W_{\text{avg, mSAP}} = \frac{35.0 + 29.0}{2} = 32.0\ \mu\text{m}$$
- พื้นที่หน้าตัด:
  $$A_{\text{mSAP}} = 32.0\ \mu\text{m} \times 18.0\ \mu\text{m} = 576.0\ \mu\text{m}^2$$

---

**3. คำนวณความคลาดเคลื่อนของอิมพีแดนซ์ ($\Delta Z_0$):**
ความกว้างเป้าหมายอุดมคติคือ $W_{\text{ideal}} = 35.0\ \mu\text{m}$ ($Z_0 = 50.0\ \Omega$)

- **สำหรับ Subtractive:**
  $$\Delta W_{\text{sub}} = W_{\text{avg, sub}} - W_{\text{ideal}} = 26.0 - 35.0 = -9.0\ \mu\text{m}$$
  $$\Delta Z_{\text{0, sub}} = (-9.0\ \mu\text{m}) \times (-0.45\ \Omega/\mu\text{m}) = +4.05\ \Omega$$
  อิมพีแดนซ์จริง:
  $$Z_{\text{0, actual, sub}} = 50.0 + 4.05 = 54.05\ \Omega$$
  *(หมายเหตุ: หากการกัดกรดทำให้ฐานล่างคอดลงอีกเพียง $3\ \mu\text{m}$ อิมพีแดนซ์จะพุ่งเกิน $55.5\ \Omega$ ทันที ซึ่งจะหลุดกรอบ $\pm 10\%$)*

- **สำหรับ mSAP:**
  $$\Delta W_{\text{mSAP}} = W_{\text{avg, mSAP}} - W_{\text{ideal}} = 32.0 - 35.0 = -3.0\ \mu\text{m}$$
  $$\Delta Z_{\text{0, mSAP}} = (-3.0\ \mu\text{m}) \times (-0.45\ \Omega/\mu\text{m}) = +1.35\ \Omega$$
  อิมพีแดนซ์จริง:
  $$Z_{\text{0, actual, mSAP}} = 50.0 + 1.35 = 51.35\ \Omega$$

**บทวิเคราะห์ทางวิศวกรรม:**  
กระบวนการ mSAP ให้ความแม่นยำของอิมพีแดนซ์ยอดเยี่ยม โดยคลาดเคลื่อนเพียง $+1.35\ \Omega$ ($+2.7\%$) ซึ่งอยู่ในเกณฑ์ควบคุมคุณภาพระดับเข้มงวด ($\pm 5\%$) ในขณะที่ Subtractive ทำให้เกิดการสูญเสียพื้นที่หน้าตัดตัวนำไปถึง $18.75\%$ ส่งผลให้อิมพีแดนซ์แกว่งสูงเกือบหลุดกรอบ และยังมีความต้านทาน DC ($R_{\text{DC}}$) สูงขึ้นถึง $23\%$ ซึ่งทำให้การสูญเสียสัญญาณแบบ Conductor Loss พุ่งสูงขึ้นอย่างมีนัยสำคัญ

</details>

### ข้อที่ 2: การวิเคราะห์ขีดจำกัดทางเรขาคณิตและการจัดชั้น Stackup ของ BGA Pitch $0.35\text{ mm}$

**โจทย์:**  
ชิปเซนเซอร์ขนาดจิ๋ว (Miniature Biomedical SoC) บรรจุในตัวถัง WLCSP พิตช์ $P = 0.35\text{ mm}$ ($350\ \mu\text{m}$) มีอาร์เรย์พินแบบสี่เหลี่ยมจัตุรัสเต็มพื้นที่ (Full Array) ขนาด $12 \times 12$ พิน (รวมทั้งหมด $144$ พิน)  
กำหนดขนาดเส้นผ่านศูนย์กลางแลนด์แพดบนแผง PCB: $D_{\text{pad}} = 0.20\text{ mm}$ ($200\ \mu\text{m}$)  
ในการประเมินขีดจำกัดการคลี่สาย (Escape Feasibility):
1. หากใช้เทคโนโลยี Any-Layer HDI ที่มีความสามารถผลิตเส้น Trace กว้าง $W_{\text{tr}} = 0.035\text{ mm}$ ($35\ \mu\text{m}$) และระยะห่าง Pad-to-Trace $S_{\text{clr}} = 0.050\text{ mm}$ ($50\ \mu\text{m}$) จงคำนวณว่าสามารถลากเส้นสัญญาณลอดระหว่างแพดคู่ติดกันได้หรือไม่?
2. สำหรับพินทั้งหมด 144 พิน:
   - พินในวงนอกสุด (Ring 1) มีจำนวนกี่พิน และสามารถคลี่สายออกทางผิวชั้นบน (L1) ได้กี่พิน?
   - พินในวงที่สอง (Ring 2) มีจำนวนกี่พิน และสามารถคลี่สายออกทาง L1 ได้หรือไม่?
3. หากพินวงในทั้งหมด (Ring 2 ถึง Ring 6) ต้องเจาะเวียแนวดิ่งด้วย Micro-via in Pad (VIPPO) ลงสู่ชั้นใน และขีดจำกัดของการคลี่สายในแต่ละชั้นสัญญาณด้านใน (Inner Layer) สามารถรองรับสัญญาณได้สูงสุดชั้นละ $24$ เส้น จงคำนวณหา **จำนวนชั้นสัญญาณภายในขั้นต่ำ (Minimum Inner Signal Layers)** ที่ต้องการ

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. ตรวจสอบการลากเส้นสัญญาณลอดระหว่างแพด:**
- ระยะห่างว่างระหว่างขอบแพด:
  $$W_{\text{channel}} = P - D_{\text{pad}} = 350\ \mu\text{m} - 200\ \mu\text{m} = 150\ \mu\text{m}$$
- พื้นที่ขั้นต่ำที่ต้องการสำหรับลากเส้นเดี่ยว:
  $$W_{\text{required}} = W_{\text{tr}} + 2 \cdot S_{\text{clr}} = 35\ \mu\text{m} + (2 \times 50\ \mu\text{m}) = 35 + 100 = 135\ \mu\text{m}$$
- เปรียบเทียบ:
  $$W_{\text{channel}} (150\ \mu\text{m}) > W_{\text{required}} (135\ \mu\text{m})$$
**คำตอบส่วนที่ 1:** สามารถลากเส้นสัญญาณเดี่ยว 1 เส้น ($N_{\text{tr}} = 1$) ลอดผ่านระหว่างแพดที่พิตช์ $0.35\text{ mm}$ ได้ (มีระยะเผื่อ Margin คงเหลือ $15\ \mu\text{m}$)

---

**2. คำนวณจำนวนพินในแต่ละวงรอบ (Perimeter Rings):**
- ตัวถังมีขนาด $12 \times 12$ พิน
- **วงนอกสุด (Ring 1):**
  $$N_{\text{ring1}} = 4 \times (12 - 1) = 44\ \text{พิน}$$
  พินทั้ง 44 พินนี้อยู่ขอบนอกสุด สามารถลากสายตรงออกจากตัวถังบนชั้นผิวนอก L1 ได้ทั้งหมด $100\%$ ($44$ เส้น)

- **วงที่สอง (Ring 2):**
  กรอบขนาด $(12 - 2) \times (12 - 2) = 10 \times 10$
  $$N_{\text{ring2}} = 4 \times (10 - 1) = 36\ \text{พิน}$$
  การจะคลี่สายออกจาก Ring 2 บนชั้น L1 สัญญาณจะต้องวิ่งลอดผ่านช่องว่างระหว่างแพดของ Ring 1:
  - ในแต่ละด้านของ Ring 1 มีช่องว่างระหว่างแพด $= 12 - 1 = 11$ ช่อง
  - แต่ละช่องลากได้ 1 เส้น $\to$ รวม 4 ด้านมีช่องทางลอด $= 4 \times 11 = 44$ ช่อง
  - เนื่องจากพินใน Ring 2 มีเพียง 36 พิน ซึ่งน้อยกว่า 44 ช่อง:
    **ในทางทฤษฎี พิน Ring 2 ทั้ง 36 พินสามารถคลี่สายออกทาง L1 ได้ทั้งหมด!**

---

**3. คำนวณพินคงเหลือและจำนวนชั้นสัญญาณภายใน:**
- จำนวนพินรวมใน Ring 1 และ Ring 2:
  $$N_{\text{L1\_escape}} = 44 + 36 = 80\ \text{พิน}$$
- พินวงในที่เหลืออยู่ (Ring 3 ถึง Ring 6):
  $$N_{\text{inner\_pins}} = N_{\text{total}} - N_{\text{L1\_escape}} = 144 - 80 = 64\ \text{พิน}$$
- กำหนดให้พินทั้ง 64 พินนี้เป็นพินสัญญาณที่ต้องเจาะลงชั้นใน และแต่ละชั้นสัญญาณภายในรับได้สูงสุด $24$ เส้น:
  $$L_{\text{inner\_signal}} = \left\lceil \frac{N_{\text{inner\_pins}}}{\text{Capacity per layer}} \right\rceil = \left\lceil \frac{64}{24} \right\rceil = \lceil 2.667 \rceil = 3\ \text{ชั้น}$$

**บทสรุป:**  
ต้องการชั้นสัญญาณภายในอย่างน้อย **3 ชั้นสัญญาณ (Inner Signal Layers)** เมื่อรวมกับผิวบน L1 จะมีชั้นสัญญาณทั้งหมด 4 ชั้น และเมื่อรวมกับระนาบ Ground/Power สำหรับอ้างอิงอิมพีแดนซ์ แผงวงจร Any-Layer HDI นี้จะต้องมีโครงสร้างอย่างน้อย **8 ชั้นเลเยอร์ (เช่น 1-8 Any-Layer ELIC)**

</details>

### ข้อที่ 3: การประเมินความเสี่ยงของการลัดวงจร (Solder Bridging Risk Analysis) จากค่าความคลาดเคลื่อน Solder Mask

**โจทย์:**  
การออกแบบแผงวงจรสำหรับ Ultra-Fine Pitch BGA ระยะพิตช์ $P = 0.40\text{ mm}$ ($400\ \mu\text{m}$) โดยใช้โครงสร้างแพดแบบ **Non-Solder Mask Defined (NSMD)**:
- เส้นผ่านศูนย์กลางแลนด์แพดทองแดง: $D_{\text{pad}} = 220\ \mu\text{m}$
- ช่องเปิดของหน้ากาก Solder Mask (Mask Clearance Opening): ออกแบบเผื่อขอบข้างละ $25\ \mu\text{m}$ (เส้นผ่านศูนย์กลางช่องเปิด $D_{\text{mask}} = 270\ \mu\text{m}$)
- ระยะห่างระหว่างขอบทองแดงของแพดสองตัวที่ติดกัน: $S_{\text{pad}} = P - D_{\text{pad}} = 400 - 220 = 180\ \mu\text{m}$
- ความกว้างของเขื่อนกั้นหน้ากากในอุดมคติ (Nominal Solder Mask Dam Width):
  $$W_{\text{dam, nominal}} = P - D_{\text{mask}} = 400\ \mu\text{m} - 270\ \mu\text{m} = 130\ \mu\text{m}$$

วิศวกรต้องการเปรียบเทียบความเสี่ยงในการผลิตระหว่าง 2 เทคโนโลยีการวางหน้ากาก:
- **เทคโนโลยี A (ฟิล์มโฟโตมาสก์แบบดั้งเดิม - Film Tooling):** มีค่าความคลาดเคลื่อนของการจัดวาง (Registration Tolerance) $\Delta_{\text{align, A}} = \pm 35\ \mu\text{m}$ และมีความกว้างเขื่อนกั้นขั้นต่ำก่อนฉีกขาด $W_{\text{break, A}} = 60\ \mu\text{m}$
- **เทคโนโลยี B (เลเซอร์ไดเร็กต์อิมเมจจิ้ง - LDI):** มีค่าความคลาดเคลื่อนของการจัดวาง $\Delta_{\text{align, B}} = \pm 10\ \mu\text{m}$ และมีความกว้างเขื่อนกั้นขั้นต่ำก่อนฉีกขาด $W_{\text{break, B}} = 40\ \mu\text{m}$

1. หากเกิดความคลาดเคลื่อนของการวางหน้ากากในแนวแกน X ไปในทิศทางเดียวกันในกรณีเลวร้ายที่สุด (Worst-case Alignment Shift) จงคำนวณหา **ความกว้างประสิทธิผลของเขื่อนกั้นหน้ากากจริง ($W_{\text{dam, effective}}$)** ของทั้งสองเทคโนโลยี
2. ตรวจสอบว่าเทคโนโลยีใดที่เขื่อนกั้นหน้ากากจะเกิดการฉีกขาดหรือหลุดร่อน (Dam Peeling / Breakage) ซึ่งจะนำไปสู่ความล้มเหลวของการบัดกรีลัดวงจร (Solder Bridging)
3. หากจำเป็นต้องใช้เทคโนโลยี A วิศวกรสามารถเปลี่ยนไปใช้โครงสร้าง **Solder Mask Defined (SMD)** ได้หรือไม่ และมีข้อเสียเชิงวิศวกรรมอะไรที่จะเกิดขึ้นตามมา?

<details>
<summary>เฉลยและบทวิเคราะห์เชิงวิศวกรรม</summary>

**ขั้นตอนการคำนวณ:**

**1. คำนวณความกว้างประสิทธิผลของเขื่อนกั้นหน้ากาก ($W_{\text{dam, effective}}$):**
ช่องเปิดหน้ากาก $D_{\text{mask}} = 270\ \mu\text{m}$ วางห่างกันด้วยระยะพิตช์ $P = 400\ \mu\text{m}$
- ในทางเรขาคณิต เมื่อแผ่นฟิล์มหน้ากากทั้งหมดขยับเลื่อนไปทางขวาด้วยระยะ $\Delta$:
  ช่องเปิดตัวที่ 1 เลื่อนขวา $\Delta$ และช่องเปิดตัวที่ 2 ก็เลื่อนขวา $\Delta$ เท่ากัน  
  *ระยะห่างระหว่างจุดศูนย์กลางของช่องเปิดยังคงเท่ากับพิตช์ $P$ เสมอ!*  
  ดังนั้น ความกว้างของเนื้อหน้ากากระหว่างช่องเปิดทั้งสองจะยังคงเท่ากับ:
  $$W_{\text{mask\_strip}} = P - D_{\text{mask}} = 400 - 270 = 130\ \mu\text{m}$$
- **แต่จุดวิกฤตที่แท้จริงคือ:** การที่ช่องเปิดเลื่อนเบี้ยวไปทับขอบทองแดงของแพด!
  ระยะห่างระหว่างขอบช่องเปิดของหน้ากากกับขอบทองแดงของแพดด้านตรงข้าม (Edge Clearance) ในสภาวะปกติคือ:
  $$\text{Clearance}_{\text{nominal}} = \frac{D_{\text{mask}} - D_{\text{pad}}}{2} = \frac{270 - 220}{2} = 25\ \mu\text{m}$$

- **สำหรับเทคโนโลยี A (Film Tooling, Shift $\Delta = 35\ \mu\text{m}$):**
  - ช่องเปิดหน้ากากเลื่อนเบี้ยวไป $35\ \mu\text{m}$
  - ระยะเผื่อ Clearance มีเพียง $25\ \mu\text{m}$
  - การเลื่อนเบี้ยวเกินระยะเผื่อ:
    $$\text{Overlap} = 35\ \mu\text{m} - 25\ \mu\text{m} = 10\ \mu\text{m}$$
    หน้ากาก Solder Mask จะเลื่อนขึ้นมา **ทับขอบทองแดงของแพดด้านหนึ่งลึกเข้าไป $10\ \mu\text{m}$** (กลายสภาพเป็น SMD บางส่วนแบบไม่สมมาตร)
  - ในขณะที่อีกด้านหนึ่ง ช่องเปิดขยับถอยห่างออกจากแพด ทำให้ระยะเปิดฉนวนกว้างขึ้นเป็น:
    $$\text{Clearance}_{\text{wide}} = 25 + 35 = 60\ \mu\text{m}$$
  - เมื่อนำไปรวมกับความคลาดเคลื่อนของการกัดกรดทองแดง (Etch Tolerance $\pm 15\ \mu\text{m}$) เขื่อนหน้ากากส่วนที่เหลือจะถูกบีบอัดและมีแรงยึดเกาะกับผิว FR-4 ไม่สม่ำเสมอ

---

**2. การประเมินความเสี่ยงต่อการหลุดร่อนและ Solder Bridging:**
- **สำหรับเทคโนโลยี B (LDI, Shift $\Delta = 10\ \mu\text{m}$):**
  - ระยะเลื่อน $10\ \mu\text{m}$ น้อยกว่าระยะ Clearance $25\ \mu\text{m}$
  - ช่องเปิดหน้ากากยังคงลอยตัวอยู่รอบแพดทองแดงอย่างสมบูรณ์ในทุกสภาวะ โดยมี Clearance ต่ำสุด $25 - 10 = 15\ \mu\text{m}$
  - เขื่อนกั้น Solder Mask Dam มีความกว้างสม่ำเสมอ $130\ \mu\text{m}$ ซึ่งสูงกว่าเกณฑ์วิกฤต $40\ \mu\text{m}$ อย่างมาก
  - **ผลการตัดสิน:** **ปลอดภัยสมบูรณ์ (PASS / Zero Risk of Bridging)**

- **สำหรับเทคโนโลยี A (Film Tooling):**
  - เมื่อหน้ากากเลื่อนทับขอบแพดข้างหนึ่ง และเปิดกว้างในอีกข้างหนึ่ง จะเกิดภาวะ **การกระจายแรงตึงผิวไม่สมดุล (Asymmetric Solder Surface Tension)** เมื่อตะกั่วหลอมเหลว
  - ชิป BGA จะถูกแรงดึงกระชากให้เอียงตัว (Component Skewing / Swimming) ส่งผลให้เม็ดบอลด้านข้างถูกดึงไปแตะชิดกับแพดข้างเคียงจนเกิด **Solder Bridging** อย่างรุนแรง

---

**3. การวิเคราะห์ทางเลือกการเปลี่ยนไปใช้ SMD และผลเสียเชิงวิศวกรรม:**
- หากเปลี่ยนเป็น **SMD (Solder Mask Defined)** โดยกำหนดให้ทองแดงกว้าง $270\ \mu\text{m}$ และช่องเปิดหน้ากากกว้าง $220\ \mu\text{m}$:
  - เทคโนโลยี A จะสามารถเปิดช่องบนเนื้อทองแดงได้โดยไม่ต้องกังวลเรื่องการเปิดเลยขอบ
- **แต่ข้อเสียร้ายแรงระดับ Senior ที่จะตามมาคือ:**
  1. **การลดลงของ Thermal Fatigue Life:** โครงสร้าง SMD มีจุดรวมความเค้นมุมแหลม (Sharp Stress Notch) รอบขอบหน้ากาก ทำให้อายุการใช้งานต้านทานความล้าจากการเปลี่ยนแปลงอุณหภูมิลดลง $30\% - 40\%$
  2. **ความเสี่ยง Pad Cratering:** สำหรับ BGA Pitch เล็ก $0.40\text{ mm}$ แรงดึงจากการหดตัวของชิ้นส่วนจะส่งผ่านเข้าสู่เนื้อเรซิน FR-4 ใต้ขอบหน้ากากโดยตรง ทำให้เนื้อบอร์ดฉีกขาด (Pad Cratering) ได้ง่ายมากเมื่อบอร์ดได้รับแรงตกกระแทก (Drop Impact)

**บทสรุปคำแนะนำ:**  
ห้ามแก้ปัญหาด้วยการเปลี่ยนเป็น SMD แต่ต้อง **บังคับใช้เทคโนโลยี Laser Direct Imaging (LDI) ร่วมกับโครงสร้าง NSMD** เพื่อรักษาทั้งความแม่นยำทางมิติและความทนทานเชิงกลของจุดบัดกรีสูงสุด

</details>
