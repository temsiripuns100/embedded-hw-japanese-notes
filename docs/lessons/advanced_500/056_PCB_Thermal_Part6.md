## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในแพ็กเกจเพาเวอร์อิเล็กทรอนิกส์ยุคใหม่ เช่น QFN (Quad Flat No-Lead), DFN, PowerPAD (HTSSOP), และ D2PAK/TOLL ความร้อนจากการสูญเสียพลังงาน ($P_{loss}$) มากกว่า $85\% - 95\%$ ไม่ได้ถูกพาออกผ่านตัวถังพลาสติก (Mold Compound) ด้านบน แต่จะถูกเหนี่ยวนำลงสู่ **Exposed Thermal Pad (ePad)** ด้านล่างของตัวถัง การถ่ายเทความร้อนจาก ePad ผ่านแผ่น PCB หลายชั้น (Multilayer PCB) ลงสู่ชั้น Ground Plane ภายในหรือ Bottom Layer ต้องพึ่งพาโครงสร้าง **Thermal Vias Array** อย่างหลีกเลี่ยงไม่ได้

```
+-------------------------------------------------------------+
|                IC Silicon Die (P_loss)                      |
|                  │           │                              |
|           Die Attach Material (Ag Sinter / Solder)          |
|                  │           │                              |
|          Copper Exposed Thermal Pad (ePad)                  |
|                  │           │                              |
|          Solder Joint Layer (t_solder ~ 50 µm)              |
|──────────────────▼───────────▼──────────────────────────────| Top Copper
|     [Via 1]       [Via 2]       [Via 3]       [Via 4]       |
|      │ │           │ │           │ │           │ │          |
|      │ │ Cu Plated │ │ Barrel    │ │ Thickness │ │ t_plate  | FR-4 Core
|      │ │           │ │ (>=25 µm) │ │           │ │          | & Prepreg
|      │ │           │ │           │ │           │ │          |
|──────▼─▼───────────▼─▼───────────▼─▼───────────▼─▼──────────| Bottom Copper
|                Heat Spreading Ground Plane                  |
+-------------------------------------------------------------+
```

### 1.1 การสร้างแบบจำลองความต้านทานความร้อนของ Thermal Via เดี่ยว (Single Via Analytical Model)

ท่อทองแดงชุบ (Plated Copper Cylinder) ของรูเจาะ Through-hole Via ทำหน้าที่เป็นตัวนำความร้อนความต้านทานต่ำในแนวแกน $z$ ตัดผ่านชั้นฉนวน FR-4 ซึ่งเป็นตัวต้านทานความร้อนสูง ความต้านทานความร้อนของ Via เดี่ยว ($R_{\theta, via}$) คำนวณได้จากกฎการนำความร้อนของฟูริเยร์:

$$R_{\theta, via} = \frac{h_{board}}{k_{Cu} \cdot A_{Cu, barrel}} \quad [^{\circ}\text{C/W}]$$

โดยที่:
- $h_{board}$ คือ ความหนารวมของแผ่นวงจรพิมพ์ ($\text{m}$)
- $k_{Cu}$ คือ สภาพนำความร้อนของทองแดงชุบด้วยไฟฟ้า (Electroplated Copper, $k_{Cu} \approx 380 - 390 \text{ W/(m}\cdot\text{K)}$)
- $A_{Cu, barrel}$ คือ พื้นที่หน้าตัดของท่อทองแดงชุบ ($\text{m}^2$)

พื้นที่หน้าตัดทรงกระบอกทองแดงคำนวณจากเส้นผ่านศูนย์กลางรูเจาะ ($d_{drill}$) และความหนาของการชุบทองแดงในผนังรู ($t_{plate}$):

$$A_{Cu, barrel} = \frac{\pi}{4} \left[ d_{drill}^2 - (d_{drill} - 2 t_{plate})^2 \right] = \pi \cdot t_{plate} \cdot (d_{drill} - t_{plate})$$

ในกรณีที่ความหนาของการชุบบางกว่าเส้นผ่านศูนย์กลางรูมาก ($t_{plate} \ll d_{drill}$):
$$A_{Cu, barrel} \approx \pi \cdot d_{drill} \cdot t_{plate}$$

ดังนั้น:
$$R_{\theta, via} \approx \frac{h_{board}}{k_{Cu} \cdot \pi \cdot d_{drill} \cdot t_{plate}}$$

| ขนาดรูเจาะ ($d_{drill}$) | ความหนาทองแดงชุบ ($t_{plate}$) | ความหนาบอร์ด ($h_{board}$) | พื้นที่หน้าตัด ($A_{Cu}$) | ความต้านทานความร้อน ($R_{\theta, via}$) |
| :--- | :--- | :--- | :--- | :--- |
| **0.20 mm (Micro-hole)** | 20 µm (IPC Class 2) | 1.6 mm | 0.0113 mm² | 36.8 °C/W |
| **0.30 mm (Standard)** | 25 µm (IPC Class 3) | 1.6 mm | 0.0216 mm² | 19.3 °C/W |
| **0.30 mm (Heavy Plating)** | 35 µm (1 oz Cu) | 1.6 mm | 0.0291 mm² | 14.3 °C/W |
| **0.50 mm (Large Via)** | 25 µm (IPC Class 3) | 1.6 mm | 0.0373 mm² | 11.2 °C/W |
| **0.30 mm (Standard)** | 25 µm | 1.0 mm (Thin Board)| 0.0216 mm² | 12.0 °C/W |

### 1.2 ทฤษฎี Thermal Via Array และจุดอิ่มตัวของผลตอบแทน (Diminishing Returns)

เมื่อวาง Thermal Vias จำนวน $N$ รูต่อขนานกันใต้ Exposed Pad ความต้านทานความร้อนรวมของกลุ่ม Via ($R_{\theta, array}$) ไม่ได้ลดลงตามสูตร $\frac{R_{\theta, via}}{N}$ เสมอไป เนื่องจากมีข้อจำกัดทางกายภาพ 2 ประการ:

1. **Spreading Resistance บน Top/Bottom Copper:** หากระยะห่างระหว่าง Via (Via Pitch, $P$) กว้างเกินไป ความร้อนจะสูญเสียพลังงานในการเดินทางในแนวระนาบก่อนจะเข้าสู่รู Via
2. **Thermal Mutual Coupling:** หากวาง Via ชิดกันเกินไป ($P < 0.8 \text{ mm}$) เวกเตอร์ฟลักซ์ความร้อนจะแย่งพื้นที่ระบายออกสู่ Ground Plane ด้านล่าง เกิดการสะสมความร้อนซ้อนทับกัน (Thermal Shadowing Effect)

```
Total Thermal Resistance R_th (°C/W)
   ▲
   │  \
   │   \
   │    \   Curve of Diminishing Returns
   │     \______________________ (Saturation Level)
   │
   └──────┴─────┴─────┴─────┴────► Number of Vias (N)
          4     9    16    25
```

สมการความต้านทานความร้อนรวมของระบบ ePad:
$$R_{\theta, total} = R_{\theta, solder} + R_{\theta, spreading(top)} + \left( \frac{R_{\theta, via}}{N_{eff}} \right) + R_{\theta, spreading(bot)}$$

ระยะพิทช์ที่เหมาะสมที่สุดในทางวิศวกรรม (Optimal Pitch) ตามมาตรฐานอุตสาหกรรมคือ:
$$P_{opt} \approx 1.0 - 1.2 \text{ mm}$$

การเจาะรูมากกว่านี้ (เช่น เจาะรูพิทช์ $0.5 \text{ mm}$) จะเพิ่มต้นทุนการผลิตและทำลายความแข็งแรงเชิงกลของแผ่นวงจร โดยลดค่าความต้านทานความร้อนรวมได้ไม่เกิน $3 - 5\%$ เท่านั้น

### 1.3 ปัญหาโครงสร้างทางกล: การโป่งพองและรอยแตกของทองแดงในรูเจาะ (Barrel Cracking Under CTE Stress)

ความหนาในแนวแกน $z$ ของแผ่น FR-4 มีค่าสัมประสิทธิ์การขยายตัวเนื่องจากความร้อน ($\alpha_{z, FR4} \approx 50 - 70 \text{ ppm/}^{\circ}\text{C}$ ต่ำกว่า $T_g$, และพุ่งสูงถึง $250 - 350 \text{ ppm/}^{\circ}\text{C}$ เมื่ออุณหภูมิสูงเกิน $T_g$) ในขณะที่ทองแดงชุบในกระบอก Via มีค่า $\alpha_{Cu} \approx 17 \text{ ppm/}^{\circ}\text{C}$

ความแตกต่างของอัตราการขยายตัว ($\Delta\alpha_z = \alpha_{z, FR4} - \alpha_{Cu}$) ก่อให้เกิดความเค้นดึงมหาศาล (Cyclic Tensile Stress) บนกระบอกทองแดงทุกครั้งที่บอร์ดผ่านเตาอบ Reflow หรือผ่านการทดสอบ Thermal Shock ($-40^{\circ}\text{C} \leftrightarrow +125^{\circ}\text{C}$):

$$\sigma_{tensile} \approx E_{Cu} \cdot (\alpha_{z, FR4} - \alpha_{Cu}) \cdot \Delta T$$

หากความหนาทองแดงชุบในผนังรู ($t_{plate}$) ต่ำกว่า $20 \ \mu\text{m}$ หรือมีช่องว่างอากาศ (Voids) ในเนื้อทองแดง ความเค้นนี้จะทำให้เกิด **Barrel Cracking (รอยร้าวรอบผนังกระบอก Via)** หรือ **Corner Knee Cracking (รอยแตกที่คอเชื่อมต่อระหว่าง Pad กับ Via)** ส่งผลให้วงจรกราวด์เปิด (Open Circuit) และตัดเส้นทางระบายความร้อน นำไปสู่การระเบิดของเพาเวอร์ชิปในเวลาต่อมา

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน: 失敗事例 (Shippai Jirei)

**เหตุการณ์:** บอร์ดควบคุมไดรเวอร์มอเตอร์ Brushless DC (BLDC) กำลัง $350 \text{ W}$ ในระบบหุ่นยนต์อุตสาหกรรม ใช้เพาเวอร์สวิตช์ MOSFET ตัวถัง QFN 5x6 mm (กินกระแส $30 \text{ A}$ ต่อเฟส) จำนวน 6 ตัว บนบอร์ด 6-Layer FR-4 (ความหนา $1.6 \text{ mm}$) 

**อาการล้มเหลว:**
1. ในสายการผลิต SMT หลังผ่านเตาอบ Reflow พบชิป MOSFET เอียงกระดก (Tilted / Tombstoning) และเกิดสะพานเชื่อมตะกั่ว (Solder Bridging) ลัดวงจรระหว่างขา Signal ขอบข้างบอร์ดถึง $12\%$
2. บอร์ดที่ผ่านการทดสอบเบื้องต้น เมื่อนำไปเปิดรันโหลด $25 \text{ A}$ ในขั้นตอน Burn-in Test ตัวถัง MOSFET เกิดการระเบิดไหม้ (Thermal Destruction) ภายใน 4 นาที
3. จากการส่องตรวจด้วยภาพเอกซเรย์ 2D/3D X-Ray Inspection พบว่าใต้แผ่น Exposed Pad ของ QFN มีโพรงอากาศ (Solder Voiding) สูงถึง $68\%$ (เกณฑ์มาตรฐาน IPC-A-610 Class 3 อนุญาตให้มี Void ได้ไม่เกิน $15 - 25\%$) และพบว่าตะกั่วบัดกรีไหลทะลุรู Thermal Vias หยดลงไปกองเป็นเม็ดกลม (Solder Balls) ที่ด้านล่างของบอร์ด

```
[Failure Mechanism: Solder Wicking & Giant Voiding]
           IC Body (QFN)
  ┌──────────────────────────────┐
  └──[Lead]───[ ePad ]───[Lead]──┘
       │     (No Solder!)  │
  ═════╪═══════XXXX════════╪═════  <--- Giant Void (68%)!
       │      │    │       │
       │      │    │       │       <--- Open/Tented Via (Suction)
  ─────┴──────┼────┼───────┴─────
              ▼    ▼
          (Solder Droplet)         <--- Solder Wicking to Bottom Layer
```

**Root Cause Analysis (RCA):**
1. **การกำหนดประเภท Via ผิดพลาด (Open Through Vias ใต้ Pad):** วิศวกรผู้ออกแบบเจาะ Thermal Vias ขนาด Drill $0.35 \text{ mm}$ จำนวน 12 รูไว้บน ePad โดยเลือกสเปกบอร์ดเป็น **Tenting Via (ปิดด้วย Solder Mask ฝั่ง Bottom เท่านั้น)** เมื่อผ่านเตาอบ Reflow อากาศที่ติดค้างในรูกระบอก Via ขยายตัวดันฟิล์มมาสก์แตกออก เกิดแรงดูดคาปิลลารี (Capillary Action) ดึงตะกั่วบัดกรีเหลวไหลย้อยลงไปด้านล่างบอร์ด (ปรากฏการณ์ **Solder Wicking**)
2. **การเปิด Stencil หน้าต่างเดียว 100% (Solid Aperture):** สเตนซิลสำหรับพิมพ์ครีมบัดกรี (Solder Paste) ถูกเปิดเป็นช่องสี่เหลี่ยมขนาดเท่ากับ ePad ($100\%$ Coverage) เมื่อตะกั่วถูกดูดลงรูไปบางส่วน และตัวทำละลาย (Flux Volatiles) ไม่สามารถระเหยหนีออกไปทางด้านข้างได้ ฟลักซ์จึงเดือดกลายเป็นฟองอากาศกักอยู่ใต้ชิป กลายเป็นโพรงอากาศขนาดยักษ์ ($68\%$ Voids)
3. **ผลกระทบต่อเนื่อง:** โพรงอากาศขนาดใหญ่ตัดขาดเส้นทางนำความร้อน ความต้านทานความร้อนรอยต่อพุ่งสูงขึ้นกว่าปกติ 8 เท่า ส่งผลให้อุณหภูมิชิปพุ่งทะลุ $175^{\circ}\text{C}$ ภายใต้โหลดปกติและระเบิดทำลายตัวเอง

### Step-by-Step Engineering Checklist: กฎเหล็กการออกแบบ Thermal Pad และ Vias

#### ขั้นตอนที่ 1: การเลือกเทคโนโลยี Via สำหรับ Exposed Pad (Via Treatment Options)
การเลือกสเปก Via ใต้ Pad ส่งผลต่อต้นทุนและความเชื่อถือได้โดยตรง:

```
Option A: Open Through Via (Do NOT use under small ePad)
Option B: Solder Mask Tented (RISK: Gas trapped, blowholes)
Option C: Resin Plugged & Plated Over (VIPPO) - GOLD STANDARD
Option D: Copper Paste Filled & Plated Over - EXTREME PERFORMANCE
```

- **กฎข้อที่ 1:** หากชิ้นส่วนเป็นแพ็กเกจละเอียด เช่น QFN, DFN, หรือ WLCSP **ห้ามใช้ Open Through Via หรือ Tented Via เด็ดขาด** 
- **กฎข้อที่ 2 (โซลูชันสำหรับ Mass Production สูงสุด):** ให้ระบุใน Drawing สั่งทำเป็น **VIPPO (Via-in-Pad Plated Over)** ตามมาตรฐาน IPC-4761 Type VII (ฉีดเรซินอีพ็อกซีอุดเต็มรู เจียรหน้าสัมผัสให้เรียบเสมอกัน และชุบทองแดงทับหน้าเรียบสนิท) ซึ่งจะป้องกัน Solder Wicking ได้ $100\%$ และยอมให้บัดกรีได้เหมือนผิวทองแดงปกติ
- **กฎข้อที่ 3 (โซลูชันประหยัดต้นทุนสำหรับชิ้นส่วนใหญ่ เช่น D2PAK):** หากบอร์ดราคาถูกไม่สามารถจ่ายค่า VIPPO ได้ ให้ออกแบบรูเจาะขนาดเล็กพิเศษ ($d_{drill} \le 0.20 - 0.25 \text{ mm}$) และกำหนดระยะห่างของรูกับขอบ Pad ให้มากพอ พร้อมเปิดหน้าต่าง Stencil ให้หลบตำแหน่งรูเจาะ

```
+-------------------------------------------------------------+
|  VIPPO Structure (IPC-4761 Type VII):                       |
|                                                             |
|  [================ Flat Cu Cap Layer ===============]       |
|  │ ┌──────────────────────────────────────────────┐ │       |
|  │ │          Epoxy Non-Conductive Resin          │ │       |
|  │ │                 (Plugged)                    │ │       |
|  │ └──────────────────────────────────────────────┘ │       |
|  [========= Plated Copper Barrel Wall (>=25µm) ======]       |
+-------------------------------------------------------------+
```

#### ขั้นตอนที่ 2: การออกแบบ Stencil Windowing (หน้าต่างสเตนซิลแบบแบ่งช่อง)
ห้ามเปิดช่อง Stencil แบบเต็มแผ่น ($100\%$ Area) ใต้ Exposed Thermal Pad:
- **Matrix Windowing Pattern:** แบ่งช่องเปิดของสเตนซิลออกเป็นตารางสี่เหลี่ยมย่อยๆ (Window Panes) เช่น $2 \times 2, 3 \times 3,$ หรือ $4 \times 4$
- **Solder Coverage Target:** กำหนดพื้นที่เปิดของเนื้อตะกั่วให้อยู่ระหว่าง **$50\% - 70\%$** ของพื้นที่ ePad ทั้งหมด
- **Webbing / Bridge Width:** เว้นแนวสะพานโลหะ (Web Width) ระหว่างช่องหน้าต่างกว้างอย่างน้อย $0.15 - 0.20 \text{ mm}$ เพื่อให้ก๊าซจากฟลักซ์สามารถระเหยหนีออกมาระหว่างขั้นตอน Reflow ได้อย่างราบรื่น ช่วยลดอัตราการเกิด Voids ให้เหลือต่ำกว่า $10 - 15\%$

```

|    ├──────────┼───┼──────────┼───┼──────────┤               |
|    │  Paste   │   │  Paste   │   │  Paste   │               |
|    │  Window  │   │  Window  │   │  Window  │               |

+-------------------------------------------------------------+
```

#### ขั้นตอนที่ 3: กฎการกระจายตำแหน่ง Thermal Vias (Via Placement Rules)
- **เจาะรูในตำแหน่งสัมผัสหลัก:** วาง Thermal Vias ใต้จุดที่ตรงกับ Die กึ่งกลางตัวถังชิป
- **Via Drill Diameter:** กำหนดขนาดเจาะมาตรฐาน $d_{drill} = 0.30 \text{ mm}$ (Finished Hole Size $\approx 0.25 \text{ mm}$) ซึ่งเป็นจุดสมดุลที่ดีที่สุดระหว่างความต้านทานความร้อนและต้นทุน Tooling ของโรงงาน
- **Plating Specification:** ระบุความหนาของทองแดงชุบในกระบอกรูให้ชัดเจนในแบบสั่งผลิตว่า **Plating Thickness $\ge 25 \ \mu\text{m}$ (Average) / $\ge 20 \ \mu\text{m}$ (Minimum at any point)** เพื่อป้องกันปัญหา Barrel Fatigue Cracking

#### คอมเมนต์ที่ 1: ตรวจพบ Open Thermal Vias ใต้ตัวถัง QFN เสี่ยงต่อ Solder Wicking และ Voiding
> **検図指摘 (Kenzu Feedback 1):**  
> 「U301（モーター駆動用ゲートドライバ IC、QFN-32パッケージ）直下の放熱パッド設計について確認しました。現在、パッド内部に$\phi 0.35\text{mm}$のスルーホールビアが9箇所配置されていますが、基板仕様書上で穴埋め処理（樹脂埋め平坦化メッキ：VIPPO）の指定が抜けており、オープンビア（レジスト開口状態）となっています。このまま量産SMT工程に投入した場合、リフロー加熱時にキャピラリー現象によってはんだが裏面へ吸い込まれ（はんだ吸い込み）、部品の傾き浮きや放熱パッド下のはんだボイド率が40%以上に達する致命的不良が発生します。IPC-4761 Type VIIに準拠した樹脂埋め銅メッキ（VIPPO仕様）を追加指定するか、製造コスト制約がある場合はビア径を$\phi 0.20\text{mm}$以下に絞り、メタルマスク開口を分割窓（クロススパイダー形状、開口率60%）に変更してボイド逃げ道を確保してください。」  
> *(คำแปล: ตรวจสอบการออกแบบ Thermal Pad ใต้ U301 (Gate Driver IC สำหรับขับมอเตอร์ ตัวถัง QFN-32) พบว่าปัจจุบันมี Through-hole Vias ขนาด 0.35 mm วางอยู่ 9 รู แต่ในแบบสั่งผลิตบอร์ดไม่ได้ระบุการอุดรูและชุบทองแดงทับ (VIPPO) ทำให้กลายเป็น Open Vias หากนำไปผลิต SMT สภาวะจริงจะเกิดแรงดูดดึงตะกั่วไหลลงด้านล่าง ส่งผลให้ชิปเอียงและเกิดโพรงอากาศใต้ Pad เกิน 40% ซึ่งเป็นข้อบกพร่องร้ายแรง ขอให้ระบุสเปก VIPPO ตาม IPC-4761 Type VII เพิ่มเติม หรือหากติดเงื่อนไขด้านต้นทุน ให้ลดขนาดรูเจาะลงไม่เกิน 0.20 mm และแบ่งช่องเปิดสเตนซิลเป็นแบบ Windowing เปิดพื้นที่ 60% เพื่อให้ก๊าซฟลักซ์ระเหยออกได้)*

#### คอมเมนต์ที่ 2: ความหนาทองแดงชุบไม่เพียงพอต่อการทนทาน Thermal Cycling (Barrel Cracking Risk)
> **検図指摘 (Kenzu Feedback 2):**  
> 「多層基板（6層、板厚1.6mm、High-Tg FR-4）の放熱ビア仕様書において、スルーホール銅メッキ厚の要求が『公称18µm以上（IPC Class 1/2レベル）』となっています。本製品は車載パワートレイン近傍に搭載され、動作保証温度$-40^\circ\text{C} \sim +125^\circ\text{C}$の過酷な環境下で稼働します。板厚方向（Z軸）の熱膨張係数ミスマッチ（$\alpha_z \approx 60\text{ ppm/}^\circ\text{C}$ vs $\alpha_{Cu} \approx 17\text{ ppm/}^\circ\text{C}$）により、長期熱衝撃サイクル試験においてスルーホール胴体部の破断（バレルクラック）およびコーナークラックに至るリスクがあります。車載品質および信頼性担保のため、放熱ビアを含む全スルーホールめっき厚を『平均25µm以上、局所最小20µm以上（IPC Class 3準拠）』に引き上げるよう設計指示書を改訂してください。」

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### คำถามที่ 1: การคำนวณจำนวน Thermal Vias เพื่อควบคุมอุณหภูมิรอยต่อของ Buck Converter Power IC

เพาเวอร์ไอซี Step-down Buck Converter ตัวถัง QFN 4x4 mm มีค่าความต้านทานความร้อนภายในรอยต่อไปยังแผ่นสัมผัสใต้ตัวถัง $\theta_{JC} = 2.5 \ ^{\circ}\text{C/W}$ ไอซีนี้ทำงานสูญเสียพลังงานความร้อน $P_{loss} = 4.0 \text{ W}$ บอร์ดทำจาก 4-Layer FR-4 หนา $h_{board} = 1.6 \text{ mm}$ อุณหภูมิสภาพแวดล้อมสูงสุด $T_{amb} = 60^{\circ}\text{C}$ 

ความร้อนทั้งหมดต้องถูกส่งผ่าน Thermal Vias ใต้ ePad ลงสู่ระนาบกราวด์ชั้นล่างสุด (Bottom Layer) ซึ่งระบายความร้อนออกสู่อากาศและโครงตู้โลหะ โดยมีค่าความต้านทานความร้อนจากระนาบทองแดงด้านล่างสู่อากาศ $R_{\theta, bot-amb} = 12.0 \ ^{\circ}\text{C/W}$

วิศวกรใช้ Thermal Via ขนาดมาตรฐาน:
- รูเจาะเสร็จสิ้น (Finished Drill Diameter) $d = 0.30 \text{ mm}$
- ความหนาทองแดงชุบในผนังรู $t_{plate} = 25 \ \mu\text{m}$ ($k_{Cu} = 385 \text{ W/(m}\cdot\text{K)}$)
- ความต้านทานความร้อนของชั้นบัดกรีและทองแดง ePad คิดรวมเป็น $R_{\theta, pad} = 0.5 \ ^{\circ}\text{C/W}$

หากข้อกำหนดความน่าเชื่อถือระบุว่า อุณหภูมิรอยต่อสูงสุดของไอซี ($T_j$) ต้องไม่เกิน $105^{\circ}\text{C}$ จงคำนวณหา:
1. ค่าความต้านทานความร้อนรวมสูงสุดที่ระบบยอมรับได้ ($R_{\theta, JA(max)}$)
2. ค่าความต้านทานความร้อนของ Thermal Via เดี่ยว ($R_{\theta, via}$)
3. จำนวน Thermal Vias ขั้นต่ำ ($N_{min}$) ที่ต้องเจาะใต้ ePad เพื่อให้อุณหภูมิไม่เกินสเปก?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความต้านทานความร้อนรวมสูงสุด ($R_{\theta, JA(max)}$):**
$$\Delta T_{max} = T_{j, max} - T_{amb} = 105^{\circ}\text{C} - 60^{\circ}\text{C} = 45^{\circ}\text{C}$$
$$R_{\theta, JA(max)} = \frac{\Delta T_{max}}{P_{loss}} = \frac{45^{\circ}\text{C}}{4.0 \text{ W}} = 11.25 \ ^{\circ}\text{C/W}$$

**2. กระจายโครงข่ายความต้านทานความร้อนรวม:**
$$R_{\theta, JA} = \theta_{JC} + R_{\theta, pad} + R_{\theta, vias} + R_{\theta, bot-amb}$$
$$11.25 = 2.5 + 0.5 + R_{\theta, vias} + 12.0 = 15.0 + R_{\theta, vias}$$

*สังเกต:* เมื่อพิจารณาผลรวม พบว่า $\theta_{JC} + R_{\theta, pad} + R_{\theta, bot-amb} = 15.0 \ ^{\circ}\text{C/W}$ ซึ่งมีค่าสูงกว่า $R_{\theta, JA(max)} = 11.25 \ ^{\circ}\text{C/W}$ อยู่แล้ว ต่อให้ความต้านทานของ Via เป็นศูนย์ ($R_{\theta, vias} = 0$) อุณหภูมิรอยต่อก็ยังพุ่งสูงถึง $60 + 4 \times 15.0 = 120^{\circ}\text{C}$!

นี่คือคำถามดักทางวิศวกรรมที่เกิดขึ้นจริงบ่อยครั้ง! วิศวกรจำนวนมากพยายามเพิ่ม Thermal Vias นับร้อยตัวเพื่อแก้ปัญหาความร้อน แต่ลืมตรวจสอบความต้านทานภายนอก ($R_{\theta, bot-amb}$)

**3. การปรับปรุงระบบ:**
เพื่อให้ระบบสามารถทำงานได้ ทีมฮาร์ดแวร์ต้องปรับปรุงการระบายความร้อนที่ระนาบด้านล่าง (Bottom Layer) เช่น ขยายพื้นที่ระบายความร้อน หรือเพิ่มการไหลเวียนของอากาศ จนกระทั่งลดค่า $R_{\theta, bot-amb}$ ลงมาอยู่ที่ $6.0 \ ^{\circ}\text{C/W}$

เมื่อปรับปรุงแล้ว ความต้านทานของ Via ที่ยอมรับได้คือ:
$$R_{\theta, vias} \le 11.25 - (2.5 + 0.5 + 6.0) = 11.25 - 9.0 = 2.25 \ ^{\circ}\text{C/W}$$

**4. คำนวณความต้านทานของ Thermal Via เดี่ยว ($R_{\theta, via}$):**
- เส้นผ่านศูนย์กลางเฉลี่ยของกระบอกทองแดง:
  $$d_{mid} = d_{drill} - t_{plate} = 0.30 \text{ mm} - 0.025 \text{ mm} = 0.275 \text{ mm} = 2.75 \times 10^{-4} \text{ m}$$
- พื้นที่หน้าตัดทองแดงชุบ:
  $$A_{Cu} \approx \pi \cdot d_{mid} \cdot t_{plate} = \pi \cdot (2.75 \times 10^{-4}) \cdot (25 \times 10^{-6}) \approx 2.16 \times 10^{-8} \text{ m}^2$$
- ความต้านทานความร้อนของ Via ข้ามบอร์ดหนา $1.6 \text{ mm} = 1.6 \times 10^{-3} \text{ m}$:
  $$R_{\theta, via} = \frac{h_{board}}{k_{Cu} \cdot A_{Cu}} = \frac{1.6 \times 10^{-3}}{385 \cdot (2.16 \times 10^{-8})} \approx 19.24 \ ^{\circ}\text{C/W}$$

**5. คำนวณจำนวน Via ขั้นต่ำ ($N_{min}$):**
$$R_{\theta, vias} = \frac{R_{\theta, via}}{N} \le 2.25 \ ^{\circ}\text{C/W}$$
$$N \ge \frac{19.24}{2.25} \approx 8.55$$

ดังนั้น ต้องใช้ Thermal Vias อย่างน้อยที่สุด **9 รู (จัดวางแบบอาเรย์ $3 \times 3$ ที่พิทช์ $1.0 \text{ mm}$)** ภายใต้ ePad เพื่อให้ค่า $R_{\theta, vias} \approx 2.14 \ ^{\circ}\text{C/W}$ จึงจะสามารถควบคุมให้อุณหภูมิชิปไม่เกิน $105^{\circ}\text{C}$ ได้ตามสเปก

### คำถามที่ 2: ผลกระทบของ Solder Voiding ต่อค่าความต้านทานความร้อนและจุด Hotspot ใต้ชิป

ในการตรวจสอบคุณภาพรอยต่อบัดกรีของ Exposed Pad ขนาด $5.0 \text{ mm} \times 5.0 \text{ mm}$ ($A = 25 \text{ mm}^2$) ชิปปล่อยความร้อน $P = 15 \text{ W}$ โดยความหนาของชั้นบัดกรีประสาน (Solder Joint Thickness) อยู่ที่ $t_{solder} = 50 \ \mu\text{m}$ โลหะบัดกรี SAC305 มีสภาพนำความร้อน $k_{solder} = 58 \text{ W/(m}\cdot\text{K)}$

ในการผลิตบอร์ดสองล็อต:
- **ล็อต A (ควบคุมกระบวนการดี):** มี Solder Void กระจายตัวเป็นจุดเล็กๆ รวมพื้นที่ Voiding เท่ากับ $10\%$ ($A_{void} = 2.5 \text{ mm}^2$)
- **ล็อต B (เกิดข้อบกพร่อง Solder Wicking):** เกิด Giant Voiding รวมตัวกันเป็นโพรงอากาศขนาดใหญ่ตรงกึ่งกลาง ePad มีพื้นที่ Voiding สูงถึง $50\%$ ($A_{void} = 12.5 \text{ mm}^2$) โดยอากาศมี $k_{air} \approx 0.026 \text{ W/(m}\cdot\text{K)}$

จงคำนวณ:
1. ค่าความต้านทานความร้อน 1D ของชั้นตะกั่วบัดกรี ($R_{\theta, solder}$) ของทั้งสองล็อต
2. อธิบายปรากฏการณ์กระจุกตัวของความร้อน (Thermal Crowding Effect) และเหตุใดโพรงอากาศขนาดใหญ่ตรงจุดกึ่งกลาง (Central Giant Void) จึงสร้างความเสียหายรุนแรงกว่าโพรงอากาศขนาดเล็กที่กระจายตัวอย่างสม่ำเสมอ แม้จะมีพื้นที่ Void รวมเท่ากัน?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณความต้านทานความร้อน 1D ของชั้นบัดกรี:**
- ความต้านทานความร้อนของเนื้อบัดกรี SAC305 ต่อพื้นที่หน้าตัดที่มีประสิทธิผล ($A_{eff} = A_{total} - A_{void}$):
  $$R_{\theta, solder} = \frac{t_{solder}}{k_{solder} \cdot A_{eff}}$$

- **สำหรับล็อต A ($10\%$ Voids):**
  $$A_{eff, A} = 25 \text{ mm}^2 \times 0.90 = 22.5 \text{ mm}^2 = 2.25 \times 10^{-5} \text{ m}^2$$
  $$R_{\theta, solder(A)} = \frac{50 \times 10^{-6} \text{ m}}{58 \text{ W/(m}\cdot\text{K)} \cdot (2.25 \times 10^{-5} \text{ m}^2)} \approx 0.0383 \ ^{\circ}\text{C/W}$$

- **สำหรับล็อต B ($50\%$ Voids):**
  $$A_{eff, B} = 25 \text{ mm}^2 \times 0.50 = 12.5 \text{ mm}^2 = 1.25 \times 10^{-5} \text{ m}^2$$
  $$R_{\theta, solder(B)} = \frac{50 \times 10^{-6} \text{ m}}{58 \text{ W/(m}\cdot\text{K)} \cdot (1.25 \times 10^{-5} \text{ m}^2)} \approx 0.0690 \ ^{\circ}\text{C/W}$$

**2. บทวิเคราะห์ทางฟิสิกส์: ทำไม Central Giant Void จึงอันตรายร้ายแรงกว่า:**
- **ข้อจำกัดของการคำนวณ 1D:** ในโมเดล 1D ดูเหมือนค่าความต้านทานต่างกันเพียง $0.03 \ ^{\circ}\text{C/W}$ แต่ในความเป็นจริง การกระจายความร้อนเป็น 3 มิติ (3D Heat Flux Spreading)
- **ตำแหน่งของ Silicon Die:** ในตัวถังเพาเวอร์ชิป แหล่งกำเนิดความร้อน (Active Die Junction) มักอยู่ตรงกึ่งกลางของแพ็กเกจ ฟลักซ์ความร้อนสูงสุด ($q''_{max}$) จะพุ่งลงตรงแนวดิ่งจากกึ่งกลาง
- **Thermal Crowding Effect:** เมื่อเกิดโพรงอากาศขนาดใหญ่ตรงกึ่งกลาง (Central Void) อากาศทำตัวเสมือนกำแพงกั้นความร้อน ($k_{air} = 0.026 \text{ W/(m}\cdot\text{K)}$ ต่ำกว่าเนื้อตะกั่วกว่า 2,200 เท่า) ฟลักซ์ความร้อนไม่สามารถพุ่งลงตรงๆ ได้ แต่ถูกบีบให้เบี่ยงเบนออกไปทางขอบข้าง (Lateral Spreading) ก่อนจะม้วนลงสู่บอร์ด
- เส้นทางการเดินทางของความร้อนที่ยาวขึ้นบวกกับการบีบอัดของฟลักซ์ความร้อน ก่อให้เกิด **Localized Hotspot อุณหภูมิพุ่งสูงกว่าปกติถึง $30^{\circ}\text{C} - 50^{\circ}\text{C}$** ตรงใจกลางชิป นำไปสู่การเสื่อมสภาพของซิลิคอน การหลอมละลายของชั้น Die Attach และเกิดการระเบิดทำลายตัวถัง
- ในทางตรงกันข้าม โพรงอากาศขนาดเล็กที่กระจายตัวอยู่ทั่วไป (Distributed Micro-voids ตามเกณฑ์ IPC Class 3) จะไม่ขัดขวางฟลักซ์ความร้อนหลัก ความร้อนสามารถอ้อมผ่านช่องว่างขนาดไมครอนได้อย่างง่ายดายโดยไม่เกิดการสะสมความร้อนเฉพาะจุด

### คำถามที่ 3: การประเมินอายุการใช้งานของจุดเชื่อมต่อและกระบอก Via จากความเค้นดึง (Coffin-Manson & Barrel Reliability)

บอร์ดคอนโทรลเลอร์ยานยนต์ 8-Layer ผลิตจากมาตรฐาน FR-4 ($T_g = 150^{\circ}\text{C}$, ค่า CTE ในแนวแกน $z$ ก่อนถึง $T_g$ คือ $\alpha_{z1} = 55 \text{ ppm/}^{\circ}\text{C}$ และหลังเกิน $T_g$ คือ $\alpha_{z2} = 280 \text{ ppm/}^{\circ}\text{C}$) แผ่นบอร์ดมีความหนา $h = 1.6 \text{ mm}$ ชุบทองแดงในรูกระบอก Via หนา $t_{plate} = 20 \ \mu\text{m}$ (เส้นผ่านศูนย์กลางรู $d = 0.3 \text{ mm}$, สภาพยืดหยุ่นของทองแดง $E_{Cu} = 110 \text{ GPa}$, ขีดจำกัดครากของทองแดงชุบ $\sigma_y \approx 220 \text{ MPa}$)

ระหว่างกระบวนการบัดกรี Lead-Free Reflow อุณหภูมิบอร์ดพุ่งจาก $25^{\circ}\text{C}$ ขึ้นสู่จุดสูงสุดที่ $T_{peak} = 260^{\circ}\text{C}$ 

จงคำนวณ:
1. การขยายตัวในแนวแกน $z$ ของแผ่น FR-4 ($\Delta h_{FR4}$) ในช่วงอุณหภูมิดังกล่าว
2. การขยายตัวตามธรรมชาติของทองแดง ($\Delta h_{Cu}$) ที่ $\alpha_{Cu} = 17 \text{ ppm/}^{\circ}\text{C}$
3. ความเครียดเชิงพลาสติก (Plastic Strain, $\varepsilon_p$) ที่เกิดขึ้นบนกระบอกทองแดง และอธิบายกลไกการเกิด Corner Knee Cracking?

#### เฉลยและบทวิเคราะห์เชิงลึก:

**1. คำนวณการขยายตัวในแนวแกน $z$ ของแผ่น FR-4 ($\Delta h_{FR4}$):**
การเปลี่ยนแปลงอุณหภูมิแบ่งเป็น 2 ช่วงตามอุณหภูมิเปลี่ยนสถานะคล้ายแก้ว ($T_g = 150^{\circ}\text{C}$):
- ช่วงที่ 1: จาก $25^{\circ}\text{C}$ ถึง $150^{\circ}\text{C}$ ($\Delta T_1 = 125^{\circ}\text{C}$):
  $$\Delta h_1 = h \cdot \alpha_{z1} \cdot \Delta T_1 = (1.6 \text{ mm}) \cdot (55 \times 10^{-6} \text{ /}^{\circ}\text{C}) \cdot 125 = 0.0110 \text{ mm} = 11.0 \ \mu\text{m}$$
- ช่วงที่ 2: จาก $150^{\circ}\text{C}$ ถึง $260^{\circ}\text{C}$ ($\Delta T_2 = 110^{\circ}\text{C}$):
  $$\Delta h_2 = h \cdot \alpha_{z2} \cdot \Delta T_2 = (1.6 \text{ mm}) \cdot (280 \times 10^{-6} \text{ /}^{\circ}\text{C}) \cdot 110 = 0.04928 \text{ mm} = 49.28 \ \mu\text{m}$$
- การขยายตัวรวมของ FR-4 ในแนวแกน $z$:
  $$\Delta h_{FR4} = \Delta h_1 + \Delta h_2 = 11.0 + 49.28 = 60.28 \ \mu\text{m}$$

**2. คำนวณการขยายตัวตามธรรมชาติของทองแดง ($\Delta h_{Cu}$):**
$$\Delta T_{total} = 260^{\circ}\text{C} - 25^{\circ}\text{C} = 235^{\circ}\text{C}$$
$$\Delta h_{Cu} = h \cdot \alpha_{Cu} \cdot \Delta T_{total} = (1.6 \text{ mm}) \cdot (17 \times 10^{-6} \text{ /}^{\circ}\text{C}) \cdot 235 \approx 0.00639 \text{ mm} = 6.39 \ \mu\text{m}$$

**3. คำนวณความเครียด (Strain) และการวิเคราะห์ความเค้น:**
ความแตกต่างของการขยายตัวระหว่าง FR-4 กับทองแดง:
$$\delta = \Delta h_{FR4} - \Delta h_{Cu} = 60.28 \ \mu\text{m} - 6.39 \ \mu\text{m} = 53.89 \ \mu\text{m}$$

ความเครียดรวม (Total Strain) ที่เนื้อ FR-4 พยายามยืดกระบอกทองแดง:
$$\varepsilon_{total} = \frac{\delta}{h} = \frac{53.89 \times 10^{-6} \text{ m}}{1.6 \times 10^{-3} \text{ m}} \approx 0.03368 = 3.37\%$$

- ขีดจำกัดความเครียดแบบอิลาสติกของทองแดงชุบ:
  $$\varepsilon_{elastic} = \frac{\sigma_y}{E_{Cu}} = \frac{220 \times 10^6 \text{ Pa}}{110 \times 10^9 \text{ Pa}} = 0.002 = 0.2\%$$
- ความเครียดส่วนเกินกลายเป็น **Plastic Strain (ความเครียดถาวร)**:
  $$\varepsilon_p = \varepsilon_{total} - \varepsilon_{elastic} = 3.37\% - 0.2\% = 3.17\%$$

**บทสรุปทางวิศวกรรมขั้นสูง:**
- ความเครียดระดับ $3.17\%$ ถือว่าสูงมากเมื่อเทียบกับความสามารถในการยืดตัวของทองแดงชุบคุณภาพต่ำ (Electrodeposited copper ductility อยู่ที่ประมาณ $6\% - 12\%$)
- จุดที่เกิดความเค้นรวมศูนย์สูงสุด (Stress Concentration) ไม่ใช่กึ่งกลางรู แต่เป็นจุดเชื่อมต่อมุมฉากระหว่างผนังกระบอก Via กับ Capture Pad บนพื้นผิวบอร์ด (**Knee Region**)
- เมื่อกระบอกถูกดึงยืดอย่างรวดเร็วในเตา Reflow หากกระบวนการชุบมีจุดบกพร่อง เช่น การชุบทองแดงที่มุมบางกว่าปกติ (Knee Thinning $< 15 \ \mu\text{m}$) แรงเฉือนจะฉีกขาดรอยต่อบริเวณมุมทันที เกิดเป็นความล้มเหลวแบบ **Corner Knee Cracking**
- แนวทางป้องกันคือการเลือกใช้วัสดุ **High-Tg / Low-CTE FR-4 ($\alpha_{z} < 40 \text{ ppm/}^{\circ}\text{C}$)** และควบคุมกระบวนการชุบให้มีความหนาทองแดงที่มุม Knee สม่ำเสมอไม่น้อยกว่า $25 \ \mu\text{m}$ ตามเกณฑ์ IPC Class 3
