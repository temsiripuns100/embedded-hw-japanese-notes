# Lesson 048: PCB Vias Part 8 - Differential Pair Vias, Return Ground Cage & Racetrack Anti-Pads
*(差動ペアのビア遷移設計 - リターンGNDケージ・トラック型アンチパッドとモード変換Scd21抑制)*

---

## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในระบบส่งสัญญาณดิจิทัลความเร็วสูงแบบดิฟเฟอเรนเชียล (Differential Signaling เช่น PCIe Gen 5/6 ที่ 32/64 GT/s, 112G PAM4, และ USB4) การเดินสายบนระนาบ 2 มิติมักได้รับการควบคุมอิมพีแดนซ์อย่างแม่นยำ ($85 \ \Omega \pm 5\%$ หรือ $100 \ \Omega \pm 5\%$) 
ทว่าจุดเปราะบางที่สุดที่มักก่อให้เกิดการสะท้อนของคลื่นและการแผ่รังสีสัญญาณรบกวน EMI มหาศาล คือ **จุดเปลี่ยนเลเยอร์ของคู่สาย Differential ผ่านรูเจาะ Via (Differential Via Transition)**

วิศวกรระดับ Senior ต้องเข้าใจปฏิสัมพันธ์ของสนามแม่เหล็กไฟฟ้าในแนวดิ่ง 3 มิติ (3D EM Field Interactions), การควบคุม Differential Impedance ($Z_{diff,via}$) ผ่านการรวมรอยฉลุกราวด์เป็น **รูปสนามแข่งม้า (Racetrack Anti-Pad)**, การจัดวางโครงสร้างกรงกราวด์สมมาตร **(Symmetric Return Ground Cage: G-S-S-G)**, และการกำจัดการแปลงโหมดสัญญาณเป็น **Common-Mode Noise ($S_{cd21}$)**

---

### 1.1 วงจรสมมูลของคู่สาย Differential Via และทฤษฎี Racetrack Anti-Pad

เมื่อคู่สาย Differential (เส้น $P$ และ $N$) มุดลงในแนวดิ่งผ่านรูเจาะคู่ขนาน:

```
        Trace P In ───────( ( ( )────────┬─────────( ( ( )─────── Trace P Out
                          L_v - L_m      │         L_v - L_m
                                       ──┴── C_m (Mutual Coupling)
                                       ──┬──
                                         │
        Trace N In ───────( ( ( )────────┴─────────( ( ( )─────── Trace N Out
                          L_v - L_m                L_v - L_m
                                         │
                                       ──┴── C_p / C_n (to GND)
                                       ──┬──
        ─────────────────────────────────┴─────────────────────── Ground Reference
```

1. **Characteristic Impedance ของคู่สาย Differential Via ($Z_{diff,via}$):**

$$Z_{diff,via} = 2 \times Z_{odd,via} = 2 \times \sqrt{\frac{L_v - L_m}{C_{p} + 2C_m}} \quad [\Omega]$$

- ในโครงสร้างรูเจาะเดี่ยวทรงกลมแยกกัน 2 รู เนื้อทองแดงของระนาบ Ground ที่คั่นอยู่ตรงกลางระหว่างรูเจาะ จะสร้างความจุแฝงลงกราวด์ ($C_p, C_n$) มหาศาล ในขณะที่ขัดขวางการคู่ควบระหว่างคู่สาย ($C_m \approx 0$) ส่งผลให้ $Z_{diff,via}$ **ดิ่งฮวบลงเหลือเพียง $60 - 70 \ \Omega$** (Capacitive Impedance Dip รุนแรง)

2. **วิวัฒนาการสู่โครงสร้างสนามแข่งม้า (Racetrack / Dog-Bone Anti-Pad):**

```
     Structure A: Isolated Circular Anti-Pads        Structure B: Unified Racetrack Anti-Pad
          Ground Plane Web (C_gnd too high!)              Copper Web Removed! (Cm restored)
       ════════════════════════════════════════        ════════════════════════════════════════
       ║   ┌──────┐   ╔════════╗   ┌──────┐   ║        ║   ┌──────────────────────────────┐   ║
       ║   │ ViaP │   ║ Copper ║   │ ViaN │   ║        ║   │  (ViaP)              (ViaN)  │   ║
       ║   └──────┘   ║  Web   ║   └──────┘   ║        ║   └──────────────────────────────┘   ║
       ════════════════════════════════════════        ════════════════════════════════════════
       Result: Z_diff = 65Ω (Mismatch!)                Result: Z_diff = 85Ω or 100Ω (Matched!)
```

- **กลไกการทำงานของ Racetrack Anti-Pad:**  
  การผสานรอยฉลุกราวด์ของทั้งสองรูเจาะเข้าด้วยกันเป็นรูปวงรีทรงยาว (Racetrack / Oval Void):
  1. ขจัดเนื้อทองแดงส่วนเกินที่อยู่ตรงกลางระหว่างคู่สายออกไป ทำให้ความจุแฝงลงกราวด์ ($C_p$) ลดลง
  2. เปิดช่องว่างให้เส้นแรงสนามไฟฟ้าระหว่างเส้น $P$ และ $N$ สามารถคู่ควบเข้าหากันได้โดยตรง เพิ่มค่า Mutual Capacitance ($C_m$)
  3. ช่วยยกค่า Differential Impedance จาก $65 \ \Omega$ กลับขึ้นมาแมตช์ที่ **$85 \ \Omega$ (PCIe) หรือ $100 \ \Omega$ (Ethernet)** ได้อย่างสมบูรณ์แบบ

### 1.2 โครงสร้างกรงกราวด์ (Ground Return Shielding Cage) และการกำจัด Mode Conversion ($S_{cd21}$)

ปัญหาที่อันตรายที่สุดในจุดเปลี่ยนผ่านของคู่สาย Differential คือ **ความไม่สมมาตรของเส้นทางกระแสไหลกลับ (Asymmetric Return Path)**:

```
     Structure A: Asymmetric G-S-S (Severe EMI!)       Structure B: Symmetric G-S-S-G Array
         GND         Sig_P       Sig_N                     GND         Sig_P       Sig_N       GND
        ( o )       ( O )       ( O )                     ( o )       ( O )       ( O )       ( o )
          ◄── d1 ──►  ◄────── d2 ─────►                     ◄── d ──►   ◄── S ──►   ◄── d ──►
        Asymmetrical Return Coupling!                     Symmetrical Return Coupling!
        Result: Scd21 = -12 dB (Massive Common-Mode)      Result: Scd21 < -35 dB (Zero Common-Mode)
```

1. **หายนะจากโครงสร้างไม่สมมาตร (Asymmetric G-S-S Structure):**  
   หากมี Ground Return Via วางอยู่เพียงฝั่งเดียว (ใกล้เส้น $P$ แต่ไกลจากเส้น $N$):
   - กระแสไหลกลับของเส้น $P$ จะมีลูปเหนี่ยวนำขนาดเล็ก ($L_{loop,P}$ ต่ำ)
   - กระแสไหลกลับของเส้น $N$ จะมีลูปเหนี่ยวนำขนาดใหญ่กว่า ($L_{loop,N}$ สูง)
   - ผลต่างความเหนี่ยวนำนี้ทำลายสมดุลทางไฟฟ้า แปลงสัญญาณ Differential ให้กลายเป็น **Common-Mode Noise ($S_{cd21}$ พุ่งสูงแตะ $-10 \text{ dB}$ ถึง $-15 \text{ dB}$)** คลื่นรังสี EMI จะแผ่ออกจากรูเจาะกระจายไปทั่วทั้งบอร์ด

2. **การจัดวางแบบสมมาตรระดับคัมภีร์ (Symmetric Shielding Topologies):**
   - **Linear G-S-S-G Array:** วาง Return Via ประกบหัว-ท้ายในแนวเส้นตรงเดียวกัน
   - **Cross / Hexagonal Pattern (รูปแบบ 6 รู หรือ 4 รูกากบาท):** วาง Return Via ขนาบข้างบนและล่างของคู่สัญญาณในระยะห่างที่เท่ากันเป๊ะ ($d_P = d_N$)
   - ช่วยรักษาค่า $S_{cd21} < -35 \text{ dB}$ ขจัดสัญญาณรบกวน EMI และรักษาสภาพความสมบูรณ์ของ Eye Diagram ได้ดีเยี่ยม

### 1.3 การควบคุม Vertical Intra-Pair Skew ในจุดเลี้ยวเข้า Via (Breakout Routing)

เมื่อคู่สาย Differential เดินทางมาถึงจุดเปลี่ยนเลเยอร์ ทิศทางการเลี้ยวเข้าสู่ Via Pad มักก่อให้เกิดความยาวสายที่ไม่เท่ากันในระดับเศษส่วนของมิลลิเมตร (Breakout Skew):

```
       Trace P ──────────────────────────┐
                                         │ Turn 90° (Longer path L_P)
                                         ▼
                                       ( P ) Via
                                       ( N ) Via
                                         ▲
       Trace N ──────────────────────────┘ Turn 90° (Shorter path L_N)
```

**เกณฑ์การควบคุม Timing Skew ในแนวดิ่ง:**
- ในย่านความถี่ 112G PAM4 หรือ PCIe Gen 6 (Nyquist $16 - 28 \text{ GHz}$):
  ค่า Intra-pair Skew ที่ยอมรับได้มีค่า **ไม่เกิน $0.3 - 0.5 \text{ ps}$ (เทียบเท่าความต่างระยะทางบนบอร์ด $\le 0.05 \text{ mm} \ / \ 2 \text{ mil}$)**
- วิศวกรต้องทำ **Jog / Meander Length Compensation ทันทีที่ปากทางเข้า Via** ก่อนที่สัญญาณจะมุดลงในแนวดิ่ง ห้ามปล่อยให้เกิด Phase Mismatch ภายในกระบอก Via โดยเด็ดขาด

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** การ์ดเร่งความเร็ว AI เซิร์ฟเวอร์ PCIe Gen 5 x16 AIC ไม่ผ่านการทดสอบ FCC Part 15 Class B Radiated Emission อย่างรุนแรง โดยพบคลื่นวิทยุแผ่กระจายสูงเกินเกณฑ์มาตรฐานถึง **$14 \text{ dB}\mu\text{V/m}$ ที่ความถี่ 16 GHz และ 32 GHz** และพอร์ต PCIe เกิดการเจรจาลดความเร็ว (Link Speed Down-training) จาก Gen 5 ลงเหลือ Gen 3 เป็นระยะ
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **จัดวาง Ground Return Via ไม่สมมาตร (Asymmetric Pin Pattern):** ในจุดเปลี่ยนเลเยอร์ของเลน PCIe ทั้ง 16 เลน มีการเจาะ Ground Via คั่นเฉพาะฝั่งซ้ายของคู่สาย (G-S-S) แต่ไม่มี Ground Via ฝั่งขวา เนื่องจากติดขัดพื้นที่ชิปข้างเคียง
2. **Mode Conversion $S_{cd21}$ แย่ลงถึง $-11.5 \text{ dB}$:**  
   สนามแม่เหล็กไฟฟ้าที่ไม่สมมาตรเปลี่ยนพลังงานของสัญญาณ Differential กลายเป็นคลื่น Common-Mode พุ่งลงสู่โครงแชสซีโลหะและแผ่รังสีออกสู่อากาศเหมือนเสาอากาศไดโพล
3. **ใช้ Anti-Pad ทรงกลมแยกเดี่ยว:** ทำให้ Differential Impedance ตกเหลือเพียง $68 \ \Omega$ เกิดการสะท้อนกลับหลายระลอก

---

### ขั้นตอนการออกแบบ Differential Via ระดับ Senior (検図チェックリスト):
1. **การรวม Anti-Pad เป็นรูปสนามแข่งม้า (Racetrack Optimization):**
   - รวมรอยฉลุกราวด์ชั้นใน L2 ถึง Ln ของคู่สัญญาณเข้าด้วยกัน:
     - ความกว้างรอยฉลุ (Short axis): $D_{anti\_short} = D_{pad} + 0.35 \text{ mm} \ (14 \text{ mil})$
     - ความยาวรอยฉลุ (Long axis): ครอบคลุมทั้งสอง Via ต่อเนื่องกันเป็นรูปวงรี
   - ใช้ 3D EM Solver (HFSS / Clarity) จำลองปรับแต่งจนได้ค่า $Z_{diff,via} = 85.0 \ \Omega \pm 2 \ \Omega$
2. **การบังคับใช้โครงสร้าง Ground Return Via แบบสมมาตร $100\%$:**
   - **กฎเหล็ก:** ห้ามใช้โครงสร้าง G-S-S แบบมีกราวด์ข้างเดียวเด็ดขาด!
   - ต้องใช้โครงสร้าง **G-S-S-G (กราวด์ประกบทั้งซ้ายและขวา)** หรือวางกราวด์ 4 รูประกบหัวท้ายสมมาตร:
     - รักษาระยะห่างจาก Signal Via ไปยัง Ground Return Via ($d_{return}$) ให้เท่ากันทั้งฝั่งบวกและลบภายในพิกัด $\pm 0.05 \text{ mm}$
     - ช่วยกดค่า $S_{cd21}$ ให้ลดลงต่ำกว่า **$-35 \text{ dB}$** กำจัดคลื่นรังสี EMI ได้อย่างหมดจด
3. **การชดเชย Intra-pair Skew ที่รอยต่อ Breakout:**
   - ลากสายเข้า Via ทั้งสองเส้นให้มีความสมมาตรทางเรขาคณิตสูงสุด หากเส้นหนึ่งต้องเลี้ยวหลบ ให้ใส่จุดชดเชย Meander ทันทีก่อนมุดลง Via เพื่อรักษาผลต่างเวลาเดินทาง $\Delta t \le 0.3 \text{ ps}$

### ประโยคตัวอย่างที่ใช้จริงในการทำ Design Review (検図の指摘文例)

> **指摘事項 1:**  
> 「PCIe Gen5（32GT/s）差動ペアの層間遷移ビア部において、GNDリターンビアが片側のみ配置された非対称G-S-S構造となっています。電磁界シミュレーション結果より、Nyquist周波数16GHzにおける差動-コモンモード変換損失（Scd21）が-11.5dBまで悪化しており、放射ノイズ規格（FCC Class B）の超過およびジッタ増大の原因となっています。信号対を両脇から均等に挟み込む対称G-S-S-G配置（または上下対称4本ケージ配置）へ修正し、Scd21を-35dB以下へ抑制してください。」  
> *(ในจุดเปลี่ยนเลเยอร์ของ PCIe Gen5 มีการวาง Ground Via ฝั่งเดียวแบบ G-S-S ไม่สมมาตร ทำให้ Mode Conversion Scd21 ที่ 16GHz แย่ลงถึง -11.5dB แผ่คลื่น EMI เกินเกณฑ์ FCC Class B กรุณาแก้ไขเป็นโครงสร้างสมมาตร G-S-S-G ประกบสองข้างอย่างเท่าเทียม เพื่อกดค่า Scd21 ให้ต่ำกว่า -35dB)*

> **指摘事項 2:**  
> 「内層GNDプレーンにおける差動ビアのアンチパッドが個別円形（φ0.45mm分離型）で設計されているため、差動ビア間の中間銅箔プレーンにより奇モード容量が過剰となり、差動インピーダンスが67Ωまで急落（容量性ディップ）しています。内層アンチパッドを統合長円形状（トラック型ボイド：長径1.35mm×短径0.65mm）へ変更し、差動特性インピーダンスを仕様値（85Ω±5%）へ整合させてください。」  
> *(เนื่องจาก Anti-pad บนระนาบกราวด์ชั้นในแยกเป็นรูกลมเดี่ยว เนื้อทองแดงตรงกลางทำให้ความจุแฝงสูง ดึง Differential Impedance ดิ่งลงเหลือ 67 โอห์ม กรุณาเปลี่ยน Anti-pad เป็นรูปสนามแข่งม้ารวมขนาด 1.35x0.65mm เพื่อปรับอิมพีแดนซ์ให้ได้ 85 โอห์มตามสเปก)*

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (ผลกระทบของ Asymmetric Ground Return Via ต่อการแปลงโหมดสัญญาณ)
ในการเปลี่ยนเลเยอร์ของคู่สายส่ง Differential Line หากวิศวกรจัดวาง Ground Return Via ในลักษณะไม่สมมาตร (เช่น อยู่ชิดเส้น $P$ แต่ห่างจากเส้น $N$) ปรากฏการณ์ทางฟิสิกส์ข้อใดจะเกิดขึ้นกับรูปคลื่นของสัญญาณที่ความถี่สูง?

- **ก)** สัญญาณทั้งสองเส้นจะเดินทางเร็วขึ้นเป็น 2 เท่า
- **ข)** ลูปความเหนี่ยวนำของเส้น $P$ และเส้น $N$ จะมีขนาดไม่เท่ากัน ทำให้เกิดความต่างศักย์และเฟสที่เหลื่อมกัน แปลงพลังงานของคลื่น Differential ให้กลายเป็น Common-Mode Noise ($S_{cd21}$ พุ่งสูง) ซึ่งไม่สามารถหักล้างกันได้ที่ตัวรับ และแผ่รังสีเป็นคลื่นแม่เหล็กไฟฟ้า EMI รุนแรง
- **ค)** ความจุไฟฟ้าแฝงของเส้น $N$ จะลดลงเป็นศูนย์
- **ง)** สัญญาณจะเปลี่ยนเป็นไฟฟ้ากระแสตรง

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> เมื่อ Ground Return Via วางอยู่ใกล้เส้น $P$ มากกว่าเส้น $N$:  
> - กระแสไหลกลับของเส้น $P$ จะมีเส้นทางลัดเลาะที่สั้นมาก ส่งผลให้ค่าลูปความเหนี่ยวนำ $L_{loop,P}$ ต่ำ และมีเวลาหน่วง $t_{d,P}$ สั้น  
> - แต่กระแสไหลกลับของเส้น $N$ จะต้องเดินทางไกลกว่าเพื่อหาทางมุดลง Return Via ส่งผลให้ค่า $L_{loop,N}$ สูงกว่า และมีเวลาหน่วง $t_{d,N}$ ยาวนานกว่า  
> ความไม่สมมาตรทางฟิสิกส์นี้ทำลายสภาวะสมดุลของคู่สาย Differential ($V_P(t) \ne -V_N(t)$)  
> ผลต่างของรูปคลื่นจะถูกแปลงสภาพกลายเป็น **Common-Mode Voltage: $V_{comm} = (V_P + V_N)/2$** ซึ่งกระแส Common-Mode นี้จะไหลวนผ่านระนาบกราวด์และโครงสร้างตัวถัง แผ่รังสีออกสู่อากาศเป็นคลื่นวิทยุ EMI ขนาดมหาศาล ($S_{cd21} \uparrow$) ทำให้บอร์ดตกการทดสอบมาตรฐาน EMC ทันที

### ข้อที่ 2 (ทำไม Racetrack Anti-Pad จึงช่วยดึง Differential Impedance ให้สูงขึ้นได้?)
เหตุใดการเปลี่ยนรอยฉลุกราวด์จากรูกลมแยกเดี่ยว 2 รู มาเป็นรอยฉลุรูปสนามแข่งม้า (Racetrack Anti-Pad) ที่ผสานช่องว่างของทั้งสองรูเข้าด้วยกัน จึงสามารถแก้ปัญหา Capacitive Dip และดึงค่า Differential Impedance ($Z_{diff}$) ของคู่ Via ให้สูงขึ้นได้?

- **ก)** เพราะความต้านทานของทองแดงในกระบอก Via ลดลง
- **ข)** เพราะการรวมช่องว่างช่วยขจัดเนื้อทองแดงของระนาบ Ground ที่คั่นอยู่ตรงกลางระหว่าง Via ทั้งสองออกไป ช่วยลดค่าความจุไฟฟ้าแฝงลงกราวด์ ($C_p, C_n$) และเปิดทางให้สนามไฟฟ้าระหว่างเส้น $P$ และ $N$ คู่ควบกันได้โดยตรง ($C_m \uparrow$) ซึ่งช่วยดึงอิมพีแดนซ์โหมดแปลกแยก ($Z_{odd} = \sqrt{(L-L_m)/(C+2C_m)}$) ให้แมตช์ที่ 85/100 โอห์ม
- **ค)** เพราะรอยฉลุรูปวงรีช่วยให้อากาศไหลผ่านระบายความร้อนได้ดีขึ้น
- **ง)** เพราะช่วยลดค่าความเหนี่ยวนำในตัวเองของกระบอก Via ลงเหลือศูนย์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในรูกลมเดี่ยวแยกกัน: เนื้อทองแดงของ Ground Plane ที่แทรกอยู่ตรงกลางระหว่างรูเจาะทั้งสองทำหน้าที่เป็นแผ่นขั้วลบ ดึงดูดเส้นแรงสนามไฟฟ้าจากทั้ง Via $P$ และ Via $N$ ลงสู่กราวด์ เกิดค่าความจุไฟฟ้าแฝงลงดิน ($C_{gnd}$) ขนาดมหึมา ส่งผลให้อิมพีแดนซ์ชั่วขณะดิ่งลงเหลือเพียง $60 - 70 \ \Omega$  
> เมื่อเปลี่ยนเป็น **Racetrack Anti-Pad**:  
> 1. เนื้อทองแดงคั่นกลางถูกลบออกไป ขจัดตัวเก็บประจุแฝงลงดินส่วนเกินทิ้งไปทันที  
> 2. ตัวนำ $P$ และ $N$ หันหน้าเข้าหากันโดยตรงในเนื้อไดอิเล็กทริก ทำให้เส้นแรงสนามไฟฟ้าจับคู่กันเองตามธรรมชาติ (Mutual Coupling)  
> การลดทอนความจุแฝงลงดินนี้ ช่วยดึงให้อิมพีแดนซ์ดิฟเฟอเรนเชียลขยับสูงขึ้น ชดเชยหลุม Capacitive Dip และทำให้สัญญาณ Multi-Gigabit วิ่งผ่านจุดเปลี่ยนเลเยอร์ได้อย่างราบรื่น

### ข้อที่ 3 (เกณฑ์ความคลาดเคลื่อนของเวลา Intra-pair Skew ที่ยอมรับได้ในจุดเปลี่ยนเลเยอร์ 112G PAM4)
ในระบบส่งสัญญาณ 112G PAM4 (ความถี่ Nyquist $28.0 \text{ GHz}$, คาบเวลาของบิตข้อมูล $UI \approx 17.85 \text{ ps}$) ค่า Intra-pair Timing Skew สูงสุดที่ยอมรับได้ ณ จุดเปลี่ยนผ่านของ Via Breakout มีค่าเท่ากับข้อใดโดยประมาณ?

- **ก)** ไม่เกิน $5.0 \text{ ps}$
- **ข)** ไม่เกิน $0.3 - 0.5 \text{ ps}$ (เทียบเท่าความต่างความยาวบนบอร์ดประมาณ $\le 0.05 \text{ mm}$)
- **ค)** ไม่เกิน $20.0 \text{ ps}$
- **ง)** ยอมรับค่า Skew เท่าใดก็ได้เพราะมีวงจร DSP ช่วยปรับแก้

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ในสัญญาณ 112G PAM4 คาบเวลาของหนึ่งสัญลักษณ์ (Symbol Period) สั้นเพียง $17.85 \text{ ps}$  
> ตามกฎเกณฑ์ทางวิศวกรรมสากล: Intra-pair Skew รวมของทั้งช่องสัญญาณจะต้องถูกจำกัดให้ **ไม่เกิน $5\% - 8\%$ ของคาบเวลา UI** ($\approx 0.9 - 1.4 \text{ ps}$ ตลอดทั้งช่องสัญญาณ)  
> ดังนั้น ในจุดสะดุดเพียงจุดเดียวอย่าง Via Transition งบประมาณความคลาดเคลื่อน (Skew Budget) ที่อนุญาตให้เกิดขึ้นได้จึงถูกบีบให้แคบมาก:  
> $$\Delta t_{skew} \le \mathbf{0.3 \ - \ 0.5 \text{ ps}}$$  
> เมื่อคำนวณย้อนกลับเป็นระยะทางบนบอร์ดที่มีความเร็วคลื่น $v_p \approx 150 \text{ mm/ns}$ ($6.67 \text{ ps/mm}$):  
> $$\Delta L \le \frac{0.3 \text{ ps}}{6.67 \text{ ps/mm}} \approx \mathbf{0.045 \text{ mm} \ (\approx 1.8 \text{ mil})}$$  
> วิศวกรจึงต้องควบคุมความยาวของการเลี้ยวเข้า Via ของทั้งสองเส้นให้เท่ากันอย่างเข้มงวดในระดับไมครอน
