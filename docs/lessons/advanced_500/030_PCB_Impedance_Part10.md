## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการเปลี่ยนแบบร่างวงจรในโปรแกรม EDA (เช่น Altium, Cadence Allegro) ให้กลายเป็นแผ่นบอร์ดฮาร์ดแวร์จริงในโรงงานอุตสาหกรรม ค่าอิมพีแดนซ์ที่สมบูรณ์แบบบนหน้าจอคอมพิวเตอร์จะต้องเผชิญหน้ากับ **ความแปรปรวนในกระบวนการผลิตจริง (Manufacturing Tolerances)** 
ไม่ว่าจะเป็นการกัดกรดทองแดงที่ทำให้หน้าตัดกลายเป็นรูปสี่เหลี่ยมคางหมู (Trapezoidal Etch Profile), ความหนาและการยุบตัวของพรีเพร็ก (Resin Receding / Prepreg Lamination Variation), ความหยาบของผิวฟอยล์ทองแดง (Copper Foil Surface Roughness), และความคลาดเคลื่อนของค่าคงที่ไดอิเล็กทริก ($\epsilon_r$)

วิศวกรระดับ Senior ต้องเข้าใจ **กลไกการชดเชยข้อมูล CAM (Etch Allowance & CAM Compensation)**, **โมเดลความหยาบระดับอนุภาค Cannonball-Huray Model**, และ **เกณฑ์การตรวจรับรองคุณภาพคูปองทดสอบตามมาตรฐาน IPC-6012 Class 3**

### 1.1 หน้าตัดสี่เหลี่ยมคางหมูและแฟกเตอร์การกัดกรด (Trapezoidal Trace Profile & Etch Factor)

ในกระบวนการกัดกรดด้วยสารเคมี (Chemical Etching) น้ำยากรดจะกัดเนื้อทองแดงในแนวดิ่งพร้อมกับกัดกินเนื้อทองแดงด้านข้างใต้ชั้น Photoresist (Undercut: $U$) ทำให้ลายวงจรจริงไม่ได้มีหน้าตัดเป็นสี่เหลี่ยมผืนผ้า แต่กลายเป็น **รูปสี่เหลี่ยมคางหมู (Trapezoid)**:

```
                  Photoresist Mask (Width W_mask)
                  ┌─────────────────────────────┐
                  ▼                             ▼
                  ┌─────────────────────────────┐
                  │                             │ ◄── Undercut U
               ┌──┴─────────────────────────────┴──┐
               │         Top Width W_top           │
               │                                   │ Height T (Copper Thickness)
               │          Base Width W_base        │
         ──────┴───────────────────────────────────┴────── Substrate
```

1. **อัตราส่วนการกัดกรด (Etch Factor: $EF$):**

$$EF = \frac{T}{U}$$

- กระบวนการผลิตมาตรฐาน: $EF \approx 2.0 - 2.5$
- กระบวนการผลิตขั้นสูง (mSAP / High-Precision Advanced Etching): $EF \approx 3.0 - 4.0$

2. **ความกว้างด้านบนและด้านล่าง:**
   - ความกว้างด้านบน: $W_{top} = W_{base} - 2U = W_{base} - 2 \cdot \frac{T}{EF}$
   - ความกว้างประสิทธิผลเฉลี่ย (Effective Trace Width): $W_{eff} \approx \frac{W_{top} + W_{base}}{2} = W_{base} - \frac{T}{EF}$

3. **การชดเชยข้อมูลในขั้นตอน CAM (CAM Etch Compensation):**  
   หากวิศวกรออกแบบต้องการให้สายสำเร็จรูปกว้าง $W_{nominal} = 5.0 \text{ mil}$ บนทองแดงหนา $1 \text{ oz} \ (1.4 \text{ mil})$ โดยมี $EF = 3.0$:  
   วิศวกร CAM ในโรงงานจะต้องขยายลายเส้นในไฟล์ Gerber เพิ่มขึ้นล่วงหน้า ($\Delta W_{CAM} = +0.7 \text{ mil}$ ถึง $+1.0 \text{ mil}$) เพื่อให้หลังการกัดกรดแล้ว $W_{eff}$ ตรงกับสเปก $5.0 \text{ mil}$ พอดิบพอดี

### 1.2 ผลกระทบของความหยาบผิวทองแดง (Copper Foil Roughness) และโมเดลฟิสิกส์ Huray Model

ที่ความถี่ระดับ Multi-Gigabit กระแสสัญญาณจะไหลเบียดขึ้นมาอยู่เฉพาะบริเวณผิวนอกของตัวนำทองแดงตามปรากฏการณ์ **Skin Effect**:

$$\delta = \sqrt{\frac{1}{\pi \cdot f \cdot \mu_0 \cdot \sigma}} \quad [\text{Skin Depth}]$$

ที่ความถี่ $10 \text{ GHz}$ บนทองแดง ความลึกของกระแสสกินเดพธ์มีค่าเพียง $\delta \approx 0.66 \ \mu\text{m}$ (660 นาโนเมตร) ซึ่ง **บางกว่าความหยาบของผิวทองแดง ($R_z = 3 - 8 \ \mu\text{m}$)** เสียอีก!  
ส่งผลให้กระแสไฟฟ้าต้องไหลเลี้ยวลดคดเคี้ยวไปตามเม็ดเกร็ดขรุขระของทองแดง ทำให้ระยะทางการไหลเพิ่มขึ้น (Current Crowding) ค่าความต้านทานต่อความถี่สูง ($R_{ac}$) พุ่งขึ้น และเฟสของสัญญาณหน่วงช้าลง

```
       Smooth Surface (Ideal)              Rough Profile (ED Copper Nodules)
    ───────────────────────────       ▲     /\  /\    /\  /\  /\    /\
    ==== Skin Depth δ =========       │    /  \/  \  /  \/  \/  \  /  \
                                      │   /        \/            \/    \ ◄── Rz = 5-8 μm
    Copper Conductor                  ▼  ────────────────────────────────
                                         ════ Skin Depth δ << Rz ════════
```

| ชนิดของฟอยล์ทองแดง (Copper Foil Type) | ความหยาบผิวเฉลี่ย ($R_z$) | ระดับการสูญเสียที่ 28 GHz | การประยุกต์ใช้งาน |
|---|---|---|---|
| **Standard Electrodeposited (STD ED)**| $7.0 - 10.0 \ \mu\text{m}$ | สูงมาก (Severe Attenuation) | วงจรทั่วไปความถี่ $< 1 \text{ GHz}$, พาวเวอร์ซัพพลาย |
| **Very Low Profile (VLP)** | $3.0 - 4.5 \ \mu\text{m}$ | ปานกลาง | PCIe Gen 3/4, DDR4, สัญญาณต่ำกว่า $10 \text{ Gbps}$ |
| **Hyper Very Low Profile (HVLP / RTF)**| $1.2 - 2.0 \ \mu\text{m}$ | ต่ำมาก (Low Loss) | PCIe Gen 5/6, 56G/112G PAM4, 100GbE |
| **Rolled Annealed (RA / Ultra-Smooth)**| $< 1.0 \ \mu\text{m}$ | ต่ำที่สุด | RF มิลลิเมตรเวฟ 77GHz, Flexible PCB |

**โมเดลลูกบอลหิมะของ Huray (Cannonball-Huray Model):**  
แบบจำลองคลาสสิกของ Hammerstad ไม่สามารถทำนายการสูญเสียที่เกิน $10 \text{ GHz}$ ได้อย่างถูกต้อง มาตรฐาน IEEE จึงเปลี่ยนมาใช้โมเดลของ Huray ซึ่งจำลองผิวทองแดงเป็นลูกกลมตัวนำ (Nodules) เรียงซ้อนบนฐานพีระมิด:

$$K_{Huray}(f) = 1 + \sum_{i=1}^{N} \frac{3 \cdot \frac{A_{sphere,i}}{A_{flat}}}{1 + \frac{\delta(f)}{a_i} + \frac{\delta^2(f)}{2a_i^2}}$$

โดยที่ $a_i$ คือรัศมีของเม็ดเกร็ดทองแดง และ $A_{sphere}/A_{flat}$ คืออัตราส่วนพื้นที่ผิวขรุขระเทียบกับระนาบเรียบ โมเดลนี้ช่วยให้การจำลอง S-Parameter ที่ความถี่สูงถึง $50 - 100 \text{ GHz}$ สอดคล้องกับการตรวจวัด TDR/VNA จริงในห้องแล็บ

### 1.3 การควบคุมกระบวนการทางสถิติ (Statistical Process Control: Cpk) และมาตรฐาน IPC-6012 Class 3

ในการผลิตจำนวนมาก ค่าอิมพีแดนซ์จะมีการกระจายตัวแบบระฆังคว่ำ (Gaussian Normal Distribution):

$$C_{pk} = \min\left( \frac{USL - \mu}{3\sigma}, \frac{\mu - LSL}{3\sigma} \right)$$

- สำหรับอิมพีแดนซ์ $50 \ \Omega \pm 10\%$: $USL = 55 \ \Omega$, $LSL = 45 \ \Omega$
- **เกณฑ์มาตรฐานอุตสาหกรรม:** $C_{pk} \ge 1.33$ (ของเสียต่ำกว่า $63 \text{ PPM}$)
- **เกณฑ์อุตสาหกรรมยานยนต์/การแพทย์ (Six Sigma):** $C_{pk} \ge 1.67$

**ข้อกำหนดการทดสอบคูปองตาม IPC-6012 Class 3:**
1. บังคับวาง **Test Coupon (Coupon Z / IPC-2221B)** ไว้ที่มุมทั้ง 4 ด้านของแผงพาเนล (Panel Breakaway Margins)
2. ทำการตรวจวัดด้วยเครื่อง TDR อัตโนมัติทุกพาเนล ($100\%$ Coupon TDR Verification)
3. ค่าอิมพีแดนซ์ที่ยอมรับได้สำหรับ Class 3 ต้องอยู่ในกรอบ **$\pm 8\%$** (หรือ $\pm 5\%$ สำหรับ High-reliability Critical Nets) หากคูปองหลุดสเปกแม้แต่จุดเดียว พาเนลนั้นจะต้องถูกกักกัน (Quarantined) ทันที

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** โมดูลเซิร์ฟเวอร์ 100G Switch (25Gbps ต่อเลน x 4) ผ่านการทดสอบคูปอง TDR จากโรงงานผลิตบอร์ดว่าได้อิมพีแดนซ์ $50.2 \ \Omega$ (สเปก $50 \pm 10\%$) อย่างสมบูรณ์ แต่เมื่อนำไปประกอบชิปและวัด Eye Diagram สัญญาณ 25.78 GHz ปรากฏว่า Eye Height แคบลงอย่างรุนแรง และ Insertion Loss ($S_{21}$) สูงเกินสเปกไปถึง **$7.5 \text{ dB}$** ทำให้บอร์ดใช้งานไม่ได้ทั้งล็อต
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **โรงงานแอบสลับชนิดฟอยล์ทองแดง:** ในไฟล์ Fabrication Drawing ระบุวัสดุ Megtron 6 แต่ **ไม่ได้ระบุเกรดความหยาบของทองแดง** ไว้อย่างชัดเจน โรงงานจึงเลือกใช้ Standard ED Foil ($R_z = 7.2 \ \mu\text{m}$) แทนที่จะเป็น HVLP Foil ($R_z = 1.5 \ \mu\text{m}$) เพื่อลดต้นทุน
2. **คูปอง TDR วัดที่ความถี่ต่ำ:** เครื่อง TDR วัดความต้านทานและอิมพีแดนซ์ด้วยพัลส์ที่มีพลังงานความถี่ต่ำเป็นหลัก จึงมองไม่เห็นการสูญเสียจากผิวขรุขระ แต่ที่ความถี่ Nyquist $12.89 \text{ GHz}$ สกินเดพธ์ที่บางมากถูกดูดกลืนพลังงานหายไปในผิวขรุขระจนหมดสิ้น

---

### ขั้นตอนการควบคุมสเปกสั่งผลิตและ Acceptance Testing สไตล์ Senior (検図チェックリスト):
1. **การระบุสเปก Copper Foil Roughness ใน Master Drawing อย่างเคร่งครัด:**
   - ต้องระบุในตาราง Layer Stackup ชัดเจน:
     > *"All high-speed inner signal layers MUST use HVLP (Hyper Very Low Profile) copper foil with Rz <= 1.5 um and Ra <= 0.3 um. Standard ED copper is strictly prohibited."*
2. **การสั่งทำ Cross-Section Microsection Analysis:**
   - สั่งให้โรงงานตัดชิ้นเนื้อบอร์ด (Cross-Section Polish) ส่งภาพถ่ายกำลังขยาย 500x/1000x จากกล้องจุลทรรศน์โลหะวิทยา ยืนยัน:
     - หน้าตัดสี่เหลี่ยมคางหมู ($W_{top}$ และ $W_{base}$)
     - ความหนาของทองแดงสำเร็จรูป (Finished Copper Thickness)
     - ความหนาของไดอิเล็กทริกหลังผ่านการอบอัด (Pressed Dielectric Thickness)
3. **การกำหนดเกณฑ์ TDR Bandwidth และ Test Coupon Design:**
   - ใช้คูปองที่มีความยาวอย่างน้อย **$150 \text{ mm} \ (6 \text{ inches})$** เพื่อให้เครื่อง TDR มีระยะเวลาในการวัดค่าที่นิ่งเสถียร (Steady State Window)
   - ปรับ Rise Time ของเครื่อง TDR ให้สัมพันธ์กับความเร็วของสัญญาณจริง (เช่น $t_r = 30 \text{ ps}$ กรองด้วย Gaussian Filter) ไม่ใช้ค่าเริ่มต้นที่ช้าเกินไป

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ CAM Etch Compensation และหน้าตัดสี่เหลี่ยมคางหมู)
โรงงานผลิตแผ่นวงจรพิมพ์ใช้กระบวนการกัดกรดที่มี Etch Factor เท่ากับ $EF = 3.0$ โดยใช้แผ่นฟอยล์ทองแดงความหนา $1 \text{ oz} \ (T = 35 \ \mu\text{m})$ วิศวกรออกแบบต้องการให้สายส่งเมื่อผลิตเสร็จมี **ความกว้างประสิทธิผลเฉลี่ย (Average Effective Width: $W_{eff} = (W_{top} + W_{base})/2$) เท่ากับ $120 \ \mu\text{m}$** พอดิบพอดี ถามว่าวิศวกร CAM ในโรงงานจะต้องกำหนดความกว้างของฐานทองแดง ($W_{base}$) ในกระบวนการกัดกรดให้มีขนาดเท่ากับข้อใด?

- **ก)** $W_{base} = 120.0 \ \mu\text{m}$ (เท่ากับความกว้างเป้าหมาย)
- **ข)** $W_{base} = 131.7 \ \mu\text{m}$ (ขยายเพิ่มขึ้นเพื่อชดเชย Undercut)
- **ค)** $W_{base} = 108.3 \ \mu\text{m}$ (บีบให้เล็กลงเพื่อป้องกันการลัดวงจร)
- **ง)** $W_{base} = 145.0 \ \mu\text{m}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> 1. คำนวณหาค่าการกัดแหว่งด้านข้าง (Undercut: $U$):  
> จากนิยามของ Etch Factor: $EF = \frac{T}{U}$  
> $$U = \frac{T}{EF} = \frac{35 \ \mu\text{m}}{3.0} \approx 11.67 \ \mu\text{m}$$  
> 2. ความสัมพันธ์ทางเรขาคณิตของหน้าตัดสี่เหลี่ยมคางหมู:  
> ด้านบนจะถูกกัดกินจากทั้งสองข้างข้างละ $U$:  
> $$W_{top} = W_{base} - 2U$$  
> ความกว้างเฉลี่ย $W_{eff}$:  
> $$W_{eff} = \frac{W_{top} + W_{base}}{2} = \frac{(W_{base} - 2U) + W_{base}}{2} = W_{base} - U$$  
> 3. หาค่า $W_{base}$ ที่ต้องตั้งค่าในกระบวนการผลิต:  
> $$W_{base} = W_{eff} + U = 120.0 \ \mu\text{m} + 11.67 \ \mu\text{m} = \mathbf{131.67 \ \mu\text{m}} \ (\approx 131.7 \ \mu\text{m})$$  
> ดังนั้นวิศวกร CAM จะต้องขยายลายเส้นบนฟิล์มโฟโต้มาสก์ให้กว้างขึ้นประมาณ $+11.7 \ \mu\text{m}$ (หรือเกือบ $+0.5 \text{ mil}$) เพื่อให้หลังน้ำยากรดกัดเนื้อทองแดงด้านข้างออกไปแล้ว ได้ความกว้างเฉลี่ย $120 \ \mu\text{m}$ ตามที่ผู้ออกแบบต้องการ

### ข้อที่ 2 (ทำไม Test Coupon TDR ผ่านฉลุย แต่บอร์ดจริงกลับส่งข้อมูล 56G PAM4 ไม่ได้?)
ในการผลิตบอร์ดประมวลผลเครือข่ายความเร็วสูง คูปองทดสอบอิมพีแดนซ์ (TDR Coupon Z) ผ่านการตรวจวัดตามสเปก $100 \ \Omega \pm 8\%$ ทุกชิ้น แต่เมื่อนำบอร์ดจริงไปทดสอบส่งข้อมูล 56G PAM4 (ความถี่ Nyquist $14 \text{ GHz}$) ปรากฏว่าสัญญาณเกิด Bit Errors มหาศาลและ Eye Diagram ปิดทึบจากค่า Insertion Loss ที่สูงเกินค่ามาตรฐาน ข้อใดอธิบายสาเหตุทางเทคนิคได้ถูกต้องที่สุด?

- **ก)** คูปอง TDR บนพาเนลใช้ตัวเหนี่ยวนำเทียมทำให้ค่าที่วัดได้หลอกตา
- **ข)** เครื่อง TDR มาตรฐานส่งพัลส์ที่มีพลังงานความถี่ต่ำและวัดเฉพาะ Characteristic Impedance ($Z_0 = \sqrt{L/C}$) แต่ไม่ได้วัดการสูญเสียที่ความถี่สูงจาก Copper Surface Roughness ($R_z$) และ Dielectric Loss Tangent ($\tan\delta$)
- **ค)** คูปองทดสอบไม่ได้รับการบัดกรีด้วยตะกั่วไร้สารพิษ (RoHS)
- **ง)** ชิป PAM4 ต้องการอิมพีแดนซ์ $200 \ \Omega$ จึงเกิดการไม่แมตช์

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> การทดสอบ TDR Acceptance Test ตามมาตรฐาน IPC-6012 มุ่งเน้นการตรวจวัดค่าพารามิเตอร์ทางเรขาคณิต ได้แก่ ความจุ ($C$) และความเหนี่ยวนำ ($L$) ของสายส่ง เพื่อยืนยันว่าความกว้างสายและความหนาของไดอิเล็กทริกตรงตามคำนวณ ($Z_0 \approx \sqrt{L/C}$)  
> ทว่าเครื่อง TDR ทั่วไปไม่ได้วัด **การลดทอนของสัญญาณที่ความถี่สูง (Insertion Loss / Attenuation)**  
> หากโรงงานใช้วัสดุที่มีค่าความหยาบผิวทองแดงสูง (STD ED Copper: $R_z \approx 8 \ \mu\text{m}$) ค่า $Z_0$ ที่วัดด้วย TDR จะยังคงผ่านเกณฑ์ $100 \ \Omega$ ได้อย่างสมบูรณ์แบบ แต่ที่ความถี่ Nyquist $14 \text{ GHz}$ สกินเดพธ์จะบางเพียง $0.55 \ \mu\text{m}$ ทำให้กระแสสัญญาณวิ่งชนเม็ดเกร็ดทองแดงและสูญเสียพลังงานเป็นความร้อนมหาศาล (Conductor Attenuation พุ่งสูงขึ้นเป็นเท่าตัว) ดึงให้ Eye Diagram ปิดสนิท บอร์ดจริงจึงใช้งานไม่ได้

### ข้อที่ 3 (การประเมินค่าความสามารถของกระบวนการผลิต Process Capability: Cpk)
โรงงาน PCB ทำการผลิตบอร์ด 8 เลเยอร์สำหรับอุปกรณ์การแพทย์ โดยมีข้อกำหนด Characteristic Impedance ที่ $50.0 \ \Omega \pm 4.0 \ \Omega$ (USL = $54.0 \ \Omega$, LSL = $46.0 \ \Omega$) จากการสุ่มตรวจวัดคูปองจำนวน 500 พาเนล พบว่าค่าเฉลี่ยของกระบวนการอยู่ที่ $\mu = 50.8 \ \Omega$ และมีค่าส่วนเบี่ยงเบนมาตรฐาน $\sigma = 0.80 \ \Omega$ ถามว่ากระบวนการผลิตนี้มีค่า $C_{pk}$ เท่าใด และผ่านเกณฑ์มาตรฐานระดับสูง ($C_{pk} \ge 1.33$) หรือไม่?

- **ก)** $C_{pk} = 1.67$ (ผ่านเกณฑ์ระดับยอดเยี่ยม)
- **ข)** $C_{pk} = 1.33$ (ผ่านเกณฑ์พอดีเป๊ะ)
- **ค)** $C_{pk} = 2.00$ (ผ่านเกณฑ์ระดับ Six Sigma)
- **ง)** $C_{pk} = 1.00$ (ไม่ผ่านเกณฑ์)

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> คำนวณหาค่า $C_{pk}$ จากค่าน้อยที่สุดระหว่างฝั่ง Upper และ Lower:  
> 1. ด้านขอบเขตบน (Upper Capability Index: $C_{pu}$):  
> $$C_{pu} = \frac{USL - \mu}{3\sigma} = \frac{54.0 - 50.8}{3 \times 0.80} = \frac{3.2}{2.4} \approx \mathbf{1.333}$$  
> 2. ด้านขอบเขตล่าง (Lower Capability Index: $C_{pl}$):  
> $$C_{pl} = \frac{\mu - LSL}{3\sigma} = \frac{50.8 - 46.0}{3 \times 0.80} = \frac{4.8}{2.4} = \mathbf{2.000}$$  
> 3. ค่า Process Capability Index ($C_{pk}$):  
> $$C_{pk} = \min(C_{pu}, C_{pl}) = \min(1.333, 2.000) = \mathbf{1.33}$$  
> กระบวนการนี้มีค่า $C_{pk} = 1.33$ พอดีเป๊ะ ซึ่งถือว่า **ผ่านเกณฑ์ขั้นต่ำของการควบคุมคุณภาพระดับอุตสาหกรรม (Industry Standard Capability)** โดยมีอัตราการหลุดสเปกของผลิตภัณฑ์ต่ำกว่า $63 \text{ PPM}$ ในการผลิตเชิงพาณิชย์
