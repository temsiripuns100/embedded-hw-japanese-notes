## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

ในการส่งสัญญาณความเร็วสูงระดับ Multi-Gigabit (เช่น PCIe Gen 5/6, 112G PAM4, USB4) สายส่งไม่ได้มีโครงสร้างหน้าตัดสม่ำเสมอเป็นอุดมคติ ($50 \ \Omega$ คงที่ตลอดแนว) แต่จะต้องพบเจอกับ **จุดสะดุดของอิมพีแดนซ์ (Impedance Discontinuities)** ตลอดเส้นทาง 
ไม่ว่าจะเป็นการเลี้ยวโค้งของลายวงจร (Corner Bends), จุดบัดกรีอุปกรณ์ SMD (Component Pads), รอยคอดใต้ตัวถัง BGA (Neckdowns), และแพดของตัวเก็บประจุ AC Coupling Capacitors

วิศวกรระดับ Senior ต้องเข้าใจพฤติกรรมทางฟิสิกส์ของความไม่ต่อเนื่องเหล่านี้ สามารถอ่านลายเซ็นของรูปคลื่นสะท้อนบนเครื่อง **TDR (Time Domain Reflectometry Signatures)** และคำนวณชดเชยค่าความจุแฝง ($C_{excess}$) หรือความเหนี่ยวนำแฝง ($L_{excess}$) ได้อย่างแม่นยำ

### 1.1 ปรากฏการณ์ทางฟิสิกส์ของการเลี้ยวโค้ง 90 องศา และทฤษฎี Mitered Bend

เมื่อลายวงจรเลี้ยวโค้ง 90 องศาแบบมุมฉาก (Right-Angle Bend) หน้าตัดของทองแดงตรงมุมหักจะขยายตัวขึ้นในแนวทแยงมุมจาก $W$ เป็น $\sqrt{2} \cdot W \approx 1.414 \cdot W$:

```
        Right-Angle Bend (Unmitred)                 Optimal Mitered Bend
       ┌────────────────────────┐                  ┌─────────────┐\
       │                        │                  │             │ \  ◄── 45° Miter Cut
       │    Trace Width W       │                  │ Trace Width │  \     Cut Depth A
       │                        │                  │             │   \
       └───────────┐            │                  └───────────┐ │    \
                   │            │                              │ │     │
                   │ Diagonal   │                              │ │     │
                   │ √2 * W     │                              │ │     │
                   │            │                              │ │     │
```

1. **การก่อตัวของ Excess Capacitance ($\Delta C$):**  
   พื้นที่ผิวทองแดงส่วนเกินบริเวณมุมฉากทำหน้าที่เสมือนตัวเก็บประจุแบบขนานลงสู่ระนาบ Ground ด้านล่าง:

$$\Delta C \approx \frac{\epsilon_0 \epsilon_r A_{excess}}{H} \approx C' \times 0.414 \cdot W$$

2. **การแก้ไขด้วยการบากมุม (Mitering Formula):**  
   เพื่อขจัดเนื้อทองแดงส่วนเกินและรักษาค่า Characteristic Impedance ให้คงที่ตลอดการเลี้ยวโค้ง วิศวกรจะใช้สูตรการบากมุมของ Douville & James:

$$M = 52 + 65 \cdot \exp\left( -1.35 \cdot \frac{W}{H} \right) \quad [\%]$$

โดยที่ $M$ คือเปอร์เซ็นต์การตัดทอนมุมในแนวทแยง (Optimal Miter Fraction: ปกติอยู่ที่ $50\% - 60\%$) หรือในทางปฏิบัติทั่วไป การเลี้ยวด้วย **มุม 45 องศา 2 จังหวะ (Dual 45-degree Bends)** หรือ **เส้นโค้งรัศมีมน (Curved Bends: $R \ge 3W$)** จะช่วยกำจัด Capacitive Dip ได้อย่างสมบูรณ์แบบ

### 1.2 การวิเคราะห์จุดสะดุดของ AC Coupling Capacitor Pads และเทคนิค Reference Plane Voiding

ในมาตรฐานบัสความเร็วสูงยุคใหม่ (PCIe, SATA, SerDes) จำเป็นต้องมีตัวเก็บประจุ AC Coupling ขนาด $0.1 \ \mu\text{F}$ หรือ $0.22 \ \mu\text{F}$ เพื่อกั้นระดับแรงดันไฟตรง (DC Bias Isolation):
- ลายวงจรความเร็วสูงกว้าง $W \approx 4 - 6 \text{ mil}$ ($Z_0 = 50 \ \Omega$) วิ่งมาเชื่อมต่อกับ Pad บัดกรีขนาด 0402 หรือ 0201 ซึ่งมีความกว้าง $W_{pad} \approx 16 - 24 \text{ mil}$
- การขยายขนาดของแผ่นทองแดงอย่างฉับพลันทำให้ค่าความจุแฝงพุ่งขึ้น ส่งผลให้อิมพีแดนซ์ **ดิ่งฮวบลงเหลือ $30 - 38 \ \Omega$** (Capacitive Impedance Valley)

```
        Top Layer (Trace + Cap Pads)
        Trace (50Ω)      Pad (0201/0402)       Capacitor       Pad         Trace (50Ω)
       ──────────────┬──────────────────────┬─────────────┬──────────────┬──────────────
                     │  Z_pad = 32Ω (Dip)   │  Component  │  Z_pad = 32Ω │
       ──────────────┴──────────────────────┴─────────────┴──────────────┴──────────────
        Layer 2 GND Plane (Defected / Cutout Void)
       ══════════════╗                                                   ╔══════════════
                     ║ ◄─────────────── Anti-pad Void ─────────────────► ║
       ══════════════╝                                                   ╚══════════════
        Layer 3 GND Plane (New Reference Plane)
       ─────────────────────────────────────────────────────────────────────────────────
```

**วิธีแก้ปัญหาด้วย Reference Plane Voiding (ฉลุกราวด์ชั้นล่าง):**
- เจาะหน้าต่าง Void บนระนาบ Ground ชั้น L2 ใต้แผ่น Pad โดยตรง เพื่อบังคับให้สนามไฟฟ้าของ Pad ต้องเดินทางทะลุลงไปจับกับระนาบ Ground ชั้น L3 แทน
- การเพิ่มระยะห่าง $H$ จาก $H_{L1-L2}$ เป็น $H_{L1-L3}$ จะช่วยลดค่าความจุไฟฟ้าแฝงลงตามสัดส่วน $C \propto 1/H$ ดึงให้อิมพีแดนซ์บริเวณ Pad ดีดกลับขึ้นมาแมตช์ที่ **$50 \ \Omega$** พอดี

### 1.3 ลายเซ็นบนรูปคลื่น TDR และสมการอินทิกรัลหาค่าพารามิเตอร์แฝง ($L_{excess}, C_{excess}$)

เครื่อง Time Domain Reflectometer (TDR) ส่งสัญญาณขั้นบันได (Step Pulse) ที่มี Rise Time เร็วระดับ $t_r \le 20 \text{ ps}$ เข้าสู่สายส่ง:

```
    Impedance [Ω]
      ▲
   70 ┼                            /\  ◄── Neckdown / Thin Trace (Inductive Peak)
      │                           /  \
   50 ┼─────────\                /    \───────────────────────── Matched Z0 = 50Ω
      │          \              /
   35 ┼           \/ ◄─────────┴─────────────────────────────── Cap Pad / Via (Capacitive Dip)
      └────────────────────────────────────────────────────────► Time [ps]
```

วิศวกรสามารถคำนวณหาค่าความจุแฝง ($C_{excess}$) หรือความเหนี่ยวนำแฝง ($L_{excess}$) ได้อย่างแม่นยำจากพื้นที่ใต้กราฟสะท้อนแรงดัน ($V_{refl}(t)$):

$$C_{excess} = \frac{2}{Z_0} \int_{t_1}^{t_2} \frac{V_{refl}(t)}{V_{step}} \, dt \quad [\text{pF}]$$

$$L_{excess} = 2 \cdot Z_0 \int_{t_1}^{t_2} \frac{V_{refl}(t)}{V_{step}} \, dt \quad [\text{nH}]$$

### 1.4 ปรากฏการณ์คอคอดใต้ BGA (Neckdown Trace) และเกณฑ์ความยาววิกฤต (Critical Neckdown Length)

เมื่อต้องเดินสายส่งสัญญาณลอดผ่านช่องว่างระหว่างลูกบอลของชิป Fine-Pitch BGA (เช่น Pitch $0.8 \text{ mm}$ หรือ $0.65 \text{ mm}$) วิศวกรจำเป็นต้องบีบลายวงจรให้แคบลง (Neckdown) เช่น จาก $W = 5.5 \text{ mil}$ เหลือ $W = 3.2 \text{ mil}$:
- สายที่แคบลงจะมีความจุลดลงและความเหนี่ยวนำสูงขึ้น ส่งผลให้อิมพีแดนซ์พุ่งสูงขึ้นเป็น **$Z_{neck} \approx 62 - 70 \ \Omega$ (Inductive Spike)**

**เกณฑ์ความยาวปลอดภัยทางวิศวกรรม (Rule of Critical Length):**  
ความไม่ต่อเนื่องจะไม่มีผลกระทบต่อสัญญาณดิจิทัล (คลื่นมองไม่เห็นจุดสะดุด) ตราบใดที่เวลาการเดินทางข้ามรอยคอคอด ($t_d$) สั้นกว่าเศษเสี้ยวของขอบเวลาขาขึ้น (Rise Time):

$$l_{neck,max} \le \frac{t_r \times v_p}{10}$$

ตัวอย่าง: สัญญาณ PCIe Gen 4 ($t_r = 30 \text{ ps}$, $v_p = 150 \text{ mm/ns}$):
$$l_{neck,max} \le \frac{0.030 \text{ ns} \times 150 \text{ mm/ns}}{10} = \mathbf{0.45 \text{ mm} \ (17.7 \text{ mil})}$$
หากระยะ Neckdown ยาวเกิน $0.45 \text{ mm}$ จุดคอคอดจะก่อให้เกิดคลื่นสะท้อนขนาดใหญ่และบิดเบือนรูปคลื่นสัญญาณอย่างรุนแรง

## 2. ทริคหน้างาน OJT แบบ Step-by-Step (現場の実践テクニック)

### กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
**ปัญหา:** ลิงก์สื่อสาร 56G PAM4 ระหว่างสวิตช์ ASIC ไปยัง Front-Panel Optical Transceiver ล้มเหลวในการทดสอบ Bit Error Rate (BER พุ่งแตะ $10^{-4}$ สเปกต้องการ $< 10^{-12}$) โดยตรวจพบ TDR Discontinuity ลึกถึง **$37 \ \Omega$** บริเวณตัวเก็บประจุ AC Coupling Capacitors
**สาเหตุที่ตรวจพบ (検図での指摘):**
1. **ใช้แพดขนาด 0402 โดยไม่มีการเจาะกราวด์ใต้แพด:** วิศวกรเลือกใช้ตัวเก็บประจุขนาดใหญ่ 0402 ($1.0 \times 0.5 \text{ mm}$) และมีแผ่น Ground Plane ชั้น L2 อยู่ห่างเพียง $3.5 \text{ mil}$ ใต้แพดโดยตรง
2. **เกิด Multi-reflection ระหว่าง Pad กับขาคอนเนคเตอร์:** สัญญาณสะท้อนไปมาระหว่างหลุม $37 \ \Omega$ ของแพด และลูกบอล BGA ส่งผลให้ Eye Diagram ของ PAM4 ทั้ง 3 ตาปิดสนิท

---

### ขั้นตอนการแก้ปัญหาและปรับแต่ง Discontinuities สไตล์ Senior (検図チェックリスト):
1. **การดาวน์ไซส์อุปกรณ์เป็น 0201 หรือ 01005 สำหรับความถี่สูงพิเศษ:**
   - เปลี่ยนตัวเก็บประจุ AC Coupling จากขนาด 0402 มาเป็น **0201 ($0.6 \times 0.3 \text{ mm}$)** หรือขนาดพิเศษ Ultra-Broadband เพื่อลดพื้นที่ทองแดงของแพดลง $65\%$
2. **การทำ Reference Ground Voiding บน L2:**
   - ทำรอยตัดฉลุรูปสี่เหลี่ยม (Ground Cutout Void) บนระนาบ Ground ชั้น L2 ใต้แพด 0201 โดยมีขนาดขอบ Void กว้างกว่าตัวแพดข้างละ **$3 - 5 \text{ mil}$**
   - ตรวจสอบให้แน่ใจว่าเลเยอร์ L3 ด้านล่างเป็นแผ่น Solid Ground Plane ที่ต่อเนื่อง เพื่อทำหน้าที่เป็นระนาบอ้างอิงสำรอง
3. **การหลีกเลี่ยงการหักมุมฉาก 90 องศา:**
   - ห้ามเดินสายเลี้ยวโค้ง 90 องศาเด็ดขาด ให้ใช้เส้นโค้งมน (Arc Bends) หรือการหักมุม 45 องศาที่มีระยะห่างระหว่างจุดหักเลี้ยวอย่างน้อย **$3 \times W$**
4. **การควบคุมความยาวคอคอด (BGA Escape Neckdown Minimization):**
   - จำกัดความยาวของสายคอดใต้ BGA ให้สั้นที่สุด (ไม่เกิน $1.0 \text{ mm}$) และขยายขนาดสายกลับคืนเป็นขนาดปกติ ($50 \ \Omega$) ทันทีที่พ้นจากกรอบวงแหวนลูกบอลรอบนอกของ BGA

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1 (การคำนวณ Excess Capacitance จาก TDR Integral)
วิศวกรใช้เครื่องวัด TDR ตรวจวัดขั้วต่อ SMA Connector บนบอร์ดทดสอบความเร็วสูงด้วย Step Voltage ขนาด $V_{step} = 200 \text{ mV}$ เข้าสู่สายส่งที่มี Characteristic Impedance $Z_0 = 50.0 \ \Omega$ โดยที่รอยต่อของตัวต่อเกิดความจุแฝงดิ่งลงเป็น Capacitive Dip จากการอินทิเกรตพื้นที่ของคลื่นสะท้อน $\int V_{refl}(t) dt$ ในช่วงเวลาที่เกิดการสะท้อน ได้ผลลัพธ์เป็นค่าลบเท่ากับ $-4.0 \times 10^{-12} \text{ V} \cdot \text{s}$ ($-4.0 \text{ pV}\cdot\text{s}$) ถามว่าค่าความจุไฟฟ้าแฝง ($C_{excess}$) ของขั้วต่อนี้มีค่าเท่ากับข้อใด?

- **ก)** $C_{excess} = 0.80 \text{ pF}$
- **ข)** $C_{excess} = 0.08 \text{ pF} \ (80 \text{ fF})$
- **ค)** $C_{excess} = 1.60 \text{ pF}$
- **ง)** $C_{excess} = 0.04 \text{ pF}$

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ก)**  
> จากสมการการหาค่าความจุแฝงจากพื้นที่อินทิกรัลของ TDR:  
> $$C_{excess} = \frac{2}{Z_0} \times \frac{1}{V_{step}} \times \left| \int V_{refl}(t) dt \right|$$  
> แทนค่าตัวเลขลงในสมการ:  
> $$C_{excess} = \frac{2}{50.0 \ \Omega} \times \frac{4.0 \times 10^{-12} \text{ V}\cdot\text{s}}{0.200 \text{ V}}$$  
> $$C_{excess} = 0.04 \times \left( 2.0 \times 10^{-11} \right) = 0.80 \times 10^{-12} \text{ F} = \mathbf{0.80 \text{ pF}}$$  
> ค่าความจุแฝงขนาด $0.80 \text{ pF}$ ถือเป็นค่าที่สูงมากสำหรับสัญญาณ Multi-Gigabit (ซึ่งยอมรับได้ไม่เกิน $0.1 - 0.2 \text{ pF}$) ค่านี้จะดึงให้อิมพีแดนซ์ดิ่งลงและทำให้เกิดการสูญเสีย Return Loss อย่างรุนแรง

### ข้อที่ 2 (กลไกการปรับจูนอิมพีแดนซ์ด้วย Reference Ground Plane Voiding)
เมื่อทำ Reference Ground Plane Voiding ใต้แพดของตัวเก็บประจุ AC Coupling โดยเจาะเอาแผ่นทองแดงชั้น L2 ออก เพื่อให้แพดลงไปอ้างอิงกับระนาบกราวด์ชั้น L3 เหตุใดค่าอิมพีแดนซ์ของแพดจึงดีดตัวสูงขึ้นจาก $35 \ \Omega$ กลับขึ้นมาเป็น $50 \ \Omega$ ได้ตามกฎทางฟิสิกส์?

- **ก)** เพราะความต้านทานของทองแดงบนชั้น L3 มีค่าสูงกว่าชั้น L2
- **ข)** เพราะระยะห่างระหว่างตัวนำกับระนาบอ้างอิง ($H$) เพิ่มขึ้น ทำให้ค่าความจุไฟฟ้าแฝงต่อหน่วยความยาว ($C'$) ลดลง และความเหนี่ยวนำ ($L'$) เพิ่มขึ้น ส่งผลให้ $Z_0 = \sqrt{L'/C'}$ เพิ่มขึ้น
- **ค)** เพราะสนามแม่เหล็กถูกดูดกลืนหายไปในช่องว่าง Void
- **ง)** เพราะชั้น L3 เคลือบด้วยสารไดอิเล็กทริกที่มีค่า $\epsilon_r$ ต่ำกว่าอากาศ

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> แผ่น Pad ของตัวเก็บประจุมีพื้นที่หน้าตัดขนาดใหญ่ ทำให้ความจุไฟฟ้าแฝง ($C' \propto A/H$) มีค่าสูงลิ่วเมื่ออยู่ชิดกับระนาบกราวด์ L2 ($H$ แคบ)  
> เมื่อทำการฉลุ Void บน L2 ออก:  
> 1. ระยะห่างระหว่าง Pad บน Top Layer ไปยังระนาบ Ground ถัดไป (L3) จะเพิ่มขึ้นเป็น $H_{new} = H_{L1-L2} + H_{L2-L3}$ (เพิ่มขึ้นเป็น $2-3$ เท่า)  
> 2. ค่าความจุไฟฟ้าแฝงจะลดลงอย่างมีนัยสำคัญ ($C' \downarrow$)  
> 3. ลูปของกระแสไหลกลับ (Return Current Loop) มีขนาดใหญ่ขึ้นเล็กน้อย ส่งผลให้ความเหนี่ยวนำแฝงเพิ่มขึ้น ($L' \uparrow$)  
> 4. ตามสมการ $Z_0 = \sqrt{L'/C'}$ การที่ $C'$ ลดลงและ $L'$ เพิ่มขึ้น จะช่วยดึงให้อิมพีแดนซ์บริเวณ Pad ขยับสูงขึ้น ชดเชยจุดสะดุดจนกลายเป็นเส้นตรงเรียบเสมอกับสายส่ง $50 \ \Omega$ หลัก

### ข้อที่ 3 (ผลกระทบของการบีบสายคอด Neckdown ใต้ชิป BGA)
ในการเดินสายสัญญาณนาฬิกา 10 GHz ออกจากชิป BGA วิศวกรจำเป็นต้องคอดความกว้างสายส่งลงเหลือ $W = 3 \text{ mil}$ เพื่อลอดช่องระหว่าง Pad เป็นระยะทางยาว $4.0 \text{ mm}$ หากสัญญาณมี Rise Time $t_r = 25 \text{ ps}$ สัญญาณจะได้รับผลกระทบอย่างไร?

- **ก)** สัญญาณจะสูญเสียเฟสเพียงเล็กน้อยแต่รูปคลื่นสมบูรณ์ดี
- **ข)** เกิดการสะท้อนของคลื่นแบบ Inductive Spike อย่างรุนแรง ($Z_{neck} \approx 65 \ \Omega$) เกิดคลื่นสะท้อนกลับหลายทอด (Ringing) ทำให้ขอบสัญญาณแตกและเกิด Inter-Symbol Interference (ISI)
- **ค)** สัญญาณจะวิ่งเร็วขึ้นจนแซงหน้าสัญญาณอื่นๆ ในบัส
- **ง)** กระแสจะไหลล้นจนทำให้ทองแดงบริเวณคอคอดละลาย

> **เฉลยและบทวิเคราะห์:**  
> **ข้อ ข)**  
> ความยาวปลอดภัยสูงสุดของรอยคอดสำหรับสัญญาณ $t_r = 25 \text{ ps}$ บนบอร์ด FR-4 ($v_p \approx 150 \text{ mm/ns}$) คือ:  
> $$l_{critical} \approx \frac{0.025 \times 150}{10} \approx 0.375 \text{ mm}$$  
> แต่ในกรณีนี้สายคอดยาวถึง $4.0 \text{ mm}$ ซึ่งยาวกว่าความยาววิกฤตถึงกว่า 10 เท่า!  
> คลื่นสัญญาณจะ "มองเห็น" ช่วงคอดนี้เป็นสายส่งขนาดย่อมที่มีอิมพีแดนซ์สูงถึง $\sim 65 \ \Omega$ เกิดการสะท้อนกลับสองจังหวะ (ที่รอยต่อต้นทางและปลายทางของคอคอด) ก่อให้เกิด Inductive Voltage Overshoot และ Ringing แทรกซ้อน ส่งผลให้ Eye Diagram แคบลงและเกิดข้อผิดพลาดในการประมวลผลข้อมูล
