## 1. ทฤษฎีวิศวกรรมเชิงลึก (高度なエンジニアリング理論)

### 1.1 องค์ประกอบของพลังงานสูญเสียใน FPGA (Static vs Dynamic Power)
ในระบบฝังตัวและอุปกรณ์พกพาที่ใช้ FPGA ประสิทธิภาพการใช้พลังงาน (Energy Efficiency) และการระบายความร้อนเป็นตัวแปรชี้ขาดความสำเร็จของผลิตภัณฑ์ พลังงานความร้อนรวมที่เกิดขึ้นในเนื้อซิลิคอนของชิป ($P_{total}$) ประกอบด้วย 2 ส่วนหลักตามสมการฟิสิกส์สารกึ่งตัวนำ:

$$P_{total} = P_{static} + P_{dynamic}$$

```
                FPGA Total Power Dissipation Breakdown
  
   +-------------------------------------------------------------------------+
   |                     Total Power Dissipation P_total                     |
   +------------------------------------+------------------------------------+
   |    P_static (Static / Leakage)     |       P_dynamic (Dynamic Power)    |
   |------------------------------------+------------------------------------|
   | * Subthreshold Leakage I_sub       | * Capacitive Switching Power P_cap |
   | * Gate Oxide Tunneling I_gate      | * Internal Cell Short-Circuit P_sc |
   | * Band-to-Band Tunneling I_btbt    | * Glitch Power (Spurious toggles)  |
   | (ขึ้นกับอุณหภูมิ Junction T_J แบบ Exp)| (ขึ้นกับความถี่ f_clk และ Toggle Rate)|
   +------------------------------------+------------------------------------+
```

#### 1.1.1 พลังงานสถิตและกระแสรั่วไหล (Static Leakage Power: $P_{static}$)
พลังงานสถิตคือพลังงานที่สูญเสียไปตลอดเวลาแม้ว่าชิปจะไม่มีสัญญาณนาฬิกาหรือหยุดทำงานชั่วคราว:

$$P_{static} = V_{DD} \cdot I_{leakage}(T_J)$$

กระแสรั่วไหล $I_{leakage}$ ประกอบด้วย:
1. **Subthreshold Leakage ($I_{sub}$):** กระแสที่แอบไหลระหว่าง Drain และ Source เมื่อทรานซิสเตอร์อยู่ในสถานะปิด ($V_{GS} < V_{th}$) ตามสมการ:
   $$I_{sub} = \mu \cdot C_{ox} \cdot \left(\frac{W}{L}\right) \cdot \left(\frac{k T_J}{q}\right)^2 \cdot \exp\left(\frac{q(V_{GS} - V_{th})}{n k T_J}\right)$$
   *เนื่องจากมีฟังก์ชันเอกซ์โพเนนเชียลของอุณหภูมิ ($T_J$) กระแสรั่วไหลจะเพิ่มขึ้นเป็น 2 เท่าในทุกๆ อุณหภูมิที่เพิ่มขึ้น $15^\circ\text{C} - 20^\circ\text{C}$*
2. **Gate Oxide Tunneling Leakage ($I_{gate}$):** อิเล็กตรอนที่ทะลุผ่านชั้นฉนวน Gate Oxide ที่มีความบางระดับอะตอม
3. **อันตรายของปรากฏการณ์ Thermal Runaway (熱暴走):**
   เมื่อชิปร้อนขึ้น $\to$ กระแสรั่วไหล $I_{leakage}$ พุ่งสูงขึ้น $\to$ ชิปปล่อยความร้อน $P_{static}$ มากขึ้น $\to$ อุณหภูมิ $T_J$ ยิ่งสูงขึ้นไปอีก หากระบบระบายความร้อน (Heatsink) ไม่สามารถดึงความร้อนออกได้ทัน อุณหภูมิจะพุ่งทะลุจุดวิกฤตจนซิลิคอนละลายเสียหายถาวร

### 1.2 พลังงานพลวัต (Dynamic Switching Power: $P_{dynamic}$)
พลังงานพลวัตเกิดขึ้นเมื่อเกตตรรกะและเส้นทางเดินสายทองแดงมีการสลับสถานะไปมา ($0 \to 1$ และ $1 \to 0$):

$$P_{dynamic} = P_{switching} + P_{short\_circuit} + P_{glitch}$$

สมการการประจุและคายประจุของตัวเก็บประจุแฝงบนเส้นทองแดง (Capacitive Switching Power):

$$P_{switching} = \sum_{i} \alpha_i \cdot C_i \cdot V_{DD}^2 \cdot f_{clk}$$

โดยที่:
* $V_{DD}$ คือ แรงดันไฟเลี้ยงแกนหลัก (Core Voltage, $V_{core}$) สังเกตว่ากำลังไฟฟ้า **แปรผันตรงกับกำลังสองของแรงดัน ($V_{DD}^2$)** การลดแรงดันไฟเลี้ยงจึงเป็นวิธีประหยัดพลังงานที่มีประสิทธิภาพสูงสุด
* $f_{clk}$ คือ ความถี่ของสัญญาณนาฬิการะบบ ($\text{Hz}$)
* $C_i$ คือ ค่าความจุไฟฟ้าแฝงรวมของเส้นทองแดงและเกตปลายทางของโหนด $i$
* $\alpha_i$ คือ **Toggle Rate (อัตราการเปลี่ยนระดับสถานะ):** สัดส่วนความน่าจะเป็นที่โหนดนั้นจะเปลี่ยนสถานะใน 1 คาบของสัญญาณนาฬิกา (เช่น สัญญาณ Clock มี $\alpha = 100\%$ หรือ 1.0, สัญญาณข้อมูลทั่วไปมี $\alpha \approx 10\% - 20\%$)

#### พลังงานสูญเสียจากสัญญาณรบกวนชั่วขณะ (Glitch Power - 30% ถึง 50% ของ Dynamic Power)
ในวงจรลอจิกคอมบิเนชันที่มีความลึกมาก (เช่น Ripple Carry Adder, Parity Tree หรือตัวคูณขนาดใหญ่ที่ไม่ได้ทำ Pipeline) สัญญาณอินพุตแต่ละขาจะเดินทางมาถึงไม่พร้อมกัน ทำให้เอาต์พุตของ LUT สลับสถานะกระเพื่อมไปมาหลายครั้ง (Spurious Transitions / Glitches) ก่อนที่จะนิ่งสู่ค่าจริง
การกระเพื่อมของแรงดันที่ไร้ประโยชน์นี้สูญเสียพลังงานในการประจุ/คายประจุเส้นทองแดง คิดเป็นสัดส่วนสูงถึง **$30\% - 50\%$ ของ Dynamic Power ทั้งหมดของชิป!**

### 1.3 กลยุทธ์การลดการใช้พลังงานในระดับสถาปัตยกรรม (Architectural Power Optimization)

```
                     Hierarchical Power Reduction Strategy
  
  [ ระดับระบบ & แรงดัน ]     -> ลด VCCINT (Voltage Scaling / Low-Voltage Bins เช่น 0.72V)
  [ ระดับสัญญาณนาฬิกา ]    -> โครงข่าย Clock Gating อัตโนมัติ (BUFGCE / Regional Gate)
  [ ระดับเมมโมรี & DSP ]   -> เปิด Sleep Mode ใน BRAM / ปิด Cascade เมื่อไม่ได้อ่าน
  [ ระดับ RTL ลอจิก ]       -> ทำ Pipelining เพื่อตัด Glitch / ลด Toggle Rate ของบัส
```

#### 1.3.1 การควบคุมสัญญาณนาฬิกา (Fine-Grained Clock Gating)
การปิดสัญญาณนาฬิกาไปยัง Flip-Flop กลุ่มที่ไม่มีการใช้งาน (Idle Logic) ผ่านทางบัฟเฟอร์สัญญาณนาฬิกาเฉพาะทาง (`BUFGCE`) จะช่วยตัด $P_{dynamic}$ ของทั้งทรีนาฬิกาลงสู่ศูนย์

```verilog
// Professional Clock Gating Implementation using Dedicated FPGA Primitive
BUFGCE #(
    .SIM_DEVICE("ULTRASCALE_PLUS")
) u_bufgce_dsp_clk (
    .I  (sys_clk_raw),       // Un-gated Source Clock
    .CE (dsp_engine_active), // Clock Enable Control Signal
    .O  (dsp_clk_gated)      // Gated Clock to DSP Core Array
);
```

#### 1.3.2 การลดขนาดการแกว่งของข้อมูลบัส (Bus Invert Coding: DBI)
เมื่อต้องส่งบัสข้อมูลขนาดกว้างข้ามชิป (เช่น อินเทอร์เฟซหน่วยความจำ DDR) หากข้อมูลคำถัดไปมีจำนวนบิตที่ต้องสลับสถานะเกินกว่าครึ่งหนึ่ง ($> 50\%$) วงจรจะส่งบิตกลับขั้ว (Inverted Data) พร้อมยกสัญญาณแฟล็ก `DBI = 1` เพื่อจำกัดจำนวนการสลับสถานะไม่ให้เกิน $50\%$ เสมอ ช่วยตัดกระแส $dI/dt$ และลด Dynamic Power ลงอย่างมหาศาล

### 1.4 การคำนวณอุณหภูมิรอยต่อ (Junction Temperature: $T_J$) และเครือข่ายความร้อน
ความร้อนที่เกิดขึ้นในชิปต้องถูกระบายออกสู่สิ่งแวดล้อมภายนอกผ่านเครือข่ายความต้านทานความร้อน (Thermal Resistance Network):

$$T_J = T_A + P_{total} \cdot \theta_{JA}$$

$$\theta_{JA} = \theta_{JC} + \theta_{CS} + \theta_{SA}$$

```
                       Thermal Network Equivalent Circuit
         +--------------------------------------------------------+
         | Silicon Die (Junction)  T_J = T_A + P * theta_JA       |
         +---------------------------+----------------------------+
                                     |
                                     |  theta_JC (Junction-to-Case: 0.2 - 0.8 °C/W)
                                     v
         +--------------------------------------------------------+
         | Package Lid / Case (T_C)                               |
         +---------------------------+----------------------------+
                                     |
                                     |  theta_CS (TIM / Gap Pad: 0.1 - 0.5 °C/W)
                                     v
         +--------------------------------------------------------+
         | Heat Sink (T_S)                                        |
         +---------------------------+----------------------------+
                                     |
                                     |  theta_SA (Sink-to-Ambient: Natural vs Airflow)
                                     v
         +--------------------------------------------------------+
         | Ambient Air (T_A: e.g., 55°C Industrial / 85°C Auto)    |
         +--------------------------------------------------------+
```

* **$T_J$ (Junction Temperature):** อุณหภูมิที่รอยต่อสารกึ่งตัวนำภายในชิป (พิกัดสูงสุดมาตรฐาน: Commercial $= 85^\circ\text{C}$, Industrial $= 100^\circ\text{C}$, Automotive Grade 1 $= 125^\circ\text{C}$)
* **$\theta_{JA}$:** ความต้านทานความร้อนรวมจากรอยต่อสู่อากาศแวดล้อม ($^\circ\text{C/W}$)

### 2.1 กรณีศึกษาความล้มเหลวหน้างาน (失敗事例: Shippai Jirei)
* **บริบท:** กล่องประมวลผลการบินอัตโนมัติของโดรนสำรวจการเกษตร (Avionics Flight Computer) ใช้ชิป Xilinx Zynq UltraScale+ MPSoC ตัวเครื่องปิดผนึกกันน้ำตามมาตรฐาน IP67 ไม่มีพัดลมระบายความร้อน (Fanless Enclosure)
* **อาการเสียหน้างาน:** ระหว่างการบินทดสอบจริง โดรนสามารถบินขึ้นและทำงานได้ปกติ แต่หลังจากผ่านไปเพียง **3 นาที 40 วินาที** ชิป FPGA เกิดอาการดับวูบและรีบูตตัวเองกะทันหัน ส่งผลให้โดรนตกกระแทกพื้น
* **การตรวจบันทึกข้อมูล (Black Box Log):** ตรวจสอบไฟล์ Telemetry Log ก่อนระบบดับ พบข้อความเตือนจากชิปมอนิเตอร์ฮาร์ดแวร์ภายใน (System Monitor / SYSMON):

### 2.3 มาตรการแก้ไขและกฎทองการออกแบบ Low-Power FPGA
1. **ติดตั้ง Clock Gating ผ่าน BUFGCE:**
   * สั่งตัดสัญญาณนาฬิกาของวงจร FFT ทันทีที่ไม่มีข้อมูลเข้ามาประมวลผล
2. **ประเมินพลังงานด้วย Gate-Level Activity Simulation (SAIF/VCD):**
   * รัน UVM Simulation พร้อมบันทึกไฟล์สถิติการสลับสถานะจริง (`.saif`) แล้วป้อนกลับเข้าเครื่องมือ Vivado Report Power เพื่อให้ได้ค่ากำลังงานที่แม่นยำระดับ $98\%$
3. **เปิดออปชัน Intelligent Power Optimization ใน Synthesis/Implementation:**
   ```tcl
   # เปิดออปชันลดพลังงานอัตโนมัติใน Vivado
   set_property STEPS.OPT_DESIGN.ARGS.IS_POWER_OPT true [get_runs impl_1]
   set_property STEPS.POWER_OPT_DESIGN.IS_ENABLED true [get_runs impl_1]
   ```
4. **ผลลัพธ์หลังแก้ไข:** กำลังไฟฟ้ารวมของระบบลดลงจาก $18.2\text{W}$ เหลือเพียง **$7.8\text{W}$ (ลดลง $57\%$!)** อุณหภูมิ Junction ทำงานสูงสุดไม่เกิน **$82^\circ\text{C}$** บินทดสอบต่อเนื่องได้ตลอดอายุแบตเตอรี่

## 3. คำศัพท์และประโยคภาษาญี่ปุ่นสำหรับตรวจแบบ (検図 - Kenzu)

## 4. ควิซวิเคราะห์ปัญหาระดับวิศวกรอาวุโส (上級技術クイズ)

### ข้อที่ 1: การคำนวณการลดทอนของ Dynamic Power จากการทำ Voltage Scaling
ในชิปประมวลผล UltraScale+ FPGA กำลังไฟฟ้าพลวัต (Dynamic Switching Power) ส่วนใหญ่ถูกใช้ไปบนรางจ่ายไฟแกนหลัก $VCCINT$

สมมติว่าในระบบเดิม ชิปทำงานที่ระดับแรงดันไฟมาตรฐาน:
* $V_{DD1} = 0.85\text{ V}$ โดยกินกำลังไฟฟ้าพลวัต $P_{dyn1} = 12.00\text{ W}$

หากทีมสถาปัตยกรรมตัดสินใจเลือกใช้ชิปตัวเลือกพิเศษ Low-Voltage Option (ชิปรหัส `-1L` หรือ `-1LV`) ซึ่งผ่านการคัดเกรดให้สามารถทำงานที่ความถี่เดียวกันได้อย่างเสถียรที่แรงดันไฟเลี้ยงลดลงเหลือ:
* $V_{DD2} = 0.72\text{ V}$ (โดยที่ความถี่ $f_{clk}$ และปริมาณการสลับบิต $\alpha$ คงที่เดิมทุกประการ)

จงคำนวณหากำลังไฟฟ้าพลวัตใหม่ ($P_{dyn2}$) และวิเคราะห์ว่า **กำลังไฟฟ้าพลวัตลดลงไปกี่เปอร์เซ็นต์ (%)**?

a) ลดลงประมาณ $15.29\%$  
b) ลดลงประมาณ $28.24\%$  
c) ลดลงประมาณ $38.50\%$  
d) ลดลงประมาณ $42.10\%$  

---

#### เฉลยและบทวิเคราะห์เชิงลึกข้อที่ 1
**คำตอบที่ถูกต้องคือ: b) ลดลงประมาณ $28.24\%$**

**ขั้นตอนการคำนวณทางคณิตศาสตร์:**
1. ทบทวนสมการความสัมพันธ์ของ Dynamic Switching Power:
   $$P_{dyn} = \alpha \cdot C_L \cdot V_{DD}^2 \cdot f_{clk} \implies P_{dyn} \propto V_{DD}^2$$
2. คำนวณอัตราส่วนกำลังไฟฟ้าใหม่เทียบกับกำลังไฟฟ้าเดิม:
   $$\frac{P_{dyn2}}{P_{dyn1}} = \left(\frac{V_{DD2}}{V_{DD1}}\right)^2 = \left(\frac{0.72\text{ V}}{0.85\text{ V}}\right)^2 = (0.8470588)^2 \approx 0.717508$$
3. คำนวณกำลังไฟฟ้าใหม่ ($P_{dyn2}$):
   $$P_{dyn2} = 12.00\text{ W} \times 0.717508 \approx 8.61\text{ W}$$
4. คำนวณสัดส่วนเปอร์เซ็นต์ที่ประหยัดได้:
   $$\% \text{ Power Reduction} = (1 - 0.717508) \times 100\% \approx 28.249\% \approx 28.24\%$$
5. **ข้อสรุปเชิงวิศวกรรม:**
   * การลดแรงดันไฟเลี้ยงลงเพียง $15.3\%$ ($0.85\text{V} \to 0.72\text{V}$) ส่งผลให้ประหยัดพลังงานพลวัตได้ถึง **$28.24\%$ (ลดลงถึง $3.39\text{W}$)** เนื่องจากความสัมพันธ์ที่เป็นกำลังสอง ($V^2$) ซึ่งช่วยปลดเปลื้องภาระของระบบระบายความร้อนได้อย่างมหาศาล

### ข้อที่ 2: การคำนวณเสถียรภาพความร้อนและอุณหภูมิรอยต่อ Junction Temperature ($T_J$)
พิจารณาโมดูล FPGA บนระบบดาวเทียมขนาดเล็ก (CubeSat):
* กำลังงานสูญเสียรวมของชิป: $P_{total} = 6.50\text{ W}$
* อุณหภูมิแวดล้อมสูงสุดภายในโครงสร้างดาวเทียม: $T_A = +55.0^\circ\text{C}$
* ความต้านทานความร้อนจากรอยต่อไปยังหลังแพ็กเกจ (Junction-to-Case): $\theta_{JC} = 0.40^\circ\text{C/W}$
* ความต้านทานความร้อนของแผ่นตัวกลางนำความร้อน (TIM Pad): $\theta_{CS} = 0.60^\circ\text{C/W}$
* ความต้านทานความร้อนของโครงสร้างระบายความร้อนสู่อากาศ (Case/Sink-to-Ambient): $\theta_{SA} = 5.50^\circ\text{C/W}$

หากพิกัดอุณหภูมิสูงสุดที่ยอมรับได้ตามมาตรฐานอวกาศ (Derated Maximum Junction Temperature) คือ $T_{J\_max} = 100.0^\circ\text{C}$ 

จงคำนวณหาค่า **Junction Temperature ($T_J$)** และวิเคราะห์ว่าระบบนี้ **มี Thermal Margin เหลืออยู่กี่องศาเซลเซียส ($^\circ\text{C}$)**?

a) $T_J = 97.25^\circ\text{C}$, $\text{Margin} = +2.75^\circ\text{C}$ (ผ่านเกณฑ์แบบปลอดภัย)  
b) $T_J = 105.50^\circ\text{C}$, $\text{Margin} = -5.50^\circ\text{C}$ (ความร้อนเกินพิกัด ไม่ผ่านเกณฑ์)  
c) $T_J = 90.75^\circ\text{C}$, $\text{Margin} = +9.25^\circ\text{C}$ (ผ่านเกณฑ์)  
d) $T_J = 84.00^\circ\text{C}$, $\text{Margin} = +16.00^\circ\text{C}$ (ผ่านเกณฑ์)  

---

#### เฉลยและบทวิเคราะห์เชิงลึกข้อที่ 2
**คำตอบที่ถูกต้องคือ: a) $T_J = 97.25^\circ\text{C}$, $\text{Margin} = +2.75^\circ\text{C}$ (ผ่านเกณฑ์แบบปลอดภัย)**

**ขั้นตอนการคำนวณทางคณิตศาสตร์:**
1. คำนวณความต้านทานความร้อนรวมจากรอยต่อสู่อากาศภายนอก ($\theta_{JA}$):
   $$\theta_{JA} = \theta_{JC} + \theta_{CS} + \theta_{SA} = 0.40^\circ\text{C/W} + 0.60^\circ\text{C/W} + 5.50^\circ\text{C/W} = 6.50^\circ\text{C/W}$$
2. คำนวณอุณหภูมิที่เพิ่มสูงขึ้นจากความร้อนภายใน ($\Delta T$):
   $$\Delta T = P_{total} \times \theta_{JA} = 6.50\text{ W} \times 6.50^\circ\text{C/W} = 42.25^\circ\text{C}$$
3. คำนวณอุณหภูมิรอยต่อจริง ($T_J$):
   $$T_J = T_A + \Delta T = 55.0^\circ\text{C} + 42.25^\circ\text{C} = 97.25^\circ\text{C}$$
4. คำนวณ Thermal Design Margin:
   $$\text{Margin} = T_{J\_max} - T_J = 100.0^\circ\text{C} - 97.25^\circ\text{C} = +2.75^\circ\text{C}$$
5. **การประเมินผลระดับ Senior:**
   แม้ว่าระบบจะผ่านเกณฑ์ในทางทฤษฎี ($+2.75^\circ\text{C} > 0$) แต่มาร์จินมีความแคบมาก หากเกิดกรณีผิวสัมผัสของ TIM เสื่อมสภาพตามกาลเวลา อุณหภูมิจะเสี่ยงต่อการทะลุ $100^\circ\text{C}$ ทันที วิศวกรจึงควรขยายขนาดพื้นที่แผ่นระบายความร้อนเพื่อดึงค่า $\theta_{SA}$ ลงมาให้ต่ำกว่า $4.5^\circ\text{C/W}$

### ข้อที่ 3: ปรากฏการณ์ Glitch Power ในลอจิกคอมบิเนชันและการทำ Pipelining
เหตุใดการแทรก Register ขั้นกลาง (Pipelining) ในวงจรคณิตศาสตร์ที่มีลอจิกลึก (Deep Logic Levels เช่น 64-bit Adder หรือ Hamming Code Generator) จึงสามารถ **"ลดการใช้พลังงานพลวัต (Dynamic Power) ของระบบลงได้"** ทั้งๆ ที่การเพิ่มจำนวน Flip-Flop มักทำให้ปริมาณ Clock Tree Capacitance เพิ่มขึ้น?

a) เพราะ Flip-Flop ที่เพิ่มเข้ามาจะทำหน้าที่เป็นฉนวนกันความร้อนให้กับซิลิคอน  
b) เพราะการทำ Pipelining ช่วยตัดวงจรความล่าช้าที่ไม่เท่ากันของสัญญาณอินพุต (Unequal Path Delays) ทำให้ขจัดสัญญาณรบกวนกระเพื่อมชั่วขณะ (Spurious Glitches) ของเกตตรรกะในแต่ละชั้นทิ้งไป พลังงานที่ประหยัดได้จากการกำจัด Glitch จึงสูงกว่าพลังงานที่เสียไปในการขับ Register เพิ่มเติม  
c) เพราะโปรแกรม Vivado จะตัดขนาดแรงดันไฟเลี้ยงลงโดยอัตโนมัติเมื่อตรวจพบ Pipeline Register  
d) เพราะ Flip-Flop ใช้กำลังไฟฟ้าเฉพาะในจังหวะรีเซ็ตเท่านั้น

#### เฉลยและบทวิเคราะห์เชิงลึกข้อที่ 3
**คำตอบที่ถูกต้องคือ: b) เพราะการทำ Pipelining ช่วยตัดวงจรความล่าช้าที่ไม่เท่ากันของสัญญาณอินพุต (Unequal Path Delays) ทำให้ขจัดสัญญาณรบกวนกระเพื่อมชั่วขณะ (Spurious Glitches) ของเกตตรรกะในแต่ละชั้นทิ้งไป พลังงานที่ประหยัดได้จากการกำจัด Glitch จึงสูงกว่าพลังงานที่เสียไปในการขับ Register เพิ่มเติม**

**บทวิเคราะห์เชิงลึกระดับสถาปัตยกรรม:**
* ในวงจรที่ไม่มีการทำ Pipeline (Unpipelined Deep Logic):
  * สัญญาณขาเข้าผ่านเกตตรรกะหลายชั้น (เช่น 8 ระดับของ LUT)
  * เนื่องจากสัญญาณแต่ละสายมีความล่าช้าในการเดินทางไม่เท่ากัน โหนดภายในจะสลับสถานะ $0 \to 1 \to 0 \to 1$ รัวๆ เฉลี่ย 3 ถึง 7 ครั้งใน 1 ไซเคิล ก่อนที่จะตกตะกอนนิ่งสู่ค่าผลลัพธ์สุดท้าย
  * ทุกๆ ครั้งที่มีการสลับสถานะ ประจุไฟฟ้าจะถูกดึงมาชาร์จความจุแฝงของสายทองแดงแล้วปล่อยทิ้งลงกราวด์ ก่อให้เกิด Glitch Power สิ้นเปลืองพลังงานมหาศาล
* เมื่อทำการแทรก **Pipeline Register**:

  * ความลึกของลอจิกลดลงเหลือเพียง 1 หรือ 2 ระดับ ทำให้โอกาสที่สัญญาณจะแข่งขันกัน (Race Condition) หมดไป โหนดต่างๆ จึงสลับสถานะเพียง **1 ครั้งต่อไซเคิล (Zero Glitch)**
