# 2.1 差動信号（LVDS/USB）の基礎と等長配線 (พื้นฐานสัญญาณส่วนต่างและการเดินสายแบบ Length Matching)

## 📖 ทฤษฎี (Theory - Engineering Perspective)
**差動信号 (Differential Signaling)** เช่น LVDS, USB, PCIe, HDMI ทำงานโดยการส่งสัญญาณที่มีเฟสตรงข้ามกันผ่านสายไฟ 2 เส้น (D+ และ D- หรือ P และ N) เครื่องรับ (Receiver) จะทำการลบแรงดันของทั้งสองเส้นเพื่ออ่านข้อมูล วิธีนี้ช่วยหักล้างสัญญาณรบกวนที่เข้ามาพร้อมกันทั้งสองสาย (Common-mode Noise) ได้อย่างหมดจด

**等長配線 (Length Matching)** เมื่อเราส่งข้อมูลความเร็วสูง สัญญาณทั้งเส้น P และ N ต้องเดินทางไปถึงปลายทาง "พร้อมกัน" พอดี หากสายเส้นใดเส้นหนึ่งยาวกว่า จะทำให้เกิด Time Skew (ความเหลื่อมล้ำทางเวลา) ส่งผลให้หักล้าง Noise ได้ไม่หมด และ Eye Diagram ปิด

## 💡 ทริคหน้างาน (OJT Tricks)
- **แก้ปัญหาที่ต้นเหตุ:** เมื่อเดินลายปริ้นท์เลี้ยวโค้ง สายด้านนอกจะยาวกว่าด้านในเสมอ ทริคคือให้ทำ Length Matching แบบยึกยือ (Serpentine/Meander) **ใกล้กับจุดที่เกิดความยาวต่างกันมากที่สุด** (เช่น บริเวณหลังโค้ง) อย่าไปรอชดเชยความยาวรวมที่ปลายทางฝั่งเดียว เพราะมันไม่ช่วยแก้ปัญหา Phase Mismatch ตลอดเส้นทาง
- **Via มีผลกับเวลา (Delay):** อย่าดูแค่ความยาวรวม 2D บนหน้าจอ CAD! การเจาะ Via ลงไปชั้นล่างก็เพิ่มระยะทางในแกน Z (Thickness) และเพิ่ม Delay เช่นกัน

## 🗣️ คำศัพท์และประโยคภาษาญี่ปุ่น
- **差動信号 (Sadō Shingō):** Differential Signal (สัญญาณส่วนต่าง)
- **等長配線 (Tōchō Haisen):** Length Matching (การเดินสายให้ยาวเท่ากัน)
- **蛇行配線 (Dakō Haisen):** Serpentine Routing / Meander (การเดินสายแบบเลื้อยยึกยือ)
- **同相ノイズ (Dōsō Noizu):** Common-mode Noise
- **配線長 (Haisenchō):** Trace Length

**ประโยคที่ใช้บ่อย:**
> 「LVDSのPとNの配線長に差があると、同相ノイズが発生するため、等長配線を徹底してください。」
> *(LVDS no P to N no haisenchō ni sa ga aru to, dōsō noizu ga hassei suru tame, tōchō haisen o tettei shite kudasai.)*
> "หากความยาวสาย P และ N ของ LVDS มีความแตกต่างกัน จะก่อให้เกิด Common-mode Noise ดังนั้นขอให้เคร่งครัดเรื่องการทำ Length Matching ด้วยครับ/ค่ะ"
