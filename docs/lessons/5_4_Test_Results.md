# 5.4 測定値、基準、合否判定の表現 (คำศัพท์ในตารางทดสอบ: ค่าที่วัด, เกณฑ์, ผลการประเมิน)

## 📖 ทฤษฎี (Theory - Engineering Perspective)
เมื่อถึงขั้นตอนการทดสอบบอร์ด (Board Bring-up / Evaluation) วิศวกรจะต้องเขียนเอกสารสรุปผลการทดสอบ (Test Report) ซึ่งตารางสรุปผลมักจะประกอบด้วยคอลัมน์สำคัญ 3 อย่าง:
1. **基準 / 規格 (Kijun / Kikaku - Criteria/Standard):** สเปคหรือเกณฑ์ที่ตั้งไว้ (เช่น $3.3V \pm 5\%$)
2. **測定値 (Sokuteichi - Measured Value):** ค่าจริงที่วัดได้ด้วยเครื่องมือ (เช่น $3.28V$)
3. **合否 (Gōhi - Pass/Fail):** ผลการประเมิน (เช่น OK / NG)

## 💡 ทริคหน้างาน (OJT Tricks)
- **อย่าเขียนแค่ "OK" ลงใน Report:** นี่คือข้อห้ามเด็ดขาดของวิศวกรญี่ปุ่น! ถ้าช่องผลลัพธ์คุณติ๊กแค่ OK หรือใส่สัญลักษณ์วงกลม (⭕) โดยไม่มีตัวเลขกำกับ อนาคตถ้าบอร์ดมีปัญหา เราจะไม่รู้เลยว่าคำว่า OK ตอนนั้นมันคือ $3.31V$ (เพอร์เฟกต์) หรือ $3.15V$ (คาบเส้น) ทริคคือต้องกรอก **"ค่าตัวเลขที่วัดได้จริง"** ลงไปเสมอ
- **จด Serial Number เครื่องมือวัดด้วย:** เครื่องมือวัดแต่ละตัวมีความคลาดเคลื่อน (Calibration offset) ไม่เท่ากัน การจดรหัสเครื่องมือลงใน Test Report จะช่วยให้ตามสืบได้ง่ายขึ้นเมื่อค่าที่วัดได้ดูแปลกๆ

## 🗣️ คำศัพท์และประโยคภาษาญี่ปุ่น
- **測定値 (Sokuteichi):** Measured Value (ค่าที่วัดได้)
- **基準 / 規格 (Kijun / Kikaku):** Criteria / Spec (เกณฑ์ / มาตรฐาน)
- **合否 (Gōhi):** Pass/Fail (การผ่าน/ไม่ผ่าน)
- **合格 (Gōkaku):** Pass (OK / ⭕)
- **不合格 (Fugōkaku):** Fail (NG / ❌)
- **閾値 (Shikiichi):** Threshold (จุดตัด / ค่าเกณฑ์)

**ประโยคที่ใช้บ่อย:**
> 「測定値が規格の閾値を下回ったため、不合格（NG）と判定しました。」
> *(Sokuteichi ga kikaku no shikiichi o shitamawatta tame, fugōkaku (Enu-Jī) to hantei shimashita.)*
> "เนื่องจากค่าที่วัดได้มีค่าต่ำกว่าเกณฑ์ของมาตรฐาน จึงตัดสินให้ผลเป็น ไม่ผ่าน (NG) ครับ/ค่ะ"

## 📝 ควิซทดสอบ (Quiz)
**คำถาม:** ในตาราง Test Report กำหนดสเปคของสัญญาณ Clock ไว้ว่า Jitter ต้องน้อยกว่า 50ps (Picoseconds) หากคุณวัดได้ 48ps คุณควรบันทึกผลลงในตารางว่าอย่างไรให้เป็นมืออาชีพที่สุดตามสไตล์วิศวกรญี่ปุ่น? (ระหว่างเขียน "OK" กับเขียน "48ps (OK)")
