# 2.6 リターンパス（GNDリターン）とスリット跨ぎ (เส้นทางไหลกลับของกระแส GND และข้อห้ามในการเดินข้ามร่อง)

## 📖 ทฤษฎี (Theory - Engineering Perspective)
**リターンパス (Return Path):** กระแสไฟฟ้าต้องไหลครบวงจรเสมอ สัญญาณความเร็วสูงที่วิ่งไปในสาย จะต้องมีเส้นทางไหลกลับ (Return Current) ซึ่งในความถี่สูง กระแสไหลกลับจะเลือก "เส้นทางที่มีอิมพีแดนซ์ต่ำที่สุด" ซึ่งก็คือ **"ระนาบทองแดง (GND/Power Plane) ที่อยู่ใต้ลายปริ้นท์นั้นโดยตรง"**
**スリット跨ぎ (Split Plane Crossing):** หากเราเดินลายเส้นสัญญาณความเร็วสูงข้าม "รอยแยก (Split/Gap)" บนระนาบอ้างอิง กระแสไหลกลับจะไม่สามารถวิ่งใต้เส้นสัญญาณได้ มันจะต้องวิ่งอ้อมรอยแยกนั้น ส่งผลให้ Loop Area กว้างขึ้นอย่างมหาศาล ทำให้เกิด 2 หายนะ:
1. การเหนี่ยวนำเพิ่มขึ้น ทำให้สัญญาณเกิด Ringing / Slew Rate แย่ลง
2. Loop Area ที่ใหญ่ขึ้นจะทำหน้าที่เป็น "เสาอากาศ" แผ่สัญญาณรบกวน (EMI) ออกไปรบกวนวงจรอื่น

## 💡 ทริคหน้างาน (OJT Tricks)
- **กฎเหล็ก "ห้ามข้ามร่อง":** ก่อนสั่งผลิต PCB ให้เปิด Layer ชั้นสัญญาณ (Top/Bottom) ซ้อนทับกับชั้น GND/Power Plane (Inner) แล้วมองหาว่ามีเส้นไหนวิ่งตัดรอยแหว่งหรือช่องว่างของ Plane หรือไม่ ถ้ามี... ให้แก้ทันที!
- **การใช้ Stitching Capacitor:** เมื่อเส้นสัญญาณต้องเปลี่ยนชั้น (ทะลุ Via จาก Top ไป Bottom) และระนาบอ้างอิงเปลี่ยนจาก GND เป็น Power กระแสกลับจะกระโดดข้ามชั้นไม่ได้ ทริคคือให้ใส่ตัวเก็บประจุ (Stitching Cap เช่น 0.1uF) ไว้ใกล้ๆ Via นั้น เพื่อให้ความถี่สูงกระโดดข้าม Plane ผ่าน Capacitor ได้ครบวงจร

## 🗣️ คำศัพท์และประโยคภาษาญี่ปุ่น
- **リターンパス (Ritānpasu):** Return Path (เส้นทางไหลกลับของกระแส)
- **スリット跨ぎ (Suritto Matagi):** Crossing a split / Gap routing (การเดินเส้นสัญญาณข้ามรอยแยก)
- **基準層 (Kijunsō):** Reference Plane (ระนาบอ้างอิง)
- **ループ面積 (Rūpu Menseki):** Loop Area (พื้นที่ลูปของวงจร)
- **分断 (Bundan):** Separation / Severance (การถูกตัดขาด/แบ่งแยก)

**ประโยคที่ใช้บ่อย:**
> 「高速信号がGND層のスリットを跨いでいるため、リターンパスが分断され、EMIが悪化します。」
> *(Kōsoku shingō ga Gurando-sō no suritto o mataide iru tame, ritānpasu ga bundan sare, EMI ga akka shimasu.)*
> "เนื่องจากสัญญาณความเร็วสูงเดินข้ามรอยแยกของชั้น GND ทำให้เส้นทางไหลกลับ (Return path) ถูกตัดขาด และจะทำให้ค่า EMI แย่ลงครับ/ค่ะ"

## 📝 ควิซทดสอบ (Quiz)
**คำถาม:** เมื่อเส้นสัญญาณความเร็วสูงเดินจากชั้น Top (มีชั้น GND เป็น Plane อ้างอิงอยู่ชั้น 2) มุด Via ลงไปยังชั้น Bottom (มีชั้น 3V3 Power เป็น Plane อ้างอิงอยู่ชั้น 3) คุณควรใส่อุปกรณ์ชนิดใดไว้ใกล้ๆ กับ Via นั้นเพื่อรักษาความต่อเนื่องของ Return Path สำหรับสัญญาณความถี่สูง?
