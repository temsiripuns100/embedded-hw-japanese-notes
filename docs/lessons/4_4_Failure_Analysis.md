# 4.4 不具合解析（Failure Analysis）の進め方 (สเต็ปการวิเคราะห์หาสาเหตุของปัญหาบอร์ดพัง)

## 📖 ทฤษฎี (Theory - Engineering Perspective)
**不具合解析 (Failure Analysis - FA)** คือกระบวนการสืบสวนหา "คนร้าย" เมื่อบอร์ดพังหรือทำงานผิดปกติ สเต็ปมาตรฐานของ FA ที่วิศวกรญี่ปุ่นใช้คือ:
1. **再現確認 (Replication):** พยายามทำให้อาการเสียเกิดขึ้นอีกครั้งให้ได้ เพื่อยืนยันเงื่อนไขการเกิดปัญหา
2. **現象の切り分け (Isolation):** ตัดวงจรหรือแยกส่วนการทำงานออกทีละบล็อก เพื่อตีกรอบให้แคบลงว่าปัญหาอยู่ที่ส่วนไหน
3. **データ計測 (Measurement):** ใช้เครื่องมือ (Oscilloscope, Multimeter, Logic Analyzer) วัดค่าต่างๆ ในบล็อกที่น่าสงสัย
4. **原因特定 (Root Cause Identification):** สรุปสาเหตุที่แท้จริง

## 💡 ทริคหน้างาน (OJT Tricks)
- **A-B-A Swap (Cross-Swapping):** ทริคขั้นเทพเวลาสงสัยว่า IC ตัวนี้เสียหรือเปล่า? ให้เอาบอร์ดดี (A) กับบอร์ดเสีย (B) มา 
  - ถอด IC จากบอร์ด B ไปใส่บอร์ด A -> ถ้าบอร์ด A เสียตาม แปลว่า **IC เสีย**
  - เอา IC จากบอร์ด A ไปใส่บอร์ด B -> ถ้าบอร์ด B กลับมาทำงานได้ แปลว่า **ชัวร์!** 
  - แต่ระวัง! ถ้าเอา IC ดีไปใส่บอร์ด B แล้ว IC พังอีกตัว แปลว่าปัญหาอยู่ที่จุดอื่นบนบอร์ดที่คอยช็อตทำลาย IC!
- **อย่าเพิ่งรีบเปิดเครื่อง (Power-ON):** ได้บอร์ดเคลมคืนจากลูกค้ามา อย่าเพิ่งเสียบปลั๊ก! ให้ใช้มัลติมิเตอร์วัดความต้านทาน (Ohms) เทียบกราวด์ทุกจุดก่อน ถ้ามีรอยไหม้หรือช็อตอยู่ การเสียบไฟอาจทำลายหลักฐาน (ระเบิดซ้ำ) จนไม่เหลืออะไรให้สืบสวน

## 🗣️ คำศัพท์และประโยคภาษาญี่ปุ่น
- **不具合解析 (Fuguai Kaiseki):** Failure Analysis (การวิเคราะห์ปัญหา/ของเสีย)
- **再現 (Saigen):** Reproduction / Replication (การทำให้เกิดอาการเดิมซ้ำ)
- **切り分け (Kiriwake):** Isolation (การแยกแยะปัญหา/การตีกรอบปัญหา)
- **クロススワップ (Kurosu Suwappu):** Cross-Swap / A-B-A Swap
- **焼損 (Shōson):** Burn out (รอยไหม้)

**ประโยคที่ใช้บ่อย:**
> 「不良基板と良品基板でICのクロススワップを行い、不具合がIC側にあるのか基板側にあるのかを切り分けます。」
> *(Furyō kiban to ryōhin kiban de IC no kurosu suwappu o okonai, fuguai ga IC-gawa ni aru no ka kiban-gawa ni aru no ka o kiriwakemasu.)*
> "จะทำการ Cross-swap ไอซีระหว่างบอร์ดดีกับบอร์ดเสีย เพื่อแยกแยะให้ชัดเจนว่าต้นตอของปัญหาอยู่ที่ตัวไอซี หรืออยู่ที่ตัวบอร์ดครับ/ค่ะ"
