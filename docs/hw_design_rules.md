# 📙 ハードウェア設計基準 (Hardware Design Guidelines)

เอกสารรวบรวมกฎการออกแบบฮาร์ดแวร์และข้อควรระวังจากการทำงานจริง (OJT)

## 1. วงจรจ่ายไฟ (Power Supply Design)

### 1.1 การเลือกใช้ LDO vs DCDC Converter
* **LDO (Low Dropout Regulator):**
  * **จุดเด่น:** สัญญาณรบกวนต่ำมาก (Low Ripple/Noise)
  * **จุดด้อย:** ประสิทธิภาพต่ำ ความร้อนสูง ($P_{loss} = (V_{in} - V_{out}) \times I$)
  * **การใช้งาน:** ใช้กับวงจร Analog, ADC, PLL, RF ที่ต้องการไฟเรียบกริบ (Precision LDO) และกินกระแสไม่สูง
* **DCDC Converter (Switching Regulator):**
  * **จุดเด่น:** ประสิทธิภาพสูง (High Efficiency > 85%) ไม่ร้อนแม้กระแสสูง
  * **จุดด้อย:** มีสัญญาณรบกวนความถี่สูง (Switching Noise) ปล่อยออกมา
  * **การใช้งาน:** ใช้กับไฟ Core ของชิป FPGA/CPU ที่ต้องการกระแสสูง (เช่น $1.2\text{V}$ / 3A)

### 1.2 การกรองสัญญาณรบกวนด้วย Ferrite Bead (フェライトビーズ)
* **หลักการ:** ปล่อยไฟ DC (0 Hz) ผ่านได้สบาย แต่จะบล็อกความถี่สูง (High Frequency Noise) โดยแปลงเป็นความร้อน
* **กฎการเลือกสเปก (Design Rules):**
  * ห้ามเลือกดูแค่ค่า Impedance (เช่น $1000\ \Omega$ @ 100MHz) 
  * ⚠️ **ต้องตรวจสอบ 定格電流 (Rated Current):** หากกระแสที่ไหลจริงสูงกว่าพิกัด จะทำให้เกิด **磁気飽和 (Magnetic Saturation)** ส่งผลให้ความสามารถในการกรอง Noise หายไปทันที
  * ⚠️ **ต้องตรวจสอบ DCR (DC Resistance):** หากนำไปใช้กับวงจรกินกระแสสูง ค่า DCR จะทำให้เกิด Voltage Drop และความร้อน ($P = I^2R$) จนชิปไหม้ได้

### 1.3 ระบบป้องกันในวงจรจ่ายไฟ (Power Supply Protection)
* **ソフトスタート (Soft-Start):**
  * **จุดประสงค์:** ควบคุมให้แรงดันขาออก (Vout) ของ DCDC ค่อยๆ ไต่ระดับขึ้น (เช่น ใช้เวลา 1.3ms) เพื่อป้องกันกระแสดึงกระชากมหาศาลตอนเปิดเครื่อง (**突入電流 / Inrush Current**)
  * **จุดที่ต้องระวัง:** หาก Soft-start เร็วไปหรือวงจรออกแบบไม่ดี อาจเกิด **オーバーシュート (Overshoot)** แรงดันทะลุเป้าหมายไปทำลาย IC ปลายทางได้
* **リセットIC / 電圧監視IC (Reset IC / Voltage Supervisor):**
  * **จุดประสงค์:** ตรวจจับแรงดันไฟเลี้ยง หากไฟมาเต็มจะหน่วงเวลา (**リセット遅延時間 / Reset Delay Time**) ไว้ระยะหนึ่งก่อนปล่อยให้ CPU/FPGA ทำงาน เพื่อรอให้ระบบไฟเสถียร
  * **การตรวจไฟตก:** หากแรงดันตกลงมาถึงจุดที่กำหนด (**検出電圧 / Detection Threshold**) ต้องสั่ง Reset ทันทีเพื่อป้องกันระบบค้าง (Brown-out)


## 2. การออกแบบลายวงจรความเร็วสูง (High-Speed PCB Routing)

### 2.1 Differential Signaling (เช่น USB, LVDS, Ethernet)
* **Impedance Control:** สายคู่ส่วนต่างต้องมีการควบคุม **差動インピーダンス (Differential Impedance)** ให้ตรงสเปก (เช่น USB = $90\ \Omega \pm 10\%$, LVDS/Ethernet = $100\ \Omega$)
* **Length Matching (等長配線):** สาย D+ และ D- ต้องมีความยาวเท่ากันเป๊ะ (Tolerance มักจะอยู่ในหลักไม่เกิน 0.5 - 1.2 mm สำหรับ USB 2.0)
* **ผลเสียหากสายยาวไม่เท่ากัน (Mismatch):** 
  * ทำให้สัญญาณเดินทางไปถึงปลายทางไม่พร้อมกัน เกิดสิ่งที่เรียกว่า **スキュー (Skew)**
  * จุดตัด (Crossover point) ของกราฟ D+ กับ D- จะเหลื่อมกัน ทำให้เสียคุณสมบัติการหักล้างสัญญาณรบกวน (Common-mode rejection หายไป) และแผ่คลื่นแม่เหล็กไฟฟ้า (EMI) ออกมากวนบอร์ด
* **การแก้ไข:** 
  1. พยายามเดินสายคู่กันไปหลบสิ่งกีดขวางพร้อมๆ กัน
  2. หากจำเป็นต้องอ้อม ทำความยาวให้เท่ากันด้วยการทำงูเลื้อย **(Serpentine Routing)** ที่บริเวณใกล้กับจุดที่เกิดความต่างความยาวให้มากที่สุด
